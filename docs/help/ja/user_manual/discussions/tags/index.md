# カテゴリタグ

カテゴリタグを使うと、特定の種類の作業や話題に関するディスカッション、アンケート、結論、コメントを見つけられます。

タグは組織全体で共有されます。親グループで使うタグはサブグループでも同じタグとして扱われるため、組織全体で関連する作業を整理できます。Loomioではタグ名がアルファベット順に表示され、名前の横にタグの色を示す点が表示されます。

グループページでスレッド一覧の上にある**タグ**をクリックします。タグを選択すると、そのタグが付いた投稿を1つ以上含むスレッドが表示されます。タグの一覧が長い場合は、絞り込み用のテキストボックスで検索できます。

![](tags_view.png)

<!-- translation-section: apply-tags -->

## タグを付ける

投稿者とスレッドのコーディネーターは、ロックされていないスレッド内で、アクセスできる投稿のタグを追加または解除できます。**メンバーはディスカッションを編集できます**が有効な場合、メンバーも冒頭のディスカッションにタグを付けられます。アンケートが締め切られた後も、タグは編集できます。アクセス権が取り消された場合、以前の投稿にタグを付ける権限も失われます。

スレッドやアンケートを開始するときに、**タグ**欄をクリックして、タグを1つ以上選択します。

![](tags_add_new.png)

文字を入力すると、一覧を絞り込めます。タグをもう一度選択するか、タグのチップにある×をクリックすると、そのタグを外せます。

<!-- translation-section: create-tags -->

## タグを作成する

親グループの管理者は、いつでも親グループとそのサブグループで使うタグを作成できます。サブグループの管理者は、自分が管理するサブグループのコンテンツにタグを付ける際に、新しいタグを作成できます。グループの権限設定**メンバーはタグを作成できます**は、初期設定で有効になっています。この設定により、コンテンツにタグを付けられる他のメンバーも、新しいタグ名を作成できます。この権限が無効な場合、メンバーは組織の既存のタグと、作成先のグループのテンプレートで指定されたタグ名を使えます。それ以外の名前は保存時に除外されますが、ディスカッション、アンケート、タグの変更は保存されます。

スレッドやアンケートを開始するときにタグを作成するには、**タグ**欄に名前を入力してEnterキーを押します。

![新しいタグを作成](tags_create_new.png)

![作成された新しいタグ](tags_created_new.png)

「財務」「組織運営」「梱包」「カフェとの連携」など、グループのメンバーが分かる、短くなじみのある名前を使います。

<!-- translation-section: template-tags -->

## テンプレートのタグ

ディスカッションとアンケートのテンプレートには、タグ名が初期設定として保存されます。テンプレートを作成または編集できる人は、そのタグ名を自由に変更できます。テンプレートを保存または閲覧しても、これらの名前は組織のタグ一覧に追加されません。組織のタグの名前を変更したり削除したりしても、テンプレートの初期設定は変わりません。

ディスカッションやアンケートでこれらの初期設定を使うと、Loomioは組織の既存のタグを適用するか、権限がある場合はタグを作成します。タグを作成する権限がないメンバーも、作成先のグループで利用できるテンプレートに指定された名前は使えます。他のグループのテンプレートを使っても、タグを作成する権限が追加されるわけではありません。その初期設定が維持されるのは、作成先の組織に同じタグがすでにある場合か、作成先のグループのテンプレートに同じ名前が指定されている場合だけです。それ以外の名前は除外されます。タグを作成できるメンバーは、テンプレートの初期設定をすべて維持できます。

<!-- translation-section: edit-tags -->

## タグを編集する

タグの名前や色の変更、統合、削除ができるのは、親グループの管理者だけです。これらの変更は、サブグループを含む組織全体で、そのタグが付いているすべての投稿に適用されます。

グループページで**タグ**を開き、**タグを編集**を選択します。

![カテゴリタグを編集](tags_edit_new.png)

タグの横にある鉛筆アイコンを選択します。

![カテゴリタグを編集](tags_edit_new_pencil.png)

タグ名を編集するか色を選択して、**保存**をクリックします。

![タグの色を編集](tags_edit_name.png)

**消去**をクリックすると、組織全体のディスカッション、アンケート、結論、コメントからそのタグが削除されます。

![タグを削除](tags_delete.png)

<!-- translation-section: edit-tag-in-thread-or-poll -->

### スレッドやアンケートのタグを編集する

既存のスレッドやアンケートのタグを変更するには、そのスレッドやアンケートを開き、タイトル付近の現在のタグの横にあるタグボタンをクリックします。

タグを選択して追加または解除します。変更はすぐに保存されます。

タグの選択画面には、現在のグループで使われているタグ、組織内の未使用のタグ、その投稿で選択されているタグが表示されます。他のグループだけで使われているタグがある場合、**他のグループのタグを表示**を選択すると、同じ組織の親グループとそのサブグループのタグも表示されます。**このグループで使用されているタグを表示する**を選択すると、表示するタグを絞った一覧に戻ります。グループが1つしかない組織には、一覧を広げる選択肢はありません。

![スレッドのタグを編集](tags_thread_edit.png)

<!-- translation-section: tag-contributions -->

## 投稿にタグを付ける

アンケート、結論、コメントの操作メニューを開き、**タグを適用する**を選択します。ディスカッションのタイトルの横にあるものと同じ選択画面で、タグを追加または解除できます。変更はすぐに保存されます。投稿にタグが付いている場合、投稿者と投稿日時の行の右側に、タグのチップとタグボタンが表示されます。

タグは選択した投稿に適用されます。返信には引き継がれません。冒頭のディスカッションにタグを付けても、そのスレッド内のすべてのコメントやアンケートにタグが付くわけではありません。投票や投票用紙にはタグを付けられません。

<!-- translation-section: find-tagged-contributions -->

## タグ付きの投稿を見つける

冒頭のディスカッションやアンケート以外の投稿にタグが付くと、スレッドのサイドバーに**タグ**セクションが表示されます。ここには、冒頭の項目と、それ以外のすべてのタグ付き投稿から集めたタグが表示されます。タグを選択すると、一致する投稿が、その投稿の文脈が分かる親の投稿とともに表示されます。絞り込み中は、スレッドの上にツールバーが表示され続けます。右側の×ボタンでツールバーを閉じるか、タグをもう一度選択するか、サイドバーで**クリア**を選択すると、通常のスレッド表示に戻ります。モバイルでは、スレッドのナビゲーションドロワーを開くと、同じ絞り込み機能を使えます。

ディスカッションのタイトルの横にあるタグは、冒頭のディスカッションに付いているタグです。グループのスレッド一覧ではスレッド内のすべてのタグが使われるため、冒頭のディスカッションからタグを外しても、別の投稿にそのタグが残っていれば、スレッドはそのカテゴリに表示され続けます。

全体検索でタグを選択すると、そのタグが直接付いている投稿が見つかります。検索語句を入力せずに、タグで閲覧することもできます。タグと語句を組み合わせると、スレッド内のすべての投稿ではなく、そのタグが付いた投稿の内容が検索されます。

投稿者は、アンケートの結果の公開状態に関係なく、自分のコメントにタグを付けられます。タグは共有されるメタデータであり、アンケートが再開されたり、結果が非表示になったりしても利用できます。アンケートの結果が非表示の間も、コメントとそのタグは検索できます。削除された投稿はタグによる絞り込みの対象から除外されます。投稿を復元すると、そのタグも復元されます。タイムラインの項目には、引き続き個々の投稿への名前付きのショートカットが表示され、タグとは独立して機能します。

参加状況レポートでは、各タグを含むスレッドの数が集計されます。そのスレッドに参加していても、そのタグが付いた投稿を作成したとは限りません。
