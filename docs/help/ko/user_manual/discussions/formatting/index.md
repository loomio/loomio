# 텍스트 서식 지정 및 파일 첨부

토론을 시작하거나 편집할 때, 투표를 만들 때, 또는 댓글을 작성할 때 텍스트 입력란 아래에 서식 도구 모음이 표시됩니다. 도구 모음 끝에 있는 화살표를 선택하면 전체 도구를 표시하거나 숨길 수 있습니다.

아이콘 위에 마우스 포인터를 올리면 도구 이름이 표시됩니다.

![](thread_format_bar.png)

<!-- translation-section: attach-file -->

## 파일 첨부

텍스트 입력란 아래에 있는 클립 아이콘을 선택해 기기의 파일을 첨부하세요.

![](format_attach.png)

<!-- translation-section: remove-attachments -->

### 첨부 파일 삭제

편집 중에 파일 이름 옆의 **×**를 선택하면 해당 파일을 삭제할 수 있습니다.

![](thread_file_remove.png)

<!-- translation-section: insert-image -->

## 이미지 삽입

**이미지 삽입**을 선택해 이미지를 업로드하거나, 편집기에 이미지를 직접 붙여 넣으세요. 이미지는 토론, 투표 또는 댓글의 본문 안에 표시됩니다.

![](format_insert_example.png)

<!-- translation-section: insert-link -->

## 링크 삽입

웹페이지나 온라인 문서로 연결되는 링크를 추가할 수 있습니다:

1. 링크로 만들 텍스트를 선택하세요.
2. 링크 아이콘을 선택하세요.
3. **링크 삽입** 입력란에 URL을 붙여 넣고 **적용**을 선택하세요.

참여자가 외부 문서를 열 수 있도록 문서의 공유 권한을 확인하세요. 텍스트 아래에 링크 미리 보기가 표시되면 삭제할 수 있습니다.

![](format_link.png)

<!-- translation-section: insert-emoji -->

## 이모지 삽입

웃는 얼굴 아이콘을 선택해 이모지를 고르세요.

![](thread_insert_emoji.png)

<!-- translation-section: headings -->

## 제목

**제목 1**, **제목 2**, **제목 3**을 사용해 긴 토론이나 댓글의 내용을 체계적으로 구성하세요.

**제목 2** 또는 **제목 3**이 포함된 댓글은 스레드의 **바로 이동** 목록에 자동으로 추가됩니다.

![](format_heading.png)

<!-- translation-section: bold-italicize-strikethrough -->

## 굵게, 기울임꼴, 취소선

텍스트를 선택하고 굵게, 기울임꼴 또는 취소선을 선택해 단어를 강조하거나 취소선을 적용하세요.

![](format_bold.png)

<!-- translation-section: list -->

## 목록

**목록**을 사용해 글머리 기호 목록을 만드세요.

![](thread_bullets.png)

<!-- translation-section: numbered-list -->

## 번호 목록

순서가 있는 단계나 항목에는 **번호 목록**을 사용하세요.

![](format_numbers.png)

<!-- translation-section: task-list -->

## 할 일 목록

**할 일 목록**을 사용해 확인란을 추가하세요. 할 일을 작성하면서 @멘션을 입력해 그룹 멤버에게 배정한 다음, **마감일 추가**를 선택해 마감일과 알림을 설정하세요.

![](format_tasks.png)

자세한 내용은 [할 일 배정 및 추적](/en/user_manual/discussions/tasks/)을 참고하세요.

<!-- translation-section: colors -->

## 색상

**색상**을 사용해 선택한 텍스트에 강조 색상을 적용하세요.

![](thread_colors.png)

<!-- translation-section: align -->

## 정렬

텍스트를 왼쪽, 가운데 또는 오른쪽으로 정렬하세요.

![](thread_align.png)

<!-- translation-section: embed-videos-and-webpages -->

## 동영상 및 웹페이지 삽입

서식 도구 모음이 표시되는 곳이면 어디든 지원되는 동영상과 웹페이지를 삽입할 수 있습니다.

1. 동영상 또는 웹페이지의 URL을 복사하세요.
2. **동영상 삽입**을 선택하고 URL을 붙여넣은 다음 **적용**을 선택하세요.

![](format_embed.png)

>[!Tip]
>토론에 참여하는 모든 사람이 동영상을 볼 수 있는지 확인하세요. 공개 검색 결과에 동영상이 표시되지 않게 하려면 일부 공개로 설정하면 됩니다.

## 인용

**인용**을 사용하여 인용문을 구분하거나 중요한 텍스트를 강조하세요.

![](thread_quote.png)

<!-- translation-section: code-block -->

## 코드 블록

**코드 블록**을 사용하여 코드나 서식이 미리 지정된 텍스트를 표시하세요.

![](thread_codeblock.png)

<!-- translation-section: divider -->

## 구분선

**구분선**을 사용하여 섹션 사이에 가로선을 삽입하세요.

![](thread_line.png)

<!-- translation-section: add-table -->

## 표 추가

표를 삽입하고 표 도구를 사용하여 행과 열을 추가하거나 삭제하세요.

![](thread_table.png)

<!-- translation-section: markdown -->

## 마크다운

마크다운으로 작성하려면 **마크다운 편집**을 선택하세요.

마크다운으로 변환하면 제목, 굵은 글씨와 기울임꼴, 목록, 기본 표, 완료 표시된 할 일, 이미지, 링크, @멘션이 유지됩니다. 동영상, 오디오, 삽입된 콘텐츠는 링크로 바뀝니다.

텍스트 색상, 강조 색상, 밑줄, 정렬, 사용자 지정 표 배치는 유지되지 않을 수 있습니다. 할 일의 마감일과 알림은 삭제됩니다. 서식 있는 텍스트로 다시 전환하면 텍스트와 완료 표시 상태가 동일한 새 할 일이 생성됩니다.

<!-- translation-section: rich-text -->

### 서식 있는 텍스트

**서식 있는 텍스트 편집**을 선택하여 서식 도구 모음으로 돌아가고 지원되는 마크다운을 서식 있는 텍스트로 변환하세요.

마크다운을 변환하지 않고 표시될 모습을 확인하려면 **미리 보기**를 선택하세요.
