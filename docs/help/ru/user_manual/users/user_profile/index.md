# Ваш профиль

Ваш профиль помогает другим людям узнавать вас в Loomio. Добавьте фотографию, информацию о себе и другие сведения, которыми вы хотите поделиться.

<!-- translation-section: edit-profile -->

## Редактирование профиля

Откройте меню пользователя, нажав на своё имя в боковой панели, затем выберите **Редактировать профиль**. Если боковая панель закрыта, откройте её с помощью кнопки меню (**☰**).

![](edit_profile.png)

<!-- translation-section: update-your-personal-info -->

## Обновление личной информации

На странице профиля вы можете изменить любое из этих полей:

- **Имя**
- **Адрес электронной почты** — адрес, связанный с вашей учётной записью Loomio, на который Loomio отправляет уведомления.
- **Имя пользователя** — имя, которое другие люди используют, чтобы уведомить вас с помощью `@mention`. Оно может содержать строчные буквы, цифры, знаки подчёркивания и дефисы внутри имени.
- **Введение** — несколько строк о себе для других участников вашей группы.
- **Расположение** — полезно для удалённо работающих или распределённых групп, чтобы другие люди знали, где вы находитесь.

![](user_profile.png)

<!-- translation-section: uploading-a-profile-photo -->

## Загрузка фотографии профиля

При создании учётной записи Loomio изображением вашего профиля по умолчанию будут ваши инициалы. Чтобы загрузить фотографию, выберите своё изображение на странице профиля.

![](profile_photo.png)

<!-- translation-section: language-settings -->

## Язык

По умолчанию Loomio определяет язык вашего браузера. Вы также можете выбрать предпочитаемый язык на странице профиля. О возможностях перевода интерфейса и содержимого см. [Языки и перевод](../translation).

<!-- translation-section: time-zone -->

## Часовой пояс

Варианты опроса времени используют часовой пояс, сохранённый в вашем профиле. Включите **Автоопределение часового пояса**, чтобы использовать часовой пояс вашего браузера, или отключите эту настройку, выберите свой регион в поле **Часовой пояс** и нажмите **Обновить профиль**.

<!-- translation-section: resetting-your-password -->

## Сброс пароля

Чтобы изменить пароль, откройте страницу профиля и выберите **Сбросить пароль**.

![](reset_password.png#width-90)

<!-- translation-section: passkeys -->

## Ключи доступа

На странице профиля вы можете добавлять ключи доступа, давать им имена и удалять их. Ключи доступа позволяют входить с помощью отпечатка пальца, распознавания лица, PIN-кода вашего устройства или ключа безопасности. См. [Вход с помощью ключа доступа](../signing_in#sign-in-with-a-passkey).

<!-- translation-section: merge-accounts -->

## Объединение учётных записей

Если у вас две учётные записи Loomio, вы можете объединить их в одну.

См. [Объединение учётных записей](../merge_accounts).

<!-- translation-section: deleting-your-account -->

## Удаление учётной записи

Чтобы навсегда удалить свою учётную запись Loomio и выйти из своих групп, см. [Удаление учётной записи Loomio](../deleting_your_account).
