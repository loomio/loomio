# Tareas

Usa las tareas en hilos y comentarios para indicar qué hay que hacer, asignarlo a alguien, fijar una fecha de vencimiento y seguir su progreso.

<!-- translation-section: add-a-task -->

## Añadir una tarea

Mientras escribes un hilo o comentario, despliega la barra de herramientas de formato y haz clic en **Lista de tareas**. Escribe la acción junto a la casilla.

![](tasklist1.png)

<!-- translation-section: name-and-assign-the-task-to-a-person -->

## Describir la tarea y asignarla a una persona

Menciona con @ a un miembro del grupo en la tarea para asignársela. Cuando la tarea tenga una persona asignada, aparecerá el botón **Añadir fecha de vencimiento**.

![](tasklist2.png)

Las tareas que tienes asignadas aparecen en tu página **Tareas**. Ábrela desde la barra lateral para verlas agrupadas por hilo o encuesta.

![](task_list.png)

<!-- translation-section: set-a-reminder -->

## Configurar un recordatorio

Haz clic en **Añadir fecha de vencimiento** para elegir la fecha y cuándo debe Loomio enviar un recordatorio por correo a la persona asignada. También puedes quitar una fecha de vencimiento desde este cuadro de diálogo.

![](taskreminderform.png)

<!-- translation-section: mark-it-as-done -->

## Marcar una tarea como completada

![](taskdone.png)

Haz clic en la casilla junto a una tarea para marcarla como completada. Puedes hacerlo mientras editas el texto, mientras lo lees si tienes la tarea asignada o desde la página **Tareas**. Vuelve a hacer clic para reabrirla.
