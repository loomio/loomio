# Etiquetas de categoría

Las etiquetas de categoría facilitan encontrar hilos y encuestas sobre un tipo de trabajo o tema concreto.

Las etiquetas pertenecen a toda la organización. Una etiqueta utilizada en un grupo principal es la misma en sus subgrupos, lo que permite organizar el trabajo relacionado en toda la organización. Loomio muestra los nombres de las etiquetas en orden alfabético y sus colores como puntos junto a los nombres.

En la página de tu grupo, haz clic en **Etiquetas**, encima de la lista de hilos, para ver las etiquetas utilizadas en el grupo actual. Selecciona una etiqueta para mostrar solo los hilos con esa etiqueta. Usa el campo de filtro para buscar en una lista larga o selecciona **Mostrar más** para incluir todas las etiquetas de la organización. Selecciona **Mostrar menos** para volver a las etiquetas del grupo actual.

![](tags_view.png)

<!-- translation-section: apply-tags -->

## Aplicar etiquetas

Los miembros que pueden editar un hilo o una encuesta pueden aplicarle etiquetas.

Cuando inicies un hilo o una encuesta, haz clic en el campo **Etiquetas** y selecciona una o varias etiquetas.

![](tags_add_new.png)

Empieza a escribir para filtrar la lista. Para quitar una etiqueta, selecciónala de nuevo o haz clic en la × de su ficha.

<!-- translation-section: create-tags -->

## Crear etiquetas

Los admins del grupo principal siempre pueden crear etiquetas para el grupo principal y sus subgrupos. Los admins de los subgrupos pueden crear etiquetas al etiquetar contenido en su subgrupo. El permiso del grupo **Los miembros pueden crear etiquetas**, activado de forma predeterminada, permite que otros miembros que pueden etiquetar un hilo o una encuesta creen nuevos nombres de etiquetas. Si el permiso está desactivado, los miembros pueden seguir aplicando etiquetas existentes.

Para crear una etiqueta al iniciar un hilo o una encuesta, escribe su nombre en el campo **Etiquetas** y pulsa Enter.

![crear una etiqueta nueva](tags_create_new.png)

![etiqueta nueva creada](tags_created_new.png)

Usa nombres cortos y conocidos que los miembros del grupo reconozcan, como Finanzas, Gobernanza, Embalaje o Colaboraciones con cafeterías.

## Editar etiquetas

Solo los admins del grupo principal pueden cambiar el nombre o el color de las etiquetas, fusionarlas o eliminarlas. Estos cambios se aplican a toda la organización, incluidos sus subgrupos.

En la página del grupo, abre **Etiquetas** y selecciona **Editar etiquetas**.

![editar etiquetas de categoría](tags_edit_new.png)

Selecciona el icono del lápiz junto a una etiqueta.

![editar etiquetas de categoría](tags_edit_new_pencil.png)

Edita el nombre de la etiqueta o elige un color y luego haz clic en **Guardar**.

![editar el color de la etiqueta](tags_edit_name.png)

Haz clic en **Eliminar** para quitar la etiqueta de todos los hilos y encuestas de la organización.

![eliminar etiqueta](tags_delete.png)

### Editar etiquetas en un hilo o una encuesta

Para cambiar las etiquetas de un hilo o una encuesta existente, ábrelo y haz clic en el botón de etiquetas junto a las etiquetas actuales, cerca del título.

Selecciona etiquetas para añadirlas o quitarlas. Los cambios se guardan inmediatamente.

![editar etiquetas en un hilo](tags_thread_edit.png)
