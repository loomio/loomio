# Microsoft Teams 연동

Loomio는 새 토론, 투표, 댓글, 표, 결론이 등록되면 Microsoft Teams 채널로 알림을 보낼 수 있습니다.

---

1. [Microsoft Teams](https://teams.microsoft.com)를 열고 **앱**을 선택하세요.

   ![](t1.png)

2. `webhook`을 검색하고 **수신 웹후크**를 선택하세요.

   ![](t2.png)

3. **팀에 추가**를 선택하세요.

   ![](t3.png)

4. Loomio 알림을 표시할 채널을 선택하세요.

   ![](t4.png)

5. `Loomio notifications`와 같은 이름을 입력하고 **만들기**를 선택하세요.

   ![](t5.png)

6. Loomio에 붙여넣을 수 있도록 웹후크 URL을 복사하세요.

   ![](t6.png)

이제 웹후크 URL이 준비되었으니 Loomio에서 연결을 완료하세요.

[Loomio에서 채팅 연동 설정](../chatbots/#set-up-a-chat-integration)

_Loomio는 Microsoft가 제작한 서비스가 아니며, Microsoft와 제휴 관계가 없고 Microsoft의 지원을 받지 않습니다._
