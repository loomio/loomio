# Read the manual in your language

The user manual and guides are now available in Belarusian, Brazilian Portuguese, Dutch, Finnish, French, German, Hebrew, Hungarian, Italian, Japanese, Russian, Spanish and Ukrainian, alongside English. Choose a language from the menu on a manual page.

These translations were produced automatically. If you spot an error, you can suggest a correction to the translated Markdown on [GitHub](https://github.com/loomio/loomio/tree/master/docs). Screenshots use English where a translated image is not available. Policy pages and the changelog remain in English.
