## איך Loomio פועל

ל־Loomio שלושה חלקים עיקריים: קבוצות, דיונים וסקרים.

<!-- translation-section: groups -->

### קבוצות

קבוצה היא מקום שבו ארגון, צוות או קהילה יכולים לעבוד יחד. דף הבית שלה מסביר את מטרת הקבוצה ומאפשר גישה לדיונים, לסקרים, לחברי הקבוצה ולקבצים שלה.

![](orientation_group.png)

<!-- translation-section: discussions -->

### דיונים

דיונים מרכזים את המידע והשיחה בנושא מסוים. אפשר לשתף רקע, לכתוב תגובות, להשיב, להגיב בסימונים ולהשתמש בסקרים כדי לקדם את הדיון לקראת מסקנה.

![](orientation_discussion.png)

עם הזמן, הדיונים יוצרים תיעוד שאפשר לחפש בו את המידע שנבחן ואת ההחלטות שהקבוצה קיבלה.

<!-- translation-section: polls-and-proposals -->

### סקרים והצעות

סקרים עוזרים לקבוצה להבין העדפות, לקבל עצות ולקבל החלטות. תבניות סקר שונות מתאימות לתהליכים שונים. הצעה מבקשת מאנשים להגיב לדרך פעולה מוצעת ולהסביר את הסיבה לתשובתם.

![](orientation_proposal.png)

סקרים יכולים להיות חלק מדיון או להתנהל בנפרד דרך הלשונית **סקרים** בדף הקבוצה.

כדי לראות היכן החלקים האלה מופיעים בממשק, אפשר לעיין ב[סיור קצר](/en/user_manual/overview/orientation). כדי להתחיל להשתתף, אפשר לעיין ב[איך להשתתף](/en/user_manual/overview/how-to-participate).

## איך משתמשים ב־Loomio

**ארגוני חברים** משתמשים ב־Loomio כדי לשתף חברים בהחלטות בקנה מידה רחב. מפלגות פוליטיות, קואופרטיבים של צרכנים ועובדים וארגוני חברים משתמשים בכלי כדי ליצור מרחב בטוח ומכיל לשיתוף מידע ולהעלאת נושאים, להשתתפות בהחלטות חשובות ולהצבעה באספה כללית. כך אפשר לייעל תהליכי קבלת החלטות, לשפר שקיפות ואחריותיות, לתעד דיונים והחלטות ולכלול את קולות החברים בתכנון פעולה משותפת.

**ארגונים בניהול עצמי** משתמשים ב־Loomio כדי לשתף את הצוות בהחלטות. צוותים בניהול עצמי, קואופרטיבים של עובדים וארגונים סוציוקרטיים משתמשים בכלי לניהול תהליכי החלטה המבוססים על הסכמה, קונצנזוס וקבלת עצות, גם כשהצוותים פועלים במקומות ובאזורי זמן שונים. כך אפשר להיעזר בידע הקבוצתי, לחלק את האחריות לקבלת החלטות, לבנות יחד כללי ממשל ומדיניות ולתעד החלטות ודיונים.

**ועדים, מועצות ורשתות מבוזרות** משתמשים ב־Loomio כדי לשתף בעלי עניין בהחלטות. אפשר ליצור מרחב בטוח לדיון, לעקוב אחר התקשורת ולתאם עבודה בין מקומות ואזורי זמן. הכלי מסייע לארגן תהליכי קבלת החלטות, לקצר זמני תגובה ולשמר את הידע הארגוני.

**קהילות מגורים וקואופרטיבים** משתמשים ב־Loomio כדי לקבל החלטות יחד כשכנים. קהילות של דיור שיתופי, כפרים אקולוגיים, קואופרטיבים למגורים, אגודות דיור ונאמנויות קרקע משתמשים בכלי כדי להחליף או להשלים ניהול מסורתי של בתים משותפים ונכסים בממשל דמוקרטי. התושבים מעצבים החלטות על קרקע משותפת, מרחבים משותפים והסכמות קהילתיות. הדיון שאינו דורש השתתפות בו־זמנית מאפשר לחברי הקהילה להשתתף באופן מלא גם כשהם במקום וגם כשהם בנסיעה, ושומר תיעוד ברור של האופן שבו הקהילה בחרה לחיות יחד.

Loomio יוצר תיעוד מתמשך של הארגון: ההחלטות שהתקבלו, האנשים שהשתתפו והדיונים שהובילו להחלטות.
