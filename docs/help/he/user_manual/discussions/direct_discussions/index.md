# דיונים ישירים

דיון ישיר הוא שרשור פרטי המיועד לאנשים מסוימים. הוא אינו שייך לקבוצה, ואין צורך שהאנשים שהוזמנו יהיו חברים בקבוצה כלשהי ב־Loomio.

כדי לקבוע מי יוכל לצפות ולהשתתף, יש להוסיף אנשים או כתובות דוא״ל לשדה **הזמן**.

דיונים ישירים תומכים באותן תגובות, סקרים וכלי עיצוב כמו דיונים בקבוצה. הם מתאימים לשיחות פרטיות או לטיוטות כשאין צורך בתת־קבוצה.

![טופס דיון ישיר ללא קבוצה נבחרת, עם סמירה פאטל בשדה הזמן](direct-discussion-example.png)

כדי לראות את הדיונים והסקרים הישירים, יש לבחור **חוטים ישירים** בסרגל הצד. משם, יש לפתוח את התפריט **חָדָשׁ** ולבחור **דיון חדש** כדי להתחיל דיון ישיר, או **סקר חדש** כדי להתחיל סקר ללא קבוצה.

סקר ישיר גלוי רק לאנשים שהוזמנו אליו. לאחר יצירתו, ניתן להשתמש ב[ניהול מצביעים](/en/user_manual/polls/manage_voters) כדי להזמין אנשים או כתובות דוא״ל.

![הפריט חוטים ישירים בסרגל הצד ורשימת הדיונים הישירים](direct-discussion-sidebar.png)

## העברת דיון ישיר לקבוצה

אם שיחה פרטית או טיוטה מתפתחת לנושא הנוגע לקבוצה, ניתן להעביר אותה בהמשך לקבוצה או לתת־קבוצה. ניתן לעיין ב[העברת שרשור](/en/user_manual/discussions/using_discussions/#move-a-thread).
