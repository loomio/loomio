# 그룹 설정

그룹 설정에서는 그룹이 표시되는 방식, 그룹을 찾고 가입할 수 있는 대상, 멤버가 할 수 있는 작업을 정합니다. 그룹 관리자만 이 설정을 수정할 수 있습니다.

그룹 페이지에서 작업 메뉴를 열고 **그룹 설정 수정**을 선택하세요.

![그룹 페이지에서 그룹 설정 수정](group_settings.png)

설정 양식은 다음 세 영역으로 나뉩니다:

<!-- translation-section: group-profile -->

## 그룹 프로필

[그룹 프로필](/en/user_manual/groups/settings/profile)에서는 그룹 이름, 핸들, 설명, 커버 이미지, 로고를 설정합니다.

<!-- translation-section: group-privacy -->

## 그룹 공개 범위

[그룹 공개 범위](/en/user_manual/groups/settings/privacy)에서는 그룹을 찾을 수 있는 대상, 그룹 콘텐츠를 읽을 수 있는 대상, 가입 방법, 디렉터리 표시 여부, 공개 그룹 팔로우를 설정합니다.

<!-- translation-section: group-permissions -->

## 그룹 권한

[그룹 권한](/en/user_manual/groups/settings/permissions)에서는 멤버, 비멤버, 관리자가 할 수 있는 작업을 정합니다.
