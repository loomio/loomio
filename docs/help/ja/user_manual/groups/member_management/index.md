# メンバー管理

グループの管理者は、グループページの**メンバー**タブからメンバーを管理します。メンバーの横にある操作メニューを開くと、タイトルの設定、グループの管理者や代理人への変更、グループからの削除ができます。

![Oatmilk Cooperativeのメンバーページにあるメンバー操作メニュー](member_management.png)

<!-- translation-section: administering-your-group -->

## グループの管理

Loomioのグループには、**メンバー**と**グループの管理者**の2つの役割があります。

グループの管理者は、メンバーの追加と削除、メンバーの権限管理、グループのプライバシー設定の変更、サブスクリプションの管理、メンバーのメールアドレスの確認、グループのデータのエクスポートができます。

グループを作成した人は、初期設定でグループの管理者になります。常に誰かがグループを管理できるように、グループの管理者を少なくとも2人にすることをお勧めします。グループの管理者の人数に制限はありません。

メンバーをグループの管理者にするには、**メンバー**タブで名前の横にある操作メニューを開き、**管理者を作ります**を選択します。

![メンバーのメニューにある管理者への変更操作](member_make_admin.png)

<!-- translation-section: managing-subgroups -->

## サブグループの管理

親グループの管理者は、秘密ではないどのサブグループにも参加し、自分自身をサブグループの管理者にすることができます。

サブグループのページで**グループに参加**を選択します。

![非公開のOatmilk Cooperativeサブグループにあるグループ参加ボタン](member_join_subgroup.png)

サブグループのメンバーになったら、そのサブグループの**メンバー**タブで自分の名前の横にある操作メニューを開き、**管理者を作ります**を選択します。

>[!Note]
>これは、[**秘密**のサブグループ](/en/user_manual/groups/subgroups#permissions)には適用されません。

<!-- translation-section: removing-members -->

## メンバーの削除

メンバーを削除するには、名前の横にある操作メニューを開き、**グループから削除**を選択します。

![メンバーのメニューにあるグループからの削除操作](member_remove.png)

グループから削除されると、次のようになります。

- その人はグループとそのサブグループにアクセスできなくなり、グループの通知も届かなくなります。
- その人の既存のコメントや投票はそのまま残ります。
- 非公開のアンケートは、その人のダッシュボードと投票リストに表示されなくなります。公開のアンケートは引き続き閲覧できますが、再び招待されない限り投票できません。アンケートが締め切り済みの間に脱退した場合も、再開時に投票する権限は引き継がれません。

削除したメンバーは、後で再びグループに追加できます。再参加すると、アクセスと、投票受付中のアンケートでの既存の投票が復元されます。

<!-- translation-section: leaving-group -->

## グループからの脱退

グループを離れるには、グループページの**設定**を開き、**グループを離れる**を選択します。

脱退すると、グループの管理者によって削除された場合と同じように、グループとサブグループへのアクセスが失われます。

![Oatmilk Cooperativeの設定ページにあるグループからの脱退操作](member_leave_group.png)

<!-- translation-section: set-title -->

## タイトルの設定

メンバーのタイトルは、グループ内での役割や、代表している組織を示します。本人またはグループの管理者が、**メンバー**タブで名前の横にある操作メニューから**タイトルを設定する**を選択して、タイトルを設定または変更できます。

![メンバーのメニューにあるタイトルの設定操作](member_set_title.png)

サブグループごとに異なるタイトルを設定できます。

<!-- translation-section: member-email-addresses -->

## メンバーのメールアドレス

メンバーのメールアドレスを確認できるのは、グループの管理者だけです。

グループとそのサブグループのすべてのメンバーのメールアドレスを確認するには、[グループのデータをエクスポート](/en/user_manual/groups/data_export)してCSVファイルを取得し、Microsoft ExcelまたはGoogle スプレッドシートで開きます。

**メンバー**タブでは、メールアドレスでメンバーを検索し、特定の人を見つけて管理することもできます。
