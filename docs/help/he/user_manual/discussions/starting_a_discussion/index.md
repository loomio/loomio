# פתיחת דיון

פתיחת דיון ב-Loomio דומה לכתיבת מייל. שורת הנושא של המייל דומה לכותרת הדיון, והטקסט שנכתב במייל דומה להקשר של הדיון.

כמו הוספת אנשים לרשימת הנמענים במייל, ב-Loomio ניתן להזמין אנשים לדיון בנפרד או כקבוצה — תישלח אליהם התראה במייל עם תוכן הדיון.

ניתן להשיב לדיון באמצעות מייל, והתגובות יופיעו בדיון.

כמו במייל, דיון יכול להיות שאלה פשוטה או הקדמה מפורטת יותר לנושא, עם קישורים או קבצים מצורפים המספקים מידע רקע.

<!-- translation-section: new-discussion -->

## דיון חדש

כדי לפתוח דיון חדש, יש לבחור בכפתור **דיון חדש** בדף הקבוצה ב־Loomio.

ניתן לפתוח דיון בקבוצה ב־Loomio או בכל תת־קבוצה.

![כפתור דיון חדש בדף קואופרטיב Oatmilk](new-discussion-button.png)

![טופס דיון חדש לתכנון ניסוי בבקבוקים להחזרה](new-discussion-example.png)

<!-- translation-section: group -->

### קבוצה
יש לוודא ששם הקבוצה או תת־הקבוצה מתאים לדיון. כל חברי הקבוצה יוכלו לראות את הדיון. ניתן גם לפתוח את הדיון בקבוצה אחרת או כדיון 'ישיר' (ללא קבוצה).

>[!Tip]
>אם עדיין אין רצון להציג את הדיון בקבוצה, ניתן לפתוח אותו כדיון 'ישיר'. ניתן להעביר את הדיון לקבוצה ב־Loomio כשיגיע הזמן המתאים.

<!-- translation-section: invite-and-notify -->

### הזמנה ושליחת התראות

השדה **הזמן** קובע למי יישלח הדיון החדש מיד עם פתיחתו.

חברי הקבוצה יכולים לראות דיון בקבוצה שלהם גם ללא קבלת התראה. הוספת חבר קבוצה לשדה **הזמן** שולחת אליו התראה במייל והתראה ב-Loomio.

יש לבחור קבוצה כדי לשלוח התראה לכל חבריה, או להרחיב את הקבוצה לבחירה של חברים מסוימים. יש לבחור בסימן × לצד שם כדי להסיר את האדם מרשימת הנמענים להתראה.

![השדה הזמן מורחב להצגת נמענים בודדים](../notifying_people/thread_notification.png)

יש להתחיל להקליד שם של חבר קבוצה ולבחור אותו מהרשימה.

![חיפוש סמירה פאטל בשדה הזמן](../notifying_people/thread_notify_user.png)

יש להזין כתובת מייל כדי להזמין אורח. אורח יכול לראות את השרשור הזה ולהשתתף בו, אך אינו יכול לראות דיונים אחרים בקבוצה ללא הזמנה נפרדת.

![הוספת כתובת מייל של אורח לשדה הזמן](../notifying_people/thread_notify_email.png)

ניתן גם לפתוח את הדיון ללא שליחת התראות. חברי הקבוצה עדיין יכולים למצוא אותו ב-Loomio, והוא עשוי להופיע במייל העדכונים שלהם, בהתאם להגדרות ההתראות שלהם.

### תגיות

ניתן להוסיף תגיות כדי לעזור לאנשים למצוא את הדיון בחיפוש לפי תגית. מנהלים יכולים ליצור תגיות חדשות.

<!-- translation-section: title -->

### כותרת
יש לתת לדיון כותרת מתאימה. כותרת הדיון דומה לשורת הנושא במייל.

<!-- translation-section: context -->

### הקשר
יש להשתמש בהקשר של הדיון כדי להציג את הנושא ולהגדיר את מסגרת השיחה או את ההחלטה שיש לקבל. ניתן להשתמש בכלי העיצוב כדי להדגיש נקודות מרכזיות. ניתן לכלול מידע רקע, לצרף קבצים, להוסיף קישורים למסמכים מקוונים ולהטמיע סרטון.

ההקשר תמיד יישאר בראש הדיון, וניתן לעדכן אותו בכל עת ככל שהדיון מתקדם. בסיום הדיון, יש לעדכן את ההקשר במסקנה.
