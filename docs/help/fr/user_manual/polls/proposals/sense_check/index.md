# Prise de température

La prise de température recueille les réactions pendant qu’une idée est encore en cours d’élaboration. Ses options — **Ça a l'air bien**, **Pourrait être mieux** et **Il faut le repenser** — indiquent si le groupe est prêt à poursuivre ou s’il doit d’abord revoir l’idée.

Cette page explique comment organiser une prise de température. Consultez le [Processus de décision simple](/en/guides/making_decisions/simple_decision_process), le [Processus de consentement](/en/guides/making_decisions/consent_process) ou le [Processus de consensus](/en/guides/making_decisions/consensus_process) pour découvrir des exemples où la prise de température constitue une étape d’un processus plus large.

<!-- translation-section: when-to-use-sense-check -->

## Quand utiliser la prise de température

Utilisez la prise de température pour :

- tester une première ébauche avant de consacrer du temps à une proposition détaillée ;
- faire ressortir les questions et les préoccupations avant une décision formelle ;
- vérifier si un autre tour de discussion est nécessaire ; ou
- comparer le soutien avant et après la révision d’une idée.

Ne considérez pas **Ça a l'air bien** comme une approbation formelle, sauf si le groupe en a explicitement convenu. Utilisez le [Consentement](../consent/) ou le [Consensus](../consensus/) lorsque la réponse doit autoriser une décision.

<!-- translation-section: example-check-a-trial-plan -->

## Exemple : vérifier un plan d’essai

La coopérative Oatmilk a préparé un projet d’essai de bouteilles consignées. Elle organise une prise de température pour savoir si le calendrier de collecte, les contrôles de lavage et le plan de suivi sont prêts pour un examen final.

<!-- translation-section: set-up-the-proposal -->

## Configurer la proposition

Indiquez à quel stade se trouve l’idée et comment les retours seront utilisés. Conservez le sens des réponses par défaut ou modifiez-les pour les adapter au vocabulaire du groupe. Fixez une heure de clôture qui laisse suffisamment de temps pour revoir le plan.

<!-- translation-section: vote -->

## Voter

Les participants choisissent la réponse qui représente le mieux leur avis actuel et expliquent ce qui est prêt ou ce qui devrait changer. Une raison utile donne à l’auteur de la proposition un point concret sur lequel agir.

![](../proposal_sense_check_voting.png)

<!-- translation-section: read-the-results -->

## Lire les résultats

Le graphique indique le nombre et la proportion de votes pour chaque réponse. Lisez les raisons en plus de la répartition des votes : une seule préoccupation bien fondée peut mériter votre attention, même si la plupart des participants choisissent **Ça a l'air bien**.

![](../proposal_sense_check_results.png)

<!-- translation-section: share-an-outcome -->

## Partager une conclusion

Lorsque la prise de température est clôturée, partagez une conclusion. Résumez les changements que le groupe apportera ou indiquez que l’idée est prête pour la prochaine étape de décision. Consultez [Partager une conclusion](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome) pour comprendre le fonctionnement des conclusions.
