# STV選挙

**単記移譲式投票（STV）**は、複数の候補者から複数の当選者を選ぶ比例代表制の投票方式です。有権者の多様な意見が、当選者の構成に比例して反映されます。

<!-- translation-section: when-to-use-stv -->

## STVを使う場面

次のような場合にSTV選挙を使います。

- 候補者の中から**委員会、理事会、代表団**のメンバーを選ぶ
- 少数派も支持に応じて議席を得られる**比例代表**を実現する
- 有権者が候補者を希望順に並べる選挙を行う

>[!NOTE]
>STVはLoomioの[ランク投票](/en/user_manual/polls/rank/)とは**異なります**。ランク投票は、点数に基づいて候補を順位付けし、最もよい選択肢を一つ選ぶ簡単な方式です。STVは票の移譲と候補者の脱落を繰り返し、複数の当選者を選びます。

<!-- translation-section: creating-an-stv-election -->

## STV選挙を作成する

投票を開始するとき、投票の種類に**STV選挙**を選び、候補者を投票の選択肢として追加します。**議席数**、**集計方法**、**クォータの種類**を設定できます。

この例では、Oatmilk Cooperativeが返却可能な包装の試験運用を監督する3人を選びます。フォームには役割の説明と5人の候補者があり、Scottish STVとDroopクォータを使用しています。

![](form.png)

<!-- translation-section: number-of-seats -->

### 議席数

選出する当選者の人数です。候補者の人数より少なくする必要があります。

<!-- translation-section: counting-method -->

### 集計方法

票の集計方法は二つあります。

Scottish STV
  : 推奨。2007年からスコットランドの地方選挙で使われている加重包括グレゴリー方式（WIGM）です。規則が明確で分かりやすく、ほとんどの組織に適しています。
  
Meek STV
  : コンピューターでのみ集計できる、より精密な方式です。候補者が当選すると、その候補者が必要としない各票の部分を、有権者の次以降の希望先へ移譲し続けます。集計の途中で後からその候補者に移譲された票も対象です。候補者が脱落すると、その候補者が最初から立候補していなかったものとして票を再集計します。Scottish STVよりも生かされない票が少なくなりますが、手計算で集計を検証することはできません。

<!-- translation-section: quota-type -->

### クォータの種類

クォータは、候補者が議席を得るために必要な最低票数です。次のいずれかを選べます。

Droop
  : 推奨。STV選挙の標準的なクォータで、アイルランド、オーストラリア、スコットランドで使われています。議席数を超える人数の候補者が到達することのない、最小のクォータです。自分たちの候補者を第一希望に順位付けする有権者の集団は、その集団の票数に含まれるクォータの個数以上の議席を獲得します。次のように計算します。
\\[ floor(\frac{votes}{(seats + 1)}) + 1 \\]

Hare
  : より大きなクォータです。票数の多い集団は、獲得する議席ごとにより多くの票を使うため、小さな集団が最後の議席を獲得しやすくなります。次のように計算します。
    \\[ \frac{votes}{seats}\\]

どちらの式でも、*votes*は少なくとも1人の候補者に順位を付けた投票用紙の数です。

Meek STVでは、クォータを丸めずに計算します。Droopの場合は votes ÷ (seats + 1) です。各ラウンドで候補者が保持している票を基にクォータを再計算し、候補者が当選するにはクォータを超える必要があります。
  
  >[!TIP]
  > Droopの必要票数は常にHareより少なくなります。たとえば、100票で4議席を選ぶ場合、Droopクォータは21票、Hareクォータは25票です。

<!-- translation-section: how-voting-works -->

## 投票の仕組み

この例では、Oatmilk Cooperativeが再利用可能な包装の試験運用を監督する3人を選びます。有権者は候補者を線の上へドラッグし、希望する順に並べます。

![](stv-vote-in-progress.png)

- **第1希望** = 最も希望する候補者
- **第2希望** = 2番目に希望する候補者
- 希望する人数まで候補者に順位を付けます

有権者は少なくとも1人の候補者に順位を付ける必要がありますが、すべての候補者に順位を付ける必要はありません。順位を付けなかった候補者に、その有権者の票が移ることはありません。

<!-- translation-section: how-counting-works -->

## 集計の仕組み
集計は次の手順で行います。

1. **クォータ**（議席を得るために必要な最低票数）を計算します。
2. 各候補者の**第一希望**の票を数えます。
3. クォータに達した候補者は全員**当選**します。クォータを超えた余剰票は、余剰が最も多い候補者から順に、票の価値を按分して有権者の次の希望先へ**移譲**します。票の移譲先は、集計に残っている候補者に限られます。
4. 移譲する余剰票が残っていない場合は、**得票数が最も少ない候補者が脱落**します。その候補者の票は、票の価値を減らさずに有権者の次の希望先へ移譲します。
5. 残っている候補者の数が残りの議席数と等しくなると、クォータに達していなくても、その候補者は全員当選します。
6. それ以外の場合は、すべての議席が埋まるまで手順3から繰り返します。

票の価値を按分することで、当選者が必要としない票だけを配分します。たとえば、クォータが26票で、候補者が40票を得ている場合、余剰は14票です。40枚の投票用紙はそれぞれ、14 ÷ 40 = 0.35票の価値で次の希望先へ移譲されます。

Scottish STVでは、スコットランドの地方議会選挙と同様に、移譲する各票の価値を小数点以下5桁までで切り捨てます。

得票数が最も少ない候補者が2人以上いる場合は、過去のラウンドを直近からさかのぼり、得票数に差があったラウンドで票数が少なかった候補者が脱落します。

>[!TIP]
>投票用紙は、順位を付けた候補者が集計に残っている間だけ集計対象になります。その候補者が誰も残っていなくなると、その投票用紙は「移譲先なし」となり、以後の集計には使われません。

### 集計方法とクォータ

上部には、集計方法（Scottish STVまたはMeek STV）、クォータの種類（DroopまたはHare）、当選に必要だった票数が表示されます。

<!-- translation-section: elected-candidates -->

### 当選者

当選者の概要が、5列の表に表示されます。

| 列 | 意味 |
|--------|---------|
| **候補者** | 当選した候補者の名前 |
| **ラウンド選出** | クォータに達して議席を得た集計ラウンド。第1ラウンドは第一希望の票だけで当選したことを示します。それ以降のラウンドでは、脱落者の票や当選者の余剰票の移譲によって当選しています。 |
| **第一希望** | この候補者を第1希望に選んだ有権者の数。票が移譲される前の直接の支持を示します。 |
| **最終集計** | 当選した時点での候補者の得票数。票の移譲によって、第一希望の票数より多くなることがよくあります。 |
| **余剰** | 最終集計がクォータを超えた票数（最終集計からクォータを引いた数）。余剰が多いほど、当選に必要な票数を超える支持が多いことを示します。Scottish STVでは、この余剰を有権者の次の希望先に再配分します。 |

過去のラウンドでも同点を解消できない場合があります。同点の扱いによって当選者が変わらない場合は、集計を続けます。当選者が変わる場合は、そのラウンドで集計を停止します。同点をどのように解消しても当選する候補者は、当選者として表示されます。同点の扱いによって当選にも落選にもなり得る候補者は、別の表に表示されます。Loomioでは、無作為に1人を選ぶ代わりに、これらの候補者を同点として表示します。

<!-- translation-section: round-by-round-details -->

### ラウンドごとの詳細

**ラウンドごとの詳細**を展開すると、票の移譲と候補者の脱落を確認できます。各行が候補者、各列が集計ラウンドです。各数値は、そのラウンドの開始時点で候補者が保持していた票数です。

![](stv-results.png)

緑色は当選、赤色は脱落、オレンジ色は同点になったラウンドを示します。

## 結論を共有する

選挙が終了したら、結論を共有します。当選した人の名前と、役割を開始する時期を記載します。結論の使い方については、[結論を共有する](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome)を参照してください。

## 投票用紙のエクスポート

選挙の締め切り後、結果を閲覧できる人は、独立した再集計や監査のために投票用紙をBLT形式でエクスポートできます。エクスポートには候補者の順位が含まれ、同じ順位付けの投票用紙は件数とともに1行にまとめられます。匿名選挙では、投票者の身元、投票用紙の識別子、送信日時、送信順序は含まれません。
