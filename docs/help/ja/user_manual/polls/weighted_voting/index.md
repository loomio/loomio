# 加重投票

加重投票では、各投票者に票の重みを設定することで、一部の票を他の票よりも大きく数えることができます。例えば、次のように使えます。

- 住宅コミュニティで、各物件に1票を与えます。3つの物件を代表するメンバーの票の重みは `3` になります。
- 労働者協同組合で、加入から一定期間が経過したメンバーに投票権を与えます。加入して間もないメンバーの票の重みは `0` に設定されるため、結果に影響を与えることなく、ディスカッションに参加し、投票を試すことができます。
- 会社が株主に持株比率に応じた票を与えます。株式の12.5%を保有する人の票の重みは `12.5` になります。

<!-- translation-section: set-members-vote-weights -->

## メンバーの票の重みを設定する

グループの管理者は、グループの**メンバー**ページを開き、**投票の重みを編集する**を選択できます。票の重み（`0` 以上、小数点以下3桁まで）を入力し、**投票の重みを保存する**を選択します。名前やメールアドレスで検索して対象の人を見つけるか、**すべての投票の重みを設定する**を選択して、すべてのメンバーに同じ票の重みを設定できます。

![グループのメンバーの票の重み](member-weights.png)

メンバーの票の重みは、そのメンバーが各アンケートに追加されるときにコピーされます。後から変更しても、既存のアンケートには影響しません。

<!-- translation-section: use-weighted-voting-in-a-poll -->

## アンケートで加重投票を使用する

アンケートのフォームで**その他の設定**を開き、**加重投票を使用する**を選択します。投票開始後も、加重投票を有効または無効にできます。無効にすると、アンケート内のすべての票の重みが `1` にリセットされ、そのアンケートで個別に設定した票の重みは失われます。

グループの定例の手順で加重投票を使う場合は、[アンケートのテンプレート](/en/user_manual/polls/poll_templates)で**加重投票を使用する**を有効にします。そのテンプレートから開始したアンケートでは、既定で加重投票が使われます。

![アンケートの「加重投票を使用する」設定](poll-setting.png)

加重投票は、次のアンケート形式で使用できます。[提案](/en/user_manual/polls/proposals)、[選択](/en/user_manual/polls/choose)、[スコア](/en/user_manual/polls/score)、[配分](/en/user_manual/polls/allocate)、[ランク](/en/user_manual/polls/rank)です。

同じアンケートで、加重投票と[匿名投票](/en/user_manual/polls/anonymous_voting)を併用することはできません。

1人の投票者の票の重みを変更するには、**有権者の管理**を選択し、その人の名前の横にある票の重みを選択します。全員の票の重みを変更するには、**すべての投票の重みを設定する**を選択します。グループから各メンバーの票の重みをコピーするか、全員に同じ値を設定できます。グループのメンバーではない投票者の票の重みは `1` になります。

![アンケートの「有権者の管理」ボタン](poll-manage-voters.png)

![個別の票の重みが設定されたアンケートの投票者](poll-voter-weights.png)

## 結果

結果では、重みを適用しない合計と、重みを適用した合計が並んで表示されます。

- 提案と選択のアンケートでは、**投票**と**加重投票**が表示されます。
- スコア、配分、ランクのアンケートでは、**ポイント**と**加重ポイント**が表示されます。

グラフには、重みを適用した結果が表示されます。列の見出しを選択すると、その列のデータをグラフに表示できます。投票を閲覧できる人は、各投票者の票の重みも閲覧できます。

提案と選択のアンケートでは、**未投票**の行の**投票**列に未投票の人数が、**加重投票**列に未投票の票の重みの合計が表示されます。これらの列と**投票可能な票の重みに対する%**では、未投票の人もグラフに含まれます。**投票済みの票の重みに対する%**では、**未投票**の欄は空白になり、グラフからも除外されます。

票の重みは、[定足数](/en/user_manual/polls/quorum)と[得票率の要件](/en/user_manual/polls/vote_share_requirements)にも適用されます。

以下の例では、Jamieは票の重み `2` で**賛成**に投票しています。3人が**反対**に投票しており、票の重みはそれぞれ `1`、`0`、`0` です。票の重みが `2` と `1` の2人は、まだ投票していません。

賛成の票数は投票済みの4票のうち1票ですが、票の重みでは投票済みの合計の3分の2を占めます。投票済みの票の重みは、投票可能な票の重みの合計の半分なので、60%の定足数には達していません。
