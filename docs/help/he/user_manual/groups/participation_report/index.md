# דוח השתתפות

דוח ההשתתפות מציג את הפעילות בקבוצת Loomio ובתת־הקבוצות שלה.

ניתן לבחור אילו קבוצות לכלול, לקבוע תאריכי התחלה וסיום ולקבץ את התוצאות לפי שנה, חודש, שבוע או יום.

הדוח זמין לכל חברי הקבוצה, אך לכל אדם מוצגות רק תוצאות של קבוצות שיש בהן חברות. לכן חברים שונים עשויים לראות סיכומים שונים.

כדי לפתוח את הדוח, יש לפתוח את **הגדרות** בדף הקבוצה ולבחור ב־**דוח השתתפות**. בכל טבלה בדוח, ניתן לבחור בכותרת עמודה כדי למיין לפי אותה עמודה.

![האפשרות לפתיחת דוח השתתפות בדף ההגדרות של קואופרטיב Oatmilk](group_participation_report.png)

## מה כולל הדוח

### פעולות לאורך זמן

הגרף מציג כמה שרשורים, תגובות, סקרים, הצבעות ותגובות אימוג׳י נוצרו בכל פרק זמן שנבחר, כדי לאפשר לזהות שינויים בפעילות. יש לבחור בתווית בגרף כדי להסתיר או להציג את המדד המתאים.

![פקדי דוח ההשתתפות, סיכומים וגרף פעילות של קואופרטיב Oatmilk](group_participation_report_graph.png)

### שימוש בתגיות

התרשים מציג את התדירות שבה הוחלו תגיות במהלך התקופה שנבחרה, למשל כמה דיונים השתמשו בתהליך החלטה או בתבנית מסוימים.

![פעילות תגיות לאורך זמן עבור ייצור, שותפויות עם בתי קפה ותפעול](group_participation_report_tags.png)

### פעולות לפי משתמש

הטבלה מציגה כמה שרשורים, תגובות, סקרים, הצבעות ותגובות אימוג׳י נוצרו על ידי כל חבר בקבוצה במהלך התקופה שנבחרה.

יש להפעיל את **נציגים בלבד** כדי להגביל את הטבלה לאנשים המשמשים כעת כנציגים באחת מהקבוצות שנבחרו. הפעילות שלהם מרוכזת מכל הקבוצות שנבחרו, ונציגים ללא פעילות עדיין מופיעים בטבלה. אותו סינון חל גם על קובץ ה־CSV להורדה.

![פעולות לפי נציג המציגות שלוש רמות השתתפות](group_participation_report_actions_per_user.png)

### רישום הצבעות לפי משתמש

הטבלה משווה בין מספר ההצבעות שכל אדם הוזמן להשתתף בהן לבין מספר ההצבעות שבוצעו בפועל, מציגה הצבעות שהוחמצו ומדגישה אנשים שהצביעו בכל ההצבעות שהוזמנו להשתתף בהן. אדם שלא הוזמן להשתתף באף הצבעה אינו מסומן כמי שהצביע בכל ההצבעות. סקרים אנונימיים אינם נכללים, משום שהצבעות אנונימיות אינן מקושרות למצביעים מסוימים.

יש להפעיל את **נציגים בלבד** כדי לבדוק את רישום ההצבעות של הנציגים הנוכחיים. אותם מסננים לפי שם ולפי נציגים חלים גם על קובץ ה־CSV להורדה.
