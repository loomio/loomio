# בעלי זכות הצבעה כנציגים

ניתן להשתמש בנציגים כשכל חברי הקבוצה צריכים לחלוק מרחב דיון משותף, אך רק קבוצה מוגדרת של חברים, כגון חברי דירקטוריון או נציגים נבחרים, אמורה להצביע. זה פשוט יותר מניהול תת־קבוצה נפרדת שמטרתה היחידה היא להפריד בין מצביעים למי שאינם מצביעים.

יש להשתמש בתת־קבוצה פרטית כאשר אותם חברים זקוקים גם לדיונים, לקבצים או לרשימת חברים שאין לחשוף בפני חברים אחרים.

רק מנהל קבוצה יכול להעניק או להסיר מעמד של נציג. בלשונית **חברים** בדף הקבוצה, יש לפתוח את תפריט הפעולות שלצד שם האדם ולבחור **לעשות נציג**. להסרת המעמד יש לבחור **בטל נציג** באותו תפריט.

![הפעולה לעשות נציג בתפריט של חבר בקבוצה](member_make_delegate.png)

כדי ליצור סקר או הצעה שרק נציגים יכולים להצביע בהם, יש לבחור **אנשים נבחרים בלבד** בהגדרות הסקר.

![ההגדרה אנשים נבחרים בלבד בעת יצירת הצעה](poll_invited_people_only.png)

בעת בחירת האנשים שיוזמנו להצביע, יש לבחור **נציגים של [שם הקבוצה]**.

![האפשרות נציגים של קואופרטיב חלב שיבולת שועל בטופס ההזמנה להצבעה](poll_invite_delegates_group.png)

כדי להציג את כל הנציגים בקבוצה, יש לפתוח את הלשונית **חברים** ולבחור **נציגים** מתפריט הסינון.

![האפשרות נציגים במסנן החברים](members_list_delegates.png)
