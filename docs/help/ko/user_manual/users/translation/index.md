# 언어 및 번역

Loomio의 인터페이스 언어를 변경하거나 토론, 댓글, 제안을 원하는 언어로 번역하세요.

<!-- translation-section: application-translation -->

## 앱 번역

Loomio는 브라우저의 기본 언어를 감지합니다. 다른 언어를 사용하려면 **프로필 수정**을 열고 원하는 언어를 선택하세요.

![기본 언어 변경](change_language.png)

<!-- translation-section: content-translation -->

## 콘텐츠 번역
그룹의 다른 사람이 작성한 메시지의 언어가 설정한 기본 언어와 다르면 메시지 아래에 "번역" 버튼이 표시됩니다. 이 버튼을 클릭하면 메시지가 기본 언어로 자동 번역됩니다.

![댓글 아래의 번역 버튼](content_translation.png)

토론에서 원문이 번역된 텍스트로 대체됩니다. 원문을 다시 표시하려면 **원문**을 선택하세요.

![스페인어에서 영어로 번역된 댓글](content_translated.png)

사용자 콘텐츠 번역은 Google 번역을 통해 제공되며, 사용자가 요청할 때 수행됩니다.

<!-- translation-section: automatic-translation -->

## 자동 번역

지원되는 콘텐츠를 자동으로 번역하려면 **프로필 수정**을 열고 **내 언어로 콘텐츠 자동 번역**을 선택하세요. Loomio는 프로필에서 선택한 언어를 사용합니다.

![프로필 수정 페이지의 콘텐츠 자동 번역 설정](automatic_translation.png)
