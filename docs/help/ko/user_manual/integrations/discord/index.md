# Discord 연동

_Loomio 그룹 알림을 Discord 팀 채팅에 연결합니다._

Loomio는 새 토론, 제안, 댓글, 표, 결론이 등록되면 Discord 채널로 알림을 보낼 수 있습니다. 결정에 대해 다시 알려야 할 때는 채팅방에 직접 알림을 보낼 수도 있습니다.

---

Discord 서버를 열고 서버 설정 메뉴를 찾으세요.
![](server-settings.png)

"연동"을 클릭하세요.
![](integrations.png)

그런 다음 "웹후크 추가"를 클릭하고 "Loomio 봇"과 같은 이름을 입력하세요.

![](add-webhook.png)

웹후크 URL을 클립보드에 복사했는지 확인하고 아래 링크를 따라가세요.

[Loomio에서 채팅 연동 설정](../chatbots/#set-up-a-chat-integration)
