# グループの削除

Loomioのグループを削除すると、グループのすべてのデータを完全に削除する処理が開始されます。

残しておきたいデータがある場合は、続行する前に必ず[グループのデータをエクスポート](/en/user_manual/groups/data_export/)し、アップロードした重要なファイルを手動でダウンロードしてください。

3つの点をクリックしてグループのドロップダウンメニューを開き、**グループの削除**を選択すると、グループへのアクセスが無効になり、Loomioに保存されているグループのすべてのデータの削除処理が開始されます。グループを削除するには、管理者である必要があります。

グループを削除すると、すぐに表示されなくなり、90日後に完全に削除されます。削除した人を含め、グループのメンバーはすぐにグループへアクセスできなくなります。誤って削除した場合は、グループを削除してから90日以内にLoomioに連絡し、復元を依頼してください。

削除待ちのグループとそのサブグループでは、メンバーやコーディネーターによる閲覧、参加、エクスポートができなくなります。保存したリンクから開くアンケートも対象です。メンバーはコンテンツの作成や編集、投票、お知らせやリマインダーの送信、招待の承諾ができません。削除を確定する前に、グループをエクスポートし、重要なファイルをダウンロードしてください。グループに属さない直接のディスカッションやアンケートには影響しません。

グループの削除を予約すると、そのグループとサブグループの未送信のアクティビティ通知とアンケートのリマインダーが停止します。すでに送信中のメッセージは届く場合があります。

警告メールには、グループのサブグループ数、メンバー数、ディスカッション数、アンケート数、コメント数が記載されます。グループを残す必要がある場合や、[データをエクスポート](/en/user_manual/groups/data_export/)する必要がある場合は、削除前にアクセスを復元できるよう、90日以内に返信してください。

グループを削除すると、Loomioのサブスクリプションも解約されます。

グループの削除を確認するため、グループ名の入力を求められます（*大文字と小文字は区別されます*）。

![Oatmilk Cooperativeのハンドル名の入力を求める確認フォーム](group_delete_group_confirm.png)

## グループのデータは90日後に完全に削除されます

90日後、すべてのスレッド、アンケート、ファイル、その他のグループ内のコンテンツが完全に削除されます。***この操作は取り消せません。***

続行する前に、[グループのデータをエクスポート](/en/user_manual/groups/data_export/)し、アップロードした重要なファイルを手動でダウンロードすることをお勧めします。
