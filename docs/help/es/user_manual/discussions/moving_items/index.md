# Mover elementos entre hilos

Mueve comentarios o encuestas cuando una conversación corresponda a otro hilo, cuando una discusión se divida en temas distintos o cuando quieras combinar hilos relacionados.

Los admins del grupo pueden mover elementos. Los miembros también pueden mover elementos cuando la opción **Los miembros pueden gestionar discusiones y comentarios.** está activada en [Permisos del grupo](/en/user_manual/groups/settings/permissions).

1. Abre el menú de tres puntos (**⋯**) de un elemento y selecciona **Mover elemento**.

![](../using_discussions/comment_move.png)

2. Usa las casillas para seleccionar los elementos que quieras mover y luego selecciona **Mover** en la franja de la parte superior del hilo.

![](../using_discussions/comment_select.png)

![](../using_discussions/move_items.png)

3. Elige el grupo o subgrupo de destino y luego busca una discusión existente. Para crear una nueva discusión, selecciona **Nueva discusión**, añade un título y un contexto y selecciona **Iniciar discusión**.

![](../using_discussions/move_items_new_thread.png)

Los elementos seleccionados se trasladan del hilo original al hilo de destino.

![](../using_discussions/new_thread.png)

Si ya no necesitas el hilo original, puedes [bloquearlo](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread). Elimínalo solo si tienes la certeza de que no volverás a necesitarlo.
