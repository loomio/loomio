# Äänioikeutetut edustajat

Jos osalla ryhmäsi jäsenistä pitäisi olla äänioikeus ja osalla ei, voit merkitä äänioikeutetut jäsenet ”Tee valtuutettu” -toiminnolla. Voit myös poistaa edustajan aseman ”Peruuta edustaja” -toiminnolla.

Käytä edustajia, kun kaikkien pitäisi voida osallistua samoihin keskusteluihin, mutta vain tietty joukko, kuten johtokunnan jäsenet tai valitut edustajat, saa äänestää. Tämä on yleensä yksinkertaisempaa kuin ylläpitää erillistä alaryhmää, jonka ainoa tarkoitus on erottaa äänestäjät muista jäsenistä.

Käytä yksityistä alaryhmää, jos sen jäsenet tarvitsevat myös keskusteluja, tiedostoja tai jäsentietoja, joita muut jäsenet eivät saa nähdä.

Avaa ryhmäsivulla **Jäsenet**, etsi henkilö ja valitse **Tee valtuutettu** hänen nimensä vieressä olevasta kolmen pisteen valikosta. Poista edustajan asema valitsemalla samasta valikosta **Peruuta edustaja**.

![Tee valtuutettu -toiminto jäsenen valikossa](member_make_delegate.png)

Jos haluat luoda kyselyn tai ehdotuksen ja kutsua siihen vain edustajat, valitse kyselyn asetuksista ”Vain valitut henkilöt”.
![Vain valitut henkilöt -asetus ehdotusta luotaessa](poll_invited_people_only.png)
Kun kutsut ihmisiä äänestämään, näet vaihtoehdon ”Ryhmän ryhmän-nimi edustajat”.
![Oatmilk Cooperative -ryhmän edustajat -vaihtoehto äänestyskutsulomakkeessa](poll_invite_delegates_group.png)

Näet luettelon edustajista ryhmäsivusi jäsenet-välilehdellä. Avaa suodatusvalikko ja valitse ”Edustajat”.
![Edustajat-vaihtoehto jäsenluettelon suodattimessa](members_list_delegates.png)
