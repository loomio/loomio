# 管理と記録の保管

理事会や委員会では、管理業務と監査のための適切な記録保管が重要です。法律で求められる場合もあります。

紙の記録に代わって、電子記録が使われることが増えています。

デジタルツールを使えば、議事録の保管にとどまらない仕事ができます。

理事会の活動を変えるには：

*「私たちの理事会グループは大きく変わりました。継続的な運営が可能になり、対応が速くなり、柔軟性、回復力、持続可能性も高まりました。Loomio によって毎年数千ポンドを節約しています」*
- オースティン・コルダスコ、Co-operative Assistance Network Limited（CAN）、事業支援サービス、英国

Loomio で仕事を整理し、ディスカッションを管理し、データを安全に保ち、記録を保存する方法を見ていきます。

<!-- translation-section: administering-discussions -->

## ディスカッションの管理

ディスカッションの右側にあるドロップダウンメニューから、管理に役立つさまざまな機能を利用できます。

次の機能を使って、ディスカッションの一覧を整理できます：

- **ピンの議論**を使うと、重要なディスカッションを一覧の先頭に表示できます
- **スレッドを編集する**を使うと、タイトルや説明を変更できます
- **グループに移動**を使うと、ディスカッションを別のグループ、サブグループ、またはアーカイブ用のグループに移動できます。
- **スレッドをロック**を使うと、コメントや変更を防ぎ、開いているスレッドの一覧から除外できます。ロックしたスレッドはディスカッションのフィルターや検索バーから見つけられ、いつでもロックを解除できます。
- **ディスカッションを削除**は、記録を残す必要がない場合に使います。削除したディスカッションは元に戻せません。

<!-- translation-section: category-tags -->

## カテゴリタグ

カテゴリタグを付けると、ディスカッションを見つけやすくなります。タグを設定し、各ディスカッションに一貫した基準で適用してください。

理事会でよく使うタグには、管理、年次総会、理事会、報告、財務、法務、メンバー、議事録、計画、方針、決議、規約、総会、戦略などがあります。

グループのメンバーは、**タグ**のドロップダウンメニューから、タグでディスカッションを検索できます。

![](thread_tags.png#width-90)

## ディスカッションの話題を保つ

ディスカッションの話題を一つに保つと、参加者全員が内容を追いやすくなります。

ディスカッションの途中で新しい話題が出た場合は、該当するコメントを選んで別のディスカッションに移動するか、新しいディスカッションを始められます。

![](thread_comments_move.png#width-90)

<!-- translation-section: subgroups -->

## サブグループ

サブグループを使うと、連絡やメンバーを整理し、関係する人たちが一緒に活動できます。たとえば、小委員会や作業グループに利用できます。

[サブグループの設定](/en/user_manual/groups/subgroups)

<!-- translation-section: archiving-records -->

## 記録のアーカイブ

スレッドのディスカッションと投票での決定を記録するには、**[スレッドを印刷](/en/user_manual/groups/data_export#print-thread-to-pdf)**を使って PDF に保存します。保存したスレッドの写しは、任意の文書アーカイブに保管できます。

Loomio グループのデータをすべて記録として保存するには、**[グループデータをエクスポート](/en/user_manual/groups/data_export#group-data-backup-or-export)**を使います。

<!-- translation-section: data-storage -->

## データの保存

Loomio のクラウドサービスでは、データを複数のディスクに即座に書き込み、毎日バックアップし、複数の場所に保存しています。

スレッド、コメント、投票、添付ファイルのデータは、すべてこの方法で保存されます。

スレッドに添付されたファイルは、ファイルタブからも確認できます。

![](files_tab.png#width-90)

[Loomio のセキュリティについて詳しく見る。 ](/en/policy/security)
