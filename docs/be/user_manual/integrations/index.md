# Інтэграцыі

Злучыце Loomio з іншымі інструментамі, якімі карыстаецца ваша група.

<!-- translation-section: choose-where-work-belongs -->

## Выбар месца для працы

Loomio дапаўняе чаты, агульныя дакументы і інструменты кіравання задачамі, а не замяняе ўсе інструменты для працы.

| Праца | Рэкамендаваны інструмент |
|---|---|
| Кароткія пытанні, нефармальныя размовы і своечасовыя паведамленні | Чат |
| Сумеснае рэдагаванне дакумента, які пастаянна абнаўляецца | Агульны дакумент |
| Прызначэнне і адсочванне задач | Інструмент кіравання праектамі або задачамі |
| Важнае абмеркаванне пэўнай тэмы, шырокі ўдзел, рашэнні і высновы | Loomio |

Выкарыстоўвайце Loomio, калі людзям патрэбны час, каб абдумаць тэму, калі ўсе, каго яна закранае, павінны мець рэальную магчымасць удзельнічаць або калі групе спатрэбіцца пазней знайсці абмеркаванне і рашэнне. Дадайце ў абмеркаванне ў Loomio спасылку на адпаведны дакумент або задачу, каб кантэкст было лёгка знайсці.
