# Создание новой группы

Если вы впервые пользуетесь Loomio, вы можете создать группу с бесплатным пробным периодом на [сайте Loomio](https://www.loomio.com/). Если вы уже пользуетесь Loomio и хотите создать ещё одну группу, выберите **Новая группа** в боковом меню.

Большинству организаций достаточно одной родительской группы с необходимым количеством [подгрупп](/en/user_manual/groups/subgroups) внутри неё.

### Название группы

Введите короткое и понятное название вашей группы.

<!-- translation-section: group-handle -->

### Идентификатор группы

Loomio автоматически присваивает группе идентификатор на основе её названия. Идентификатор используется в URL и адресе электронной почты группы, например `loomio.com/your-group-handle` и `your-group-handle@loomio.com`.

Вы можете отредактировать идентификатор при создании группы или изменить его позже в настройках группы. После изменения ссылки и адреса электронной почты со старым идентификатором продолжат работать. Loomio сохраняет до трёх старых идентификаторов; при превышении этого количества самый старый перестаёт действовать.

<!-- translation-section: group-description -->

### Описание группы

Добавьте краткое описание, которое будет отображаться в верхней части страницы группы и давать новым участникам необходимые пояснения.

Выберите [настройку конфиденциальности](/en/user_manual/groups/settings/privacy) и нажмите **Стартовая группа**, чтобы создать группу. Вы автоматически становитесь первым администратором группы и можете позже изменить эти сведения в настройках группы.
