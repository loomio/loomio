# Slack 연동
_Loomio 그룹 알림을 Slack에 연결하세요._

Loomio는 새 토론, 제안, 댓글, 표, 결론이 등록되면 Slack 채널로 알림을 보낼 수 있습니다. 중요한 토론과 결정에 관한 주요 소식을 적절한 시점에 받아 보세요.

---
