# 분류 태그

분류 태그를 사용하면 특정 업무 유형이나 주제에 관한 토론, 투표, 결론, 댓글을 찾을 수 있습니다.

태그는 조직 전체에 속합니다. 상위 그룹에서 사용하는 태그는 하위 그룹에서도 동일한 태그이므로, 조직 전체의 관련 업무를 정리할 수 있습니다. Loomio는 태그 이름을 알파벳순으로 표시하고 이름 옆에 색상을 점으로 표시합니다.

그룹 페이지에서 스레드 목록 위의 **태그**를 클릭하세요. 태그를 선택하면 해당 태그가 적용된 게시물이 하나 이상 있는 스레드가 표시됩니다. 목록이 길면 필터 입력란으로 검색하세요.

![](tags_view.png)

## 태그 적용

직접 작성한 토론, 투표, 결론, 댓글에 태그를 적용할 수 있습니다. 그룹 관리자, 스레드 관리자, 토론 배경을 편집할 권한이 있는 사람은 잠기지 않은 스레드의 모든 게시물에 태그를 적용할 수 있습니다. 다이렉트 스레드에서는 모든 참여자가 모든 게시물에 태그를 적용할 수 있습니다.

스레드나 투표를 시작할 때 **태그** 입력란을 클릭하고 태그를 하나 이상 선택하세요.

![](tags_add_new.png)

글자를 입력하면 목록을 필터링할 수 있습니다. 태그를 제거하려면 해당 태그를 다시 선택하거나 태그 칩의 ×를 클릭하세요.

## 태그 만들기

상위 그룹 관리자는 언제든지 상위 그룹과 하위 그룹에서 사용할 태그를 만들 수 있습니다. 하위 그룹 관리자는 해당 하위 그룹의 콘텐츠에 태그를 적용하면서 태그를 만들 수 있습니다. 기본적으로 활성화된 **멤버가 태그를 만들 수 있습니다** 그룹 권한은 콘텐츠에 태그를 적용할 수 있는 다른 멤버도 새 태그 이름을 만들 수 있게 합니다. 이 권한이 비활성화되면 멤버는 조직의 기존 태그와 대상 그룹의 템플릿에 지정된 태그 이름을 사용할 수 있습니다.

스레드나 투표를 시작하면서 태그를 만들려면 **태그** 입력란에 이름을 입력하고 Enter를 누르세요.

![새 태그 만들기](tags_create_new.png)

![새로 만든 태그](tags_created_new.png)

재무, 운영, 포장, 카페 협력처럼 그룹 멤버가 알아볼 수 있는 짧고 익숙한 이름을 사용하세요.

## 템플릿의 태그

토론 및 투표 템플릿은 태그 이름을 기본값으로 저장합니다. 템플릿을 만들거나 편집할 수 있는 사람은 누구나 태그 이름을 자유롭게 변경할 수 있습니다. 템플릿을 저장하거나 살펴보는 것만으로는 이 이름들이 조직의 태그 목록에 추가되지 않습니다. 조직 태그의 이름을 변경하거나 태그를 삭제해도 템플릿 기본값은 변경되지 않습니다.

토론이나 투표에서 이 기본값을 사용하면 Loomio는 조직의 기존 태그를 적용하거나, 권한이 허용되는 경우 새 태그를 만듭니다. 태그를 만들 권한이 없는 멤버도 대상 그룹에서 사용할 수 있는 템플릿에 지정된 이름은 사용할 수 있습니다. 다른 그룹의 템플릿을 사용해도 태그 생성 권한이 추가로 부여되지는 않습니다. 대상 조직에 해당 태그가 이미 있거나 대상 그룹의 템플릿에 해당 이름이 지정되어 있을 때만 기본값이 유지됩니다. 그 외의 이름은 제외됩니다. 태그를 만들 수 있는 멤버는 템플릿의 모든 기본값을 유지할 수 있습니다.

## 태그 편집

상위 그룹 관리자만 태그의 이름과 색상을 변경하거나 태그를 병합하거나 삭제할 수 있습니다. 이러한 변경 사항은 하위 그룹을 포함한 조직 전체에서 해당 태그가 적용된 모든 곳에 반영됩니다.

그룹 페이지에서 **태그**를 열고 **태그 편집**을 선택하세요.

![분류 태그 편집](tags_edit_new.png)

태그 옆의 연필 아이콘을 선택하세요.

![분류 태그 편집](tags_edit_new_pencil.png)

태그 이름을 편집하거나 색상을 선택한 다음 **저장**을 클릭하세요.

![태그 색상 편집](tags_edit_name.png)

**삭제**를 클릭하면 조직 전체의 토론, 투표, 결론, 댓글에서 해당 태그가 제거됩니다.

![태그 삭제](tags_delete.png)

### 스레드나 투표의 태그 편집

기존 스레드나 투표의 태그를 변경하려면 해당 항목을 열고 제목 근처의 현재 태그 옆에 있는 태그 버튼을 클릭하세요.

태그를 선택하여 추가하거나 제거하세요. 변경 사항은 즉시 저장됩니다.

태그 선택 창에는 현재 그룹에서 사용하는 태그, 아직 사용하지 않는 조직 태그, 해당 게시물에 선택된 태그가 표시됩니다. 다른 그룹에서만 사용하는 태그가 더 있으면 **다른 그룹의 태그 보기**를 선택하여 같은 조직의 상위 그룹과 하위 그룹 태그를 포함하세요. 더 짧은 목록으로 돌아가려면 **이 그룹에서 사용하는 태그 보기**를 선택하세요. 그룹이 하나뿐인 조직에는 목록을 확장하는 선택 항목이 없습니다.

![스레드의 태그 편집](tags_thread_edit.png)

## 게시물에 태그 적용

투표, 결론 또는 댓글의 작업 메뉴를 열고 **태그 적용**을 선택하세요. 토론 제목 옆에서 사용하는 것과 같은 태그 선택 창에서 태그를 추가하거나 제거할 수 있습니다. 변경 사항은 즉시 저장됩니다. 게시물에 태그가 있으면 작성자와 작성 시간이 표시된 줄의 오른쪽에 태그 칩과 태그 버튼이 표시됩니다.

태그는 선택한 게시물에 적용됩니다. 표와 투표용지에는 태그를 적용할 수 없습니다.

## 태그가 적용된 게시물 찾기

첫 토론이나 투표 외의 게시물에 태그가 적용되면 스레드 사이드바에 **태그** 영역이 표시됩니다. 이 영역에는 첫 항목과 태그가 적용된 다른 모든 게시물의 태그가 모입니다. 태그를 선택하면 일치하는 게시물이 해당 게시물의 상위 맥락과 함께 표시됩니다. 필터가 활성화된 동안에는 스레드 위에 도구 모음이 계속 표시됩니다. 일반 스레드 보기로 돌아가려면 오른쪽의 × 버튼으로 도구 모음을 닫거나, 해당 태그를 다시 선택하거나, 사이드바에서 **지우기**를 선택하세요. 모바일에서는 스레드 탐색 패널을 열어 같은 필터를 사용하세요.

![스레드 사이드바의 태그](tags_thread_sidebar.png)

## 태그로 검색

상단 탐색 메뉴에서 **검색**을 열고 상위 그룹을 선택하면 태그 메뉴가 표시됩니다. 태그를 선택하여 해당 태그가 적용된 토론, 투표, 결론, 댓글을 찾으세요.

태그별로 살펴보려면 검색 입력란을 비워 두세요. 태그가 적용된 게시물 안에서 검색하려면 단어나 구문을 입력하세요. 태그 필터를 해제하려면 **모든 태그**를 선택하세요.

![전체 검색에서 상위 그룹을 선택한 후 태그 선택](tags_global_search.png)
