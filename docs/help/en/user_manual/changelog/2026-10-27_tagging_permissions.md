People with permission to edit the discussion context can now add or remove tags on any discussion, poll, outcome, or comment in the thread. Previously, that permission only allowed tagging the opening discussion. All participants in direct threads can also tag any contribution.

Group admins and thread admins can still tag any contribution, and authors can still tag their own contributions. Threads must be unlocked. The **Members can create tags** setting continues to control who can introduce new tag names.
