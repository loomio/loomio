# Mattermost 연동

Loomio는 새 토론, 투표, 댓글, 표, 결론이 등록되면 Mattermost 채널로 알림을 보낼 수 있습니다.

---

1. 브라우저에서 Mattermost 팀을 열고 **연동**으로 이동하세요.

   ![](mm1.png)

2. **수신 웹훅**을 선택하세요.

   ![](mm2.png)

3. **수신 웹훅 추가**를 선택하세요.

   ![](mm3.png)

4. 이름을 입력하고 알림을 표시할 채널을 선택한 다음 **저장**을 선택하세요.

   ![](mm4.png)

5. 웹훅 URL을 복사하세요.

   ![](mm5.png)

이제 웹훅 URL을 사용해 Loomio에서 연결을 완료하세요.
