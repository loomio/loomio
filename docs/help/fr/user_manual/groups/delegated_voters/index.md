# Membres délégués au vote

Si certains membres de votre groupe doivent avoir le droit de vote et d’autres non, vous pouvez utiliser la fonctionnalité « Faire déléguer » pour désigner les personnes qui ont le droit de vote. L’action correspondante « Révoquer le délégué » est également disponible.

Utilisez les délégués lorsque les personnes doivent partager le même espace de discussion, mais que seules certaines d’entre elles, comme les membres du conseil d’administration ou les représentants élus, peuvent voter. C’est généralement plus simple que de gérer un second sous-groupe dont le seul but est de séparer les électeurs des personnes sans droit de vote.

Utilisez plutôt un sous-groupe privé lorsque ses membres ont également besoin de discussions, de fichiers ou d’informations sur les membres auxquels les autres membres ne doivent pas avoir accès.

Sur la page du groupe, ouvrez **Membres**, trouvez la personne et sélectionnez **Faire déléguer** dans le menu à trois points à côté de son nom. Utilisez **Révoquer le délégué** dans le même menu pour retirer cette désignation.

![Action Faire déléguer dans le menu d’un membre](member_make_delegate.png)

Pour créer un sondage ou une proposition et inviter uniquement les délégués, utilisez le paramètre du sondage « Personnes sélectionnées uniquement ».
![Paramètre Personnes sélectionnées uniquement lors de la création d’une proposition](poll_invited_people_only.png)
Ensuite, lorsque vous inviterez des personnes à voter, vous verrez l’option « Délégués de nom-du-groupe ».
![Option Délégués de Oatmilk Cooperative dans le formulaire d’invitation à voter](poll_invite_delegates_group.png)

Vous pouvez consulter la liste des délégués dans l’onglet des membres de la page de votre groupe. Utilisez le menu de filtrage et choisissez « Délégués ».
![Option Délégués dans le filtre des membres](members_list_delegates.png)
