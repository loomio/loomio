# Отправьте письмо, чтобы создать ветку в вашей группе

У каждой группы в Loomio есть свой адрес электронной почты. Вы можете отправить или переслать письмо на этот адрес, чтобы создать новую ветку в группе.

Адрес электронной почты группы указан на странице группы:

![Расположение адреса электронной почты на странице группы](email_email_button.png)

Когда вы отправляете письмо на этот адрес, Loomio создаёт новую ветку. Тема письма становится заголовком ветки, текст письма — её описанием, а все вложенные файлы прикрепляются к ветке.

По адресу в поле «От» Loomio определяет, кто из участников группы отправил письмо, и указывает этого участника как автора ветки.

<!-- translation-section: preventing-unauthorized-emails -->

## Защита от писем посторонних отправителей

Чтобы создавать ветки могли только участники группы, Loomio требует, чтобы адрес в поле «От» входящего письма совпадал с адресом электронной почты участника группы.

Если участник отправляет письмо с неизвестного адреса, Loomio задерживает письмо и уведомляет администраторов группы. Администратор группы может одобрить письмо и добавить этот адрес как дополнительный адрес участника или отклонить дальнейшие письма с этого адреса.

После добавления дополнительного адреса письма с него сразу создают ветки.
