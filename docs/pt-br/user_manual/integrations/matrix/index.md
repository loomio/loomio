# Integração com o Matrix

O Loomio pode enviar notificações aos seus canais do Matrix quando há novas discussões, propostas, comentários, votos e conclusões.

O Matrix permite usar alguns elementos HTML nas salas de conversa, e o Loomio aproveita esse recurso.

A integração com o Matrix funciona de forma diferente das outras integrações de chat: ela usa um bot criado para essa finalidade em vez de um webhook.

Você precisa criar uma conta no Matrix para o bot usar.

Depois de criar a conta do bot, entre nela para obter as informações a seguir.

Este guia usa o Element.
