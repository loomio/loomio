# Delegierte mit Stimmrecht

Nutze Delegierte, wenn alle in einer Gruppe denselben Raum für Diskussionen nutzen sollen, aber nur ein festgelegter Kreis von Mitgliedern, etwa Vorstandsmitglieder oder gewählte Vertretungen, abstimmen darf. Das ist einfacher, als eine separate Untergruppe zu verwalten, deren einziger Zweck darin besteht, Personen mit und ohne Stimmrecht zu trennen.

Nutze stattdessen eine private Untergruppe, wenn diese Mitglieder auch Diskussionen, Dateien oder eine Mitgliederliste benötigen, die andere Mitglieder nicht sehen sollen.

Nur ein Gruppenadmin kann den Delegiertenstatus vergeben oder entziehen. Öffne im Reiter **Mitglieder** auf deiner Gruppenseite das Aktionsmenü neben dem Namen einer Person und wähle **Delegieren**. Wähle im selben Menü **Delegierten widerrufen**, um die Kennzeichnung zu entfernen.

![Aktion „Delegieren“ im Menü eines Mitglieds](member_make_delegate.png)

Um eine Abstimmung oder einen Vorschlag zu erstellen, bei dem nur Delegierte abstimmen können, wähle in den Abstimmungseinstellungen **Nur für ausgewählte Personen**.

![Einstellung „Nur für ausgewählte Personen“ beim Starten eines Vorschlags](poll_invited_people_only.png)

Wenn du auswählst, wen du zur Stimmabgabe einladen möchtest, wähle **Delegierte von [Gruppenname]**.

![Option „Delegierte von Oatmilk Cooperative“ im Formular zur Einladung zur Stimmabgabe](poll_invite_delegates_group.png)

Um alle Delegierten einer Gruppe zu sehen, öffne den Reiter **Mitglieder** und wähle im Filtermenü **Delegierte**.

![Option „Delegierte“ im Mitgliederfilter](members_list_delegates.png)
