# Конфиденциальность группы

Настройки конфиденциальности определяют, кто может найти группу и читать её материалы. На странице группы откройте **Редактировать настройки группы**, затем выберите **Конфиденциальность**.

![Настройки конфиденциальности группы](group_privacy_settings.png#width-90)

При изменении настроек конфиденциальности уже опубликованные материалы группы могут стать доступными или скрытыми. Выберите самый строгий режим, который подходит для целей группы.

<!-- translation-section: open -->

## Открыто

Открытые группы доступны всем. Любой может найти группу и читать её обсуждения, опросы и файлы. Список участников виден только участникам.

В открытой группе можно разрешить вступление без одобрения, принимать заявки на вступление или вступать только по приглашению.

<!-- translation-section: follow-an-open-group -->

### Как следить за открытой группой

За новостями открытой группы можно следить, не вступая в неё. Непрочитанные события группы будут добавлены в письмо со сводкой, чтобы их можно было просмотреть в удобное время. Те, кто следит за группой, не становятся её участниками, не получают право голоса как участники и не получают немедленных уведомлений только потому, что следят за ней.

На странице группы включите **Следите за обновлениями**, чтобы непрочитанные обсуждения, комментарии, опросы и другие события в темах группы попадали в ваше письмо со сводкой. Чтобы исключить группу из сводки, отключите эту настройку.

![Настройка «Следите за обновлениями» в открытой группе](group_follow_updates.png)

<!-- translation-section: closed -->

## Закрыто

Любой может найти закрытую группу и прочитать её название и описание. Обсуждения, опросы, файлы и список участников доступны только участникам и приглашённым гостям.

В закрытой группе можно разрешить подавать заявки на вступление или вступать только по приглашению. Вступить без одобрения нельзя.

В закрытой подгруппе можно разрешить участникам родительской группы читать обсуждения, не вступая в подгруппу.

<!-- translation-section: secret -->

## Выделить

Скрытые группы и их материалы видны только приглашённым или добавленным людям. Вступить в такую группу можно только по приглашению. Скрытые группы не отображаются в общедоступном каталоге групп.

<!-- translation-section: how-people-join -->

## Как вступить в группу

Доступные способы вступления зависят от настроек конфиденциальности:

| Конфиденциальность группы | Доступные способы вступления |
| --- | --- |
| **Открыто** | Без одобрения, по заявке или только по приглашению |
| **Закрыто** | По заявке или только по приглашению |
| **Выделить** | Только по приглашению |

Если для вступления требуется одобрение, человек выбирает **Вступить в группу**, отвечает на вопрос группы и отправляет заявку. О том, как настроить вопрос, рассматривать заявки и приглашать людей напрямую, читайте в разделе [Приглашение людей](/en/user_manual/groups/inviting_people#request-to-join-group).

<!-- translation-section: group-directory -->

## Каталог групп

Открытые и закрытые родительские группы можно добавить в общедоступный каталог групп, чтобы люди могли их найти. Размещение в каталоге не меняет того, кто может читать материалы группы или стать её участником. Подгруппы и скрытые группы нельзя добавить в каталог.
