# Взвешенное голосование

Взвешенное голосование позволяет учитывать одни голоса с большим весом, чем другие. У каждого избирателя есть вес голоса. Например:

- Жилищное сообщество предоставляет один голос каждому объекту недвижимости. Участник, представляющий три объекта недвижимости, имеет вес голоса `3`.
- Правление кооператива принимает решение, а сотрудники участвуют в обсуждении. Члены правления имеют вес голоса `1`. Сотрудники имеют вес голоса `0`, поэтому их голоса записываются, но не влияют на результат.
- Компания предоставляет акционерам голоса в соответствии с их долей владения. Владелец 12,5% акций имеет вес голоса `12.5`.

## Установка весов голосов участников

Администратор группы может открыть страницу **Участники** и выбрать **Изменить вес голосов**. Введите веса голосов и выберите **Сохранить вес голосов**. Вес голоса может быть равен `0` или больше и содержать до трёх знаков после запятой. Чтобы найти участника, воспользуйтесь поиском по имени или электронной почте. Чтобы назначить всем участникам одинаковый вес голоса, выберите **Установить все веса голосов**.

![Веса голосов участников группы](member-weights.png)

Вес голоса участника копируется в каждый опрос, в который его добавляют. Последующее изменение веса не влияет на опросы, в которые он уже скопирован.

## Использование взвешенного голосования в опросе

Выберите **Используйте взвешенное голосование** в дополнительных настройках опроса. Вы можете включить или отключить его после начала голосования. При отключении вес каждого голоса в опросе становится равным `1`, а все веса голосов, которые вы изменили для этого опроса, теряются.

Если ваша группа использует взвешенное голосование в рамках установленного процесса, выберите **Используйте взвешенное голосование** в [шаблоне опроса](/en/user_manual/polls/poll_templates). Опросы, начатые по этому шаблону, будут использовать взвешенное голосование.

![Настройка «Используйте взвешенное голосование» в опросе](poll-setting.png)

Взвешенное голосование доступно для следующих типов опросов: [Предложение](/en/user_manual/polls/proposals), [Выбирать](/en/user_manual/polls/choose), [Счет](/en/user_manual/polls/score), [Выделить](/en/user_manual/polls/allocate) и [Классифицировать](/en/user_manual/polls/rank).

В одном опросе нельзя одновременно использовать взвешенное голосование и [анонимное голосование](/en/user_manual/polls/anonymous_voting).

Чтобы изменить вес голоса одного избирателя, выберите **Управление избирателями**, затем выберите вес голоса рядом с его именем. Чтобы изменить веса голосов всех избирателей, выберите **Установить все веса голосов**. Вы можете скопировать вес голоса каждого участника из группы или назначить всем одинаковое значение. Избиратели, которые не являются участниками группы, получают вес голоса `1`.

![Кнопка «Управление избирателями» в опросе](poll-manage-voters.png)

## Результаты

Результаты показывают обычные итоги и итоги с учётом весов рядом друг с другом:

- В опросах «Предложение» и «Выбирать» отображаются **Голоса** и **Взвешенные голоса**.
- В опросах «Счет», «Выделить» и «Классифицировать» отображаются **Точки** и **Взвешенные баллы**.

Диаграмма показывает результат с учётом весов. Выберите заголовок другого столбца, чтобы отобразить на диаграмме его данные. Число избирателей, имеющих право голоса, и кворум определяются по числу людей, а не по весам голосов. Любой, кто может видеть голоса, может видеть и вес голоса каждого избирателя.
