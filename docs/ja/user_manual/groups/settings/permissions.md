# グループの権限

権限タブでは、一般のメンバーが利用できるグループ内の操作を設定します。秘密のグループ以外では、メンバー以外の人が利用できる操作も設定できます。グループページから **グループ設定を編集する** を開き、**権限** を選択します。

![グループの権限設定](group_group_settings_permissions.png)

管理者は引き続きグループを管理できます。メンバー向けの権限を有効にすると、一般のメンバーもその操作を行えるようになりますが、管理者になるわけではありません。

権限では、メンバーが次の操作を行えるかどうかを設定できます。

- メンバーの追加またはゲストの招待
- お知らせの送信
- サブグループの作成
- ディスカッションの開始と管理
- タグの作成と管理
- 設定で許可されている場合のコメントの編集または削除
- 提案とアンケートの開始
- ディスカッションとアンケートのテンプレートの作成

秘密のグループ以外では、管理者はメンバー以外の人によるディスカッションの開始を別途許可できます。メンバー以外の人がディスカッションを開始すると、そのディスカッションのゲストになりますが、他の非公開ディスカッションへのアクセス権を得たり、グループのメンバーになったりすることはありません。

**管理者はメンバーのコメントを編集できます** の設定は、管理者に特別なモデレーション権限を与えます。管理者がメンバーの作成した内容を変更できることについて、グループで合意した場合にのみ有効にしてください。

グループの目的、メンバー構成、またはモデレーションの責任が変わったときは、権限を見直してください。各役割には、必要な権限だけを付与してください。
