# 제안

제안은 사람들이 어떤 진술이나 행동 방안에 응답하도록 요청합니다. 참여자는 정해진 응답 중 하나를 선택하고 투표한 이유를 설명할 수 있습니다. 피드백을 모으거나, 조언을 구하거나, 이의를 파악하거나, 동의 여부를 확인할 때 제안을 사용하세요.

이 섹션은 Loomio의 기본 제안 템플릿을 선택하고 사용하는 데 도움이 됩니다. 토론, 제안, 수정안, 결론으로 이어지는 전체 절차는 [의사결정 가이드](/en/guides/making_decisions/)를 참고하세요. 그룹에서 사용할 수 있는 템플릿을 변경하려면 [투표 템플릿](../poll_templates/)을 참고하세요.

## 제안 템플릿 선택

| 템플릿 | 질문 | 사용 시점 |
|---|---|---|
| [의견 확인](sense_check/) | 올바른 방향으로 가고 있나요? | 아이디어를 아직 구체화하는 중일 때 |
| [조언](advice/) | 결정을 내리는 사람이 어떤 조언을 고려해야 하나요? | 개인이나 팀에 결정 권한이 있을 때 |
| [이의 없음](consent/) | 안전하게 시도할 수 있나요, 아니면 타당한 이의가 있나요? | 그룹이 이의 없는 의사결정을 사용할 때 |
| [합의](consensus/) | 이 제안에 대한 입장은 무엇인가요? | 그룹이 공동의 합의를 구할 때 |

답을 얻으려는 질문에 맞는 응답 선택지가 있는 템플릿을 선택하세요. 각 템플릿 페이지에서는 사용 사례, 설정, 투표 양식, 결과를 설명합니다.

## 기타 제안 템플릿

Loomio는 제안, 동의 수준, 다수결 등의 템플릿도 제공합니다. 일부는 처음에는 숨겨져 있습니다. 그룹 관리자는 [투표 템플릿](../poll_templates/)에서 이러한 템플릿을 사용할 수 있도록 설정하거나 그룹의 용어와 규칙에 맞는 템플릿을 만들 수 있습니다.

## 제안 기록

제안이 진행 중인 동안 표와 이유가 갱신되며, 참여자는 응답을 변경할 수 있습니다. 제안이 마감되면 결정이나 다음 단계를 명시하는 [결론](../outcomes/)을 게시하세요. 토론, 제안, 표, 이유, 결론은 그룹이 어떻게 결정에 도달했는지 보여 주는 기록이 됩니다.
