# ディスカッションの紹介

Loomioのディスカッションでは、グループで情報を共有し、話題について話し合い、決定を行えます。コメントや返信を投稿して参加します。

- 話題に関するすべての情報が、簡単にアクセスできる1か所にまとまります。
- メールで返信すると、コメントがディスカッションに表示されます。
- ディスカッションを読んだ人と、参加を促す必要がある人を確認できます。
- ディスカッションの記録が残り、後から簡単に見つけられます。

ディスカッションは、一般的な話し合いの場としての利用から、特定の業務や意思決定のプロセスの進行まで、幅広い用途に使えます。

例えば、特定の話題についてディスカッションを始め、意見や情報の共有を呼びかけ、合意した結論に向けて話し合いを進められます。

また、同意や助言に基づく意思決定のプロセスを使い、特定の決定への参加を呼びかけることもできます。

ディスカッションにはアンケートや提案を追加でき、話し合いを結論へと進めるのに役立ちます。参加者がディスカッションにコメントし、アンケートに投票すると、ディスカッションのタイムラインが作られ、重要な節目を簡単に見つけられます。

## 主な用途

ディスカッションの主な用途を紹介します。

<!-- translation-section: boards-and-governance -->

### 理事会とガバナンス

**会議の準備をする** - 議題を作成し、理事会資料を投稿し、事務事項を整理します。全員が最新の情報と背景を把握し、準備を整えられます。

**決議案を可決する** - 背景説明や関連情報を投稿し、質問に答え、決議案の可決に向けた提案を作成します。

**Loomioで議題について話し合う** - 会議の前に議題についてディスカッションを始めます。会議で時間が足りなくなった場合は、ディスカッションをLoomioに移して続けられます。

**議事録を承認し、対応事項を確認する** - 議事録を投稿し、対応事項の担当者を割り当てます。アンケートを使って議事録を承認します。

<!-- translation-section: member-participation -->

### メンバーの参加

**ニュースを共有する（メーリングリストの代わりに使う）** - メンバー向けの情報を投稿し、コメントを募ります。

**イベントを企画する** - 運営チームで詳細を詰めます。ディスカッションと情報をすべてスレッド内にまとめ、その後、メンバー全体にイベントを告知します。

**方針を策定する** - 方針の草案を投稿し、メンバーから意見やフィードバックを募り、方針をまとめて正式に承認します。

**総会** - 戦略に関わる事項を審議し、決定するために、すべてのメンバーが参加する正式な会議を企画、準備、運営します。

<!-- translation-section: self-organizing-working-teams -->

### 自主的に運営する作業チーム

**情報を共有する** - チームに関係する情報や報告を投稿し、コメントやディスカッションを募ります。

**作業を進める** - 作業タスクの概要を示し、完了までチームのメンバーから助言、意見、フィードバックを募ります。

**会議の記録と対応事項** - ディスカッションの記録として会議のメモを投稿し、タスクの進捗を確認します。

**アイデアを検討する** - 気づいた懸念や改善できる点について考えを共有し、ディスカッションを呼びかけます。

**助言、同意、生成的な意思決定** - 準備、提案、内容の明確化、リアクションや異議への対応、賛成、実行まで、すべてをLoomioのディスカッション内で進めます。
