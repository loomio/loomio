# Profil du groupe

L’onglet Profil permet de définir comment votre groupe est identifié et présenté. Ouvrez **Modifier les paramètres du groupe** depuis la page du groupe, puis sélectionnez **Profil**.

![Paramètres du profil du groupe](group_profile.png)

<!-- translation-section: name-and-handle -->

## Nom et identifiant

Choisissez un nom de groupe concis, en particulier si le groupe doit contenir des sous-groupes. Loomio utilise l’identifiant dans l’adresse web et l’adresse e-mail du groupe, par exemple `loomio.com/your-group-handle` et `your-group-handle@loomio.com`.

Lorsque vous modifiez l’identifiant, les liens utilisant l’ancien identifiant redirigent vers la nouvelle adresse, et les e-mails envoyés à l’ancienne adresse du groupe continuent de parvenir au groupe. Loomio conserve jusqu’à trois anciens identifiants ; toute modification supplémentaire de l’identifiant entraîne l’expiration du plus ancien.

<!-- translation-section: description -->

## Description

Utilisez la description pour expliquer à quoi sert le groupe, qui y participe et comment les personnes sont censées l’utiliser. Vous pouvez mettre en forme la description et y inclure des liens, des documents et des vidéos.

Le nom et la description peuvent être visibles par les personnes qui ne sont pas membres, selon les [paramètres de confidentialité](/en/user_manual/groups/settings/privacy) du groupe.

<!-- translation-section: cover-image-and-logo -->

## Image de couverture et logo

L’image de couverture s’affiche en haut de la page du groupe, sur toute sa largeur. Une image large convient le mieux ; les dimensions recommandées sont de 2048 × 512 pixels.

Le logo du groupe permet de l’identifier dans la navigation et dans les autres espaces à affichage compact. Importez l’image de couverture et le logo séparément afin de pouvoir recadrer chacun au format prévu.
