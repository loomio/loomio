# 言語と翻訳

Loomioのインターフェースの言語を変更したり、ディスカッション、コメント、提案を希望する言語に翻訳したりできます。

<!-- translation-section: application-translation -->

## アプリケーションの翻訳

Loomioはブラウザーの優先言語を検出します。別の言語に変更するには、**プロファイル編集**を開き、言語を選択します。

![希望する言語の変更](change_language.png)

<!-- translation-section: content-translation -->

## コンテンツの翻訳

グループ内で希望する言語とは異なる言語のメッセージが投稿されると、メッセージの下に**翻訳する**ボタンが表示されます。**翻訳する**を選択すると、メッセージが希望する言語に翻訳されます。

![コメントの下にある翻訳ボタン](content_translation.png)

ディスカッション内の元のテキストは、翻訳されたテキストに置き換わります。**原文**を選択すると、元のテキストが再び表示されます。

![スペイン語から英語に翻訳されたコメント](content_translated.png)

Loomioは、翻訳のリクエストに応じてGoogle翻訳を使用してコンテンツを翻訳します。

<!-- translation-section: automatic-translation -->

## 自動翻訳

ディスカッション、コメント、提案を自動的に翻訳するには、**プロファイル編集**を開き、**コンテンツを自動的に自分の言語に翻訳する**をオンにします。Loomioはプロファイルで選択された言語にコンテンツを翻訳します。

![プロファイル編集ページのコンテンツ自動翻訳設定](automatic_translation.png)
