# 둘러보기

이 페이지에서는 Loomio 인터페이스의 주요 구성 요소와 참여할 일이 있는 곳을 소개합니다.

<!-- translation-section: group-page -->

## 그룹 페이지

그룹 홈 페이지에서는 그룹을 소개하고 그룹의 활동에 접근할 수 있습니다.

![](group_example.png)

<!-- translation-section: tabs -->

### 탭

그룹 설명 아래의 탭에서 다음 항목을 확인할 수 있습니다.

**토론** - 그룹의 토론 스레드와 최근 활동입니다.

**투표** - 그룹에서 진행 중인 투표 목록입니다.

**멤버** - 그룹에 속한 사람들입니다.

**파일** - 그룹 전반에 첨부된 문서와 기타 파일입니다. 이 탭에는 토론의 배경, 댓글, 제안, 투표에 첨부된 파일이 모여 있어 첨부한 위치를 기억하지 않아도 문서를 찾을 수 있습니다.

검색, 필터, 태그, 북마크, 읽지 않은 토론에 관한 도움말은 [콘텐츠 찾기](/en/user_manual/overview/finding-content)를 참고하세요.

<!-- translation-section: sidebar -->

## 사이드바

데스크톱에서는 왼쪽 위의 메뉴 버튼(**☰**)으로, 모바일에서는 하단 탐색 모음의 메뉴 버튼으로 사이드바를 여세요.

![](sidebar.png)

사이드바에서 대시보드, 참여를 기다리는 투표, 읽지 않은 토론과 직접 토론, 할 일, 그룹을 열 수 있습니다. 사용자 설명서와 지원 페이지로 연결되는 링크도 있습니다.

<!-- translation-section: user-settings -->

### 사용자 설정

사이드바에서 이름을 선택하면 사용자 메뉴가 열립니다.

![](user_settings_sidebar.png)

이 메뉴에서 프로필 편집, 알림 설정 변경, 테마 선택, 계정 설정 관리, 로그아웃을 할 수 있습니다.

<!-- translation-section: notifications -->

## 알림

데스크톱에서는 오른쪽 위의 종 모양 버튼으로, 모바일에서는 하단 탐색 모음의 종 모양 버튼으로 앱 내 알림을 열 수 있습니다. 확인하지 않은 알림이 있으면 배지가 표시됩니다.

![](../users/email_settings/in_app_notifications.png)

앱 내 알림, 이메일 수신 설정, 그룹과 토론의 알림 설정에 관해서는 [알림](/en/user_manual/users/email_settings)을 참고하세요.

<!-- translation-section: mobile-navigation -->

## 모바일 탐색과 불러오기

하단 탐색 모음의 아이콘으로 사이드바, 대시보드, 알림을 열 수 있습니다. 스레드를 읽는 동안에는 목차와 스레드 관련 작업을 위한 스레드 메뉴 버튼도 표시됩니다. 검색은 대시보드에서 사용할 수 있습니다. 페이지의 제목이 스크롤되어 화면에서 사라지면 제목 표시줄에 페이지 제목이 표시됩니다.

Loomio는 업데이트를 확인하는 동안 현재 세션에 이미 저장된 콘텐츠를 표시합니다. 데이터를 가져오는 동안 제목 표시줄 오른쪽 위에 불러오기 표시가 나타납니다. 대시보드, 참여를 기다리는 투표, 알림은 앱 시작 후 백그라운드에서 불러옵니다. 알림을 가져오는 것만으로는 확인한 것으로 표시되지 않습니다.

스레드는 처음부터 열립니다. 가장 최근 활동으로 이동하려면 **최신**을 선택하세요. 특정 댓글이나 투표로 연결되는 링크는 해당 항목을 바로 엽니다.
