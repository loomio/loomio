# Microsoft Teams連携

新しいディスカッションやアンケートが作成されたとき、コメントや投票が投稿されたとき、結論が設定されたときに、LoomioからMicrosoft Teamsのチャネルへ通知を送信できます。

---

1. [Microsoft Teams](https://teams.microsoft.com)を開き、**アプリ**を選択します。

   ![](t1.png)

2. `webhook`を検索し、**受信 Webhook**を選択します。

   ![](t2.png)

3. **チームに追加**を選択します。

   ![](t3.png)

4. Loomioの通知を表示するチャネルを選択します。

   ![](t4.png)

5. `Loomio notifications`などの名前を入力し、**作成**を選択します。

   ![](t5.png)

6. Loomioに貼り付けるため、Webhook URLをコピーします。

   ![](t6.png)

Webhook URLを取得したら、Loomioで接続の設定を完了します。

[Loomioでチャット連携を設定する](../chatbots/#set-up-a-chat-integration)

_LoomioはMicrosoftが作成したものではなく、Microsoftとの提携関係やMicrosoftによるサポートもありません。_
