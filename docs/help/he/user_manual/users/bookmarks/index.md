# סימניות

סימניות הן רשימה אישית של פריטים ב-Loomio שרוצים לחזור אליהם. הסימניות גלויות רק למי ששמרו אותן, ושמירת פריט אינה שולחת הודעה לאף אחד אחר.

ניתן לשמור סימניות עבור:

- דיונים
- תגובות
- הצעות וסקרים
- הצבעות
- מסקנות

<!-- translation-section: save-a-bookmark -->

## שמירת סימניה

יש לפתוח את תפריט הפעולות של הפריט ולבחור **שמור סימניה**. תפריט הפעולות מוצג בדרך כלל כשלוש נקודות. עבור דיון, יש להשתמש בתפריט הפעולות שליד כותרת הדיון; עבור תגובה, הצבעה, הצעה, סקר או מסקנה, יש להשתמש בתפריט שעל הפריט עצמו.

## צפייה בסימניות

יש לפתוח את סרגל הצד ולבחור **סימניות**. המספר שליד הקישור מציין כמה סימניות נשמרו.

בדף הסימניות, הפריטים שנשמרו לאחרונה מופיעים בראש הרשימה. כל שורה מציגה את סוג הפריט ואת שם מי שיצרו אותו. יש לבחור שורה כדי לחזור לפריט שנשמר בסימניות.

![](bookmarks_page.png)

## הסרת סימניה

בדף הסימניות, יש לבחור בכפתור להסרת הסימניה שבקצה השורה. ניתן גם לפתוח את תפריט הפעולות של הפריט שנשמר בסימניות ולבחור **הסר סימניה**.

הסרת סימניה משפיעה רק על הרשימה האישית. ניתן לשמור את הפריט שוב בהמשך.
