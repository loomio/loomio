# 参加方法

Loomioのグループにサインインすると、ディスカッションに参加したり、アンケートに投票したりできます。

<!-- translation-section: comment -->

## コメント

ディスカッションのスレッドにコメントを投稿して、考えを共有します。スレッドを閲覧できる人は誰でも、コメントを読んだり、返信やリアクションをしたりできます。

![](comment_add.png#width-90)

<!-- translation-section: reply-to-a-comment -->

### コメントに返信する

特定の点について応答するには、コメントに直接返信します。Loomioは返信をスレッドに投稿し、元のコメントの投稿者に通知します。

![](comment_reply.png#width-90)

<!-- translation-section: get-someone-s-attention -->

### 相手に知らせる

コメントに**@**を入力し、その後に相手の名前を入力すると、その人に通知できます。

![](comment_mention.png#width-90)

<!-- translation-section: reactions -->

### リアクション

絵文字のリアクションを追加すると、返信を書いたりメール通知を送信したりせずに、コメントを受け止めたことを示せます。

![](comment_reaction.png#width-90)

<!-- translation-section: vote -->

## 投票する

メールの招待、アプリ内の通知、**すべてのグループ**、またはグループの**アンケート**セクションからアンケートを開きます。アンケートと添付ファイルを読んでから、選択肢を選びます。

Loomioにはいくつかの種類のアンケートがあります。以下の例は、**賛成**、**棄権**、**反対**を選択肢とする提案です。

![](proposal_example.png#width-90)

<!-- translation-section: state-a-reason -->

### 理由を書く

投票について説明する短い**理由**を追加できます。アンケートで必須とされていない限り、理由の記入は任意です。

![](vote_reason.png#width-90)

<!-- translation-section: change-your-vote -->

### 投票を変更する

新しい情報が明らかになった場合など、アンケートが締め切られるまでは、いつでも投票を変更できます。（匿名のアンケートでは、投票を送信した後に変更することはできません。）

![](vote_change.png#width-90)

理由を更新して、投票を変更した理由を説明することもできます。

![](vote_edit.png#width-90)

<!-- translation-section: results -->

### 結果

ほとんどのアンケートでは、投票のたびに結果が更新されます。（投票が締め切られるまで結果を表示しないアンケートもあります。）

![](proposal_results.png#width-90)

難しいテーマでは投票結果が分かれることはよくあり、意思決定の進め方が失敗したことを意味するわけではありません。新たな視点は、グループがよりよい提案を作るのに役立つことがよくあります。

<!-- translation-section: outcome -->

### 結論

アンケートが締め切られると、作成者は**結論**を公開して、何が決まったか、次に何が行われるかを記録できます。

![](proposal_outcome.png#width-90)
