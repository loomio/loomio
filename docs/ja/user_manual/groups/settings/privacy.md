# グループのプライバシー

プライバシー設定では、グループを見つけられる人と、その内容を閲覧できる人を管理します。グループページで**グループ設定を編集する**を開き、**プライバシー**を選択します。

![グループのプライバシー設定](group_privacy_settings.png#width-90)

プライバシー設定を変更すると、変更後に作成される内容だけでなく、既存のグループの内容も公開または非公開になる場合があります。グループの目的を満たせる範囲で、最も制限の厳しい設定を選択します。

<!-- translation-section: open -->

## 公開グループ

公開グループは、誰でも閲覧できる場です。誰でもグループを見つけて、ディスカッション、アンケート、ファイルを閲覧できます。メンバー一覧は、メンバーだけが閲覧できます。

公開グループでは、誰でもすぐに参加できるようにする、参加に承認を必要とする、招待された人だけが参加できるようにする、という設定ができます。

<!-- translation-section: follow-an-open-group -->

### 公開グループをフォローする

公開グループには、参加せずに最新の活動を確認する方法があります。フォローすると、グループの未読の活動がまとめメールに追加され、都合のよいときに確認できます。フォローするだけでは、メンバーになることも、メンバーの投票権を得ることも、即時の通知を受け取ることもありません。

グループページで**最新情報をフォロー**をオンにすると、未読のディスカッション、コメント、アンケート、その他のスレッド内の活動がまとめメールに含まれます。グループをまとめメールに含めるのをやめるには、この設定をオフにします。

![公開グループの最新情報をフォロー](group_follow_updates.png)

<!-- translation-section: closed -->

## 非公開グループ

非公開グループは、誰でも見つけて、その名前と説明を閲覧できます。ディスカッション、アンケート、ファイル、メンバー一覧は、メンバーと招待されたゲストだけが閲覧できます。

非公開の親グループでは、参加申請を受け付けるか、招待された人だけが参加できるように設定できます。承認なしですぐに参加できる設定にはできません。

非公開のサブグループでは、誰でも承認なしで参加できるように設定することもできます。サブグループを見つけられる人と、すぐに参加できる人を親グループのメンバーに限定するには、代わりに**親グループに表示**を選択します。

親グループ内の非公開サブグループでは、親グループのメンバーがサブグループに参加せずに、そのディスカッションを閲覧できるように設定することもできます。

<!-- translation-section: visible-to-parent-group -->

## 親グループに表示

このサブグループ設定では、親グループのメンバーがサブグループを見つけられますが、スレッドはサブグループのメンバーと招待されたゲストだけが閲覧できます。どちらのグループにも属していない人は、親グループが公開されていても、サブグループを見つけられません。

親グループのメンバーが自分で参加できるようにするには、**親グループに表示**を選択してから、**[親グループ]のメンバーは承認なしで参加できます**を選択します。参加すると、非公開スレッドへのアクセスを含む、通常のサブグループのメンバー資格が得られます。承認が必要な参加方法や、招待された人だけが参加できる方法も選択できます。

親グループが公開になっても、サブグループのこの公開範囲は維持されます。親グループが非公開になると、その公開サブグループは**親グループに表示**に変わり、スレッドは非公開になります。秘密のサブグループは秘密のままです。非公開の親グループ内で、以前は非公開と表示されていた既存のサブグループは、現在は**親グループに表示**と表示されますが、既存のアクセス権は変わりません。

親グループのメンバーが参加前に非公開スレッドを閲覧できるようにするには、**権限**で**[親グループ]のメンバーは非公開スレッドを閲覧できます**を有効にします。これにより閲覧権限が付与されますが、サブグループのメンバー資格や投票権は付与されません。

<!-- translation-section: secret -->

## 秘密のグループ

秘密のグループとその内容は、招待された人または追加された人だけが閲覧できます。参加には招待が必要です。秘密のグループは、公開グループ一覧には表示されません。

秘密の親グループでは、サブグループの設定は**親グループに表示**または**秘密**に限られます。サブグループを公開グループや非公開グループに設定することはできません。

<!-- translation-section: how-people-join -->

## グループへの参加方法

選択できる参加方法は、プライバシー設定によって決まります。

| グループのプライバシー | 選択できる参加方法 |
| --- | --- |
| **議論中** | 誰でも参加可能、承認が必要、または招待のみ |
| **非公開の親グループ** | 承認が必要、または招待のみ |
| **非公開のサブグループ** | 誰でも参加可能、承認が必要、または招待のみ |
| **親グループに表示** | 親グループのメンバーが参加可能、承認が必要、または招待のみ |
| **秘密** | 招待のみ |

すぐに参加できる人の範囲は、グループの公開範囲に従います。公開サブグループには、誰でも参加できます。**親グループに表示**されるサブグループには、親グループのメンバーが参加できます。メンバーは、参加条件を満たしている限り、退出して再び参加できます。参加方法を変更しても、参加前に非公開スレッドを閲覧できる人の範囲は変わりません。

承認が必要な場合は、**グループに参加する**を選択し、グループが設定した参加時の質問に回答して、参加申請を送信します。質問の設定、申請の確認、人を直接招待する方法については、[人を招待する](/en/user_manual/groups/inviting_people#request-to-join-group)を参照してください。

<!-- translation-section: group-directory -->

## グループ一覧

公開または非公開の親グループは、誰でも見つけられるように公開グループ一覧に掲載できます。一覧への掲載によって、グループの内容を閲覧できる人や、メンバーになれる人が変わることはありません。サブグループと秘密のグループは掲載できません。
