# クイックツアー

このページでは、Loomioの画面の主な構成と、自分に関係する活動を確認できる場所を紹介します。

<!-- translation-section: group-page -->

## グループページ

グループのホームページにはグループの紹介があり、グループの活動にアクセスできます。

![](group_example.png)

<!-- translation-section: tabs -->

### タブ

グループの説明の下にあるタブから、次の内容にアクセスできます。

**議論** - グループのディスカッションのスレッドと最近の活動です。

**アンケート** - グループで実施中のアンケートの一覧です。

**メンバー** - グループに所属する人々です。

**ファイル** - グループ内の各所に添付された文書やその他のファイルです。このタブには、ディスカッションの背景説明、コメント、提案、アンケートに添付されたファイルがまとめられるため、添付場所を覚えていなくても文書を見つけられます。

検索、フィルター、タグ、ブックマーク、未読のディスカッションについては、[コンテンツを探す](/en/user_manual/overview/finding-content)を参照してください。

<!-- translation-section: sidebar -->

## サイドバー

デスクトップでは左上、モバイルでは下部のナビゲーションバーにあるメニューボタン（**☰**）でサイドバーを開きます。

![](sidebar.png)

サイドバーから、ダッシュボード、投票待ちのアンケート、未読のディスカッション、ダイレクトディスカッション、タスク、グループを開けます。ユーザーマニュアルやサポートへのリンクもあります。

<!-- translation-section: user-settings -->

### ユーザー設定

サイドバーで自分の名前を選択すると、ユーザーメニューが開きます。

![](user_settings_sidebar.png)

このメニューでは、プロフィールの編集、通知設定の変更、テーマの選択、アカウント設定の管理、サインアウトができます。

<!-- translation-section: notifications -->

## 通知

デスクトップでは右上、モバイルでは下部のナビゲーションバーにあるベルボタンでアプリ内通知を開きます。まだ確認していない通知があると、バッジが表示されます。

![](../users/email_settings/in_app_notifications.png)

アプリ内通知、メールの受信設定、グループやディスカッションの通知設定については、[通知](/en/user_manual/users/email_settings)を参照してください。

<!-- translation-section: mobile-navigation -->

## モバイルのナビゲーションと読み込み

下部のナビゲーションバーにあるアイコンから、サイドバー、ダッシュボード、通知を開けます。スレッドを読んでいる間は、目次やスレッドの操作にアクセスするためのスレッドメニューボタンも表示されます。検索はダッシュボードから利用できます。ページの見出しがスクロールで画面外に移動すると、タイトルバーにページタイトルが表示されます。

Loomioは、更新を確認している間、現在のセッションにすでに保持されているコンテンツを表示します。データの取得中は、タイトルバーの右上に読み込みインジケーターが表示されます。ダッシュボード、投票待ちのアンケート、通知は、起動後にバックグラウンドで読み込まれます。通知を取得しても、確認済みにはなりません。

スレッドは先頭から開きます。**最新**を選択すると、最新のアクティビティに移動します。特定のコメントやアンケートへのリンクは、引き続きその項目を開きます。
