# 대의원 투표자

그룹의 모든 멤버가 같은 토론 공간을 공유하면서 이사나 선출된 대표자 등 정해진 멤버만 투표해야 할 때 대의원 기능을 사용하세요. 투표자와 투표 권한이 없는 멤버를 구분하기 위해 별도의 하위 그룹을 유지하는 것보다 간단합니다.

해당 멤버들에게 다른 멤버가 볼 수 없어야 하는 토론, 파일 또는 멤버 목록도 필요한 경우에는 비공개 하위 그룹을 사용하세요.

그룹 관리자만 대의원을 지정하거나 해제할 수 있습니다. 그룹 페이지의 **멤버** 탭에서 해당 멤버의 이름 옆에 있는 작업 메뉴를 열고 **대표자 지정**을 선택하세요. 지정을 해제하려면 같은 메뉴에서 **대표자 해제**를 선택하세요.

![멤버 메뉴의 대표자 지정 기능](member_make_delegate.png)

대의원만 투표할 수 있는 투표나 제안을 만들려면 투표 설정에서 **선택한 사람만**을 선택하세요.

![제안을 시작할 때의 선택한 사람만 설정](poll_invited_people_only.png)

투표에 초대할 사람을 고를 때 **[group name]의 대의원**을 선택하세요.

![투표 초대 양식의 Oatmilk Cooperative 대의원 선택지](poll_invite_delegates_group.png)

그룹의 모든 대의원을 확인하려면 **멤버** 탭을 열고 필터 메뉴에서 **대의원**을 선택하세요.

![멤버 필터의 대의원 선택지](members_list_delegates.png)
