# Резервное копирование и экспорт данных группы

Экспорт данных группы позволяет:

- Скачать файл с данными участников, чтобы проверить состав группы.
- Скачать содержимое группы, включая тексты обсуждений и голосований, для архива или анализа.
- Открыть результаты голосования в электронной таблице или обработать их с помощью скрипта.
- [Распечатать обсуждение или голосование либо сохранить его в PDF для архива.](#print-thread-to-pdf)
- Перенести группу вместе со всеми пользователями, обсуждениями, голосованиями и файлами на другой сервер Loomio.

Если вы решите перейти с серверов под управлением Loomio [на собственный сервер](https://github.com/loomio/loomio), воспользуйтесь этой функцией.

Если вы больше не хотите поддерживать собственный сервер Loomio, можно перейти на хостинг Loomio в США, ЕС или Австралии. Чтобы перенести группу на один из этих серверов, [свяжитесь с нами](/contact).

[Свяжитесь с нами](/contact), если хотите перенести группу с общего сервиса Loomio на loomio.com на один из региональных сервисов: loomio.eu для Европы или loomio.nz для Австралии и Новой Зеландии.

## Экспорт данных

Откройте меню группы, нажав на три точки, и выберите **Экспортировать данные группы**.

![Пункт «Экспортировать данные группы» в меню Oatmilk Cooperative](group_export_group_data.png)

<!-- translation-section: export-group-data-as-csv -->

### Экспорт данных группы в CSV

*Для работы с данными группы в электронной таблице, например MS Excel или Google Sheets.*

Loomio подготовит файл CSV в фоновом режиме и отправит вам ссылку для скачивания по электронной почте. Ссылка действует одну неделю.

<!-- translation-section: export-group-data-as-html -->

### Экспорт данных группы в HTML

*Для сохранения данных в архиве.*

Loomio подготовит файл HTML в фоновом режиме и отправит вам ссылку для скачивания по электронной почте. Ссылка действует одну неделю.

<!-- translation-section: export-group-data-as-json -->

### Экспорт данных группы в JSON

*Для переноса данных группы на собственный сервер Loomio.*

Чтобы экспортировать группу, вы должны быть её администратором. В экспорт JSON входят:

- Группа, её участники и запросы на вступление
- Обсуждения, комментарии, реакции, теги, шаблоны, уведомления и связанные записи из включённых групп
- Голосования, варианты, голоса и итоги; анонимное голосование включается только после его завершения
- Подгруппы, в которых вы состоите
- Открытые и закрытые подгруппы при экспорте родительской группы её администратором, даже если вы не состоите в этих подгруппах
- Ссылки на файлы и изображения, прикреплённые к включённым материалам

В экспорт JSON не входят:

- Секретные подгруппы, в которых вы не состоите, включая сведения об их участниках и содержимое
- Подгруппы, ожидающие удаления
- Анонимные голосования, которые ещё не завершились
- Прямые обсуждения и голосования, не принадлежащие группе

Вскоре вы получите письмо со ссылкой для скачивания файла JSON.

## Печать обсуждения в PDF

Вы можете сохранить копию обсуждения в отдельном файловом архиве.

При **Печать** сохраняются все комментарии, голосования, голоса, итоги и форматирование обсуждения.

В меню обсуждения нажмите на три точки (⋯) и выберите **Печать**. Loomio создаст страницу HTML. Затем вы сможете распечатать её или сохранить в PDF с помощью функции печати браузера.

Вы можете скопировать страницу и вставить её в редактор документов, файл или хранилище данных.

![Пункт «Печать» для обсуждения возвратных бутылок](discussion_print_discussion.png#width-90)

## Импорт данных группы на другой сервер Loomio

Инструкции по настройке собственного сервера Loomio: https://github.com/loomio/loomio

Если вы разместили Loomio на собственном сервере и хотите импортировать экспортированные данные:

Скопируйте файл .json в папку `import` экземпляра контейнера:

`scp your-group-data.json username@some-domain.org:loomio-deploy/import`

Откройте консоль работающего приложения Rails:

`docker exec -ti loomio-app rails console`

Вызовите сервис:

`GroupExportService.import('/import/your-group-data.json')`
