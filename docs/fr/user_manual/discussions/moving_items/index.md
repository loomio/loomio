# Déplacer des éléments entre les discussions

Déplacez les éléments sélectionnés lorsqu’une conversation a sa place dans une autre discussion, lorsqu’une discussion s’est divisée en plusieurs sujets ou lorsque vous souhaitez regrouper des discussions liées. Il n’existe pas de commande **Fusionner les discussions** distincte.

Cette option est accessible aux administrateurs du groupe, ainsi qu’aux membres si **Les membres peuvent gérer les discussions et les commentaires.** est activé dans les [permissions du groupe](/en/user_manual/groups/settings/permissions).

Ouvrez le menu à trois points (**⋯**) d’un élément et sélectionnez **Déplacer l'élément**.

![](../using_discussions/comment_move.png)

Sélectionnez les éléments à déplacer.

![](../using_discussions/comment_select.png)

Cochez les autres éléments à déplacer, puis cliquez sur **Déplacer** dans la bannière en haut de la discussion.

![](../using_discussions/move_items.png)

Choisissez le groupe ou le sous-groupe, puis recherchez la discussion de destination.

Pour déplacer les éléments vers une nouvelle discussion, sélectionnez **Nouvelle discussion**, puis ajoutez un titre et un contexte.

![](../using_discussions/move_items_new_thread.png)

Les éléments sont déplacés de la discussion d’origine vers la discussion sélectionnée ou nouvellement créée.

![](../using_discussions/new_thread.png)

Si la discussion d’origine n’est plus nécessaire, vous pouvez la [verrouiller](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread). Ne la supprimez que si vous êtes certain qu’elle ne sera plus utile.
