# Etiquetas de categoría

Las etiquetas de categoría te ayudan a encontrar discusiones, encuestas, conclusiones y comentarios sobre un tema o área de trabajo.

Las etiquetas pertenecen a toda la organización. Una etiqueta creada en un grupo principal se comparte con sus subgrupos, para que puedas hacer un seguimiento del trabajo relacionado entre grupos. Loomio muestra las etiquetas en orden alfabético con un punto de color junto a cada nombre.

En la página de tu grupo, selecciona **Etiquetas**, encima de la lista de hilos, y elige una etiqueta para mostrar los hilos que contienen al menos un elemento con esa etiqueta. Escribe en el campo de filtro para buscar en una lista larga.

![](tags_view.png)

<!-- translation-section: apply-tags -->

## Aplicar etiquetas

Puedes etiquetar tus propias discusiones, encuestas, conclusiones y comentarios. Los admins del grupo, los admins del hilo y las personas con permiso para editar el contexto de la discusión pueden etiquetar cualquier elemento en un hilo desbloqueado. En los hilos directos, todos los participantes pueden etiquetar cualquier elemento.

Al iniciar un hilo o una encuesta, selecciona el campo **Etiquetas** y elige una o varias etiquetas.

![](tags_add_new.png)

Empieza a escribir para filtrar la lista. Selecciona una etiqueta de nuevo, o selecciona **×** en la etiqueta, para quitarla.

<!-- translation-section: create-tags -->

## Crear etiquetas

Quién puede crear etiquetas depende de los roles y permisos del grupo:

- Los **admins del grupo principal** siempre pueden crear etiquetas para el grupo principal y sus subgrupos.
- Los **admins de los subgrupos** pueden crear etiquetas al etiquetar contenido en su subgrupo.
- Los **Integrantes del grupo** que pueden etiquetar contenido también pueden crear etiquetas mientras esté activado el permiso **Los miembros pueden crear etiquetas** (activado de forma predeterminada). Si un admin del grupo lo desactiva, los miembros solo pueden usar las etiquetas existentes de la organización y las etiquetas predeterminadas de las plantillas de ese grupo.

Para crear una etiqueta al iniciar un hilo o una encuesta, escribe el nombre en el campo **Etiquetas** y pulsa Enter.

![crear una etiqueta nueva](tags_create_new.png)

![etiqueta nueva creada](tags_created_new.png)

Usa nombres cortos y reconocibles, como Finanzas, Gobernanza, Embalaje o Colaboraciones con cafeterías.

## Etiquetas en las plantillas

Las plantillas de discusiones y encuestas guardan nombres de etiquetas predeterminadas. Cualquier persona que pueda crear o editar una plantilla puede cambiar sus etiquetas predeterminadas. Guardar una plantilla no añade esos nombres a la lista de etiquetas de la organización, y cambiar el nombre de una etiqueta de la organización o eliminarla no modifica los valores predeterminados de las plantillas.

Cuando alguien inicia una discusión o una encuesta a partir de una plantilla, Loomio aplica las etiquetas coincidentes de la organización o crea otras nuevas si el autor tiene permiso:

- Los **miembros que pueden crear etiquetas** conservan todas las etiquetas predeterminadas de la plantilla.
- Los **miembros sin permiso para crear etiquetas** conservan las etiquetas existentes de la organización y las etiquetas predeterminadas definidas por las plantillas del grupo de destino. Se descartan los nombres de etiquetas de una plantilla de otro grupo que no coincidan.

## Editar etiquetas

Solo los admins del grupo principal pueden cambiar el nombre o el color de las etiquetas, fusionarlas o eliminarlas. Los cambios se aplican en toda la organización, incluidos todos los subgrupos.

En la página del grupo, abre **Etiquetas** y selecciona **Editar etiquetas**.

![editar etiquetas de categoría](tags_edit_new.png)

Selecciona el icono del lápiz junto a una etiqueta para editarla.

![editar etiquetas de categoría](tags_edit_new_pencil.png)

Cambia el nombre de la etiqueta o elige un color y luego selecciona **Guardar**.

![editar el color de la etiqueta](tags_edit_name.png)

Para fusionar una etiqueta con otra, selecciona el icono de fusión junto a ella y elige la etiqueta que quieras conservar. Todos los elementos con la etiqueta anterior pasan a tener la etiqueta elegida.

Para eliminar una etiqueta, selecciona **Eliminar** (o el icono de la papelera). Esto quita la etiqueta de todas las discusiones, encuestas, conclusiones y comentarios de la organización.

![eliminar etiqueta](tags_delete.png)

### Editar etiquetas en un hilo o una encuesta

Para cambiar las etiquetas de un hilo o una encuesta existente, ábrelo y selecciona el botón de etiquetas junto a las etiquetas actuales, cerca del título.

Selecciona etiquetas para añadirlas o quitarlas. Los cambios se guardan inmediatamente.

El selector muestra las etiquetas utilizadas en el grupo actual, las etiquetas de la organización que no se utilizan y las etiquetas seleccionadas para el elemento. En una organización con varios grupos, selecciona **Muestra etiquetas de otros grupos** para incluir las etiquetas utilizadas solo en otros grupos, o **Mostrar etiquetas utilizadas en este grupo** para volver a reducir la lista.

![editar etiquetas en un hilo](tags_thread_edit.png)

## Etiquetar contribuciones

Abre el menú de tres puntos (**⋯**) de una encuesta, una conclusión o un comentario y selecciona **Aplicar etiquetas**. Añade o quita etiquetas en el selector; los cambios se guardan inmediatamente. Cuando una contribución tiene etiquetas, estas y el botón de etiquetas aparecen a la derecha de la línea del autor.

Las etiquetas se aplican al elemento que seleccionas. Los votos y las papeletas no se pueden etiquetar.

<!-- translation-section: find-tagged-contributions -->

## Encontrar contribuciones etiquetadas

Cuando un comentario, una encuesta o una conclusión dentro de un hilo tiene una etiqueta, aparece una sección **Etiquetas** en la barra lateral del hilo (o en el panel de navegación en el móvil).

Selecciona una etiqueta para filtrar el hilo y mostrar los elementos coincidentes y los elementos a los que responden. Para volver al hilo completo, selecciona **×** en la barra de filtro, selecciona la etiqueta de nuevo o selecciona **Limpiar** en la barra lateral.

![Etiquetas en la barra lateral del hilo](tags_thread_sidebar.png)

<!-- translation-section: global-search -->

## Buscar por etiqueta

Abre **Buscar** desde la navegación superior y selecciona tu grupo principal para mostrar el menú de etiquetas. Elige una etiqueta para encontrar discusiones, encuestas, conclusiones y comentarios con esa etiqueta.

Deja el campo de búsqueda vacío para explorar por etiqueta, o introduce palabras clave para buscar en los elementos etiquetados. Selecciona **cualquier etiqueta** para quitar el filtro.

![Selección de una etiqueta en la búsqueda global después de elegir el grupo principal](tags_global_search.png)
