# Let non-members start discussions

Admins of Open and Closed groups can enable **Non-members can start discussions** in group permissions. Anyone with a user account can choose one of the group's discussion templates and start a discussion. This supports processes where a person nominates themselves or someone else for a position. The submitter becomes a guest of that discussion without joining the group or gaining access to other private discussions.

The setting is off by default and is not available for Secret groups.

See [Collect private submissions](/en/user_manual/discussions/private_submissions) for a complete example workflow.
