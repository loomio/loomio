# Распределение

Распределение, также известное как распределение баллов, помогает выявить приоритеты, когда приходится идти на компромиссы. Каждый участник получает фиксированное количество баллов и распределяет их между вариантами. Чем больше баллов получает один вариант, тем меньше остаётся для остальных.

<!-- translation-section: when-to-use-allocate -->

## Когда использовать Распределение

Используйте Распределение, когда время, деньги, внимание или другой ресурс ограничены. Этот метод подходит для следующих задач:

- определение приоритетов работы на следующий период планирования;
- распределение бюджета между проектами с участием заинтересованных людей;
- определение времени для нескольких тем в повестке;
- распределение фиксированного количества часов волонтёрской работы; или
- определение улучшений, наиболее важных для участников группы.

Баллы выражают относительный приоритет, а не количество ресурсов, которое Loomio автоматически выделит. Используйте [Оценку](/en/user_manual/polls/score/), когда каждый вариант может получить высокую оценку без снижения поддержки других вариантов.

<!-- translation-section: example-set-priorities-for-an-annual-strategy-review -->

## Пример: определите приоритеты ежегодного пересмотра стратегии

Кооператив Oatmilk планирует ежегодный пересмотр стратегии. Он спрашивает участников группы, каким направлениям следует уделить больше всего времени и внимания при пересмотре. Каждый участник получает десять баллов для распределения между пятью направлениями. Это показывает относительные приоритеты группы и требует от участников делать выбор в условиях ограниченных ресурсов.

<!-- translation-section: set-up-the-poll -->

## Настройте опрос

Опишите решение и объясните, что означают баллы. Добавьте варианты сопоставимого масштаба, затем задайте **Баллы на человека**. В этом примере каждый голосующий получает десять баллов, чтобы показать, сколько времени следует уделить каждому стратегическому направлению при пересмотре.

![](form.png)

Слишком большое количество баллов может создать ложное впечатление точности. Обычно баллов должно быть достаточно, чтобы показать различия, но достаточно мало, чтобы требовалось делать выбор. Укажите, допустимо ли отдать все баллы одному варианту.

<!-- translation-section: vote -->

## Голосуйте

Участники перемещают ползунки, чтобы распределить свои баллы. Loomio показывает, сколько баллов осталось, и не позволяет отправить голос, пока баллы не будут распределены корректно.

![](voting.png)

В этом примере голосующий отдаёт по три балла вариантам **Участие участников группы** и **Финансовая устойчивость**, по два — вариантам **Воздействие на окружающую среду** и **Развитие сотрудников**, и ни одного — варианту **Продукты и услуги**. Ноль не обязательно означает, что направление не имеет ценности; он означает, что голосующий использовал ограниченные баллы для других направлений.

<!-- translation-section: read-the-results -->

## Изучите результаты

В результатах варианты упорядочены по общему количеству полученных баллов. Также показаны:

- **% баллов**: доля варианта во всех распределённых баллах;
- **Точки**: общее количество распределённых баллов;
- **Иметь в виду**: среднее количество баллов среди голосующих, которые дали этому варианту баллы; и
- **Избиратели**: количество людей, которые дали варианту хотя бы один балл.

![](results.png)

В этом примере **Финансовая устойчивость** получает больше всего баллов, за ней следует **Развитие сотрудников**. Финансовая устойчивость получает баллы от каждого голосующего, что указывает на широкое согласие с тем, что этому направлению нужно уделить значительное время при пересмотре. Сопоставляйте общее количество баллов с числом голосующих, чтобы отличить общие приоритеты от направлений, которые активно поддерживает меньшее число людей.

Рассматривайте общее количество баллов вместе с числом голосующих и указанными ими причинами выбора.

<!-- translation-section: share-an-outcome -->

## Поделитесь выводом

Когда опрос закроется, поделитесь выводом. Опрос не распределяет время или деньги автоматически, поэтому объясните, как будут использованы результаты. О том, как работают выводы, читайте в разделе [Поделитесь выводом](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome).
