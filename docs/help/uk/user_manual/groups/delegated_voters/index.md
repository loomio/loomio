# Делегати з правом голосу

Використовуйте делегатів, коли всі учасники групи мають спільний простір для обговорень, але голосувати повинно лише визначене коло учасників, наприклад директори або обрані представники. Це простіше, ніж підтримувати окрему підгрупу лише для відокремлення виборців від тих, хто не має права голосу.

Використовуйте приватну підгрупу, якщо цим учасникам також потрібні обговорення, файли або список учасників, які інші учасники групи не повинні бачити.

Лише адміністратор групи може надавати або скасовувати статус делегата. На вкладці **Учасники** на сторінці вашої групи відкрийте меню дій поруч з іменем людини та виберіть **Делегувати**. Щоб скасувати цей статус, виберіть **Відкликати делегата** в тому самому меню.

![Дія «Делегувати» в меню учасника](member_make_delegate.png)

Щоб створити опитування або пропозицію, у яких можуть голосувати лише делегати, виберіть **Тільки вибрані люди** в налаштуваннях опитування.

![Налаштування «Тільки вибрані люди» під час створення пропозиції](poll_invited_people_only.png)

Вибираючи, кого запросити голосувати, виберіть **Делегати групи [назва групи]**.

![Варіант «Делегати групи Oatmilk Cooperative» у формі запрошення голосувати](poll_invite_delegates_group.png)

Щоб переглянути всіх делегатів групи, відкрийте вкладку **Учасники** та виберіть **Делегати** в меню фільтра.

![Варіант «Делегати» у фільтрі учасників](members_list_delegates.png)
