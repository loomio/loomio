# カテゴリタグ

カテゴリタグを使うと、特定の種類の作業や話題に関するスレッドやアンケートを簡単に見つけられます。

タグは組織全体で共有されます。親グループで使うタグはサブグループでも同じタグとして扱われるため、組織全体で関連する作業を整理できます。Loomioではタグ名がアルファベット順に表示され、名前の横にタグの色を示す点が表示されます。

グループページでスレッド一覧の上にある**タグ**をクリックすると、そのグループで使われているタグが表示されます。タグを選択すると、そのタグが付いたスレッドだけが表示されます。タグの一覧が長い場合は、絞り込み用のテキストボックスで検索できます。**もっと見せる**を選択すると、組織内のすべてのタグが表示されます。**表示数を減らす**を選択すると、そのグループのタグの表示に戻ります。

![](tags_view.png)

<!-- translation-section: apply-tags -->

## タグを付ける

スレッドやアンケートを編集できるメンバーは、タグを付けられます。

スレッドやアンケートを開始するときに、**タグ**欄をクリックして、タグを1つ以上選択します。

![](tags_add_new.png)

文字を入力すると、一覧を絞り込めます。タグをもう一度選択するか、タグのチップにある×をクリックすると、そのタグを外せます。

<!-- translation-section: create-tags -->

## タグを作成する

親グループの管理者は、いつでも親グループとそのサブグループで使うタグを作成できます。サブグループの管理者は、自分が管理するサブグループのコンテンツにタグを付ける際に、新しいタグを作成できます。グループの権限設定**メンバーはタグを作成できます**は、初期設定で有効になっています。この設定により、スレッドやアンケートにタグを付けられる他のメンバーも、新しいタグ名を作成できます。この権限が無効になっていても、メンバーは既存のタグを付けられます。

スレッドやアンケートを開始するときにタグを作成するには、**タグ**欄に名前を入力してEnterキーを押します。

![新しいタグを作成](tags_create_new.png)

![作成された新しいタグ](tags_created_new.png)

「財務」「組織運営」「梱包」「カフェとの連携」など、グループのメンバーが分かる、短くなじみのある名前を使います。

<!-- translation-section: edit-tags -->

## タグを編集する

タグの名前や色の変更、統合、削除ができるのは、親グループの管理者だけです。これらの変更は、サブグループを含む組織全体に適用されます。

グループページで**タグ**を開き、**タグを編集**を選択します。

![カテゴリタグを編集](tags_edit_new.png)

タグの横にある鉛筆アイコンを選択します。

![カテゴリタグを編集](tags_edit_new_pencil.png)

タグ名を編集するか色を選択して、**保存**をクリックします。

![タグの色を編集](tags_edit_name.png)

**消去**をクリックすると、組織内のすべてのスレッドとアンケートからそのタグが削除されます。

![タグを削除](tags_delete.png)

<!-- translation-section: edit-tag-in-thread-or-poll -->

### スレッドやアンケートのタグを編集する

既存のスレッドやアンケートのタグを変更するには、そのスレッドやアンケートを開き、タイトル付近の現在のタグの横にあるタグボタンをクリックします。

タグを選択して追加または解除します。変更はすぐに保存されます。

![スレッドのタグを編集](tags_thread_edit.png)
