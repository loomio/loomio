# Закладки

Закладки — это ваш личный список элементов Loomio, к которым вы хотите вернуться. Ваши закладки видны только вам, и при сохранении элемента никто другой не получает уведомлений.

Вы можете добавлять в закладки:

- обсуждения
- комментарии
- предложения и опросы
- голоса
- выводы

<!-- translation-section: save-a-bookmark -->

## Сохранение закладки

Откройте меню действий элемента и выберите **Сохранить закладку**. Меню действий обычно обозначено тремя точками. Для обсуждения используйте меню действий рядом с заголовком обсуждения; для комментария, голоса, предложения, опроса или вывода используйте меню самого элемента.

![](save_bookmark.png)

<!-- translation-section: view-your-bookmarks -->

## Просмотр ваших закладок

Откройте боковую панель и выберите **Закладки**. Число рядом со ссылкой показывает, сколько закладок вы сохранили.

На странице «Закладки» сначала отображаются элементы, сохранённые последними. В каждой строке указаны тип элемента и его автор. Выберите строку, чтобы вернуться к элементу, сохранённому в закладках.

![](bookmarks_page.png)

<!-- translation-section: remove-a-bookmark -->

## Удаление закладки

На странице «Закладки» нажмите кнопку удаления закладки в конце строки. Вы также можете открыть меню действий элемента, сохранённого в закладках, и выбрать **Удалить закладку**.

Удаление закладки влияет только на ваш личный список. Позже вы можете снова сохранить этот элемент.
