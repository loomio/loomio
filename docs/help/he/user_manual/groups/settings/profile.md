# פרופיל הקבוצה

לשונית הפרופיל קובעת כיצד הקבוצה מזוהה ומוצגת. יש לפתוח את **ערוך הגדרות קבוצה** מדף הקבוצה, ואז לבחור **פרופיל**.

![הגדרות פרופיל הקבוצה](group_profile.png)

<!-- translation-section: name-and-handle -->

## שם ומזהה

מומלץ לתת לקבוצה שם קצר, במיוחד אם היא עתידה לכלול תת־קבוצות. Loomio משתמש במזהה בכתובת האתר ובכתובת הדוא״ל של הקבוצה, למשל `loomio.com/your-group-handle` ו־`your-group-handle@loomio.com`.

לאחר שינוי המזהה, קישורים המשתמשים במזהה הקודם מפנים לכתובת החדשה, ודוא״ל שנשלח לכתובת הקודמת של הקבוצה ממשיך להגיע לקבוצה. Loomio שומר עד שלושה מזהים קודמים; שינוי נוסף של המזהה לאחר מכן גורם למזהה הישן ביותר לצאת משימוש.

<!-- translation-section: description -->

## תיאור

יש להשתמש בתיאור כדי להסביר מה מטרת הקבוצה, מי משתתפים בה וכיצד מצופה להשתמש בה. ניתן לעצב את התיאור ולכלול בו קישורים, מסמכים וסרטונים.

השם והתיאור עשויים להיות גלויים גם למי שאינם חברים בקבוצה, בהתאם ל[הגדרות הפרטיות](/en/user_manual/groups/settings/privacy) של הקבוצה.

<!-- translation-section: cover-image-and-logo -->

## תמונת נושא ולוגו

תמונת הנושא מופיעה לרוחב החלק העליון של דף הקבוצה. תמונה רחבה מתאימה ביותר; הגודל המומלץ הוא 2048 × 512 פיקסלים.

לוגו הקבוצה מזהה את הקבוצה בניווט ובמקומות אחרים שבהם שטח התצוגה מצומצם. יש להעלות את תמונת הנושא ואת הלוגו בנפרד, כדי שניתן יהיה לחתוך כל אחד מהם לצורה המתאימה לו.
