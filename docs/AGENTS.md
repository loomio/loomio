# Documentation instructions

Before working on documentation, read the applicable task instructions:

- [User manual and help site](agents/user_manual.md) for user-manual pages, guides, API documentation, changelog entries, the site builder, navigation, links, and redirects. This includes API code-example formatting guidance.
- [User-manual translations](agents/user_manual_translations.md) for translations and translation tooling, alongside the user-manual instructions. Also read this when preparing a feature for merge.
- [User-manual screenshots](agents/user_manual_screenshots.md) for generating, changing, reviewing, or publishing manual screenshots, alongside the user-manual instructions. Also read this when preparing a feature for merge.
- [Release notes](agents/release_notes.md) for release notes and release preparation.
- [Writing and Markdown](agents/writing.md) for all documentation prose.

Files under `docs/agents/` contain repository instructions and are not published help-site pages. Maintain the root [AGENTS.md](../AGENTS.md) task index when adding, renaming, or removing an instruction document.
