# Апытанні

Апытанні дапамагаюць сабраць выбар варыянтаў, ацэнкі, размеркаванне балаў, рэйтынгі, звесткі пра даступны час або галасы на выбарах. Выберыце спосаб галасавання з улікам таго, што ўдзельнікі хочуць выказаць і як вы плануеце выкарыстаць вынік. Калі людзям трэба выказаць стаўленне да сцвярджэння або плана дзеянняў, выкарыстоўвайце [прапанову](/en/user_manual/polls/proposals/).

<!-- translation-section: simple-poll -->

## Простае апытанне

[Выберыце](/en/user_manual/polls/choose/) дазваляе ўдзельнікам выбраць адзін або некалькі варыянтаў. Выкарыстоўвайце гэты спосаб, каб знайсці самы папулярны варыянт або скласці кароткі спіс.

<!-- translation-section: score-poll -->

## Апытанне аб ацэнцы

[Ацэнка](/en/user_manual/polls/score/) дазваляе ўдзельнікам ацаніць кожны варыянт па адной шкале. Выкарыстоўвайце гэты спосаб, каб параўнаць падтрымку, гатоўнасць, прыдатнасць або важнасць варыянтаў.

<!-- translation-section: dot-vote -->

## Галасаванне баламі

[Выдзеліць](/en/user_manual/polls/allocate/) дае кожнаму ўдзельніку фіксаваную колькасць балаў для размеркавання. Выкарыстоўвайце гэты спосаб, каб вызначыць прыярытэты, калі выбар аднаго варыянту азначае менш увагі або рэсурсаў для іншага.

<!-- translation-section: ranked-choice -->

## Рэйтынгавы выбар

[Ранг](/en/user_manual/polls/rank/) дазваляе ўдзельнікам размясціць варыянты ў парадку перавагі. Выкарыстоўвайце гэты спосаб, каб вызначыць агульны парадак пераваг групы або выбраць адзін найбольш пераважны варыянт.

<!-- translation-section: time-poll -->

## Апытанне часу

[Апытанне часу](/en/user_manual/polls/meeting_polls/) дазваляе ўдзельнікам пазначыць, калі яны могуць сустрэцца. Выкарыстоўвайце гэты спосаб, каб запланаваць сустрэчу або мерапрыемства для людзей у розных часавых паясах.

<!-- translation-section: stv-election -->

## Выбары на СТВ

[Выбары на СТВ](/en/user_manual/polls/stv/) дазваляюць удзельнікам размясціць кандыдатуры ў парадку перавагі на прапарцыйных выбарах з некалькімі пераможцамі. Выкарыстоўвайце СТВ, каб абраць склад камітэта, рады або групы дэлегатаў.

<!-- translation-section: other-specialized-method -->

## Іншы спецыяльны спосаб

У Loomio таксама ёсць раўнд пытанняў, які дазваляе збіраць пытанні без галасавання. Адміністратары групы могуць зрабіць яго даступным праз [шаблоны апытанняў](/en/user_manual/polls/poll_templates/).
