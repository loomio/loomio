# グループの削除

グループを削除できるのはグループ管理者のみです。グループを削除すると、すぐにアクセスできなくなり、グループとそのサブグループのすべてのデータが90日後に完全に削除されるよう予約されます。

グループを削除する前に、[グループのデータをエクスポート](/en/user_manual/groups/data_export)し、アップロードしたファイルのうち残しておきたいものをダウンロードしてください。

グループを削除するには、グループページの**設定**を開き、**グループの削除**を選択します。

![Oatmilk Cooperativeの設定ページにあるグループの削除操作](group_delete_group.png)

グループのハンドル名を入力して、削除を確定します。

![Oatmilk Cooperativeのハンドル名の入力を求める確認フォーム](group_delete_group_confirm.png)

削除を確定すると、次のようになります。

- グループとそのサブグループはすぐに表示されなくなります。メンバーとグループ管理者は、コンテンツの閲覧、参加、エクスポートができなくなります。保存したリンクから開くアンケートも対象です。
- グループとそのサブグループの未送信のアクティビティ通知とアンケートのリマインダーが停止します。ただし、すでに送信中のメッセージは届く場合があります。
- Loomioのサブスクリプションが解約されます。
- グループに属さない直接のディスカッションやアンケートには影響しません。

Loomioは、グループのサブグループ数、メンバー数、ディスカッション数、アンケート数、コメント数を記載した警告メールも送信します。誤ってグループを削除した場合や、データをエクスポートする必要がある場合は、アクセスを復元するため、90日以内にそのメールに返信するか、Loomioにお問い合わせください。

## グループのデータは90日後に完全に削除されます

90日後、Loomioはグループとそのサブグループ内のすべてのスレッド、アンケート、ファイル、その他のコンテンツを完全に削除します。この操作は取り消せません。
