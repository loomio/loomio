# グループの権限

権限タブでは、一般のメンバーが行える操作を設定できます。非公開ではないグループでは、非メンバーに許可する操作も設定できます。グループのページで**グループ設定を編集する**を開き、**権限**を選択します。

![グループの権限設定](group_group_settings_permissions.png)

管理者は引き続きグループを管理できます。メンバーの権限を有効にすると、一般のメンバーもその操作を行えるようになります。管理者になるわけではありません。

メンバーに許可できる操作には、次のものがあります。

- メンバーを追加する、またはゲストを招待する
- お知らせを送る
- サブグループを作成する
- ディスカッションを開始、管理する
- タグを作成、管理する
- 設定で許可されている場合にコメントを編集、削除する
- 提案や投票を開始する
- ディスカッションと投票のテンプレートを作成する

非公開ではないグループでは、管理者は非メンバーによるディスカッションの開始を別途許可できます。ディスカッションを開始した非メンバーは、そのディスカッションのゲストになります。ただし、ほかのプライベートなディスカッションにはアクセスできず、グループのメンバーにもなりません。

**管理者はメンバーのコメントを編集できます**を有効にすると、管理者はメンバーが書いたコメントを編集できるようになります。メンバーが書いた内容を管理者が変更してよいとグループで合意した場合にのみ、有効にしてください。

グループの目的、メンバー構成、モデレーションの担当が変わったときは、権限を見直してください。各役割に必要な権限だけを付与します。
