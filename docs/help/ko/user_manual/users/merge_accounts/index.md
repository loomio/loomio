# 계정 통합

서로 다른 이메일 주소를 사용하는 두 Loomio 계정을 하나로 사용하려면 계정을 통합하세요.

시작하기 전에 어떤 계정을 유지할지 결정하세요:

- **유지할 계정**은 통합 후 이메일 주소와 프로필을 사용할 계정입니다.
- **사용을 중단할 계정**은 먼저 로그인할 계정입니다. 통합 후에는 이 계정의 이메일 주소로 로그인할 수 없습니다.

두 계정 모두에 접근할 수 있어야 하며, 유지할 계정의 이메일 주소로 수신한 메일을 확인할 수 있어야 합니다.

> [!WARNING]
> 계정 통합은 되돌릴 수 없습니다. 통합을 확인하기 전에 사용을 중단할 계정과 유지할 계정의 이메일 주소를 주의 깊게 확인하세요.

## 통합 시작

1. **사용을 중단할 계정**으로 로그인하세요.
2. 사이드바를 열고 이름을 선택한 다음 **프로필 수정**을 선택하세요.
3. **계정 통합**을 선택하세요.

![계정 통합이 강조 표시된 프로필 작업 메뉴](merge_accounts_profile.png)

4. **유지할 계정**의 이메일 주소를 입력하고 **인증 이메일 보내기**를 선택하세요. 개인정보 보호를 위해 Loomio는 항상 동일한 확인 메시지를 표시하고 로그아웃합니다. 해당 주소를 사용하는 계정이 있으면 Loomio가 그 주소로 인증 이메일을 보냅니다.

<!-- translation-section: verify-the-account-you-want-to-keep -->

## 유지할 계정 인증

5. **유지할 계정**으로 전송된 인증 이메일을 열고 **이메일 인증 후 계속**을 선택하세요.

![이메일 인증 후 계속 버튼이 강조 표시된 계정 통합 인증 이메일](merge_accounts_email.png)

6. Loomio에서 로그인을 요청하면 **유지할 계정**으로 로그인하세요.
7. **통합 확인** 페이지에서 두 이메일 주소를 다시 확인하세요. **계정 통합**을 선택하여 통합을 완료하세요.

![계정 통합 버튼이 강조 표시된 최종 확인 페이지](merge_accounts_confirm.png)

## 통합 후 변경 사항

통합 후에도 유지할 계정은 계속해서 Loomio에서 사용하는 프로필과 로그인 계정이 됩니다. Loomio는 사용을 중단할 계정의 모든 그룹 멤버십과 토론, 댓글, 투표, 제출한 표를 포함한 활동을 유지할 계정으로 이전합니다. 두 계정이 이미 같은 그룹에 속해 있다면 Loomio는 유지할 계정의 멤버십을 유지합니다.

Loomio는 사용을 중단할 계정을 삭제하며, 해당 이메일 주소로는 더 이상 로그인할 수 없습니다. 통합이 완료되면 Loomio가 유지할 계정으로 확인 이메일을 보냅니다.
