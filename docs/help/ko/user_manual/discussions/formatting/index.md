# 텍스트 서식 지정 및 파일 첨부

토론이나 투표를 시작하거나 편집할 때, 또는 댓글을 작성할 때 텍스트 입력란 아래에 서식 도구 모음이 표시됩니다. 도구 모음 끝에 있는 화살표를 선택하면 전체 도구를 표시하거나 숨길 수 있습니다.

각 항목 위에 마우스 포인터나 커서를 올리면 도구 이름이 표시됩니다.

![](thread_format_bar.png)

<!-- translation-section: attach-file -->

## 파일 첨부

텍스트 입력란 바로 아래에 있는 클립 아이콘을 사용해 컴퓨터의 파일을 첨부하세요.

![](format_attach.png)

<!-- translation-section: remove-attachments -->

### 첨부 파일 삭제

배경을 편집하는 동안 파일 이름 오른쪽의 **X**를 클릭하면 해당 파일을 삭제할 수 있습니다.

![](thread_file_remove.png)

<!-- translation-section: insert-image -->

## 이미지 삽입

**이미지 삽입**을 선택하고 파일을 고르거나, 편집기에 이미지를 직접 붙여 넣으세요. 이미지는 게시된 토론, 투표 또는 댓글 안에 표시됩니다.

![](format_insert_example.png)

<!-- translation-section: insert-link -->

## 링크 삽입

인터넷에서 공유할 수 있는 문서나 페이지의 링크를 추가할 수 있습니다.  

링크를 추가하려면:

1. 문서 이름처럼 링크를 연결할 텍스트를 선택하세요.
2. 링크 아이콘을 클릭하세요.
3. **링크 삽입** 입력란에 주소를 붙여 넣고 **적용**을 선택하세요.

다른 서비스에 저장된 문서라면 토론 참여자가 열 수 있도록 공유 권한을 확인하세요.

텍스트 아래에 미리 보기가 표시될 수 있습니다. 원하면 삭제할 수 있습니다.

![](format_link.png)

<!-- translation-section: insert-emoji -->

## 이모지 삽입

웃는 얼굴 버튼을 선택하고 선택 창에서 이모지를 고르세요.

![](thread_insert_emoji.png)

<!-- translation-section: headings -->

## 제목

제목 1, 제목 2, 제목 3을 사용하면 토론이나 댓글의 내용을 체계적으로 구성할 수 있습니다.

제목으로 지정할 텍스트를 선택하고 제목 서식 도구를 클릭하세요.

댓글에 제목을 사용하면 해당 댓글이 토론 타임라인에 자동으로 추가됩니다.

![](format_heading.png)

## 굵게, 기울임꼴, 취소선

서식을 지정할 텍스트를 선택하고 원하는 서식 도구를 클릭하세요.

![](format_bold.png)

<!-- translation-section: list -->

## 목록

**목록**을 사용해 항목을 글머리 기호 목록으로 표시하세요.

![](thread_bullets.png)

<!-- translation-section: numbered-list -->

## 번호 목록

항목의 순서가 중요할 때는 **번호 목록**을 사용하세요.

![](format_numbers.png)

<!-- translation-section: task-list -->

## 할 일 목록

**할 일 목록**을 사용해 확인란을 추가하세요. 목록을 게시한 후에는 할 일을 담당자에게 배정하고 마감일을 지정할 수 있습니다.

![](format_tasks.png)

자세한 내용은 [할 일](/en/user_manual/discussions/tasks/) 페이지를 참고하세요.

<!-- translation-section: colors -->

## 색상

**색상**을 사용해 선택한 텍스트에 강조 색상을 적용하세요.

![](thread_colors.png)

<!-- translation-section: align -->

## 정렬

텍스트를 왼쪽, 가운데 또는 오른쪽으로 정렬하려면 선택하세요.

![](thread_align.png)

<!-- translation-section: embed-videos-and-webpages -->

## 동영상 및 웹페이지 삽입

서식 도구 모음이 있는 곳이면 어디든 지원되는 동영상과 웹페이지를 삽입할 수 있습니다.

동영상 삽입 기능을 사용하려면 다음 단계를 따르세요.
1. 동영상 또는 웹페이지의 주소를 복사하세요.
2. **동영상 삽입**을 선택하고 주소를 붙여넣은 다음 **적용**을 선택하세요.

![](format_embed.png)

>[!Tip]
>토론에 참여할 수 있는 모든 사람이 동영상에 접근할 수 있는지 확인하세요. 예를 들어 공개 검색 결과에 표시되지 않아야 하는 동영상은 일부 공개로 설정하는 것이 적절할 수 있습니다.

## 인용

인용은 텍스트를 강조하며, 안내 사항에 주의를 끌 때 유용합니다.

![](thread_quote.png)

## 코드 블록

코드 블록 서식은 주로 본문에 코드를 표시할 때 사용하지만, 토론에서 특정 텍스트를 구분하는 데도 사용할 수 있습니다.

![](thread_codeblock.png)

<!-- translation-section: divider -->

## 구분선

구분선을 사용하여 가로선을 긋고 내용을 구분하세요.

![](thread_line.png)

<!-- translation-section: add-table -->

## 표 추가

토론에 표를 추가하세요.

열과 행을 추가하거나 삭제하는 도구도 사용할 수 있습니다.

![](thread_table.png)

<!-- translation-section: markdown -->

## 마크다운

마크다운 편집으로 전환하려면 **마크다운 편집**을 선택하세요.

마크다운으로 변환하면 제목, 굵은 글씨와 기울임꼴, 목록, 기본 표, 완료 표시된 할 일, 이미지, 링크, @멘션이 유지됩니다. 동영상, 오디오, 삽입된 콘텐츠는 링크로 바뀝니다.

텍스트 색상, 강조 색상, 밑줄, 정렬, 표 배치는 유지되지 않을 수 있습니다. 할 일의 마감일과 알림은 삭제됩니다. 서식 있는 텍스트로 다시 변환하면 텍스트와 완료 표시 상태가 동일한 새 할 일이 생성됩니다.

<!-- translation-section: rich-text -->

### 서식 있는 텍스트

서식 도구로 돌아가려면 **서식 있는 텍스트 편집**을 선택하세요. 지원되는 마크다운이 화면에 표시되는 형태로 변환됩니다.

**미리 보기**는 마크다운을 변환하지 않고 게시 후 표시될 모습을 보여줍니다.
