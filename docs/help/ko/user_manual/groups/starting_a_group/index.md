# 새 그룹 시작하기

Loomio를 처음 사용한다면 언제든지 [Loomio 웹사이트](https://www.loomio.com/)에서 무료 체험으로 그룹을 시작할 수 있습니다. 이미 Loomio를 사용하고 있으며 다른 조직이나 목적을 위해 새 그룹을 시작하려면 사이드바 메뉴에서 **새 그룹**을 클릭하세요.

많은 조직에서는 Loomio 그룹 하나로 충분합니다. 그룹 안에 필요한 만큼 하위 그룹을 만들 수 있습니다. 자세한 내용은 [하위 그룹](/en/user_manual/groups/subgroups/)을 참고하세요.

### 그룹 이름

그룹 이름을 입력하세요. 그룹 이름은 짧고 간결하게 정하는 것이 좋습니다.

<!-- translation-section: group-handle -->

### 그룹 핸들

그룹에는 핸들이 자동으로 지정됩니다. 핸들은 **loomio.com/your-group-handle**, **your-group-handle@loomio.com**과 같이 그룹의 URL과 이메일 주소에 사용됩니다.

그룹을 만들 때 핸들을 수정할 수 있으며, 나중에 그룹 설정에서도 변경할 수 있습니다. 핸들을 변경해도 이전 핸들을 사용하는 링크와 이메일 주소는 계속 작동합니다. Loomio는 이전 핸들을 최대 3개까지 유지하며, 그 수를 넘으면 가장 오래된 핸들이 만료됩니다.

<!-- translation-section: group-description -->

### 그룹 설명

이 짧은 설명은 대시보드 상단에 표시되어 새 멤버에게 필요한 배경 정보를 제공합니다.

**'그룹 시작'을 클릭하면 새 그룹이 자동으로 만들어집니다.**
