# Langues et traduction

Loomio permet d’utiliser plusieurs langues grâce à deux fonctionnalités :

1. Traduction de l’application - Changez la langue de l’interface, notamment celle des boutons et des textes de l’application.
2. Traduction du contenu - Traduisez les commentaires, les discussions et les propositions dans la langue de votre choix.

<!-- translation-section: application-translation -->

## Traduction de l’application

Loomio détecte automatiquement votre langue préférée lorsque vous ouvrez l’application dans votre navigateur.  Pour la changer, rendez-vous sur la page « Modifier mon profil ».

![Modification de votre langue préférée](change_language.png)

<!-- translation-section: content-translation -->

## Traduction du contenu
Si une personne de votre groupe écrit dans une autre langue que votre langue préférée, un bouton « Traduire » apparaît sous son message. Cliquez dessus pour traduire automatiquement le message dans votre langue préférée.

![Traduction du contenu](content_translation.png)

Dans la discussion, le texte traduit remplace le texte d’origine. Sélectionnez **Original** pour afficher de nouveau le texte d’origine.

![Un commentaire traduit de l’espagnol vers l’anglais](content_translated.png)

La traduction du contenu rédigé par les utilisateurs est assurée par Google Traduction. Elle est effectuée lorsqu’un utilisateur en fait la demande.

<!-- translation-section: automatic-translation -->

## Traduction automatique

Pour traduire automatiquement le contenu pris en charge, ouvrez **Modifier mon profil** et sélectionnez **Traduire automatiquement le contenu dans ma langue**. Loomio utilise la langue sélectionnée dans votre profil.

![L’option de traduction automatique du contenu sur la page Modifier mon profil](automatic_translation.png)
