# Smoother page loading

Opening a thread or poll now loads its initial content with the page, so the app can display the conversation without waiting for a separate request. A loading screen replaces the temporary static thread view that appeared before the app was ready.

Recent threads and polls on the dashboard, and unread threads in the inbox, also load with the page.

Group discussion lists now load with the page too, including the selected filter and page. Other app pages receive their startup configuration immediately, while notifications and navigation data continue to load separately.

Pages also download fewer styles at startup. Poll creation forms and task calendars load when you open them.
