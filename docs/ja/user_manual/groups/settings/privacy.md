# グループのプライバシー

プライバシー設定では、グループを見つけられる人と、その内容を読める人を決めます。グループのページで**グループ設定を編集する**を開き、**プライバシー**を選択します。

![グループのプライバシー設定](group_privacy_settings.png#width-90)

プライバシー設定を変更すると、変更後に作成する内容だけでなく、既存の内容も公開されたり非公開になったりします。グループの目的に必要な範囲で、できるだけ公開範囲の狭い設定を選びます。

<!-- translation-section: open -->

## 議論中

公開グループは誰でも見つけることができ、議論、投票、ファイルを閲覧できます。メンバー一覧を見られるのはメンバーだけです。

公開グループでは、誰でもすぐに参加できるようにするか、参加に承認を必要とするか、招待制にするかを選べます。

<!-- translation-section: follow-an-open-group -->

### 公開グループをフォローする

公開グループには、参加せずに活動をフォローできます。フォローすると、グループの未読の活動がまとめメールに追加され、都合のよいときに確認できます。フォローしただけではメンバーにはならず、メンバーとして投票する権利や即時通知も受け取りません。

グループのページで**最新情報をフォロー**をオンにすると、未読の議論、コメント、投票、その他のスレッドの活動がまとめメールに含まれます。含めない場合は、この設定をオフにします。

![公開グループの最新情報をフォロー](group_follow_updates.png)

<!-- translation-section: closed -->

## 議論終了

非公開グループは誰でも見つけられ、名前と説明を読むことができます。議論、投票、ファイル、メンバー一覧を見られるのは、メンバーと招待されたゲストだけです。

非公開グループでは、参加申請を受け付けるか、招待制にするかを選べます。承認なしですぐに参加できる設定にはできません。

非公開のサブグループでは、親グループのメンバーがサブグループに参加しなくても議論を読めるように設定できます。

<!-- translation-section: secret -->

## 秘密

秘密グループとその内容を見られるのは、招待または追加された人だけです。参加は招待制です。秘密グループは公開グループディレクトリに表示されません。

<!-- translation-section: how-people-join -->

## グループへの参加方法

利用できる参加方法はプライバシー設定によって異なります。

| グループのプライバシー | 利用できる参加方法 |
| --- | --- |
| **議論中** | 誰でも参加、承認を申請、または招待制 |
| **議論終了** | 承認を申請、または招待制 |
| **秘密** | 招待制のみ |

承認が必要な場合は、**グループに参加する**を選び、グループの参加時の質問に回答して、参加申請を送ります。質問の設定、申請の確認、直接招待する方法については、[人を招待する](/en/user_manual/groups/inviting_people#request-to-join-group)をご覧ください。

<!-- translation-section: group-directory -->

## グループディレクトリ

公開または非公開の親グループは、公開グループディレクトリに掲載して、見つけられるようにできます。ディレクトリへの掲載によって、グループの内容を読める人やメンバーになれる人は変わりません。サブグループと秘密グループは掲載できません。
