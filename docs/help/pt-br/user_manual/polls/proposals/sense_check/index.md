# Verificação de opinião

A verificação de opinião reúne reações enquanto uma ideia ainda está sendo desenvolvida. Suas opções — **Parece bom**, **Poderia ser melhor** e **Precisa ser repensado.** — mostram se o grupo está pronto para prosseguir ou se deve revisar a ideia primeiro.

Esta página explica como realizar uma verificação de opinião. Consulte o [Processo simples de decisão](/en/guides/making_decisions/simple_decision_process), o [Processo de consentimento](/en/guides/making_decisions/consent_process) ou o [Processo de consenso](/en/guides/making_decisions/consensus_process) para ver exemplos de como usar a verificação de opinião como uma etapa de um processo maior.

<!-- translation-section: when-to-use-sense-check -->

## Quando usar a verificação de opinião

Use a verificação de opinião para:

- testar um rascunho inicial antes de investir em uma proposta detalhada;
- identificar dúvidas e preocupações antes de uma decisão formal;
- verificar se é necessária outra rodada de discussão; ou
- comparar o apoio antes e depois de revisar uma ideia.

Não trate **Parece bom** como aprovação formal, a menos que o grupo tenha concordado explicitamente com isso. Use [Consentimento](../consent/) ou [Consenso](../consensus/) quando a resposta precisar autorizar uma decisão.

<!-- translation-section: example-check-a-trial-plan -->

## Exemplo: avaliar um plano de teste

A Cooperativa Oatmilk elaborou um plano de teste com garrafas retornáveis. Ela realiza uma verificação de opinião para saber se o cronograma de coleta, as verificações de lavagem e o plano de relatórios estão prontos para a revisão final.

<!-- translation-section: set-up-the-proposal -->

## Configure a proposta

Informe em que etapa a ideia está e como os comentários recebidos serão usados. Mantenha os significados padrão das respostas ou edite-os para adequá-los à linguagem do grupo. Defina um horário de encerramento que deixe tempo suficiente para revisar o plano.

![](form.png)

<!-- translation-section: vote -->

## Vote

Os participantes escolhem a resposta que melhor representa sua opinião atual e explicam o que está pronto ou o que deve mudar. Um motivo útil dá ao autor da proposta algo específico sobre o qual agir.

![](../proposal_sense_check_voting.png)

<!-- translation-section: read-the-results -->

## Leia os resultados

O gráfico mostra o número e a proporção de votos para cada resposta. Leia os motivos e observe a distribuição dos votos: uma preocupação bem fundamentada pode exigir atenção mesmo quando a maioria dos participantes seleciona **Parece bom**.

![](../proposal_sense_check_results.png)

<!-- translation-section: share-an-outcome -->

## Compartilhe uma conclusão

Quando a verificação de opinião for encerrada, compartilhe uma conclusão. Resuma as mudanças que o grupo fará ou registre que a ideia está pronta para a próxima etapa de decisão. Consulte [Compartilhe uma conclusão](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome) para saber como as conclusões funcionam.
