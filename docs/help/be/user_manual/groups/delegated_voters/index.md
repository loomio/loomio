# Выбаршчыкі-дэлегаты

Выкарыстоўвайце дэлегатаў, калі ўсе ўдзельнікі групы павінны мець агульную прастору для абмеркавання, але галасаваць павінна толькі вызначанае кола ўдзельнікаў, напрыклад кіраўніцтва або абраныя прадстаўнікі. Гэта прасцей, чым падтрымліваць асобную падгрупу толькі для таго, каб аддзяліць тых, хто мае права голасу, ад тых, хто яго не мае.

Выкарыстоўвайце прыватную падгрупу, калі гэтым удзельнікам таксама патрэбныя абмеркаванні, файлы або спіс удзельнікаў, якія іншыя ўдзельнікі не павінны бачыць.

Толькі адміністратары групы могуць прызначаць або здымаць статус дэлегата. На ўкладцы **Удзельнікі** на старонцы вашай групы адкрыйце меню дзеянняў побач з імем патрэбнай асобы і выберыце **Зрабіць дэлегатам**. Каб зняць гэты статус, выберыце **Адклікаць дэлегата** ў тым жа меню.

![Дзеянне «Зрабіць дэлегатам» у меню ўдзельнікаў](member_make_delegate.png)

Каб стварыць апытанне або прапанову, дзе могуць галасаваць толькі дэлегаты, выберыце **Толькі выбраныя людзі** ў наладах апытання.

![Налада «Толькі выбраныя людзі» пры стварэнні прапановы](poll_invited_people_only.png)

Калі выбіраеце, каго запрасіць да галасавання, выберыце **Дэлегаты групы [назва групы]**.

![Варыянт «Дэлегаты кааператыва Oatmilk» у форме запрашэння да галасавання](poll_invite_delegates_group.png)

Каб паглядзець усіх дэлегатаў групы, адкрыйце ўкладку **Удзельнікі** і выберыце **Дэлегаты** ў меню фільтра.

![Варыянт «Дэлегаты» ў фільтры ўдзельнікаў](members_list_delegates.png)
