# Mover elementos entre hilos

Mueve los elementos seleccionados cuando una conversación corresponda a otro hilo, cuando un hilo se haya dividido en temas distintos o cuando quieras combinar discusiones relacionadas. No hay un comando independiente para **Combinar discusiones**.

Esta opción está disponible para los admins del grupo y para los miembros cuando **Los miembros pueden gestionar discusiones y comentarios.** está activado en [Permisos del grupo](/en/user_manual/groups/settings/permissions).

Abre el menú de tres puntos (**⋯**) de un elemento y selecciona **Mover elemento**.

![](../using_discussions/comment_move.png)

Selecciona los elementos que quieras mover.

![](../using_discussions/comment_select.png)

Selecciona los elementos adicionales con las casillas y luego haz clic en **Mover** en la franja de la parte superior de la discusión.

![](../using_discussions/move_items.png)

Elige el grupo o subgrupo y luego busca la discusión de destino.

Para mover los elementos a una nueva discusión, selecciona **Nueva discusión** y añade el título y el contexto.

![](../using_discussions/move_items_new_thread.png)

Los elementos se trasladan del hilo original al hilo seleccionado o recién creado.

![](../using_discussions/new_thread.png)

Si ya no necesitas el hilo original, puedes [bloquearlo](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread). Elimínalo solo si tienes la certeza de que no volverás a necesitarlo.
