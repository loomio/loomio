# 스레드 사용하기

토론의 배경, 댓글, 투표, 결론은 하나의 스레드에 함께 모입니다. 이 페이지에서는 스레드에 참여하고 탐색 기능, 설정, 작업을 사용하는 방법을 설명합니다.

<!-- translation-section: thread-anatomy -->

## 스레드 구성

일반적인 스레드는 다음과 같습니다.

![](thread_navigation.png)

스레드의 주요 구성 요소는 다음과 같습니다.

- **그룹 이름** — 스레드가 속한 그룹 또는 하위 그룹으로 돌아가는 링크입니다.
- **접근 설정** — 스레드를 볼 수 있는 사람이 표시됩니다. 그룹의 공개 범위 설정에 따라 그룹 멤버와 해당 토론에 초대된 사람이 그룹 토론을 볼 수 있습니다.
- **분류 태그** — 제목 아래에 표시되며 관련 토론을 묶는 데 사용하는 라벨입니다.
- **토론 배경** — 스레드 맨 위의 첫 게시물로, 반응을 남기거나 내용을 수정하는 기능이 있습니다.
- **댓글과 투표** — 배경 아래에 게시되는 답글, 투표, 결론으로, 각 항목에서 반응 및 작업 도구를 사용할 수 있습니다.
- **오른쪽 사이드바** — 주요 항목으로 이동하는 링크(**바로 이동**), 알림 설정, **읽은 사람**과 **알림 전송됨** 목록, 스레드 작업이 있습니다.

<!-- translation-section: discussion-context -->

## 토론 배경

**배경**은 스레드 맨 위에 있으며 대화나 결정의 주제와 목적을 설명합니다.

![](thread_context.png)

토론을 시작할 때 배경을 작성하며, 연필 아이콘(**수정**)을 눌러 내용을 업데이트할 수 있습니다. 대화가 진행되면 새로운 배경 정보, 의제 또는 최종 결론을 배경에 추가할 수 있습니다.

텍스트 입력란 아래의 서식 도구 모음에서 텍스트 서식을 지정하고, 파일을 첨부하고, 이미지를 삽입하고, 동영상을 삽입할 수 있습니다. [텍스트 서식 지정 및 파일 첨부](/en/user_manual/discussions/formatting/)를 참고하세요.

![](thread_context_edit.png)

배경을 수정할 때 **무엇이 바뀌었나요?**에 변경 사항을 요약하고 알림을 받을 사람을 선택하세요.

## 탐색

오른쪽 사이드바의 **바로 이동** 영역에서 스레드 내의 원하는 위치로 이동할 수 있습니다.

- **시작**을 선택하면 토론 배경으로 이동합니다.
- **아직 안 본 내용**은 스레드에 읽지 않은 활동이 있을 때 표시됩니다.
- **최신**은 현재 불러온 항목보다 더 새로운 활동이 있을 때 표시됩니다.
- 주요 항목 링크를 선택하면 중요한 댓글, 투표, 결론으로 바로 이동합니다.
- **끝**을 선택하면 스레드의 마지막 항목으로 이동합니다.

H2 또는 H3 제목이 포함된 댓글, 투표, 제안은 주요 항목 링크에 자동으로 추가됩니다. 주요 항목을 선택하면 해당 위치로 바로 이동합니다.

![](thread_timeline_1.png)

댓글, 투표, 표 또는 결론을 게시하면 Loomio는 직접 게시한 항목을 읽음으로 표시합니다.

## 알림과 멤버

오른쪽 사이드바에서 해당 스레드의 이메일 알림을 설정하고, 누가 초대되었는지, 누가 스레드를 읽었는지, 누가 알림을 받았는지 확인할 수 있습니다.

<!-- translation-section: email-notifications-for-this-thread -->

### 이 스레드의 이메일 알림

현재 알림 설정을 선택하면 Loomio에서 모든 활동에 대한 이메일을 받을지, 직접 알림을 받는 활동에 대해서만 이메일을 받을지, 이메일을 받지 않을지 선택할 수 있습니다. 모든 활동을 선택하면 활동이 많은 스레드에서는 이메일이 많이 올 수 있습니다.

![토론 사이드바에서 알림을 받을 때 이메일 수신이 선택된 상태](../notifying_people/thread_interact.png)

<!-- translation-section: invite-people -->

### 초대

사람을 초대하거나 스레드에 대해 알리려면 오른쪽 사이드바에서 **초대**를 선택하세요. 그룹, 하위 그룹, 상위 그룹, 게스트, 채팅방에 대한 자세한 내용은 [토론에 초대하기](/en/user_manual/discussions/inviting_people)를 참고하세요.

<!-- translation-section: seen-by -->

### 읽은 사람

**읽은 사람**에는 누가 언제 스레드를 열었는지 표시됩니다. 주요 참여자가 중요한 정보를 읽었는지 확인하는 데 사용하세요.

![스레드 멤버 영역의 읽은 사람과 알림 전송됨](../notifying_people/thread_engagement.png)

![스레드 멤버를 나열하는 읽은 사람 창](../notifying_people/thread_seenby.png)

<!-- translation-section: notified -->

### 알림 전송됨

**알림 전송됨**을 선택하면 초대, 멘션, 답글이 포함된 스레드 알림 내역이 열립니다. 누가 알림을 받았는지 표시되며, 확인할 수 있는 경우 각 알림을 읽었는지도 표시됩니다.

![토론 알림 내역](../notifying_people/thread_notified.png)

## 스레드 설정

스레드 관리자와 그룹 관리자는 **스레드 설정**을 선택해 답글 배치 방식을 변경하고 다른 토론 설정을 조정할 수 있습니다.

![](thread_display.png)

![배치 방식, 투표 제한, 첨부 권한, 댓글 길이 제한이 있는 스레드 설정](thread_layout_options.png)

### 배치 방식

**시간순**을 선택하면 항목이 게시된 순서대로 나열되고, **계층형**을 선택하면 답글이 해당 원문 아래에 모입니다. 이 설정을 변경하면 스레드에 참여하는 모든 사람에게 적용됩니다.

<a id="allow-multiple-polls-at-the-same-time"></a>

### 한 번에 하나의 투표만 진행

이 항목을 선택하면 현재 투표가 마감될 때까지 누구도 다른 투표를 시작할 수 없습니다. 새 스레드에서는 기본적으로 선택되어 있지 않습니다. 토론 템플릿에서 시작한 스레드는 해당 템플릿의 설정을 이어받습니다.

### 관리자만 첨부 가능

이 설정을 켜면 투표 응답과 이메일 답글을 포함한 스레드 전체에서 스레드 관리자와 그룹 관리자만 새 파일과 본문 내 이미지를 추가할 수 있습니다. 기존 첨부 파일은 계속 이용할 수 있으며, 참여자는 자신의 텍스트를 수정하거나 첨부 파일을 삭제할 수 있습니다.

토론 및 투표 템플릿에서 새 스레드에 이 설정을 적용할 수 있습니다. [토론 템플릿](/en/user_manual/discussions/templates)과 [투표 템플릿](/en/user_manual/polls/poll_templates)을 참고하세요.

### 댓글 길이 제한

답글을 간결하게 유지하려면 댓글당 최대 글자 수를 설정하세요. 제한하지 않으려면 비워 두세요. 이 제한은 그룹 관리자와 스레드 관리자를 포함한 모든 사람에게 적용됩니다.

## 작업

오른쪽 사이드바에는 스레드 전체에 적용되는 작업이 있습니다. 일부 작업은 그룹 페이지의 스레드 옆에 있는 점 세 개 메뉴(**⋯**)에도 표시됩니다.

표시되는 작업은 권한에 따라 다릅니다. 그룹 관리자는 스레드를 관리할 수 있으며, 그룹 설정에 따라 멤버도 일부 관리 작업을 수행할 수 있습니다. [그룹 권한](/en/user_manual/groups/settings/permissions)을 참고하세요.

![](thread_admin.png)

### 인쇄

**인쇄**를 선택하면 인쇄에 적합한 스레드 화면이 열립니다. 브라우저의 인쇄 대화상자에서 PDF로 저장하세요.

![](thread_print_thread.png)

<!-- translation-section: markdown -->

### Markdown

**Markdown**을 선택하면 스레드를 구조화된 Markdown으로 내보낼 수 있습니다. **마크다운 복사**를 선택하면 클립보드에 복사하고, **Markdown 다운로드**를 선택하면 회의록, 기록 보관, 문서 또는 AI 도구에 사용할 `.md` 파일로 저장합니다.

![](../discussion_management/copy_markdown_menu.png)

내보낸 문서는 스레드 키, URL, 그룹, 날짜, 태그가 포함된 YAML 머리말로 시작합니다. 이어서 토론 배경과 모든 댓글, 투표, 개별 표, 결론이 스레드의 순서와 계층 구조에 따라 포함됩니다. 각 투표는 하나의 섹션으로 표시되며, 댓글, 개별 표, 결론은 작성자, 작성 시각, 항목 번호, 반응이 표시된 인용문으로 나타납니다.

Loomio는 스레드의 공개 범위 규칙을 따릅니다. 숨겨진 결과와 투표 이유는 포함되지 않으며, 익명 투표에서는 투표자의 익명이 유지됩니다. 진행 중인 투표에서 투표하기 전까지 결과를 숨기는 경우, 먼저 투표하세요. 투표하기 전에는 **Markdown**과 **인쇄**를 사용할 수 없습니다.

예를 들어 댓글, 반응, 제안, 두 개의 표, 답글, 결론이 포함된 토론은 다음과 같은 Markdown으로 내보내집니다.

### 스레드 고정 또는 고정 해제

고정된 스레드는 그룹 페이지 상단에 유지됩니다. 그룹에서는 환영 토론, 소식, 공지를 고정하는 경우가 많습니다.

그룹 페이지에서 스레드 옆의 점 세 개 메뉴(**⋯**)를 열고 **스레드 고정**을 선택하세요. 고정된 스레드는 고정한 시각에 따라 정렬됩니다. 순서를 바꾸려면 고정을 해제한 후 다시 고정하세요.

**스레드 고정 해제**를 선택하면 스레드가 일반적인 활동 순서로 돌아갑니다.

![](../discussion_management/pin_thread.png)

<!-- translation-section: move-a-thread -->

### 스레드 이동

**스레드 이동**을 선택하면 스레드를 다른 그룹이나 하위 그룹으로 이동하거나 다이렉트 스레드로 전환할 수 있습니다. 대상 그룹의 멤버와 해당 스레드에 초대된 사람이 스레드를 볼 수 있습니다.

이동하기 전에 Loomio는 접근 권한을 잃게 되는 사람의 수를 표시합니다. 알림을 보내지 않고 이 사람들을 게스트로 유지하도록 선택할 수 있습니다.

- **다른 그룹이나 하위 그룹으로 이동:** 사람들을 게스트로 유지하려면 대상 그룹에서 게스트를 초대할 권한이 필요합니다. 기존 게스트의 접근 권한은 유지됩니다.
- **다이렉트 스레드로 전환:** 이미 참여한 사람의 접근 권한은 자동으로 유지됩니다. 게스트 유지 선택지를 선택하면 현재 다른 멤버와 게스트의 접근 권한도 유지됩니다. 이동하는 사람과 스레드 작성자는 스레드 관리자가 됩니다.

![](../discussion_management/move_thread_select.png)

>[!Tip]
>다이렉트 토론이나 비공개 하위 그룹에서 초안을 시작하고, 준비가 되면 그룹으로 이동하세요.

전체 스레드 대신 특정 항목을 이동하려면 [스레드 간 항목 이동](/en/user_manual/discussions/moving_items/)을 참고하세요.

### 스레드 잠금 또는 잠금 해제

스레드를 현재 상태로 보관하려면 잠그세요. 잠긴 스레드에서는 누구도 내용을 게시하거나 수정하거나 사람을 초대할 수 없습니다. 스레드를 잠그려면 진행 중인 투표가 모두 마감되어야 합니다.

**작업**에서 **스레드 잠금**을 선택하세요. 잠긴 스레드는 진행 중인 토론 목록에서 제외되고 **잠김** 태그가 표시됩니다.

잠긴 스레드를 찾으려면 그룹 페이지에서 토론 필터를 열고 **잠김**을 선택하세요. 댓글 작성과 변경을 다시 허용하려면 스레드를 열고 **스레드 잠금 해제**를 선택하세요.

### 스레드 삭제

스레드를 삭제하면 영구적으로 제거되며 되돌릴 수 없습니다. 나중에 필요할 수 있다면 스레드를 잠그세요.

**스레드 삭제**를 선택하고 삭제를 확인하세요.
