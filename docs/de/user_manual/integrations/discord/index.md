# Discord-Integration

_Verbinde die Benachrichtigungen deiner Loomio-Gruppe mit eurem Discord-Chat._

Loomio kann Benachrichtigungen an deine Discord-Kanäle senden, wenn neue Diskussionen, Vorschläge, Kommentare, Stimmen oder Fazits hinzukommen. Du kannst den Chat auch selbst benachrichtigen, um an eine Entscheidung zu erinnern.

---

Öffne deinen Discord-Server und suche das Menü für die Servereinstellungen.
![](server-settings.png)

Klicke auf „Integrationen“.
![](integrations.png)

Klicke dann auf „Webhook hinzufügen“ und gib ihm einen Namen, zum Beispiel „Loomio-Bot“.

![](add-webhook.png)

Kopiere die Webhook-URL in die Zwischenablage und folge dem Link unten.

[Chat-Integration in Loomio einrichten](../chatbots/#set-up-a-chat-integration)
