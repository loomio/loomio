# Membres délégués au vote

Si certains membres de votre groupe doivent pouvoir voter et d’autres non, utilisez l’action « Faire déléguer » pour désigner les personnes qui ont le droit de vote. L’action « Révoquer le délégué » permet de retirer ce droit.

Utilisez les délégués lorsque tout le monde doit partager le même espace de discussion, mais que seules certaines personnes, comme les membres d’un conseil d’administration ou les personnes élues, peuvent voter. C’est généralement plus simple que de créer un second sous-groupe uniquement pour distinguer les personnes qui peuvent voter des autres.

Utilisez plutôt un sous-groupe privé si ses membres doivent aussi accéder à des discussions, des fichiers ou des informations sur les membres que les autres ne doivent pas voir.

![Action Faire déléguer dans le menu d’un membre](member_make_delegate.png)

Pour créer un sondage ou une proposition et n’inviter que les délégués, choisissez le paramètre « Personnes sélectionnées uniquement ».
![Paramètre Personnes sélectionnées uniquement lors de la création d’une proposition](poll_invited_people_only.png)
Lorsque vous inviterez des personnes à voter, l’option « Délégués de nom-du-groupe » apparaîtra.
![Option Délégués de Oatmilk Cooperative dans le formulaire d’invitation au vote](poll_invite_delegates_group.png)

Pour voir la liste des délégués, ouvrez l’onglet des membres sur la page de votre groupe. Dans le menu des filtres, choisissez « Délégués ».
![Option Délégués dans le filtre des membres](members_list_delegates.png)
