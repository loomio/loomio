# Кворум

Кворум — это минимальный процент голосующих, имеющих право голоса, которые должны принять участие, чтобы опрос считался действительным. Используйте кворум, когда ваш процесс принятия решений требует определённого уровня участия.

При создании опроса откройте **Дополнительные настройки** и укажите необходимый процент в поле **Кворум участия**. Оставьте поле пустым, если кворум не требуется.

![Настройка кворума с кворумом участия 60 процентов](./quorum-section.png)

Вы также можете задать кворум в [шаблоне опроса](/en/user_manual/polls/poll_templates/), чтобы он использовался по умолчанию в опросах, созданных на основе этого шаблона.

## Пример сценария

Кооператив Oatmilk обсуждает пробное использование возвратных бутылок в течение шести недель. Обсуждение дошло до этапа, на котором кооперативу необходимо утвердить бюджет испытания.

Джейми выбирает **Начать голосование**, затем шаблон предложения **Согласие** и заполняет название, описание, варианты, длительность и настройки голосующих.

![Название, описание, варианты, длительность и настройки голосующих в предложении](proposal-options.png)

Джейми разрешает голосовать только пяти людям, ответственным за бюджет испытания.

Для значимых решений кооператив требует участия 60 процентов голосующих, поэтому Джейми вводит **60** в поле кворума участия и запускает предложение.

Пока никто не проголосовал, панель результатов показывает, что кворум не достигнут.

![Ни одного голоса, кворум в 60 процентов ещё не достигнут](pie-chart-0.png)

Джейми выбирает «Согласен», а Самира — «Не согласен». Диаграмма обновляется, но участие двух из пяти людей, имеющих право голосовать, составляет лишь 40 процентов, поэтому кворум ещё не достигнут.

![Поданы два голоса из пяти, кворум ещё не достигнут](pie-chart-40.png)

Затем Алекс выбирает «Согласен». Трое из пяти людей, имеющих право голосовать, приняли участие, и кворум в 60 процентов достигнут. Теперь выполнение требования отмечено зелёной галочкой. Джейми может закрыть опрос досрочно или дождаться остальных голосующих.

![Поданы три голоса из пяти, кворум в 60 процентов достигнут](pie-chart-60.png)
