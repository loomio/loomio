# Інтэграцыі

Злучыце Loomio з іншымі інструментамі, якімі карыстаецца ваша група.

<!-- translation-section: choose-where-work-belongs -->

## Выберыце інструмент для кожнай задачы

Loomio дапаўняе чаты, супольныя дакументы і інструменты кіравання задачамі. Розныя віды працы зручна весці ў розных інструментах.

| Праца | Рэкамендаваны інструмент |
|---|---|
| Кароткія пытанні, нефармальныя размовы і тэрміновыя навіны | Чат |
| Сумеснае рэдагаванне дакумента, які пастаянна абнаўляецца | Супольны дакумент |
| Размеркаванне задач і адсочванне іх выканання | Інструмент кіравання праектамі або задачамі |
| Абмеркаванне важных тэм, шырокі ўдзел, прыняцце рашэнняў і высновы | Loomio |

Выкарыстоўвайце Loomio, калі людзям патрэбны час на разгляд тэмы, калі ўсе, каго яна закранае, павінны мець магчымасць паўдзельнічаць або калі групе пазней спатрэбіцца знайсці абмеркаванне і рашэнне. Дадайце ў абмеркаванне Loomio спасылку на адпаведны дакумент або задачу, каб іх было лёгка знайсці.
