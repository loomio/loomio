# Hilos directos

Un hilo directo es una discusión privada para un conjunto específico de personas.

Un hilo directo no pertenece a ningún grupo. Las personas invitadas no necesitan ser miembros de tu grupo de Loomio.

Controlas quién puede ver el hilo y participar añadiendo personas o direcciones de correo electrónico al campo **Invitar**.

Los hilos directos permiten usar los mismos comentarios, encuestas y otras herramientas que las discusiones de grupo. Pueden ser útiles cuando no es necesario crear un subgrupo.

![Un formulario de hilo directo sin ningún grupo seleccionado y con Samira Patel en el campo Invitar](direct-discussion-example.png)

Selecciona **Hilos directos** en la barra lateral para ver tus hilos directos y encuestas. Abre el menú **Nuevo** y elige **Nueva discusión** para iniciar una discusión, o **Nuevo sondeo** para iniciar una encuesta sin un grupo.

Una encuesta directa es privada para las personas que invites. Después de crearla, usa [**Gestionar a los votantes**](/en/user_manual/polls/manage_voters) para invitar a personas o direcciones de correo electrónico.

![La opción Hilos directos en la barra lateral y la lista de hilos directos](direct-discussion-sidebar.png)

## Contactar con alguien mediante una discusión directa
Puedes usar una discusión directa para contactar con una o más personas en privado sin crear un subgrupo.
