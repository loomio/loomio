# Microsoft Teams-integráció
_Kapcsold össze a Loomio-csoportod értesítéseit a Microsoft Teamsszel._

A Loomio értesítéseket küldhet a Microsoft Teamsbe az új beszélgetésekről, javaslatokról, hozzászólásokról, szavazatokról és következtetésekről.

---

Nyisd meg a [https://teams.microsoft.com](https://teams.microsoft.com) oldalt, majd kattints az Alkalmazások elemre.
![](t1.png)

Keress rá a „webhook” szóra a keresőmezőben, majd kattints a Bejövő webhook elemre.
![](t2.png)

Kattints a „Hozzáadás csapathoz” elemre.
![](t3.png)

Írd be és válaszd ki azt a csatornát, ahol látni szeretnéd a Loomio értesítéseit.
![](t4.png)

Adj neki nevet, például „Loomio értesítések”, majd kattints a „Létrehozás” elemre.
![](t5.png)

Másold ki a kapott URL-t. Az utolsó lépésben beilleszted a Loomióba.
![](t6.png)

_A Loomiót nem a Microsoft készíti, és a Microsoft nem áll kapcsolatban vele, illetve nem támogatja._

Most, hogy megvan a webhook URL-je, folytasd a csevegőintegráció beállítását:

[Csevegőintegráció beállítása a Loomióban](../chatbots/#set-up-a-chat-integration)
