# Require vote reasons when disagreeing

Proposal authors can now require a vote reason when someone selects an option marked Disagree or Block, while leaving reasons optional for Agree and Abstain.

Choose **Required when disagreeing** under **Vote reason** when starting or editing a poll. The setting follows the option's voting icon, so it continues to work when an option is renamed, such as changing Disagree to Objection.

Loomio's built-in templates that include disagreement options now use this setting by default. Coordinators can change it to Required, Optional, or Disabled for an individual poll or template.
