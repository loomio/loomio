# Eleitores delegados

Use delegados quando todos em um grupo devem compartilhar o mesmo espaço de discussão, mas apenas um conjunto definido de membros — como diretores ou representantes eleitos — deve votar. Isso é mais simples do que manter um subgrupo separado apenas para separar eleitores de pessoas sem direito a voto.

Use um subgrupo privado quando esses membros também precisarem de discussões, arquivos ou uma lista de membros que os demais membros não devem ver.

Somente um admin do grupo pode atribuir ou remover a condição de delegado. Na aba **Membros** da página do seu grupo, abra o menu de ações ao lado do nome de uma pessoa e selecione **Fazer delegado**. Selecione **Revogar delegado** no mesmo menu para remover a designação.

![Ação Fazer delegado no menu de um membro](member_make_delegate.png)

Para criar uma enquete ou proposta em que apenas delegados possam votar, selecione **Apenas para pessoas selecionadas** nas configurações da enquete.

![Configuração Apenas para pessoas selecionadas ao iniciar uma proposta](poll_invited_people_only.png)

Ao escolher quem convidar para votar, selecione **Delegados de [nome do grupo]**.

![Opção Delegados de Oatmilk Cooperative no formulário de convite para votar](poll_invite_delegates_group.png)

Para ver todos os delegados de um grupo, abra a aba **Membros** e selecione **Delegados** no menu de filtros.

![Opção Delegados no filtro de membros](members_list_delegates.png)
