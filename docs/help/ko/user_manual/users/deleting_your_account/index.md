# Loomio 계정 삭제

<!-- translation-section: what-does-delete-account-mean -->

## 계정을 삭제하면 어떻게 되나요?

계정을 삭제하면 다음과 같이 처리됩니다.
- 이름, 이메일 주소 및 기타 개인 식별 데이터를 포함한 사용자 계정이 Loomio 시스템에서 삭제됩니다. 이 계정으로는 Loomio에 로그인할 수 없게 됩니다.
- 작성한 댓글, 제안, 토론은 그대로 남지만 이름은 삭제됩니다. 그룹의 스레드와 제안의 맥락을 유지할 의무가 있기 때문입니다.
- 모든 그룹의 멤버 목록에서 제외됩니다.
- 더 이상 알림 이메일을 받지 않습니다.

Loomio에서 생성한 데이터의 사본이 이미 그룹의 모든 멤버에게 이메일로 전송되었을 수 있으며, Loomio는 이러한 사본을 삭제할 수 없다는 점을 알아 두세요.

계정을 삭제해도 구독은 취소되지 _않습니다_. 결제를 중단하려면 [구독](/en/policy/subscriptions/management#cancel-your-plan)을 참고하세요.

Loomio는 사용자의 권리를 보호하기 위해 소유 구조, 사업 모델, 소프트웨어에 관한 근본적인 결정을 내렸습니다. Loomio는 노동자가 소유한 독립적인 협동조합이며, 소프트웨어는 오픈 소스입니다. [데이터를 내보낼 수 있으며](/en/user_manual/groups/data_export), Loomio는 데이터를 판매하거나 광고에 사용하지 않습니다. 이러한 약속은 [개인정보 처리방침](/en/policy/privacy)에 명시되어 있으며, [정관](https://www.loomio.coop/constitution.html)과 [협동조합 안내서](https://www.loomio.coop/purpose_and_vision.html)에 담긴 목적과 가치에 기반합니다. 궁금한 점이 있으면 [문의하세요](/contact).

## 계정을 완전히 삭제하는 방법

Loomio에 로그인하세요. 화면 왼쪽 상단의 메뉴 아이콘(☰)을 눌러 사이드바를 여세요. 화면 오른쪽 상단의 계정 아바타 또는 이니셜을 클릭하세요.

이름 옆의 아래쪽 화살표( ∨ )를 클릭하여 사용자 설정을 여세요. **프로필 수정**을 선택하세요.

![](profile_edit.png#width-50)

맨 아래로 스크롤한 다음 **계정 삭제**를 클릭하세요.

![](delete_user.png)

계정을 삭제할지 확인하는 팝업이 나타납니다.

![](permanently_delete_account.png#width-80)
