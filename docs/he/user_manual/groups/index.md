# מבוא לקבוצות

קבוצה בלומיו היא מרחב בטוח שבו אנשים יכולים להיפגש, לקיים דיונים ולקבל החלטות.

זהו מקום שבו חברי הקבוצה יכולים למצוא מידע ולשתף אותו, ולהשתתף בדיונים ובהחלטות חשובות המשפיעים על עבודתם.

כך נראה דף קבוצה בלומיו. בראש הדף מופיעים תמונה ולוגו שניתן להתאים כדי לייצג את הארגון. כך אנשים שמגיעים לקבוצה יכולים לזהות את המקום שאליו הצטרפו ולהרגיש בו רצויים. זהו מרחב בטוח שבו אפשר להרגיש בנוח, בחברת אנשים מוכרים, ולהשתתף ביעילות.

![דף הקבוצה של קואופרטיב חלב שיבולת השועל, עם תיאור הקבוצה ורשימת הדיונים](group_page.png)

יש לבחור שם שמייצג את הקבוצה ולהשתמש בתיאור הקבוצה כדי להסביר:
- **למה** הקבוצה משמשת,
- **מדוע** היא חשובה,
- **מי** משתתף בה, וגם
- **כיצד** חברי הקבוצה יכולים להשתתף.

ניתן לכלול גם מידע כגון קוד התנהגות, הגדרת תחומי אחריות או מסמכים אחרים המסדירים את פעילות הקבוצה.

בעת הכנת קבוצה חדשה, כדאי לעיין ב[הצגת לומיו לקבוצה](/en/user_manual/overview/introducing_loomio). המדריך מציג רצף צעדים מעשי, מבחירת המשימה הראשונה ועד לתיעוד מסקנה.

## ניהול, הנחיה ומיתון דיונים - קוד התנהגות

לומיו נבנתה כדי לעודד השתתפות של כולם, גיוון ואמון, ולעזור לקבוצות לקבל יחד החלטות טובות יותר.

נושאים מסוימים עלולים ליצור מתח בקבוצה. חשוב לאפשר דיון מעמיק, ובה בעת לשמור על מרחב בטוח, במיוחד עבור אנשים פגיעים בקבוצה.

מומלץ לקבוע קוד התנהגות לקבוצה. כך כולם יוכלו להבין את אחריותם להתנהגות הולמת ולווסת את התנהגותם בעצמם.

למידע נוסף על חשיבותו של קוד התנהגות, כדאי לעיין ב[מדריך להנחיית קבוצות](/en/guides/facilitators_guide/commencing#culture-protocol-expectations).
