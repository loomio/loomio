# Делегаты с правом голоса

Если одни участники вашей группы должны иметь право голоса, а другие — нет, используйте функцию «Сделать делегатом», чтобы обозначить участников с правом голоса. Также доступно действие «Отозвать делегата».

Назначайте делегатов, когда люди должны обсуждать вопросы в общем пространстве, но голосовать может только определённый круг людей, например директора или избранные представители. Обычно это проще, чем поддерживать отдельную подгруппу только для того, чтобы отделить голосующих от остальных участников.

Используйте закрытую подгруппу, если её участникам также нужны обсуждения, файлы или сведения об участниках, которые не должны видеть другие участники группы.

На странице группы откройте **Участники**, найдите нужного человека и выберите **Сделать делегатом** в меню с тремя точками рядом с его именем. Чтобы снять статус делегата, выберите **Отозвать делегата** в том же меню.

![Действие «Сделать делегатом» в меню участника](member_make_delegate.png)

Чтобы создать опрос или предложение и пригласить только делегатов, выберите настройку опроса «Только выбранные люди».
![Настройка «Только выбранные люди» при создании предложения](poll_invited_people_only.png)
Затем при приглашении людей голосовать вы увидите вариант «Делегаты группы „название группы“».
![Вариант «Делегаты Oatmilk Cooperative» в форме приглашения голосовать](poll_invite_delegates_group.png)

Список делегатов можно посмотреть на вкладке участников на странице вашей группы. Откройте меню фильтра и выберите «Делегаты».
![Вариант «Делегаты» в фильтре списка участников](members_list_delegates.png)
