# Прямі обговорення

Пряме обговорення — це приватне обговорення для визначеного кола людей.

Пряме обговорення не належить до групи. Запрошеним людям не обов’язково бути учасниками вашої групи в Loomio.

Ви визначаєте, хто може переглядати обговорення та брати в ньому участь, додаючи людей або адреси електронної пошти до поля **Запросити**.

Прямі обговорення підтримують ті самі коментарі, опитування та інші інструменти, що й обговорення в групах. Вони можуть бути корисними, коли створювати підгрупу немає потреби.

![Форма прямого обговорення без вибраної групи та із Самірою Патель у полі «Запросити»](direct-discussion-example.png)

Виберіть **Прямі теми** на бічній панелі, щоб переглянути ваші прямі обговорення. Виберіть **Нове обговорення** на цій сторінці, щоб розпочати ще одне.

![Пункт «Прямі теми» на бічній панелі та список прямих обговорень](direct-discussion-sidebar.png)

## Як зв’язатися з людиною через пряме обговорення
Пряме обговорення можна використовувати, щоб приватно зв’язатися з однією або кількома людьми без створення підгрупи.
