# Grupos

Um grupo no Loomio é um espaço compartilhado onde os membros participam de discussões, compartilham informações e tomam decisões em conjunto.

![A página do grupo Oatmilk Cooperative, com sua descrição e lista de discussões](group_page.png)

Você pode personalizar a página do seu grupo com um nome, uma descrição, um logotipo, uma imagem de capa e links para documentos, como os termos de referência do grupo. Isso ajuda os membros a entender o propósito do grupo e como participar.

Para começar, [crie um grupo](/en/user_manual/groups/starting_a_group), escolha suas [configurações de privacidade](/en/user_manual/groups/settings/privacy) e [convide pessoas](/en/user_manual/groups/inviting_people).

Se você está preparando um novo grupo, consulte [Apresentando o Loomio ao seu grupo](/en/user_manual/overview/introducing_loomio) para seguir uma sequência prática, desde a escolha do primeiro trabalho até o registro de uma conclusão.

## Código de conduta

Um código de conduta ajuda os membros a entender como participar e como o grupo responde a comportamentos inadequados. Consulte o [Guia de facilitação](/guides/facilitators-guide/commencing/#culture-protocol-expectations) para obter orientações sobre como estabelecer expectativas.
