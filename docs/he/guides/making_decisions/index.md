# קבלת החלטות

המדריכים האלה מסבירים תהליכי קבלת החלטות מתחילתם ועד סופם: איך להגדיר את ההחלטה, לשתף את האנשים המתאימים, לקיים דיון ולהשתמש בהצעות, להתייחס לחששות ולתעד מסקנה.

המדריכים האלה שונים מהעמודים על תבניות להצעות. [תבנית להצעה](/en/user_manual/polls/proposals/) מסבירה הצעה אחת ואת אפשרויות התגובה עליה. תהליך קבלת החלטות יכול לכלול כמה הצעות לאורך זמן.

## בחירת תהליך

| תהליך | מי מקבל את ההחלטה? | השאלה המרכזית |
|---|---|---|
| [תהליך החלטה פשוט](simple_decision_process) | לפי הגדרת הקבוצה | איך לדון, לבחון ולקבל החלטה? |
| [תהליך היוועצות](advice_process) | אדם אחד או צוות שקיבל סמכות | אילו עצות יש להביא בחשבון בעת קבלת ההחלטה? |
| [תהליך הסכמה ללא התנגדות](consent_process) | הקבוצה | האם אפשר לנסות את ההצעה ללא התנגדות מהותית? |
| [תהליך קונצנזוס](consensus_process) | הקבוצה | האם אפשר להגיע להסכמה משותפת? |

יש להשתמש בתהליך שנקבע בכללי הניהול של הקבוצה או במדיניות קבלת ההחלטות שלה. סוגים שונים של החלטות עשויים לדרוש תהליכים שונים.

אם צריך רק לבחור את סוג התגובות, ניתן להשוות בין [הצעות](/en/user_manual/polls/proposals/) לבין [משאלים](/en/user_manual/polls/proposal_types/). למידע על ניהול האפשרויות לשימוש חוזר שמופיעות בעת בחירת **התחל הצבעה**, ראו [תבניות למשאלים](/en/user_manual/polls/poll_templates/).
