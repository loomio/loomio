# Slack-Integration
_Verbinde die Benachrichtigungen deiner Loomio-Gruppe mit Slack._

Loomio kann Benachrichtigungen an deine Slack-Kanäle senden, wenn es neue Diskussionen, Vorschläge, Kommentare, Stimmen und Fazits gibt. So erhältst du wichtige Neuigkeiten zu Diskussionen und Entscheidungen zur richtigen Zeit.

---

Rufe zuerst [https://api.slack.com](https://api.slack.com) auf, melde dich bei Bedarf an und klicke auf Create New App
