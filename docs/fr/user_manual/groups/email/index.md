# Envoyer un e-mail pour lancer une discussion dans votre groupe

Votre groupe Loomio possède une adresse e-mail. Vous pouvez envoyer ou transférer un e-mail à cette adresse pour lancer une discussion dans le groupe.

L’adresse e-mail de votre groupe figure sur la page du groupe :
![Emplacement de l’adresse e-mail sur la page du groupe](email_email_button.png)

Lorsque vous envoyez un e-mail à cette adresse, une nouvelle discussion est créée. L’objet de l’e-mail devient le titre de la discussion, son contenu devient la description et les fichiers joints sont ajoutés à la discussion.

L’adresse indiquée dans le champ « De » permet d’identifier le membre du groupe qui sera l’auteur de la discussion.

<!-- translation-section: preventing-unauthorized-emails -->

## Empêcher les e-mails non autorisés

Pour empêcher les personnes extérieures à votre groupe d’utiliser cette fonction, Loomio exige que l’adresse indiquée dans le champ « De » corresponde à celle d’un membre du groupe.

Si vous utilisez plusieurs adresses e-mail, vous pouvez ajouter un alias pour que Loomio reconnaisse vos autres adresses.

Si l’adresse indiquée dans le champ « De » ne correspond à aucun membre du groupe, vous recevrez une notification vous invitant à ajouter un alias ou à refuser tous les futurs e-mails provenant de cette adresse.

La première fois que vous envoyez un e-mail depuis une adresse non reconnue, vous devez donc ajouter un alias. Les e-mails suivants seront alors acceptés immédiatement.
