# Matrix-integraatio

Loomio voi lähettää Matrix-kanaviisi ilmoituksia uusista keskusteluista, ehdotuksista, kommenteista, äänistä ja kyselyiden yhteenvedoista.

Matrixin keskusteluhuoneissa voi käyttää HTML-muotoilua, jota Loomio hyödyntää ilmoituksissa.

Matrix-integraatio toimii eri tavalla kuin muut keskustelupalvelujen integraatiomme. Se ei käytä webhookia, vaan sitä varten on rakennettu oma bottiohjelma.

Luo botille Matrix-käyttäjätili, jolla se voi kirjautua sisään.

Kun olet luonut botin käyttäjätilin, kirjaudu sisään sillä saadaksesi seuraavat tiedot.

Tässä ohjeessa käytetään Elementiä.
