# Integrazione con Slack
_Collega le notifiche del tuo gruppo Loomio a Slack._

Loomio può inviare notifiche ai tuoi canali Slack quando vengono create discussioni e proposte o vengono pubblicati commenti, voti e conclusioni. Ricevi gli aggiornamenti importanti al momento giusto sulle discussioni e sulle decisioni che contano.

---
