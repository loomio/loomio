# Інтэграцыя з Microsoft Teams

Loomio можа адпраўляць апавяшчэнні ў вашы каналы Microsoft Teams, калі з’яўляюцца новыя абмеркаванні, апытанні, каментарыі, галасы і высновы.

---

1. Адкрыйце [Microsoft Teams](https://teams.microsoft.com) і націсніце **Праграмы**.

   ![](t1.png)

2. Увядзіце ў пошуку `webhook` і націсніце **Уваходны вэбхук**.

   ![](t2.png)

3. Націсніце **Дадаць у каманду**.

   ![](t3.png)

4. Абярыце канал, у якім вы хочаце бачыць апавяшчэнні Loomio.

   ![](t4.png)

5. Увядзіце назву, напрыклад `Loomio notifications`, і націсніце **Стварыць**.

   ![](t5.png)

6. Скапіруйце URL вэбхука, каб уставіць яго ў Loomio.

   ![](t6.png)

Цяпер, калі ў вас ёсць URL вэбхука, завяршыце падключэнне ў Loomio:

[Наладзьце інтэграцыю з чатам у Loomio](../chatbots/#set-up-a-chat-integration)

_Microsoft не стварала Loomio, не мае з ім арганізацыйнай сувязі і не аказвае яму падтрымкі._
