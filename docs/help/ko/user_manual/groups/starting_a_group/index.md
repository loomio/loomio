# 새 그룹 시작하기

Loomio를 처음 사용한다면 [Loomio 웹사이트](https://www.loomio.com/)에서 무료 체험으로 그룹을 시작할 수 있습니다. 무료 체험 중 세 명이 제안이나 투표에 참여하면 그룹의 체험 기간이 30일 연장되고 하위 그룹과 게스트 기능이 활성화됩니다. 이미 Loomio를 사용하고 있으며 다른 그룹을 시작하려면 사이드바에서 **새 그룹**을 선택하세요. 사이드바가 닫혀 있으면 페이지 상단의 그룹 전환 메뉴에서 선택하세요.

대부분의 조직에서는 상위 그룹 하나만 있으면 되며, 그 안에 필요한 만큼 [하위 그룹](/en/user_manual/groups/subgroups)을 만들 수 있습니다.

### 그룹 핸들

Loomio는 그룹 이름을 바탕으로 핸들을 자동으로 지정합니다. 핸들은 `loomio.com/your-group-handle`, `your-group-handle@loomio.com`과 같이 그룹의 URL과 이메일 주소에 사용됩니다.

설정 과정에서 핸들을 수정하거나 나중에 그룹 설정에서 변경할 수 있습니다. 핸들을 변경해도 이전 핸들을 사용하는 링크와 이메일 주소는 계속 작동합니다. Loomio는 이전 핸들을 최대 3개까지 유지하며, 그 수를 넘으면 가장 오래된 핸들이 만료됩니다.

<!-- translation-section: group-description -->

### 그룹 설명

그룹 페이지 상단에 표시되어 새 멤버에게 배경 정보를 제공할 짧은 설명을 추가하세요.

[공개 범위 설정](/en/user_manual/groups/settings/privacy)을 선택하고 **그룹 만들기**를 선택하여 그룹을 만드세요. 자동으로 첫 번째 그룹 관리자가 되며, 나중에 그룹 설정에서 이 정보들을 수정할 수 있습니다.
