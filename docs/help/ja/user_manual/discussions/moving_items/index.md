# スレッド間でアイテムを移動する

会話を別のスレッドに移す場合、1つのディスカッションの話題が複数に分かれた場合、関連するスレッドをまとめる場合に、コメントやアンケートを移動できます。

グループの管理者はアイテムを移動できます。[グループの権限](/en/user_manual/groups/settings/permissions)で**メンバーはディスカッションやコメントを管理できる**が有効になっている場合は、メンバーもアイテムを移動できます。

1. アイテムの三点メニュー（**⋯**）を開き、**アイテムの移動**を選択します。

![](../using_discussions/comment_move.png)

2. チェックボックスで移動するアイテムを選択し、スレッド上部のバナーにある**動く**を選択します。

![](../using_discussions/comment_select.png)

![](../using_discussions/move_items.png)

3. 移動先のグループまたはサブグループを選択し、既存のディスカッションを検索します。新しいディスカッションを作成する場合は、**新しい議論**を選択し、タイトルと背景説明を入力して、**ディスカッションを始める**を選択します。

![](../using_discussions/move_items_new_thread.png)

選択したアイテムは、元のスレッドから移動先のスレッドに移動されます。

![](../using_discussions/new_thread.png)

元のスレッドが不要になった場合は、[ロックできます](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread)。今後も必要にならないと確信できる場合にのみ削除してください。
