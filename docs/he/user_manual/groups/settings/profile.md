# פרופיל הקבוצה

בלשונית הפרופיל ניתן לקבוע כיצד הקבוצה מזוהה ומוצגת. בדף הקבוצה יש לפתוח את **ערוך הגדרות קבוצה** ולבחור ב**פרופיל**.

![הגדרות פרופיל הקבוצה](group_profile.png)

<!-- translation-section: name-and-handle -->

## שם ומזהה קבוצה

יש לבחור שם קצר לקבוצה, במיוחד אם יהיו בה תתי־קבוצות. Loomio משתמשת במזהה הקבוצה בכתובת האינטרנט ובכתובת הדוא״ל שלה, למשל `loomio.com/your-group-handle` ו־`your-group-handle@loomio.com`.

לאחר שינוי מזהה הקבוצה, קישורים עם המזהה הקודם מפנים לכתובת החדשה, והודעות שנשלחות לכתובת הדוא״ל הקודמת ממשיכות להגיע לקבוצה. Loomio שומרת עד שלושה מזהים קודמים. אם משנים את המזהה שוב לאחר מכן, המזהה הישן ביותר מפסיק לפעול.

<!-- translation-section: description -->

## תיאור

בתיאור ניתן להסביר מה מטרת הקבוצה, מי משתתפים בה וכיצד מצופה להשתמש בה. ניתן לעצב את התיאור ולכלול בו קישורים, מסמכים וסרטונים.

ייתכן ששם הקבוצה והתיאור שלה יהיו גלויים גם למי שאינם חברים בה, בהתאם ל[הגדרות הפרטיות](/en/user_manual/groups/settings/privacy) של הקבוצה.

## תמונת רקע ולוגו

תמונת הרקע מופיעה לרוחב החלק העליון של דף הקבוצה. מומלץ להשתמש בתמונה רחבה בגודל 2048 × 512 פיקסלים.

הלוגו מזהה את הקבוצה בניווט ובמקומות אחרים שבהם מוצגת תמונה קטנה. יש להעלות את תמונת הרקע ואת הלוגו בנפרד, כדי שניתן יהיה לחתוך כל אחד מהם לצורה המתאימה לו.
