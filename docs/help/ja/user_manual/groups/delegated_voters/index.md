# 投票権を持つ代表者

グループの全員が同じディスカッションの場を共有しながら、理事や選出された代表者など、指定されたメンバーだけが投票できるようにする場合は、代表者機能を使います。投票者と投票しない人を分けるためだけに別のサブグループを管理するよりも簡単です。

そのメンバーに、他のメンバーには公開しないディスカッション、ファイル、メンバー一覧も必要な場合は、非公開のサブグループを使います。

代表者の指定や解除ができるのは、グループ管理者だけです。グループページの**メンバー**タブで、対象の人の名前の横にある操作メニューを開き、**委任する**を選択します。指定を解除するには、同じメニューで**委任を取り消す**を選択します。

![メンバーのメニューにある「委任する」操作](member_make_delegate.png)

代表者だけが投票できるアンケートや提案を作成するには、アンケートの設定で**選ばれた人のみ**を選択します。

![提案を開始するときの「選ばれた人のみ」設定](poll_invited_people_only.png)

投票に招待する人を選ぶときに、**[グループ名]の代表者**を選択します。

![投票への招待フォームにある「Oatmilk Cooperativeの代表者」の選択肢](poll_invite_delegates_group.png)

グループの代表者全員を確認するには、**メンバー**タブを開き、フィルターメニューから**代表者**を選択します。

![メンバーのフィルターにある「代表者」の選択肢](members_list_delegates.png)
