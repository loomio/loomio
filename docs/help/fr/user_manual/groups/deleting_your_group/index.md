# Supprimer votre groupe

Seul un administrateur du groupe peut supprimer un groupe. La suppression d’un groupe retire immédiatement l’accès et programme la suppression définitive de toutes les données du groupe et de ses sous-groupes après 90 jours.

Avant de supprimer un groupe, [exportez les données du groupe](/en/user_manual/groups/data_export) et téléchargez les fichiers importés que vous souhaitez conserver.

Pour supprimer un groupe, ouvrez **Paramètres** sur la page du groupe et choisissez **Supprimer le groupe**.

![Action de suppression du groupe sur la page des paramètres d’Oatmilk Cooperative](group_delete_group.png)

Saisissez l’identifiant du groupe pour confirmer la suppression.

![Formulaire de confirmation demandant l’identifiant d’Oatmilk Cooperative](group_delete_group_confirm.png)

Lorsque vous confirmez la suppression :

- Le groupe et ses sous-groupes disparaissent immédiatement de l’interface. Les membres et les administrateurs du groupe perdent l’accès leur permettant de consulter le contenu, d’y participer ou de l’exporter, y compris les sondages ouverts à partir de liens enregistrés.
- Les notifications d’activité et les rappels de sondage en attente pour le groupe et ses sous-groupes sont arrêtés, mais les messages déjà en cours d’envoi peuvent encore arriver.
- Votre abonnement Loomio est résilié.
- Les discussions et les sondages directs en dehors du groupe ne sont pas affectés.

Loomio envoie également un e-mail d’avertissement indiquant le nombre de sous-groupes, de membres, de discussions, de sondages et de commentaires du groupe. Si vous avez supprimé le groupe par erreur ou devez encore exporter ses données, répondez à cet e-mail ou contactez-nous dans les 90 jours pour rétablir l’accès.

## Les données du groupe sont définitivement supprimées après 90 jours

Après 90 jours, Loomio supprime définitivement tous les fils, sondages, fichiers et autres contenus du groupe et de ses sous-groupes. Cette action est irréversible.
