# ディスカッションを始める

Loomioでディスカッションを始める手順は、メールを送る手順に似ています。タイトルはメールの件名に相当し、背景説明では話題を紹介します。招待リストでは、通知する相手を選びます。

簡単な質問を書くことも、リンクや添付ファイルを添えて詳しい説明を共有することもできます。メールで返信することもでき、その返信はディスカッションに表示されます。

<!-- translation-section: new-discussion -->

## 新しいディスカッションを始める

グループページまたはサブグループページで、**新しいスレッド**を選択します。

グループの[ディスカッションのテンプレート](/en/user_manual/discussions/templates/)が表示されます。テンプレートまたは**空のテンプレート**を選択すると、ディスカッションの入力フォームが開きます。

![Oatmilk Cooperativeのページにある「新しいスレッド」ボタン](new-discussion-button.png)

![リターナブル瓶の試験導入を計画するディスカッションの開始フォーム](new-discussion-example.png)

<!-- translation-section: group -->

### グループ

適切なグループまたはサブグループが選択されているか確認します。そのグループの全メンバーがディスカッションを閲覧できます。別のグループで始めたり、グループに属さない[ダイレクトディスカッション](/en/user_manual/discussions/direct_discussions/)として始めたりすることもできます。

>[!Tip]
>まだグループにディスカッションを共有する準備ができていない場合は、ダイレクトディスカッションとして始めます。後からグループに移動できます。

<!-- translation-section: invite-and-notify -->

### 招待と通知

**招待する**欄では、ディスカッションを始めたときにすぐに通知する相手を指定します。

グループのメンバーは、通知を受け取らなくてもグループ内のディスカッションを閲覧できます。**招待する**欄にグループのメンバーを追加すると、そのメンバーにLoomio内の通知とメール通知が届きます。

グループ全員に通知するにはグループを選択します。個別のメンバーを選ぶには、グループを展開します。名前の横にある**×**を選択すると、その人を通知先から外せます。

![個別の通知先を表示するために展開した「招待する」欄](../notifying_people/thread_notification.png)

メンバーの名前を入力し、一覧から選択します。

![「招待する」欄でSamira Patelを検索する様子](../notifying_people/thread_notify_user.png)

ゲストを招待するには、メールアドレスを入力します。ゲストはこのスレッドを閲覧し、参加できますが、招待されない限り、グループ内の他の非公開ディスカッションは閲覧できません。

![「招待する」欄にゲストのメールアドレスを追加する様子](../notifying_people/thread_notify_email.png)

誰にも通知せずにディスカッションを始めることもできます。その場合も、グループのメンバーはLoomio内でディスカッションを見つけられます。通知設定によっては、まとめメールにも表示されます。

<!-- translation-section: tags -->

### タグ

後からディスカッションを絞り込んだり検索したりできるように、タグを1つ以上追加します。初期設定では、グループ管理者がその権限を無効にしない限り、メンバーは新しいタグを作成できます。[カテゴリタグ](/en/user_manual/discussions/tags/)を参照してください。

<!-- translation-section: title -->

### タイトル

ディスカッションの内容が伝わる、明確で具体的なタイトルを付けます。

<!-- translation-section: context -->

### 背景説明

背景説明では、話題を紹介し、話し合う内容や必要な決定を示します。テキストの書式を設定したり、ファイルを添付したり、文書へのリンクを追加したり、動画を埋め込んだりできます。

背景説明はスレッドの上部に表示され、ディスカッションの進行に合わせて更新できます。ディスカッションが終了したら、背景説明に結論を追加して、後から参加する人もすぐに結果を確認できるようにすることもできます。
