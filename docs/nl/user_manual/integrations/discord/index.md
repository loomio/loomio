# Discord-integratie

_Meldingen van je Loomio-groep verbinden met de teamchat in Discord._

Loomio kan meldingen naar je Discord-kanalen sturen bij nieuwe discussies, voorstellen, reacties, stemmen en conclusies. Je kunt de chat ook zelf een melding sturen om mensen aan een beslissing te herinneren.

---

Open je Discord-server en zoek het menu met serverinstellingen.
![](server-settings.png)

Klik op "Integraties"
![](integrations.png)

Klik daarna op "Webhook toevoegen" en geef de webhook een naam, zoals "Loomio-bot"

![](add-webhook.png)

Kopieer de webhook-URL naar je klembord en volg de link hieronder.

[Stel een chatintegratie in Loomio in](../chatbots/#set-up-a-chat-integration)
