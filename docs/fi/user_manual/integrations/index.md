# Integraatiot

Yhdistä Loomio muihin ryhmäsi käyttämiin työkaluihin.

<!-- translation-section: choose-where-work-belongs -->

## Valitse työlle sopiva paikka

Loomio täydentää chat-palveluita, jaettuja asiakirjoja ja tehtävienhallinnan työkaluja sen sijaan, että korvaisi kaikki työskentelytavat.

| Työ | Suositeltu työkalu |
|---|---|
| Nopeat kysymykset, vapaamuotoinen jutustelu ja ajankohtaiset päivitykset | Chat |
| Jatkuvasti päivitettävän asiakirjan yhteinen muokkaaminen | Jaettu asiakirja |
| Tehtävien jakaminen ja seuranta | Projektin- tai tehtävienhallinnan työkalu |
| Tärkeä aihekohtainen keskustelu, laaja osallistuminen, päätökset ja johtopäätökset | Loomio |

Tuo työ Loomioon, kun ihmiset tarvitsevat aikaa aiheen pohtimiseen, kun kaikilla asian koskettamilla ihmisillä pitäisi olla todellinen mahdollisuus osallistua tai kun ryhmän on löydettävä keskustelu ja päätös myöhemmin. Lisää Loomio-keskusteluun linkki asiaan liittyvään asiakirjaan tai tehtävään, jotta keskustelun konteksti on helppo löytää.
