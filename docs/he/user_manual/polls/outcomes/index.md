# מסקנה

כשההצעה או הסקר מסתיימים, תופיע בקשה להזין **מסקנה**.

![](outcome_prompt.png)

יש לציין את תוצאות ההצעה או הסקר ואת הצעדים הבאים.

המסקנה היא תיעוד חשוב של הסקר או ההחלטה. היא מסכמת אותם בקצרה לעיון בעתיד.

<!-- translation-section: outcome-statements-for-common-decision-processes -->

## מסקנות בתהליכי קבלת החלטות נפוצים

| **תהליך קבלת החלטות** | **מתי מתקבלת ההחלטה** | **מסקנה** |
|---|---|---|
| תהליך היוועצות | לאחר קבלת העצות ובחינתן. | יש לציין את ההחלטה שהתקבלה ולהודות למי שנתנו עצות ומשוב. |
| תהליך הסכמה | כשלא נותרו התנגדויות. | יש לציין שלא נותרו התנגדויות תקפות ושיש הסכמה לכך ש'אפשר לנסות' את ההצעה.  |
| תהליך קונצנזוס | כשרוב* המשתתפים מסכימים. | יש לציין את תוצאות ההצעה ואת ההחלטה שהתקבלה. |

**רוב או רוב מיוחס, בהתאם לתקנון הארגון או להסכמה קודמת בו.*

בכל תוצאה אפשר ללמוד משהו מההצעה ומהסקר.

אם ההצעה לא מתקבלת, כדאי לבחון מה למדו המשתתפים ואם אפשר להיעזר בכך כדי להגיע להחלטה טובה יותר.

המסקנה מאפשרת לתעד את התוצאות ואת מה שנלמד.

![](outcome_statement.png)

ניתן לשלוח עדכון למשתתפים. הם יקבלו הודעת דוא״ל מ־Loomio עם תוצאות הסקר והמסקנה.

ניתן גם לקבוע **תאריך ביקורת**: מועד עתידי לבחינה חוזרת של הסקר או ההחלטה. לדוגמה, אפשר לבחון אסטרטגיה מחדש באותה תקופה בשנה הבאה.

![](outcome_published.png)

**דוגמאות למסקנות**

> _ההצעה לא הגיעה לקונצנזוס כי כמה מהמשתתפים הביעו חשש מההשפעה על התקציב. ג׳ורג׳ וחימנה יכינו ניתוח פיננסי ויעלו הצעה חדשה בשבוע הבא._

או

> _בחנתי את הדברים שהעלו כל המשתתפים. כמנהלי הפרויקט, ההחלטה הזו באחריותי. החלטתי להאריך את לוח הזמנים בעשרה ימים._
