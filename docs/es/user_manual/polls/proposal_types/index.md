# Sondeos

Los sondeos permiten recopilar selecciones, puntuaciones, distribuciones de puntos, preferencias ordenadas, disponibilidad o votos en elecciones. Elige el método de votación según lo que necesiten expresar las personas participantes y cómo vayas a usar el resultado. Usa una [propuesta](/en/user_manual/polls/proposals/) cuando las personas deban responder a una afirmación o un plan de acción.

<!-- translation-section: simple-poll -->

## Sondeo simple

[Elegir](/en/user_manual/polls/choose/) permite seleccionar una o varias opciones. Úsalo para encontrar la opción más popular o preparar una lista de opciones finalistas.

<!-- translation-section: score-poll -->

## Encuesta de puntuación

[Puntuación](/en/user_manual/polls/score/) permite valorar cada opción con la misma escala. Úsala para comparar el grado de apoyo, preparación, idoneidad o importancia de las opciones.

<!-- translation-section: dot-vote -->

## Votación por puntos

[Distribuir](/en/user_manual/polls/allocate/) da a cada participante un número fijo de puntos para repartir. Úsalo para identificar prioridades cuando dedicar recursos o atención a una opción implica dedicar menos a otra.

<!-- translation-section: ranked-choice -->

## Elección clasificada

[Ordenar](/en/user_manual/polls/rank/) permite ordenar las opciones por preferencia. Úsalo para conocer el orden de preferencia del grupo o elegir la opción mejor situada.

<!-- translation-section: time-poll -->

## Coordinación de horario

[Coordinación de horario](/en/user_manual/polls/meeting_polls/) permite indicar cuándo está disponible cada participante. Úsala para programar una reunión o un evento entre distintas zonas horarias.

<!-- translation-section: stv-election -->

## Elecciones STV

[Elecciones STV](/en/user_manual/polls/stv/) permite ordenar candidaturas por preferencia en una elección proporcional con varios puestos. Usa STV para elegir un comité, una junta o un grupo de representantes.

<!-- translation-section: other-specialized-method -->

## Otro método especializado

Loomio también incluye una ronda de preguntas para recopilar preguntas sin votar. Quienes administran el grupo pueden activarla desde [Plantillas de sondeo](/en/user_manual/polls/poll_templates/).
