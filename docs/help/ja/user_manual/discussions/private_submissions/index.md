# 非公開の提出物を集める

非公開グループを使うと、グループのメンバーではない人から非公開の提出物を集められます。提出物ごとに個別のディスカッションが作成され、提出者とグループの審査チームが情報を交換したり、質問したり、決定を記録したりできます。提出者は、グループ内のほかの非公開ディスカッションや提出物を見ることはできません。

選考中に候補者の詳細や候補者一覧を非公開にする必要がある場合、候補者の推薦に活用できます。選挙、役職への任命、委員会、理事会、代表者の選考で、自分自身やほかの人を推薦できます。選考委員会は、推薦ごとに個別のディスカッションで審査します。

提出物を公開すべきでない、次のような用途にも適しています。

- 苦情、虐待や危害から人を守るための報告、安全上の懸念、事故や問題の報告
- 個別の案件に関する決定への異議申し立てや再検討の依頼
- 調停、紛争解決、個人的な支援の依頼
- 生活困窮者向けの助成金や奨学金など、個人情報、財務情報、申請資格に関する情報を含む申請
- 審査中に非公開にする必要がある封印入札や入札への回答

この手順では提出者同士に提出物が公開されませんが、匿名ではありません。提出者にはユーザーアカウントが必要で、非公開グループのすべてのメンバーが提出物を見ることができます。機密性の高い情報を扱う場合は、事前に審査用グループのメンバーを確認してください。

## 非公開の提出を有効にする

提出物を集めるグループまたはサブグループの管理者である必要があります。

1. グループを開きます。
2. **設定**を選択します（または**もっと**から**グループ設定を編集する**を選択します）。
3. **権限**を開きます。
4. **非会員でも議論を開始できます**を有効にします。
5. グループ設定を保存します。

![グループ設定の「権限」タブで「非会員でも議論を開始できます」が強調表示されている画面](non_members_can_start_discussions.png)

この設定は、**議論中**と**閉鎖**のグループでのみ利用できます。**秘密**のグループでは表示されません。表示されない場合は、グループ設定の**プライバシー**を開き、**グループのプライバシー**を**閉鎖**（非公開の提出物を集める場合に推奨）または**議論中**に変更してから、**権限**に戻ります。

この権限を有効にしても、グループのディスカッションは公開されません。メンバーではない人は、新しいディスカッションを始め、ゲストとしてそのディスカッションにアクセスできますが、グループ内のほかの非公開ディスカッションを見ることはできません。

## 非公開の提出手順を設定する

1. 提出物を受け付ける専用のサブグループを作成し、プライバシーを**閉鎖**に設定します。サブグループを使うと、提出物を親グループのほかの活動から分けて管理できます。
2. 選考委員会の担当者や、提出物の審査を担当する人をサブグループのメンバーとして追加します。サブグループのすべてのメンバーがすべての提出物を見ることができるため、アクセスが必要な人だけを追加します。
3. サブグループに[ディスカッションのテンプレート](/en/user_manual/discussions/templates)を作成します。提出者が回答すべき質問や提供すべき情報を含めます。提出物の種類ごとに異なるディスカッションのテンプレートを作成できます。
4. 提出者からサブグループへの参加申請を受け付けない場合は、参加方法を**招待のみ**に設定します。
5. サブグループの権限で[非公開の提出を有効にします](#enable-private-submissions)。
6. サブグループのメンバーではないアカウントで手順を確認します。
7. 提出を予定している人にサブグループのページを共有します。提出する前に、ユーザーアカウントにサインインする必要があります。

## 提出する

提出者はサブグループを開き、**ディスカッションを始める**を選択します。Loomioに、そのサブグループで利用できるディスカッションのテンプレートが表示されます。提出者は適切なディスカッションのテンプレートを選び、質問に回答してディスカッションを始めます。

ディスカッションはサブグループに属しますが、提出者はサブグループのメンバーにはなりません。Loomioは提出者を、そのディスカッションのスレッドにゲストとして追加します。これにより、提出者はディスカッションを閲覧し、選考委員会や審査チームとやり取りできます。サブグループ内のほかの非公開ディスカッションや提出物を見ることはできません。

<!-- translation-section: review-submissions -->

## 提出物を審査する

サブグループのメンバーは、サブグループ内の提出物に関するすべてのディスカッションを見ることができます。追加の質問をしたり、コメント、アンケート、その他のディスカッション用ツールを使ったりして、審査を進められます。

ほかの人から情報を得る必要がある場合は、権限を持つサブグループのメンバーが、その人を提出物のディスカッションに招待できます。たとえば、推薦者が推薦を提出した場合、候補者の参加が必要であれば、その候補者をスレッドに招待できます。招待された人はゲストとして参加し、サブグループ内のほかの非公開ディスカッションへのアクセス権は得ません。

各提出者は自分の提出物を見ることができますが、サブグループ内のほかの非公開ディスカッションや提出物を見ることはできません。提出の受け付けを締め切ったら、**非会員でも議論を開始できます**を無効にします。既存のディスカッションとゲストのアクセス権は変わりません。
