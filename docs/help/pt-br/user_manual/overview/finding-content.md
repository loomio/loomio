# Encontrar conteúdo

O Loomio oferece várias maneiras de encontrar discussões e decisões nos seus grupos.

<!-- translation-section: search -->

## Busca

Selecione **Pesquisar** na barra de navegação superior para fazer uma busca a partir de qualquer página do Loomio.

![](search_button.png)

A busca abrange todos os grupos e discussões diretas que você pode acessar. Ela encontra títulos de discussões, contexto, comentários, enquetes, votos e conclusões.

Digite uma palavra ou frase e pressione Enter. Por exemplo, buscar **bottle** encontra conteúdo da Oatmilk Cooperative que contém essa palavra.

![](search_strategy.png)

<!-- translation-section: search-tips -->

### Dicas de busca

- Comece com uma ou duas palavras específicas do título ou do conteúdo.
- A busca encontra correspondências pelo início de uma palavra, então uma palavra parcial como **bott** pode encontrar **bottle**.
- A busca compensa pequenos erros de digitação quando há poucos resultados para o termo pesquisado.
- Filtre os resultados por organização, subgrupo, tag ou tipo de conteúdo (como comentários ou enquetes). Os filtros de tag funcionam sem um termo de busca e retornam itens com essa tag.
- Ordene por **Melhor resultado** para priorizar a relevância, ou pelos mais recentes ou mais antigos se você souber aproximadamente quando algo foi publicado.

<!-- translation-section: filter-discussions -->

## Filtrar discussões

Na aba **Discussões** de um grupo, você pode filtrar conversas pelo status de aberta ou encerrada ou por tag de categoria. Combine um filtro com a caixa de busca da lista para reduzir rapidamente uma longa lista de discussões.

<!-- translation-section: category-tags -->

## Tags de categoria

As tags agrupam discussões, enquetes, conclusões e comentários relacionados sob nomes escolhidos pelo seu grupo, como um projeto, equipe ou área de trabalho.

![](tags.png)

Selecione uma tag na aba **Discussões** para exibir discussões que contenham itens com essa tag. Dentro de uma discussão, selecione uma tag na barra lateral para ver comentários, enquetes ou conclusões com essa tag, junto com os itens aos quais respondem.

Autores podem adicionar tags às próprias publicações. Admins de grupo, admins de conversa e qualquer pessoa que possa editar o contexto da discussão podem adicionar tags a qualquer item. Consulte [Tags de categoria](/en/user_manual/discussions/tags) para obter detalhes sobre configuração e permissões.

<!-- translation-section: unread-discussions -->

## Discussões não lidas

Selecione **Discussões não lidas** na barra lateral para ver conversas com novas atividades. Dentro de uma discussão, use a linha do tempo para ir até itens não lidos e eventos importantes.

<!-- translation-section: polls-awaiting-your-vote -->

## Enquetes aguardando seu voto

Selecione **Enquetes para votar** na barra lateral para ver enquetes abertas para as quais você recebeu um convite e nas quais ainda não votou. Você também pode abrir a aba **Enquetes** de um grupo para ver enquetes ativas e encerradas.

<!-- translation-section: bookmarks -->

## Favoritos

Adicione uma discussão, comentário, enquete, voto ou conclusão aos favoritos quando quiser voltar a esse conteúdo. Abra **Favoritos** no seu menu de usuário para ver tudo o que você salvou. Consulte [Favoritos](/en/user_manual/users/bookmarks) para obter detalhes.
