# Закладки

Закладки — це ваш особистий список матеріалів Loomio, до яких ви хочете повернутися. Ваші закладки бачите лише ви. Коли ви зберігаєте закладку, інші не отримують сповіщень.

Ви можете зберігати закладки для:

- обговорень
- коментарів
- пропозицій та опитувань
- голосів
- висновків

<!-- translation-section: save-a-bookmark -->

## Збереження закладки

Відкрийте меню дій для потрібного матеріалу та виберіть **Зберегти закладку**. Меню дій зазвичай позначено трьома крапками. Для обговорення відкрийте меню біля його назви. Для коментаря, голосу, пропозиції, опитування або висновку відкрийте меню відповідного матеріалу.

![](save_bookmark.png)

<!-- translation-section: view-your-bookmarks -->

## Перегляд закладок

Відкрийте бічну панель і виберіть **Закладки**. Число поруч із посиланням показує, скільки закладок ви зберегли.

На сторінці закладок спочатку показано матеріали, які ви зберегли останніми. У кожному рядку зазначено тип матеріалу та його автора. Виберіть рядок, щоб перейти до збереженого матеріалу.

![](bookmarks_page.png)

<!-- translation-section: remove-a-bookmark -->

## Видалення закладки

На сторінці закладок натисніть кнопку видалення закладки в кінці рядка. Також можна відкрити меню дій збереженого матеріалу та вибрати **Видалити закладку**.

Видалення закладки впливає лише на ваш особистий список. Ви можете зберегти цей матеріал знову пізніше.
