# Объединить аккаунты

Объедините два аккаунта Loomio с разными адресами электронной почты, если хотите продолжить работу с одним аккаунтом.

Прежде чем начать, решите, какой аккаунт сохранить:

- **Аккаунт, который вы сохраните**, — это аккаунт, чьи адрес электронной почты и профиль вы будете использовать после объединения
- **Аккаунт, который вы удалите**, — это аккаунт, в который вы войдёте первым. После объединения его адрес электронной почты больше нельзя будет использовать для входа

Вам нужен доступ к обоим аккаунтам и к почте аккаунта, который вы хотите сохранить.

> [!WARNING]
> Объединение аккаунтов нельзя отменить. Перед окончательным подтверждением внимательно проверьте адреса электронной почты обоих аккаунтов.

<!-- translation-section: start-the-merge -->

## Начните объединение

1. Войдите в **аккаунт, который вы хотите удалить**.
2. Откройте боковое меню, выберите своё имя, затем **Редактировать профиль**.
3. Выберите **Объединить аккаунты**.

![Действия с профилем: выделен пункт «Объединить аккаунты»](merge_accounts_profile.png)

4. Введите адрес электронной почты **аккаунта, который вы хотите сохранить**, и выберите **Отправить письмо с подтверждением**. Loomio всегда показывает одинаковое подтверждение и выводит вас из аккаунта. Если аккаунт с таким адресом существует, Loomio отправит на него письмо для подтверждения.

<!-- translation-section: verify-the-account-you-want-to-keep -->

## Подтвердите аккаунт, который хотите сохранить

5. Откройте письмо, отправленное на адрес аккаунта, который вы хотите сохранить, и выберите **Подтвердите адрес электронной почты и продолжайте**.

![Письмо для подтверждения объединения: выделена кнопка «Подтвердите адрес электронной почты и продолжайте»](merge_accounts_email.png)

6. Если Loomio попросит вас войти, войдите в аккаунт, который хотите сохранить.
7. На странице **Подтвердить объединение** ещё раз проверьте оба адреса электронной почты. Выберите **Объединить аккаунты**, чтобы завершить объединение.

![Страница окончательного подтверждения: выделена кнопка «Объединить аккаунты»](merge_accounts_confirm.png)

## Что произойдёт после объединения

Сохранённый аккаунт останется вашим аккаунтом Loomio для входа. Участие в группах и действия из удалённого аккаунта, включая обсуждения, комментарии, голосования и голоса, будут перенесены в сохранённый аккаунт. Если оба аккаунта уже состоят в одной группе, членство сохранённого аккаунта не изменится.

Второй аккаунт будет удалён, и его адрес электронной почты больше нельзя будет использовать для входа. После объединения Loomio отправит письмо с подтверждением на адрес сохранённого аккаунта.
