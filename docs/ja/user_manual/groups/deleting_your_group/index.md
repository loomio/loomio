# グループの削除

Loomioのグループを削除すると、グループのすべてのデータを完全に削除する手続きが始まります。

残しておきたいデータがある場合は、続行する前に[グループのデータをエクスポート](/en/user_manual/groups/data_export/)し、アップロードした重要なファイルを手動でダウンロードしてください。

三点のアイコンをクリックしてグループのドロップダウンメニューを開き、**グループの削除**を選択します。グループへのアクセスが停止し、保存されているグループのすべてのデータを削除する手続きが始まります。グループを削除できるのは管理者だけです。

グループを削除すると、すぐに表示されなくなり、90日後に完全に削除されます。管理者とグループのメンバーは、直ちにグループにアクセスできなくなります。誤って削除した場合は、削除から90日以内に復元を依頼してください。

削除待ちのグループとそのサブグループでは、メンバーとコーディネーターは閲覧、参加、エクスポートができません。保存したリンクから投票を開くこともできません。メンバーはコンテンツの作成や編集、投票、お知らせやリマインダーの送信、招待の承諾もできません。削除を確定する前に、グループをエクスポートし、重要なファイルをダウンロードしてください。ダイレクトディスカッションと投票には影響しません。

グループの削除を予定すると、そのグループとサブグループで送信待ちのアクティビティ通知と投票のリマインダーは停止します。すでに送信中のメッセージは届く場合があります。

警告メールには、グループのサブグループ、メンバー、ディスカッション、投票、コメントの数が記載されています。グループを残すか、[データをエクスポート](/en/user_manual/groups/data_export/)する必要がある場合は、削除前にアクセスを復元できるよう、90日以内に返信してください。

グループを削除すると、Loomioのサブスクリプションも解約されます。

![Oatmilk Cooperativeのメニューにあるグループの削除](group_delete_group.png)

削除の確認のため、グループ名の入力を求められます（*大文字と小文字は区別されます*）。

![Oatmilk Cooperativeの識別名の入力を求める確認フォーム](group_delete_group_confirm.png)

## グループのデータは90日後に完全に削除されます

90日後、すべてのスレッド、投票、ファイル、その他のグループのコンテンツが完全に削除されます。***元に戻すことはできません。***

続行する前に、[グループのデータをエクスポート](/en/user_manual/groups/data_export/)し、アップロードした重要なファイルを手動でダウンロードすることをおすすめします。
