# ディスカッションを始める

Loomioでディスカッションを始める手順は、メールを書く手順に似ています。メールの件名はディスカッションのタイトルに、メールの本文はディスカッションの背景説明に相当します。

メールの宛先に人を追加するように、Loomioでは個人やグループをディスカッションに招待できます。招待された人には、ディスカッションの内容を含むメール通知が届きます。

メールでディスカッションに返信すると、その内容がコメントとしてディスカッションに表示されます。

メールと同じように、ディスカッションには簡単な質問を書くことも、参考情報のリンクやファイルを添えて話題を詳しく説明することもできます。

<!-- translation-section: new-discussion -->

## 新しいディスカッション

新しいディスカッションを始めるには、Loomioのグループページにある**新しい議論**ボタンを選択します。

Loomioのグループや、いずれかのサブグループでディスカッションを始められます。

![Oatmilk Cooperativeのページにある「新しい議論」ボタン](new-discussion-button.png)

![リターナブル瓶の試験導入を計画する新しいディスカッションのフォーム](new-discussion-example.png)

<!-- translation-section: group -->

### グループ
ディスカッションを始めるグループまたはサブグループの名前が正しいか確認します。このグループの全メンバーがディスカッションを閲覧できます。別のグループで始めたり、グループに属さない「ダイレクト」のディスカッションとして始めたりすることもできます。

>[!Tip]
>まだグループにディスカッションを公開する準備ができていない場合は、「ダイレクト」として始めます。準備ができたら、Loomioのグループにディスカッションを移動できます。

<!-- translation-section: invite-and-notify -->

### 招待と通知

**招待する**欄では、新しいディスカッションをすぐに通知する相手を指定します。

グループのメンバーは、通知を受け取らなくてもグループ内のディスカッションを閲覧できます。**招待する**欄にグループのメンバーを追加すると、そのメンバーにメール通知とLoomio内の通知が届きます。

グループ全員に通知するにはグループを選択します。個別のメンバーを選ぶには、グループを展開します。名前の横にある×を選択すると、その人を通知先から外せます。

![個別の通知先を表示するために展開した「招待する」欄](../notifying_people/thread_notification.png)

メンバーの名前を入力し、一覧から選択します。

![「招待する」欄でSamira Patelを検索する様子](../notifying_people/thread_notify_user.png)

ゲストを招待するには、メールアドレスを入力します。ゲストはこのスレッドを閲覧し、参加できますが、別途招待されない限り、グループ内の他のディスカッションは閲覧できません。

![「招待する」欄にゲストのメールアドレスを追加する様子](../notifying_people/thread_notify_email.png)

誰にも通知せずにディスカッションを始めることもできます。その場合も、グループのメンバーはLoomio内でディスカッションを見つけられます。通知設定によっては、まとめメールにも表示されます。

<!-- translation-section: tags -->

### タグ

タグを追加すると、タグで検索したときにディスカッションを見つけやすくなります。管理者は新しいタグを作成できます。

<!-- translation-section: title -->

### タイトル
ディスカッションの内容に合ったタイトルを付けます。ディスカッションのタイトルは、メールの件名に相当します。

<!-- translation-section: context -->

### 背景説明
ディスカッションの背景説明では、話題を紹介し、話し合う内容や必要な決定を示します。書式設定ツールで要点を強調できます。参考情報を記載し、ファイルを添付したり、オンライン文書へのリンクを追加したり、動画を埋め込んだりできます。

背景説明は常にディスカッションの上部に表示され、ディスカッションの進行に合わせていつでも更新できます。ディスカッションが終了したら、背景説明に結論を記載します。
