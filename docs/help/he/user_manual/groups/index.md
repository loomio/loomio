# קבוצות

קבוצה ב-Loomio היא מרחב משותף שבו חברי הקבוצה מקיימים דיונים, משתפים מידע ומקבלים החלטות יחד.

![עמוד הקבוצה של קואופרטיב Oatmilk, עם תיאור הקבוצה ורשימת הדיונים](group_page.png)

ניתן להתאים את עמוד הקבוצה באמצעות שם, תיאור, סמל, תמונת כיסוי וקישורים למסמכים, כגון מסמך המגדיר את מטרות הקבוצה וסמכויותיה. כך קל יותר לחברי הקבוצה להבין את מטרתה וכיצד להשתתף.

כדי להתחיל, יש [ליצור קבוצה](/en/user_manual/groups/starting_a_group), לבחור את [הגדרות הפרטיות](/en/user_manual/groups/settings/privacy) שלה ו[להזמין אנשים](/en/user_manual/groups/inviting_people).

בעת הכנת קבוצה חדשה, ניתן לעיין ב[היכרות עם Loomio בקבוצה](/en/user_manual/overview/introducing_loomio) לקבלת סדר פעולות מעשי, מבחירת המשימה הראשונה ועד לתיעוד מסקנה.

## כללי התנהגות

כללי התנהגות עוזרים לחברי הקבוצה להבין כיצד להשתתף וכיצד הקבוצה מגיבה להתנהגות בלתי הולמת. ניתן לעיין ב[מדריך להנחיה](/guides/facilitators-guide/commencing/#culture-protocol-expectations) לקבלת הנחיות לתיאום ציפיות.
