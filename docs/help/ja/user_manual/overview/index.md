# はじめに

Loomioは、協働する組織のためのディスカッションと意思決定のツールです。

人々が集まり、話題について話し合い、提案を検討し、決定を行うことができます。

## Loomioの仕組み

Loomioには、グループ、ディスカッション、アンケートという3つの主要な要素があります。

<!-- translation-section: groups -->

### グループ

グループは、組織、チーム、コミュニティが協力して活動する場所です。ホームページにはグループの目的が示され、ディスカッション、アンケート、メンバー、ファイルにアクセスできます。

![](orientation_group.png)

<!-- translation-section: discussions -->

### ディスカッション

ディスカッションは、ある話題に関する情報と会話を一か所にまとめます。背景説明の共有、コメント、返信、リアクションができ、アンケートを使ってディスカッションを結論へと進めることができます。

![](orientation_discussion.png)

ディスカッションを重ねることで、グループが検討した情報と行った決定が、検索できる記録として蓄積されます。

<!-- translation-section: polls-and-proposals -->

### アンケートと提案

アンケートは、グループが参加者の希望を把握し、助言を集め、決定を行うのに役立ちます。さまざまなアンケートのテンプレートが、異なる意思決定の進め方に対応しています。提案では、示された行動方針に対して回答し、その理由を説明します。

![](orientation_proposal.png)

アンケートはディスカッションの一部として使うことも、グループページの**アンケート**タブから単独で実施することもできます。

これらの要素が画面のどこに表示されるかは、[クイックツアー](/en/user_manual/overview/orientation)をご覧ください。参加を始めるには、[参加方法](/en/user_manual/overview/how-to-participate)をご覧ください。

## Loomioの活用例

**会員制の組織**では、多くのメンバーが意思決定に参加できるようにします。政党、消費者協同組合、労働者協同組合、会員制団体は、メンバーが安心して参加できる場を設けるためにLoomioを使っています。メンバーは情報を共有し、話題を提起し、重要な決定に参加し、総会で投票できます。意思決定の手順を効率化し、透明性と説明責任を高め、ディスカッションと決定を記録し、メンバーの声を取り入れて行動につなげることができます。

**自主管理型の組織**では、スタッフが意思決定に参加できるようにします。自主管理型のチーム、労働者協同組合、ソシオクラシーを採用する組織は、離れた場所や異なる時間帯で活動するチームの間で、同意、コンセンサス、助言に基づく意思決定を進めるためにLoomioを使っています。集合知を活かし、意思決定を分散させ、運営の仕組みや方針を共同で作り、決定とディスカッションを記録できます。

**理事会、評議会、各地に分散したネットワーク**では、関係者が意思決定に参加できるようにします。安心してディスカッションできる場を設け、やり取りを記録し、地域や時間帯を越えて連携できます。意思決定の手順を整え、柔軟かつ迅速に対応し、組織の経験や知識を引き継ぐことができます。

**居住コミュニティや協同組合**では、近隣の住民が共同で決定を行います。コハウジングのコミュニティ、エコビレッジ、共同居住の協同組合、住宅協同組合、ランドトラストは、従来の区分所有や不動産の管理に代えて、またはそれを補う形で、民主的な運営を行うためにLoomioを使っています。住民は、共有の土地、共用スペース、コミュニティの取り決めに関する決定に関わります。同じ時間に集まらずにディスカッションできるため、メンバーは現地にいても旅行などで不在でも十分に参加できます。また、コミュニティが共に暮らす方法をどのように決めたかを、明確な記録として残せます。

Loomioには、組織が行った決定、参加した人々、決定に至るまでのディスカッションが、継続的に記録されていきます。
