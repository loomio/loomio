# Прамыя абмеркаванні

Прамое абмеркаванне — гэта прыватнае абмеркаванне для пэўнага кола людзей.

Прамое абмеркаванне не належыць да групы. Запрошаным людзям не абавязкова быць удзельнікамі вашай групы ў Loomio.

Вы вызначаеце, хто можа бачыць абмеркаванне і ўдзельнічаць у ім, дадаючы людзей або адрасы электроннай пошты ў поле **Запрасіць**.

Прамыя абмеркаванні падтрымліваюць тыя ж каментарыі, апытанні і іншыя інструменты, што і абмеркаванні ў групах. Яны могуць быць карысныя, калі няма патрэбы ствараць падгрупу.

![Форма прамога абмеркавання без выбранай групы і з Самірай Патэл у полі «Запрасіць»](direct-discussion-example.png)

Выберыце **Прамыя тэмы** на бакавой панэлі, каб убачыць свае прамыя абмеркаванні. Выберыце **Новая дыскусія** на гэтай старонцы, каб пачаць яшчэ адно.

## Сувязь з людзьмі праз прамое абмеркаванне
Прамое абмеркаванне можна выкарыстоўваць, каб прыватна звязацца з адным ці некалькімі людзьмі без стварэння падгрупы.
