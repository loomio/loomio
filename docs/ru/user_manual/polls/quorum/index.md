# Кворум

Кворум — минимальный процент людей с правом голоса, которые должны проголосовать, чтобы голосование считалось действительным. Используйте его, если для принятия решений в вашей группе требуется определённый уровень участия.

При создании опроса откройте **Дополнительные настройки** и укажите нужный процент в поле **Кворум участия**. Если кворум не нужен, оставьте поле пустым.

![Настройка кворума участия на уровне 60 процентов](./quorum-section.png)

Кворум также можно задать в [шаблоне опроса](/en/user_manual/polls/poll_templates/). Тогда он будет применяться по умолчанию к опросам, созданным по этому шаблону.

## Пример

Кооператив Oatmilk обсуждает шестинедельное испытание возвратных бутылок. Теперь кооперативу нужно утвердить бюджет испытания.

Джейми выбирает **Начать голосование**, затем шаблон предложения **Согласие** и заполняет название, описание, варианты ответа, срок и настройки для голосующих.

![Название предложения, описание, варианты ответа, срок и настройки для голосующих](proposal-options.png)

Джейми ограничивает участие в голосовании пятью людьми, отвечающими за бюджет испытания.

Для важных решений кооператив требует участия не менее 60 процентов голосующих. Поэтому Джейми вводит **60** в поле кворума участия и запускает предложение.

До первого голоса панель результатов показывает, что кворум ещё не достигнут.

![Голосов пока нет, кворум в 60 процентов не достигнут](pie-chart-0.png)

Джейми соглашается, а Самира не соглашается. Диаграмма обновляется, но два человека из пяти — это только 40 процентов. Кворум всё ещё не достигнут.

![Проголосовали двое из пяти, кворум ещё не достигнут](pie-chart-40.png)

Затем Алекс соглашается. Проголосовали трое из пяти, и кворум в 60 процентов достигнут. Рядом с требованием появляется зелёная галочка. Джейми может закрыть опрос досрочно или дождаться остальных голосов.

![Проголосовали трое из пяти, кворум в 60 процентов достигнут](pie-chart-60.png)
