# סקרים

סקרים אוספים בחירות, ציונים, הקצאות, דירוגים, זמינות או פתקי הצבעה בבחירות. יש להתאים את שיטת ההצבעה למה שהמשתתפים צריכים להביע ולאופן שבו ייעשה שימוש בתוצאה. ניתן להשתמש ב[הצעה](/en/user_manual/polls/proposals/) כשנדרשת תגובה להצהרה או לדרך פעולה.

<!-- translation-section: simple-poll -->

## סקר פשוט

[בחירה](/en/user_manual/polls/choose/) מאפשרת למשתתפים לבחור אפשרות אחת או יותר. ניתן להשתמש בה כדי למצוא את האפשרות הפופולרית ביותר או ליצור רשימה מצומצמת של אפשרויות.

<!-- translation-section: score-poll -->

## סקר ציון

[ציון](/en/user_manual/polls/score/) מאפשר למשתתפים לתת לכל אפשרות ציון באותו סולם. ניתן להשתמש בו כדי להשוות בין האפשרויות מבחינת עוצמת התמיכה, המוכנות, ההתאמה או החשיבות.

<!-- translation-section: dot-vote -->

## הצבעת נקודות

[הקצאה](/en/user_manual/polls/allocate/) מעניקה לכל משתתף מכסה קבועה של נקודות לחלוקה. ניתן להשתמש בה כדי לזהות סדרי עדיפויות כאשר בחירה בדבר אחד פירושה הפניית פחות תשומת לב או משאבים לדבר אחר.

<!-- translation-section: ranked-choice -->

## בחירה מדורגת

[דירוג](/en/user_manual/polls/rank/) מאפשר למשתתפים לסדר אפשרויות לפי סדר העדפה. ניתן להשתמש בו כדי למצוא את סדר ההעדפה הכולל של הקבוצה או לבחור אפשרות מובילה אחת.

<!-- translation-section: time-poll -->

## סקר זמן

[סקר זמן](/en/user_manual/polls/meeting_polls/) מאפשר למשתתפים לציין מתי הם זמינים. ניתן להשתמש בו כדי לתאם פגישה או אירוע בין אזורי זמן שונים.

<!-- translation-section: stv-election -->

## בחירות STV

[בחירות STV](/en/user_manual/polls/stv/) מאפשרות למשתתפים לדרג מועמדים בבחירות יחסיות שבהן נבחרים כמה מועמדים. ניתן להשתמש ב־STV כדי לבחור ועדה, ועד מנהל או קבוצת נציגים.
