# סימניות

סימניות הן רשימה אישית של פריטים ב-Loomio שרוצים לחזור אליהם. הסימניות גלויות רק למי ששמר אותן, ושמירת פריט אינה שולחת הודעה לאף אחד אחר.

ניתן לשמור סימניות עבור:

- דיונים
- תגובות
- הצעות ומשאלים
- הצבעות
- מסקנות

<!-- translation-section: save-a-bookmark -->

## שמירת סימנייה

יש לפתוח את תפריט הפעולות של הפריט ולבחור **שמור סימניה**. תפריט הפעולות מופיע בדרך כלל כשלוש נקודות. בדיון, יש להשתמש בתפריט שליד כותרת הדיון; בתגובה, בהצבעה, בהצעה, במשאל או במסקנה, יש להשתמש בתפריט של אותו פריט.

![](save_bookmark.png)

<!-- translation-section: view-your-bookmarks -->

## הצגת הסימניות

יש לפתוח את סרגל הצד ולבחור **סימניות**. המספר שליד הקישור מציג כמה סימניות נשמרו.

בדף הסימניות, הפריטים שנשמרו לאחרונה מופיעים ראשונים. בכל שורה מוצגים סוג הפריט ושם מי שיצר אותו. יש לבחור שורה כדי לחזור לפריט שסומן.

![](bookmarks_page.png)

<!-- translation-section: remove-a-bookmark -->

## הסרת סימנייה

בדף הסימניות, יש לבחור בלחצן הסרת הסימנייה שבסוף השורה. ניתן גם לפתוח את תפריט הפעולות של הפריט שסומן ולבחור **הסרת סימנייה**.

הסרת סימנייה משפיעה רק על הרשימה האישית. ניתן לשמור את הפריט שוב בהמשך.
