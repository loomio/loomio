# Loomio 계정 삭제

<!-- translation-section: what-does-delete-account-mean -->

## 계정을 삭제하면 어떻게 되나요?

계정 삭제는 영구적이며 되돌릴 수 없습니다. 계정을 삭제하면 다음과 같이 처리됩니다.

- 이름, 이메일 주소 및 기타 개인 정보를 포함한 계정이 Loomio에서 삭제됩니다. 이 계정으로는 더 이상 로그인할 수 없습니다.
- 작성한 댓글, 제안, 토론은 이름이 삭제된 상태로 남아 그룹의 스레드가 유지됩니다.
- 모든 그룹에서 멤버 자격이 삭제됩니다.
- 더 이상 알림 이메일을 받지 않습니다.

활동 내역의 사본이 이미 그룹 멤버에게 이메일로 전송되었을 수 있습니다. Loomio는 이미 전송된 이메일을 삭제할 수 없습니다.

계정을 삭제해도 유료 구독은 취소되지 않습니다. 결제를 중단하려면 [구독](/en/policy/subscriptions/management#cancel-your-plan)을 참고하세요.

Loomio의 데이터 처리 방식에 관한 자세한 내용은 [개인정보 처리방침](/en/policy/privacy)을 참고하거나 [문의하세요](/contact). 계정을 삭제하기 전에 그룹 기록의 사본이 필요하다면 그룹 관리자가 [그룹 데이터를 내보낼 수 있습니다](/en/user_manual/groups/data_export).

## 계정을 완전히 삭제하는 방법

1. Loomio에 로그인하세요.
2. 사이드바에서 이름을 선택하여 사용자 메뉴를 연 다음 **프로필 수정**을 선택하세요. 사이드바가 닫혀 있으면 메뉴 버튼(**☰**)으로 여세요.

![](profile_edit.png#width-50)

3. 페이지 맨 아래로 스크롤한 다음 **계정 삭제**를 선택하세요.

![](delete_user.png)

4. 계정을 영구적으로 삭제할지 확인하세요.

![](permanently_delete_account.png#width-80)
