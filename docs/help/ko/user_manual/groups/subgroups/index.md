# 하위 그룹

하위 그룹을 사용하면 상위 그룹 안에서 특정 팀이나 주제별로 토론과 멤버를 체계적으로 관리할 수 있습니다. 예를 들어, 조직에서 다음과 같은 하위 그룹을 만들 수 있습니다:

- 이사회
- 실무 팀 또는 프로젝트 그룹
- 전략이나 학습과 같은 주제별 그룹

하위 그룹은 일반 그룹과 같은 방식으로 작동하며, 기능과 설정도 대부분 같습니다. 상위 그룹에 속하지 않아도 이사회와 같은 하위 그룹에 속할 수 있습니다.

<!-- translation-section: add-a-subgroup -->

## 하위 그룹 추가

>[!Note]
>하위 그룹을 추가할 수 있는 사람은 상위 그룹의 [권한 설정](/en/user_manual/groups/settings/permissions)으로 정합니다. 기본적으로 그룹 관리자만 하위 그룹을 만들 수 있습니다.

하위 그룹을 만들려면 상위 그룹 페이지를 열고 사이드바에서 **새 하위 그룹**을 선택한 다음, 이름을 입력하고 공개 범위를 선택한 뒤 **하위 그룹 만들기**를 선택하세요.

![Oatmilk Cooperative 사이드바의 새 하위 그룹 버튼](subgroups-sidebar.png)

![Packaging Working Group의 새 하위 그룹 양식](subgroups_new.png)

하위 그룹이 준비되면 가입할 [사람들을 초대하세요](/en/user_manual/groups/inviting_people). 하위 그룹 페이지의 작업 메뉴에서 하위 그룹의 [그룹 설정](/en/user_manual/groups/settings)을 변경할 수 있습니다.

![Packaging Working Group의 그룹 설정 수정 메뉴](subgroups_edit_group_settings.png)

## 하위 그룹 설정

<!-- translation-section: privacy -->

### 공개 범위

하위 그룹을 찾고 스레드를 읽을 수 있는 사람을 선택하세요:

| 공개 범위 | 그룹을 찾을 수 있는 사람 | 스레드를 읽을 수 있는 사람 |
| --- | --- | --- |
| **개방** | 누구나 | 누구나 |
| **폐쇄** | 누구나 | 하위 그룹 멤버와 초대받은 게스트 |
| **상위 그룹에 공개** | 상위 그룹 멤버와 하위 그룹 멤버 | 하위 그룹 멤버와 초대받은 게스트 |
| **비밀** | 초대받은 하위 그룹 멤버 | 하위 그룹 멤버와 초대받은 게스트 |

**상위 그룹 멤버가 비공개 스레드를 볼 수 있습니다** 권한을 사용하면 상위 그룹 멤버가 하위 그룹에 가입하지 않고도 하위 그룹의 스레드를 읽을 수 있습니다.

상위 그룹이 비공개인 경우 하위 그룹은 **상위 그룹에 공개** 또는 **비밀**로만 설정할 수 있습니다. 자세한 내용은 [그룹 공개 범위](/en/user_manual/groups/settings/privacy)를 참고하세요.

<!-- translation-section: how-people-join -->

### 가입 방법

하위 그룹을 만들 때 또는 **그룹 설정 수정** > **공개 범위**에서 [가입 방법](/en/user_manual/groups/settings/privacy#how-people-join)을 선택하세요.

![하위 그룹의 공개 범위 및 가입 설정](subgroups_privacy_settings.png)

<!-- translation-section: permissions -->

### 권한

상위 그룹 멤버가 하위 그룹에 가입하지 않고도 하위 그룹의 스레드를 읽을 수 있도록 하려면 **권한**에서 **상위 그룹 멤버가 비공개 스레드를 볼 수 있습니다**를 활성화하세요. 이 권한으로 스레드를 읽는 사람에게는 투표권이나 하위 그룹 멤버 자격이 부여되지 않습니다.

![상위 그룹 멤버가 하위 그룹의 비공개 스레드를 볼 수 있도록 하는 설정](subgroups_private_threads_settings.png)

사이드바에서 상위 그룹 이름을 선택하면 해당 그룹의 하위 그룹을 볼 수 있습니다.

![사이드바에 표시된 Oatmilk Cooperative의 하위 그룹 목록](subgroups_find_subgroups.png)

## 하위 그룹에 초대

상위 그룹에 초대하는 것과 같은 방법으로 [하위 그룹에 사람들을 초대할 수 있습니다](/en/user_manual/groups/inviting_people). 초대할 사람이 이미 상위 그룹이나 본인이 속한 다른 하위 그룹의 멤버라면, 이름을 입력하거나 해당 그룹을 선택한 다음 개별 사람들로 펼쳐 초대하지 않을 사람을 제외하세요.

<!-- translation-section: simultaneously-invite-people-to-subgroups-and-parent-group -->

### 하위 그룹과 상위 그룹에 동시에 초대

상위 그룹의 **멤버** 탭에서 **초대**를 선택할 때, 초대받은 사람들이 동시에 가입할 하위 그룹의 체크박스를 선택하세요.

![초대 양식에서 상위 그룹과 하위 그룹 선택](group_invite_email_subgroups.png)

## 하위 그룹 관리

하위 그룹에는 상위 그룹의 그룹 관리자와 별도로 자체 그룹 관리자를 둘 수 있습니다.

상위 그룹 관리자는 비밀이 아닌 모든 하위 그룹에 가입하여 자신을 해당 하위 그룹의 그룹 관리자로 지정할 수 있습니다. 비밀 하위 그룹에는 적용되지 않습니다. 자세한 내용은 [하위 그룹 관리](/en/user_manual/groups/member_management#managing-subgroups)를 참고하세요.

![폐쇄 하위 그룹의 그룹 가입 버튼](member_join_subgroup.png)

![상위 그룹 관리자가 자신을 하위 그룹 관리자로 지정하는 메뉴](member_make_admin.png)

<!-- translation-section: delete-a-subgroup -->

## 하위 그룹 삭제

그룹 관리자는 [그룹을 삭제](/en/user_manual/groups/deleting_your_group)하는 것과 같은 방법으로 하위 그룹을 삭제할 수 있습니다. 삭제하기 전에 상위 그룹 페이지가 아닌 하위 그룹 페이지에 있는지 확인하세요.
