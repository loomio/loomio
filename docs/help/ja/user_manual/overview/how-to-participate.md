# 参加方法

招待されたLoomioのグループにサインインすると、ディスカッションや意思決定に参加できます。

ここでは、スレッドにコメントを書く方法と、アンケートに投票する方法を説明します。

<!-- translation-section: comment -->

## コメント

スレッドにコメントを書くと、ほかの人が返信やリアクションをしたり、コメントを投稿したりして、ディスカッションを続けられます。

文章を書いたら、**コメントを投稿**を選択すると、すぐにコメントが公開されます。コメントは、そのスレッドを閲覧する権限があるすべての人に表示されます。

![](comment_add.png#width-90)

<!-- translation-section: reply-to-a-comment -->

### コメントに返信する

コメントの下にある返信アイコンをクリックすると、そのコメントに返信できます。

返信はスレッドに公開され、元のコメントの投稿者にメール通知が送られます。

![](comment_reply.png#width-90)

<!-- translation-section: get-someone-s-attention -->

### 相手に知らせる

コメントを書くときに、ほかの人に通知できます。

![](comment_mention.png#width-90)

<!-- translation-section: reactions -->

### リアクション

コメントへのリアクションは、投稿者に気持ちを伝え、コメントを受け止めたことや支持する気持ちを示す方法です。文章を書く必要がなく、メールも送信されないため、手軽に参加できます。コメントの下にある笑顔の絵文字アイコンをクリックすると、絵文字でリアクションできます。

![](comment_reaction.png#width-90)

<!-- translation-section: vote -->

## 投票する

メールやLoomio内の通知で、アンケートへの投票の招待が届くことがあります。メール内のリンクをクリックすると、投票できます。

投票は簡単です。希望する選択肢のアイコンをクリックまたはタップします。

アンケートにはさまざまな種類があります。以下の例は、**賛成**、**棄権**、**反対**を選択肢とする一般的な提案です。ほかの選択肢が用意されている場合もあります。

アンケートと添付ファイルを読んでから、選択肢を1つ選んで投票します。

![](proposal_example.png#width-90)

<!-- translation-section: state-a-reason -->

### 理由を書く

投票するときに、その選択肢を選んだ**理由**を書くこともできます。理由の記入は任意です。

![](vote_reason.png#width-90)

<!-- translation-section: change-your-vote -->

### 投票を変更する

提案が締め切られるまでは、**投票を変更**できます。

![](vote_change.png#width-90)

投票を変更する理由はさまざまです。例えば、新しい情報が明らかになったことで、決定を見直し、投票を変更することがあります。

変更するときも、その理由を書くことができます。

![](vote_edit.png#width-90)

<!-- translation-section: results -->

### 結果

提案の結果は投票のたびに更新されるため、投票の傾向を確認できます。

![](proposal_results.png#width-90)

意見が分かれる提案では、投票結果も分かれることがよくありますが、それだけで提案が失敗したことにはなりません。

提案について検討する中で明らかになった新しい情報は、より賛成を得やすい、改善された提案を作るのに役立つことがあります。

<!-- translation-section: outcome -->

### 結論

提案が締め切られると、作成者は**結論**を記入するよう求められます。

これは、何が決まったかを記録し、次に何が行われるかを全員に知らせるための重要な最後の手順です。

![](proposal_outcome.png#width-90)
