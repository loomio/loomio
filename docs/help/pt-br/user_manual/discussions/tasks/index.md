# Atribua e acompanhe tarefas

Use tarefas em conversas e comentários para indicar uma ação, atribuí-la a alguém, definir uma data de vencimento e acompanhar se ela foi concluída.

<!-- translation-section: add-a-task -->

## Adicionar uma tarefa

Ao escrever uma conversa ou um comentário, expanda a barra de ferramentas de formatação e clique em **Lista de tarefas**. Digite a ação ao lado da caixa de seleção.

![](tasklist1.png)

<!-- translation-section: name-and-assign-the-task-to-a-person -->

## Nomear e atribuir a tarefa a uma pessoa

Use uma @menção na tarefa para atribuí-la a um membro do grupo. O botão **Adicionar data de vencimento** aparece quando a tarefa tem uma pessoa responsável.

![](tasklist2.png)

Abra **Tarefas** em **Todos os grupos** para ver as tarefas atribuídas a você em todos os seus grupos, ou abra **Tarefas** na página de um grupo para ver as tarefas desse grupo. As tarefas são agrupadas por conversa ou enquete, e você pode filtrá-las por status (**A fazer**, **Concluídas** ou **Todas**), data de vencimento (**Atrasadas**, **Próximos 7 dias**, **Mais tarde** ou **Sem data de vencimento**), pessoa responsável (na página de um grupo), subgrupo, tag de categoria ou busca.

![](task_list.png)

<!-- translation-section: set-a-reminder -->

## Definir um lembrete

Clique em **Adicionar data de vencimento** para escolher uma data de vencimento e quando o Loomio deve enviar um lembrete por e-mail à pessoa responsável. Você também pode remover uma data de vencimento existente nessa janela.

![](taskreminderform.png)

<!-- translation-section: mark-it-as-done -->

## Marcar como concluída

![](taskdone.png)

Clique na caixa de seleção ao lado de uma tarefa para marcá-la como concluída. Você pode fazer isso ao editar o texto, ao lê-lo se você for a pessoa responsável pela tarefa, ou na página **Tarefas**. Clique novamente na caixa de seleção para reabrir a tarefa.
