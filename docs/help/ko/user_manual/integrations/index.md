# 연동

Loomio를 그룹에서 사용하는 다른 도구와 연결하세요.

<!-- translation-section: choose-where-work-belongs -->

## 업무에 맞는 도구 선택

Loomio는 모든 종류의 업무 도구를 대체하기보다 채팅, 공유 문서, 할 일 관리 도구를 보완합니다.

| 업무 | 권장 도구 |
|---|---|
| 간단한 질문, 일상 대화, 시의적절한 소식 공유 | 채팅 |
| 지속적으로 수정하는 문서의 공동 편집 | 공유 문서 |
| 할 일 배정 및 진행 상황 추적 | 프로젝트 또는 할 일 관리 도구 |
| 중요한 주제별 토론, 폭넓은 참여, 결정 및 결론 | Loomio |

주제를 검토할 시간이 필요하거나, 영향을 받는 모든 사람에게 의미 있게 참여할 기회를 제공해야 하거나, 그룹에서 나중에 토론과 결정을 다시 찾아봐야 할 때는 Loomio에서 업무를 진행하세요. 관련 배경을 쉽게 찾을 수 있도록 Loomio 토론에 해당 문서나 할 일의 링크를 추가하세요.
