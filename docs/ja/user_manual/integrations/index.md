# 連携

Loomioをグループで使っているほかのツールと連携できます。

<!-- translation-section: choose-where-work-belongs -->

## 作業に合ったツールを選ぶ

Loomioはあらゆる作業を置き換えるものではなく、チャット、共有ドキュメント、タスク管理ツールを補完します。

| 作業 | 推奨ツール |
|---|---|
| 簡単な質問、雑談、タイムリーな情報共有 | チャット |
| 継続的に更新するドキュメントの共同編集 | 共有ドキュメント |
| タスクの割り当てと進捗管理 | プロジェクト管理ツールまたはタスク管理ツール |
| 重要なテーマについてのディスカッション、幅広い参加、決定、結論 | Loomio |

テーマについて考える時間が必要な場合、影響を受ける全員に十分な参加の機会を設ける必要がある場合、またはグループで後からディスカッションや決定を見つける必要がある場合は、Loomioを使います。関連するドキュメントやタスクへのリンクをLoomioのディスカッションに追加すると、その背景説明を簡単に確認できます。

<!-- translation-section: chat-integrations -->

## チャット連携

[チャット連携](/en/user_manual/integrations/chatbots)は、Discord、Matrix、Mattermost、Microsoft Teams、SlackなどのチャットサービスにLoomioのアクティビティを投稿します。

<!-- translation-section: api -->

## API

[Loomio API](/en/user_manual/integrations/api)を使うと、独自のソフトウェアや自動化したワークフローとLoomioを連携できます。
