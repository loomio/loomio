# Інтеграція з Mattermost

Loomio може надсилати сповіщення у ваші канали Mattermost, коли з’являються нові обговорення, опитування, коментарі, голоси та висновки.

---

1. Відкрийте свою команду Mattermost у браузері та перейдіть до розділу **Інтеграція**.

   ![](mm1.png)

2. Виберіть **Вхідні вебхуки**.

   ![](mm2.png)

3. Виберіть **Додати вхідний вебхук**.

   ![](mm3.png)

4. Укажіть назву, виберіть канал, у якому мають з’являтися сповіщення, і виберіть **Зберегти**.

   ![](mm4.png)

5. Скопіюйте URL вебхука.

   ![](mm5.png)

Тепер, коли у вас є URL вебхука, завершіть його підключення в Loomio:

[Налаштуйте інтеграцію з чатом у Loomio](../chatbots/#set-up-a-chat-integration)
