# ディスカッションを進める

会議と会議の間に、理事会や委員会のメンバーによる対応が必要な話題が生じることがあります。

また、会議中にはディスカッションや決定に向けた十分な検討の時間を確保できないこともあります。

<!-- translation-section: on-loomio -->

## Loomioで進める

Loomioの**スレッド**を使ってディスカッションを進めます。メンバーが内容を把握できる具体的なタイトルを付け、スレッドの背景説明に詳細を記載します。関連するカテゴリーのタグを付けると、メンバーが後からスレッドを見つけやすくなります。

メンバーをスレッドに招待すると、スレッドの内容がメールで届きます。メンバーはリンクをクリックしてLoomioでディスカッションに参加できます。また、通知メールに返信すると、その内容がスレッドにコメントとして表示されます。

![](thread_discussion.png#width-90)

Loomioのスレッドには、ディスカッションに役立つファイルを添付したり、オンラインの資料へのリンクを追加したりできます。

よくある活用例には、次のようなものがあります。
- 方針を見直し、策定します
- 話題や課題について理事会に助言を求めます
- 戦略について話し合います
- アイデアや機会を検討します
- リスクを評価します

## 理事会の会議と会議の間に生じる課題

会議と会議の間には組織内でさまざまなことが起こり、多くの人がメールで理事会のメンバーに知らせています。メールでディスカッションの流れを追うのは難しく、返信が受信トレイに埋もれたり、一部の人に情報が届かなかったりすることがよくあります。

*「メールではガバナンスを行えません！」リチャード・ウェストレイク（Westlake Governance）*

理事会の対応が必要な課題が生じた場合は、メールの代わりにLoomioのスレッドを使います。メンバーがメールで返信すると、その内容がLoomioのスレッドにコメントとして表示されるため、ディスカッションを一か所にまとめられます。

手順は次のとおりです。
- メールの件名をスレッドのタイトルにします
- メールの本文をスレッドの背景説明に記載します
- メールアドレスまたはLoomioのユーザー名を使って、チームのメンバーをスレッドに招待します

Loomioのスレッドを使うと、次のことができます。
- 話題に関するすべての情報を、アクセスしやすい一か所に整理できます
- 一部の人に情報が届かなくなるおそれのある「返信」や「全員に返信」のメールの連鎖を生じさせずに、返信できます
- 誰がメッセージを読んだか、誰に確認を促す必要があるかを把握できます
- 実際の作業を結論に向けて進め、メールの量を減らせます

## 会議中に時間を確保できない場合

理事会の会議で、限られた時間内に議題を解決できない場合は、Loomioに移してディスカッションを続けられます。関連するスレッドを案内するか、新しいスレッドを作成して理事会のメンバーに通知します。

これにより理事会の負担が軽減され、情報収集やディスカッション、より深い検討に時間をかけられるため、よりよい決定につながることが多くあります。
