# グループ設定

グループ設定では、グループの表示内容、グループを見つけて参加できる人、メンバーが行える操作を設定します。これらの設定を編集できるのは、グループ管理者のみです。

グループページで操作メニューを開き、**グループ設定を編集する**を選択します。

![グループページからグループ設定を編集する](group_settings.png)

設定フォームは、次の3つの項目に分かれています：

<!-- translation-section: group-profile -->

## グループプロフィール

[グループプロフィール](/en/user_manual/groups/settings/profile)では、グループ名、ハンドル、説明、カバー画像、ロゴを設定します。

<!-- translation-section: group-privacy -->

## グループのプライバシー

[グループのプライバシー](/en/user_manual/groups/settings/privacy)では、グループを見つけられる人、コンテンツを閲覧できる人、参加方法、ディレクトリへの掲載、公開グループのフォローについて設定します。

<!-- translation-section: group-permissions -->

## グループの権限

[グループの権限](/en/user_manual/groups/settings/permissions)では、メンバー、メンバー以外の人、管理者が行える操作を設定します。
