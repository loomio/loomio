# Выборы STV

**Единый передаваемый голос (STV)** — метод пропорционального голосования для избрания нескольких кандидатов. Он помогает распределить места в соответствии с разными взглядами избирателей.

<!-- translation-section: when-to-use-stv -->

## Когда использовать STV

Используйте выборы STV, если вам нужно:

- Избрать **комитет, совет или группу делегатов** из числа выдвинутых кандидатов
- Обеспечить **пропорциональное представительство**, чтобы группы меньшинства получили места соразмерно своей поддержке
- Провести выборы, на которых избиратели располагают кандидатов в порядке предпочтения

>[!NOTE]
>STV отличается от [рейтингового голосования](/en/user_manual/polls/rank/) в Loomio. В рейтинговом голосовании варианты получают баллы, чтобы выбрать один лучший вариант. STV позволяет избрать нескольких кандидатов с передачей голосов и раундами исключения.

<!-- translation-section: creating-an-stv-election -->

## Как создать выборы STV

При создании голосования выберите тип **Выборы STV**, затем добавьте кандидатов в качестве вариантов. Вы можете задать **количество мест**, **метод подсчёта** и **тип квоты**.

В этом примере кооператив Oatmilk выбирает трёх человек для наблюдения за испытанием возвратной упаковки. В форме описана их роль, перечислены пять кандидатов и выбраны метод Scottish STV и квота Droop.

![](form.png)

<!-- translation-section: number-of-seats -->

### Количество мест

Укажите, сколько человек нужно избрать. Мест должно быть меньше, чем кандидатов.

<!-- translation-section: counting-method -->

### Метод подсчёта

Доступны два метода подсчёта голосов:

Scottish STV
  : Рекомендуемый метод. Взвешенный инклюзивный метод Грегори (WIGM), который используется на местных выборах в Шотландии с 2007 года. У него чёткие и простые правила. Подходит большинству организаций.
  
Meek STV
  : Более точный метод, подсчёт по которому возможен только на компьютере. После избрания кандидата метод Meek продолжает передавать ненужную ему часть каждого голоса следующим по предпочтению кандидатам, в том числе для голосов, которые поступают ему позднее в ходе подсчёта. Когда кандидат выбывает, голоса пересчитываются так, как если бы он не участвовал в выборах. По сравнению с Scottish STV меньше голосов остаётся неиспользованными, но проверить подсчёт вручную невозможно.

<!-- translation-section: quota-type -->

### Тип квоты

Квота — минимальное число голосов, необходимое кандидату для получения места. Доступны два типа:

Droop
  : Рекомендуемая квота. Стандартная квота для выборов STV, используемая в Ирландии, Австралии и Шотландии. Это наименьшая квота, которую не может достичь больше кандидатов, чем имеется мест. Группа избирателей, ставящих своих кандидатов на первые места, получает как минимум столько мест, сколько полных квот содержится в её голосах. Она рассчитывается так:
\\[ floor(\frac{votes}{(seats + 1)}) + 1 \\]

Hare
  : Более высокая квота. Группы с большим числом голосов расходуют больше голосов на каждое полученное место, поэтому у небольших групп больше шансов получить последние места. Она рассчитывается так:
    \\[ \frac{votes}{seats}\\]

В обеих формулах *votes* — число бюллетеней, в которых указан хотя бы один кандидат в порядке предпочтения.

Метод Meek STV рассчитывает квоту без округления: для Droop это votes ÷ (seats + 1). В каждом раунде квота пересчитывается на основе голосов, которые ещё учитываются у кандидатов. Для избрания кандидат должен превысить квоту.
  
  >[!TIP]
  > Квота Droop всегда требует меньше голосов, чем квота Hare. Например, при 100 голосах и четырёх местах квота Droop составит 21 голос, а квота Hare — 25 голосов.

<!-- translation-section: how-voting-works -->

## Как проходит голосование

В этом примере кооператив Oatmilk выбирает трёх человек для наблюдения за испытанием многоразовой упаковки. Избиратели перетаскивают кандидатов выше линии и располагают их в порядке предпочтения:

![](stv-vote-in-progress.png)

- **Ранг 1** = наиболее предпочтительный кандидат
- **Ранг 2** = второй по предпочтению кандидат
- Вы можете ранжировать столько кандидатов, сколько хотите

Избиратели должны ранжировать хотя бы одного кандидата, но ранжировать всех кандидатов необязательно. Кандидаты без ранга не получат никакой поддержки от этого избирателя.

<!-- translation-section: how-counting-works -->

## Как подсчитываются голоса
Подсчёт проходит следующим образом:

1. Рассчитывается **квота** (минимальное число голосов для получения места).
2. Для каждого кандидата подсчитываются **Первые предпочтения**.
3. Каждый кандидат, достигший квоты, **избирается**. Его излишек голосов (сверх квоты) **передаётся** следующим по предпочтению кандидатам с дробным весом, начиная с наибольшего излишка. Голоса передаются только кандидатам, которые ещё участвуют в подсчёте.
4. Если излишков для передачи не осталось, кандидат с **наименьшим числом голосов выбывает**. Его голоса передаются следующим по предпочтению кандидатам с полным весом.
5. Когда число оставшихся кандидатов равно числу оставшихся мест, все они избираются, даже если не достигли квоты.
6. В остальных случаях подсчёт повторяется с шага 3, пока все места не будут заполнены.

Дробный вес позволяет распределить только ту часть голосов, которая не нужна избранному кандидату. Например, если квота составляет 26, а у кандидата 40 голосов, его излишек равен 14. Каждый из его 40 бюллетеней передаётся следующему по предпочтению кандидату с весом 14 ÷ 40 = 0.35 голоса.

В методе Scottish STV вес каждого передаваемого голоса округляется вниз до пяти знаков после запятой, как на выборах в местные советы Шотландии.

Если у двух или более кандидатов наименьшее число голосов одинаково, выбывает тот, у кого было меньше голосов в последнем из предыдущих раундов, в котором их число различалось.

>[!TIP]
>Бюллетень учитывается, пока в нём есть ранжированный кандидат, который ещё участвует в подсчёте. Когда таких кандидатов не остаётся, бюллетень считается «исчерпанным» и больше не учитывается.

### Метод и квота

Вверху указаны метод подсчёта (Scottish STV или Meek STV), тип квоты (Droop или Hare) и сама квота — число голосов, необходимое кандидату для получения места.

<!-- translation-section: elected-candidates -->

### Избранные кандидаты

Сводная таблица избранных кандидатов состоит из пяти столбцов:

| Столбец | Значение |
|--------|---------|
| **Кандидат** | Имя избранного кандидата |
| **Раунд избран** | Раунд подсчёта, в котором кандидат достиг квоты и получил место. Раунд 1 означает, что ему хватило первых предпочтений. В последующих раундах для избрания понадобились голоса, переданные от выбывших кандидатов или излишек голосов избранных кандидатов. |
| **Первые предпочтения** | Число избирателей, поставивших кандидата на первое место. Показывает прямую поддержку до передачи голосов. |
| **Итоговый результат** | Число голосов у кандидата в момент избрания. После передачи голосов оно часто превышает число первых предпочтений. |
| **Излишек** | Число голосов сверх квоты в момент избрания: итоговый результат минус квота. Чем больше излишек, тем выше поддержка сверх необходимой для избрания. В методе Scottish STV излишек перераспределяется следующим по предпочтению кандидатам. |

Иногда сравнение результатов предыдущих раундов не позволяет разрешить ничью. Если ничья не влияет на то, кто будет избран, подсчёт продолжается. Если влияет, подсчёт останавливается на этом раунде. Кандидаты, которые побеждают при любом разрешении ничьей, показываются как избранные. Кандидаты, которые могут победить или проиграть в зависимости от разрешения ничьей, показываются в отдельной таблице. Loomio показывает у них ничью вместо того, чтобы выбирать одного из них случайным образом.

<!-- translation-section: round-by-round-details -->

### Подробности по каждому раунду

Разверните **Подробности по каждому раунду**, чтобы увидеть передачу голосов и исключение кандидатов. Каждая строка соответствует кандидату, а каждый столбец — раунду подсчёта. Каждое число показывает, сколько голосов было у кандидата в начале этого раунда:

![](stv-results.png)

Зелёная подсветка показывает, когда кандидат был избран, красная — когда он выбыл, а оранжевая — когда возникла ничья.

## Опубликуйте заключение

Когда выборы завершатся, опубликуйте заключение. Назовите избранных людей и укажите, когда они приступят к своим обязанностям. Подробнее о заключениях см. в разделе [Опубликуйте заключение](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome).

## Экспорт бюллетеней

После закрытия выборов люди с доступом к результатам могут экспортировать бюллетени в формате BLT для независимого пересчёта или проверки. Экспорт содержит порядок предпочтения кандидатов. Одинаковые варианты ранжирования объединяются в одну строку с числом бюллетеней. Для анонимных выборов экспорт не содержит имён избирателей, идентификаторов бюллетеней, времени отправки или порядка отправки.
