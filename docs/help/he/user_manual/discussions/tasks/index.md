# הקצאת משימות ומעקב אחריהן

ניתן להשתמש במשימות בשרשורים ובתגובות כדי להגדיר פעולה, להקצות אותה לאדם מסוים, לקבוע תאריך יעד ולעקוב אחר השלמתה.

## הוספת משימה

בעת כתיבת שרשור או תגובה, יש להרחיב את סרגל העיצוב וללחוץ על **רשימת מטלות**. יש להקליד את הפעולה לצד תיבת הסימון.

## הגדרת המשימה והקצאתה לאדם

יש להשתמש באזכור באמצעות @ בתוך המשימה כדי להקצות אותה לחבר בקבוצה. הכפתור **הוסף תאריך יעד** מופיע לאחר שהמשימה הוקצתה לאדם מסוים.

![](tasklist2.png)

לצפייה במשימות שהוקצו לך בכל הקבוצות שלך, יש לפתוח את **משימות** תחת **כל הקבוצות**. לצפייה במשימות בקבוצה מסוימת, יש לפתוח את **משימות** בדף הקבוצה. המשימות מקובצות לפי שרשור או סקר, וניתן לסנן אותן לפי מצב (**לביצוע**, **בוצע** או **הכל**), תאריך יעד (**באיחור**, **ב־7 הימים הקרובים**, **בהמשך** או **ללא תאריך יעד**), האדם שהמשימה הוקצתה לו (בדף קבוצה), תת־קבוצה, תגית קטגוריה או חיפוש.

![](task_list.png)
