# בעלי זכות הצבעה כנציגים

אם לחלק מחברי הקבוצה צריכה להיות זכות הצבעה ולאחרים לא, ניתן להשתמש בפעולה "לעשות נציג" כדי לסמן את בעלי זכות ההצבעה. קיימת גם פעולה מקבילה: "בטל נציג".

ניתן להשתמש בנציגים כשנדרש מרחב דיון משותף, אך רק לקבוצה מוגדרת של אנשים, כגון חברי דירקטוריון או נציגים נבחרים, מותר להצביע. בדרך כלל זה פשוט יותר מניהול תת־קבוצה נוספת שמטרתה היחידה היא להפריד בין מצביעים למי שאינם מצביעים.

יש להשתמש בתת־קבוצה פרטית כאשר חבריה זקוקים גם לדיונים, לקבצים או למידע על החברות בקבוצה שאין לחשוף בפני חברים אחרים.

בדף הקבוצה יש לפתוח את **חברים**, למצוא את האדם הרצוי ולבחור **לעשות נציג** מתפריט שלוש הנקודות שלצד השם. להסרת ההגדרה יש לבחור **בטל נציג** באותו תפריט.

![הפעולה לעשות נציג בתפריט של חבר בקבוצה](member_make_delegate.png)

כדי ליצור סקר או הצעה ולהזמין רק את הנציגים, יש להשתמש בהגדרת הסקר "אנשים נבחרים בלבד".
![ההגדרה אנשים נבחרים בלבד בעת יצירת הצעה](poll_invited_people_only.png)
לאחר מכן, בעת הזמנת אנשים להצביע, תופיע האפשרות "נציגי שם־הקבוצה".
![האפשרות נציגי קואופרטיב חלב שיבולת שועל בטופס ההזמנה להצבעה](poll_invite_delegates_group.png)

ניתן לראות את רשימת הנציגים בלשונית החברים בדף הקבוצה. יש לפתוח את תפריט הסינון ולבחור "נציגים".
