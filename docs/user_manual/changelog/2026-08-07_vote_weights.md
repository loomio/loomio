# Vote weights

Poll coordinators can enable vote weights in a poll's advanced settings before voting opens. Group administrators can set a default vote weight for each group member. The default is copied to the member's vote when they are added to a poll with vote weights enabled. Changing a membership weight does not change existing polls.

Poll coordinators can adjust the copied weights until the poll closes. Weights are whole numbers. A weight of `0` lets someone participate and records their vote in the voter count without adding their choices to the score.

Weighted results show both the number of voters and the weighted score. Voter avatars show their weights in the results table, and the votes page shows each person's vote and weight. Anonymous polls and STV elections do not support vote weights.
