# Consenso

Una propuesta de Consenso busca el acuerdo colectivo de todas las personas involucradas. Las respuestas predeterminadas permiten a los participantes estar de acuerdo, abstenerse, estar en desacuerdo o bloquear.

Esta página explica cómo llevar a cabo una propuesta de Consenso. Consulta el [Proceso de consenso](/en/guides/making_decisions/consensus_process) para conocer el proceso completo, desde la discusión y la toma de pulso hasta las modificaciones y la conclusión.

<!-- translation-section: when-to-use-consensus -->

## Cuándo usar Consenso

Usa Consenso para decisiones en las que sea importante que muchas personas las asuman como propias y el grupo esté dispuesto a abordar las preocupaciones en conjunto. Es adecuado para normas compartidas, acuerdos de gobernanza, compromisos estratégicos y decisiones que afectan a todo el grupo.

El consenso suele requerir una discusión y la elaboración de una propuesta antes de votar. Define el significado y las consecuencias de **Bloquear** para tu grupo. Si tu proceso no utiliza bloqueos, edita la plantilla para eliminar esa opción.

## Ejemplo: adoptar una norma de devolución de botellas

La cooperativa Oatmilk ha elaborado una norma que abarca los depósitos, la recogida, el lavado, los registros de seguridad alimentaria y la presentación de informes. Como todos los equipos la utilizarán, la cooperativa busca el consenso antes de adoptarla.

<!-- translation-section: set-up-the-proposal -->

## Configura la propuesta

Expón el acuerdo completo que se está considerando y añade enlaces a la información de apoyo. Explica cada respuesta, especialmente la diferencia entre estar en desacuerdo y bloquear. Deja tiempo suficiente para preguntas y modificaciones.

![](form.png)

<!-- translation-section: vote -->

## Vota

Los participantes eligen la respuesta que corresponde a su postura y explican los intereses o las preocupaciones que la motivan. El motivo de un bloqueo debe indicar por qué adoptar la propuesta vulneraría una necesidad fundamental o un principio acordado.

## Lee los resultados

El gráfico muestra la distribución de las respuestas. Revisa los motivos de cada respuesta de desacuerdo y de cada bloqueo; el consenso es un proceso para resolver preocupaciones, no solo para contar los votos de acuerdo.

<!-- translation-section: share-an-outcome -->

## Comparte una conclusión

Cuando se cierre la propuesta, comparte una conclusión. Si el grupo llegó a un acuerdo, registra el acuerdo final y quién se responsabiliza de llevarlo a cabo. En caso contrario, registra qué se revisará y cuándo el grupo retomará la propuesta. Consulta [Comparte una conclusión](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome) para saber cómo funcionan las conclusiones.
