# Опросы

Опросы собирают выбранные варианты, оценки, распределения баллов, предпочтения по порядку, сведения о доступном времени или избирательные бюллетени. Выберите способ голосования в зависимости от того, что участникам нужно выразить и как вы намерены использовать результат. Используйте [предложение](/en/user_manual/polls/proposals/), когда людям нужно выразить своё отношение к утверждению или плану действий.

| Что вы хотите сделать | Способ голосования | Как формируется результат |
| --- | --- | --- |
| Найти популярные варианты или составить короткий список | [Выбор](/en/user_manual/polls/choose) (выбор из нескольких вариантов) | Подсчитывается, сколько раз выбран каждый вариант |
| Сравнить степень поддержки вариантов | [Оценка](/en/user_manual/polls/score) | Объединяются оценки по общей шкале |
| Определить приоритеты с ограниченным количеством баллов | [Распределение](/en/user_manual/polls/allocate) (распределение баллов) | Суммируются баллы, отданные каждому варианту |
| Расположить варианты в порядке предпочтения | [Ранжирование](/en/user_manual/polls/rank) (ранжирование) | На основе ранжирований формируется порядок по сумме баллов |
| Найти время для встречи | [Опрос времени](/en/user_manual/polls/meeting_polls) | Показывается, кто доступен в каждое из предложенных времён |
| Избрать нескольких представителей по принципу пропорционального представительства | [Выборы STV](/en/user_manual/polls/stv) | Подсчитываются бюллетени с ранжированными кандидатами для избрания нескольких победителей |

## Простой опрос

[Выбор](/en/user_manual/polls/choose/) позволяет участникам выбрать один или несколько вариантов. Используйте его, чтобы найти самый популярный вариант или составить короткий список.

<!-- translation-section: score-poll -->

## Оценка

[Оценка](/en/user_manual/polls/score/) позволяет участникам оценить каждый вариант по одной и той же шкале. Используйте её, чтобы сравнить степень поддержки, готовности, пригодности или важности разных вариантов.

<!-- translation-section: dot-vote -->

## Распределение баллов

[Распределение](/en/user_manual/polls/allocate/) даёт каждому участнику фиксированное количество баллов для распределения. Используйте его, чтобы определить приоритеты, когда выбор одного означает, что другому достанется меньше внимания или ресурсов.

<!-- translation-section: ranked-choice -->

## Ранжирование

[Ранжирование](/en/user_manual/polls/rank/) позволяет участникам расположить варианты в порядке предпочтения. Используйте его, чтобы определить общий порядок предпочтений группы или выбрать один наиболее предпочтительный вариант.

<!-- translation-section: time-poll -->

## Опрос времени

[Опрос времени](/en/user_manual/polls/meeting_polls/) позволяет участникам указать, когда они свободны. Используйте его, чтобы назначить время встречи или мероприятия с учётом разных часовых поясов.

<!-- translation-section: stv-election -->

## Выборы STV

[Выборы STV](/en/user_manual/polls/stv/) позволяют участникам расположить кандидатов в порядке предпочтения на выборах с пропорциональным представительством и несколькими победителями. Используйте STV, чтобы избрать комитет, правление или группу делегатов.
