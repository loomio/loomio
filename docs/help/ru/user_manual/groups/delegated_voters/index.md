# Делегаты с правом голоса

Назначайте делегатов, когда все участники группы должны обсуждать вопросы в общем пространстве, но голосовать должен только определённый круг участников, например директора или избранные представители. Это проще, чем поддерживать отдельную подгруппу только для того, чтобы отделить голосующих от остальных участников.

Используйте закрытую подгруппу, если этим участникам также нужны обсуждения, файлы или список участников, которые не должны видеть другие участники группы.

Только администратор группы может назначить или снять статус делегата. На вкладке **Участники** на странице вашей группы откройте меню действий рядом с именем человека и выберите **Сделать делегатом**. Чтобы снять статус делегата, выберите **Отозвать делегата** в том же меню.

![Действие «Сделать делегатом» в меню участника](member_make_delegate.png)

Чтобы создать опрос или предложение, в котором могут голосовать только делегаты, выберите **Только для избранных** в настройках опроса.

![Настройка «Только для избранных» при создании предложения](poll_invited_people_only.png)

При выборе людей, которых вы хотите пригласить голосовать, выберите **Делегаты группы [название группы]**.

![Вариант «Делегаты Oatmilk Cooperative» в форме приглашения голосовать](poll_invite_delegates_group.png)

Чтобы посмотреть всех делегатов группы, откройте вкладку **Участники** и выберите **Делегаты** в меню фильтра.

![Вариант «Делегаты» в фильтре списка участников](members_list_delegates.png)
