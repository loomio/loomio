# Profile bios and usernames

Profile introductions entered with the rich-text editor are now included when you update your profile. Saving no longer clears the introduction or ignores rich-text changes.

Usernames can now contain underscores and internal hyphens. This applies to profile changes, SSO-managed usernames, and API updates; usernames remain limited to 30 lower case letters, numbers, underscores, and hyphens between other characters.
