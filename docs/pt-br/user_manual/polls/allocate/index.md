# Distribuir

Distribuir, às vezes chamado de enquete de distribuição, revela prioridades quando é preciso fazer escolhas entre alternativas. Cada participante recebe uma quantidade fixa de pontos e os distribui entre as opções. Dar mais pontos a uma opção deixa menos pontos para as outras.

<!-- translation-section: when-to-use-allocate -->

## Quando usar Distribuir

Use Distribuir quando o tempo, o dinheiro, a atenção ou outro recurso for limitado. Funciona bem para:

- priorizar o trabalho para o próximo período de planejamento;
- dividir um orçamento participativo entre projetos;
- escolher quanto tempo da pauta dedicar a vários assuntos;
- distribuir uma quantidade fixa de horas de trabalho voluntário; ou
- identificar quais melhorias são mais importantes para os membros.

Os pontos expressam a prioridade relativa, não uma quantidade que o Loomio atribuirá automaticamente. Use [Pontuar](/en/user_manual/polls/score/) quando cada opção puder receber uma avaliação alta sem reduzir o apoio a outra.

<!-- translation-section: example-set-priorities-for-an-annual-strategy-review -->

## Exemplo: definir prioridades para uma revisão anual da estratégia

A Cooperativa Oatmilk está planejando sua revisão anual da estratégia. Ela pergunta aos membros quais áreas devem receber mais tempo e atenção durante a revisão. Cada membro recebe dez pontos para distribuir entre cinco áreas. Isso mostra as prioridades relativas do grupo e exige que os participantes façam escolhas entre alternativas.

<!-- translation-section: set-up-the-poll -->

## Configure a enquete

Descreva a decisão e o que os pontos representam. Adicione opções com abrangência semelhante e defina **Pontos por pessoa**. Neste exemplo, cada eleitor recebe dez pontos para indicar quanto tempo de revisão cada área estratégica deve receber.

![](form.png)

Uma quantidade muito grande de pontos pode criar uma falsa precisão. Uma quantidade útil costuma ser suficiente para mostrar diferenças, mas pequena o bastante para exigir escolhas. Deixe claro se é aceitável concentrar todos os pontos em uma única opção.

<!-- translation-section: vote -->

## Vote

Os participantes movem os controles deslizantes para distribuir seus pontos. O Loomio mostra quantos pontos restam e impede o envio até que a distribuição seja válida.

![](voting.png)

Neste exemplo, o eleitor atribui três pontos a **Participação dos membros** e três a **Sustentabilidade financeira**, dois a **Impacto ambiental** e dois a **Desenvolvimento da equipe**, e nenhum a **Produtos e serviços**. Um zero não significa necessariamente que uma área não tenha valor; significa que o eleitor usou seus pontos limitados em outras áreas.

<!-- translation-section: read-the-results -->

## Leia os resultados

Os resultados ordenam as opções pelo total de pontos recebidos. Eles também mostram:

- **% de pontos**: a proporção de todos os pontos distribuídos que a opção recebeu;
- **Pontos**: o total de pontos distribuídos;
- **Significar**: a média entre os eleitores que deram pontos à opção; e
- **Eleitores**: quantas pessoas deram pelo menos um ponto à opção.

![](results.png)

Neste exemplo, **Sustentabilidade financeira** recebe mais pontos, seguida de **Desenvolvimento da equipe**. Sustentabilidade financeira recebe pontos de todos os eleitores, o que sugere um amplo consenso de que ela precisa de um tempo considerável de revisão. Leia os totais junto com o número de eleitores para distinguir prioridades amplamente apoiadas de áreas com forte apoio de menos pessoas.

## Compartilhe uma conclusão

Quando a enquete for encerrada, compartilhe uma conclusão. A enquete não distribui tempo ou dinheiro automaticamente, então explique como o resultado será usado. Veja [Compartilhe uma conclusão](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome) para saber como as conclusões funcionam.
