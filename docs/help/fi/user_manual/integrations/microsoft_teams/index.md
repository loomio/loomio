# Microsoft Teams -integraatio

Loomio voi lähettää Microsoft Teams -kanavillesi ilmoituksia uusista keskusteluista, kyselyistä, kommenteista, äänistä ja johtopäätöksistä.

---

1. Avaa [Microsoft Teams](https://teams.microsoft.com) ja valitse **Sovellukset**.

   ![](t1.png)

2. Hae hakusanalla `webhook` ja valitse **Saapuva webhook**.

   ![](t2.png)

3. Valitse **Lisää tiimiin**.

   ![](t3.png)

4. Valitse kanava, jossa haluat Loomion ilmoitusten näkyvän.

   ![](t4.png)

5. Anna nimi, esimerkiksi `Loomio notifications`, ja valitse **Luo**.

   ![](t5.png)

6. Kopioi webhook-URL-osoite, jotta voit liittää sen Loomioon.

   ![](t6.png)

Nyt kun sinulla on webhook-URL-osoite, viimeistele yhteyden määrittäminen Loomiossa:

[Määritä chat-integraatio Loomiossa](../chatbots/#set-up-a-chat-integration)

_Microsoft ei ole luonut Loomiota, ei ole sidoksissa siihen eikä tarjoa sille tukea._
