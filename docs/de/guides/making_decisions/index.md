# Entscheidungen treffen

Diese Anleitungen beschreiben vollständige Entscheidungsprozesse: wie du eine Entscheidung vorbereitest, die richtigen Menschen einbeziehst, Diskussionen und Vorschläge nutzt, auf Bedenken eingehst und ein Fazit festhältst.

Sie unterscheiden sich von den Seiten zu Vorschlagsvorlagen. Eine [Vorschlagsvorlage](/en/user_manual/polls/proposals/) erklärt einen einzelnen Vorschlag und seine Antwortmöglichkeiten. Ein Entscheidungsprozess kann im Laufe der Zeit mehrere Vorschläge umfassen.

<!-- translation-section: choose-a-process -->

## Wähle einen Prozess

| Prozess | Wer entscheidet? | Zentrale Frage |
|---|---|---|
| [Einfacher Entscheidungsprozess](simple_decision_process) | Von der Gruppe festgelegt | Wie können wir diskutieren, einen Vorschlag prüfen und entscheiden? |
| [Beratungsprozess](advice_process) | Eine Person oder ein beauftragtes Team | Welche Ratschläge sollte die entscheidende Person berücksichtigen? |
| [Konsentprozess](consent_process) | Die Gruppe | Können wir den Vorschlag ausprobieren, ohne dass ein schwerwiegender Einwand dagegen spricht? |
| [Konsensprozess](consensus_process) | Die Gruppe | Können wir gemeinsam eine Einigung erzielen? |

Verwende den Prozess, den die Regeln oder die Entscheidungsrichtlinie deiner Gruppe vorsehen. Für verschiedene Arten von Entscheidungen können unterschiedliche Prozesse gelten.

Wenn du nur ein Antwortformat auswählen möchtest, vergleiche [Vorschläge](/en/user_manual/polls/proposals/) und [Abstimmungen](/en/user_manual/polls/proposal_types/). Wenn du die wiederverwendbaren Auswahlmöglichkeiten verwaltest, die nach **Jetzt abstimmen** angezeigt werden, lies [Abstimmungsvorlagen](/en/user_manual/polls/poll_templates/).
