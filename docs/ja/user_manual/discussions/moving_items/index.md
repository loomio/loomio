# スレッド間でアイテムを移動する

会話を別のスレッドに移す場合、1つのスレッドの話題が複数に分かれた場合、関連するディスカッションをまとめる場合に、選択したアイテムを移動できます。独立した**ディスカッションを統合**コマンドはありません。

この機能はグループの管理者が利用できます。[グループの権限](/en/user_manual/groups/settings/permissions)で**メンバーはディスカッションやコメントを管理できる**が有効になっている場合は、メンバーも利用できます。

アイテムの三点メニュー（**⋯**）を開き、**アイテムの移動**を選択します。

![](../using_discussions/comment_move.png)

移動するアイテムを選択します。

![](../using_discussions/comment_select.png)

追加で移動するアイテムをチェックボックスで選択し、ディスカッション上部のバナーにある**動く**をクリックします。

![](../using_discussions/move_items.png)

グループまたはサブグループを選択し、移動先のディスカッションを検索します。

アイテムを新しいディスカッションに移動するには、**新しい議論**を選択し、タイトルと背景説明を入力します。

![](../using_discussions/move_items_new_thread.png)

アイテムは元のスレッドから、選択したスレッドまたは新しく作成したスレッドに移動されます。

![](../using_discussions/new_thread.png)

元のスレッドが不要になった場合は、[ロックできます](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread)。今後も必要にならないと確信できる場合にのみ削除してください。
