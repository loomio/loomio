# 定足数

定足数は、投票を有効にするために参加が必要な有資格投票者の最低割合です。意思決定の手続きで一定の参加率が必要な場合に設定します。

投票を作成するときに **その他の設定** を開き、**参加定足数** に必要な割合を入力します。定足数が不要な場合は空欄のままにします。

![参加定足数を60%に設定した定足数の項目](./quorum-section.png)

[投票テンプレート](/en/user_manual/polls/poll_templates/)にも定足数を設定できます。そのテンプレートから作成した投票には、設定した値が初期値として適用されます。

## 利用例

オーツミルク協同組合では、返却可能なボトルを6週間試験的に導入することについて議論しています。試験の予算を承認する段階になりました。

ジェイミーは **投票を開始する** を選び、**同意** の提案テンプレートを選択します。その後、タイトル、詳細、選択肢、期間、投票者の設定を入力します。

![提案のタイトル、詳細、選択肢、期間、投票者の設定](proposal-options.png)

ジェイミーは、試験の予算を担当する5人に投票者を限定します。

この協同組合では、重要な決定に60%の参加が必要です。ジェイミーは参加定足数の欄に **60** と入力し、提案を開始します。

投票が始まる前は、結果欄に定足数に達していないことが表示されます。

![投票がなく、60%の定足数に達していない状態](pie-chart-0.png)

ジェイミーが賛成し、サミラが反対します。グラフは更新されますが、有資格投票者5人のうち2人の参加率は40%なので、まだ定足数に達していません。

![5人のうち2人が投票し、定足数に達していない状態](pie-chart-40.png)

続いてアレックスが賛成します。有資格投票者5人のうち3人が参加し、60%の定足数に達します。要件の横に緑色のチェックマークが表示されます。ジェイミーは投票を早期に締め切ることも、残りの投票者を待つこともできます。

![5人のうち3人が投票し、60%の定足数に達した状態](pie-chart-60.png)
