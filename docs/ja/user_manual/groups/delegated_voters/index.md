# 投票権を持つ代表者

グループの一部のメンバーにのみ投票権を付与する場合は、「代表者にする」機能を使って、投票権を持つ人を指定できます。対応する「代表者の指定を解除」操作もあります。

同じディスカッションの場を共有しながら、理事や選出された代表者など、指定された人だけが投票できるようにする場合は、代表者機能を使います。通常は、投票者と投票しない人を分けるためだけに別のサブグループを管理するよりも簡単です。

そのメンバーだけが閲覧できるディスカッション、ファイル、メンバー情報も必要な場合は、非公開のサブグループを使います。

![メンバーのメニューにある「代表者にする」操作](member_make_delegate.png)

アンケートや提案を作成して代表者だけを招待するには、アンケートの設定で「選択した人のみ」を使います。
![提案を開始するときの「選択した人のみ」設定](poll_invited_people_only.png)
投票への招待時に、「グループ名の代表者」という選択肢が表示されます。
![投票への招待フォームにある「Oatmilk Cooperativeの代表者」の選択肢](poll_invite_delegates_group.png)

代表者の一覧は、グループページのメンバータブで確認できます。フィルターメニューで「代表者」を選択します。
![メンバーのフィルターにある「代表者」の選択肢](members_list_delegates.png)
