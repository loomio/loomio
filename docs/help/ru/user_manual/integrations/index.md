# Интеграции

Подключите Loomio к другим инструментам, которые использует ваша группа.

<!-- translation-section: choose-where-work-belongs -->

## Выберите подходящий инструмент для работы

Loomio дополняет чаты, совместные документы и инструменты управления задачами, а не заменяет все инструменты для работы.

| Работа | Рекомендуемый инструмент |
|---|---|
| Короткие вопросы, неформальное общение и оперативные сообщения | Чат |
| Совместное редактирование постоянно обновляемого документа | Совместный документ |
| Назначение и отслеживание задач | Инструмент управления проектами или задачами |
| Обсуждение важных тем, широкое участие, решения и выводы | Loomio |

Используйте Loomio, когда людям нужно время на обдумывание темы, когда всем, кого она затрагивает, нужно дать возможность полноценно участвовать или когда группе потребуется найти обсуждение и решение позже. Добавьте в обсуждение Loomio ссылку на соответствующий документ или задачу, чтобы сведения по теме было легко найти.
