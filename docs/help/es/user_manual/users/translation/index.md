# Idiomas y traducción

Cambia el idioma de la interfaz de Loomio o traduce discusiones, comentarios y propuestas a tu idioma preferido.

<!-- translation-section: application-translation -->

## Traducción de la aplicación

Loomio detecta el idioma preferido de tu navegador. Para elegir otro idioma, abre **Editar perfil ** y selecciona uno allí.

![Cambiar tu idioma preferido](change_language.png)

<!-- translation-section: content-translation -->

## Traducción del contenido

Cuando alguien de tu grupo escribe un mensaje en un idioma distinto de tu idioma preferido, aparece un botón **Traducir** debajo del mensaje. Selecciona **Traducir** para traducir el mensaje a tu idioma preferido.

![Opción de traducir debajo de un comentario](content_translation.png)

El texto traducido sustituye al texto original en la discusión. Selecciona **original** para volver a mostrar el texto original.

![Un comentario traducido del español al inglés](content_translated.png)

Loomio utiliza Google Translate para traducir el contenido cuando lo solicitas.

<!-- translation-section: automatic-translation -->

## Traducción automática

Para traducir discusiones, comentarios y propuestas automáticamente, abre **Editar perfil ** y activa **Traducir automáticamente el contenido a mi idioma**. Loomio traduce el contenido al idioma seleccionado en tu perfil.

![La preferencia de traducción automática del contenido en la página Editar perfil](automatic_translation.png)
