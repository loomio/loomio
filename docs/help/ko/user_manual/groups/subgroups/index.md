# 하위 그룹

하위 그룹을 사용하면 소통과 멤버를 체계적으로 관리하여 필요한 사람들이 함께 업무에 참여할 수 있습니다.

예를 들어, 조직에는 다음과 같은 하위 그룹이 있을 수 있습니다:
- 이사회
- 실무 팀 또는 프로젝트 작업 그룹
- 주제별 그룹(예: '전략' 또는 '학습')

하위 그룹은 일반 그룹과 같은 방식으로 작동하지만, 상위 그룹 안에 있습니다. 사용할 수 있는 기능과 설정은 대부분 상위 그룹과 같습니다. 또한 상위 그룹의 멤버가 아니어도 이사회와 같은 하위 그룹의 멤버가 될 수 있습니다.

## 하위 그룹 추가

>[!Note]
>새 하위 그룹을 추가할 수 있는 권한은 그룹의 [권한 설정](/en/user_manual/groups/settings/permissions)에 포함됩니다. 기본적으로 그룹 관리자만 새 하위 그룹을 만들 수 있습니다.

하위 그룹을 추가하려면 기본 그룹 페이지로 이동한 다음 사이드바에서 **새 하위 그룹**을 클릭하세요.  

![Oatmilk Cooperative 사이드바의 새 하위 그룹 버튼](subgroups-sidebar.png)

**새 하위 그룹** 버튼을 클릭하고 이름을 입력한 뒤 공개 범위를 선택하고 **하위 그룹 만들기**를 클릭하세요.

![Packaging Working Group의 새 하위 그룹 양식](subgroups_new.png)

준비가 되면 하위 그룹에 [사람들을 초대하세요](/en/user_manual/groups/inviting_people/).

하위 그룹 페이지에서 톱니바퀴 아이콘을 클릭하면 하위 그룹의 [그룹 설정](/en/user_manual/groups/settings/)을 수정할 수 있습니다.

![Packaging Working Group의 그룹 설정 수정 메뉴](subgroups_edit_group_settings.png)

## 하위 그룹 설정

<!-- translation-section: privacy -->

### 공개 범위

하위 그룹을 찾고 스레드를 읽을 수 있는 사람을 선택하세요:

| 공개 범위 | 그룹을 찾을 수 있는 사람 | 스레드를 읽을 수 있는 사람 |
| --- | --- | --- |
| **개방** | 누구나 | 누구나 |
| **폐쇄** | 누구나 | 하위 그룹 멤버와 초대받은 게스트 |
| **상위 그룹에 공개** | 상위 그룹 멤버와 하위 그룹 멤버 | 하위 그룹 멤버와 초대받은 게스트 |
| **비밀** | 초대받은 하위 그룹 멤버 | 하위 그룹 멤버와 초대받은 게스트 |

**상위 그룹 멤버가 비공개 스레드를 볼 수 있습니다** 권한을 사용하면 상위 그룹 멤버가 하위 그룹에 가입하지 않고도 하위 그룹의 스레드에 접근할 수 있습니다.

상위 그룹이 비공개인 경우 하위 그룹은 **상위 그룹에 공개** 또는 **비밀**로 설정할 수 있습니다.

[그룹 공개 범위에 대해 알아보세요](/en/user_manual/groups/settings/privacy).

### 가입 방법

하위 그룹을 만들 때 또는 **그룹 설정 수정 → 공개 범위**에서 [가입 방법](/en/user_manual/groups/settings/privacy#how-people-join)을 선택하세요.

![하위 그룹의 공개 범위 및 가입 설정](subgroups_privacy_settings.png)

<!-- translation-section: permissions -->

### 권한

상위 그룹 멤버가 하위 그룹에 가입하지 않고도 하위 그룹의 스레드를 읽을 수 있도록 하려면 **권한**에서 **상위 그룹 멤버가 비공개 스레드를 볼 수 있습니다**를 활성화하세요. 이 권한으로 스레드를 읽는 사람에게는 투표권이나 하위 그룹 멤버 자격이 부여되지 않습니다.

![상위 그룹 멤버가 하위 그룹의 비공개 스레드를 볼 수 있도록 하는 설정](subgroups_private_threads_settings.png)

![사이드바에 표시된 Oatmilk Cooperative의 하위 그룹 목록](subgroups_find_subgroups.png)

## 하위 그룹에 초대

그룹에 초대하는 것과 같은 방법으로 하위 그룹에 사람들을 초대하세요. 초대할 사람이 이미 같은 조직 내에서 본인도 속한 상위 그룹이나 다른 하위 그룹의 멤버라면, 이름을 입력하거나 해당 그룹을 초대 대상으로 선택할 수 있습니다. 초대 대상 칩을 선택하여 개별 사람들로 펼친 다음, 초대하지 않을 사람을 제외하세요.

<!-- translation-section: simultaneously-invite-people-to-subgroups-and-parent-group -->

### 하위 그룹과 상위 그룹에 동시에 초대

상위 그룹의 **멤버** 탭에서 **초대** 버튼을 사용하면, 바로 가입시키려는 하위 그룹의 체크박스를 선택하여 여러 하위 그룹에 동시에 사람들을 초대할 수 있습니다.

![초대 양식에서 상위 그룹과 하위 그룹 선택](group_invite_email_subgroups.png)

<!-- translation-section: administer-a-subgroup -->

## 하위 그룹 관리

하위 그룹에는 별도의 그룹 관리자를 둘 수 있으며, 하위 그룹의 그룹 관리자는 상위 그룹의 그룹 관리자와 다를 수 있습니다.

상위 그룹 관리자는 비밀이 아닌 하위 그룹에 가입한 뒤 자신을 해당 하위 그룹의 그룹 관리자로 지정할 수 있습니다. 비밀 하위 그룹에는 적용되지 않습니다.

하위 그룹 탭으로 이동하여 하위 그룹을 찾은 뒤 **그룹 가입**을 클릭하세요.

![폐쇄 하위 그룹의 그룹 가입 버튼](member_join_subgroup.png)

하위 그룹의 멤버가 된 상위 그룹 관리자는 자신을 해당 하위 그룹의 그룹 관리자로 지정할 수 있습니다.

![상위 그룹 관리자가 자신을 하위 그룹 관리자로 지정하는 메뉴](member_make_admin.png)

<!-- translation-section: delete-a-subgroup -->

## 하위 그룹 삭제

그룹 관리자는 그룹을 삭제하는 것과 같은 방법으로 하위 그룹을 삭제할 수 있습니다. 하위 그룹을 삭제할 때 상위 그룹을 삭제하지 않도록 주의하세요.

[그룹 삭제 방법](/en/user_manual/groups/deleting_your_group/)을 알아보세요.
