# Delegati con diritto di voto

Se solo alcuni membri del tuo gruppo devono avere diritto di voto, usa l'azione "Rendi delegato" per identificarli. Per revocare il diritto di voto, usa "Revoca delegato".

Usa i delegati quando tutti devono condividere lo stesso spazio di discussione, ma solo un gruppo definito di persone, come i dirigenti o i rappresentanti eletti, può votare. Di solito è più semplice che mantenere un secondo sottogruppo solo per distinguere chi può votare da chi non può.

Usa invece un sottogruppo privato se i suoi membri hanno bisogno anche di discussioni, file o informazioni sui membri che gli altri non devono vedere.

![Azione Rendi delegato nel menu di un membro](member_make_delegate.png)

Per creare un sondaggio o una proposta e invitare solo i delegati, usa l'impostazione "Solo persone selezionate".
![Impostazione Solo persone selezionate durante la creazione di una proposta](poll_invited_people_only.png)
Quando inviti le persone a votare, vedrai l'opzione "Delegati di nome-gruppo".
![Opzione Delegati di Oatmilk Cooperative nel modulo di invito al voto](poll_invite_delegates_group.png)

Per vedere l'elenco dei delegati, apri la scheda dei membri nella pagina del tuo gruppo. Apri il menu dei filtri e seleziona "Delegati".
![Opzione Delegati nel filtro dei membri](members_list_delegates.png)
