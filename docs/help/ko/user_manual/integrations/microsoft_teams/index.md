# Microsoft Teams 연동
_Loomio 그룹 알림을 Microsoft Teams에 연결하세요._

Loomio는 새 토론, 제안, 댓글, 표, 결론이 등록되면 Microsoft Teams로 알림을 보낼 수 있습니다.

---

[https://teams.microsoft.com](https://teams.microsoft.com)에 접속한 다음 앱을 클릭하세요.
![](t1.png)

검색창에 "webhook"을 입력한 다음 수신 웹후크를 클릭하세요.
![](t2.png)

"팀에 추가"를 클릭하세요.
![](t3.png)

Loomio 알림을 받을 채널 이름을 입력하고 선택하세요.
![](t4.png)

"Loomio 알림"과 같은 이름을 지정한 다음 "만들기"를 클릭하세요.
![](t5.png)

표시된 URL을 복사하세요. 마지막 단계에서 Loomio에 붙여넣습니다.
![](t6.png)

_Loomio는 Microsoft가 제작한 서비스가 아니며, Microsoft와 제휴 관계가 없고 Microsoft의 지원을 받지 않습니다._

이제 웹후크 URL이 준비되었으니 채팅 연동 설정을 계속하세요.

[Loomio에서 채팅 연동 설정](../chatbots/#set-up-a-chat-integration)
