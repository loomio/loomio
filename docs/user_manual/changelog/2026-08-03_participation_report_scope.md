# Simpler participation report scope

Participation reports now use the group where the report was opened to offer a small set of reporting scopes.

- Instance administrators can report on the whole server.
- Parent-group administrators can report on the parent group with its accessible subgroups, or on the parent group alone.
- Reports opened from a subgroup cover that subgroup alone.
- Other members opening a report from a parent group can select any group they belong to within that organisation.

Secret subgroups are included in a parent-group report only when the parent-group administrator is also a member of the secret subgroup.
