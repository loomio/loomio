# Integraciones

Conecta Loomio con otras herramientas que utiliza tu grupo.

<!-- translation-section: choose-where-work-belongs -->

## Elige dónde realizar cada tipo de trabajo

Loomio complementa el chat, los documentos compartidos y las herramientas de gestión de tareas, en lugar de sustituir todas las formas de trabajo.

| Trabajo | Herramienta sugerida |
|---|---|
| Preguntas rápidas, conversaciones informales y actualizaciones oportunas | Chat |
| Edición colaborativa de un documento que se actualiza continuamente | Documento compartido |
| Asignación y seguimiento de tareas | Herramienta de gestión de proyectos o tareas |
| Discusión sobre temas importantes, participación amplia, decisiones y conclusiones | Loomio |

Lleva el trabajo a Loomio cuando las personas necesiten tiempo para considerar un tema, cuando todas las personas afectadas deban tener una oportunidad real de participar o cuando el grupo necesite encontrar la discusión y la decisión más adelante. Añade un enlace al documento o a la tarea pertinente desde la discusión de Loomio para que el contexto siga siendo fácil de encontrar.
