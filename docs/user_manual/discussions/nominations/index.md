# Collect nominations

Use a discussion template to collect structured nominations from Loomio users who are not members of your group. A person can nominate themselves or someone else for a position within an organization or process. Each nomination becomes a separate discussion where group members can ask the nominator for more information before comparing candidates or making an appointment.

## Set up the nomination process

1. Create a [discussion template](/en/user_manual/discussions/templates) for nominations. Include every question nominators should answer, such as whether they are nominating themselves or another person, the candidate's name, relevant experience, reasons for the nomination, and any declarations the group requires.
2. Set the group privacy to **Open** or **Closed**. If nominators should not request group membership, set membership to **Invitation only**. This workflow is not available for Secret groups.
3. In **Group settings** under **Permissions**, enable **Non-members can start discussions**.
4. Share the group page with prospective nominators. They must sign in to Loomio before submitting a nomination.

## Submit a nomination

The nominator opens the group and selects **Start discussion**. Loomio shows the group's available discussion templates before displaying the discussion form. The nominator selects the nomination template, identifies themselves or the other person being nominated, completes the template's questions, and starts the discussion.

The discussion belongs to the group, but the nominator does not become a group member. Instead, Loomio adds them as a guest of the discussion so they can read it, receive notifications, and respond to follow-up questions.

## Review nominations

Group members can see every nomination discussion in the group. They can ask follow-up questions in each discussion until the nomination contains enough information to describe and compare candidates accurately.

In a Closed group, each nominator can see their own nomination but cannot see the group's other private discussions or nomination submissions. Discussions in an Open group follow the group's public discussion policy.

Disable **Non-members can start discussions** when submissions close. Existing nomination discussions and guest access are unchanged.
