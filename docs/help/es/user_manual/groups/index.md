# Grupos

Un grupo de Loomio es un espacio compartido donde los miembros mantienen discusiones, comparten información y toman decisiones juntos.

![La página del grupo Oatmilk Cooperative, con su descripción y lista de discusiones](group_page.png)

Puedes personalizar la página de tu grupo con un nombre, una descripción, un logotipo, una imagen de portada y enlaces a documentos como los términos de referencia del grupo. Esto ayuda a los miembros a entender el propósito del grupo y cómo participar.

Para empezar, [crea un grupo](/en/user_manual/groups/starting_a_group), elige la [configuración de privacidad](/en/user_manual/groups/settings/privacy) del grupo e [invita a otras personas](/en/user_manual/groups/inviting_people).

Si estás preparando un grupo nuevo, consulta [Cómo presentar Loomio a tu grupo](/en/user_manual/overview/introducing_loomio) para seguir una secuencia práctica desde la elección del primer trabajo hasta el registro de una conclusión.

## Código de conducta

Un código de conducta ayuda a los miembros a entender cómo participar y cómo responde el grupo ante comportamientos inapropiados. Consulta la [Guía de facilitación](/guides/facilitators-guide/commencing/#culture-protocol-expectations) para obtener orientación sobre cómo establecer expectativas.
