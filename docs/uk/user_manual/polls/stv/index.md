# Вибори на СТВ

**Єдиний передаваний голос (STV)** — метод пропорційного голосування для обрання кількох переможців із числа кандидатів. Він допомагає обрати кандидатів, які пропорційно представляють різні погляди виборців.

<!-- translation-section: when-to-use-stv -->

## Коли використовувати СТВ

Використовуйте вибори на СТВ, якщо потрібно:

- Обрати **комітет, правління або групу делегатів** із числа висунутих кандидатів
- Забезпечити **пропорційне представництво**, щоб групи з меншою підтримкою могли отримати відповідну частку місць
- Провести вибори, на яких виборці ранжують кандидатів за вподобаннями

>[!NOTE]
>СТВ **відрізняється** від [рангового опитування](/en/user_manual/polls/rank/) у Loomio. Рангове опитування використовує простіше оцінювання, щоб вибрати один найкращий варіант. СТВ дає змогу обрати кількох переможців шляхом передавання голосів і вибування кандидатів у раундах.

<!-- translation-section: creating-an-stv-election -->

## Створення виборів на СТВ

Під час створення опитування виберіть тип **Вибори на СТВ**, а потім додайте кандидатів як варіанти відповіді. Ви можете налаштувати **кількість місць**, **метод підрахунку** та **тип квоти**.

У цьому прикладі кооператив Oatmilk обирає трьох людей для нагляду за випробуванням багаторазової упаковки. У формі описано цю роль, перелічено п’ятьох кандидатів і вибрано шотландський метод СТВ із квотою Друпа.

![](form.png)

<!-- translation-section: number-of-seats -->

### Кількість місць

Кількість переможців, яких потрібно обрати. Вона має бути меншою за кількість кандидатів.

<!-- translation-section: counting-method -->

### Метод підрахунку

Доступні два методи підрахунку голосів:

Шотландський СТВ : Рекомендовано. Зважений інклюзивний метод Грегорі (WIGM), який використовують на місцевих виборах у Шотландії з 2007 року. Має чіткі й прості правила. Підходить більшості організацій.

Метод Міка : Ітеративний метод із вищою математичною точністю. Коли кандидат вибуває, голоси перераховують так, ніби він ніколи не брав участі у виборах.

<!-- translation-section: quota-type -->

### Тип квоти

Квота — це мінімальна кількість голосів, потрібна кандидату для здобуття місця. Є два типи квоти:

Друпа : Рекомендовано. Стандартний тип квоти для більшості виборів на СТВ. Його використовують в Ірландії, Австралії та Шотландії. Квота Друпа гарантує, що коаліція з більшістю голосів отримає більшість місць. Її обчислюють так: \\[ floor(\frac{votes}{(seats + 1)}) + 1 \\]

Гера
  : Вищий мінімальний поріг, який забезпечує більшу пропорційність для невеликих груп.
    Осередки DSA віддають перевагу квоті Гера, щоб захистити представництво меншості.
   Її обчислюють так:
    \\[ \frac{votes}{seats}\\]

>[!TIP]
  > Квота Друпа завжди потребує меншої кількості голосів, ніж квота Гера. Наприклад, на виборах зі 100 голосами й чотирма місцями квота Друпа становить 21 голос, а квота Гера — 25.

<!-- translation-section: how-voting-works -->

## Як відбувається голосування

У цьому прикладі кооператив Oatmilk обирає трьох людей для нагляду за випробуванням багаторазової упаковки. Виборці перетягують кандидатів вище лінії та ранжують їх за вподобаннями:

![](stv-vote-in-progress.png)

- **Ранг 1** = найбажаніший кандидат
- **Ранг 2** = другий вибір
- Продовжуйте ранжувати стільки кандидатів, скільки бажаєте

Виборцям не обов’язково ранжувати всіх кандидатів. Кандидати без рангу не отримають підтримки цього виборця.

<!-- translation-section: how-counting-works -->

## Як відбувається підрахунок
Голоси підраховують так:

1. Обчислюється **квота** — мінімальна кількість голосів, потрібна для отримання місця.
2. Для кожного кандидата підраховуються **Перші уподобання**.
3. Якщо кандидат досягає квоти, його **обирають**. Його надлишкові голоси (понад квоту) **передаються** наступним за пріоритетом кандидатам виборців із дробовою вагою.
4. Якщо жоден кандидат не досягає квоти, кандидат із **найменшою кількістю голосів вибуває**. Його голоси передаються наступним за пріоритетом кандидатам виборців із повною вагою.
5. Процес повторюється, доки всі місця не будуть заповнені.

>[!TIP]
>Якщо виборець не ранжував жодного з кандидатів, які залишилися, його бюлетень вичерпано, а голос більше не враховують. Тому зазвичай варто ранжувати більше кандидатів.

### Метод і квота

Угорі ви побачите метод підрахунку (шотландський СТВ або метод Міка), тип квоти (Друпа або Гера) і саму квоту — кількість голосів, потрібну кандидату для здобуття місця.

<!-- translation-section: elected-candidates -->

### Обрані кандидати

Підсумкова таблиця переможців має п’ять стовпців:

| Стовпець | Значення |
|--------|---------|
| **Кандидат** | Ім’я обраного кандидата |
| **Обраний у раунді** | Раунд підрахунку, у якому кандидат досяг квоти й здобув місце. Раунд 1 означає перемогу лише завдяки першим уподобанням. У наступних раундах для перемоги знадобилися передані голоси кандидатів, які вибули або отримали голоси понад квоту. |
| **Перші уподобання** | Кількість виборців, які поставили цього кандидата на перше місце. Показує пряму підтримку кандидата до передавання голосів. |
| **Остаточний підрахунок** | Кількість голосів кандидата на момент обрання. Через передавання голосів вона часто перевищує кількість перших уподобань. |
| **Надлишок** | Наскільки остаточна кількість голосів кандидата перевищила квоту (остаточний підрахунок мінус квота). Більший надлишок означає сильнішу підтримку понад необхідну для перемоги. У шотландському СТВ цей надлишок перерозподіляють між наступними за вподобанням кандидатами. |

Якщо підрахунок завершується нічиєю і вибування будь-кого з кандидатів, які залишилися, змінило б результат, цих кандидатів показують в окремій таблиці. Переможця не обирають довільно.

### Деталі по кожному раунду

Розгорніть **Деталі по кожному раунду**, щоб побачити передавання голосів і вибування кандидатів. Кожен рядок відповідає кандидату, а кожен стовпець — раунду підрахунку:

![](stv-results.png)

Зеленим позначено раунд обрання кандидата, червоним — раунд його вибування, а помаранчевим — раунд нічиєї.

## Поділіться висновком

Коли вибори завершаться, поділіться висновком. Назвіть обраних людей і вкажіть, коли вони почнуть виконувати свої обов’язки. Докладніше про висновки дивіться в розділі [Поділіться висновком](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome).

## Експорт бюлетенів

Після закриття виборів люди, які мають доступ до результатів, можуть експортувати бюлетені у форматі BLT для незалежного перерахунку або перевірки. Експорт містить ранжування кандидатів. Однакові ранжування об’єднано в один рядок із кількістю бюлетенів. Для анонімних виборів експорт не містить даних про виборців, ідентифікаторів бюлетенів, часу подання чи порядку подання.
