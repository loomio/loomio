# Discusiones directas

Una discusión directa es una discusión privada entre un grupo específico de personas.

Una discusión directa no pertenece a ningún grupo. Las personas invitadas no necesitan ser miembros de tu grupo de Loomio.

Para decidir quién puede verla y participar, añade personas o direcciones de correo electrónico al campo **Invitar**.

Las discusiones directas tienen los mismos comentarios, sondeos y otras herramientas que las discusiones de grupo. Pueden ser útiles cuando no hace falta crear un subgrupo.

![Formulario de una discusión directa sin un grupo seleccionado y con Samira Patel en el campo Invitar](direct-discussion-example.png)

Selecciona **Hilos directos** en la barra lateral para ver tus discusiones directas. Selecciona **Nueva discusión** en esa página para iniciar otra.

![La opción Hilos directos en la barra lateral y la lista de discusiones directas](direct-discussion-sidebar.png)

## Contactar con alguien mediante una discusión directa
Puedes usar una discusión directa para contactar en privado con una o más personas sin crear un subgrupo.
