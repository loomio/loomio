# Прямые обсуждения

Прямое обсуждение — это закрытое обсуждение для определённого круга людей.

Прямое обсуждение не относится к группе. Приглашённым людям не нужно быть участниками вашей группы в Loomio.

Чтобы выбрать, кто может видеть обсуждение и участвовать в нём, добавьте людей или адреса электронной почты в поле **Приглашать**.

В прямых обсуждениях доступны те же комментарии, опросы и другие инструменты, что и в обсуждениях группы. Это удобно, когда создавать подгруппу не нужно.

![Форма прямого обсуждения: группа не выбрана, в поле «Приглашать» указана Самира Патель](direct-discussion-example.png)

Выберите **Прямые темы** в боковой панели, чтобы увидеть свои прямые обсуждения. Чтобы начать ещё одно, выберите **Новое обсуждение** на открывшейся странице.

![Пункт «Прямые темы» в боковой панели и список прямых обсуждений](direct-discussion-sidebar.png)

## Как связаться с кем-то через прямое обсуждение
Прямое обсуждение позволяет связаться с одним или несколькими людьми без создания подгруппы.
