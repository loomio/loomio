# 다이렉트 토론

다이렉트 토론은 특정 사람들만 참여하는 비공개 스레드입니다. 그룹에 속하지 않으며, 초대받은 사람은 어떤 Loomio 그룹에도 속해 있을 필요가 없습니다.

**초대** 입력란에 사람이나 이메일 주소를 추가하여 내용을 보고 참여할 수 있는 사람을 정하세요.

다이렉트 토론에서는 그룹 토론과 동일한 댓글, 투표 및 서식 도구를 사용할 수 있습니다. 하위 그룹이 필요하지 않은 비공개 대화나 초안 작성에 유용합니다.

![그룹이 선택되지 않고 초대 입력란에 Samira Patel이 추가된 다이렉트 토론 양식](direct-discussion-example.png)

**모든 그룹**을 열고 **스레드**에서 **다이렉트**를 선택하거나 **스레드** 카드에서 다이렉트 항목의 개수를 선택하면 다이렉트 토론을 볼 수 있습니다. 여기에서 **새 스레드**를 선택하여 다이렉트 토론을 시작하세요. **모든 그룹**에서 **사람**을 열고 이름 옆의 **다이렉트 스레드**를 선택할 수도 있습니다.

다이렉트 투표는 초대한 사람에게만 표시됩니다. 투표를 만든 후 [투표자 관리](/en/user_manual/polls/manage_voters)에서 사람이나 이메일 주소를 추가하여 초대하세요.

## 다이렉트 토론을 그룹으로 이동하기

비공개 대화나 초안이 그룹에서 다룰 주제로 발전하면 나중에 그룹이나 하위 그룹으로 이동할 수 있습니다. [스레드 이동하기](/en/user_manual/discussions/using_discussions/#move-a-thread)를 참고하세요.
