# クイックツアー

このページでは、Loomio の画面の主な部分と、自分が関わる活動を確認する場所を紹介します。

<!-- translation-section: group-page -->

## グループページ

グループのホームページには、グループの紹介と活動への入口があります。

![](group_example.png)

<!-- translation-section: tabs -->

### タブ

グループの説明の下にあるタブから、次の内容を確認できます。

**議論** - グループの議論スレッドと最近の活動。

**投票** - グループで進行中の投票の一覧。

**メンバー** - グループに所属する人の一覧。

**ファイル** - グループ内で添付された文書やその他のファイル。議論の本文、コメント、提案、投票に添付されたファイルが集められます。添付された場所を覚えていなくても、文書を探せます。

検索、フィルター、タグ、ブックマーク、未読の議論については、[コンテンツを探す](/en/user_manual/overview/finding-content)をご覧ください。

<!-- translation-section: sidebar -->

## サイドバー

左上のメニューボタン（**☰**）でサイドバーを開きます。

![](sidebar.png)

サイドバーから、ダッシュボード、投票を待っている案件、未読の議論、ダイレクトな議論、タスク、グループを開けます。ユーザーマニュアルとサポートへのリンクもあります。

<!-- translation-section: user-settings -->

### ユーザー設定

サイドバーで自分の名前を選ぶと、ユーザーメニューが開きます。

![](user_settings_sidebar.png)

このメニューから、プロフィールの編集、通知設定の変更、テーマの選択、アカウント設定の管理、サインアウトができます。

<!-- translation-section: notifications -->

## 通知

右上のベルのボタンを押すと、アプリ内の通知が開きます。未確認の通知がある場合は、バッジが表示されます。

![](../users/email_settings/in_app_notifications.png)

アプリ内の通知、メールの受信設定、グループや議論の通知設定については、[通知](/en/user_manual/users/email_settings)をご覧ください。

<!-- translation-section: what-to-do-next -->

## 次のステップ

- コメント、返信、リアクション、投票の方法は、[参加方法](/en/user_manual/overview/how-to-participate)をご覧ください。
- 議論や決定事項の探し方は、[コンテンツを探す](/en/user_manual/overview/finding-content)をご覧ください。
- 詳しくは、[議論](/en/user_manual/discussions)または[提案と投票](/en/user_manual/polls/intro_to_decisions)をご覧ください。
