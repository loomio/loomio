# Integración con Mattermost

Loomio puede enviar notificaciones a tus canales de Mattermost cuando hay nuevas discusiones, encuestas, comentarios, votos y conclusiones.

---

1. Abre tu equipo de Mattermost en un navegador y ve a **Incorporaciones**.

   ![](mm1.png)

2. Selecciona **Webhooks entrantes**.

   ![](mm2.png)

3. Selecciona **Añadir webhook entrante**.

   ![](mm3.png)

4. Introduce un nombre, elige el canal donde quieres que aparezcan las notificaciones y selecciona **Guardar**.

   ![](mm4.png)

5. Copia la URL del webhook.

   ![](mm5.png)

Ahora que tienes una URL de webhook, termina de conectarlo en Loomio:

[Configura una integración de chat en Loomio](../chatbots/#set-up-a-chat-integration)
