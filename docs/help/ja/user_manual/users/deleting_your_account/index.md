# Loomioアカウントの削除

<!-- translation-section: what-does-delete-account-mean -->

## アカウントを削除するとどうなりますか？

アカウントの削除は恒久的なもので、元に戻すことはできません。アカウントを削除すると、次のようになります。

- 名前、メールアドレス、その他の個人情報を含むアカウントがLoomioから削除されます。このアカウントではサインインできなくなります。
- 投稿したコメント、提案、ディスカッションは、名前が削除された状態で残り、グループのスレッドは維持されます。
- すべてのグループからメンバーとして削除されます。
- 通知メールが届かなくなります。

活動内容のコピーが、すでにグループのメンバーにメールで送信されている場合があります。Loomioでは、送信済みのメールを削除できません。

アカウントを削除しても、有料サブスクリプションは解約されません。支払いを停止する方法は、[サブスクリプション](/en/policy/subscriptions/management#cancel-your-plan)をご覧ください。

Loomioでのデータの取り扱いについて詳しくは、[プライバシーポリシー](/en/policy/privacy)をご覧いただくか、[お問い合わせください](/contact)。削除する前にグループの記録のコピーが必要な場合は、グループ管理者が[グループのデータをエクスポート](/en/user_manual/groups/data_export)できます。

<!-- translation-section: to-delete-your-account-entirely -->

## アカウントを完全に削除するには

1. Loomioにサインインします。
2. サイドバーで名前を選択してユーザーメニューを開き、**プロファイル編集**を選択します。サイドバーが閉じている場合は、メニューボタン（**☰**）で開きます。

![](profile_edit.png#width-50)

3. ページの一番下までスクロールし、**アカウントを削除する**を選択します。

![](delete_user.png)

4. アカウントを完全に削除することを確認します。

![](permanently_delete_account.png#width-80)
