# Интеграция с Discord

Loomio может отправлять уведомления в ваши каналы Discord при появлении новых обсуждений, опросов, комментариев, голосов и выводов. Вы также можете вручную отправить уведомление в канал, когда нужно напомнить людям о решении.

---

1. Откройте ваш сервер Discord и перейдите в **Настройки сервера**.

   ![](server-settings.png)

2. Выберите **Интеграции**.

   ![](integrations.png)

3. Выберите **Добавить вебхук**, задайте ему имя, например `Loomio`, выберите канал и скопируйте URL вебхука.

   ![](add-webhook.png)

Теперь, когда у вас есть URL вебхука, завершите подключение в Loomio:

[Настройте интеграцию с чатом в Loomio](../chatbots/#set-up-a-chat-integration)
