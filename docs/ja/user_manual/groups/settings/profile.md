# グループのプロフィール

プロフィールタブでは、グループの名前や紹介を設定できます。グループページで**グループ設定を編集する**を開き、**プロフィール**を選択します。

![グループのプロフィール設定](group_profile.png)

<!-- translation-section: name-and-handle -->

## 名前とハンドル

グループ名は簡潔にします。サブグループを作る場合は特に重要です。ハンドルは、`loomio.com/your-group-handle` や `your-group-handle@loomio.com` のように、グループのウェブアドレスとメールアドレスに使われます。

ハンドルを変更すると、以前のハンドルを使ったリンクは新しいアドレスに転送されます。以前のグループのメールアドレスに送られたメールも引き続き届きます。Loomioは以前のハンドルを最大3つ保持します。それを超えて変更すると、最も古いハンドルが使えなくなります。

<!-- translation-section: description -->

## 説明

説明には、グループの目的、参加する人、利用方法を記載します。書式を設定したり、リンク、文書、動画を追加したりできます。

グループの[プライバシー設定](/en/user_manual/groups/settings/privacy)によっては、メンバー以外にも名前と説明が表示されます。

<!-- translation-section: cover-image-and-logo -->

## カバー画像とロゴ

カバー画像はグループページの上部に表示されます。横長の画像が適しています。推奨サイズは2048 × 512ピクセルです。

グループのロゴは、ナビゲーションなどの小さな表示領域でグループを識別するために使われます。用途に合った形にそれぞれ切り抜けるよう、カバー画像とロゴは別々にアップロードします。
