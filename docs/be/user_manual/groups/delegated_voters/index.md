# Выбаршчыкі-дэлегаты

Калі права голасу павінны мець толькі некаторыя ўдзельнікі вашай групы, пазначце іх з дапамогай дзеяння «Зрабіць дэлегатам». Каб скасаваць гэтае права, выкарыстоўвайце дзеянне «Адклікаць дэлегата».

Выкарыстоўвайце дэлегатаў, калі ўсім патрэбна агульная прастора для абмеркаванняў, але галасаваць можа толькі вызначанае кола людзей, напрыклад члены праўлення або абраныя прадстаўнікі. Звычайна гэта прасцей, чым падтрымліваць асобную падгрупу толькі для размежавання тых, хто можа галасаваць, і тых, хто не можа.

Калі ўдзельнікам таксама патрэбны асобныя абмеркаванні, файлы або звесткі пра склад групы, недаступныя іншым, стварыце прыватную падгрупу.

![Дзеянне «Зрабіць дэлегатам» у меню ўдзельніка](member_make_delegate.png)

Каб стварыць апытанне або прапанову і запрасіць толькі дэлегатаў, выберыце ў наладах апытання «Толькі выбраныя людзі».
![Налада «Толькі выбраныя людзі» пры стварэнні прапановы](poll_invited_people_only.png)
Пры запрашэнні да галасавання вы ўбачыце варыянт «Дэлегаты назвы групы».
![Варыянт «Дэлегаты кааператыва Oatmilk» у форме запрашэння да галасавання](poll_invite_delegates_group.png)

Спіс дэлегатаў можна паглядзець на ўкладцы ўдзельнікаў старонкі вашай групы. Адкрыйце меню фільтра і выберыце «Дэлегаты».
![Варыянт «Дэлегаты» ў фільтры спіса ўдзельнікаў](members_list_delegates.png)
