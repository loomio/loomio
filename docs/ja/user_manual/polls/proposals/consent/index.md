# 同意

同意による提案では、ある行動を試しても問題ないかを確かめます。参加者は同意するか、異議を唱えます。異議では、提案で対処すべき具体的なリスクや害を示します。

このページでは、同意による提案の進め方を説明します。質問、意向の確認、修正、異議、結論を含む一連の流れは、[同意による意思決定の進め方](/en/guides/making_decisions/consent_process)を参照してください。

<!-- translation-section: when-to-use-consent -->

## 同意を使う場面

有効な異議がなければ進められる、実行可能な決定をグループが必要としているときに、同意を使います。試行、運営方針、役割についての合意など、経験を積んだ後に見直せる決定に適しています。

同意には、全員がその提案を最も望ましい案だと考える必要はありません。投票前に何を異議とみなすかを定め、異議をどう検討し、解決するかを説明します。

<!-- translation-section: example-start-a-bottle-trial -->

## 例：瓶の試験運用を始める

オーツミルク協同組合は、来月から返却可能な瓶を6週間試験運用することを提案します。試験運用の範囲を限定し、見直しも予定しているため、グループは試しても問題ないかを確かめます。

<!-- translation-section: set-up-the-proposal -->

## 提案を設定する

提案する行動、その範囲、安全策、見直す時期を説明します。**同意**と**異議**の意味を明確にし、懸念を理解して対処できるよう、異議には理由を求めます。

![](form.png)

<!-- translation-section: vote -->

## 投票する

参加者は、最も望ましい案でなくても、試すのに十分安全だと判断した場合は**同意**を選びます。重大なリスクや害を具体的に説明できる場合は**異議**を選びます。

![](../proposal_consent_voting.png)

<!-- translation-section: read-the-results -->

## 結果を確認する

グラフには異議が表示されますが、グループはその理由を確認する必要があります。有効な異議には、提案の修正、安全策の追加、範囲の変更、または実施を見送ることで対処します。

![](../proposal_consent_results.png)

<!-- translation-section: share-an-outcome -->

## 結論を共有する

提案の投票が終了したら、結論を共有します。合意した行動、異議をどのように解決したか、担当者、グループが見直す時期を記録します。結論の仕組みについては、[結論を共有する](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome)を参照してください。
