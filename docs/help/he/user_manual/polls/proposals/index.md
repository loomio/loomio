# הצעות

הצעה מבקשת מאנשים להגיב להצהרה או לדרך פעולה. במסגרת ההשתתפות ניתן לבחור תגובה מתוך אפשרויות מוגדרות ולהסביר את ההצבעה. ניתן להשתמש בהצעה כדי לאסוף משוב, לבקש עצות, לזהות התנגדויות או לבדוק אם יש הסכמה.

סעיף זה מסייע בבחירה ובהפעלה של תבניות ההצעה המוגדרות כברירת מחדל ב-Loomio. לתהליך מלא הכולל דיון, הצעות, תיקונים ומסקנה, ניתן להיעזר ב[מדריכים לקבלת החלטות](/en/guides/making_decisions/). לשינוי התבניות הזמינות לקבוצה, יש לעיין ב[תבניות סקרים](../poll_templates/).

## תבניות נוספות להצעות

Loomio מספקת גם תבניות כגון הצעה, דרגות הסכמה ורוב. חלקן מוסתרות בתחילה. בהגדרות [תבניות סקרים](../poll_templates/) ניתן, בהרשאת ניהול הקבוצה, להפוך אותן לזמינות או ליצור תבנית המותאמת למונחים ולכללים של הקבוצה.

<!-- translation-section: proposal-records -->

## תיעוד הצעות

ההצבעות והנימוקים מתעדכנים כל עוד ההצעה פתוחה, והמשתתפים יכולים לשנות את תגובתם. לאחר סגירת ההצעה, יש לפרסם [מסקנה](../outcomes/) המציינת את ההחלטה או את הצעד הבא. הדיון, ההצעה, ההצבעות, הנימוקים והמסקנה מתעדים כיצד הגיעה הקבוצה להחלטתה.
