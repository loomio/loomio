# 意思決定

これらのガイドでは、意思決定の進め方を最初から最後まで説明します。決めるべきことを明確にし、関係者を交え、ディスカッションと提案を使い、懸念に対応して、結論を記録する方法を扱います。

これらは提案テンプレートのページとは異なります。[提案テンプレート](/en/user_manual/polls/proposals/)では、1つの提案とその回答の選択肢を説明します。意思決定の過程では、時間をかけて複数の提案を使うことができます。

<!-- translation-section: choose-a-process -->

## 進め方を選ぶ

| 進め方 | 誰が決めますか？ | 主な問い |
|---|---|---|
| [シンプルな意思決定](simple_decision_process) | グループが定める人 | どう話し合い、案を試し、決定しますか？ |
| [助言を得る進め方](advice_process) | 個人または委任されたチーム | 決定する人はどのような助言を考慮すべきですか？ |
| [同意による意思決定](consent_process) | グループ | 重要な異議がなく、提案を試しても安全ですか？ |
| [合意による意思決定](consensus_process) | グループ | 全員で合意に達することができますか？ |

グループの運営規則や意思決定方針で定められた進め方を使ってください。決定する内容によって、進め方が異なる場合もあります。

回答形式を選ぶための情報が必要な場合は、[提案](/en/user_manual/polls/proposals/)と[投票](/en/user_manual/polls/proposal_types/)を比較してください。誰かが**投票を開始する**を選んだときに表示される、再利用可能な選択肢を管理する場合は、[投票テンプレート](/en/user_manual/polls/poll_templates/)をご覧ください。
