# Руководство по фасилитации в Loomio

Подробное руководство по применению ключевых принципов фасилитации в онлайн-пространстве.

Loomio создан фасилитаторами, и это во многом определило его устройство. Это руководство рассказывает об этих предпосылках и о том, как перенести принципы фасилитации из очного взаимодействия в онлайн-пространство.

<!-- translation-section: more-about-this-guide -->

## Подробнее об этом руководстве

Кто бы ни использовал Loomio — профессиональный фасилитатор, люди, помогающие друг другу вести обсуждения, или группа, которая вообще не знакома с фасилитацией, — его основная функция заключается в том, чтобы помогать группе общаться и двигаться к желаемой цели. Другими словами, обеспечивать фасилитацию.

Loomio — это *программное обеспечение для совместной работы*:

> Программное обеспечение для совместной работы предназначено для того, чтобы помогать людям, занятым общей задачей, достигать своих целей. Одно из первых определений такого программного обеспечения — «целенаправленные групповые процессы и программное обеспечение для их поддержки». -- Википедия

В очной фасилитации и онлайн-модерации накоплен большой объём знаний, практик и традиций, но искусство и наука их сочетания только начинают формироваться. Именно в этой области Loomio стремится добиться наилучших результатов.
