# Loomioアカウントの削除

<!-- translation-section: what-does-delete-account-mean -->

## アカウントを削除するとどうなりますか？

アカウントを削除すると、次のようになります。
- 名前、メールアドレス、その他の個人を特定できるデータを含むユーザーアカウントが、Loomioのシステムから削除されます。このアカウントではLoomioにサインインできなくなります。
- 投稿したコメント、提案、ディスカッションは残りますが、それらから名前が削除されます。これは、スレッドや提案の内容のつながりを保つ責任を、Loomioがグループに対して負っているためです。
- どのグループにもメンバーとして表示されなくなります。
- 通知メールが届かなくなります。

Loomio上で作成したデータのコピーは、グループの全員にメールで送信されている可能性が高いことにご留意ください。Loomioでは、それらのコピーを削除できません。

アカウントを削除しても、サブスクリプションは_解約されません_。支払いを停止する方法は、[サブスクリプション](/en/policy/subscriptions/management#cancel-your-plan)をご覧ください。

Loomioは、ユーザーの権利を守るために、所有形態、ビジネスモデル、ソフトウェアについて基本的な決定を行ってきました。Loomioは独立した、働く人々が所有する協同組合です。ソフトウェアはオープンソースで、[データをエクスポート](/en/user_manual/groups/data_export)できます。Loomioはデータを販売したり、広告に利用したりすることはありません。これらの方針は[プライバシーポリシー](/en/policy/privacy)に明記されており、[定款](https://www.loomio.coop/constitution.html)と[協同組合ハンドブック](https://www.loomio.coop/purpose_and_vision.html)に記載された目的と価値観に基づいています。ご質問がある場合は、[お問い合わせください](/contact)。

## アカウントを完全に削除するには

Loomioにサインインします。画面左上のメニューアイコン（☰）からサイドバーを開きます。画面右上のアカウントのアバターまたはイニシャルをクリックします。

名前の横にある下向き矢印（ ∨ ）をクリックして、ユーザー設定を開きます。**プロファイル編集**を選択します。

![](profile_edit.png#width-50)

一番下までスクロールし、**アカウントを削除する**をクリックします。

![](delete_user.png)

アカウントを削除するかどうかを確認するポップアップが表示されます。

![](permanently_delete_account.png#width-80)
