# Mattermost-integratie
_Meldingen van je Loomio-groep koppelen aan de teamchat in Mattermost._

Loomio kan meldingen naar je Mattermost-kanalen sturen bij nieuwe discussies, voorstellen, reacties, stemmen en conclusies.

---

Open je Mattermost-team in je browser. Ga vervolgens naar de instellingen voor integraties.
![](mm1.png)

Klik op "Incoming Webhooks"
![](mm2.png)

Klik vervolgens op  "Add Incoming Webhook"
![](mm3.png)

Geef de webhook een eenvoudige naam, selecteer het kanaal waarin de meldingen moeten verschijnen en klik op Save
![](mm4.png)

Kopieer de Webhook-URL naar je klembord. Je hebt deze nodig bij de volgende stap.
![](mm5.png)

Zorg dat de Webhook-URL op je klembord staat en volg de onderstaande link.
