# Mattermost-integratie
_Meldingen van jouw Loomio-groep koppelen aan de teamchat in Mattermost._

Loomio kan meldingen naar jouw Mattermost-kanalen sturen wanneer er nieuwe discussies, voorstellen, reacties, stemmen en conclusies zijn.

---

Open jouw Mattermost-team in je browser. Open vervolgens de instellingenpagina voor integraties.
![](mm1.png)

Klik op "Inkomende webhooks"
![](mm2.png)

Klik vervolgens op "Inkomende webhook toevoegen"
![](mm3.png)

Geef de webhook een eenvoudige naam, selecteer het kanaal waarin de meldingen moeten verschijnen en klik op Opslaan
![](mm4.png)

Kopieer de webhook-URL naar je klembord. Je hebt deze bij de volgende stap nodig.
![](mm5.png)

Zorg dat de webhook-URL op je klembord staat en volg de onderstaande link.
