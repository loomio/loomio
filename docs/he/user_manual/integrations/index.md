# שילובים

ניתן לחבר את Loomio לכלים אחרים שהקבוצה משתמשת בהם.

<!-- translation-section: choose-where-work-belongs -->

## בחירת הכלי המתאים לעבודה

Loomio משלימה כלי צ׳אט, מסמכים משותפים וכלים לניהול משימות. לכל סוג עבודה מתאים כלי אחר.

| סוג העבודה | כלי מוצע |
|---|---|
| שאלות קצרות, שיחה חברתית ועדכונים שדורשים תגובה מהירה | צ׳אט |
| עריכה משותפת של מסמך שמתעדכן לאורך זמן | מסמך משותף |
| הקצאה ומעקב אחר משימות | כלי לניהול פרויקטים או משימות |
| דיון חשוב בנושא מסוים, השתתפות רחבה, החלטות ומסקנות | Loomio |

כדאי להשתמש ב־Loomio כשדרוש זמן לשקול נושא, כשחשוב לתת לכל מי שהנושא נוגע להם הזדמנות להשתתף, או כשהקבוצה תצטרך למצוא את הדיון וההחלטה בהמשך. ניתן לקשר מהדיון ב־Loomio למסמך או למשימה הרלוונטיים, כדי שיהיה קל למצוא את ההקשר.
