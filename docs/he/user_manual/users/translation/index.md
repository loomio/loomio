# שפות ותרגום

Loomio תומכת בשפות רבות באמצעות שתי תכונות:

1. תרגום הממשק - ניתן לשנות את שפת הכפתורים ושאר הטקסט בממשק.
2. תרגום תוכן - ניתן לתרגם תגובות, דיונים והצעות לשפה המועדפת.

<!-- translation-section: application-translation -->

## תרגום הממשק

בעת פתיחת Loomio בדפדפן, השפה המועדפת מזוהה באופן אוטומטי.  כדי לשנות אותה, יש לפתוח את הדף "עריכת פרופיל".

![שינוי השפה המועדפת](change_language.png)

<!-- translation-section: content-translation -->

## תרגום תוכן
כאשר הודעה בקבוצה נכתבת בשפה שונה מהשפה המועדפת, מופיע מתחתיה כפתור "תרגום". ניתן לבחור בו כדי לתרגם את ההודעה באופן אוטומטי לשפה המועדפת.

![תרגום תוכן](content_translation.png)

הטקסט המתורגם מחליף את הטקסט המקורי בדיון. כדי להציג שוב את הטקסט המקורי, יש לבחור **מְקוֹרִי**.

![תגובה שתורגמה מספרדית לאנגלית](content_translated.png)

תרגום תוכן משתמשים נעשה באמצעות Google Translate, לפי בקשת המשתמשים.

## תרגום אוטומטי

כדי לתרגם תוכן נתמך באופן אוטומטי, יש לפתוח את **עריכת פרופיל** ולבחור **תרגם תוכן לשפה שלי באופן אוטומטי**. Loomio משתמשת בשפה שנבחרה בפרופיל.
