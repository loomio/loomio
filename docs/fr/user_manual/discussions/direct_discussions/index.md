# Discussions directes

Une discussion directe est une discussion privée réservée à des personnes précises.

Une discussion directe n’appartient à aucun groupe. Les personnes invitées n’ont pas besoin d’être membres de votre groupe Loomio.

Vous choisissez qui peut voir la discussion et y participer en ajoutant des personnes ou des adresses e-mail dans le champ **Inviter**.

Les discussions directes disposent des mêmes commentaires, sondages et autres outils que les discussions de groupe. Elles sont utiles lorsqu’il n’est pas nécessaire de créer un sous-groupe.

![Formulaire de discussion directe sans groupe sélectionné, avec Samira Patel dans le champ Inviter](direct-discussion-example.png)

Sélectionnez **Discussions directes** dans la barre latérale pour voir vos discussions directes. Sur cette page, sélectionnez **Nouvelle discussion** pour en commencer une autre.

![L’élément Discussions directes dans la barre latérale et la liste des discussions directes](direct-discussion-sidebar.png)

<!-- translation-section: contacting-someone-via-a-direct-discussion -->

## Contacter quelqu’un par une discussion directe
Vous pouvez utiliser une discussion directe pour contacter une ou plusieurs personnes en privé sans créer de sous-groupe.
