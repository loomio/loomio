# Loomioのファシリテーターガイド

ファシリテーションの主要な概念をオンラインの場で活用するための詳しいガイドです。

Loomioはファシリテーターによって作られており、そのことが設計に大きく影響しています。このガイドでは、その背景を詳しく紹介し、対面の場で使われるファシリテーションの概念をオンラインの場に応用する方法を説明します。

<!-- translation-section: more-about-this-guide -->

## このガイドについて

専門のファシリテーターが使う場合も、参加者同士で進行を支え合う場合も、ファシリテーションをまったく知らないグループが使う場合も、Loomioの基本的な役割は、望ましい結論に向けてグループのコミュニケーションを仲介し、支えることです。つまり、ファシリテーションです。

Loomioは*グループウェア*です。

> 共同作業用ソフトウェア、つまりグループウェアは、共通の作業に携わる人々が目標を達成できるように設計されています。共同作業用ソフトウェアの初期の定義の一つは、「目的を持ったグループの活動と、それを支えるソフトウェア」です。 -- Wikipedia

対面でのファシリテーションとオンラインでのモデレーションには、どちらにも豊富な知識、実践方法、伝統があります。しかし、この二つを組み合わせる技法や理論は、まだ発展し始めたばかりです。Loomioが力を発揮しようとしているのは、まさにこの領域です。
