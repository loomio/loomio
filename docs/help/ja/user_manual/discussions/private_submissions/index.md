# 非公開の提出物を集める

非公開グループを使うと、グループ外の人から非公開の提出物を集められます。提出物ごとに個別のディスカッションが作成され、提出者と審査チームが情報を交換したり、質問したり、決定を記録したりできます。提出者は、グループ内のほかの非公開ディスカッションや提出物を見ることはできません。

選考中に候補者の詳細や候補者一覧を非公開にする必要がある場合、候補者の推薦に活用できます。選挙や委員会、理事会の役職の候補者として、自分自身やほかの人を推薦できます。選考委員会は、推薦ごとに個別のスレッドで審査します。

ほかにも、次のような用途があります。

- 苦情、虐待や危害から人を守るための報告、安全上の懸念、事故や問題の報告
- 個別の案件に関する決定への異議申し立てや再検討の依頼
- 調停、紛争解決、個人的な支援の依頼
- 生活困窮者向けの助成金や奨学金など、個人情報、財務情報、申請資格に関する情報を含む申請
- 審査中に非公開にする必要がある封印入札や入札への回答

この手順では提出者同士に提出物が公開されませんが、匿名ではありません。提出者にはユーザーアカウントが必要で、非公開グループのすべてのメンバーがすべての提出物を見ることができます。機密性の高い情報を扱う場合は、事前にグループのメンバーを確認してください。

## 非公開の提出を有効にする

提出物を集めるグループまたはサブグループのグループ管理者である必要があります。

1. グループを開きます。
2. **設定**を開き、**グループ設定を編集する**を選択します。
3. **権限**を開きます。
4. **非会員でも議論を開始できます**を有効にします。
5. グループ設定を保存します。

![グループ設定の「権限」タブで「非会員でも議論を開始できます」が強調表示されている画面](non_members_can_start_discussions.png)

この設定は、**議論中**と**閉鎖**のグループでのみ表示され、**秘密**のグループでは表示されません。表示されない場合は、グループ設定の**プライバシー**を開き、**グループのプライバシー**を**閉鎖**（非公開の提出物を集める場合に推奨）または**議論中**に設定してから、**権限**に戻ります。

この権限を有効にしても、グループのディスカッションは公開されません。メンバーではない人は、ディスカッションを始め、ゲストとしてそのスレッドにアクセスできますが、グループ内のほかの非公開ディスカッションを見ることはできません。

## 非公開の提出手順を設定する

1. 提出物を受け付ける専用のサブグループを作成し、プライバシーを**閉鎖**に設定します。サブグループを使うと、提出物を親グループのほかの活動から分けて管理できます。
2. 審査チームや選考委員会の担当者をサブグループのメンバーとして追加します。サブグループのすべてのメンバーがすべての提出物を見ることができるため、アクセスが必要な人だけを追加します。
3. サブグループに、提出者が回答すべき質問や提供すべき詳細情報を含む[ディスカッションのテンプレート](/en/user_manual/discussions/templates)を1つ以上作成します。
4. 提出者からサブグループへの参加申請を受け付けない場合は、参加方法を**招待のみです**に設定します。
5. サブグループの権限で[非公開の提出を有効にします](#enable-private-submissions)。
6. サブグループのメンバーではないアカウントで手順を確認します。
7. 提出者にサブグループのページを共有します。提出する前に、ユーザーアカウントにサインインする必要があります。

## 提出する

提出者はサブグループを開き、**新しいスレッド**を選択します。Loomioに、そのサブグループのディスカッションのテンプレートが表示されます。提出者は適切なテンプレートを選び、質問に回答してディスカッションを始めます。

ディスカッションはサブグループに属し、Loomioは提出者をそのスレッドにゲストとして追加します。提出者はサブグループのメンバーにはなりません。自分のスレッドで審査チームとやり取りできますが、サブグループ内のほかの非公開ディスカッションや提出物を見ることはできません。

<!-- translation-section: review-submissions -->

## 提出物を審査する

サブグループのメンバーは、サブグループ内の提出物に関するすべてのスレッドを見ることができます。追加の質問をしたり、コメント、アンケート、その他のツールを使ったりして、審査を進められます。

ほかの人の意見が必要な場合は、権限を持つサブグループのメンバーが、その人をスレッドに招待できます。たとえば、推薦者が推薦を提出した後、選考委員会は候補者をスレッドに招待できます。招待された人はゲストとして参加し、サブグループ内のほかの非公開ディスカッションへのアクセス権は得ません。

提出の受け付けを締め切ったら、**非会員でも議論を開始できます**を無効にします。既存の提出物のスレッドとゲストのアクセス権は変わりません。
