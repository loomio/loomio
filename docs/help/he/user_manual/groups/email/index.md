# שליחת דוא״ל לפתיחת שרשור בקבוצה

לכל קבוצה ב-Loomio יש כתובת דוא״ל משלה. ניתן לשלוח או להעביר הודעת דוא״ל לכתובת זו כדי לפתוח שרשור חדש בקבוצה.

ניתן למצוא את כתובת הדוא״ל של הקבוצה בדף הקבוצה:

![מיקום כתובת הדוא״ל בדף הקבוצה](email_email_button.png)

בעת שליחת הודעת דוא״ל לכתובת זו, Loomio יוצרת שרשור חדש. נושא ההודעה הופך לכותרת השרשור, גוף ההודעה הופך לתיאור השרשור, וכל הקבצים המצורפים מתווספים לשרשור.

Loomio משתמשת בכתובת הדוא״ל בשדה "מאת" כדי לזהות את חשבון החבר בקבוצה שממנו נשלחה ההודעה ולשייך אליו את השרשור כמחבר.

## מניעת הודעות דוא״ל לא מורשות

כדי למנוע פתיחת שרשורים בידי מי שאינם חברים בקבוצה, Loomio דורשת שהכתובת בשדה "מאת" של הודעת דוא״ל נכנסת תתאים לכתובת הדוא״ל של אחד מחברי הקבוצה.

כאשר הודעת דוא״ל של חבר בקבוצה נשלחת מכתובת לא מזוהה, Loomio מעכבת את ההודעה ושולחת התראה למנהלי הקבוצה. מנהלי הקבוצה יכולים לאשר את ההודעה ולהוסיף את הכתובת ככתובת חלופית לאותו חבר, או לדחות הודעות דוא״ל נוספות מכתובת זו.

לאחר הוספת כתובת חלופית, הודעות דוא״ל עתידיות מכתובת זו פותחות שרשורים מיד.
