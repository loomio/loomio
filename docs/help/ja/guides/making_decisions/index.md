# 意思決定

これらのガイドでは、決定する内容を明確にし、関係する人々に参加してもらい、ディスカッションと提案を活用し、懸念に対応して結論を記録するまでの、意思決定のプロセス全体を説明します。

これらのガイドは、提案テンプレートのページとは異なります。[提案テンプレート](/en/user_manual/polls/proposals/)では、個々の提案とその回答の選択肢を説明します。意思決定のプロセスでは、段階を追って複数の提案を使うことがあります。

<!-- translation-section: choose-a-process -->

## プロセスを選ぶ

| プロセス | 決定する人 | 主な問い |
|---|---|---|
| [シンプルな意思決定プロセス](simple_decision_process) | グループが定めます | どのように話し合い、試し、決定できますか？ |
| [助言プロセス](advice_process) | 個人または権限を委任されたチーム | 決定する人はどのような助言を考慮すべきですか？ |
| [同意プロセス](consent_process) | グループ | 重要な異議がなく、提案を安全に試せますか？ |
| [コンセンサスプロセス](consensus_process) | グループ | 全員で合意に達することができますか？ |

グループの運営規則や意思決定方針で定められたプロセスを使います。決定の種類によって、異なるプロセスを使うこともあります。

回答形式を選ぶための説明だけが必要な場合は、[提案](/en/user_manual/polls/proposals/)と[アンケート](/en/user_manual/polls/proposal_types/)を比較してください。**投票を開始する**を選択したときに表示される、再利用可能なテンプレートを管理する場合は、[アンケートのテンプレート](/en/user_manual/polls/poll_templates/)を参照してください。
