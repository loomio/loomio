# Verificação de opinião

A verificação de opinião reúne reações enquanto uma ideia ainda está em desenvolvimento. As opções **Parece bom**, **Poderia ser melhor** e **Precisa ser repensado.** mostram se o grupo está pronto para avançar ou se deve revisar a ideia primeiro.

Esta página explica como realizar uma verificação de opinião. Veja o [Processo simples de decisão](/en/guides/making_decisions/simple_decision_process), o [Processo de consentimento](/en/guides/making_decisions/consent_process) ou o [Processo de consenso](/en/guides/making_decisions/consensus_process) para ver exemplos de como usá-la como etapa de um processo maior.

<!-- translation-section: when-to-use-sense-check -->

## Quando usar a verificação de opinião

Use a verificação de opinião para:

- avaliar um rascunho inicial antes de investir em uma proposta detalhada;
- identificar dúvidas e preocupações antes de uma decisão formal;
- verificar se é necessária outra rodada de discussão; ou
- comparar o apoio antes e depois de revisar uma ideia.

Não considere **Parece bom** uma aprovação formal, a menos que o grupo tenha concordado explicitamente com isso. Use [Consentimento](../consent/) ou [Consenso](../consensus/) quando a resposta precisar autorizar uma decisão.

<!-- translation-section: example-check-a-trial-plan -->

## Exemplo: avaliar um plano piloto

A Cooperativa Oatmilk elaborou um plano piloto de garrafas retornáveis. Ela realiza uma verificação de opinião para saber se o cronograma de coleta, as verificações de lavagem e o plano de prestação de contas estão prontos para a revisão final.

<!-- translation-section: set-up-the-proposal -->

## Configure a proposta

Informe em que estágio está a ideia e o que será feito com os comentários recebidos. Mantenha o significado padrão das respostas ou adapte-o à linguagem do grupo. Defina um prazo de encerramento que dê tempo suficiente para revisar o plano.

![](form.png)

<!-- translation-section: vote -->

## Vote

Os participantes escolhem a resposta que melhor representa sua opinião no momento e explicam o que está pronto ou o que precisa mudar. Uma justificativa útil dá a quem criou a proposta algo específico para fazer.

![](../proposal_sense_check_voting.png)

<!-- translation-section: read-the-results -->

## Leia os resultados

O gráfico mostra o número e a proporção de votos para cada resposta. Leia as justificativas além da distribuição dos votos: uma preocupação bem fundamentada pode exigir atenção mesmo quando a maioria dos participantes seleciona **Parece bom**.

![](../proposal_sense_check_results.png)

<!-- translation-section: share-an-outcome -->

## Compartilhe uma conclusão

Quando a verificação de opinião terminar, compartilhe uma conclusão. Resuma as mudanças que o grupo fará ou registre que a ideia está pronta para a próxima etapa da decisão. Veja [Compartilhe uma conclusão](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome) para saber como as conclusões funcionam.
