# Удаление вашего аккаунта Loomio

<!-- translation-section: what-does-delete-account-mean -->

## Что означает удаление аккаунта?

Удаление аккаунта необратимо. Когда вы удаляете свой аккаунт:

- Loomio удаляет ваш аккаунт, включая ваше имя, адрес электронной почты и другие персональные данные. Вы больше не сможете войти с этим аккаунтом.
- Ваши комментарии, предложения и обсуждения остаются, но ваше имя удаляется из них, чтобы ветки группы сохраняли связность.
- Вы перестаёте быть участником всех групп.
- Вы перестаёте получать уведомления по электронной почте.

Копии ваших действий в Loomio уже могли быть отправлены участникам группы по электронной почте. Loomio не может удалить уже отправленные письма.

Удаление аккаунта не отменяет платную подписку. Чтобы прекратить платежи, см. раздел [Подписки](/policy/subscriptions/management/#cancel-your-plan).

Подробнее о том, как Loomio обрабатывает ваши данные, читайте в нашей [политике конфиденциальности](/policy/privacy/) или [свяжитесь с нами](/contact). Если перед удалением вам нужна копия записей группы, администратор группы может [экспортировать данные группы](/en/user_manual/groups/data_export).

## Как полностью удалить аккаунт

1. Войдите в Loomio.
2. Откройте меню пользователя, выбрав ваше имя на боковой панели, затем выберите **Редактировать профиль**. Если боковая панель закрыта, откройте её с помощью кнопки меню (**☰**).

![](profile_edit.png#width-50)

3. Прокрутите страницу вниз и выберите **Удалить аккаунт**.

![](delete_user.png)

4. Подтвердите, что вы хотите навсегда удалить свой аккаунт.

![](permanently_delete_account.png#width-80)
