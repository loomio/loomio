# メンバー管理

管理者は、グループページの**メンバー**タブからメンバーを管理できます。

グループのメンバーの右側にある3点メニュー（**⋮**）をクリックすると、タイトルの設定、管理者や代理人への変更、グループからの削除ができます。

![Oatmilk Cooperativeのメンバーページにあるメンバー操作メニュー](member_management.png)

<!-- translation-section: administering-your-group -->

## グループの管理
Loomioのグループには、**メンバー**と**管理者**の2種類のユーザーだけが存在します。

管理者は、メンバーの追加と削除、メンバーの権限管理、グループのプライバシーレベルの設定、サブスクリプションプランの管理など、グループの管理作業を行います。また、メンバーのメールアドレスの確認やグループのデータのエクスポートもできます。

新しいLoomioグループを作成した人は、初期設定で管理者になります。常に誰かがグループを管理できるように、グループ内の信頼できる人を少なくとももう1人、管理者にすることをお勧めします。管理者の人数に制限はありません。

メンバーを**管理者**にするには、メンバータブで対象のメンバーを探し、名前の横にある3点メニュー（**⋮**）をクリックします。**管理者を作ります**を選択すると、名前の横に`Admin`タグが表示されます。

![メンバーのメニューにある管理者への変更操作](member_make_admin.png)

<!-- translation-section: managing-subgroups -->

## サブグループの管理
親グループまたは組織の管理者には、__非公開__のサブグループに対する追加の権限があります。

対象のサブグループページの左側（タブのすぐ下）にある「グループに参加」ボタンをクリックすると、どの非公開サブグループにも参加できます。

![非公開のOatmilk Cooperativeサブグループにあるグループ参加ボタン](member_join_subgroup.png)

サブグループに参加した後は、他のメンバーを管理者にするのと同じ方法で、自分自身をそのサブグループの管理者にすることもできます。

>[!Note]
>これらの権限は、[**秘密**のサブグループ](/en/user_manual/groups/subgroups/?highlight=secret#permissions)には適用されません。

<!-- translation-section: removing-members -->

## メンバーの削除
**グループから削除**をクリックすると、削除の確認を求められます。削除されたユーザーは、グループのページ、スレッド、アンケート、提案にアクセスできなくなります。グループの活動に関するメールや通知も届かなくなります。ただし、そのユーザーが投稿したコメントや行った投票はそのまま残ります。

![メンバーのメニューにあるグループからの削除操作](member_remove.png)

削除したメンバーは、後で再びグループに追加できます。

## グループからの脱退
グループを離れるには、グループページで3点メニューを開き、**グループを離れる**をクリックします。

![Oatmilk Cooperativeの設定メニューにあるグループからの脱退操作](member_leave_group.png)

<!-- translation-section: set-title -->

## タイトルの設定
メンバータブでは、**タイトル**を使ってグループ内での役割や、代表している組織を表示することもできます。本人またはグループの管理者が、名前の近くにある3点メニューから**タイトルを設定する**を選択して、タイトルを変更できます。

![メンバーのメニューにあるタイトルの設定操作](member_set_title.png)

サブグループごとに異なるタイトルを設定できます。

<!-- translation-section: member-email-addresses -->

## メンバーのメールアドレス

グループのメンバーのメールアドレスを確認できるのは管理者だけです。グループのメンバーを点検する際に、メールアドレスの確認が必要になることがあります。

メンバーのメールアドレスを確認するには、[データのエクスポート](/en/user_manual/groups/data_export/)でCSVファイルをダウンロードし、ExcelまたはGoogle スプレッドシートで開きます。

エクスポートしたグループのデータファイルには、すべてのサブグループの各メンバーとそのメールアドレスが表示されます。

メンバータブでは、メールアドレスでメンバーを検索することもできます。削除したいメンバーがいる場合は、メールアドレスで検索して削除できます。
