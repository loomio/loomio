# Manage voters in one window

Poll administrators can now find existing voters and invite new people from the same field in **Manage voters**. The voter list shows the most recently added people first, with pages for larger polls. Selecting invitees gives the invitation form the full window; clearing the selection returns to the voter list.

On polls with vote weights, administrators can change one person's weight or set all weights to member defaults or a shared value. Removing a voter requires confirmation. Removal is unavailable for anonymous polls.
