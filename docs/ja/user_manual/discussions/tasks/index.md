# タスク

スレッドやコメントでタスクを使うと、行うことを記入し、担当者を割り当て、期限を設定して、完了状況を確認できます。

<!-- translation-section: add-a-task -->

## タスクを追加する

スレッドやコメントの作成中に、書式設定ツールバーを展開して**タスクリスト**をクリックします。チェックボックスの横に、行うことを入力します。

![](tasklist1.png)

<!-- translation-section: name-and-assign-the-task-to-a-person -->

## タスクの内容を記入し、担当者を割り当てる

タスク内でグループのメンバーを@メンションすると、そのメンバーを担当者に割り当てられます。担当者が割り当てられると、**期限を追加**ボタンが表示されます。

![](tasklist2.png)

自分に割り当てられたタスクは、**タスク**ページに表示されます。サイドバーから**タスク**を開くと、スレッドやアンケートごとにまとめられたタスクを確認できます。

![](task_list.png)

<!-- translation-section: set-a-reminder -->

## リマインダーを設定する

**期限を追加**をクリックして、期限と、Loomioが担当者にリマインダーメールを送信するタイミングを選択します。このダイアログから、設定済みの期限を削除することもできます。

![](taskreminderform.png)

<!-- translation-section: mark-it-as-done -->

## 完了にする

![](taskdone.png)

タスクの横にあるチェックボックスをクリックすると、タスクが完了になります。テキストの編集中、担当者としてテキストを読んでいるとき、または**タスク**ページから操作できます。もう一度クリックすると、タスクが未完了に戻ります。
