# Резервное копирование или экспорт данных группы

С помощью экспорта данных группы вы можете:

- Скачать файл с данными участников для проверки состава группы.
- Скачать содержимое группы, включая тексты веток и опросов, для архивирования или анализа.
- Открыть результаты опросов в электронной таблице или обработать их на скриптовом языке программирования.
- [Распечатать ветку или опрос либо сохранить их в PDF для архивирования.](#print-thread-to-pdf)
- Перенести группу, включая всех пользователей, ветки, опросы и файлы, на другой сервер Loomio.

Если вы захотите перейти с серверов, управляемых Loomio, [на собственный сервер](https://github.com/loomio/loomio), вы можете воспользоваться этой функцией.

Если вы используете собственный сервер Loomio и больше не хотите обслуживать его самостоятельно, Loomio предлагает управляемый хостинг в США, ЕС и Австралии. Чтобы перенести группу на один из этих серверов, [свяжитесь с нами](/contact).

[Свяжитесь с нами](/contact), если вы хотите перенести группу Loomio с нашего глобального сервиса loomio.com на один из региональных сервисов: loomio.eu для Европы или loomio.nz для Австралии и Новой Зеландии.

## Экспорт данных

Нажмите на три точки, чтобы открыть выпадающее меню группы, и выберите **Экспортировать данные группы**.

![Команда экспорта данных группы в меню Oatmilk Cooperative](group_export_group_data.png)

<!-- translation-section: export-group-data-as-csv -->

### Экспорт данных группы в CSV

*Для работы с данными группы в электронной таблице, например в MS Excel или Google Sheets.*

Loomio подготавливает файл CSV в фоновом режиме и отправляет вам по электронной почте ссылку для скачивания, когда файл готов. Ссылка доступна в течение одной недели.

<!-- translation-section: export-group-data-as-html -->

### Экспорт данных группы в HTML

*Для сохранения данных в архиве.*

Loomio подготавливает файл HTML в фоновом режиме и отправляет вам по электронной почте ссылку для скачивания, когда файл готов. Ссылка доступна в течение одной недели.

<!-- translation-section: export-group-data-as-json -->

### Экспорт данных группы в JSON

*Для переноса данных группы на собственный сервер Loomio.*

Чтобы экспортировать данные группы, вы должны быть её администратором. Экспорт в JSON включает:

- Группу, её участников и заявки на вступление
- Ветки, комментарии, реакции, теги, шаблоны, уведомления и связанные записи из включённых в экспорт групп
- Опросы, варианты, голоса и выводы; анонимный опрос включается только после его закрытия
- Подгруппы, в которых вы состоите
- Открытые, закрытые и видимые родительской группе подгруппы при экспорте их родительской группы, если вы являетесь её администратором, даже если вы не состоите в этих подгруппах
- Ссылки на файлы и изображения, прикреплённые к включённому в экспорт содержимому

Экспорт в JSON не включает:

- Секретные подгруппы, в которых вы не состоите, включая данные об их участниках и содержимое
- Подгруппы, ожидающие удаления
- Анонимные опросы, которые ещё не закрыты
- Личные ветки и опросы, которые не относятся к группе

Вскоре вы получите письмо со ссылкой для скачивания файла JSON.

## Печать ветки в PDF

Вам может понадобиться копия ветки для хранения в отдельном файловом архиве.

Команда **Печать** сохраняет все комментарии, опросы, голоса и выводы, а также форматирование ветки.

Откройте меню ветки, нажав на три точки (⋯), и выберите **Печать**. Loomio создаст HTML-страницу, которую вы сможете распечатать или сохранить в PDF с помощью функции печати в браузере.

Вы можете скопировать страницу и вставить её содержимое в редактор документов, файл или хранилище данных.

![Команда печати для обсуждения возвратных бутылок](discussion_print_discussion.png#width-90)

## Импорт данных группы на другой сервер Loomio

Инструкции по настройке собственного сервера Loomio доступны по адресу: https://github.com/loomio/loomio

Если вы используете собственный сервер Loomio и хотите импортировать экспортированные данные:

Скопируйте файл .json в папку `import` экземпляра контейнера:

`scp your-group-data.json username@some-domain.org:loomio-deploy/import`

Откройте консоль Rails в работающем контейнере:

`docker exec -ti loomio-app rails console`

Вызовите сервис:

`GroupExportService.import('/import/your-group-data.json')`
