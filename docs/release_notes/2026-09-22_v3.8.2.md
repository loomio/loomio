Loomio 3.8.2 restores auditable BLT exports for closed anonymous STV elections, tightens permissions for moving thread items, and fixes subgroup invitations and time poll editing.

- **Fix:** Export closed anonymous STV ballots in BLT format
- **Fix:** Require topic admin permission before moving thread items
- **Fix:** Bug inviting everyone in the parent group to a subgroup, or everyone in a subgroup to another subgroup
- **Fix:** Preserve manually selected time zones when editing time polls
- **Fix:** Prevent time picker validation from hanging the browser
- **Fix:** Upload the avatar file selected in the profile form
- **Fix:** Keep demo group creation working when automatic translation quota is exhausted

## Upgrade

See [Upgrading Loomio](https://github.com/loomio/loomio/blob/master/deploy/UPGRADING.md) for instructions. This release requires no additional upgrade steps.
