# 同意

同意の提案では、ある行動を安全に試せるかどうかを確認します。参加者は同意するか、異議を申し立てます。異議では、提案で対処すべき具体的なリスクや害を示します。

このページでは、同意の提案を実施する方法を説明します。質問、意向確認、修正、異議、結論を含む一連の進め方については、[同意のプロセス](/en/guides/making_decisions/consent_process)を参照してください。

<!-- translation-section: when-to-use-consent -->

## 同意を使う場面

グループが、有効な異議がなければ実行に移せる、実用的な決定を必要としている場合に、同意を使います。試験的な取り組み、運営方針、役割についての合意など、経験を積んだ後にグループで見直せる決定に適しています。

同意では、全員がその提案を最も望ましいと考える必要はありません。投票前に、何を異議として扱うかを定義し、異議をどのように検証して解決するかを説明してください。

<!-- translation-section: example-start-a-bottle-trial -->

## 例：回収・再利用できるボトルの試験導入を始める

Oatmilk Cooperativeは、来月から6週間、回収・再利用できるボトルを試験導入することを提案しています。試験導入は範囲を限定し、見直しも予定しているため、グループは安全に試せるかどうかを確認します。

<!-- translation-section: set-up-the-proposal -->

## 提案を設定する

提案する行動、その範囲や制限、安全対策、見直しの時点を説明してください。**同意**と**異議**の意味を明確にし、懸念を理解して対処できるように、異議には理由を必須にしてください。

![](form.png)

<!-- translation-section: vote -->

## 投票する

参加者は、提案が自分の最も望む計画ではなくても、試すうえで十分に安全だと考える場合は**同意**を選択します。重大なリスクや害を具体的に説明できる場合は**異議**を選択します。

![](../proposal_consent_voting.png)

<!-- translation-section: read-the-results -->

## 結果を確認する

グラフで異議の有無を確認できますが、グループはその理由を検討する必要があります。有効な異議には、提案の修正、安全対策の追加、範囲の変更、または実行しないという決定によって対処してください。

![](../proposal_consent_results.png)

<!-- translation-section: share-an-outcome -->

## 結論を共有する

提案を締め切ったら、結論を共有してください。合意した行動、異議をどのように解決したか、担当者、グループで見直す時期を記録してください。結論の仕組みについては、[結論を共有する](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome)を参照してください。
