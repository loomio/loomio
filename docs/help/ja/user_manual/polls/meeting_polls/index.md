# 日程調整

**日程調整**を使って、会議やイベントの日時を決めます。Doodleなどの日程調整ツールと同じ目的で使え、グループの他のLoomioでの活動と一緒に日程調整を進められます。参加者には、自分のタイムゾーンで選択肢が表示されます。

![](meeting_polls.png)

<!-- translation-section: time-poll -->

## 日程調整

_参加者が集まれる日時を探します_

会議やイベントの日程を調整する時間を節約できます。

![](timepoll_label.png)

日程調整では、全員の都合を確認し、最適な日時を簡単に見つけられます。

日程調整のタイトルと詳細を入力します。自分のタイムゾーンで、日時の選択肢を一覧にして入力します。

時間枠を設定する際は、異なるタイムゾーンにいる人にも配慮します。参加者には、それぞれのタイムゾーンに合わせた日時が表示されます。

会議の所要時間を設定します。

![](timepoll_options.png)

<!-- translation-section: voting -->

### 投票

参加できる日時には緑色の親指を上に向けたアイコン、必要であれば参加できる日時には黄色の親指を横に向けたアイコン、参加できない日時には赤色の親指を下に向けたアイコンを付けます。

参加者は、主催者が適切な日時を見つけられるよう、理由をコメントとして残せます。

提示された日時では都合が合わない場合、参加者はメッセージ欄で別の日時を提案できます。その後、アンケートに新しい日時を追加できます。

![](timepoll_vote.png)

投票が進むにつれて結果が更新され、誰がいつ参加できるかが表に表示されます。全員が、どの時間枠に多くの参加者が集まれるかを確認できます。

<!-- translation-section: outcome -->

### 結論を共有する

日程調整を締め切ったら、最適な日時を選び、結論を共有します。結論の仕組みについては、[結論を共有する](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome)を参照してください。

![](timepoll_outcome.png)

**通知する**: 会議やイベントに招待する人を追加します

**会議の時間**: 最適な日時を選択します

**会議名**: 会議に名前を付けます。既定では日程調整のタイトルが使われます

**位置**: 会場の所在地またはオンライン会議のリンクを追加します

**声明**: 結果を要約し、会議に関する案内を追加します

Loomioは、選択した日時、会議名、所要時間、位置、声明を、結論の通知とカレンダーの招待に含めます。
