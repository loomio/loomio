# מחיקת הקבוצה

מחיקת קבוצה מחייבת הרשאות מנהל קבוצה. מחיקת קבוצה מסירה את הגישה מיד ומתזמנת את כל נתוני הקבוצה ותת־הקבוצות שלה למחיקה לצמיתות לאחר 90 יום.

לפני מחיקת קבוצה, יש [לייצא את נתוני הקבוצה](/en/user_manual/groups/data_export) ולהוריד את כל הקבצים שהועלו שברצונכם לשמור.

כדי למחוק קבוצה, יש לפתוח את תפריט הפעולות של הקבוצה ולבחור באפשרות **מחק קבוצה**.

![פעולת מחיקת קבוצה בתפריט של קואופרטיב Oatmilk](group_delete_group.png)

יש להזין את מזהה הקבוצה כדי לאשר את המחיקה.

![טופס אישור המחייב הזנת המזהה של קואופרטיב Oatmilk](group_delete_group_confirm.png)

לאחר אישור המחיקה:

- הקבוצה ותת־הקבוצות שלה מוסרות מהתצוגה מיד. חברים ומנהלי קבוצה מאבדים את הגישה לצפייה בתוכן, להשתתפות או לייצוא, לרבות סקרים שנפתחים מקישורים שמורים.
- התראות פעילות ותזכורות לסקרים הממתינות לשליחה עבור הקבוצה ותת־הקבוצות שלה נעצרות, אך הודעות שכבר נמצאות בתהליך שליחה עשויות עדיין להגיע.
- המינוי ל-Loomio מבוטל.
- דיונים וסקרים ישירים מחוץ לקבוצה אינם מושפעים.

Loomio שולחת גם הודעת אזהרה בדוא״ל הכוללת את מספר תת־הקבוצות, החברים, הדיונים, הסקרים והתגובות בקבוצה. אם הקבוצה נמחקה בטעות או שעדיין יש צורך לייצא את נתוניה, יש להשיב להודעה זו או לפנות אלינו בתוך 90 יום כדי לשחזר את הגישה.

## נתוני הקבוצה נמחקים לצמיתות לאחר 90 יום

לאחר 90 יום, Loomio מוחקת לצמיתות את כל השרשורים, הסקרים, הקבצים ושאר התוכן בקבוצה ובתת־הקבוצות שלה. לא ניתן לבטל את המחיקה.
