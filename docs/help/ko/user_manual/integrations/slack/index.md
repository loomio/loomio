# Slack 연동

Loomio는 새 토론, 투표, 댓글, 표, 결론이 등록되면 Slack 채널로 알림을 보낼 수 있습니다.

---

1. [api.slack.com](https://api.slack.com)에 접속하여 로그인한 다음 **새 앱 만들기**를 선택하세요.

   ![](s1.png)

2. Slack 앱의 이름을 입력하고 워크스페이스를 선택하세요.

   ![](s2.png)

3. **수신 웹훅**을 선택하세요.

   ![](s3.png)

4. **수신 웹훅 활성화**를 켜세요.

   ![](s4.png)

5. **워크스페이스에 새 웹훅 추가**를 선택하세요.

   ![](s5.png)

6. Loomio 알림을 표시할 채널을 선택하세요.

   ![](s6.png)

7. 웹훅 URL을 복사하세요.

   ![](s7.png)

이제 웹훅 URL을 준비했으니 Loomio에서 연결을 완료하세요.

[Loomio에서 채팅 연동 설정하기](../chatbots/#set-up-a-chat-integration)

_Loomio는 Slack이 제작한 서비스가 아니며, Slack과 제휴 관계가 없고 Slack의 지원을 받지 않습니다._
