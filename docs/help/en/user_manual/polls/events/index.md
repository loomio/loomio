# Events

Use an **Event** to schedule an event and confirm who’s coming. People respond with **Going**, **Maybe**, or **Not attending**, either in Loomio or through a compatible email or calendar client.

Choose **Event** when starting a poll, or choose **Create an event** on a [Time poll outcome](/en/user_manual/polls/meeting_polls#share-an-outcome). A Time poll finds the best time; an Event asks people to confirm attendance at the chosen time.

<!-- translation-section: schedule -->

## Schedule an event

Give the Event a title, start and end times, and a location or meeting link. Choose the event time zone, or select **All day** for an event that lasts one or more whole days. Set a response deadline; by default, attendance closes when the event starts.

Events use the same permissions as other polls. People who can start polls can create Events, and thread admins can edit or cancel them. Attendance responses are named and have equal weight.

<!-- translation-section: attendance -->

## Confirm attendance

Invite people using the Event’s voter controls. Calendar invitations request an explicit response. Accepting records **Going**, a tentative response records **Maybe**, and declining records **Not attending**.

**No response** means Loomio has no attendance response from that person. It does not indicate whether they received or read the invitation. Email delivery information is separate from attendance.

Attendance appears as three groups: **Going**, **Maybe**, and **Not attending**. Each shows a count and a crowd of participant avatars, with names available when you hover or focus an avatar. The groups appear side by side on larger screens and stack on mobile. Choose **Show more** to load additional avatars for larger groups. **No response** appears separately below the crowds.

People can also respond directly in Loomio. If a calendar response does not appear in Loomio, use the link in the invitation to record attendance there.

<!-- translation-section: changes -->

## Change or cancel an event

Editing the schedule sends updated calendar invitations to people who previously received one. A change to the start or end time requests fresh attendance confirmations.

Choose **Cancel event** to cancel the event and send calendar cancellations. Closing attendance early ends responses while keeping the event scheduled.

Events also appear on the [group calendar](/en/user_manual/groups/calendar). Subscribing to that calendar lets people follow upcoming work; they still need to respond to each Event to confirm attendance.
