# Votes page

The Votes page now shows voters in a table with their vote, voting date, and weight when the poll uses vote weights. It no longer displays vote reasons. Search and page controls help find voters in longer polls.

For anonymous polls, poll coordinators can select **View votes** to verify participation on the same page. The table includes the membership and invitation details previously shown on Verify participants. Whether each person voted remains hidden until at least three people have voted, and the page never shows an anonymous person's choices or voting time. Access to these records remains limited to eligible roles.
