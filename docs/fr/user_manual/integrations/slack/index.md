# Intégration Slack
_Connectez les notifications de votre groupe Loomio à Slack._

Loomio peut envoyer des notifications dans vos canaux Slack lorsqu’il y a de nouvelles discussions, propositions, commentaires, votes ou conclusions. Recevez les informations importantes au bon moment pour suivre les discussions et les décisions qui comptent.

---

Commencez par ouvrir [https://api.slack.com](https://api.slack.com), connectez-vous si nécessaire, puis cliquez sur Create New App

![](s1.png)

Donnez un nom à votre application Slack

![](s2.png)

Ajoutez la prise en charge des webhooks entrants

![](s3.png)

Activez ensuite cette fonction

![](s4.png)

Ajoutez ensuite un webhook

![](s5.png)

Sélectionnez un canal

![](s6.png)

Copiez l’URL du webhook dans votre presse-papiers

![](s7.png)

Une fois l’URL du webhook obtenue, poursuivez la configuration de votre intégration de messagerie :

[Configurer une intégration de messagerie dans Loomio](../chatbots/#set-up-a-chat-integration)

_Loomio n’est ni créé par Slack, ni affilié à Slack, ni pris en charge par Slack._
