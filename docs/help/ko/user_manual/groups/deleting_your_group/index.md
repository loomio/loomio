# 그룹 삭제

Loomio 그룹을 삭제하면 모든 그룹 데이터를 영구적으로 삭제하는 절차가 시작됩니다.

보관할 데이터가 있다면 계속하기 전에 반드시 [그룹 데이터를 내보내고](/en/user_manual/groups/data_export/) 업로드한 중요한 파일을 직접 다운로드하세요.

점 세 개를 클릭하여 그룹 드롭다운 메뉴를 열고 **그룹 삭제**를 선택하면 그룹에 대한 접근이 차단되고 저장된 모든 그룹 데이터의 삭제 절차가 시작됩니다. 그룹을 삭제하려면 그룹 관리자여야 합니다.

그룹을 삭제하면 즉시 화면에서 사라지며 90일 후에 영구적으로 삭제됩니다. 모든 그룹 멤버는 즉시 그룹에 접근할 수 없게 됩니다. 실수로 삭제했다면 그룹을 삭제한 날부터 90일 이내에 저희에게 연락하여 복원을 요청하세요.

삭제 대기 중인 그룹과 해당 하위 그룹에서는 멤버와 관리자가 내용을 보거나 참여하거나 데이터를 내보낼 수 없으며, 저장된 링크로 연 투표도 이용할 수 없습니다. 멤버는 콘텐츠를 작성하거나 수정하고, 투표하고, 공지나 알림을 보내고, 초대를 수락할 수 없습니다. 삭제를 확정하기 전에 그룹 데이터를 내보내고 중요한 파일을 다운로드하세요. 직접 토론과 투표에는 영향을 주지 않습니다.

그룹 삭제가 예약되면 해당 그룹과 하위 그룹에서 발송 대기 중인 활동 알림과 투표 알림이 중단됩니다. 이미 발송 중인 메시지는 도착할 수 있습니다.

경고 이메일에는 그룹의 하위 그룹, 멤버, 토론, 투표, 댓글 수가 포함됩니다. 그룹을 유지하거나 [데이터를 내보내야](/en/user_manual/groups/data_export/) 한다면 삭제 전에 접근 권한을 복원할 수 있도록 90일 이내에 답장하세요.

그룹을 삭제하면 Loomio 구독도 취소됩니다.

![Oatmilk Cooperative 메뉴의 그룹 삭제 항목](group_delete_group.png)

그룹 삭제 의사를 확인하기 위해 그룹 이름을 입력하라는 안내가 표시됩니다(*대소문자 구분*).

![Oatmilk Cooperative 핸들을 입력해야 하는 확인 양식](group_delete_group_confirm.png)

## 그룹 데이터는 90일 후에 영구적으로 삭제됩니다

90일 후에는 모든 스레드, 투표, 파일 및 기타 그룹 콘텐츠가 영구적으로 삭제됩니다. ***삭제 후에는 복원할 수 없습니다!***

계속하기 전에 [그룹 데이터를 내보내고](/en/user_manual/groups/data_export/) 업로드한 중요한 파일을 직접 다운로드하는 것이 좋습니다.
