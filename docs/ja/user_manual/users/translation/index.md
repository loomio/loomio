# 言語と翻訳

Loomio は、次の 2 つの機能で複数の言語に対応しています。

1. アプリの翻訳 - ボタンなど、画面に表示される文字の言語を変更します。
2. コンテンツの翻訳 - コメント、ディスカッション、提案を希望する言語に翻訳します。

<!-- translation-section: application-translation -->

## アプリの翻訳

ブラウザーで Loomio を開くと、優先言語が自動的に検出されます。 優先言語は「プロファイル編集」ページで変更できます。

![優先言語の変更](change_language.png)

<!-- translation-section: content-translation -->

## コンテンツの翻訳
グループ内の人が優先言語と異なる言語で投稿すると、メッセージの下に「翻訳する」ボタンが表示されます。このボタンを選ぶと、メッセージが優先言語に自動翻訳されます。

![コンテンツの翻訳](content_translation.png)

ディスカッションでは、翻訳文が原文に代わって表示されます。**オリジナル**を選ぶと、原文が再び表示されます。

![スペイン語から英語に翻訳されたコメント](content_translated.png)

ユーザーが翻訳を依頼すると、Google 翻訳を使用してコンテンツが翻訳されます。

<!-- translation-section: automatic-translation -->

## 自動翻訳

対応するコンテンツを自動翻訳するには、**プロファイル編集**を開き、**コンテンツを自動的に自分の言語に翻訳する**を選びます。翻訳には、プロフィールで選択した言語が使用されます。

![プロファイル編集ページにあるコンテンツの自動翻訳設定](automatic_translation.png)
