# グループにLoomioを導入する

役に立つ取り組みを一つ選んで、Loomioを導入します。人を招待する前にグループを整え、全員が一度は参加できるように支援し、結論を示すところまで進めます。

<!-- translation-section: choose-one-useful-starting-point -->

## 最初に取り組むことを一つ選ぶ

グループがすでに必要としている実際の取り組みから始めます。最初の用途には、短期間で完了できる規模で、参加する理由があるものが適しています。

例えば、次のような取り組みです。

- 次の会議の議題を準備します。
- 議事録を確認し、承認します。
- 文書の草案について意見を集めます。
- 日常の運営に関する小さな課題について決定します。
- 翌月の優先事項を整理します。

すべてのディスカッションや決定を一度にLoomioへ移すことは避けます。繰り返し行う取り組みがあれば、グループがLoomioに戻る理由が明確になり、実施するたびに進め方を改善できます。

<!-- translation-section: prepare-the-group-before-inviting-people -->

## 人を招待する前にグループを整える

参加した人がすぐに活用でき、どのグループなのか分かるように準備します。

- グループの名前、ロゴ、カバー画像、目的、重要なリンクを追加します。
- グループのプライバシーと権限を確認します。
- グループで日常的に使う[分類用のタグ](/en/user_manual/discussions/tags)を追加します。
- 必要な背景情報を含めて、最初の実際のディスカッションを作成します。
- コメント、リアクション、投票を実際の決定に影響させずに試すことがメンバーの役に立つ場合は、練習用のディスカッションを作成します。

プロフィールには自身の写真を、グループには組織のロゴを使います。これにより、誰からの招待なのか、メールがどの組織に関するものなのかを認識しやすくなります。

<!-- translation-section: decide-where-work-belongs -->

## 作業ごとに使う場所を決める

Loomioは、グループですでに使っているツールと併用できます。

| 用途 | 適した場所 |
|---|---|
| 簡単な質問、雑談、タイムリーな情報共有 | Slack、Teams、Matrix、Discordなどのチャット |
| 継続的に更新する文書の共同編集 | 文書共有ツール |
| 作業の割り当てと完了状況の管理 | タスク管理ツールやプロジェクト管理ツール |
| テーマを絞ったディスカッション、幅広い参加、決定、その記録の保存 | Loomio |

グループの説明やディスカッションの背景説明に、文書や他のシステムへのリンクを追加します。[チャット連携](/en/user_manual/integrations/chatbots)を使うと、Loomioでの重要な活動を、メンバーが普段確認しているチャンネルに届けられます。

Loomioで何を行うのかをメンバーに伝えます。「重要なディスカッションや決定はLoomioで行い、簡単な調整はチャットで行う」といった分かりやすい使い分けを示すと、説明なしに新しいツールを導入するよりも受け入れられやすくなります。

<!-- translation-section: decide-how-your-group-decides -->

## グループの意思決定の進め方を決める

Loomioでは、すべてのグループや決定に同じ手順を使う必要はありません。すでにルールが定まっているグループもあれば、Loomioを使いながら、より明確な意思決定の進め方を一緒に作っていくグループもあります。

<!-- translation-section: if-your-process-is-already-established -->

### 手順がすでに定まっている場合

グループの既存の要件をLoomioでの手順に反映します。正式な決定を行う前に、参加者が次の点を理解できるようにします。

- どのような種類の決定をLoomioで行えるか。
- 誰が意見を提供し、誰が決定する権限を持つか。
- 誰に投票資格があるか。
- [定足数](/en/user_manual/polls/quorum)が必要か。
- 決定に過半数、特別多数、全員の賛成、同意、またはその他の[必要な得票割合](/en/user_manual/polls/vote_share_requirements)が求められるか。
- 結論の公開時点で決定が有効になるか、別の場で承認を受ける必要があるか。
- 誰が結論を記録し、実行するか。

定款、規約、方針、または地域の法律に電子的な意思決定に関する規定がある場合は、Loomioでの手順がその要件を満たしていることを確認します。[代理投票者](/en/user_manual/groups/delegated_voters)、提案の設定、[アンケートのテンプレート](/en/user_manual/polls/poll_templates)を設定して、合意した手順を繰り返し使いやすくします。

<!-- translation-section: if-your-group-is-still-deciding -->

### グループの意思決定の方法がまだ決まっていない場合

どのように決定を行うかについて、ディスカッションを始めます。投票ツールを使うことから始めるのではなく、グループで次の点を検討します。

- どのような種類の決定を行いますか？
- 誰が影響を受け、誰に意見を求め、誰が決定の責任を負いますか？
- どの決定に助言、同意、コンセンサス、投票、または権限の委任が必要ですか？
- 決定を有効とするには、どの程度の参加や支持が必要ですか？
- 異議、同票の結果、参加不足にはどのように対応しますか？
- 決定をどのように伝え、記録し、見直し、変更しますか？

日常業務に関する決定、方針、選挙、規約の変更では、答えが異なる場合があります。一連の意思決定の手順を比較するには、[決定を行う](/en/guides/making_decisions)を参照してください。

すべてのルールを決める準備が整っていない場合は、リスクの低い決定を一つ選び、暫定的な手順について合意します。参加を求める前に結果が何を意味するかを明示し、結論を公開してから、手順がどのように機能したかを振り返ります。グループで学んだことを、グループの説明、運営に関する文書、または再利用できるテンプレートに記録します。

<!-- translation-section: invite-people -->

## 人を招待する

次の内容を説明する短い個別のメッセージを添えて、[人を招待します](/en/user_manual/groups/inviting_people)。

- グループがLoomioを使う理由。
- 最初に取り組んでほしいこと。
- いつまでに返答が必要か。
- どこで支援を受けられるか。

手順を積極的に試す少人数から始めることも、最初から全員の参加が必要な場合にグループ全体を招待することもできます。どちらの場合も、空のグループに招待するのではなく、参加できるディスカッションを用意しておきます。

<!-- translation-section: help-everyone-participate-once -->

## 全員が一度は参加できるように支援する

最初の目標は、一人ひとりが招待を受け取るだけでなく、何かを投稿したり投票したりすることです。

次の操作を依頼します。

1. サインインして、プロフィール写真を追加します。
2. 歓迎用または練習用のディスカッションを開きます。
3. 短いコメントやリアクションを投稿します。
4. 影響の小さい提案に投票し、必要に応じて理由を添えます。

メンバーはパスワードを作成する必要がありません。[メールでサインイン](/en/user_manual/users/signing_in)できます。また、メールでの返信に対応しているディスカッションでは、スレッドを開き直さずにメールへ返信できます。

<!-- translation-section: use-notifications-deliberately -->

## 目的に合わせて通知を使う

内容へのアクセスと、その内容に関する通知は別のものです。グループのメンバーは、すぐに通知されなかった場合でも、グループ内のディスカッションを見つけられます。

ディスカッションを始めるときは、その段階で意見が必要な人に通知します。特定の人に返答を求める場合は、@メンションや返信を使います。後から投票を開始するときに、投票資格のある投票者を招待します。

投票を集めるためだけにディスカッションとアンケートを一緒に作成する場合は、ディスカッションへの招待の直後にアンケートへの招待を送ることを避けます。通知せずにディスカッションを始めてアンケートから招待するか、[単独のアンケート](/en/user_manual/polls/intro_to_decisions#without-a-discussion)を実施します。

メンバーに[未読の確認と通知の設定](/en/user_manual/users/email_settings)を案内します。特に、毎日Loomioを開く予定がない場合に役立ちます。

<!-- translation-section: complete-the-first-process -->

## 最初の取り組みを完了する

最初の取り組みでは、一連の流れを最後まで示します。

1. テーマを紹介し、背景説明を記載します。
2. 必要に応じて、ディスカッションへの参加や質問を呼びかけます。
3. 適切な提案またはアンケートを開始します。
4. 必要に応じて、まだ参加していない人にリマインダーを送ります。
5. 何が決まり、次に何をするのかを示す[結論](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome)を公開します。

結論を示すことで一連の手順が完了し、メンバーが後から確認できる記録が残ります。その後、うまくいった点を尋ね、手順を調整して、次にLoomioで行う定期的な取り組みを選びます。

ディスカッションから決定までの進行方法については、[意思決定](/en/guides/making_decisions)を参照してください。理事会での実践方法については、[理事会にLoomioを導入する](/en/guides/board_processes/introduce)を参照してください。
