# グループ

Loomioのグループは、メンバーがディスカッションを行い、情報を共有し、ともに決定を下すための共有スペースです。

![説明とディスカッション一覧が表示されたOatmilk Cooperativeのグループページ](group_page.png)

グループページには、名前、説明、ロゴ、カバー画像、活動の目的や範囲を定めた文書などへのリンクを設定できます。これにより、メンバーがグループの目的や参加の仕方を理解しやすくなります。

まず、[グループを作成](/en/user_manual/groups/starting_a_group)し、[プライバシー設定](/en/user_manual/groups/settings/privacy)を選び、[参加者を招待](/en/user_manual/groups/inviting_people)します。

新しいグループを準備する場合は、[グループにLoomioを導入する](/en/user_manual/overview/introducing_loomio)を参照してください。最初に取り組む活動の選択から結論の記録まで、具体的な手順を紹介しています。

<!-- translation-section: administration-facilitation-and-moderation-code-of-conduct -->

## 行動規範

行動規範は、メンバーが参加の仕方や、不適切な行動にグループがどのように対応するかを理解する助けになります。期待される行動を定める方法については、[ファシリテーターガイド](/guides/facilitators-guide/commencing/#culture-protocol-expectations)を参照してください。
