# グループにLoomioを導入する

まず、役に立つ仕事を一つLoomioで進めましょう。招待する前にグループを準備し、全員が一度参加できるようにして、結論を出すところまで進めます。

<!-- translation-section: choose-one-useful-starting-point -->

## 最初に取り組む仕事を一つ選ぶ

グループがすでに必要としている実際の仕事から始めます。短期間で終えられる規模で、参加する理由があるものを選ぶとよいでしょう。

例えば、次のような仕事です。

- 次の会議の議題を準備する
- 会議の議事録を確認し、承認する
- 文書の草案について意見を集める
- 小さな運営上の課題について決める
- 来月の優先事項を決める

すべてのディスカッションや意思決定を一度にLoomioへ移す必要はありません。繰り返し行う仕事なら、グループがLoomioを再び使う理由が明確になり、進め方も毎回改善できます。

<!-- translation-section: prepare-the-group-before-inviting-people -->

## 招待する前にグループを準備する

招待された人が目的を理解し、すぐに使えるグループを用意します。

- グループ名、ロゴ、カバー画像、目的、重要なリンクを追加する
- グループのプライバシー設定と権限を確認する
- 定期的に使う[カテゴリタグ](/en/user_manual/discussions/tags)を追加する
- 必要な背景情報を添えて、最初の実際のディスカッションを作成する
- メンバーが気軽にコメント、リアクション、投票を試せるようにしたい場合は、練習用のディスカッションを作成する

プロフィールには自分の写真を、グループには組織のロゴを使いましょう。招待した人や、メールに関係する組織が分かりやすくなります。

<!-- translation-section: decide-where-work-belongs -->

## 仕事に使う場所を決める

Loomioは、グループがすでに使っているツールと併用できます。

| 用途 | 適した場所 |
|---|---|
| 簡単な質問、雑談、すぐに伝えたい近況 | Slack、Teams、Matrix、Discordなどのチャット |
| 更新を続ける文書の共同編集 | 共同編集できる文書ツール |
| 作業の割り当てと完了状況の管理 | タスク管理またはプロジェクト管理ツール |
| 論点を絞ったディスカッション、幅広い参加、意思決定、後から参照できる記録 | Loomio |

グループの説明やディスカッションの背景情報から、文書やほかのシステムにリンクできます。[チャット連携](/en/user_manual/integrations/chatbots)を使うと、Loomioでの重要な活動を、メンバーが普段見ているチャンネルに届けられます。

Loomioで何を行うか、メンバーに伝えましょう。「重要なディスカッションと意思決定はLoomioで行い、簡単な調整はチャットで行う」のように使い分けを示すと、導入しやすくなります。

<!-- translation-section: decide-how-your-group-decides -->

## グループの意思決定方法を決める

Loomioでは、すべてのグループや意思決定に同じ手順を使う必要はありません。すでにルールが決まっているグループもあれば、Loomioを使いながら意思決定の方法を整えていくグループもあります。

<!-- translation-section: if-your-process-is-already-established -->

### すでに手順が決まっている場合

グループの既存の要件をLoomioでの手順に反映します。正式な意思決定を始める前に、参加者が次の点を理解できるようにしてください。

- Loomioで決められる事項の種類
- 誰が意見を出し、誰が決定権を持つか
- 誰に投票資格があるか
- [定足数](/en/user_manual/polls/quorum)が必要か
- 過半数、特別多数、全員一致、同意、または別の[得票率の要件](/en/user_manual/polls/vote_share_requirements)が必要か
- 結論の公開時に決定が有効になるか、別の場での承認が必要か
- 誰が結論を記録し、実行するか

規約、細則、方針、地域の法律が電子的な意思決定について定めている場合は、Loomioでの手順がその要件に従うようにしてください。[代理投票者](/en/user_manual/groups/delegated_voters)、提案の設定、[投票テンプレート](/en/user_manual/polls/poll_templates)を設定すると、合意した手順を繰り返し使いやすくなります。

<!-- translation-section: if-your-group-is-still-deciding -->

### これから手順を決める場合

意思決定の方法についてディスカッションを始めます。投票ツールを選ぶ前に、グループで次の点を検討しましょう。

- どのような事項を決めるか？
- 誰が影響を受け、誰に意見を求め、誰が決定に責任を持つか？
- 助言、同意、合意形成、投票、権限の委任が必要なのは、それぞれどのような決定か？
- どの程度の参加や支持があれば、決定を有効とするか？
- 異議、同数の結果、参加不足にはどう対応するか？
- 決定をどのように伝え、記録し、見直し、変更するか？

運営上の決定、方針、選挙、規約の変更では、答えが異なる場合があります。いくつかの意思決定手順を比較するには、[意思決定を行う](/en/guides/making_decisions)を参照してください。

すべてのルールをまだ決められない場合は、影響の小さい決定を一つ選び、暫定的な手順に合意します。参加を求める前に結果が何を意味するかを示し、結論を公開してから手順を振り返ります。分かったことをグループの説明、運営文書、再利用できるテンプレートに記録しましょう。

<!-- translation-section: invite-people -->

## メンバーを招待する

次の点を説明する短い個別メッセージを添えて、[メンバーを招待します](/en/user_manual/groups/inviting_people)。

- グループがLoomioを使う理由
- 最初にしてほしいこと
- いつまでに返答が必要か
- 困ったときにどこで助けを得られるか

まず少人数で手順を試すことも、全員が最初から参加する必要があればグループ全体を招待することもできます。どちらの場合も、空のグループに招待する前に、参加できるディスカッションを用意してください。

<!-- translation-section: help-everyone-participate-once -->

## 全員が一度参加できるようにする

最初の目標は、招待を受け取った一人ひとりが何か一つ投稿したり、投票したりすることです。

次のことを依頼します。

1. サインインしてプロフィール写真を追加する
2. 歓迎用または練習用のディスカッションを開く
3. 短いコメントやリアクションを投稿する
4. 影響の小さい提案に投票し、必要なら理由を添える

メンバーはパスワードを作成する必要はありません。[メールでサインイン](/en/user_manual/users/signing_in)できます。また、返信に対応したディスカッションのメールには、スレッドに戻らずに返信できます。

<!-- translation-section: use-notifications-deliberately -->

## 通知を目的に合わせて使う

内容へのアクセスと通知は別です。すぐに通知を受けなかった場合でも、グループのメンバーはグループ内のディスカッションを見つけられます。

ディスカッションを始めるときは、その段階で意見が必要な人に通知します。特定の人に返答を求めるときは、@メンションや返信を使います。後で投票を開始するときに、投票資格のある人を招待します。

投票だけを行うためにディスカッションと投票を同時に作成する場合は、ディスカッションへの招待に続けて投票への招待を送らないようにします。通知せずにディスカッションを始めて投票から招待するか、[単独の投票](/en/user_manual/polls/intro_to_decisions#without-a-discussion)を実施してください。

メンバーに[キャッチアップと通知の設定](/en/user_manual/users/email_settings)を案内してください。特に、毎日Loomioを開く予定がない場合に役立ちます。

<!-- translation-section: complete-the-first-process -->

## 最初のプロセスを完了する

最初のプロセスでは、次の一連の流れを実践します。

1. テーマを紹介し、背景を説明します。
2. 必要に応じて、議論や質問を呼びかけます。
3. 適切な提案または投票を開始します。
4. 必要に応じて、まだ参加していない人に知らせます。
5. 何が決まり、次に何をするかを記した[結論](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome)を公開します。

結論を公開すると、一連のプロセスが完了し、メンバーが後から参照できる記録が残ります。その後、うまくいった点を確認してプロセスを調整し、次にLoomioで行う定期的な作業を選びます。

議論から決定までの進め方は、[意思決定の進め方](/en/guides/making_decisions)をご覧ください。理事会での進め方は、[理事会にLoomioを導入する](/en/guides/board_processes/introduce)をご覧ください。
