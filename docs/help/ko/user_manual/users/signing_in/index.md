# 로그인

Loomio.com에서는 패스키, 이메일 주소와 비밀번호, 이메일로 받은 로그인 코드 또는 Google로 로그인할 수 있습니다. 가장 편리한 방법을 선택하세요.

![패스키, 이메일, 비밀번호, 이메일 코드로 로그인할 수 있는 Loomio 로그인 양식](sign_in_email.png)

<!-- translation-section: sign-in-with-a-passkey -->

## 패스키로 로그인

**패스키 사용**을 선택하세요. 이메일 주소를 먼저 입력할 필요가 없습니다. 브라우저나 기기에 사용 가능한 Loomio 패스키가 표시되며, 화면 잠금, 지문, 얼굴 인식, PIN 또는 보안 키로 패스키의 잠금을 해제하라는 메시지가 나타납니다.

프로필에서 패스키를 추가하고, 이름을 지정하고, 삭제할 수 있습니다. 보안을 위해 패스키를 변경하기 전에 Loomio에서 다시 로그인을 요청할 수 있습니다. 각 패스키에 “업무용 노트북”이나 “휴대폰”처럼 알아보기 쉬운 이름을 지정하세요. 패스키는 생성된 Loomio 사이트에 연결되며, 기기나 비밀번호 관리자를 통해 여러 기기 간에 동기화될 수 있습니다.

<!-- translation-section: sign-in-with-email-and-password -->

## 이메일과 비밀번호로 로그인

이메일 주소와 비밀번호를 입력한 다음 **로그인**을 선택하세요. 개인정보 보호를 위해 Loomio는 이메일 주소가 잘못된 경우와 비밀번호가 잘못된 경우에 동일한 오류 메시지를 표시합니다.

아직 패스키를 추가하지 않았다면 로그인한 후 Loomio에서 패스키 추가를 제안합니다. 제안을 닫을 수 있으며, Loomio는 이 선택을 기억합니다.

비밀번호가 없거나 기억나지 않으면 대신 **코드 받기**를 선택하세요.

<!-- translation-section: get-a-sign-in-code -->

## 로그인 코드 받기

**코드 받기**를 선택하고 이메일 주소를 입력한 다음 양식을 제출하세요. 개인정보 보호를 위해 Loomio는 해당 주소로 등록된 계정이 있는지와 관계없이 동일한 확인 메시지를 표시합니다.

입력한 주소가 계정에 등록된 주소이면 Loomio에서 이메일로 6자리 코드를 보냅니다. 로그인 양식으로 돌아가 코드를 입력한 다음 **로그인**을 선택하세요. 코드는 24시간 후에 만료되며 한 번만 사용할 수 있습니다. 이메일이 도착하지 않으면 스팸 폴더를 확인하고, 계정에 등록된 이메일 주소를 입력했는지 확인하세요.

![6자리 로그인 코드를 입력하는 Loomio 양식](sign_in_code.png)

코드로 로그인한 후 Loomio에서 비밀번호 설정 또는 변경을 제안하며, 브라우저가 패스키를 지원하면 패스키 추가도 제안합니다. 이 단계를 건너뛰고 이메일 코드를 계속 사용할 수 있습니다.

## 계정 만들기

**계정 만들기**를 선택하고 이메일 인증 절차를 따르세요.

개인정보 보호를 위해 그룹 초대를 받은 이메일 주소를 사용하세요. 여러 이메일 주소로 만든 계정이 있다면 [계정을 통합할 수 있습니다](/en/user_manual/users/merge_accounts).

<!-- translation-section: sign-in-with-google -->

## Google로 로그인

**Google로 로그인**을 선택하고 Google 계정으로 로그인하세요. 기존 Loomio 계정에서 해당 이메일 주소를 사용하고 있으면 Loomio는 해당 계정에 Google 로그인 정보를 연결합니다. 그렇지 않으면 Loomio에서 새 계정을 만듭니다.

<!-- translation-section: other-loomio-sites -->

## 다른 Loomio 사이트

자체 Loomio 사이트를 운영하는 조직은 로그인 방법을 다르게 설정할 수 있습니다. 사이트에서 비밀번호, 이메일 코드, 패스키, Google, SAML 또는 다른 OAuth 제공자를 통한 로그인을 함께 제공할 수 있습니다.

일부 사이트에서는 계정을 만들려면 먼저 초대를 받아야 합니다. 이러한 사이트에서는 초대 링크로 접속한 경우에만 **계정 만들기**가 표시됩니다.

일부 비공개 사이트에서는 조직의 통합 로그인(SSO) 시스템을 통해 로그인해야 합니다. 이러한 사이트에서는 Loomio 비밀번호, 이메일 코드 또는 패스키를 제공하지 않으며, 별도의 Loomio 계정을 만들 수도 없습니다. 조직에서 패스키를 사용하는 경우 조직의 로그인 화면에서 패스키를 사용하게 됩니다.

## 로그아웃

사이드바를 열고 이름을 선택한 다음 **로그아웃**을 선택하세요. 공용 컴퓨터에서는 사용을 마치면 브라우저 탭만 닫지 말고 항상 로그아웃하세요.

로그아웃하면 해당 브라우저의 세션이 즉시 종료됩니다. Loomio는 보안 조사를 위해 세션의 IP 주소, 브라우저 정보, 시작 및 종료 시간을 기본적으로 60일 동안 보관합니다(비공개 사이트 운영자는 이 기간을 변경할 수 있습니다). 계정을 영구적으로 삭제하면 이 세션 기록도 삭제됩니다.
