# カテゴリタグ

カテゴリタグを使うと、特定の作業や話題に関するスレッドや投票を見つけやすくなります。

タグは組織全体で共有されます。親グループで使用するタグは サブグループでも同じタグです。これにより、組織全体で関連する作業を 整理できます。Loomio ではタグ名がアルファベット順に表示され、 色は名前の横に点で示されます。

グループページでスレッド一覧の上にある **タグ** をクリックすると、 現在のグループで使われているタグが表示されます。タグを選ぶと、そのタグが付いたスレッドだけが表示されます。 一覧が長い場合は絞り込み用の入力欄で検索できます。**もっと見せる** を選ぶと、 組織内のすべてのタグが表示されます。**表示数を減らす** を選ぶと、 現在のグループで使われているタグの表示に戻ります。

![](tags_view.png)

<!-- translation-section: apply-tags -->

## タグを付ける

スレッドや投票を編集できるメンバーは、タグを付けることができます。

スレッドや投票を開始するときに、**タグ** 欄をクリックしてタグを1つ以上選びます。

![](tags_add_new.png)

入力を始めると一覧を絞り込めます。タグを外すには、もう一度そのタグを選ぶか、タグのチップにある × をクリックします。

<!-- translation-section: create-tags -->

## タグを作成する

親グループの管理者は、親グループとそのサブグループで使うタグをいつでも作成できます。 サブグループの管理者は、自分のサブグループのコンテンツにタグを付ける際にタグを作成できます。 グループの権限 **メンバーはタグを作成できます** は初期設定で有効です。 この権限により、スレッドや投票にタグを付けられるほかのメンバーも新しいタグを作成できます。 権限が無効でも、メンバーは既存のタグを付けられます。

スレッドや投票を開始するときにタグを作成するには、**タグ** 欄に名前を入力して Enter キーを押します。

![新しいタグを作成](tags_create_new.png)

![作成された新しいタグ](tags_created_new.png)

「財務」「運営」「梱包」「カフェとの提携」など、グループのメンバーに分かりやすい短い名前を付けます。

<!-- translation-section: edit-tags -->

## タグを編集する

タグの名前や色の変更、統合、削除ができるのは親グループの管理者だけです。 変更はサブグループを含む組織全体に適用されます。

グループページで **タグ** を開き、**タグを編集** を選びます。

![カテゴリタグを編集](tags_edit_new.png)

タグの横にある鉛筆アイコンを選びます。

![カテゴリタグを編集](tags_edit_new_pencil.png)

タグの名前を編集するか色を選び、**保存** をクリックします。

![タグの色を編集](tags_edit_name.png)

**消去** をクリックすると、組織内のすべてのスレッドと投票からそのタグが削除されます。

![タグを削除](tags_delete.png)

<!-- translation-section: edit-tag-in-thread-or-poll -->

### スレッドや投票のタグを編集する

既存のスレッドや投票のタグを変更するには、対象を開き、タイトル付近の現在のタグの横にあるタグボタンをクリックします。

タグを選んで追加または削除します。変更はすぐに保存されます。

![スレッドのタグを編集](tags_thread_edit.png)
