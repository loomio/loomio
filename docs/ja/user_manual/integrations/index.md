# 連携

グループで使っているほかのツールとLoomioを連携できます。

<!-- translation-section: choose-where-work-belongs -->

## 作業に合ったツールを選ぶ

Loomioはチャット、共同編集する文書、タスク管理ツールと併用できます。

| 作業 | おすすめのツール |
|---|---|
| 簡単な質問、雑談、すぐに伝えたい更新情報 | チャット |
| 継続的に更新する文書の共同編集 | 共有文書 |
| タスクの割り当てと進捗管理 | プロジェクト管理ツールやタスク管理ツール |
| 重要なテーマについての議論、幅広い参加、意思決定、結論の記録 | Loomio |

テーマを検討する時間が必要なとき、関係者全員が参加できる機会を設けたいとき、後から議論や決定を探せるようにしたいときは、Loomioを使います。関連する文書やタスクへのリンクをLoomioのディスカッションに追加すると、背景情報を見つけやすくなります。

<!-- translation-section: chat-integrations -->

## チャット連携

[チャット連携](/en/user_manual/integrations/chatbots)を使うと、Loomioでの活動をDiscord、Matrix、Mattermost、Microsoft Teams、Slackなどのチャットサービスに投稿できます。

<!-- translation-section: api -->

## API

[Loomio API](/en/user_manual/integrations/api)を使うと、独自のソフトウェアや自動化したワークフローとLoomioを連携できます。
