# Äänioikeutetut edustajat

Käytä edustajia, kun kaikkien ryhmän jäsenten pitäisi voida osallistua samoihin keskusteluihin, mutta vain tietty joukko jäseniä, kuten johtokunnan jäsenet tai valitut edustajat, saa äänestää. Tämä on yksinkertaisempaa kuin ylläpitää erillistä alaryhmää vain äänestäjien erottamiseksi muista jäsenistä.

Käytä yksityistä alaryhmää, jos nämä jäsenet tarvitsevat myös keskusteluja, tiedostoja tai jäsenluettelon, joita muut jäsenet eivät saa nähdä.

Vain ryhmän ylläpitäjä voi myöntää tai poistaa edustajan aseman. Avaa ryhmäsivusi **Jäsenet**-välilehdellä henkilön nimen vieressä oleva toimintovalikko ja valitse **Tee valtuutettu**. Poista edustajan asema valitsemalla samasta valikosta **Peruuta edustaja**.

![Tee valtuutettu -toiminto jäsenen valikossa](member_make_delegate.png)

Jos haluat luoda kyselyn tai ehdotuksen, jossa vain edustajat voivat äänestää, valitse kyselyn asetuksista **Vain valitut henkilöt**.

![Vain valitut henkilöt -valinta ehdotusta luotaessa](poll_invited_people_only.png)

Kun valitset, ketkä kutsut äänestämään, valitse **Ryhmän [group name] edustajat**.

![Oatmilk Cooperative -ryhmän edustajat -vaihtoehto äänestyskutsulomakkeessa](poll_invite_delegates_group.png)

Näet kaikki ryhmän edustajat avaamalla **Jäsenet**-välilehden ja valitsemalla suodatusvalikosta **Edustajat**.

![Edustajat-vaihtoehto jäsenluettelon suodattimessa](members_list_delegates.png)
