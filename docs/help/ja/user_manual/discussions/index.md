# ディスカッションの紹介

Loomioのディスカッションでは、グループで情報を共有し、話題について話し合い、一緒に決定を行えます。コメント、返信、アンケート、提案を投稿して参加します。

- 話題に関するすべての情報を1か所にまとめられます。
- メールで返信すると、コメントがスレッドに表示されます。
- ディスカッションを読んだ人と、リマインダーが必要な人を確認できます。
- すべてのディスカッションと決定の記録を残し、検索できます。

ディスカッションは、一般的な近況の共有から、体系的な業務の進行や[意思決定のプロセス](/en/user_manual/polls/intro_to_decisions/)まで、幅広い用途に使えます。例えば、話題を紹介し、アイデアや参考資料を集め、[同意](/en/user_manual/polls/proposals/consent/)や[助言](/en/user_manual/polls/proposals/advice/)に基づくプロセスを進めて、結論に至ることができます。

参加者がコメントや投票をすると、スレッドに重要な節目の記録が蓄積され、いつでもその箇所に移動できます。使い始めるには、[ディスカッションを始める](/en/user_manual/discussions/starting_a_discussion/)と[スレッドを使う](/en/user_manual/discussions/using_discussions/)をご覧ください。

## 主な用途

グループでのディスカッションの主な使い方を紹介します。

<!-- translation-section: boards-and-governance -->

### 理事会とガバナンス

- **会議の準備をする** — 議題を作成し、理事会資料を共有し、事務事項に対応して、全員が準備を整えて会議に参加できるようにします。
- **決議案を可決する** — 背景情報を共有し、質問に答え、提案を作成して決定を記録します。
- **Loomioで議題について話し合う** — 会議の前に議題について話し合いを始めます。会議で時間が足りなくなった場合は、Loomioに移して続けられます。
- **議事録を承認し、対応事項の進捗を確認する** — 議事録を投稿し、タスクの担当者を割り当て、アンケートを使って議事録を承認します。

<!-- translation-section: member-participation -->

### メンバーの参加

- **ニュースを共有する** — メーリングリストの代わりに、メンバー向けの情報を投稿し、コメントを募ります。
- **イベントを企画する** — 運営チームで1つのスレッド内で詳細を詰め、その後、メンバー全体にイベントを告知します。
- **方針を策定する** — 草案を投稿し、フィードバックを集めて修正し、最終的な方針を正式に承認します。
- **総会を運営する** — すべてのメンバーが戦略に関わる決定について審議し、投票できるよう、事前に資料を共有します。

<!-- translation-section: self-organizing-working-teams -->

### 自主的に運営する作業チーム

- **情報を共有する** — チーム向けの最新情報や報告を投稿し、質問やコメントを募ります。
- **作業を進める** — タスクの概要を示し、完了までチームのメンバーから助言やフィードバックを募ります。
- **会議の記録を残し、対応事項の進捗を確認する** — 会議のメモを共有の記録として投稿し、その後のタスクの進捗を確認します。
- **アイデアを検討する** — 懸念を示したり、改善を提案したりして、ディスカッションを呼びかけます。
- **共同で意思決定のプロセスを進める** — 準備、提案、内容の明確化、異議への対応、賛成、実行までを1つのスレッド内で進めます。
