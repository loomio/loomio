# Loomio 3.1.7

[Loomio 3.1.6](https://github.com/loomio/loomio/releases/tag/v3.1.6) contains
all significant application and user-visible changes in this release series.
This `3.1.7` follow-up updates the HTTP client used by Loomio's bundled Haraka
mail service. Operators using the bundled Haraka service should upgrade both
the Loomio application and Haraka images. This release contains no database
migration and requires no new environment variable.

- **Fix:** Upgrade Undici to address published HTTP client security advisories.

## Haraka HTTP client security update

The Haraka image now uses Undici 7.29.0, addressing one high-severity and four
moderate-severity advisories affecting HTTP response handling, caching, header
parsing, and cookies:

- [GHSA-8xcm-r25x-g524](https://github.com/advisories/GHSA-8xcm-r25x-g524)
- [GHSA-4cwx-7wf7-3272](https://github.com/advisories/GHSA-4cwx-7wf7-3272)
- [GHSA-m8rv-5g2x-5cg5](https://github.com/advisories/GHSA-m8rv-5g2x-5cg5)
- [GHSA-jr45-8vmc-qm54](https://github.com/advisories/GHSA-jr45-8vmc-qm54)
- [GHSA-v3r7-h72x-cjcm](https://github.com/advisories/GHSA-v3r7-h72x-cjcm)

The dependency audit prevented a `3.1.6` Haraka image from being published.
Use Haraka image `3.1.7` when upgrading the application to this release.

## Upgrade notes

1. Edit `.env` and set the application image tag:

   ```sh
   LOOMIO_CONTAINER_TAG=3.1.7
   ```

   Use `3.1.7` to pin this release, or `3.1` to track the 3.1 patch series.

2. If the Haraka image is pinned separately, set it to:

   ```text
   loomio/haraka-rails-docker:3.1.7
   ```

3. Run the update script from the deployment directory:

   ```sh
   ./update.sh
   ```

4. Confirm that the application, worker, and inbound-mail services are
   running.

No data migration, data backfill, or new environment variable is required.
