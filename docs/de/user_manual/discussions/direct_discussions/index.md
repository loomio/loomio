# Direkte Diskussionen

Eine direkte Diskussion ist eine private Diskussion für einen bestimmten Personenkreis.

Eine direkte Diskussion gehört zu keiner Gruppe. Eingeladene Personen müssen kein Mitglied deiner Loomio-Gruppe sein.

Du legst fest, wer die Diskussion sehen und daran teilnehmen kann, indem du Personen oder E-Mail-Adressen zum Feld **Einladen** hinzufügst.

Direkte Diskussionen bieten dieselben Kommentare, Abstimmungen und anderen Werkzeuge wie Diskussionen in Gruppen. Sie können nützlich sein, wenn es nicht nötig ist, eine Untergruppe zu erstellen.

![Ein Formular für eine direkte Diskussion ohne ausgewählte Gruppe und mit Samira Patel im Feld Einladen](direct-discussion-example.png)

Wähle **Direkte Diskussionen** in der Seitenleiste, um deine direkten Diskussionen zu sehen. Wähle auf dieser Seite **Neue Diskussion**, um eine weitere zu starten.

![Der Eintrag Direkte Diskussionen in der Seitenleiste und die Liste der direkten Diskussionen](direct-discussion-sidebar.png)

## Jemanden über eine direkte Diskussion kontaktieren
Mit einer direkten Diskussion kannst du eine oder mehrere Personen privat kontaktieren, ohne eine Untergruppe zu erstellen.
