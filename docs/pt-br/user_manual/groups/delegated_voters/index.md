# Votantes delegados

Se algumas pessoas do seu grupo devem ter direito a voto e outras não, use **Fazer delegado** para identificar quem pode votar. Você também pode usar **Revogar delegado** para retirar esse direito.

Use delegados quando as pessoas devem compartilhar o mesmo espaço de discussão, mas apenas um grupo definido, como diretores ou representantes eleitos, pode votar. Em geral, isso é mais simples do que manter um segundo subgrupo apenas para separar quem pode votar de quem não pode.

Use um subgrupo privado se seus membros também precisarem de discussões, arquivos ou informações sobre os membros que outras pessoas do grupo não devem ver.

![Ação Fazer delegado no menu de um membro](member_make_delegate.png)

Para criar uma enquete ou proposta e convidar apenas os delegados, use a configuração **Apenas para pessoas selecionadas**.
![Configuração Apenas para pessoas selecionadas ao iniciar uma proposta](poll_invited_people_only.png)
Ao convidar pessoas para votar, você verá a opção **Delegados de nome-do-grupo**.
![Opção Delegados da Cooperativa de Leite de Aveia no formulário de convite para votar](poll_invite_delegates_group.png)

Para ver a lista de delegados, abra a aba de membros na página do seu grupo. No menu de filtros, selecione **Delegados**.
![Opção Delegados no filtro de membros](members_list_delegates.png)
