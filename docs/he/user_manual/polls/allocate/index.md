# הקצאת נקודות

הקצאת נקודות, המכונה לפעמים הצבעת נקודות, עוזרת לזהות סדרי עדיפויות כשצריך לבחור בין אפשרויות. כל משתתף מקבל מספר קבוע של נקודות ומחלק אותן בין האפשרויות. הקצאת יותר נקודות לאפשרות אחת משאירה פחות נקודות לאחרות.

<!-- translation-section: when-to-use-allocate -->

## מתי להשתמש בהקצאת נקודות

ניתן להשתמש בהקצאת נקודות כשזמן, כסף, תשומת לב או משאב אחר מוגבלים. היא מתאימה ל:

- קביעת סדר עדיפויות לעבודה בתקופת התכנון הבאה;
- חלוקת תקציב משתף בין פרויקטים;
- החלטה כמה זמן בסדר היום להקדיש לכמה נושאים;
- חלוקת מספר קבוע של שעות התנדבות; או
- זיהוי השיפורים החשובים ביותר לחברי הקבוצה.

הנקודות מבטאות עדיפות יחסית, ולא כמות ש־Loomio תקצה באופן אוטומטי. ניתן להשתמש ב[סקר ציון](/en/user_manual/polls/score/) כשכל אפשרות יכולה לקבל דירוג גבוה בלי להפחית את התמיכה באפשרות אחרת.

## דוגמה: קביעת סדרי עדיפויות לסקירת האסטרטגיה השנתית

קואופרטיב חלב שיבולת שועל מתכנן סקירה שנתית של האסטרטגיה שלו. הקואופרטיב שואל את חברי הקבוצה לאילו תחומים יש להקדיש את מרב הזמן ותשומת הלב במהלך הסקירה. כל חבר מקבל עשר נקודות לחלוקה בין חמישה תחומים. כך אפשר לראות את סדרי העדיפויות היחסיים של הקבוצה, תוך בחירה בין התחומים.

## הגדרת המשאל

יש לתאר את ההחלטה ואת משמעות הנקודות. יש להוסיף אפשרויות בהיקף דומה, ואז להגדיר **נקודות לאדם**. בדוגמה זו, כל מצביע מקבל עשר נקודות כדי לציין כמה זמן סקירה יש להקדיש לכל תחום אסטרטגי.

![](form.png)

מספר גדול מאוד של נקודות עלול ליצור רושם מטעה של דיוק. בדרך כלל כדאי להקצות מספיק נקודות כדי להראות הבדלים, אך מעט מספיק כדי לחייב בחירה. יש להבהיר אם מותר להקצות את כל הנקודות לאפשרות אחת.

<!-- translation-section: vote -->

## הצבעה

המשתתפים מזיזים את המחוונים כדי לחלק את הנקודות. Loomio מציגה כמה נקודות נותרו ומונעת שליחה עד שחלוקת הנקודות תקינה.

![](voting.png)

בדוגמה זו מוקצות שלוש נקודות לכל אחת מהאפשרויות **השתתפות חברים** ו**יציבות פיננסית**, שתי נקודות לכל אחת מהאפשרויות **השפעה סביבתית** ו**פיתוח צוות**, ואפס נקודות ל**מוצרים ושירותים**. אפס אינו מעיד בהכרח שהתחום חסר ערך; פירושו שהנקודות המוגבלות הוקצו לתחומים אחרים.

<!-- translation-section: read-the-results -->

## קריאת התוצאות

האפשרויות בתוצאות מסודרות לפי סך הנקודות שקיבלו. התוצאות מציגות גם:

- **אחוז הנקודות**: חלקה של האפשרות מתוך כלל הנקודות שהוקצו;
- **נקודות**: סך הנקודות שהוקצו לאפשרות;
- **מתכוון**: הממוצע בקרב המצביעים שהקצו נקודות לאפשרות; וכן
- **מצביעים**: מספר האנשים שהקצו לאפשרות לפחות נקודה אחת.

![](results.png)

בדוגמה זו, **יציבות פיננסית** מקבלת את מספר הנקודות הגבוה ביותר, ואחריה **פיתוח צוות**. כל המצביעים הקצו נקודות ליציבות פיננסית. הדבר עשוי להעיד על הסכמה רחבה שיש להקדיש לתחום זה זמן סקירה משמעותי. יש לבחון את סך הנקודות לצד מספר המצביעים כדי להבחין בין עדיפות רחבה לבין תחומים שמקבלים תמיכה חזקה ממספר קטן יותר של אנשים.

יש לבחון את סך הנקודות לצד מספר המצביעים והנימוקים שלהם. יש לפרסם מסקנה שמסבירה כיצד תיערך סקירת האסטרטגיה; המשאל אינו מקצה זמן באופן אוטומטי.
