# Profil du groupe

L’onglet Profil définit la façon dont votre groupe est présenté et identifié. Sur la page du groupe, ouvrez **Modifier les paramètres du groupe**, puis sélectionnez **Profil**.

![Paramètres du profil du groupe](group_profile.png)

<!-- translation-section: name-and-handle -->

## Nom et identifiant

Choisissez un nom de groupe concis, surtout si le groupe doit contenir des sous-groupes. Loomio utilise l’identifiant dans l’adresse web et l’adresse e-mail du groupe, par exemple `loomio.com/your-group-handle` et `your-group-handle@loomio.com`.

Lorsque vous modifiez l’identifiant, les liens qui utilisent l’ancien identifiant redirigent vers la nouvelle adresse. Les e-mails envoyés à l’ancienne adresse du groupe continuent de lui parvenir. Loomio conserve jusqu’à trois anciens identifiants. Si vous modifiez encore l’identifiant après avoir atteint cette limite, le plus ancien cesse de fonctionner.

<!-- translation-section: description -->

## Description

Utilisez la description pour expliquer le rôle du groupe, qui y participe et comment l’utiliser. Vous pouvez mettre le texte en forme et ajouter des liens, des documents et des vidéos.

Selon les [paramètres de confidentialité](/en/user_manual/groups/settings/privacy) du groupe, son nom et sa description peuvent être visibles par des personnes qui n’en sont pas membres.

<!-- translation-section: cover-image-and-logo -->

## Image de couverture et logo

L’image de couverture apparaît en haut de la page du groupe. Une image large convient le mieux. La taille recommandée est de 2048 × 512 pixels.

Le logo permet de reconnaître le groupe dans la navigation et les espaces où la place est limitée. Téléversez l’image de couverture et le logo séparément afin de pouvoir recadrer chacun selon son format.
