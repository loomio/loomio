# Aufgaben zuweisen und nachverfolgen

Nutze Aufgaben in Threads und Kommentaren, um eine Handlung zu benennen, sie jemandem zuzuweisen, ein Fälligkeitsdatum festzulegen und nachzuverfolgen, ob sie erledigt ist.

<!-- translation-section: add-a-task -->

## Eine Aufgabe hinzufügen

Klappe beim Schreiben eines Threads oder Kommentars die Formatierungsleiste auf und klicke auf **Aufgabenliste**. Gib die Handlung neben dem Kontrollkästchen ein.

![](tasklist1.png)

<!-- translation-section: name-and-assign-the-task-to-a-person -->

## Die Aufgabe benennen und einer Person zuweisen

Verwende eine @Erwähnung in der Aufgabe, um sie einem Gruppenmitglied zuzuweisen. Sobald die Aufgabe einer Person zugewiesen ist, erscheint die Schaltfläche **Fälligkeitsdatum hinzufügen**.

![](tasklist2.png)

Dir zugewiesene Aufgaben erscheinen auf deiner Seite **Aufgaben**. Öffne **Aufgaben** über die Seitenleiste, um sie nach Thread oder Abstimmung gruppiert zu sehen.

![](task_list.png)

<!-- translation-section: set-a-reminder -->

## Eine Erinnerung festlegen

Klicke auf **Fälligkeitsdatum hinzufügen**, um ein Fälligkeitsdatum auszuwählen und festzulegen, wann Loomio der zugewiesenen Person eine Erinnerung per E-Mail senden soll. In diesem Dialog kannst du auch ein bestehendes Fälligkeitsdatum entfernen.

![](taskreminderform.png)

<!-- translation-section: mark-it-as-done -->

## Eine Aufgabe als erledigt markieren

![](taskdone.png)

Klicke auf das Kontrollkästchen neben einer Aufgabe, um sie als erledigt zu markieren. Das kannst du beim Bearbeiten des Textes, beim Lesen, wenn dir die Aufgabe zugewiesen ist, oder auf der Seite **Aufgaben** tun. Klicke erneut darauf, um die Aufgabe wieder zu öffnen.
