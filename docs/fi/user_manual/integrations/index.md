# Integraatiot

Yhdistä Loomio muihin ryhmäsi käyttämiin työkaluihin.

<!-- translation-section: choose-where-work-belongs -->

## Valitse työlle sopiva paikka

Loomio täydentää keskustelupalveluja, jaettuja asiakirjoja ja tehtävienhallintatyökaluja. Kaikkea työtä ei tarvitse tehdä Loomiossa.

| Työ | Suositeltu työkalu |
|---|---|
| Nopeat kysymykset, vapaamuotoinen keskustelu ja ajankohtaiset päivitykset | Keskustelupalvelu |
| Yhteistyössä muokattava asiakirja | Jaettu asiakirja |
| Tehtävien jakaminen ja seuranta | Projektin- tai tehtävienhallintatyökalu |
| Tärkeät aihekohtaiset keskustelut, laaja osallistuminen, päätökset ja yhteenvedot | Loomio |

Käytä Loomiota, kun ihmiset tarvitsevat aikaa aiheen pohtimiseen, kun kaikilla asianomaisilla tulisi olla mahdollisuus osallistua tai kun ryhmän on löydettävä keskustelu ja päätös myöhemmin. Lisää Loomion keskusteluun linkki asiaankuuluvaan asiakirjaan tai tehtävään, jotta asiayhteys löytyy helposti.
