# הרשאות קבוצה

הלשונית הרשאות קובעת אילו פעולות בקבוצה זמינות לחברים רגילים, ובקבוצות שאינן סודיות, גם למי שאינם חברי הקבוצה. יש לפתוח את **ערוך הגדרות קבוצה** מדף הקבוצה, ואז לבחור ב־**הרשאות**.

![הגדרות הרשאות קבוצה](group_group_settings_permissions.png)

המנהלים שומרים על היכולת לנהל את הקבוצה. הפעלת הרשאה לחברים מאפשרת גם לחברים רגילים לבצע את הפעולה המסוימת הזאת; היא אינה הופכת אותם למנהלים.

ההרשאות קובעות אם חברים יכולים:

- להוסיף חברים או להזמין אורחים;
- לשלוח הודעות לכלל הקבוצה;
- ליצור תת־קבוצות;
- לפתוח ולנהל דיונים;
- ליצור ולנהל תגיות;
- לערוך או למחוק תגובות כאשר ההגדרה מאפשרת זאת;
- לפתוח הצעות וסקרים; וכן
- ליצור תבניות לדיונים ולסקרים.

בקבוצות שאינן סודיות, מנהלים יכולים לאפשר בנפרד למי שאינם חברי הקבוצה לפתוח דיונים. פתיחת דיון בידי מי שאינם חברי הקבוצה מקנה להם מעמד של אורחים באותו דיון, אך אינה מקנה גישה לדיונים פרטיים אחרים או חברות בקבוצה.

ההגדרה **מנהלי מערכת יכולים לערוך תגובות של חברים** מעניקה למנהלים יכולת חריגה לניהול התוכן. יש להפעיל אותה רק כאשר הקבוצה הסכימה שלמנהלים צריכה להיות אפשרות לשנות תוכן שכתבו חברים.

יש לבדוק את ההרשאות כאשר מטרת הקבוצה, הרכב החברים או תחומי האחריות לניהול התוכן משתנים. יש להעניק לכל תפקיד רק את היכולות הנחוצות לו.
