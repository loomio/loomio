# Distribuir

Distribuir, às vezes chamado de enquete de distribuição, revela prioridades quando é preciso fazer escolhas entre alternativas. Cada participante recebe uma quantidade fixa de pontos para distribuir entre as opções. Dar mais pontos a uma opção deixa menos pontos para as outras.

<!-- translation-section: when-to-use-allocate -->

## Quando usar Distribuir

Use Distribuir quando o tempo, o dinheiro, a atenção ou outro recurso for limitado. Funciona bem para:

- priorizar o trabalho para o próximo período de planejamento;
- dividir um orçamento participativo entre projetos;
- escolher quanto tempo da pauta dedicar a vários assuntos;
- distribuir uma quantidade fixa de horas de trabalho voluntário; ou
- identificar quais melhorias são mais importantes para os membros.

Os pontos mostram a prioridade relativa, não uma quantidade que o Loomio atribuirá automaticamente. Use [Pontuar](/en/user_manual/polls/score/) quando cada opção puder receber uma avaliação alta sem reduzir o apoio a outra.

## Exemplo: definir prioridades para uma revisão anual da estratégia

A Cooperativa Oatmilk está planejando sua revisão anual da estratégia. Ela pergunta aos membros quais áreas devem receber mais tempo e atenção. Cada membro recebe dez pontos para distribuir entre cinco áreas, mostrando as prioridades relativas e exigindo escolhas entre alternativas.

<!-- translation-section: set-up-the-poll -->

## Configure a enquete

Descreva a decisão e o que os pontos representam. Adicione opções com abrangência semelhante e defina **Pontos por pessoa**. Neste exemplo, cada eleitor recebe dez pontos para mostrar quanto tempo de revisão cada área estratégica deve receber.

![](form.png)

Uma quantidade muito grande de pontos pode criar uma falsa precisão. Escolha uma quantidade suficiente para mostrar diferenças, mas pequena o bastante para exigir escolhas entre alternativas. Deixe claro se é aceitável concentrar todos os pontos em uma única opção.

<!-- translation-section: vote -->

## Vote

Os participantes movem os controles deslizantes para distribuir seus pontos. Você pode deixar pontos sem usar.

![](voting.png)

Neste exemplo, o eleitor atribui três pontos a **Participação dos membros** e três a **Sustentabilidade financeira**, dois a **Impacto ambiental** e dois a **Desenvolvimento da equipe**, e nenhum a **Produtos e serviços**. Dar zero pontos a uma opção não significa necessariamente que ela não tenha valor — o eleitor pode simplesmente ter usado seus pontos limitados em outras opções.

<!-- translation-section: read-the-results -->

## Leia os resultados

Os resultados ordenam as opções pelo total de pontos recebidos. Eles também mostram:

- **% de pontos**: a proporção de todos os pontos distribuídos que a opção recebeu;
- **Pontos**: o total de pontos distribuídos;
- **Significar**: a média entre os eleitores que deram pontos à opção; e
- **Eleitores**: quantas pessoas deram pelo menos um ponto à opção.

![](results.png)

Neste exemplo, **Sustentabilidade financeira** recebe mais pontos, seguida de **Desenvolvimento da equipe**. Todos os eleitores deram pontos a Sustentabilidade financeira, mostrando um amplo consenso de que ela precisa de tempo de revisão.

Leia os totais de pontos junto com o número de eleitores e os motivos dos votos para distinguir prioridades amplamente apoiadas de áreas com forte apoio de menos pessoas.

## Compartilhe uma conclusão

Quando a enquete for encerrada, compartilhe uma conclusão. Como a enquete não distribui tempo ou dinheiro automaticamente, explique como os resultados da votação serão usados. Veja [Compartilhe uma conclusão](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome) para saber como as conclusões funcionam.
