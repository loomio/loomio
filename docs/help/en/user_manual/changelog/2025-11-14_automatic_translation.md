# Automatic translation of user content

User-generated content — discussions, comments, and poll details — can now be translated inline with one click.

## How it works

When a comment or thread body appears in a language different from your interface language, a "Translate" button appears. Clicking it replaces the text with a machine translation. A "Show original" link lets you switch back.

Translations are generated on demand and cached, so re-opening a thread doesn't re-trigger a translation request.

## Email translation

The same translation feature is available in notification emails. When an email contains content in a language different from your account language setting, it's automatically translated.
