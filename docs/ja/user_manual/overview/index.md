# はじめに

Loomioは、組織が協力して議論し、意思決定するためのツールです。

人々が集まって議題を話し合い、提案を検討し、意思決定できます。

## Loomioの仕組み

Loomioには、グループ、ディスカッション、投票の3つの主な要素があります。

<!-- translation-section: groups -->

### グループ

グループは、組織、チーム、コミュニティが協力する場です。ホームページにはグループの目的が示され、ディスカッション、投票、メンバー、ファイルにアクセスできます。

![](orientation_group.png)

<!-- translation-section: discussions -->

### ディスカッション

ディスカッションでは、議題に関する情報と会話を一か所にまとめられます。背景情報の共有、コメント、返信、リアクションができます。投票を使って議論を結論へ進めることもできます。

![](orientation_discussion.png)

ディスカッションを重ねると、グループが検討した情報と下した決定が、検索できる記録として残ります。

<!-- translation-section: polls-and-proposals -->

### 投票と提案

投票は、グループ内の意向を把握し、意見を集め、意思決定するのに役立ちます。投票テンプレートごとに異なる進め方に対応しています。提案では、示された行動案について意見とその理由を求めます。

![](orientation_proposal.png)

投票はディスカッションに含めることも、グループページの**投票**タブから単独で実施することもできます。

各要素が画面のどこにあるかは、[クイックツアー](/en/user_manual/overview/orientation)をご覧ください。参加を始めるには、[参加方法](/en/user_manual/overview/how-to-participate)をご覧ください。

## Loomioの活用例

**会員制組織**では、多くの会員が意思決定に参加できます。政党、消費者協同組合、労働者協同組合、会員団体は、会員が情報を共有し、議題を提起し、重要な決定に参加し、総会で投票できる場としてLoomioを使っています。意思決定の手順を整え、透明性と説明責任を高め、議論と決定を記録できます。会員の意見を活動につなげられます。

**自主管理型の組織**では、職員が意思決定に参加できます。自主管理チーム、労働者協同組合、ソシオクラシーを採用する組織は、離れた場所や異なる時間帯で働く人々の間で、同意、合意、助言に基づく意思決定を進めるためにLoomioを使っています。知識を持ち寄り、意思決定を分担し、運営方針や規則をともに作り、決定と議論を記録できます。

**理事会、協議会、分散型ネットワーク**では、関係者が意思決定に参加できます。安心して議論できる場を設け、連絡の経緯を記録し、場所や時間帯が異なる人々の間で活動を調整できます。意思決定の手順を整え、対応を早め、組織の知識を残せます。

**居住コミュニティと協同組合**では、住民が近隣の人々とともに意思決定できます。コハウジング、エコビレッジ、共同生活の協同組合、住宅協同組合、土地信託では、従来の区分所有や不動産管理を民主的な運営に置き換えたり、補ったりするためにLoomioを使っています。住民は共有地、共用スペース、コミュニティの取り決めに関する決定に参加できます。時間を合わせずに議論できるため、現地にいる人も旅行中の人も参加でき、コミュニティがどのように暮らし方を決めたかを記録できます。

Loomioには、組織が下した決定、参加した人々、決定に至る議論が、継続して記録されます。
