# メールを送信してグループ内にスレッドを開始する

Loomioのグループにはメールアドレスがあります。このアドレスにメールを送信または転送すると、グループ内にスレッドを開始できます。

グループのメールアドレスはグループページで確認できます。
![グループページに表示されたメールアドレスの場所](email_email_button.png)

このアドレスにメールを送信すると、新しいスレッドが開始されます。メールの件名がスレッドのタイトル、本文が説明になります。添付ファイルもスレッドに添付されます。

メールの「From」アドレスをもとに、スレッドの作成者となるグループのメンバーが特定されます。

## 権限のないメールを防ぐ

グループのメンバー以外がこの機能を使えないように、Loomioは受信メールの「From」アドレスがグループのメンバーのアドレスと一致することを確認します。

複数のメールアドレスを使用している場合は、エイリアスを追加して別のアドレスをLoomioに登録できます。

「From」アドレスがグループのメンバーのアドレスと一致しない場合は、エイリアスの追加か、そのアドレスからの今後のメールの拒否を求める通知が届きます。

登録されていないアドレスから初めてメールを送信したときは、エイリアスを追加する必要があります。その後は、そのアドレスからのメールがすぐに受け付けられます。
