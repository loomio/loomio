# 그룹 공개 범위

공개 범위는 누가 그룹을 찾고 콘텐츠를 읽을 수 있는지 결정합니다. 그룹 페이지에서 **그룹 설정 수정**을 연 다음 **공개 범위**를 선택하세요.

![그룹 공개 범위 설정](group_privacy_settings.png#width-90)

공개 범위를 변경하면 기존 콘텐츠에도 영향을 줍니다. 상위 그룹을 비공개로 변경하면 공개 상태인 하위 그룹도 **상위 그룹에 공개**로 변경되며, 해당 하위 그룹의 스레드도 비공개로 변경됩니다.

<!-- translation-section: open -->

## 공개 그룹

공개 그룹은 누구나 볼 수 있는 공간입니다. 누구나 그룹을 찾고 토론, 투표, 파일을 볼 수 있습니다. 멤버 목록은 멤버만 볼 수 있습니다.

<!-- translation-section: follow-an-open-group -->

### 공개 그룹 소식 구독

그룹에 가입하지 않아도 공개 그룹의 소식을 받아볼 수 있습니다. 소식을 구독하면 아직 읽지 않은 그룹 활동이 활동 요약 이메일에 포함되어 편한 시간에 확인할 수 있습니다. 소식을 구독하는 것만으로는 멤버가 되거나 멤버의 투표 권한을 얻거나 즉시 알림을 받지는 않습니다.

그룹 페이지에서 **소식 구독**을 켜면 아직 읽지 않은 토론, 댓글, 투표 및 기타 스레드 활동이 활동 요약 이메일에 포함됩니다. 해당 그룹을 더 이상 포함하지 않으려면 이 설정을 끄세요.

![공개 그룹 소식 구독](group_follow_updates.png)

<!-- translation-section: closed -->

## 비공개 그룹

누구나 비공개 그룹을 찾고 이름과 설명을 읽을 수 있습니다. 토론, 투표, 파일, 멤버 목록은 멤버와 초대받은 게스트만 볼 수 있습니다.

<!-- translation-section: visible-to-parent-group -->

## 상위 그룹에 공개

상위 그룹 멤버와 하위 그룹 멤버는 해당 하위 그룹을 찾을 수 있습니다. 해당 하위 그룹의 스레드는 하위 그룹 멤버와 초대받은 게스트만 볼 수 있습니다.

<!-- translation-section: secret -->

## 숨김 그룹

숨김 그룹과 그 콘텐츠는 초대받았거나 추가된 사람만 볼 수 있습니다. 숨김 그룹은 공개 그룹 디렉터리에 표시되지 않습니다.

<!-- translation-section: how-people-join -->

## 가입 방법

**어떻게 가입하나요?**에서 사용 가능한 선택지 중 하나를 선택하세요.

| 가입 방식 | 작동 방식 |
| --- | --- |
| **승인 없이 가입** | 누구나 직접 가입할 수 있습니다 |
| **가입 요청** | 가입을 요청하고 승인을 기다립니다 |
| **초대로만 가입** | 가입하려면 초대가 필요합니다 |

승인이 필요한 경우 **그룹 가입**을 선택하고 그룹의 가입 질문에 답한 다음 가입 요청을 보냅니다. 가입 질문 설정, 요청 검토, 직접 초대 방법은 [사람 초대하기](/en/user_manual/groups/inviting_people#request-to-join-group)를 참조하세요.

<!-- translation-section: group-directory -->

## 그룹 디렉터리

공개 또는 비공개 상태인 상위 그룹은 사람들이 찾을 수 있도록 공개 그룹 디렉터리에 등록할 수 있습니다. 하위 그룹과 숨김 그룹은 등록할 수 없습니다.
