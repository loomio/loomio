# Інтеграції

Підключіть Loomio до інших інструментів, якими користується ваша група.

<!-- translation-section: choose-where-work-belongs -->

## Вибір місця для роботи

Loomio доповнює чати, спільні документи та інструменти керування завданнями, а не замінює всі інструменти для роботи.

| Робота | Рекомендований інструмент |
|---|---|
| Короткі запитання, неформальне спілкування та своєчасні повідомлення | Чат |
| Спільне редагування документа, який постійно оновлюється | Спільний документ |
| Призначення та відстеження завдань | Інструмент керування проєктами або завданнями |
| Важливі тематичні обговорення, широка участь, рішення та висновки | Loomio |

Використовуйте Loomio, коли людям потрібен час для розгляду теми, коли всі, кого вона стосується, повинні мати реальну можливість долучитися або коли групі потрібно буде згодом знайти обговорення та рішення. Додайте до обговорення в Loomio посилання на відповідний документ або завдання, щоб контекст обговорення було легко знайти.
