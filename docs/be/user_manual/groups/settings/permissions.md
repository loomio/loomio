# Дазволы групы

Укладка дазволаў вызначае, якія дзеянні ў групе даступныя звычайным удзельнікам групы, а для несакрэтных груп — таксама людзям, якія не ўваходзяць у групу. На старонцы групы адкрыйце **Рэдагаваць налады групы**, затым выберыце **Дазволы**.

![Налады дазволаў групы](group_group_settings_permissions.png)

Адміністратары захоўваюць магчымасць кіраваць групай. Уключэнне дазволу для ўдзельнікаў групы робіць адпаведнае дзеянне даступным звычайным удзельнікам групы, але не робіць іх адміністратарамі.

Дазволы вызначаюць, ці могуць удзельнікі групы:

- дадаваць удзельнікаў групы або запрашаць гасцей;
- адпраўляць аб'явы;
- ствараць падгрупы;
- пачынаць абмеркаванні і кіраваць імі;
- ствараць тэгі і кіраваць імі;
- рэдагаваць або выдаляць каментарыі, калі гэта дазваляюць налады;
- пачынаць прапановы і апытанні; і
- ствараць шаблоны абмеркаванняў і апытанняў.

У групах, якія не з'яўляюцца сакрэтнымі, адміністратары могуць асобна дазволіць людзям, якія не ўваходзяць у групу, пачынаць абмеркаванні. Людзі, якія пачынаюць абмеркаванне, не ўваходзячы ў групу, становяцца гасцямі гэтага абмеркавання, але не атрымліваюць доступу да іншых прыватных абмеркаванняў і не становяцца ўдзельнікамі групы.

Налада **Адміністратары могуць рэдагаваць каментарыі ўдзельнікаў** дае адміністратарам асаблівую магчымасць мадэрацыі. Уключайце яе толькі тады, калі група дамовілася, што адміністратары павінны мець магчымасць змяняць змесціва, створанае ўдзельнікамі групы.

Пераглядайце дазволы, калі змяняюцца мэта групы, яе склад або абавязкі па мадэрацыі. Давайце кожнай ролі толькі тыя магчымасці, якія ёй патрэбныя.
