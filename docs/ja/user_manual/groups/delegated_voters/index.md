# 投票権を持つ代表者

グループ内で投票できるメンバーを限定する場合は、**委任する**で投票権を持つ代表者を指定できます。指定を解除するには、**委任を取り消す**を使います。

代表者は、全員が同じ場で議論し、理事や選出された代表者など、決まった人だけが投票する場合に使います。投票できる人を分けるためだけに別のサブグループを管理するより、通常は簡単です。

一部のメンバーだけが閲覧できる議論、ファイル、メンバー情報も必要な場合は、非公開のサブグループを使います。

![メンバーのメニューにある「委任する」](member_make_delegate.png)

代表者だけを招待して世論調査や提案を作成するには、投票の設定で**選ばれた人のみ**を選びます。
![提案の開始時に表示される「選ばれた人のみ」の設定](poll_invited_people_only.png)
投票する人を招待する際に、**グループ名 の代表者**という選択肢が表示されます。
![投票への招待フォームに表示される「Oatmilk Cooperative の代表者」](poll_invite_delegates_group.png)

代表者の一覧は、グループページのメンバータブで確認できます。フィルターメニューから**代表者**を選びます。
![メンバーのフィルターにある「代表者」](members_list_delegates.png)
