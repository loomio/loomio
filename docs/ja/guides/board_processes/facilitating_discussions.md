# ディスカッションを進める

会議と会議の間に、理事会や委員会のメンバーが対応すべき議題が生じることがあります。

また、会議中に十分な時間を取って話し合い、決定を検討できないこともあります。

<!-- translation-section: on-loomio -->

## Loomioでの進め方

話し合いを進めるには、Loomioの**スレッド**を使います。メンバーに内容が伝わるタイトルを付け、スレッドの説明に詳細を書きます。関連するカテゴリタグを追加すると、後からスレッドを見つけやすくなります。

メンバーをスレッドに招待すると、スレッドの内容がメールで届きます。メンバーはリンクからLoomioを開いてディスカッションに参加できます。通知メールに返信することもでき、その内容はスレッドのコメントとして表示されます。

![](thread_discussion.png#width-90)

Loomioのスレッドには、話し合いの資料となるファイルを添付したり、オンライン資料へのリンクを追加したりできます。

例えば、次のような話し合いに使えます。
- 方針を見直し、作成する
- 議題や課題について理事会に意見を求める
- 戦略を話し合う
- アイデアや機会を検討する
- リスクを評価する

## 理事会の会議と会議の間に生じる課題

会議と会議の間にも、組織ではさまざまなことが起こります。理事会のメンバーへの連絡には、メールがよく使われます。しかし、メールでの話し合いは経過を追いにくく、返信が受信箱に埋もれたり、連絡から漏れる人が出たりします。

*「メールで組織運営はできません」、リチャード・ウェストレイク（Westlake Governance）。*

理事会の対応が必要な課題が生じたら、メールの代わりにLoomioのスレッドを使います。メンバーがメールで返信すると、その内容がスレッドのコメントとして表示され、話し合いを一か所にまとめられます。

手順は次のとおりです。
- メールの件名にする内容をスレッドのタイトルにします。
- メールの本文にする内容をスレッドの説明に書きます。
- メールアドレスまたはLoomioのユーザー名を使って、チームのメンバーをスレッドに招待します。

Loomioのスレッドを使うと、次のことができます。
- 議題に関する情報を、アクセスしやすい一か所にまとめられます。
- 全員に返信するメールのやり取りを増やさずに回答でき、連絡から漏れる人を減らせます。
- 誰がメッセージを読んだか、誰に確認が必要かを把握できます。
- 作業を結論まで進めながら、メールの量を減らせます。

<!-- translation-section: when-there-isn-t-space-during-meetings -->

## 会議中に時間が足りないとき

理事会の会議中に議題を解決する時間が足りない場合は、Loomioで話し合いを続けられます。関連するスレッドを案内するか、新しいスレッドを作成して理事会のメンバーに通知します。

会議中に結論を急ぐ必要がなくなり、情報収集や話し合い、十分な検討に時間を使えます。その結果、よりよい決定につながることがあります。
