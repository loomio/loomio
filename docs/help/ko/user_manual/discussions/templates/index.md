# 토론 템플릿

토론 템플릿을 사용하면 그룹에서 매번 같은 방식으로 토론을 시작할 수 있습니다. 템플릿은 토론을 시작하는 사람에게 제목, 배경, 태그, 안내를 제공할 수 있습니다. 그룹 전체에 알릴지, 어떤 투표를 제안할지 등의 기본값도 설정합니다.

그룹의 모든 새 토론은 템플릿에서 시작합니다. **토론 시작**을 선택하면 Loomio가 그룹의 템플릿을 표시합니다. **빈 템플릿**도 템플릿이므로 그룹에서 기본값을 변경할 수 있습니다.

템플릿은 프로젝트 검토, 자문 절차, 회의 준비, 자금 지원 결정, 문서 승인처럼 그룹에서 반복하는 절차에 유용합니다. 토론을 시작하는 사람은 시작 전에 모든 내용을 수정할 수 있습니다.

<!-- translation-section: how-templates-are-used -->

## 템플릿 사용 방법

1. 멤버가 그룹 페이지에서 **토론 시작**을 선택합니다.
2. Loomio가 그룹에서 표시하도록 설정된 템플릿을 나열합니다. 각 템플릿에는 제목과 부제가 표시됩니다.
3. 멤버가 템플릿을 선택합니다. Loomio가 템플릿의 내용이 입력된 새 토론 양식을 엽니다.
4. 양식 상단에 템플릿 도움말이 안내로 표시됩니다.
5. 멤버가 제목, 배경, 태그, 초대 목록을 수정한 다음 **토론 시작**을 선택합니다.

![](list.png)

템플릿 변경은 변경 후 시작하는 토론에만 적용됩니다. 이미 해당 템플릿으로 시작한 토론은 기존 내용과 설정을 유지합니다.

<!-- translation-section: choose-who-is-notified-by-default -->

## 기본 알림 대상 선택

**초대** 설정은 새 토론 양식에서 기본으로 초대할 대상을 정합니다. 다음 두 가지 선택지가 있습니다.

- **그룹의 모든 멤버**: 토론 양식의 **초대** 필드에 그룹이 표시되며, 토론이 시작되면 모든 멤버에게 알림이 전송됩니다.
- **없음**: **초대** 필드가 비어 있는 상태로 시작합니다. 작성자가 사람을 추가하지 않으면 아무에게도 알림이 전송되지 않습니다.

**빈 템플릿**을 포함한 Loomio의 기본 제공 템플릿은 **그룹의 모든 멤버**를 사용합니다. 새 토론을 시작할 때마다 모든 멤버에게 알리고 싶지 않다면 그룹에서 사용하는 템플릿을 수정하고 **초대**를 **없음**으로 설정하세요.

![](use.png)

작성자는 토론을 시작하기 전에 언제든지 초대 목록을 변경할 수 있습니다. 그룹을 제거해 아무에게도 알리지 않거나, 특정 사람을 추가할 수 있습니다. 이 설정은 알림에만 영향을 줍니다. 어떤 선택지를 선택하든 그룹 멤버는 그룹에서 토론을 찾아 읽을 수 있습니다.

작성자에게 그룹 전체에 알릴 권한이 있을 때만 초대 목록에 그룹이 추가됩니다. 그룹 관리자는 항상 이 권한이 있습니다. 멤버는 그룹 권한에서 **멤버가 그룹 전체에 알릴 수 있습니다**가 활성화되어 있을 때 이 권한이 있습니다.

## 템플릿 설정

그룹 관리자는 템플릿 목록에서 템플릿 옆의 작업 메뉴를 통해 템플릿을 수정할 수 있습니다. 양식에는 다음 설정이 있습니다.

![](form.png)

- **템플릿 제목**: 템플릿 목록에 표시되는 짧은 이름입니다.
- **템플릿 부제**: 템플릿을 언제 사용하는지 설명하는 한 줄입니다.
- **템플릿 도움말**: 새 토론 양식 상단에 표시되는 안내입니다. 절차를 설명하고 참고 자료의 링크를 제공하는 데 사용하세요. 토론 내용에는 포함되지 않습니다.
- **그룹**: 템플릿으로 그룹 내 토론을 시작할지, 직접 토론을 시작할지 정합니다. 직접 토론은 초대받은 사람에게만 표시됩니다.
- **기본 제목**: 새 토론마다 미리 입력되는 제목입니다. 작성자가 수정할 수 있습니다.
- **제목 예시**: 비어 있는 제목 필드에 표시되는 예시입니다. 기본 제목이 모든 토론에 적합하지 않을 때 사용하세요.
- **태그**: 새 토론마다 적용되는 태그입니다. 작성자가 제거할 수 있습니다.
- **배경**: 토론의 시작 내용입니다. 제목, 질문, 링크를 사용해 작성할 내용을 안내하세요.
- **초대**: 기본으로 그룹의 모든 멤버를 초대할지 정합니다. [기본 알림 대상 선택](#choose-who-is-notified-by-default)을 참고하세요.
- **투표 템플릿**: 이 절차에 제안되는 투표입니다. 새 토론 양식에 나열됩니다. 토론에서 투표를 시작할 때도 먼저 표시됩니다. 자동으로 시작되지는 않습니다.
- **한 번에 투표 하나만**: 현재 투표가 마감될 때까지 다른 투표를 시작하지 못하게 합니다. 새 템플릿에서는 기본으로 선택되어 있지 않습니다.
- **댓글 길이 제한**: 선택적으로 설정할 수 있는 댓글의 최대 길이입니다.
- **관리자만 첨부 파일을 추가할 수 있습니다**: 이 템플릿으로 시작한 토론에서 새 파일과 본문 내 이미지를 추가할 수 있는 사람을 스레드 관리자와 그룹 관리자로 제한합니다.

기본 제목은 계속 정확하게 사용할 수 있을 때만 설정하세요. 그렇지 않다면 작성자가 구체적인 검토 대상, 기간, 문서 또는 결정의 이름을 입력하도록 유도하는 제목 예시를 작성하세요.

## 예시: 회수용 병 시범 운영 검토

오트밀크 협동조합은 매 운영 주기가 끝날 때마다 회수용 병 시범 운영을 검토합니다. 템플릿 제목은 "회수용 병 시범 운영 검토"이며 기본 제목이 설정되어 있습니다. "회수용 병 시범 운영" 태그를 추가합니다. 배경에서는 멤버에게 주간 보고서를 읽고 병 회수율, 세척 기록, 카페의 의견, 운송 비용을 검토하도록 안내합니다. 의견 확인 후 이의 없음 투표를 진행하도록 권장합니다.

매 주기마다 목적과 검토할 근거가 같으므로 템플릿으로 사용하기에 적합합니다. 관찰 내용과 결정만 달라집니다.

## 템플릿 만들기

그룹 관리자는 템플릿 목록에서 **새 템플릿**을 선택할 수 있습니다. Loomio 갤러리에서 예시를 선택하거나 빈 템플릿으로 시작한 다음, 필요에 맞게 수정하고 저장하세요.

갤러리를 검색하거나 필터링할 수 있습니다. 예시는 저장해야 그룹에 추가됩니다.

<!-- translation-section: save-an-existing-discussion-as-a-template -->

### 기존 토론을 템플릿으로 저장

토론의 배경 아래에 있는 작업 메뉴에서 **템플릿으로 저장**을 선택하세요. 새 템플릿은 토론의 제목, 배경, 태그, 스레드 설정을 유지합니다. 템플릿 부제를 추가하고 내용을 검토한 다음 **템플릿 저장**을 선택하세요. 저장된 템플릿은 그룹의 템플릿 목록에 표시됩니다.

그룹 관리자는 이 작업을 사용할 수 있습니다. **멤버가 템플릿을 만들 수 있습니다**가 활성화되어 있으면 멤버도 사용할 수 있습니다. 이 작업은 그룹 내 토론에서 사용할 수 있습니다.

<!-- translation-section: manage-the-template-list -->

## 템플릿 목록 관리

그룹이 생성되면 Loomio가 그룹 유형에 맞는 템플릿 모음을 추가합니다. 처음에는 **빈 템플릿**과 **토론 연습**만 표시됩니다. 나머지는 숨겨져 있으며 그룹 관리자가 숨김을 해제할 수 있습니다.

그룹 관리자는 템플릿 옆의 작업 메뉴에서 다음 작업을 할 수 있습니다.

- 내용과 설정 수정
- 템플릿 목록에서 숨기기
- **숨긴 템플릿**에서 숨김 해제
- 표시되는 템플릿의 순서 변경
- JSON 파일로 내보내기
- 삭제

템플릿을 숨기면 나중에 사용할 수 있도록 보관됩니다. 템플릿을 삭제해도 해당 템플릿으로 시작한 토론은 삭제되지 않습니다.

<!-- translation-section: share-templates-between-groups -->

## 그룹 간 템플릿 공유

템플릿의 작업 메뉴에서 **JSON 내보내기**를 선택하면 파일로 다운로드할 수 있습니다. 다른 그룹에서 사용하려면 **새 템플릿**을 선택한 다음 **JSON 가져오기**를 선택하세요. 가져온 내용이 입력된 양식이 열리므로 저장 전에 검토할 수 있습니다.

사용자 지정 투표 템플릿의 링크는 파일에 포함되지 않습니다. 해당 투표 템플릿은 별도로 내보내고 가져오세요.

<!-- translation-section: let-members-create-templates -->

## 멤버의 템플릿 생성 허용

기본적으로 그룹 관리자만 템플릿을 만들고 수정할 수 있습니다. 그룹 관리자는 **그룹 설정** → **권한**에서 **멤버가 템플릿을 만들 수 있습니다**를 활성화할 수 있습니다.

이 설정을 활성화하면 멤버는 토론 템플릿과 투표 템플릿을 만들고, 자신이 만든 템플릿을 수정할 수 있습니다. 그룹 관리자는 그룹의 모든 템플릿을 수정할 수 있습니다. 멤버의 템플릿은 저장하면 그룹의 템플릿 목록에 표시되므로, 이 권한을 활성화하기 전에 이름 지정과 검토 방식을 합의하세요.

<!-- translation-section: templates-for-non-members -->

## 멤버가 아닌 사람을 위한 템플릿

**멤버가 아닌 사람도 토론을 시작할 수 있습니다**가 활성화되어 있으면 그룹 외부의 사람도 같은 템플릿 목록에서 선택합니다. 이들의 토론 양식에서는 그룹을 기본으로 초대하지 않습니다. [비공개 제출 받기](/en/user_manual/discussions/private_submissions)를 참고하세요.
