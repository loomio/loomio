# מתחילים

Loomio הוא כלי לדיון ולקבלת החלטות עבור ארגונים הפועלים בשיתוף פעולה.

## איך Loomio עובד

ל-Loomio שלושה חלקים עיקריים: קבוצות, דיונים וסקרים.

<!-- translation-section: groups -->

### קבוצות

קבוצה היא מקום שבו ארגון, צוות או קהילה יכולים לעבוד יחד. דף הבית שלה מסביר את מטרת הקבוצה ומקשר לדיונים, לסקרים, לחברים ולקבצים שלה.

![](orientation_group.png)

<!-- translation-section: discussions -->

### דיונים

דיונים מרכזים את המידע ואת השיחה בנושא מסוים במקום אחד. ניתן לשתף הקשר, לכתוב תגובות, להשיב, להביע תגובות באמצעות סמלים ולהשתמש בסקרים כדי לקדם דיון לקראת מסקנה.

![](orientation_discussion.png)

עם הזמן, הדיונים יוצרים תיעוד שניתן לחפש בו של המידע שנבחן ושל ההחלטות שהתקבלו בקבוצה.

<!-- translation-section: polls-and-proposals -->

### סקרים והצעות

סקרים מסייעים לקבוצה להבין העדפות, לאסוף עצות ולקבל החלטות. תבניות שונות של סקרים תומכות בתהליכים שונים. הצעה מבקשת מאנשים להגיב לדרך פעולה מוצעת ולהסביר את הנימוק לתגובתם.

![](orientation_proposal.png)

סקרים יכולים להיות חלק מדיון או להתנהל באופן עצמאי דרך הלשונית **סקרים** בדף הקבוצה.

כדי להכיר את מיקומם של החלקים האלה בממשק, ניתן לעיין ב[סיור הקצר](/en/user_manual/overview/orientation). כדי להתחיל להשתתף, ניתן לעיין ב[איך להשתתף](/en/user_manual/overview/how-to-participate).

## כיצד משתמשים ב-Loomio

**ארגונים מבוססי חברות** משתמשים ב-Loomio כדי לשתף חברים רבים בקבלת החלטות. מפלגות פוליטיות, קואופרטיבים של צרכנים ועובדים ואגודות חברים מספקים לחברים מקום משותף להעלות נושאים, לדון בסוגיות ולהצביע באספות כלליות.

**ארגונים בניהול עצמי** משתמשים ב-Loomio כדי לשתף את צוות העובדים בקבלת החלטות. צוותים בניהול עצמי, קואופרטיבים של עובדים וארגונים סוציוקרטיים מקיימים תהליכי הסכמה, קונצנזוס והתייעצות בצוותים הפועלים במקומות ובאזורי זמן שונים.

**דירקטוריונים, מועצות ורשתות מבוזרות** משתמשים ב-Loomio כדי לתאם פעילות בין בעלי עניין במקומות ובאזורי זמן שונים. הם שומרים על דיונים מסודרים, עוקבים אחר החלטות ומשמרים את הזיכרון הארגוני.

**קהילות מגורים וקואופרטיבים לדיור** משתמשים ב-Loomio כדי לקבל החלטות יחד כקהילת שכנים. קהילות דיור שיתופי, כפרים אקולוגיים, קואופרטיבים למגורים משותפים, קואופרטיבים לדיור ונאמנויות קרקע משתמשים בו כדי לנהל קרקע משותפת, מרחבים משותפים והסכמות קהילתיות. דיונים שאינם מחייבים השתתפות בו־זמנית מאפשרים לתושבים להשתתף גם בזמן שהייה במקום וגם במהלך נסיעות.
