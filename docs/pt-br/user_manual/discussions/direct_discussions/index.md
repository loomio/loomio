# Conversas diretas

Uma conversa direta é uma discussão privada para um conjunto específico de pessoas.

Uma conversa direta não pertence a um grupo. As pessoas convidadas não precisam ser membros do seu grupo no Loomio.

Você controla quem pode ver e participar adicionando pessoas ou endereços de e-mail ao campo **Convidar**.

As conversas diretas oferecem os mesmos comentários, enquetes e outras ferramentas que as discussões em grupo. Elas podem ser úteis quando não é necessário criar um subgrupo.

![Um formulário de conversa direta sem nenhum grupo selecionado e com Samira Patel no campo Convidar](direct-discussion-example.png)

Selecione **Tópicos diretos** na barra lateral para ver suas conversas diretas. Selecione **Nova discussão** nessa página para iniciar outra.

![O item Tópicos diretos na barra lateral e a lista de conversas diretas](direct-discussion-sidebar.png)

## Entrar em contato com alguém por meio de uma discussão direta
Uma discussão direta pode ser usada para entrar em contato com uma ou mais pessoas de forma privada, sem criar um subgrupo.
