# 日程調整

**日程調整**を使って、グループの他のLoomioでの活動と一緒に、会議やイベントの日時を決めます。参加者には、それぞれのタイムゾーンで日時の選択肢が表示されます。

![](meeting_polls.png)

<!-- translation-section: time-poll -->

## アンケートを設定する

![](timepoll_label.png)

日程調整のタイトルと詳細を入力します。自分のタイムゾーンで日時の選択肢を入力し、会議の所要時間を設定します。

選択肢を決める際は、全員が参加できる日時を選べるよう、異なるタイムゾーンにいる人にも配慮します。

![](timepoll_options.png)

<!-- translation-section: voting -->

### 投票

参加者は、各日時の選択肢について、参加できる、必要であれば参加できる、参加できない、のいずれかを選びます。投票の理由を追加して、参加の都合を説明したり、別の日時を提案したりすることもできます。どの選択肢も都合が合わない場合は、アンケートを編集して新しい日時を追加できます。

![](timepoll_vote.png)

投票が進むにつれて結果が更新され、各日時に誰が参加できるかが表示されます。

<!-- translation-section: outcome -->

### 結論を共有する

日程調整を締め切ったら、最適な日時を選び、結論を共有します。結論の仕組みについては、[結論を共有する](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome)を参照してください。

![](timepoll_outcome.png)

- **通知する**: 会議やイベントに招待する人を追加します。
- **会議の時間**: 最適な日時を選択します。選択肢には[プロフィールのタイムゾーン](/en/user_manual/users/user_profile#time-zone)が使われます。
- **会議名**: 会議に名前を付けます。Loomioは、既定で日程調整のタイトルを使います。
- **位置**: 会場の所在地またはオンライン会議のリンクを追加します。
- **声明**: 決定を要約し、会議に関する案内を追加します。

Loomioは、選択した日時、会議名、所要時間、位置、声明を、結論の通知とカレンダーの招待に含めます。
