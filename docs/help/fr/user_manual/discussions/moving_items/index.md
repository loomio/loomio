# Déplacer des éléments entre les fils

Déplacez des commentaires ou des sondages lorsqu’une conversation a sa place dans un autre fil, lorsqu’une discussion se scinde en plusieurs sujets distincts ou lorsque vous souhaitez regrouper des fils liés.

Les administrateurs du groupe peuvent déplacer des éléments. Les membres peuvent également déplacer des éléments lorsque l’option **Les membres peuvent gérer les discussions et les commentaires.** est activée dans les [Permissions du groupe](/en/user_manual/groups/settings/permissions).

1. Ouvrez le menu à trois points (**⋯**) d’un élément et sélectionnez **Déplacer l'élément**.

![](../using_discussions/comment_move.png)

2. Utilisez les cases à cocher pour sélectionner les éléments que vous souhaitez déplacer, puis sélectionnez **Déplacer** dans le bandeau en haut du fil.

![](../using_discussions/comment_select.png)

![](../using_discussions/move_items.png)

3. Choisissez le groupe ou le sous-groupe de destination, puis recherchez une discussion existante. Pour créer une nouvelle discussion, sélectionnez **Nouvelle discussion**, ajoutez un titre et un contexte, puis sélectionnez **Lancer une discussion**.

![](../using_discussions/move_items_new_thread.png)

Les éléments sélectionnés sont déplacés du fil d’origine vers le fil de destination.

![](../using_discussions/new_thread.png)

Si le fil d’origine n’est plus nécessaire, vous pouvez [le verrouiller](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread). Supprimez-le uniquement si vous avez la certitude de ne plus en avoir besoin.
