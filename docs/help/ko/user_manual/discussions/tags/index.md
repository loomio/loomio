# 분류 태그

분류 태그를 사용하면 주제나 업무 분야에 관한 토론, 투표, 결론, 댓글을 찾을 수 있습니다.

태그는 조직 전체에 속합니다. 상위 그룹에서 만든 태그는 하위 그룹과 공유되므로 그룹 전반의 관련 업무를 추적할 수 있습니다. Loomio는 태그를 알파벳순으로 나열하고 각 이름 옆에 색상 점을 표시합니다.

**모든 그룹** 또는 그룹 페이지에서 스레드, 투표, 할 일 목록 위의 **태그**를 선택하고 태그를 고르면 해당 태그가 적용된 항목이 표시됩니다. 목록이 길면 필터 입력란에 입력하여 검색하세요.

![](tags_view.png)

## 태그 적용

직접 작성한 토론, 투표, 결론, 댓글에 태그를 적용할 수 있습니다. 그룹 관리자, 스레드 관리자, 토론 배경을 편집할 권한이 있는 사람은 잠기지 않은 스레드의 모든 항목에 태그를 적용할 수 있습니다. 다이렉트 스레드에서는 모든 참여자가 모든 항목에 태그를 적용할 수 있습니다.

스레드나 투표를 시작할 때 **태그** 입력란을 선택하고 태그를 하나 이상 선택하세요.

![](tags_add_new.png)

글자를 입력하면 목록을 필터링할 수 있습니다. 태그를 제거하려면 해당 태그를 다시 선택하거나 태그의 **×**를 선택하세요.

## 태그 만들기

태그를 만들 수 있는 사람은 그룹 역할과 권한에 따라 달라집니다.

- **상위 그룹 관리자**는 언제든지 상위 그룹과 하위 그룹에서 사용할 태그를 만들 수 있습니다.
- **하위 그룹 관리자**는 해당 하위 그룹의 콘텐츠에 태그를 적용하면서 태그를 만들 수 있습니다.
- 콘텐츠에 태그를 적용할 수 있는 **그룹 멤버**는 **멤버가 태그를 만들 수 있습니다** 권한이 활성화되어 있으면 태그도 만들 수 있습니다. 이 권한은 기본적으로 활성화되어 있습니다. 그룹 관리자가 이 권한을 비활성화하면 멤버는 조직의 기존 태그와 해당 그룹 템플릿의 기본 태그만 사용할 수 있습니다.

스레드나 투표를 시작하면서 태그를 만들려면 **태그** 입력란에 이름을 입력하고 Enter를 누르세요.

![새 태그 만들기](tags_create_new.png)

![새로 만든 태그](tags_created_new.png)

재무, 운영, 포장, 카페 협력처럼 알아보기 쉬운 짧은 이름을 사용하세요.

## 템플릿의 태그

토론 및 투표 템플릿은 기본 태그 이름을 저장합니다. 템플릿을 만들거나 편집할 수 있는 사람은 누구나 기본 태그를 변경할 수 있습니다. 템플릿을 저장해도 해당 이름이 조직의 태그 목록에 추가되지 않으며, 조직 태그의 이름을 변경하거나 태그를 삭제해도 템플릿 기본값은 변경되지 않습니다.

템플릿에서 토론이나 투표를 시작하면 Loomio는 일치하는 조직 태그를 적용하거나, 작성자에게 권한이 있으면 새 태그를 만듭니다.

- **태그를 만들 수 있는 멤버**는 템플릿의 모든 기본 태그를 유지합니다.
- **태그 생성 권한이 없는 멤버**는 조직의 기존 태그와 대상 그룹의 템플릿에 지정된 기본 태그를 유지합니다. 다른 그룹의 템플릿에 있는 태그 이름 중 이 조건에 해당하지 않는 이름은 제외됩니다.

## 태그 편집

상위 그룹 관리자만 태그의 이름과 색상을 변경하거나 태그를 병합하거나 삭제할 수 있습니다. 변경 사항은 모든 하위 그룹을 포함한 조직 전체에 적용됩니다.

그룹 페이지에서 **태그**를 열고 **태그 편집**을 선택하거나, **설정**을 열고 **분류 태그**를 선택하세요.

![분류 태그 편집](tags_edit_new.png)

태그를 편집하려면 태그 옆의 연필 아이콘을 선택하세요.

![분류 태그 편집](tags_edit_new_pencil.png)

태그 이름을 변경하거나 색상을 선택한 다음 **저장**을 선택하세요.

![태그 색상 편집](tags_edit_name.png)

태그를 다른 태그로 병합하려면 해당 태그 옆의 병합 아이콘을 선택하고 유지할 태그를 선택하세요. 기존 태그가 적용된 모든 항목이 선택한 태그로 옮겨집니다.

태그를 삭제하려면 **삭제** 또는 휴지통 아이콘을 선택하세요. 조직의 모든 토론, 투표, 결론, 댓글에서 해당 태그가 제거됩니다.

![태그 삭제](tags_delete.png)

### 스레드나 투표의 태그 편집

기존 스레드나 투표의 태그를 변경하려면 해당 항목을 열고 제목 근처의 현재 태그 옆에 있는 태그 버튼을 선택하세요.

태그를 선택하여 추가하거나 제거하세요. 변경 사항은 즉시 저장됩니다.

태그 선택 창에는 현재 그룹에서 사용하는 태그, 사용하지 않는 조직 태그, 해당 항목에 선택된 태그가 표시됩니다. 여러 그룹이 있는 조직에서는 **다른 그룹의 태그 보기**를 선택하여 다른 그룹에서만 사용하는 태그를 포함하거나, **이 그룹에서 사용하는 태그 보기**를 선택하여 목록을 다시 좁히세요.

![스레드의 태그 편집](tags_thread_edit.png)

## 게시물에 태그 적용

투표, 결론 또는 댓글의 점 세 개 메뉴(**⋯**)를 열고 **태그 적용**을 선택하세요. 태그 선택 창에서 태그를 추가하거나 제거하세요. 변경 사항은 즉시 저장됩니다. 게시물에 태그가 있으면 작성자가 표시된 줄의 오른쪽에 태그와 태그 버튼이 표시됩니다.

태그는 선택한 항목에 적용됩니다. 표와 투표용지에는 태그를 적용할 수 없습니다.

<!-- translation-section: find-tagged-contributions -->

## 태그가 적용된 게시물 찾기

스레드 안의 댓글, 투표 또는 결론에 태그가 있으면 스레드 사이드바에 **태그** 영역이 표시됩니다. 모바일에서는 탐색 패널에 표시됩니다.

태그를 선택하면 해당 태그와 일치하는 항목 및 해당 항목이 답글을 단 원래 항목만 표시됩니다. 전체 스레드로 돌아가려면 필터 표시줄의 **×**를 선택하거나, 해당 태그를 다시 선택하거나, 사이드바에서 **지우기**를 선택하세요.

![스레드 사이드바의 태그](tags_thread_sidebar.png)

## 태그로 검색

상단 탐색 메뉴에서 **검색**을 열고 상위 그룹을 선택하면 태그 메뉴가 표시됩니다. 태그를 선택하여 해당 태그가 적용된 토론, 투표, 결론, 댓글을 찾으세요.

태그별로 살펴보려면 검색 입력란을 비워 두세요. 태그가 적용된 항목 안에서 검색하려면 검색어를 입력하세요. 필터를 해제하려면 **모든 태그**를 선택하세요.

![전체 검색에서 상위 그룹을 선택한 후 태그 선택](tags_global_search.png)
