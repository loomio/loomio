# Introducción a los grupos

Un grupo de Loomio es un lugar seguro donde las personas pueden reunirse, mantener discusiones y tomar decisiones.

Es un espacio donde los miembros del grupo pueden encontrar y compartir información, participar en discusiones importantes y tomar decisiones que afectan a su trabajo.

Un grupo de Loomio tiene este aspecto. En la parte superior de la página verás una imagen y un logotipo que puedes personalizar para representar a tu organización. Esto permite que las personas que llegan a tu grupo reconozcan el espacio y se sientan bienvenidas: un lugar seguro donde sentirse como en casa, entre amistades, y participar de forma efectiva.

![La página del grupo Oatmilk Cooperative, con su descripción y lista de discusiones](group_page.png)

Elige un nombre representativo para tu grupo y utiliza la descripción del grupo para explicar:
- **para qué** se utiliza este grupo,
- **por qué** es importante,
- **quiénes** participan y
- **cómo** pueden participar los miembros.

También puedes incluir información como un código de conducta, términos de referencia u otros documentos que establezcan las normas del grupo.

Si estás preparando un grupo nuevo, consulta [Cómo presentar Loomio a tu grupo](/en/user_manual/overview/introducing_loomio) para seguir una secuencia práctica desde la elección del primer trabajo hasta el registro de una conclusión.

## Administración, facilitación y moderación - Código de conducta

Loomio está diseñado para promover la participación inclusiva, la diversidad y la confianza, y ayudar a los grupos a tomar mejores decisiones en conjunto.

Algunos temas generan tensión en un grupo. Por eso es importante permitir una discusión a fondo y, al mismo tiempo, garantizar que el espacio sea seguro, especialmente para las personas vulnerables de tu grupo.

Recomendamos establecer un código de conducta para tu grupo que ayude a todas las personas a ser conscientes de su responsabilidad de comportarse adecuadamente y fomente la autorregulación.

Consulta la [Guía de facilitación](/en/guides/facilitators_guide/commencing#culture-protocol-expectations) para conocer mejor el valor de un código de conducta.
