# Integração com o Discord

O Loomio pode enviar notificações para seus canais do Discord quando houver novas discussões, enquetes, comentários, votos e conclusões. Você também pode notificar o canal manualmente quando quiser lembrar as pessoas de uma decisão.

---

1. Abra seu servidor do Discord e acesse **Configurações do servidor**.

   ![](server-settings.png)

2. Selecione **Integrações**.

   ![](integrations.png)

3. Selecione **Adicionar webhook**, dê a ele um nome como `Loomio`, escolha um canal e copie a URL do webhook.

   ![](add-webhook.png)

Agora que você tem a URL do webhook, conclua a conexão no Loomio:

[Configure uma integração de chat no Loomio](../chatbots/#set-up-a-chat-integration)
