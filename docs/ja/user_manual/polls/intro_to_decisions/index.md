# 提案と投票

提案と投票では、グループから決まった形式の回答を集めます。アイデアの検討、意思決定、優先事項の整理、会議の日程調整、代表者の選出に役立ちます。

<!-- translation-section: find-the-right-help -->

## 目的に合った説明を探す

目的に応じて、次のページを参照してください。

| したいこと | 参照先 |
|---|---|
| 参加者に何を表明してもらうか選ぶ | [提案](../proposals/)または[投票](../proposal_types/) |
| 特定の提案テンプレートを使う | [センスチェック](../proposals/sense_check/)、[アドバイス](../proposals/advice/)、[同意](../proposals/consent/)、または[コンセンサス](../proposals/consensus/) |
| グループで利用できるテンプレートを設定する | [投票テンプレート](../poll_templates/) |
| ディスカッションから結論まで意思決定を進める | [意思決定の進め方](/en/guides/making_decisions/) |

**投票方法**は、参加者の回答方法と結果の計算方法を定めます。**投票テンプレート**は、投票方法をもとに、説明、選択肢、設定をあらかじめ用意した再利用可能な設定です。**意思決定のプロセス**では、グループが結論に至るまでに、ディスカッションと複数のテンプレートを使うことがあります。

<!-- translation-section: proposals -->

## 提案

提案では、ある考えや行動方針について参加者に回答してもらいます。Loomio には、一般的な目的に合わせたテンプレートがあります。

- [センスチェック](../proposals/sense_check/)は初期の反応を集めます。
- [アドバイス](../proposals/advice/)は意思決定者のために意見を集めます。
- [同意](../proposals/consent/)は重要な異議がないか確かめます。
- [コンセンサス](../proposals/consensus/)は全員での合意を目指します。

各テンプレートの比較は[提案](../proposals/)を参照してください。

<!-- translation-section: polls -->

## 投票

参加者に選択、採点、ポイントの配分、順位付け、参加可能な日時の表明、選挙での投票をしてもらう場合は、投票を使います。

- [選ぶ](../choose/)は人気のある選択肢を見つけます。
- [スコア](../score/)は各選択肢を尺度に沿って評価します。
- [割り当てる](../allocate/)は限られたポイントを選択肢に配分します。
- [ランク](../rank/)は全体の優先順位を調べます。
- [時間投票](../meeting_polls/)は参加できる日時を調べます。
- [STV選挙](../stv/)は得票に応じて複数の当選者を選びます。

各投票方法の比較は[投票](../proposal_types/)を参照してください。

<!-- translation-section: start-a-proposal-or-poll -->

## 提案または投票を開始する

<!-- translation-section: choose-whether-to-use-a-discussion -->

### ディスカッションを使うか選ぶ

回答する前に背景情報の共有、質問、意見交換が必要な場合は、ディスカッション内で提案または投票を開始します。一つのディスカッションで時間をかけて複数の提案を扱えます。修正の経緯と最終的な結論を、同じ議題の記録として残せます。

会議など別の場所ですでに話し合った場合や、質問が単純で回答だけを集めたい場合は、ディスカッションを作らずに投票を実施します。投票者が何に回答するのか分かるよう、十分な説明か関連する記録へのリンクを添えてください。

<!-- translation-section: in-a-discussion -->

### ディスカッション内で開始する

ディスカッションを開き、返信欄までスクロールして**投票を開始する**を選び、テンプレートを選択します。

![](process_run.png)

<!-- translation-section: without-a-discussion -->

### ディスカッションを使わずに開始する

グループのページで**投票**タブを開き、**新しい投票**を選んで、テンプレートを選択します。

![](standalone_poll.png)

投票だけを行うためにディスカッションと投票を同時に作成する場合は、通知が二重に届かないようにします。通知せずにディスカッションを開始して投票への招待を使うか、ディスカッションを作らずに投票を実施します。

<!-- translation-section: what-happens-next -->

## 開始後の流れ

提案または投票を開始するときは、タイトルと詳細を入力し、回答の選択肢と設定を確認して、締め切りを設定し、参加者を招待します。受付中は、参加者が投票し、回答の理由を説明し、投票を変更できます。結果は投票が送信されるたびに更新されますが、表示される内容は結果の公開設定によって異なります。

締め切り後は、結果が何を意味し、次に何をするかを記録した[結論](../outcomes/)を公開します。
