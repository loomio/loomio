# アドバイス

アドバイス提案は、個人やチームが責任を持って行う決定について意見を集めます。参加者はアドバイスを提供するか、追加するアドバイスがないことを示せます。

このページでは、アドバイス提案のフォーム、投票、結果について説明します。決定すべきことを明確にするところから結論を公開するまでの一連の流れについては、[アドバイスのプロセス](/en/guides/making_decisions/advice_process)を参照してください。

<!-- translation-section: when-to-use-advice -->

## アドバイスを使う場面

決定を行う人が、関連する専門知識を持つ人や決定の影響を受ける人から意見を集めたい場合に、アドバイスを使います。取引先の選定、業務上の決定、方針案の検討、委任された役割の範囲内での決定に適しています。

アドバイスは承認のための投票ではありません。誰が決定を行うのか、どのような制約があるのか、寄せられた回答をどのように検討するのかを明記します。

<!-- translation-section: example-choose-a-washing-supplier -->

## 例：洗浄業者を選ぶ

Oatmilk Cooperativeの業務コーディネーターは、洗浄業者を選定する必要があります。処理能力、食品安全に関する実績、水の使用量、サービスの対応時間、サポートについてアドバイスを求めます。

<!-- translation-section: set-up-the-proposal -->

## 提案を設定する

決定する内容を説明し、決定を行う人を明記して、参加者に必要な情報を記載します。影響を受ける人や関連する知識を持つ人を招待します。既定の選択肢では、アドバイスを提供するか、棄権するかを選べます。

![](form.png)

<!-- translation-section: vote -->

## 投票する

参加者は**アドバイス**を選択し、具体的な推奨事項、リスク、質問、関連する経験を記載します。役立つ意見がない場合は棄権できます。

![](../proposal_advice_voting.png)

<!-- translation-section: read-the-results -->

## 結果を確認する

グラフでは誰が回答したかを確認できますが、アドバイス提案の実質的な内容は投票の理由にあります。最も多い回答をそのまま決定とするのではなく、制約、意見が一致している点、相反する推奨事項を確認します。

![](../proposal_advice_results.png)

<!-- translation-section: share-an-outcome -->

## 結論を共有する

提案が締め切られたら、決定を行う人が結論を共有します。結論には、何を決定したか、アドバイスを決定にどのように活かしたかを記載します。結論の仕組みについては、[結論を共有する](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome)を参照してください。
