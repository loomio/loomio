# הגדרות הקבוצה

הגדרות הקבוצה קובעות כיצד הקבוצה מוצגת, מי יכול למצוא אותה ולהצטרף אליה, ואילו פעולות מותר לחברים לבצע. רק מנהלי הקבוצה יכולים לערוך הגדרות אלה.

בעמוד הקבוצה, יש לפתוח את **הגדרות** ולבחור **ערוך הגדרות קבוצה**.

![עריכת הגדרות הקבוצה מתוך עמוד הקבוצה](group_settings.png)

טופס ההגדרות מחולק לשלושה תחומים:

## פרופיל הקבוצה

[פרופיל הקבוצה](/en/user_manual/groups/settings/profile) כולל את שם הקבוצה, המזהה שלה, התיאור, תמונת הנושא והלוגו.

<!-- translation-section: group-privacy -->

## פרטיות הקבוצה

[פרטיות הקבוצה](/en/user_manual/groups/settings/privacy) כוללת הגדרות הקובעות מי יכול למצוא את הקבוצה, מי יכול לקרוא את התוכן שלה, כיצד ניתן להצטרף אליה, אם היא מופיעה במדריך הקבוצות וכיצד ניתן לעקוב אחר קבוצה ציבורית.

<!-- translation-section: group-permissions -->

## הרשאות הקבוצה

[הרשאות הקבוצה](/en/user_manual/groups/settings/permissions) קובעות אילו פעולות יכולים לבצע חברים, אנשים שאינם חברי הקבוצה ומנהלי הקבוצה.
