# Formatar texto e anexar arquivos

A barra de formatação aparece abaixo do campo de texto sempre que você inicia ou edita uma discussão, cria uma enquete ou escreve um comentário. Selecione a seta no final da barra para mostrar ou ocultar todas as ferramentas.

Passe o cursor sobre qualquer ícone para ver seu nome.

![](thread_format_bar.png)

<!-- translation-section: attach-file -->

## Anexar arquivo

Selecione o ícone de clipe de papel abaixo do campo de texto para anexar arquivos do seu dispositivo.

![](format_attach.png)

<!-- translation-section: remove-attachments -->

### Remover anexos

Durante a edição, selecione **×** ao lado do nome de um arquivo para removê-lo.

![](thread_file_remove.png)

<!-- translation-section: insert-image -->

## Inserir imagem

Selecione **Inserir imagem** para enviar uma imagem ou cole uma diretamente no editor. A imagem aparece no corpo da sua discussão, enquete ou comentário.

![](format_insert_example.png)

<!-- translation-section: insert-link -->

## Inserir link

Você pode adicionar um link para qualquer página ou documento na internet:

1. Selecione o texto que você quer transformar em link.
2. Selecione o ícone de link.
3. Cole a URL em **Inserir link** e selecione **Aplicar**.

Verifique as permissões de compartilhamento de qualquer documento externo para que os participantes possam abri-lo. Se uma prévia do link aparecer abaixo do seu texto, você pode removê-la.

![](format_link.png)

<!-- translation-section: insert-emoji -->

## Inserir emoji

Selecione o ícone de rosto sorridente para escolher um emoji.

![](thread_insert_emoji.png)

## Títulos

Use **Título 1**, **Título 2** e **Título 3** para estruturar discussões ou comentários longos.

Comentários que incluem um **Título 2** ou **Título 3** são adicionados automaticamente à lista **Pular para** da conversa.

![](format_heading.png)

## Lista de tarefas

## Incorporar vídeos e páginas da web

Você pode incorporar vídeos e páginas da web compatíveis em qualquer lugar onde a barra de formatação apareça:

1. Copie a URL do vídeo ou da página da web.
2. Selecione **Anexar video**, cole a URL e selecione **Aplicar**.

![](format_embed.png)

<!-- translation-section: markdown -->

## Markdown

Selecione **Editar Markdown** para escrever em Markdown.

A conversão para Markdown preserva títulos, texto em negrito e itálico, listas, tabelas básicas, tarefas marcadas como concluídas, imagens, links e @menções. Vídeos, áudios e conteúdo incorporado são convertidos em links.

Cores do texto, realces, sublinhados, alinhamento e disposições personalizadas das tabelas podem ser perdidos. Os prazos e lembretes das tarefas são removidos; ao voltar para texto formatado, novas tarefas são criadas com o mesmo texto e o mesmo estado de conclusão.

<!-- translation-section: rich-text -->

### Texto formatado

Selecione **Editar texto formatado** para voltar à barra de ferramentas de formatação e converter o Markdown compatível em texto formatado.

Selecione **Pré-visualizar** para ver como seu Markdown ficará sem convertê-lo.
