# タイムポーリング

**タイムポーリング**を使うと、会議やイベントの日時を決められます。Doodle などの日程調整ツールと同じ目的に使え、グループのほかの Loomio での作業と一緒に日程を調整できます。参加者には、候補日時が各自のタイムゾーンで表示されます。

![](meeting_polls.png)

<!-- translation-section: time-poll -->

## タイムポーリング

_参加できる日時を確認する_

会議やイベントの日程調整にかかる時間を減らせます。

![](timepoll_label.png)

タイムポーリングでは、全員の都合を確認し、最適な日時を見つけられます。

タイムポーリングのタイトルと詳細を入力します。自分のタイムゾーンで候補日時を一覧にして入力します。

候補日時を設定するときは、異なるタイムゾーンにいる人にも配慮してください。参加者には、それぞれのタイムゾーンに合わせた日時が表示されます。

会議の所要時間を設定します。

![](timepoll_options.png)

<!-- translation-section: voting -->

### 投票

参加者は各候補日時について、参加できる場合は緑色の親指を上げたアイコン、必要であれば参加できる場合は黄色の横向きの親指、参加できない場合は赤色の親指を下げたアイコンを選びます。

参加者は理由をコメントに記入して、主催者が適切な日時を選ぶための参考にできます。

候補日時が合わない場合、参加者はメッセージ欄で別の日時を提案できます。その後、タイムポーリングに新しい候補日時を追加できます。

![](timepoll_vote.png)

投票が進むと、誰がいつ参加できるかを示す表が更新されます。どの候補日時に参加できる人が多いか、全員が確認できます。

<!-- translation-section: outcome -->

### 結論

タイムポーリングが終了したら、最適な日時を選んで結論を投稿します。

![](timepoll_outcome.png)

**通知する**: 会議やイベントに招待する人を追加します

**会議の時間**: 最適な日時を選びます

**会議名**: 会議の名前を入力します。初期設定ではタイムポーリングのタイトルが使われます

**位置**: 会場の場所または会議のリンクを追加します

**声明**: 結論をまとめ、会議に関する連絡事項を追加します

選択した日時、会議名、所要時間、場所、声明は、Loomio から送られる結論の通知とカレンダーの招待に記載されます。
