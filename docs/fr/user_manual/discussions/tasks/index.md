# Tâches

Dans les discussions et les commentaires, les tâches permettent de décrire une action, de l’attribuer à une personne, de fixer une échéance et de suivre son avancement.

<!-- translation-section: add-a-task -->

## Ajouter une tâche

Lorsque vous rédigez une discussion ou un commentaire, développez la barre d’outils de mise en forme et cliquez sur **Liste des tâches**. Saisissez l’action à côté de la case à cocher.

![](tasklist1.png)

<!-- translation-section: name-and-assign-the-task-to-a-person -->

## Nommer et attribuer une tâche

Utilisez une @mention dans la tâche pour l’attribuer à un membre du groupe. Le bouton **Ajouter échéance** apparaît dès qu’une personne est désignée.

![](tasklist2.png)

Les tâches qui vous sont attribuées figurent sur votre page **Tâches**. Ouvrez **Tâches** dans la barre latérale pour les voir regroupées par discussion ou par sondage.

![](task_list.png)

<!-- translation-section: set-a-reminder -->

## Définir un rappel

Cliquez sur **Ajouter échéance** pour choisir une date limite et le moment où Loomio enverra un rappel par courriel à la personne responsable. Vous pouvez aussi supprimer une échéance existante dans cette fenêtre.

![](taskreminderform.png)

<!-- translation-section: mark-it-as-done -->

## Marquer une tâche comme terminée

![](taskdone.png)

Cliquez sur la case à cocher à côté d’une tâche pour la marquer comme terminée. Vous pouvez le faire pendant que vous modifiez le texte, pendant que vous le lisez si la tâche vous est attribuée, ou depuis la page **Tâches**. Cliquez de nouveau sur la case pour rouvrir la tâche.
