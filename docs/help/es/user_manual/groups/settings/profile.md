# Perfil del grupo

La pestaña de perfil controla cómo se identifica y se presenta tu grupo. Abre **Editar la configuración del grupo** desde la página del grupo y selecciona **Perfil**.

![Configuración del perfil del grupo](group_profile.png)

<!-- translation-section: name-and-handle -->

## Nombre e identificador

Elige un nombre breve para el grupo, especialmente si va a contener subgrupos. Loomio utiliza el identificador en la dirección web y en la dirección de correo electrónico del grupo, como `loomio.com/your-group-handle` y `your-group-handle@loomio.com`.

Cuando cambias el identificador, los enlaces que utilizan el identificador anterior redirigen a la nueva dirección, y los correos enviados a la dirección anterior del grupo siguen llegando al grupo. Loomio conserva hasta tres identificadores anteriores; si vuelves a cambiar el identificador después de alcanzar ese límite, el más antiguo caduca.

<!-- translation-section: description -->

## Descripción

Usa la descripción para explicar para qué sirve el grupo, quién participa y cómo se espera que las personas lo utilicen. Puedes dar formato a la descripción e incluir enlaces, documentos y vídeos.

El nombre y la descripción pueden ser visibles para quienes no son miembros, según la [configuración de privacidad](/en/user_manual/groups/settings/privacy) del grupo.

<!-- translation-section: cover-image-and-logo -->

## Imagen de portada y logotipo

La imagen de portada ocupa la parte superior de la página del grupo. Una imagen ancha funciona mejor; el tamaño recomendado es de 2048 × 512 píxeles.

El logotipo del grupo lo identifica en la navegación y en otros espacios reducidos. Sube la imagen de portada y el logotipo por separado para poder recortar cada uno según la forma prevista.
