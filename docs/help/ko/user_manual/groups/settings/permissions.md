# 그룹 권한

**권한** 탭에서는 멤버가 그룹에서 할 수 있는 작업을 설정합니다. 숨김 그룹이 아닌 경우에는 멤버가 아닌 사람이 할 수 있는 작업도 설정합니다. 그룹 페이지에서 **설정**을 열고 **그룹 설정 수정**을 선택한 다음 **권한**을 선택하세요.

![그룹 권한 설정](group_group_settings_permissions.png)

그룹 관리자는 항상 모든 관리 권한을 유지합니다. 권한을 활성화하면 멤버가 그룹 관리자가 되지 않고도 해당 작업을 할 수 있습니다.

권한으로 멤버에게 다음 작업을 허용할지 설정합니다.

- 멤버 추가 또는 게스트 초대
- 공지 발송
- 하위 그룹 생성
- 토론 시작 및 관리
- 태그 생성 및 관리
- 설정에서 허용하는 경우 댓글 수정 또는 삭제
- 제안 및 투표 시작
- 토론 및 투표 템플릿 생성

숨김 그룹이 아닌 경우 그룹 관리자는 멤버가 아닌 사람에게도 토론 시작을 허용할 수 있습니다. 멤버가 아닌 사람이 토론을 시작하면 해당 스레드의 게스트가 되지만, 그룹 멤버가 되거나 다른 비공개 토론에 접근할 수 있게 되지는 않습니다.

**그룹 관리자가 멤버의 댓글을 수정할 수 있습니다** 설정을 활성화하면 그룹 관리자가 멤버가 작성한 콘텐츠를 수정할 수 있습니다. 그룹 관리자가 멤버의 댓글을 수정할 수 있도록 그룹에서 합의한 경우에만 이 설정을 활성화하세요.

그룹의 목적, 멤버 구성 또는 콘텐츠 관리 요구 사항이 바뀔 때마다 권한을 검토하고, 각 역할에는 필요한 권한만 부여하세요.
