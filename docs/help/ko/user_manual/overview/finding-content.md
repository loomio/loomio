# 콘텐츠 찾기

Loomio는 여러 그룹의 토론과 결정을 찾을 수 있는 다양한 방법을 제공합니다.

<!-- translation-section: search -->

## 검색

Loomio의 어느 페이지에서든 상단 탐색 모음의 **검색**을 선택해 검색하세요.

![](search_button.png)

검색 대상에는 접근할 수 있는 모든 그룹과 직접 토론이 포함됩니다. 토론 제목, 배경, 댓글, 투표, 개별 표, 결론을 찾을 수 있습니다.

단어나 구문을 입력하고 Enter 키를 누르세요. 예를 들어 **bottle**을 검색하면 Oatmilk Cooperative에서 해당 단어가 포함된 콘텐츠를 찾습니다.

![](search_strategy.png)

<!-- translation-section: search-tips -->

### 검색 팁

- 제목이나 내용에서 구체적인 단어 한두 개로 시작하세요.
- 검색은 단어의 시작 부분과 일치하는 항목을 찾으므로 **bott**처럼 단어의 일부만 입력해도 **bottle**을 찾을 수 있습니다.
- 검색 결과가 적으면 사소한 철자 오류를 보정합니다.
- 조직, 하위 그룹, 태그 또는 댓글이나 투표 같은 콘텐츠 유형으로 결과를 필터링하세요. 태그 필터는 검색어 없이도 사용할 수 있으며, 해당 태그가 지정된 항목을 찾습니다.
- 관련성에 따라 정렬하려면 **관련도순**을 선택하고, 게시된 시점을 대략 알고 있다면 최신순이나 오래된순으로 정렬하세요.

<!-- translation-section: filter-discussions -->

## 토론 필터링

그룹의 **스레드** 페이지에서 잠금 상태, 읽지 않은 활동, 카테고리 태그 또는 하위 그룹별로 스레드를 필터링할 수 있습니다(하위 그룹 필터에서는 **이 그룹만**, **내 하위 그룹**, **모든 하위 그룹** 중 선택). **모든 그룹**에서는 **읽지 않음**, **다이렉트**, 카테고리 태그로 필터링하거나 **검색**으로 목록을 좁힐 수도 있습니다.

<!-- translation-section: category-tags -->

## 카테고리 태그

태그는 프로젝트, 팀, 업무 분야처럼 그룹에서 정한 이름으로 관련 토론, 투표, 결론, 댓글을 묶습니다.

![](tags.png)

**스레드**, **투표**, **할 일**에서 태그를 선택하면 해당 태그가 지정된 항목이 표시됩니다. 토론 안에서는 사이드바의 태그를 선택해 해당 태그가 지정된 댓글, 투표, 결론과 각 항목이 답글로 달린 원래 항목을 함께 확인하세요.

작성자는 자신의 게시물에 태그를 지정할 수 있습니다. 그룹 관리자, 스레드 관리자, 토론 배경을 편집할 수 있는 사람은 모든 항목에 태그를 지정할 수 있습니다. 설정과 권한에 관한 내용은 [카테고리 태그](/en/user_manual/discussions/tags)를 참고하세요.

<!-- translation-section: unread-discussions -->

## 읽지 않은 토론

**모든 그룹** 또는 그룹의 **스레드** 페이지에서 **읽지 않음**을 선택하거나 **스레드** 카드에서 읽지 않은 항목 수를 선택하면 최근 6주 동안 새 활동이 있는 스레드를 볼 수 있습니다. 토론 안에서는 타임라인을 사용해 읽지 않은 항목과 주요 이벤트로 이동하세요.

<!-- translation-section: polls-awaiting-your-vote -->

## 참여할 투표

**모든 그룹**에서 **투표**를 열거나 **투표** 카드에서 표 수를 선택하면 초대받았지만 아직 투표하지 않은 진행 중인 투표를 볼 수 있습니다. **모든 그룹** 또는 각 그룹 페이지에서 **투표 필요**, **진행 중**, **마감됨**, 투표 유형 또는 태그로 필터링할 수도 있습니다.

<!-- translation-section: bookmarks -->

## 북마크

나중에 다시 보고 싶은 토론, 댓글, 투표, 개별 표 또는 결론을 북마크에 추가하세요. **모든 그룹**에서 **북마크**를 열면 저장한 모든 항목을 볼 수 있고, 그룹 페이지에서 **북마크**를 열면 해당 그룹의 북마크를 볼 수 있습니다. 자세한 내용은 [북마크](/en/user_manual/users/bookmarks)를 참고하세요.
