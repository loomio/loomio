# 의견 확인

의견 확인은 아이디어를 구체화하는 동안 반응을 모으는 투표입니다. **좋아 보임**, **개선 필요**, **재검토 필요** 선택지를 통해 그룹이 다음 단계로 진행할 준비가 되었는지, 먼저 아이디어를 수정해야 하는지 확인할 수 있습니다.

이 페이지에서는 의견 확인 투표를 진행하는 방법을 설명합니다. 더 큰 의사결정 과정의 한 단계로 의견 확인을 사용하는 예시는 [간단한 의사결정 과정](/en/guides/making_decisions/simple_decision_process), [이의 없는 의사결정 과정](/en/guides/making_decisions/consent_process), [합의 과정](/en/guides/making_decisions/consensus_process)을 참고하세요.

<!-- translation-section: when-to-use-sense-check -->

## 의견 확인을 사용하는 경우

다음과 같은 경우에 의견 확인을 사용하세요.

- 구체적인 제안을 작성하는 데 시간을 들이기 전에 초기 초안을 검토합니다.
- 공식적인 결정 전에 질문과 우려 사항을 파악합니다.
- 추가 토론이 필요한지 확인합니다.
- 아이디어를 수정하기 전과 후의 지지 정도를 비교합니다.

그룹이 명시적으로 합의한 경우에만 **좋아 보임**을 공식 승인으로 간주하세요. 응답을 통해 결정을 승인해야 하는 경우에는 [이의 없음](../consent/) 또는 [합의](../consensus/)를 사용하세요.

<!-- translation-section: example-check-a-trial-plan -->

## 예시: 시범 운영 계획 확인

오트밀크 협동조합은 회수용 병을 사용하는 시범 운영 계획의 초안을 작성했습니다. 수거 일정, 세척 점검, 보고 계획이 최종 검토를 받을 준비가 되었는지 알아보기 위해 의견 확인 투표를 진행합니다.

<!-- translation-section: set-up-the-proposal -->

## 제안 설정

아이디어가 어느 단계까지 진행되었는지, 피드백을 어떻게 활용할지 명시하세요. 각 응답의 기본 의미를 유지하거나 그룹에서 사용하는 표현에 맞게 수정하세요. 계획을 수정할 시간이 충분히 남도록 마감 시간을 설정하세요.

![](form.png)

<!-- translation-section: vote -->

## 투표하기

참여자는 현재 의견을 가장 잘 나타내는 응답을 선택하고, 어떤 부분이 준비되었으며 어떤 부분을 바꿔야 하는지 설명합니다. 유용한 이유는 제안 작성자가 구체적인 조치를 취하는 데 도움이 됩니다.

![](../proposal_sense_check_voting.png)

<!-- translation-section: read-the-results -->

## 결과 확인

차트에는 각 응답의 표 수와 비율이 표시됩니다. 표의 분포와 함께 이유도 읽어 보세요. 대부분의 참여자가 **좋아 보임**을 선택했더라도, 근거가 충분한 우려 사항이 하나라도 있다면 검토가 필요할 수 있습니다.

![](../proposal_sense_check_results.png)

<!-- translation-section: share-an-outcome -->

## 결론 공유

의견 확인 투표가 마감되면 결론을 공유하세요. 그룹이 수정할 내용을 요약하거나, 아이디어가 다음 의사결정 단계로 넘어갈 준비가 되었음을 기록하세요. 결론 기능에 대한 설명은 [결론 공유](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome)를 참고하세요.
