# Groupes

Un groupe Loomio est un espace partagé où les membres discutent, partagent des informations et prennent des décisions ensemble.

![La page du groupe Oatmilk Cooperative, avec sa description et sa liste de discussions](group_page.png)

Vous pouvez personnaliser la page de votre groupe avec un nom, une description, un logo, une image de couverture et des liens vers des documents tels que votre mandat. Cela aide les membres à comprendre l’objectif du groupe et comment y participer.

Pour commencer, [créez un groupe](/en/user_manual/groups/starting_a_group), choisissez ses [paramètres de confidentialité](/en/user_manual/groups/settings/privacy) et [invitez des personnes](/en/user_manual/groups/inviting_people).

Si vous préparez un nouveau groupe, consultez [Présenter Loomio à votre groupe](/en/user_manual/overview/introducing_loomio) pour suivre une démarche pratique, du choix du premier travail à réaliser jusqu’à la consignation d’une conclusion.

## Code de conduite

Un code de conduite aide les membres à comprendre comment participer et comment le groupe réagit aux comportements inappropriés. Consultez le [Guide d’animation](/en/guides/facilitators_guide/commencing#culture-protocol-expectations) pour savoir comment définir les attentes.
