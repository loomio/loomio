# Äänioikeutetut edustajat

Jos vain osalla ryhmäsi jäsenistä tulee olla äänioikeus, voit merkitä heidät **Tee valtuutettu** -toiminnolla. Voit myös perua valtuutuksen **Peruuta edustaja** -toiminnolla.

Käytä edustajia, kun kaikki osallistuvat samoihin keskusteluihin mutta vain tietty joukko, kuten johtokunta tai valitut edustajat, saa äänestää. Tämä on yleensä yksinkertaisempaa kuin erillisen alaryhmän ylläpitäminen vain äänestäjien erottamiseksi muista jäsenistä.

Käytä sen sijaan yksityistä alaryhmää, jos sen jäsenet tarvitsevat myös keskusteluja, tiedostoja tai jäsentietoja, joita muut jäsenet eivät saa nähdä.

![Tee valtuutettu -toiminto jäsenen valikossa](member_make_delegate.png)

Kun luot kyselyn tai ehdotuksen ja haluat kutsua vain edustajat, valitse kyselyn asetukseksi **Vain valitut henkilöt**.
![Vain valitut henkilöt -asetus ehdotusta aloitettaessa](poll_invited_people_only.png)
Kun kutsut ihmisiä äänestämään, näet vaihtoehdon **ryhmän nimen edustajat**.
![Oatmilk Cooperative -ryhmän edustajat -vaihtoehto äänestyskutsun lomakkeessa](poll_invite_delegates_group.png)

Näet edustajien luettelon ryhmäsi sivun jäsenet-välilehdellä. Avaa suodatinvalikko ja valitse **Edustajat**.
![Edustajat-vaihtoehto jäsenluettelon suodattimessa](members_list_delegates.png)
