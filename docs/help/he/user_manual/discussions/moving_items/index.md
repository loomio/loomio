# העברת פריטים בין שרשורים

ניתן להעביר תגובות או סקרים כאשר שיחה שייכת לשרשור אחר, כאשר דיון אחד מתפצל לנושאים נפרדים, או כדי לשלב שרשורים קשורים.

מנהלי קבוצה יכולים להעביר פריטים. גם חברים יכולים להעביר פריטים כאשר ההגדרה **חברים יכולים לנהל דיונים ותגובות** מופעלת ב[הרשאות הקבוצה](/en/user_manual/groups/settings/permissions).

1. יש לפתוח את תפריט שלוש הנקודות (**⋯**) של פריט ולבחור באפשרות **העבר פריט**.

![](../using_discussions/comment_move.png)

2. יש לסמן את הפריטים להעברה באמצעות תיבות הסימון, ואז לבחור באפשרות **העבר** בבאנר שבראש השרשור.

![](../using_discussions/comment_select.png)

![](../using_discussions/move_items.png)

3. לאחר בחירת קבוצת היעד או תת־קבוצת היעד, יש לחפש דיון קיים. כדי ליצור דיון חדש במקום זאת, יש לבחור באפשרות **דיון חדש**, להוסיף כותרת והקשר, ולבחור באפשרות **התחל דיון**.

![](../using_discussions/move_items_new_thread.png)

הפריטים שנבחרו מועברים מהשרשור המקורי לשרשור היעד.

![](../using_discussions/new_thread.png)

אם אין עוד צורך בשרשור המקורי, ניתן [לנעול אותו](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread). יש למחוק אותו רק אם ברור שלא יהיה בו צורך שוב.
