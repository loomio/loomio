# העברת פריטים בין שרשורים

ניתן להעביר פריטים נבחרים כאשר שיחה שייכת לשרשור אחר, כאשר שרשור אחד התפצל לנושאים נפרדים, או כדי לשלב דיונים קשורים. אין פקודה נפרדת בשם **מיזוג דיונים**.

האפשרות זמינה למנהלי קבוצה ולחברים כאשר ההגדרה **חברים יכולים לנהל דיונים ותגובות** מופעלת ב[הרשאות הקבוצה](/en/user_manual/groups/settings/permissions).

יש לפתוח את תפריט שלוש הנקודות (**⋯**) של פריט ולבחור באפשרות **העבר פריט**.

![](../using_discussions/comment_move.png)

יש לסמן את הפריטים להעברה.

![](../using_discussions/comment_select.png)

יש לסמן פריטים נוספים באמצעות תיבות הסימון, ואז ללחוץ על **העבר** בבאנר שבראש הדיון.

![](../using_discussions/move_items.png)

לאחר בחירת הקבוצה או תת־הקבוצה, יש לחפש את דיון היעד.

כדי להעביר את הפריטים לדיון חדש, יש לבחור באפשרות **דיון חדש** ולהוסיף את הכותרת וההקשר שלו.

![](../using_discussions/move_items_new_thread.png)

הפריטים מועברים מהשרשור המקורי לשרשור שנבחר או לשרשור החדש שנוצר.

![](../using_discussions/new_thread.png)

אם אין עוד צורך בשרשור המקורי, ניתן [לנעול אותו](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread). יש למחוק אותו רק אם ברור שלא יהיה בו צורך שוב.
