# הרשאות קבוצה

הלשונית **הרשאות** קובעת אילו פעולות בקבוצה זמינות לחברים רגילים, ובקבוצות שאינן סודיות גם למי שאינם חברים. בדף הקבוצה יש לפתוח את **ערוך הגדרות קבוצה** ולבחור **הרשאות**.

![הגדרות הרשאות קבוצה](group_group_settings_permissions.png)

למנהלי הקבוצה נשמרת האפשרות לנהל אותה. הפעלת הרשאה לחברים מאפשרת לחברים רגילים לבצע את הפעולה המסוימת, אך אינה הופכת אותם למנהלים.

ההרשאות קובעות אם חברים יכולים:

- להוסיף חברים או להזמין אורחים;
- לשלוח הודעות;
- ליצור תת־קבוצות;
- לפתוח דיונים ולנהל אותם;
- ליצור תגיות ולנהל אותן;
- לערוך או למחוק תגובות כשההגדרה מאפשרת זאת;
- לפתוח הצעות ומשאלים; וגם
- ליצור תבניות לדיונים ולמשאלים.

בקבוצות שאינן סודיות, מנהלי הקבוצה יכולים לאפשר בנפרד למי שאינם חברים לפתוח דיונים. מי שפותחים דיון בלי להיות חברים בקבוצה הופכים לאורחים באותו דיון, אך אינם מקבלים גישה לדיונים פרטיים אחרים ואינם הופכים לחברים בקבוצה.

ההגדרה **מנהלי מערכת יכולים לערוך תגובות של חברים** מעניקה למנהלי הקבוצה יכולת חריגה לערוך תוכן במסגרת ניהול הדיונים. יש להפעיל אותה רק אם הקבוצה הסכימה שמנהליה יוכלו לשנות תוכן שנכתב בידי חברים.

כדאי לבדוק מחדש את ההרשאות כשמטרת הקבוצה, הרכב החברים או האחריות לניהול הדיונים משתנים. יש להעניק לכל תפקיד רק את היכולות הנחוצות לו.
