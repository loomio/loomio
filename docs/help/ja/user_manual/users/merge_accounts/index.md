# アカウントを統合する

異なるメールアドレスを使う2つのLoomioアカウントを、引き続き使う1つのアカウントに統合できます。

始める前に、どちらのアカウントを残すか決めます。

- **残すアカウント**は、統合後にメールアドレスとプロファイルを使用するアカウントです
- **使用を終了するアカウント**は、最初にサインインするアカウントです。統合後は、そのメールアドレスでサインインできなくなります

両方のアカウントにサインインでき、残すアカウントのメールアドレスでメールを受信できる必要があります。

> [!WARNING]
> アカウントの統合は取り消せません。最終確認の前に、統合元と統合先のメールアドレスをよく確認してください。

<!-- translation-section: start-the-merge -->

## 統合を開始する

1. **使用を終了するアカウント**にサインインします。
2. サイドバーを開き、自分の名前を選択して、**プロファイル編集**を選択します。
3. **アカウントを統合する**を選択します。

![「アカウントを統合する」が強調表示されたプロファイルの操作メニュー](merge_accounts_profile.png)

4. 統合先のアカウントのメールアドレス（**残すアカウント**のメールアドレス）を入力し、**確認メールを送信する**を選択します。Loomioは常に同じ確認メッセージを表示し、サインアウトします。そのアドレスを使うアカウントがある場合は、そのアドレスに確認メールを送信します。

<!-- translation-section: verify-the-account-you-want-to-keep -->

## 残すアカウントを確認する

5. 残すアカウントのメールアドレスに届いた確認メールを開き、**メールを確認して次に進みます**を選択します。

![「メールを確認して次に進みます」ボタンが強調表示されたアカウント統合の確認メール](merge_accounts_email.png)

6. Loomioでサインインを求められた場合は、残すアカウントにサインインします。
7. **マージの確認**ページで、両方のメールアドレスをもう一度確認します。**アカウントを統合する**を選択して、統合を完了します。

![「アカウントを統合する」ボタンが強調表示された最終確認ページ](merge_accounts_confirm.png)

<!-- translation-section: what-happens-after-the-merge -->

## 統合後の状態

残したアカウントは、引き続きLoomioでの本人識別とサインインに使用されます。使用を終了したアカウントのグループへの所属と、ディスカッション、コメント、アンケート、投票などの活動は、残したアカウントに引き継がれます。両方のアカウントがすでに同じグループに所属している場合は、残したアカウントの既存の所属情報が維持されます。

使用を終了したアカウントは削除され、そのメールアドレスではサインインできなくなります。統合が完了すると、Loomioは残したアカウントのメールアドレスに完了を知らせるメールを送信します。
