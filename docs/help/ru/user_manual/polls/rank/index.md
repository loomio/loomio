# Ранжирование

Ранжирование определяет общий порядок предпочтений группы. Участники располагают варианты от наиболее до наименее предпочтительного, а Loomio начисляет больше баллов вариантам на более высоких позициях.

<!-- translation-section: when-to-use-rank -->

## Когда использовать Ранжирование

Используйте Ранжирование, когда порядок предпочтений имеет значение и вам нужен единый общий порядок. Оно подходит для:

- выбора одного кандидата на должность;
- упорядочивания проектов в плане работы;
- определения приоритетности тем конференции;
- выбора запасных вариантов наряду с основным; или
- сокращения длинного списка до упорядоченного короткого списка.

Ранжирование упорядочивает варианты по баллам. Это не метод пропорциональных выборов. Чтобы выбрать нескольких людей с представительством разных групп голосующих, используйте [выборы STV](/en/user_manual/polls/stv/).

<!-- translation-section: example-rank-bottle-designs -->

## Пример: ранжирование вариантов дизайна бутылок

Кооператив Oatmilk просит участников группы ранжировать четыре варианта дизайна бутылок для пробного использования возвратной тары. Участники учитывают удобство обращения, долговечность, потребности покупателей, условия хранения и совместимость с оборудованием для мытья.

<!-- translation-section: set-up-the-poll -->

## Настройте опрос

Укажите, что будет определено с помощью ранжирования, и добавьте варианты. Задайте **Количество вариантов выбора**, чтобы определить, сколько вариантов может ранжировать каждый человек. Первый вариант получает больше всего баллов, каждый следующий — на один балл меньше, а варианты, не включённые в ранжирование, не получают баллов.

![](form.png)

Сделайте ранжирование всех вариантов обязательным, если вам нужен полный порядок. Разрешите выбирать меньше вариантов, если участникам может не хватать информации для ранжирования всего списка. Показ вариантов в случайном порядке может уменьшить влияние их первоначального расположения.

<!-- translation-section: vote -->

## Голосуйте

Участники перетаскивают варианты в порядке своих предпочтений, ставя наиболее предпочтительный вариант под номером 1. Они могут добавить причину выбора, объясняющую критерии ранжирования.

![](voting.png)

В этом примере голосующий ставит **бутылку из янтарного стекла объёмом 500 мл** на первое место, а **бутылку из прозрачного стекла объёмом 500 мл** — на второе, поскольку обе подходят для существующих условий хранения в кафе и оборудования для мытья.

<!-- translation-section: read-the-results -->

## Изучите результаты

Результаты объединяют все бюллетени в общее ранжирование по баллам. Для каждого варианта показаны:

- **Ранжирование**: его позиция в общем результате;
- **% баллов**: его доля от всех баллов ранжирования;
- **Точки**: общее количество баллов из всех бюллетеней;
- **Иметь в виду**: среднее количество баллов на одного голосующего; и
- **Избиратели**: сколько людей включили его в ранжирование.

![](results.png)

В этом примере **бутылка из янтарного стекла объёмом 500 мл** занимает первое место, за ней следуют **бутылка из прозрачного стекла объёмом 500 мл** и **бутылка из янтарного стекла объёмом 750 мл**. Группа может сначала изучить наиболее предпочтительный дизайн, сохранив остальные варианты как последовательность альтернатив.

Результат по баллам может скрывать разные распределения предпочтений, дающие одинаковую сумму. Просмотрите отдельные бюллетени и причины выбора, если варианты набрали близкое количество баллов или решение имеет серьёзные последствия.

## Поделитесь выводом

Когда опрос закроется, поделитесь выводом. Укажите, какой вариант группа будет реализовывать и что произойдёт, если это не удастся. О том, как работают выводы, читайте в разделе [Поделитесь выводом](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome).
