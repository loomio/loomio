# スレッド間でアイテムを移動する

会話が別のスレッドに属する場合、1つのスレッドが複数の話題に分かれた場合、関連するディスカッションをまとめたい場合は、選択したアイテムを移動できます。独立した**ディスカッションを統合**コマンドはありません。

この機能はグループ管理者が利用できます。また、[グループの権限](/en/user_manual/groups/settings/permissions)で**メンバーはディスカッションやコメントを管理できる**が有効になっている場合は、メンバーも利用できます。

アイテムの三点メニュー（**⋯**）を開き、**アイテムの移動**を選択します。

![](../using_discussions/comment_move.png)

移動するアイテムを選択します。

![](../using_discussions/comment_select.png)

ほかにも移動するアイテムがあればチェックボックスで選択し、ディスカッションの上部に表示されるバナーの**動く**をクリックします。

![](../using_discussions/move_items.png)

グループまたはサブグループを選び、移動先のディスカッションを検索します。

新しいディスカッションにアイテムを移動するには、**新しい議論**を選択し、タイトルとコンテキストを入力します。

![](../using_discussions/move_items_new_thread.png)

アイテムが元のスレッドから、選択したスレッドまたは新しく作成したスレッドに移動します。

![](../using_discussions/new_thread.png)

元のスレッドが不要になった場合は、[ロックできます](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread)。今後も必要にならないと確信できる場合にのみ、削除してください。
