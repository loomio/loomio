# Шаблоны обсуждений

Шаблоны обсуждений помогают вашей группе каждый раз начинать обсуждения одинаковым способом. Шаблон может содержать заголовок, описание, теги и инструкции для человека, который начинает обсуждение. Он также задаёт настройки по умолчанию: например, уведомлять ли всю группу и какие опросы предлагать.

Каждое новое обсуждение в группе начинается с шаблона. Когда кто-то выбирает **Начать обсуждение**, Loomio показывает шаблоны группы. Даже **Пустой шаблон** — это шаблон, поэтому ваша группа может изменить и его настройки по умолчанию.

Шаблоны подходят для процессов, которые ваша группа повторяет: например, анализа проектов, сбора рекомендаций, подготовки встреч, принятия решений о финансировании или согласования документов. Автор может изменить всё перед началом обсуждения.

<!-- translation-section: how-templates-are-used -->

## Как используются шаблоны

1. Участник выбирает **Начать обсуждение** на странице группы.
2. Loomio показывает видимые шаблоны группы. У каждого есть название и подзаголовок.
3. Участник выбирает шаблон. Loomio открывает форму нового обсуждения, заполненную данными из шаблона.
4. Вверху формы появляются инструкции из шаблона.
5. Участник редактирует заголовок, описание, теги и список приглашённых, затем выбирает **Начать обсуждение**.

![](list.png)

Изменение шаблона влияет только на обсуждения, начатые после изменения. Обсуждения, уже начатые с этого шаблона, сохраняют своё содержимое и настройки.

<!-- translation-section: choose-who-is-notified-by-default -->

## Выберите, кто получает уведомления по умолчанию

Настройка **Приглашать** определяет, кого форма нового обсуждения приглашает по умолчанию. У неё два варианта:

- **Все в группе**: группа появляется в поле **Приглашать** формы обсуждения, и каждый участник получает уведомление, когда обсуждение начинается.
- **Никто**: поле **Приглашать** изначально пустое. Никто не получает уведомление, если автор не добавит людей.

Во встроенных шаблонах Loomio, включая **Пустой шаблон**, выбран вариант **Все в группе**. Если ваша группа не хочет уведомлять всех участников о каждом новом обсуждении, отредактируйте используемые шаблоны и выберите **Никто** в настройке **Приглашать**.

![](use.png)

Автор всегда может изменить список приглашённых перед началом обсуждения. Он может удалить группу из списка, чтобы никого не уведомлять, или добавить отдельных людей. Эта настройка влияет только на уведомления. Участники группы по-прежнему могут найти и прочитать обсуждение в группе независимо от выбранного вами варианта.

Группа добавляется в список приглашённых только тогда, когда автору разрешено уведомлять всю группу. Администраторы всегда могут это делать. Участники могут это делать, если в разрешениях группы включена настройка **Участники могут уведомлять всех в группе**.

## Настройки шаблона

Администраторы группы могут редактировать шаблон через меню действий рядом с ним в списке шаблонов. В форме есть следующие настройки:

![](form.png)

- **Название шаблона**: краткое название, которое отображается в списке шаблонов.
- **Шаблон подзаголовка**: одна строка, объясняющая, когда использовать шаблон.
- **Помощь с шаблонами**: инструкции, которые отображаются вверху формы нового обсуждения. Объясните в них процесс и добавьте ссылки на материалы. Эти инструкции не входят в содержимое обсуждения.
- **Группа**: определяет, начинается ли обсуждение в группе или как прямое обсуждение. Прямое обсуждение видно только приглашённым в него людям.
- **Заголовок по умолчанию**: заголовок, который подставляется в каждое новое обсуждение. Автор может его изменить.
- **Пример заголовка**: пример, который отображается в пустом поле заголовка. Используйте его, если заголовок по умолчанию подходит не для каждого обсуждения.
- **Теги**: теги, которые добавляются к каждому новому обсуждению. Автор может их удалить.
- **Описание**: начальный текст обсуждения. Используйте заголовки, вопросы или ссылки, чтобы помочь людям понять, что писать.
- **Приглашать**: определяет, приглашать ли всех в группе по умолчанию. См. [Выберите, кто получает уведомления по умолчанию](#choose-who-is-notified-by-default).
- **Шаблоны опросов**: опросы, предлагаемые для этого процесса. Они перечислены в форме нового обсуждения. Они также появляются первыми, когда кто-то начинает опрос в обсуждении. Автоматически они не запускаются.
- **Разрешить одновременное проведение опросов.**: определяет, может ли в обсуждении одновременно быть открыто несколько опросов.
- **Ограничение на длину комментария**: необязательное ограничение максимальной длины комментариев.

Используйте заголовок по умолчанию только тогда, когда он будет оставаться точным. В остальных случаях укажите пример заголовка, который подскажет автору, как назвать конкретный анализ, период, документ или решение.

## Пример: оценка пробного использования возвратных бутылок

Кооператив Oatmilk оценивает пробное использование возвратных бутылок после каждого цикла. Его шаблон называется «Оценка пробного использования бутылок» и содержит заголовок по умолчанию. Он добавляет тег «Пробное использование бутылок». В описании участникам предлагается прочитать еженедельный отчёт и рассмотреть долю возвращённых бутылок, записи о мойке, отзывы кафе и транспортные расходы. Шаблон рекомендует сначала провести проверку мнений, затем — опрос «Согласие».

Здесь удобно использовать шаблон, потому что цель и данные для оценки остаются одинаковыми в каждом цикле. Меняются только наблюдения и решения.

## Создайте шаблон

Администраторы группы могут выбрать **Новый шаблон** в списке шаблонов. Выберите пример из галереи Loomio или начните с пустого шаблона, затем адаптируйте его и сохраните.

Вы можете искать примеры в галерее или фильтровать их. Пример не добавляется в вашу группу, пока вы его не сохраните.

<!-- translation-section: manage-the-template-list -->

## Управляйте списком шаблонов

При создании группы Loomio добавляет набор шаблонов, подходящих для её типа. Сначала видны только **Пустой шаблон** и **Практическое обсуждение**. Остальные скрыты, и администраторы могут сделать их видимыми.

Через меню действий рядом с шаблоном администраторы группы могут:

- редактировать его содержимое и настройки;
- скрывать его из списка шаблонов;
- делать его видимым через **Скрытые шаблоны**;
- менять порядок видимых шаблонов;
- экспортировать его в файл JSON; или
- удалять его.

Скрытый шаблон сохраняется для дальнейшего использования. Удаление шаблона не удаляет обсуждения, начатые с его помощью.

<!-- translation-section: share-templates-between-groups -->

## Переносите шаблоны между группами

Выберите **Экспорт в формате JSON** в меню действий шаблона, чтобы скачать его в виде файла. Чтобы использовать его в другой группе, выберите **Новый шаблон**, затем **Импортировать json**. Откроется форма с импортированным содержимым, которое вы можете проверить перед сохранением.

Ссылки на пользовательские шаблоны опросов не включаются в файл. Экспортируйте и импортируйте эти шаблоны опросов отдельно.

<!-- translation-section: let-members-create-templates -->

## Разрешите участникам создавать шаблоны

По умолчанию только администраторы группы могут создавать и редактировать шаблоны. Администратор может включить настройку **Участники могут создавать шаблоны.** в разделе **Настройки группы** → **Разрешения**.

Когда эта настройка включена, участники могут создавать шаблоны обсуждений и опросов и редактировать созданные ими шаблоны. Администраторы могут редактировать любой шаблон в группе. Шаблон участника появляется в списке шаблонов группы сразу после сохранения, поэтому перед включением этого разрешения договоритесь о правилах именования и проверки шаблонов.

<!-- translation-section: templates-for-non-members -->

## Шаблоны для людей вне группы

Если включена настройка **Участники, не являющиеся членами организации, могут начать обсуждения.**, люди вне группы выбирают из того же списка шаблонов. Их форма обсуждения никогда не приглашает группу по умолчанию. См. [Сбор конфиденциальных обращений](/en/user_manual/discussions/private_submissions).
