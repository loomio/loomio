# Tareas

Usa tareas en hilos y comentarios para indicar una acción, asignársela a alguien, establecer una fecha de vencimiento y comprobar si está completada.

<!-- translation-section: add-a-task -->

## Añadir una tarea

Mientras escribes un hilo o comentario, despliega la barra de herramientas de formato y haz clic en **Lista de tareas**. Escribe la acción junto a la casilla de verificación.

![](tasklist1.png)

<!-- translation-section: name-and-assign-the-task-to-a-person -->

## Indicar la tarea y asignarla a una persona

Usa una @mención en la tarea para asignársela a un miembro del grupo. El botón **Añadir fecha de vencimiento** aparece cuando la tarea tiene una persona asignada.

![](tasklist2.png)

Las tareas que tienes asignadas aparecen en tu página de **Tareas**. Abre **Tareas** desde la barra lateral para verlas agrupadas por hilo o encuesta.

![](task_list.png)

<!-- translation-section: set-a-reminder -->

## Establecer un recordatorio

Haz clic en **Añadir fecha de vencimiento** para elegir una fecha de vencimiento y cuándo debe enviar Loomio un recordatorio por correo electrónico a la persona asignada. También puedes eliminar una fecha de vencimiento existente desde este cuadro de diálogo.

![](taskreminderform.png)

<!-- translation-section: mark-it-as-done -->

## Marcarla como completada

![](taskdone.png)

Haz clic en la casilla de verificación junto a una tarea para marcarla como completada. Puedes hacerlo mientras editas el texto, mientras lo lees si tienes asignada la tarea o desde la página de **Tareas**. Haz clic de nuevo para reabrir la tarea.
