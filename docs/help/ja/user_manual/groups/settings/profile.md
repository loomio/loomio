# グループのプロフィール

プロフィールタブでは、グループの名前や紹介内容を設定します。グループページから**グループ設定を編集する**を開き、**プロフィール**を選択します。

![グループのプロフィール設定](group_profile.png)

<!-- translation-section: name-and-handle -->

## 名前とハンドル

グループ名は簡潔にします。サブグループを設ける場合は、特に簡潔な名前が適しています。Loomioでは、`loomio.com/your-group-handle`や`your-group-handle@loomio.com`のように、グループのウェブアドレスとメールアドレスにハンドルを使用します。

ハンドルを変更すると、以前のハンドルを使ったリンクは新しいアドレスに転送され、以前のグループのメールアドレスに送信されたメールも引き続きグループに届きます。Loomioは以前のハンドルを最大3つ保持します。それ以降にハンドルを変更すると、最も古いハンドルが無効になります。

<!-- translation-section: description -->

## 説明

説明には、グループの目的、参加する人、想定する使い方を記載します。説明の書式を整えたり、リンク、文書、動画を含めたりできます。

グループの[プライバシー設定](/en/user_manual/groups/settings/privacy)によっては、名前と説明がメンバー以外にも表示される場合があります。

<!-- translation-section: cover-image-and-logo -->

## カバー画像とロゴ

カバー画像はグループページの上部に横長に表示されます。横長の画像が適しており、推奨サイズは2048 × 512ピクセルです。

グループのロゴは、ナビゲーションなどの限られた表示スペースでグループを識別するために使われます。それぞれの用途に合った形に切り抜けるよう、カバー画像とロゴは別々にアップロードします。
