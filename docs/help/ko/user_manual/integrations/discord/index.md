# Discord 연동

Loomio는 새 토론이나 투표가 시작되거나 댓글, 표, 결론이 등록되면 Discord 채널로 알림을 보낼 수 있습니다. 결정에 대해 다시 알리고 싶을 때는 채널에 직접 알림을 보낼 수도 있습니다.

---

1. Discord 서버를 열고 **서버 설정**으로 이동하세요.

   ![](server-settings.png)

2. **연동**을 선택하세요.

   ![](integrations.png)

3. **웹후크 추가**를 선택하고, `Loomio`와 같은 이름을 입력한 다음 채널을 선택하고 웹후크 URL을 복사하세요.

   ![](add-webhook.png)

웹후크 URL을 복사했으면 Loomio에서 연결을 완료하세요.

[Loomio에서 채팅 연동 설정](../chatbots/#set-up-a-chat-integration)
