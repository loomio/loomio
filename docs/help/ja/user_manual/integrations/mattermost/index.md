# Mattermost連携
_Loomioグループの通知をMattermostのチームチャットに送信します。_

Loomioでは、新しいディスカッション、提案、コメント、投票、結論が投稿されると、Mattermostのチャンネルに通知を送信できます。

---

ブラウザーでMattermostのチームを開き、連携の設定ページを開きます。
![](mm1.png)

「受信ウェブフック」をクリックします。
![](mm2.png)

次に「受信ウェブフックを追加」をクリックします。
![](mm3.png)

簡単な名前を入力し、通知を表示するチャンネルを選択して、「保存」をクリックします。
![](mm4.png)

次の手順で使うウェブフックURLをクリップボードにコピーします。
![](mm5.png)

ウェブフックURLがクリップボードにコピーされていることを確認し、以下のリンクを開きます。

[Loomioでチャット連携を設定する](../chatbots/#set-up-a-chat-integration)
