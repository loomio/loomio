# Envie um e-mail para iniciar uma discussão em seu grupo

Seu grupo no Loomio tem um endereço de e-mail. Você pode enviar ou encaminhar um e-mail para esse endereço para iniciar uma discussão no grupo.

Você encontra o endereço de e-mail do grupo na página do grupo:
![Localização do endereço de e-mail na página do grupo](email_email_button.png)

Quando você envia um e-mail para esse endereço, uma nova discussão é iniciada. O assunto do e-mail se torna o título da discussão, o corpo se torna a descrição e os arquivos anexados são adicionados à discussão.

O endereço no campo "De" do e-mail identifica o membro do grupo que será o autor da discussão.

<!-- translation-section: preventing-unauthorized-emails -->

## Como impedir e-mails não autorizados

Para impedir que pessoas de fora do grupo usem esse recurso, o Loomio exige que o endereço no campo "De" do e-mail corresponda ao de um membro do grupo.

Se você usa vários endereços de e-mail, pode adicionar um alias para que o Loomio reconheça seus outros endereços.

Se o endereço no campo "De" não corresponder ao de um membro do grupo, você receberá uma notificação para adicionar um alias ou rejeitar todos os futuros e-mails desse endereço.

Na primeira vez que você enviar um e-mail de um endereço não reconhecido, precisará adicionar um alias. Depois disso, os e-mails desse endereço serão aceitos imediatamente.
