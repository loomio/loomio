# Mattermost 연동
_Loomio 그룹 알림을 Mattermost 팀 채팅에 연결합니다._

Loomio는 새 토론, 제안, 댓글, 표, 결론이 등록되면 Mattermost 채널로 알림을 보낼 수 있습니다.

---

브라우저에서 Mattermost 팀을 여세요. 그런 다음 연동 설정 페이지를 여세요.
![](mm1.png)

"수신 웹훅"을 클릭하세요.
![](mm2.png)

그런 다음 "수신 웹훅 추가"를 클릭하세요.
![](mm3.png)

간단한 이름을 입력하고 알림을 표시할 채널을 선택한 다음 저장을 클릭하세요.
![](mm4.png)

웹훅 URL을 클립보드에 복사하세요. 다음 단계에서 필요합니다.
![](mm5.png)

웹훅 URL이 클립보드에 복사되어 있는지 확인하고 아래 링크를 따라가세요.

[Loomio에서 채팅 연동 설정](../chatbots/#set-up-a-chat-integration)
