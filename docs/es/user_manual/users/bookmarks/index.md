# Marcadores

Los marcadores son una lista personal de elementos de Loomio a los que quieres volver. Solo tú puedes ver tus marcadores. Al guardar un elemento, nadie más recibe una notificación.

Puedes guardar como marcadores:

- discusiones
- comentarios
- propuestas y sondeos
- votos
- conclusiones

<!-- translation-section: save-a-bookmark -->

## Guardar un marcador

Abre el menú de acciones del elemento y selecciona **Guardar marcador**. El menú suele aparecer como tres puntos. Para una discusión, usa el menú junto al título. Para un comentario, voto, propuesta, sondeo o conclusión, usa el menú del elemento correspondiente.

![](save_bookmark.png)

<!-- translation-section: view-your-bookmarks -->

## Ver tus marcadores

Abre la barra lateral y selecciona **Marcadores**. El número junto al enlace indica cuántos marcadores has guardado.

La página Marcadores muestra primero los elementos que guardaste más recientemente. Cada fila indica el tipo de elemento y quién lo creó. Selecciona una fila para volver al elemento guardado.

![](bookmarks_page.png)

<!-- translation-section: remove-a-bookmark -->

## Eliminar un marcador

En la página Marcadores, selecciona el botón para eliminar el marcador al final de una fila. También puedes abrir el menú de acciones del elemento y seleccionar **Eliminar marcador**.

Eliminar un marcador solo afecta a tu lista personal. Puedes volver a guardar el elemento más adelante.
