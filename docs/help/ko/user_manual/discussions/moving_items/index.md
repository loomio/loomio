# 스레드 간 항목 이동

대화를 다른 스레드에서 이어가야 하거나, 한 스레드에서 여러 주제로 나뉘었거나, 관련 토론을 합치려면 선택한 항목을 이동하세요. 별도의 **토론 병합** 명령은 없습니다.

그룹 관리자는 이 기능을 사용할 수 있습니다. 멤버도 [그룹 권한](/en/user_manual/groups/settings/permissions)에서 **멤버가 토론과 댓글을 관리할 수 있습니다** 설정이 활성화되어 있으면 사용할 수 있습니다.

항목의 점 세 개 메뉴(**⋯**)를 열고 **항목 이동**을 선택하세요.

![](../using_discussions/comment_move.png)

이동할 항목을 선택하세요.

![](../using_discussions/comment_select.png)

체크박스로 추가 항목을 선택한 다음, 토론 상단 배너에서 **이동**을 클릭하세요.

![](../using_discussions/move_items.png)

그룹 또는 하위 그룹을 선택한 다음, 항목을 옮길 토론을 검색하세요.

항목을 새 토론으로 옮기려면 **새 토론**을 선택하고 제목과 배경을 입력하세요.

![](../using_discussions/move_items_new_thread.png)

항목이 원래 스레드에서 선택한 스레드 또는 새로 만든 스레드로 이동합니다.

![](../using_discussions/new_thread.png)

원래 스레드가 더 이상 필요하지 않으면 [스레드를 잠글 수 있습니다](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread). 앞으로도 필요하지 않을 것이 확실한 경우에만 삭제하세요.
