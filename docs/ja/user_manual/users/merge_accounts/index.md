# アカウントを統合する

異なるメールアドレスで登録した2つのLoomioアカウントを統合し、1つのアカウントを使い続けることができます。

始める前に、どちらのアカウントを残すか決めてください。

- **残すアカウント**は、統合後もメールアドレスとプロフィールを使うアカウントです
- **廃止するアカウント**は、最初にログインするアカウントです。統合後、そのメールアドレスではログインできなくなります

両方のアカウントと、残すアカウントのメールアドレスを利用できる必要があります。

> [!WARNING]
> アカウントの統合は取り消せません。最後に確定する前に、統合元と統合先のメールアドレスをよく確認してください。

<!-- translation-section: start-the-merge -->

## 統合を始める

1. **廃止するアカウント**にログインします。
2. サイドバーを開き、自分の名前を選択して、**プロファイル編集**を選択します。
3. **アカウントを統合する**を選択します。

![アカウントを統合するが強調表示されたプロフィールの操作メニュー](merge_accounts_profile.png)

4. 統合先となる**残すアカウント**のメールアドレスを入力し、**確認メールを送信する**を選択します。Loomioには常に同じ確認メッセージが表示され、ログアウトします。そのアドレスを使うアカウントが存在する場合、Loomioはそのアドレスに確認メールを送信します。

<!-- translation-section: verify-the-account-you-want-to-keep -->

## 残すアカウントを確認する

5. 残すアカウントのメールアドレスに届いた確認メールを開き、**メールを確認して次に進みます**を選択します。

![メールを確認して次に進みますボタンが強調表示された統合確認メール](merge_accounts_email.png)

6. Loomioからログインを求められた場合は、残すアカウントでログインします。
7. **マージの確認**ページで、両方のメールアドレスをもう一度確認します。**アカウントを統合する**を選択すると、統合が完了します。

![アカウントを統合するボタンが強調表示された最終確認ページ](merge_accounts_confirm.png)

<!-- translation-section: what-happens-after-the-merge -->

## 統合後について

残すアカウントが、引き続きLoomioでの利用者情報とログイン用アカウントになります。廃止するアカウントのグループへの参加情報と、ディスカッション、コメント、投票、投票への回答などの活動は、残すアカウントに引き継がれます。両方のアカウントが同じグループに参加している場合は、残すアカウントの参加情報が維持されます。

廃止するアカウントは削除され、そのメールアドレスではログインできなくなります。統合が完了すると、Loomioは残したアカウントのメールアドレスに確認メールを送信します。
