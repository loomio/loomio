# Integración con Slack

Loomio puede enviar notificaciones a tus canales de Slack cuando se crean nuevas discusiones, encuestas, comentarios, votos y conclusiones.

---

1. Abre [api.slack.com](https://api.slack.com), inicia sesión y selecciona **Crear nueva aplicación**.

   ![](s1.png)

2. Dale un nombre a tu aplicación de Slack y elige tu espacio de trabajo.

   ![](s2.png)

3. Selecciona **Webhooks entrantes**.

   ![](s3.png)

4. Activa **Activar webhooks entrantes**.

   ![](s4.png)

5. Selecciona **Añadir nuevo webhook al espacio de trabajo**.

   ![](s5.png)

6. Elige el canal donde quieres que aparezcan las notificaciones de Loomio.

   ![](s6.png)

7. Copia la URL del webhook.

   ![](s7.png)

Ahora que tienes una URL de webhook, termina de conectarlo en Loomio:

[Configura una integración de chat en Loomio](../chatbots/#set-up-a-chat-integration)

_Slack no ha creado Loomio, no está afiliado a Loomio ni le presta soporte._
