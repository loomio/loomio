# 提案

提案では、文や行動方針について回答を求めます。参加者はあらかじめ定められた回答から選び、投票の理由を説明できます。フィードバックを集める、助言を求める、異議を把握する、賛同を確認するといった目的で提案を使います。

このセクションでは、Loomioの標準の提案テンプレートを選び、使う方法を説明します。ディスカッション、提案、修正案、結論という一連の流れについては、[意思決定ガイド](/en/guides/making_decisions/)を参照してください。グループで使えるテンプレートを変更するには、[アンケートテンプレート](../poll_templates/)を参照してください。

<!-- translation-section: choose-a-proposal-template -->

## 提案テンプレートを選ぶ

| テンプレート | 質問内容 | 使う場面 |
|---|---|---|
| [意向確認](sense_check/) | この方向で進めてよいですか？ | アイデアをまだ練っているとき |
| [助言](advice/) | 決定を行う人が考慮すべき助言は何ですか？ | 個人やチームが決定の責任を担うとき |
| [同意](consent/) | 安全に試せますか、それとも解決すべき異議がありますか？ | グループが同意による意思決定を行うとき |
| [コンセンサス](consensus/) | この提案に対してどのような立場ですか？ | グループ全体で合意を目指すとき |

![](proposal_templates_list.png)

確認したい質問に回答の選択肢が合うテンプレートを選んでください。各テンプレートのページでは、用途、設定、投票フォーム、結果について説明しています。

<!-- translation-section: other-proposal-templates -->

## その他の提案テンプレート

Loomioには、提案、賛同の度合い、多数決などのテンプレートもあります。一部は初期状態では非表示です。グループ管理者は、[アンケートテンプレート](../poll_templates/)からこれらを使えるようにしたり、グループ独自の用語やルールに合わせたテンプレートを作成したりできます。

<!-- translation-section: proposal-records -->

## 提案の記録

提案の受付中は投票と理由が更新され、参加者は回答を変更できます。締め切った後は、決定や次のステップを示す[結論](../outcomes/)を公開してください。ディスカッション、提案、投票、理由、結論が、グループがどのように決定に至ったかを示す記録になります。
