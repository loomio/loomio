# Прямі обговорення

Пряме обговорення — це приватне обговорення для визначеного кола людей.

Пряме обговорення не належить до групи. Запрошеним людям не потрібно бути учасниками вашої групи в Loomio.

Ви визначаєте, хто може бачити обговорення та брати в ньому участь, додаючи людей або адреси електронної пошти в поле **Запросити**.

У прямих обговореннях доступні ті самі коментарі, опитування та інші інструменти, що й в обговореннях групи. Вони стануть у пригоді, коли створювати підгрупу немає потреби.

![Форма прямого обговорення, у якій не вибрано групу, а в полі «Запросити» зазначено Саміру Патель](direct-discussion-example.png)

Виберіть **Прямі теми** на бічній панелі, щоб переглянути свої прямі обговорення. Щоб почати ще одне, виберіть **Нове обговорення** на цій сторінці.

![Пункт «Прямі теми» на бічній панелі та список прямих обговорень](direct-discussion-sidebar.png)

## Як зв’язатися з кимось через пряме обговорення
Пряме обговорення дає змогу приватно зв’язатися з однією або кількома людьми без створення підгрупи.
