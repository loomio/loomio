# 그룹 프로필

프로필 탭에서는 그룹을 식별하고 소개하는 정보를 설정합니다. 그룹 페이지에서 **그룹 설정 수정**을 연 다음 **프로필**을 선택하세요.

![그룹 프로필 설정](group_profile.png)

<!-- translation-section: name-and-handle -->

## 이름과 핸들

특히 하위 그룹을 만들 예정이라면 그룹 이름을 간결하게 정하세요. Loomio는 `loomio.com/your-group-handle`과 `your-group-handle@loomio.com`처럼 그룹의 웹 주소와 이메일 주소에 핸들을 사용합니다.

핸들을 변경하면 이전 핸들을 사용하는 링크는 새 주소로 연결되며, 이전 그룹 주소로 보낸 이메일도 계속 그룹에 전달됩니다. Loomio는 이전 핸들을 최대 3개까지 유지합니다. 그 이후에 핸들을 다시 변경하면 가장 오래된 핸들이 만료됩니다.

<!-- translation-section: description -->

## 설명

설명에는 그룹의 목적, 참여 대상, 이용 방법을 작성하세요. 설명에 서식을 적용하고 링크, 문서, 동영상을 포함할 수 있습니다.

그룹의 [공개 범위 설정](/en/user_manual/groups/settings/privacy)에 따라 멤버가 아닌 사람에게도 이름과 설명이 표시될 수 있습니다.

<!-- translation-section: cover-image-and-logo -->

## 커버 이미지와 로고

커버 이미지는 그룹 페이지 상단에 가로로 표시됩니다. 가로로 긴 이미지가 적합하며, 권장 크기는 2048 × 512픽셀입니다.

그룹 로고는 탐색 메뉴와 그 밖의 작은 표시 영역에서 그룹을 식별하는 데 사용됩니다. 각각 용도에 맞는 모양으로 자를 수 있도록 커버 이미지와 로고를 별도로 업로드하세요.
