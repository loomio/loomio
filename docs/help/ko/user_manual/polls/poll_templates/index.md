# 투표 템플릿

투표 템플릿은 **투표 시작** 또는 **새 투표**를 선택할 때 표시되는 재사용 가능한 기본 틀입니다. 템플릿은 투표 방식에 미리 정해 둔 안내, 응답 선택지, 설정을 결합한 것입니다.

이 페이지에서는 그룹에서 사용할 수 있는 템플릿을 설정하거나 그룹의 의사결정 절차에 맞는 템플릿을 만드는 방법을 안내합니다. 특정 투표에 사용할 템플릿을 선택하려면 [제안](../proposals/) 또는 [투표](../proposal_types/)를 참고하세요. 전체 의사결정 절차를 진행하려면 [의사결정하기](/en/guides/making_decisions/)를 참고하세요.

투표를 시작할 때 **제안** 또는 **투표** 탭을 선택하고 그룹에서 사용할 수 있는 템플릿 중 하나를 선택하세요.

템플릿에는 소개, 예시 내용, 선택지, 설정이 포함됩니다. 투표를 시작하기 전에 해당 결정에 맞게 검토하고 수정하세요. 새 투표를 수정해도 재사용 가능한 템플릿은 변경되지 않습니다.

## 투표 템플릿 만들기

<!-- translation-section: save-a-poll-as-a-template -->

### 템플릿으로 저장

기존 제안이나 투표를 재사용하려면 해당 항목의 작업 메뉴를 열고 **템플릿으로 저장**을 선택하세요.

![작업 메뉴가 열리고 템플릿으로 저장이 강조 표시된 제안](save_as_template.png)

투표 날짜, 투표자, 표, 결과, 투표의 결론은 템플릿에 저장되지 않습니다.

<!-- translation-section: start-a-new-template -->

### 새 템플릿 만들기

템플릿 목록을 열고 **새 템플릿**을 선택하세요. 예시 또는 빈 템플릿으로 시작한 다음, 사용할 그룹을 선택하세요.

![](proposal_template_setting.png)

<!-- translation-section: edit-a-default-template -->

### 기본 템플릿 편집

**이의 없음**과 같은 기본 템플릿을 그룹에 맞게 바꾸려면 해당 템플릿의 작업 메뉴를 열고 **템플릿 편집**을 선택하세요. 이 기능은 그룹 관리자가 사용할 수 있습니다. 저장하면 그룹의 사용자 지정 템플릿이 만들어지고, 템플릿 목록에서 기본 버전이 숨겨집니다.

![템플릿 편집 작업이 표시된 이의 없음 기본 템플릿](edit_default_template.png)

## 템플릿 설정

언제 사용하는 템플릿인지 알 수 있도록 이름과 부제목을 지정하세요. 다른 항목도 재사용에 더 적합하도록 수정할 수 있습니다. **템플릿 저장**을 선택하면 새 제안이나 투표를 시작할 때 해당 템플릿이 목록에 표시됩니다.

[![정책 변경을 위한 이의 없는 의사결정 절차 템플릿의 전체 양식](poll_template_new.png)](poll_template_new.png)

독립형 투표에서 **관리자만 첨부 파일을 추가할 수 있습니다**를 설정하면 응답과 답글을 포함하여 스레드 관리자와 그룹 관리자만 새 파일과 본문 내 이미지를 추가할 수 있습니다. 기존 스레드 안에서 시작한 투표에는 해당 스레드의 첨부 파일 설정이 적용됩니다. 템플릿을 변경하면 이후에 만드는 투표에만 적용됩니다.

<!-- translation-section: template-title-subtitle-and-help -->

### 템플릿 제목, 부제목, 도움말

제목과 부제목으로 언제 이 템플릿을 선택해야 하는지 설명하세요. **템플릿 도움말**에 절차 안내, 의사결정 규칙, 참고 자료 링크를 넣으세요.

<!-- translation-section: voting-method -->

### 투표 방식

참여자가 무엇을 표현해야 하는지, 결과를 어떻게 계산할지 선택하세요.

- **제안**: 정해진 입장 중 하나를 선택하여 제시된 내용에 응답합니다.
- **선택**: 하나 이상의 선택지를 선택합니다.
- **점수**: 모든 선택지를 척도에 따라 평가합니다.
- **배분**: 정해진 총점 안에서 점수를 나누어 배분합니다.
- **순위**: 선택지를 선호하는 순서대로 정렬합니다.
- **시간 투표**: 참여 가능한 시간을 표시합니다.
- **STV**: 여러 명을 비례 방식으로 선출하는 선거에서 후보자의 순위를 매깁니다.

투표 방식을 변경하면 템플릿에서 사용할 수 있는 항목과 결과 계산 방식이 달라집니다.

<!-- translation-section: example-title-details-and-tags -->

### 예시 제목, 상세 내용, 태그

투표마다 다른 내용이 필요하다면 예시 제목과 상세 내용에 작성 안내 문구를 사용하세요. 기본 분류 태그는 템플릿을 사용할 때마다 적용되는 경우에만 추가하세요.

<!-- translation-section: response-options -->

### 응답 선택지

제안과 선택 등의 방식에서는 응답 선택지를 설정할 수 있습니다. 선택지 옆의 연필 아이콘을 선택하여 다음 항목을 수정하세요.

- **선택지 이름**: 응답을 나타내는 짧은 이름입니다.
- **아이콘**: 선택지를 시각적으로 나타내는 표시입니다.
- **의미**: 해당 선택지를 선택했을 때 전달되는 의미입니다.
- **이유를 묻는 질문**: 참여자가 응답을 설명할 때 표시되는 질문입니다.

![](poll_type_edit_option.png)

참여자가 추측하지 않고도 각 선택지의 차이를 알 수 있도록 정의하세요. 선택지의 의미는 그룹에서 실제로 사용하는 의사결정 규칙과 일치해야 합니다.

<!-- translation-section: duration-and-settings -->

### 기간 및 설정

템플릿을 사용하는 대부분의 경우에 적합한 기본 기간을 설정하세요. 작성자는 개별 투표의 마감 시간을 변경할 수 있습니다.

그 밖의 기본 설정으로는 결과 공개 여부, 익명 투표, [가중 투표](../weighted_voting/), 투표 이유 작성 요건, 알림, 정족수, 투표 방식별 동작을 조정할 수 있습니다. 각 설정의 효과는 [제안 및 투표 설정](../settings/)을 참고하세요.

<!-- translation-section: manage-the-template-list -->

## 템플릿 관리

템플릿 옆의 작업 메뉴에서 다음 작업을 할 수 있습니다.

- **수정**: 재사용할 내용과 기본 설정을 수정합니다.
- **이동**: 목록의 다른 위치로 이동합니다.
- **숨기기**: 투표를 시작하는 사람에게 표시되지 않도록 숨깁니다.
- **삭제**: 더 이상 필요하지 않은 사용자 지정 템플릿을 삭제합니다.

![정책 변경을 위한 이의 없는 의사결정 절차의 작업 메뉴가 열린 그룹 템플릿 목록](template_manage.png)

숨겨진 템플릿을 검토하거나 복원하려면 **숨긴 템플릿 보기**를 선택하세요. 기본 템플릿은 숨기거나 그룹에 맞게 수정할 수 있지만 삭제할 수는 없습니다.

템플릿을 변경해도 해당 템플릿으로 이미 시작한 제안이나 투표는 변경되지 않습니다.

<!-- translation-section: who-can-manage-templates -->

### 템플릿을 관리할 수 있는 사람

그룹 관리자는 그룹의 모든 투표 템플릿을 만들고 관리할 수 있습니다. **그룹 설정** → **권한**에서 **멤버가 템플릿을 만들 수 있습니다**를 활성화할 수 있습니다. 이 설정을 활성화하면 멤버는 템플릿을 만들고 자신이 작성한 템플릿을 관리할 수 있습니다.
