# 結論を出す

![](cover.jpg)

<!-- translation-section: outcomes-next-steps -->

## 結論と次のステップ

協力して進めた議論の目標を達成できたと感じるには、結論を確認することが大切です。進行役が決まったことを整理して共有すると、グループは次の重要な問いに答えを持って活動を終えられます。

* 何をしましたか？
* それにはどんな意味がありますか？
* これから何が起こりますか？
* 自分にはどんな責任がありますか？
* この経験によって何が変わりますか？

答えが具体的な行動項目になることもあれば、共通理解が深まったという抽象的なものになることもあります。

Loomio では

* [結論](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome)は重要な機能です。提案が終了しても、それで完了とは限りません。最後に内容をまとめるために、結論の機能を使います。
* Loomio のディスカッションには、提案や結論を使わずに自然に終わるものも多くあります。そうしたディスカッションにも価値があります。後で参照できるように、コンテキスト欄に結論の要約を追記すると役立ちます。
* 特定の人に担当する作業がある場合は、その名前を @メンションすると通知が届きます。

## 記録と成果の整理

経験の意味を理解するには、より大きな流れの中でその経験がどこに位置づくかを考えます。これまでの進展の中で、今回はどんな節目だったのでしょうか。得られた理解を、物語、報告書、変化、行動の呼びかけのどの形にするのでしょうか。

経験はその場で起こりますが、後から名前を付け、使いやすく、参照しやすくすることで影響が広がります。そうしなければ、忘れてしまったり、その場にいなかった人に伝わらなかったり、同じことを繰り返す必要が生じたりします。文書や報告書として残すことは、協力して進める活動に役立ちます。

Loomio では

* Loomio では、活動の過程そのものが記録になります。追加の作業をしなくても、グループにとって貴重な記録が蓄積されます。
* 記録を整理して保存するために、検索機能、「過去の決定」一覧、ディスカッションの印刷機能を利用できます。
* プレミアムプランでは、グループの Loomio データをすべてエクスポートできます。
* 多くのグループは、さまざまな場で生まれた内容を Loomio にまとめています。たとえば、会議の案内を投稿して議題を作り、対面で会議を開いた後に議事録を投稿し、同じスレッドで関連する決定を行います。これにより、オンライン以外での活動も Loomio に記録できます。

## ディスカッションを行動につなげる

議論を終えたら、会議の場を離れて現実の課題に向き合う時が来ます。実行を考えず、考えや気持ちを共有することだけが必要な場合もあります。しかし通常、結論を実際の行動に移さなければ、グループは目標を達成できません。この移行も、進行役が支える活動の一部です。

この段階で、協力して進めてきた活動は組織内のほかの仕組みとつながります。進行役は、それらとどう連携するかを考える必要があります。たとえば、次のような仕組みです。

* **権限** — 実際に決定するのは誰ですか？アイデアを実現するには何が必要ですか？
* **運営** — ほかの優先事項とどう関係しますか？先に済ませる必要のあることはありますか？
* **役割分担** — 次のステップは誰が担当しますか？担当者は進捗を説明する責任を負いますか？
* **情報共有** — この活動やディスカッションをほかの人にどう伝えますか？何を知ってもらう必要がありますか？
* **事務作業** — タスク管理ツールや連絡ツールなど、別の仕組みに情報をどう移しますか？情報はどこに保存しますか？

こうした点に障害があるなら、結論を出す時まで気づかずにいると問題になります。たとえば、参加者に決定した変更を実行する権限がなければ、無力感が残ります。活動を始める段階で実行上の条件を見据え、協力する範囲を決めてください。

Loomio では

* 決定を受けて行動する人を @メンションできます。
* 多くの人は、定期的な対面会議で Loomio の決定を確認したり、結論をタスク管理の手順に取り入れたりして、Loomio の内容を組織内のほかの仕組みにつなげています。
* 明確に決定すると、「では、これをどう進めるか」という問いが自然に生まれます。
* Loomio でグループを作ると、「決定を行動に移すには誰の参加が必要か」といった重要な問いが明らかになることがあります。関係者、リーダー、管理者が欠けていると、先に進めなくなります。

## 最後まできちんと終える

活動をきちんと終えることは大切です。終わりを確認する機会がないと、参加者は区切りがつかないと感じることがあります。時間切れで終わる場合も、目標の達成によって終わる場合もあります。個々の参加者とグループ全体が、活動やその段階を終えたと感じられるかどうか、明示的な反応にも暗黙の反応にも目を向けてください。

参加者は、いつ終わるのかをリーダーや進行役に確認したいことがよくあります。終了を明確に伝えると役立ちます。終了を告げ、決定や次のステップを振り返り、あいさつをして締めくくる場合があります。終了時に一人ずつ感想を述べるなど、決まった方法を持つグループもあります。曖昧なまま終わらせないようにします。

Loomio では

* Loomio で終了を最も明確に示す方法は、決定の結論を公開することです。
* 一部のグループは、[スレッドをロックする](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread)機能を使い、その後の変更を防いで情報を整理しています。
* グループを無効化すると、活動は完全に終了します。その後は誰も投稿できません。
* Loomio のグループは活動が増減しても残しておけます。将来また活動する予定があっても、特定の段階が終わったことを確認すると役立ちます。
