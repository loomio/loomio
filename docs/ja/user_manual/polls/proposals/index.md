# 提案

提案は、ある考えや行動方針について意見を求めるものです。参加者は用意された選択肢から回答を選び、投票の理由を説明できます。フィードバックやアドバイスを集めたり、異議を確認したり、合意を確かめたりするときに使います。

このセクションでは、Loomioの標準の提案テンプレートの選び方と使い方を説明します。ディスカッションから提案、修正、結論までの一連の進め方は、[意思決定ガイド](/en/guides/making_decisions/)をご覧ください。グループで利用できるテンプレートを変更する方法は、[投票テンプレート](../poll_templates/)をご覧ください。

<!-- translation-section: choose-a-proposal-template -->

## 提案テンプレートを選ぶ

| テンプレート | 確認すること | 適した場面 |
|---|---|---|
| [センスチェック](sense_check/) | この方向で進めてよいですか？ | アイデアを検討している段階 |
| [アドバイス](advice/) | 意思決定者はどのような助言を考慮すべきですか？ | 個人またはチームが決定を担う場合 |
| [同意](consent/) | 試しても問題ありませんか？重要な異議はありますか？ | グループが同意による意思決定を行う場合 |
| [コンセンサス](consensus/) | この提案について、どのような立場ですか？ | グループ全体の合意を目指す場合 |

![](proposal_templates_list.png)

確認したいことに合った回答の選択肢を持つテンプレートを選びます。各テンプレートのページでは、適した場面、設定、投票フォーム、結果について説明しています。

<!-- translation-section: other-proposal-templates -->

## その他の提案テンプレート

Loomioには、提案、一致の勾配、質問ラウンド、過半数などのテンプレートもあります。最初は非表示になっているものもあります。グループ管理者は、[投票テンプレート](../poll_templates/)から利用可能にしたり、グループ独自の用語やルールに合わせたテンプレートを作成したりできます。

<!-- translation-section: proposal-records -->

## 提案の記録

提案が開かれている間、投票とその理由は随時更新され、参加者は回答を変更できます。終了後は、決定事項や次のステップを示す[結論](../outcomes/)を公開します。ディスカッション、提案、投票、理由、結論が、グループの意思決定の記録になります。
