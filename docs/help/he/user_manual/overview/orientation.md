# סיור קצר

עמוד זה מציג את החלקים העיקריים בממשק Loomio והיכן למצוא את הפעילות הרלוונטית.

<!-- translation-section: group-page -->

## עמוד הקבוצה

עמוד הבית של הקבוצה מציג את הקבוצה ומאפשר גישה לפעילות שלה.

![](group_example.png)

<!-- translation-section: tabs -->

### לשוניות

הלשוניות שמתחת לתיאור הקבוצה מספקות גישה אל:

**דיונים** - שרשורי הדיון של הקבוצה והפעילות האחרונה.

**סקרים** - רשימת הסקרים הפעילים בקבוצה.

**חברים** - האנשים השייכים לקבוצה.

**קבצים** - מסמכים וקבצים אחרים שצורפו ברחבי הקבוצה. הלשונית מרכזת קבצים שצורפו בהקשרים של דיונים, בתגובות, בהצעות ובסקרים, כך שניתן למצוא מסמך בלי לזכור היכן צורף.

לעזרה בחיפוש, במסננים, בתגיות, בסימניות ובדיונים שלא נקראו, ניתן לעיין ב[איתור תוכן](/en/user_manual/overview/finding-content).

<!-- translation-section: sidebar -->

## סרגל הצד

כדי לפתוח את סרגל הצד, יש להשתמש בכפתור התפריט (**☰**) שבפינה השמאלית העליונה.

![](sidebar.png)

בסרגל הצד ניתן לפתוח את לוח הבקרה, סקרים הממתינים להצבעה, דיונים שלא נקראו ודיונים ישירים, משימות וקבוצות. הוא כולל גם קישורים למדריך למשתמש ולתמיכה.

<!-- translation-section: user-settings -->

### הגדרות משתמש

יש לבחור בשם המופיע בסרגל הצד כדי לפתוח את תפריט המשתמש.

![](user_settings_sidebar.png)

תפריט זה משמש לעריכת הפרופיל, לשינוי הגדרות ההתראות, לבחירת ערכת נושא, לניהול הגדרות החשבון ולהתנתקות.

<!-- translation-section: notifications -->

## התראות

כפתור הפעמון שבפינה הימנית העליונה פותח את ההתראות בתוך היישום. כאשר יש התראות שטרם נצפו, מופיע סימון על הכפתור.

![](../users/email_settings/in_app_notifications.png)

למידע על התראות בתוך היישום, העדפות דוא״ל והגדרות התראות לקבוצות ולדיונים, ניתן לעיין בעמוד [התראות](/en/user_manual/users/email_settings).

<!-- translation-section: what-to-do-next -->

## מה לעשות בהמשך

- לקרוא את [איך להשתתף](/en/user_manual/overview/how-to-participate) כדי ללמוד כיצד לכתוב תגובות, להשיב, להביע תגובה באמצעות סמלים ולהצביע.
- לקרוא את [מציאת תוכן](/en/user_manual/overview/finding-content) כדי ללמוד כיצד לאתר דיונים והחלטות.
- לעיין בעמוד [דיונים](/en/user_manual/discussions) או [הצעות וסקרים](/en/user_manual/polls/intro_to_decisions) להנחיות מפורטות.
