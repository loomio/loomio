# שליחת דוא״ל לפתיחת שרשור בקבוצה

לקבוצה ב-Loomio יש כתובת דוא״ל. ניתן לשלוח או להעביר הודעת דוא״ל לכתובת זו כדי לפתוח שרשור בקבוצה.

ניתן לראות את כתובת הדוא״ל של הקבוצה בדף הקבוצה:
![מיקום כתובת הדוא״ל בדף הקבוצה](email_email_button.png)

שליחת הודעת דוא״ל לכתובת זו תפתח שרשור חדש. נושא ההודעה יהפוך לכותרת השרשור, גוף ההודעה יהפוך לתיאור, וכל הקבצים המצורפים יצורפו לשרשור.

כתובת הדוא״ל בשדה "מאת" משמשת לזיהוי חשבון החבר בקבוצה שאליו ישויך השרשור כמחבר.

## מניעת הודעות דוא״ל לא מורשות

כדי למנוע שימוש בתכונה זו בידי מי שאינם חברים בקבוצה, Loomio דורשת שהכתובת בשדה "מאת" של הודעת דוא״ל נכנסת תתאים לכתובת של אחד מחברי הקבוצה.

אם נעשה שימוש בכמה כתובות דוא״ל, ניתן להוסיף כתובת חלופית כדי ש-Loomio תזהה גם את הכתובות הנוספות.

כאשר הכתובת בשדה "מאת" אינה תואמת לכתובת של חבר בקבוצה, תישלח התראה עם בקשה להוסיף כתובת חלופית או לדחות את כל הודעות הדוא״ל העתידיות מכתובת זו.

לכן, בשליחה הראשונה מכתובת לא מזוהה, יש להוסיף אותה ככתובת חלופית. לאחר מכן, הודעות דוא״ל מכתובת זו יתקבלו מיד.
