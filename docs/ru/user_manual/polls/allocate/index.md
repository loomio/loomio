# Распределение баллов

Распределение баллов, также известное как точечное голосование, помогает определить приоритеты, когда приходится выбирать между вариантами. Каждый участник получает фиксированное количество баллов и распределяет их между вариантами. Чем больше баллов отдано одному варианту, тем меньше остаётся для других.

<!-- translation-section: when-to-use-allocate -->

## Когда использовать распределение баллов

Используйте распределение баллов, когда время, деньги, внимание или другой ресурс ограничены. Оно подходит, чтобы:

- определить приоритеты работы на следующий период планирования;
- распределить бюджет участия между проектами;
- решить, сколько времени в повестке выделить разным темам;
- распределить фиксированное количество часов волонтёрской работы; или
- выяснить, какие улучшения наиболее важны для участников.

Баллы показывают относительный приоритет, а не объём ресурса, который Loomio распределит автоматически. Используйте [Опрос по очкам](/en/user_manual/polls/score/), если каждый вариант может получить высокую оценку без снижения поддержки других вариантов.

<!-- translation-section: example-set-priorities-for-an-annual-strategy-review -->

## Пример: определение приоритетов для ежегодного пересмотра стратегии

Кооператив Oatmilk планирует ежегодный пересмотр стратегии. Он спрашивает участников, каким направлениям следует уделить больше всего времени и внимания. Каждый участник получает десять баллов для распределения между пятью направлениями. Так группа видит свои относительные приоритеты, а участникам приходится выбирать между ними.

<!-- translation-section: set-up-the-poll -->

## Настройка голосования

Опишите решение и объясните, что означают баллы. Добавьте сопоставимые по масштабу варианты, затем задайте значение **Баллы на человека**. В этом примере каждый голосующий получает десять баллов, чтобы показать, сколько времени следует уделить каждому направлению стратегии.

![](form.png)

Слишком большое количество баллов может создавать ложное впечатление точности. Обычно баллов должно хватать, чтобы показать различия, но их должно быть достаточно мало, чтобы приходилось выбирать. Уточните, допустимо ли отдать все баллы одному варианту.

<!-- translation-section: vote -->

## Голосование

Участники передвигают ползунки, чтобы распределить свои баллы. Loomio показывает, сколько баллов осталось, и не позволяет отправить ответ, пока баллы не распределены правильно.

![](voting.png)

В этом примере голосующий отдаёт по три балла вариантам **Участие членов** и **Финансовая устойчивость**, по два — вариантам **Влияние на окружающую среду** и **Развитие сотрудников**, а варианту **Продукты и услуги** не отдаёт ни одного балла. Ноль не обязательно означает, что направление не имеет ценности: голосующий распределил ограниченное число баллов между другими вариантами.

<!-- translation-section: read-the-results -->

## Просмотр результатов

В результатах варианты упорядочены по общему числу полученных баллов. Также показаны:

- **% баллов**: доля варианта среди всех распределённых баллов;
- **Точки**: общее число баллов, отданных варианту;
- **Иметь в виду**: среднее число баллов среди голосующих, отдавших баллы этому варианту; и
- **Избиратели**: число людей, отдавших варианту хотя бы один балл.

![](results.png)

В этом примере **Финансовая устойчивость** получает больше всего баллов, за ней следует **Развитие сотрудников**. Финансовой устойчивости отдал баллы каждый голосующий. Это указывает на широкое согласие с тем, что этому направлению нужно уделить значительное время при пересмотре стратегии. Сопоставьте общее число баллов с числом голосующих, чтобы отличить приоритеты многих участников от направлений, которые особенно важны меньшему числу людей.

Оцените общее число баллов вместе с числом голосующих и их доводами.

## Поделитесь заключением

Когда опрос закроется, поделитесь заключением. Опрос не распределяет время или деньги автоматически, поэтому объясните, как будет использован результат. О том, как работают заключения, читайте в разделе [Поделитесь заключением](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome).
