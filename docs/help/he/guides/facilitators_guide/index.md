# המדריך להנחיית קבוצות ב־Loomio

מדריך מעמיק ליישום מושגי יסוד בהנחיה במרחב המקוון.

Loomio פותח בידי אנשי ונשות הנחיה, והדבר השפיע במידה רבה על עיצובו. מדריך זה מציג את הרקע הזה ומסביר כיצד להעביר מושגים מתחום ההנחיה מהמרחב הלא מקוון למרחב המקוון.

## עוד על המדריך

בין אם השימוש ב־Loomio נעשה במסגרת הנחיה מקצועית, בהנחיה הדדית בין עמיתים או בקבוצה שאינה מכירה כלל את תחום ההנחיה, תפקידו המרכזי הוא לתווך בתקשורת הקבוצתית ולתמוך בה כדי להגיע למטרה הרצויה. במילים אחרות, הנחיה.

Loomio הוא *תוכנה לשיתוף פעולה קבוצתי*:

> תוכנה לשיתוף פעולה, או תוכנה לעבודה קבוצתית, נועדה לעזור לאנשים העוסקים במשימה משותפת להשיג את מטרותיהם. אחת ההגדרות המוקדמות של תוכנה לשיתוף פעולה היא ״תהליכים קבוצתיים מכוונים לצד תוכנה שתומכת בהם״. -- ויקיפדיה

יש ידע רב, שיטות עבודה מומלצות ומסורת הן בהנחיה פנים אל פנים והן בניהול שיח מקוון, אך האמנות והמדע של השילוב ביניהם רק מתחילים להתפתח. זהו התחום שבו Loomio שואף להצטיין.
