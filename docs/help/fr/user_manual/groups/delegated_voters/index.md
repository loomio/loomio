# Membres délégués au vote

Utilisez les délégués lorsque tous les membres d’un groupe doivent partager le même espace de discussion, mais que seuls certains membres, comme les membres du conseil d’administration ou les représentants élus, doivent pouvoir voter. C’est plus simple que de gérer un sous-groupe distinct dans le seul but de séparer les électeurs des personnes sans droit de vote.

Utilisez plutôt un sous-groupe privé lorsque ces membres ont également besoin de discussions, de fichiers ou d’une liste des membres auxquels les autres membres ne doivent pas avoir accès.

Seul un administrateur du groupe peut attribuer ou retirer le statut de délégué. Dans l’onglet **Membres** de la page de votre groupe, ouvrez le menu d’actions à côté du nom d’une personne et sélectionnez **Faire déléguer**. Sélectionnez **Révoquer le délégué** dans le même menu pour retirer cette désignation.

![Action Faire déléguer dans le menu d’un membre](member_make_delegate.png)

Pour créer un sondage ou une proposition où seuls les délégués peuvent voter, sélectionnez **Personnes sélectionnées uniquement** dans les paramètres du sondage.

![Paramètre Personnes sélectionnées uniquement lors de la création d’une proposition](poll_invited_people_only.png)

Lorsque vous choisissez les personnes à inviter à voter, sélectionnez **Délégués de [nom du groupe]**.

![Option Délégués de Oatmilk Cooperative dans le formulaire d’invitation à voter](poll_invite_delegates_group.png)

Pour consulter la liste de tous les délégués d’un groupe, ouvrez l’onglet **Membres** et sélectionnez **Délégués** dans le menu de filtrage.

![Option Délégués dans le filtre des membres](members_list_delegates.png)
