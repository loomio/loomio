# ダイレクトディスカッション

ダイレクトディスカッションは、特定の人だけが参加できる非公開のスレッドです。グループには属さず、招待された人は、いずれのLoomioグループにも属している必要はありません。

**招待する**欄に人やメールアドレスを追加して、閲覧や参加ができる人を指定します。

ダイレクトディスカッションでは、グループのディスカッションと同じコメント、アンケート、書式設定ツールを使えます。サブグループを作成する必要がない場合の、非公開の会話や下書きに適しています。

![グループが選択されておらず、招待する欄にSamira Patelが追加されているダイレクトディスカッションのフォーム](direct-discussion-example.png)

サイドバーで**ダイレクトスレッド**を選択すると、ダイレクトディスカッションとアンケートが表示されます。そこから**新しい**メニューを開き、**新しい議論**を選択するとダイレクトディスカッションを開始でき、**新しい投票**を選択するとグループに属さないアンケートを開始できます。

ダイレクトアンケートは、招待した人だけが閲覧できます。作成後、[投票者の管理](/en/user_manual/polls/manage_voters)から人やメールアドレスを指定して招待します。

![サイドバーのダイレクトスレッド項目とダイレクトディスカッションの一覧](direct-discussion-sidebar.png)

## ダイレクトディスカッションをグループに移動する

非公開の会話や下書きがグループで扱う話題に発展した場合は、後からグループやサブグループに移動できます。[スレッドの移動](/en/user_manual/discussions/using_discussions/#move-a-thread)を参照してください。
