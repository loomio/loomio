# クイックツアー

このページでは、Loomioの主な構成と、自分に関係する活動を確認できる場所を紹介します。

<!-- translation-section: group-page -->

## グループページ

グループのホームページにはグループの説明があり、グループの活動へのリンクが表示されます。

![](group_example.png)

<!-- translation-section: tabs -->

### セクション

グループの説明の下にあるナビゲーションカードには、次の内容が表示されます。

- **スレッド**: グループのディスカッションのスレッドと、最近の活動や未読の活動です。
- **アンケート**: グループ内の受付中および締め切り済みのアンケートです。投票待ちのアンケートも含まれます。
- **メンバー**: グループに所属する人々です。新しいメンバーを招待するショートカットもあります。
- **ファイル**: グループ全体のディスカッション、コメント、提案、アンケートに添付されたファイルです。共有された場所を覚えていなくても文書を見つけられます。
- **タスク**: グループ内の未完了および完了済みのタスクです。ステータス、期限、担当者、タグで絞り込めます。
- **ブックマーク**: グループ内でブックマークしたディスカッション、コメント、アンケート、投票、結論です。
- **設定**: グループの管理、メンバーシップの設定、通知設定、外部サービスとの連携、データのエクスポートです。

検索、フィルター、タグ、ブックマーク、未読のディスカッションについては、[コンテンツを探す](/en/user_manual/overview/finding-content)を参照してください。

<!-- translation-section: all-groups -->

## すべてのグループ

サイドバーで**すべてのグループ**を選択すると、所属するすべてのグループの活動を確認できます。グループページと同じナビゲーションカードがあり、**スレッド**（未読のスレッドやダイレクトスレッドを含みます）、**アンケート**、**ユーザー**（同じグループに所属する人を検索できる一覧で、最近オンラインだった人も確認できます）、**ファイル**、**タスク**、**ブックマーク**が表示されます。

![](all_groups.png)

<!-- translation-section: sidebar -->

## サイドバー

デスクトップでは左上、モバイルでは下部のナビゲーションバーにあるメニューボタン（**☰**）でサイドバーを開きます。

![](sidebar.png)

サイドバーでは、**すべてのグループ**、所属するグループやサブグループを切り替えたり、新しいグループやサブグループを作成したりできます。サイドバーが閉じているときは、ページ上部のグループ名（または**すべてのグループ**）を選択して、グループを切り替えたり、新しいグループを作成したりできます。サイドバーには、ユーザーマニュアルやサポートへのリンクもあります。

<!-- translation-section: user-settings -->

### ユーザー設定

サイドバーで自分の名前を選択すると、ユーザーメニューが開きます。

![](user_settings_sidebar.png)

このメニューでは、プロフィールの編集、通知設定の変更、テーマの選択、アカウントの管理、サインアウトができます。

<!-- translation-section: notifications -->

## 通知

デスクトップでは右上、モバイルでは下部のナビゲーションバーにあるベルアイコンを選択すると、アプリ内通知が開きます。未読の通知があると、バッジが表示されます。

![](../users/email_settings/in_app_notifications.png)

アプリ内通知、メールの受信設定、グループやディスカッションの通知設定については、[通知](/en/user_manual/users/email_settings)を参照してください。

<!-- translation-section: mobile-navigation -->

## モバイルのナビゲーション

モバイルでは、下部のナビゲーションバーからサイドバー、**すべてのグループ**、通知を開けます。ディスカッション内では、スレッドメニューから目次やスレッドの操作を開けます。
