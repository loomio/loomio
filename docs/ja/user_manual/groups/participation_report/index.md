# 参加状況レポート

グループの参加状況レポートでは、Loomioグループの利用状況を確認できます。

レポートに含めるグループ、集計期間の開始日と終了日、結果をまとめる単位（年、月、週、日）を選べます。

レポートはグループの全員が利用できます。ただし、各ユーザーに表示されるのは所属するグループの結果だけです。そのため、ユーザーによってレポートの内容が少し異なる場合があります。

下の図のように、グループ設定メニューの歯車アイコンからレポートを開けます。

![Oatmilk Cooperativeのメニューにある参加状況レポート](group_participation_report.png)

<!-- translation-section: what-s-in-the-report -->

## レポートの内容

<!-- translation-section: actions-per-month -->

### 月ごとのアクション

指定した期間に、グループでどのくらいの参加があったかを確認できます。

スレッド、コメント、投票、投票への回答、リアクションの月ごとの件数が表示されます。グラフで利用状況の増減を確認できます。

グラフの項目名をクリックすると、その項目を表示から外せます。

表の見出しをクリックすると、その列で並べ替えられます。

![Oatmilk Cooperativeの参加状況レポートの設定、合計、活動グラフ](group_participation_report_graph.png)

<!-- translation-section: tag-usage -->

### タグの使用状況

指定した期間に、各タグがどのくらい使われたかを確認できます。たとえば、特定の意思決定プロセスやテンプレートを使った決定の件数が分かります。

![Production、Cafe partnerships、Operationsのタグの使用状況の推移](group_participation_report_tags.png)

<!-- translation-section: actions-per-user -->

### ユーザーごとのアクション
グループ内で参加が多い人と少ない人を確認できます。

この表には、指定した期間に、選択したグループの各ユーザーが作成したスレッド、コメント、投票と、行った投票への回答やリアクションの件数が表示されます。表の見出しをクリックすると、その列で並べ替えられます。

**代表者限定**をオンにすると、選択したいずれかのグループで現在代表者になっている人だけが表示されます。活動と投票記録は選択したすべてのグループを通じて集計され、指定期間に活動がなかった代表者も表に残ります。CSVのダウンロードにも同じ絞り込みが適用されます。

![参加の程度が異なる3人の代表者のアクション](group_participation_report_actions_per_user.png)

<!-- translation-section: voting-record-per-user -->

### ユーザーごとの投票記録

各人に求められた投票の数と、実際に行った投票の数を比較できます。投票しなかった回数や、求められた投票をすべて行った人も確認できます。投票を求められたことがない人は、すべて投票した人として表示されません。匿名投票は、投票内容を投票者と結び付けないため、集計から除外されます。

**代表者限定**を使うと、現在の代表者の投票記録を確認できます。CSVのダウンロードにも、同じ名前と代表者の絞り込みが適用されます。

![代表者に求められた投票、行った投票、行わなかった投票の記録](group_participation_report_voting_record.png)

<!-- translation-section: users-per-country -->

### 国ごとのユーザー数

グループ内の全ユーザーについて、現在のIPアドレスに基づく国ごとの人数を確認できます。

![選択したグループの国ごとのユーザー数](group_participation_report_users_per_country.png)

<!-- translation-section: actions-per-country -->

### 国ごとのアクション

参加が多い国と少ない国を確認できます。

「ユーザーごとのアクション」と同様のデータを、検出されたユーザーの所在国ごとに集計します。

![国ごとに集計したアクション](group_participation_report_actions_per_country.png)
