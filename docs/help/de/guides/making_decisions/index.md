# Entscheidungen treffen

Diese Anleitungen erklären vollständige Entscheidungsprozesse: wie du eine Entscheidung klar umrissen vorbereitest, die richtigen Personen einbeziehst, Diskussionen und Vorschläge nutzt, auf Bedenken eingehst und ein Fazit festhältst.

Sie unterscheiden sich von den Seiten zu Vorschlagsvorlagen. Eine [Vorschlagsvorlage](/en/user_manual/polls/proposals/) erklärt einen einzelnen Vorschlag und seine Antwortoptionen. Ein Entscheidungsprozess kann im Laufe der Zeit mehrere Vorschläge nutzen.

<!-- translation-section: choose-a-process -->

## Wähle einen Prozess

| Prozess | Wer entscheidet? | Zentrale Frage |
|---|---|---|
| [Einfacher Entscheidungsprozess](simple_decision_process) | Von der Gruppe festgelegt | Wie können wir diskutieren, erproben und entscheiden? |
| [Beratungsprozess](advice_process) | Eine Person oder ein beauftragtes Team | Welche Ratschläge sollte die entscheidende Person berücksichtigen? |
| [Konsentverfahren](consent_process) | Die Gruppe | Kann der Vorschlag ohne begründeten Einwand sicher erprobt werden? |
| [Konsensverfahren](consensus_process) | Die Gruppe | Können wir eine gemeinsame Einigung erreichen? |

Nutze den Prozess, den die verbindlichen Regeln oder die Entscheidungsrichtlinie deiner Gruppe vorsehen. Für unterschiedliche Arten von Entscheidungen können unterschiedliche Prozesse gelten.

Wenn du nur Hilfe bei der Auswahl eines Antwortformats brauchst, vergleiche [Vorschläge](/en/user_manual/polls/proposals/) und [Abstimmungen](/en/user_manual/polls/proposal_types/). Wenn du die wiederverwendbaren Auswahlmöglichkeiten verwaltest, die angezeigt werden, sobald jemand **Jetzt abstimmen** auswählt, lies die Seite [Abstimmungsvorlagen](/en/user_manual/polls/poll_templates/).
