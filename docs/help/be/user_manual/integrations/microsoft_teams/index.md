# Інтэграцыя з Microsoft Teams
_Падключыце апавяшчэнні вашай групы Loomio да Microsoft Teams._

Loomio можа адпраўляць апавяшчэнні ў ваш Microsoft Teams, калі з’яўляюцца новыя абмеркаванні, прапановы, каментарыі, галасы і высновы.

---

Перайдзіце на [https://teams.microsoft.com](https://teams.microsoft.com), затым націсніце Apps
![](t1.png)

Увядзіце «webhook» у поле пошуку, затым націсніце Incoming Webhook
![](t2.png)

Націсніце «Add to a team»
![](t3.png)

Увядзіце назву і выберыце канал, у якім вы хочаце бачыць апавяшчэнні Loomio.
![](t4.png)

Задайце назву, напрыклад «Апавяшчэнні Loomio», затым націсніце «Create»
![](t5.png)

Скапіруйце атрыманы URL — на апошнім кроку вы ўставіце яго ў Loomio.
![](t6.png)

_Microsoft не стварала Loomio, не мае з ім арганізацыйнай сувязі і не аказвае яму падтрымкі._

Цяпер, калі ў вас ёсць URL вэбхука, працягніце наладжванне інтэграцыі з чатам:

[Наладзьце інтэграцыю з чатам у Loomio](../chatbots/#set-up-a-chat-integration)
