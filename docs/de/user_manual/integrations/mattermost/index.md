# Mattermost-Integration
_Benachrichtigungen deiner Loomio-Gruppe mit dem Team-Chat in Mattermost verbinden._

Loomio kann Benachrichtigungen an deine Mattermost-Kanäle senden, wenn neue Diskussionen, Vorschläge, Kommentare, Stimmen oder Fazits hinzukommen.

---

Öffne dein Mattermost-Team im Browser. Rufe dann die Einstellungen für Integrationen auf.
![](mm1.png)

Klicke auf „Incoming Webhooks“.
![](mm2.png)

Klicke dann auf „Add Incoming Webhook“.
![](mm3.png)

Gib dem Webhook einen einfachen Namen, wähle den Kanal für die Benachrichtigungen und klicke auf „Save“.
![](mm4.png)

Kopiere die Webhook-URL in die Zwischenablage. Du brauchst sie im nächsten Schritt.
![](mm5.png)

Stelle sicher, dass die Webhook-URL in deiner Zwischenablage ist, und öffne den folgenden Link.

[Chat-Integration in Loomio einrichten](../chatbots/#set-up-a-chat-integration)
