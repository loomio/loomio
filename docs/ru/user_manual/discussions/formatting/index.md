# Форматирование

Когда вы создаёте или редактируете обсуждение или опрос либо пишете комментарий, под текстовым полем появляется панель форматирования. Нажмите стрелку в конце панели, чтобы показать или скрыть все инструменты.

Наведите указатель на инструмент, чтобы увидеть его название.

![](thread_format_bar.png)

Используйте форматирование, чтобы выделить главное и сделать текст удобнее для просмотра.

<!-- translation-section: attach-file -->

## Прикрепить файл

Нажмите значок скрепки под текстовым полем, чтобы прикрепить файл с вашего компьютера.

![](format_attach.png)

<!-- translation-section: remove-attachments -->

### Удалить вложения

При редактировании описания нажмите **X** справа от имени файла, чтобы удалить его.

![](thread_file_remove.png)

<!-- translation-section: insert-image -->

## Вставить изображение

С помощью этого инструмента можно вставить изображение в текст.

![](format_insert_image.png)

Выберите файл изображения на компьютере. После загрузки изображение появится в редакторе.

![](format_insert_example.png)

Изображение будет показано в опубликованном обсуждении, опросе или комментарии.

>[!Tip]
>Вы также можете скопировать изображение и вставить его прямо в Loomio.

![](format_image_example.png)

<!-- translation-section: insert-link -->

## Вставить ссылку

Вы можете добавить ссылку на доступный другим документ или страницу в интернете.

Чтобы добавить ссылку:

1. Выделите текст, который станет ссылкой, например название документа.
2. Нажмите значок ссылки.
3. Вставьте адрес в поле **Вставить ссылку** и нажмите **Применять**.

Если документ размещён на другом сайте, проверьте настройки доступа: участники обсуждения должны иметь возможность открыть его.

Под текстовым полем появится предварительный просмотр документа. При желании его можно удалить.

Теперь открыть и прочитать документ смогут все, у кого есть доступ к вашему обсуждению в Loomio и разрешение на просмотр документа.

![](format_link.png)

## Заголовки

Заголовки уровней 1, 2 и 3 помогают структурировать обсуждение или комментарий.

Выделите текст, который хотите сделать заголовком, и выберите нужный уровень заголовка.

Если в комментарии есть заголовок, комментарий автоматически закрепится в ленте обсуждения.

![](format_heading.png)

![](format_bold.png)

Выберите выравнивание текста по левому краю, по центру или по правому краю.

![](thread_align.png)

<!-- translation-section: embed-videos-and-webpages -->

## Встраивание видео и веб-страниц

Встраивать поддерживаемые видео и веб-страницы можно везде, где есть панель форматирования.

Чтобы встроить видео или веб-страницу: 
1. Скопируйте адрес видео или веб-страницы.
2. Выберите **Встроенное видео**, вставьте адрес и нажмите **Применять**.

![](format_embed.png)

<iframe width="100%" height="380px" src="https://www.youtube-nocookie.com/embed/AJnjTd9u4zg" frameborder="0" allowfullscreen></iframe>

>[!Tip]
>Убедитесь, что видео доступно всем участникам обсуждения. Например, видео с доступом по ссылке подойдёт, если оно не должно появляться в результатах общедоступного поиска.

## Markdown

Чтобы перейти к редактированию Markdown, выберите **Редактировать уценку**.

Если в поле уже есть текст, при преобразовании часть форматирования может потеряться.

<!-- translation-section: rich-text -->

### Форматированный текст

Выберите **Редактировать форматированный текст**, чтобы вернуться к инструментам форматирования. Поддерживаемая разметка Markdown преобразуется в отображаемый текст.

**Предварительный просмотр** показывает, как Markdown будет выглядеть после публикации, без преобразования текста.
