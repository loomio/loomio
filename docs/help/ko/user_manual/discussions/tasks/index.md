# 할 일 배정 및 진행 상황 확인

스레드와 댓글에서 할 일을 사용하면 수행할 작업을 적고, 담당자를 배정하고, 마감일을 설정하고, 완료 여부를 확인할 수 있습니다.

<!-- translation-section: add-a-task -->

## 할 일 추가

스레드나 댓글을 작성할 때 서식 도구 모음을 펼치고 **할 일 목록**을 클릭하세요. 체크박스 옆에 수행할 작업을 입력하세요.

![](tasklist1.png)

<!-- translation-section: name-and-assign-the-task-to-a-person -->

## 할 일 작성 및 담당자 배정

할 일에 @멘션을 사용하여 그룹 멤버를 담당자로 배정하세요. 담당자가 배정되면 **마감일 추가** 버튼이 나타납니다.

![](tasklist2.png)

배정받은 할 일은 **할 일** 페이지에 표시됩니다. 사이드바에서 **할 일**을 열면 스레드 또는 투표별로 묶인 할 일을 확인할 수 있습니다.

![](task_list.png)

<!-- translation-section: set-a-reminder -->

## 알림 설정

**마감일 추가**를 클릭하여 마감일과 Loomio가 담당자에게 알림 이메일을 보낼 시점을 선택하세요. 이 대화 상자에서 기존 마감일을 삭제할 수도 있습니다.

![](taskreminderform.png)

<!-- translation-section: mark-it-as-done -->

## 완료로 표시

![](taskdone.png)

할 일 옆의 체크박스를 클릭하여 완료로 표시하세요. 텍스트를 편집할 때, 담당자로서 내용을 읽을 때 또는 **할 일** 페이지에서 완료로 표시할 수 있습니다. 체크박스를 다시 클릭하면 할 일을 다시 열 수 있습니다.
