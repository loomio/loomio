# קבלת החלטות

המדריכים האלה מסבירים תהליכי קבלת החלטות מלאים: כיצד להגדיר את ההחלטה, לערב את האנשים המתאימים, להשתמש בדיון ובהצעות, להתייחס לחששות ולתעד מסקנה.

הם שונים מהעמודים העוסקים בתבניות להצעות. [תבנית להצעה](/en/user_manual/polls/proposals/) מסבירה הצעה אחת ואת אפשרויות התגובה עליה. תהליך קבלת החלטות יכול לכלול כמה הצעות לאורך זמן.
