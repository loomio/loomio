# Взвешенное голосование

Взвешенное голосование позволяет одним голосам учитываться с большим весом, чем другим. У каждого голосующего есть вес голоса. Например:

- Жилищное сообщество предоставляет каждому объекту недвижимости один голос. Участник, представляющий три объекта, имеет вес голоса `3`.
- Правление кооператива принимает решение, а сотрудники участвуют в обсуждении. Члены правления имеют вес голоса `1`. Сотрудники имеют вес голоса `0`, поэтому их голоса сохраняются, но не влияют на результат.
- Компания предоставляет акционерам голоса в соответствии с их долей владения. Акционер, владеющий 12,5% акций, имеет вес голоса `12.5`.

## Установка веса голосов участников

Администратор группы может открыть страницу **Участники** группы и выбрать **Изменить вес голосов**. Введите веса голосов и выберите **Сохранить вес голосов**. Вес голоса может быть равен `0` или больше и содержать до трёх знаков после запятой. Чтобы найти человека, выполните поиск по имени или электронной почте. Чтобы установить одинаковый вес голоса для всех участников, выберите **Установить все веса голосов**.

![Вес голосов участников группы](member-weights.png)

Вес голоса участника копируется в каждый опрос, в который его добавляют. Последующее изменение этого веса не влияет на опросы, в которые он уже скопирован.

## Использование взвешенного голосования в опросе

Выберите **Используйте взвешенное голосование** в расширенных настройках опроса. Вы можете включить или выключить эту настройку после начала голосования. При выключении вес голоса каждого голосующего в опросе устанавливается в `1`, а все изменения веса голосов, сделанные для этого опроса, теряются.

Если ваша группа использует взвешенное голосование в рамках установленного процесса, выберите **Используйте взвешенное голосование** в [шаблоне опроса](/en/user_manual/polls/poll_templates). Опросы, созданные по этому шаблону, используют взвешенное голосование.

![Настройка «Используйте взвешенное голосование» в опросе](poll-setting.png)

Взвешенное голосование доступно для следующих типов опросов: [Предложение](/en/user_manual/polls/proposals), [Выбор](/en/user_manual/polls/choose), [Оценка](/en/user_manual/polls/score), [Распределение](/en/user_manual/polls/allocate) и [Ранжирование](/en/user_manual/polls/rank).

Вы не можете использовать взвешенное голосование и [анонимное голосование](/en/user_manual/polls/anonymous_voting) в одном опросе.

Чтобы изменить вес голоса одного голосующего, выберите **Управление избирателями**, затем выберите вес голоса рядом с его именем. Чтобы изменить вес голосов всех голосующих, выберите **Установить все веса голосов**. Вы можете скопировать вес голоса каждого участника из группы или установить одинаковое значение для всех. Голосующие, которые не являются участниками группы, получают вес голоса `1`.

![Кнопка «Управление избирателями» в опросе](poll-manage-voters.png)

![Голосующие в опросе с индивидуальными весами голосов](poll-voter-weights.png)

## Результаты

В результатах рядом отображаются обычные и взвешенные итоги:

- В опросах типов «Предложение» и «Выбор» отображаются **Голоса** и **Взвешенные голоса**.
- В опросах типов «Оценка», «Распределение» и «Ранжирование» отображаются **Точки** и **Взвешенные баллы**.

Диаграмма показывает взвешенный результат. Выберите заголовок столбца, чтобы вместо него отобразить на диаграмме данные этого столбца. Число людей, имеющих право голосовать, и кворум рассчитываются по количеству людей, а не по весам голосов. Любой, кто может видеть голоса, может видеть вес голоса каждого голосующего.

![Результат предложения с голосами и взвешенными голосами](weighted-proposal-result.png)
