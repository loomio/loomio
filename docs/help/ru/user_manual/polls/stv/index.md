# Выборы STV

**Единый передаваемый голос (STV)** — это способ голосования с пропорциональным представительством для избрания нескольких победителей из числа кандидатов. Он обеспечивает пропорциональное представительство разных взглядов голосующих среди избранных кандидатов.

<!-- translation-section: when-to-use-stv -->

## Когда использовать STV

Используйте выборы STV, когда вам нужно:

- Избрать **комитет, совет или состав делегатов** из числа выдвинутых кандидатов
- Обеспечить **пропорциональное представительство**, при котором меньшинства могут получить места пропорционально своей поддержке
- Провести выборы, на которых голосующие располагают кандидатов в порядке предпочтения

>[!NOTE]
>STV — это **не** то же самое, что [опрос «Ранжирование»](/en/user_manual/polls/rank/) в Loomio, где используется более простое ранжирование на основе оценок для выбора одного лучшего варианта. STV предназначен для выборов с несколькими победителями, передачей голосов и раундами выбывания кандидатов.

<!-- translation-section: creating-an-stv-election -->

## Создание выборов STV

При создании опроса выберите **Выборы STV** в качестве типа опроса, затем добавьте кандидатов как варианты опроса. Вы можете настроить опрос, указав **количество мест**, **способ подсчёта** и **тип квоты**.

В этом примере кооператив Oatmilk избирает трёх человек для контроля за испытанием возвратной упаковки. В форме описана их роль, перечислены пять кандидатов и выбран Scottish STV с квотой Droop.

![](form.png)

<!-- translation-section: number-of-seats -->

### Количество мест

Количество победителей, которых нужно избрать. Должно быть меньше количества кандидатов.

<!-- translation-section: counting-method -->

### Способ подсчёта

Доступны два способа подсчёта голосов:

Scottish STV
  : Рекомендуется. Взвешенный инклюзивный метод Грегори (WIGM), используемый на местных выборах в Шотландии с 2007 года. Чётко определённые, понятные правила. Подходит большинству организаций.
  
Meek STV
  : Более точный способ, при котором подсчёт возможен только на компьютере. После избрания кандидата Meek продолжает передавать ненужную ему часть каждого голоса следующим кандидатам в порядке предпочтения голосующего, включая голоса, поступившие к избранному кандидату позднее в ходе подсчёта. Когда кандидат выбывает, голоса пересчитываются так, как если бы он вообще не участвовал в выборах. Меньше голосов теряется, чем при Scottish STV, но проверить подсчёт вручную невозможно.

<!-- translation-section: quota-type -->

### Тип квоты

Квота — это минимальное количество голосов, необходимое кандидату для получения места. Можно выбрать один из двух типов:

Droop
  : Рекомендуется. Стандартная квота для выборов STV, используемая в Ирландии, Австралии и Шотландии. Это наименьшая квота, которую не могут достичь больше кандидатов, чем имеется мест. Голосующие, поставившие своих кандидатов на первые позиции, получают как минимум столько мест, сколько полных квот содержится в их общем числе голосов. Она рассчитывается так:
\\[ floor(\frac{votes}{(seats + 1)}) + 1 \\]

Hare
  : Более высокая квота. Голосующие с большим общим числом голосов расходуют больше голосов на каждое полученное место, поэтому у меньшинств больше шансов получить последние места. Она рассчитывается так:
    \\[ \frac{votes}{seats}\\]

В обеих формулах *votes* — это количество бюллетеней, в которых указан хотя бы один кандидат в порядке предпочтения.

Meek STV рассчитывает квоту без округления: для Droop это votes ÷ (seats + 1). В каждом раунде квота пересчитывается на основе голосов, которые всё ещё учитываются за кандидатами. Для избрания кандидат должен превысить квоту.
  
  >[!TIP]
  > Квота Droop всегда соответствует меньшему количеству голосов, чем квота Hare. Например, на выборах со 100 голосами и четырьмя местами квота Droop составит 21, а квота Hare — 25.

<!-- translation-section: how-voting-works -->

## Как проходит голосование

В этом примере кооператив Oatmilk избирает трёх человек для контроля за испытанием многоразовой упаковки. Голосующие перетаскивают кандидатов выше линии и располагают их в порядке предпочтения:

![](stv-vote-in-progress.png)

- **Позиция 1** = наиболее предпочтительный кандидат
- **Позиция 2** = второй по предпочтению кандидат
- Продолжайте располагать кандидатов в порядке предпочтения, включив столько кандидатов, сколько хотите

Голосующие должны указать хотя бы одного кандидата, но не обязаны включать всех кандидатов. Кандидаты, не включённые в список предпочтений, не получат никакой части голоса этого голосующего.

<!-- translation-section: how-counting-works -->

## Как происходит подсчёт
Подсчёт выполняется следующим образом:

1. Рассчитывается **квота** — минимальное количество голосов, необходимое для получения места.
2. Для каждого кандидата подсчитываются **Первые предпочтения**.
3. Каждый кандидат, достигший квоты, **избран**. Его избыточные голоса сверх квоты **передаются** следующим кандидатам в порядке предпочтения голосующих с дробным весом, начиная с наибольшего излишка. Голоса передаются только кандидатам, которые ещё участвуют в подсчёте.
4. Если излишков для передачи не осталось, **выбывает кандидат с наименьшим количеством голосов**. Его голоса передаются следующим кандидатам в порядке предпочтения голосующих с полным весом.
5. Когда количество оставшихся кандидатов равно количеству оставшихся мест, все они избраны, даже если не достигли квоты.
6. В остальных случаях подсчёт повторяется с шага 3, пока все места не будут заполнены.

Дробный вес позволяет распределить только ту часть голосов, которая не нужна победителю. Например, если квота равна 26, а у кандидата 40 голосов, его излишек равен 14. Каждый из его 40 бюллетеней передаётся следующему кандидату в порядке предпочтения с весом 14 ÷ 40 = 0.35 голоса.

В Scottish STV вес каждого передаваемого голоса округляется вниз до пяти знаков после запятой, как на выборах в местные советы Шотландии.

Если у двух или более кандидатов наименьшее количество голосов, выбывает тот, у кого было меньше голосов в последнем из предыдущих раундов, позволяющем различить их результаты.

>[!TIP]
>Бюллетень учитывается только до тех пор, пока в нём указан хотя бы один кандидат, который ещё участвует в подсчёте. Когда таких кандидатов не остаётся, бюллетень считается «исчерпанным» и больше не учитывается.

### Способ подсчёта и квота

Вверху вы увидите способ подсчёта (Scottish STV или Meek STV), тип квоты (Droop или Hare) и саму квоту — количество голосов, необходимое кандидату для получения места.

<!-- translation-section: elected-candidates -->

### Избранные кандидаты

Сводная таблица победителей с пятью столбцами:

| Столбец | Значение |
|--------|---------|
| **Кандидат** | Имя избранного кандидата |
| **Раунд избран** | Раунд подсчёта, в котором кандидат достиг квоты и получил место. Раунд 1 означает, что для избрания хватило только первых предпочтений; более поздние раунды означают, что потребовались голоса, переданные от выбывших кандидатов или излишков голосов других кандидатов. |
| **Первые предпочтения** | Количество голосующих, поставивших этого кандидата на первое место. Показывает прямую поддержку кандидата до передачи голосов. |
| **Итоговый результат** | Количество голосов кандидата на момент избрания. Благодаря передаче голосов оно часто превышает количество первых предпочтений. |
| **Излишек** | Насколько итоговый результат кандидата превысил квоту (итоговый результат минус квота). Больший излишек означает более высокую поддержку сверх необходимой для избрания. В Scottish STV этот излишек распределяется между следующими кандидатами в порядке предпочтения голосующих. |

Иногда результаты предыдущих раундов не позволяют разрешить равенство голосов. Если равенство не влияет на то, кто будет избран, подсчёт продолжается. Если влияет, подсчёт останавливается на этом раунде. Кандидаты, которые побеждают при любом разрешении равенства голосов, показаны как избранные. Кандидаты, которые могут победить или проиграть в зависимости от разрешения равенства, показаны в отдельной таблице. Loomio показывает, что у них равенство голосов, вместо того чтобы выбирать одного случайным образом.

### Подробности по каждому раунду

Разверните **Подробности по каждому раунду**, чтобы увидеть передачу голосов и выбывание кандидатов. Каждая строка соответствует кандидату, а каждый столбец — раунду подсчёта. Каждое число показывает количество голосов кандидата в начале этого раунда:

![](stv-results.png)

Зелёным цветом отмечено, когда кандидат был избран, красным — когда выбыл, а оранжевым — когда у него было равенство голосов с другими кандидатами.

## Экспорт бюллетеней

После закрытия выборов люди, которым доступны результаты, могут экспортировать бюллетени в формате BLT для независимого пересчёта или проверки. Экспорт содержит порядок предпочтения кандидатов и объединяет бюллетени с одинаковым порядком предпочтений в одну строку с указанием их количества. Для анонимных выборов экспорт не содержит сведений о личности голосующих, идентификаторов бюллетеней, времени или порядка их подачи.
