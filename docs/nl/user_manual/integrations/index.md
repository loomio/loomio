# Integraties

Verbind Loomio met andere tools die jouw groep gebruikt.

<!-- translation-section: choose-where-work-belongs -->

## Kies waar het werk thuishoort

Loomio vult chat, gedeelde documenten en tools voor taakbeheer aan. Je hoeft niet al het werk in Loomio te doen.

| Werk | Aanbevolen tool |
|---|---|
| Korte vragen, informele gesprekken en actuele updates | Chat |
| Samen een document bewerken dat steeds wordt bijgewerkt | Gedeeld document |
| Taken toewijzen en bijhouden | Tool voor project- of taakbeheer |
| Belangrijke discussies over een onderwerp, brede deelname, besluiten en conclusies | Loomio |

Gebruik Loomio wanneer mensen tijd nodig hebben om over een onderwerp na te denken, wanneer iedereen die erbij betrokken is de kans moet krijgen om mee te doen, of wanneer de groep de discussie en het besluit later moet kunnen terugvinden. Voeg in de Loomio-discussie een link toe naar het relevante document of de taak, zodat de context makkelijk te vinden blijft.
