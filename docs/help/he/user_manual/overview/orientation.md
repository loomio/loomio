# סיור קצר

עמוד זה מציג את החלקים העיקריים של Loomio והיכן למצוא את הפעילות הרלוונטית.

<!-- translation-section: group-page -->

## עמוד הקבוצה

עמוד הבית של הקבוצה מתאר את הקבוצה ומקשר לפעילות שלה.

![](group_example.png)

<!-- translation-section: tabs -->

### אזורים

כרטיסי הניווט שמתחת לתיאור הקבוצה מציגים:

- **שרשורים**: שרשורי הדיון של הקבוצה ופעילות אחרונה או פעילות שלא נקראה.
- **סקרים**: סקרים פתוחים וסגורים בקבוצה, כולל סקרים הממתינים להצבעה.
- **חברים**: האנשים השייכים לקבוצה, עם קיצור דרך להזמנת חברים חדשים.
- **קבצים**: קבצים שצורפו לדיונים, לתגובות, להצעות ולסקרים ברחבי הקבוצה, כך שניתן למצוא מסמך בלי לזכור היכן שותף.
- **משימות**: משימות פתוחות ומשימות שהושלמו בקבוצה, עם מסננים לפי מצב, תאריך יעד, אחראים ותגיות.
- **סימניות**: דיונים, תגובות, סקרים, הצבעות ומסקנות שנשמרו בסימניות בקבוצה.
- **הגדרות**: ניהול הקבוצה, אפשרויות חברות, הגדרות התראות, שילובים וייצוא נתונים.

לעזרה בחיפוש, במסננים, בתגיות, בסימניות ובדיונים שלא נקראו, ניתן לעיין ב[איתור תוכן](/en/user_manual/overview/finding-content).

<!-- translation-section: all-groups -->

## כל הקבוצות

כדי לראות את העבודה בכל הקבוצות שאליהן משויכים, יש לבחור ב**כל הקבוצות** בסרגל הצד. העמוד משתמש באותם כרטיסי ניווט כמו עמוד קבוצה: **שרשורים** (כולל שרשורים שלא נקראו ושרשורים ישירים), **סקרים**, **אנשים** (מדריך אנשים שניתן לחפש בו, הכולל אנשים החולקים קבוצות משותפות ומציג מי היו מחוברים לאחרונה), **קבצים**, **משימות** ו**סימניות**.

![](all_groups.png)

<!-- translation-section: sidebar -->

## סרגל הצד

כדי לפתוח את סרגל הצד, יש להשתמש בכפתור התפריט (**☰**) שבפינה השמאלית העליונה במחשב, או בסרגל הניווט התחתון בנייד.

![](sidebar.png)

בסרגל הצד ניתן לעבור בין **כל הקבוצות**, הקבוצות ותת־הקבוצות שאליהן משויכים, וליצור קבוצה או תת־קבוצה חדשה. כשסרגל הצד סגור, יש לבחור בשם הקבוצה (או ב**כל הקבוצות**) בראש העמוד כדי לעבור בין קבוצות או ליצור קבוצה חדשה. סרגל הצד כולל גם קישורים למדריך למשתמש ולתמיכה.

<!-- translation-section: user-settings -->

### הגדרות משתמש

יש לבחור בשם המופיע בסרגל הצד כדי לפתוח את תפריט המשתמש.

![](user_settings_sidebar.png)

מתפריט זה ניתן לערוך את הפרופיל, לשנות את הגדרות ההתראות, לבחור ערכת נושא, לנהל את החשבון ולהתנתק.

<!-- translation-section: notifications -->

## התראות

יש לבחור בסמל הפעמון שבפינה הימנית העליונה במחשב, או בסרגל הניווט התחתון בנייד, כדי לפתוח את ההתראות בתוך היישום. כאשר יש התראות שלא נקראו, מופיע סימון על הסמל.

![](../users/email_settings/in_app_notifications.png)

למידע על התראות בתוך היישום, העדפות דוא״ל והגדרות התראות לקבוצות ולדיונים, ניתן לעיין בעמוד [התראות](/en/user_manual/users/email_settings).

<!-- translation-section: mobile-navigation -->

## ניווט בנייד

בנייד, סרגל הניווט התחתון פותח את סרגל הצד, את **כל הקבוצות** ואת ההתראות. בתוך דיון, תפריט השרשור מאפשר גישה לתוכן השרשור ולפעולות בו.

<!-- translation-section: what-to-do-next -->

## מה לעשות בהמשך

- לקרוא את [איך להשתתף](/en/user_manual/overview/how-to-participate) כדי ללמוד כיצד לכתוב תגובות, להשיב, להביע תגובה באמצעות סמלים ולהצביע.
- לקרוא את [מציאת תוכן](/en/user_manual/overview/finding-content) כדי ללמוד כיצד לאתר דיונים והחלטות.
- לעיין בעמוד [דיונים](/en/user_manual/discussions) או [הצעות וסקרים](/en/user_manual/polls/intro_to_decisions) להנחיות מפורטות.
