# 그룹 권한

권한 탭에서는 일반 멤버가 사용할 수 있는 그룹 기능을 설정합니다. 숨김 그룹이 아닌 경우에는 멤버가 아닌 사람이 사용할 수 있는 기능도 설정합니다. 그룹 페이지에서 **그룹 설정 수정**을 연 다음 **권한**을 선택하세요.

![그룹 권한 설정](group_group_settings_permissions.png)

그룹 관리자는 그룹을 관리할 권한을 계속 유지합니다. 멤버 권한을 활성화하면 일반 멤버도 해당 작업을 할 수 있지만, 그룹 관리자가 되는 것은 아닙니다.

멤버에게 허용할 수 있는 작업은 다음과 같습니다.

- 멤버 추가 또는 게스트 초대
- 공지 발송
- 하위 그룹 생성
- 토론 시작 및 관리
- 태그 생성 및 관리
- 설정에서 허용하는 경우 댓글 수정 또는 삭제
- 제안 및 투표 시작
- 토론 및 투표 템플릿 생성

숨김 그룹이 아닌 경우 그룹 관리자는 멤버가 아닌 사람에게 토론 시작을 별도로 허용할 수 있습니다. 멤버가 아닌 사람이 토론을 시작하면 해당 토론의 게스트가 되지만, 다른 비공개 토론에 접근하거나 그룹 멤버가 되지는 않습니다.

**그룹 관리자가 멤버의 댓글을 수정할 수 있습니다** 설정은 그룹 관리자에게 예외적인 콘텐츠 관리 권한을 부여합니다. 그룹 관리자가 멤버가 작성한 콘텐츠를 수정할 수 있도록 그룹에서 합의한 경우에만 이 설정을 활성화하세요.

그룹의 목적, 멤버 구성 또는 콘텐츠 관리 책임이 바뀌면 권한을 검토하세요. 각 역할에는 필요한 권한만 부여하세요.
