# Інтэграцыя са Slack

Loomio можа адпраўляць апавяшчэнні ў вашы каналы Slack, калі з’яўляюцца новыя абмеркаванні, апытанні, каментарыі, галасы і высновы.

---

1. Адкрыйце [api.slack.com](https://api.slack.com), увайдзіце ў свой уліковы запіс і націсніце **Стварыць новую праграму**.

   ![](s1.png)

2. Дайце назву вашай праграме Slack і абярыце працоўную прастору.

   ![](s2.png)

3. Націсніце **Уваходныя вэбхукі**.

   ![](s3.png)

4. Уключыце **Актываваць уваходныя вэбхукі**.

   ![](s4.png)

5. Націсніце **Дадаць новы вэбхук у працоўную прастору**.

   ![](s5.png)

6. Абярыце канал, у якім вы хочаце атрымліваць апавяшчэнні Loomio.

   ![](s6.png)

7. Скапіруйце URL вэбхука.

   ![](s7.png)

Цяпер, калі ў вас ёсць URL вэбхука, завяршыце падключэнне ў Loomio:

[Наладзьце інтэграцыю з чатам у Loomio](../chatbots/#set-up-a-chat-integration)

_Loomio не створаны Slack, не звязаны са Slack і не падтрымліваецца Slack._
