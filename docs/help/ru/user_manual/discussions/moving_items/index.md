# Перемещение элементов между ветками

Перемещайте комментарии или опросы, если разговор относится к другой ветке, одно обсуждение разделилось на несколько тем или вы хотите объединить связанные ветки.

Администраторы группы могут перемещать элементы. Участники группы также могут перемещать элементы, если в [разрешениях группы](/en/user_manual/groups/settings/permissions) включена настройка **Участники могут управлять обсуждениями и комментариями.**

1. Откройте меню с тремя точками (**⋯**) у элемента и выберите **Переместить элемент**.

![](../using_discussions/comment_move.png)

2. Отметьте флажками элементы, которые хотите переместить, затем выберите **Переместить** на панели в верхней части ветки.

![](../using_discussions/comment_select.png)

![](../using_discussions/move_items.png)

3. Выберите группу или подгруппу назначения, затем найдите существующее обсуждение. Чтобы создать новое обсуждение, выберите **Новое обсуждение**, добавьте заголовок и описание, затем выберите **Начать обсуждение**.

![](../using_discussions/move_items_new_thread.png)

Выбранные элементы перемещаются из исходной ветки в ветку назначения.

![](../using_discussions/new_thread.png)

Если исходная ветка больше не нужна, вы можете [заблокировать её](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread). Удаляйте её только в том случае, если уверены, что она больше не понадобится.
