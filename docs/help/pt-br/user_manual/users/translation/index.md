# Idiomas e tradução

Altere o idioma da interface do Loomio ou traduza discussões, comentários e propostas para o seu idioma preferido.

<!-- translation-section: application-translation -->

## Tradução do aplicativo

O Loomio detecta o idioma preferido do seu navegador. Para escolher outro idioma, abra **Editar perfil** e selecione o idioma desejado.

![Alterando seu idioma preferido](change_language.png)

<!-- translation-section: content-translation -->

## Tradução de conteúdo

Quando alguém do seu grupo escreve uma mensagem em um idioma diferente do seu idioma preferido, um botão **Traduzir** aparece abaixo da mensagem. Selecione **Traduzir** para traduzir a mensagem para o seu idioma preferido.

![Ação de traduzir abaixo de um comentário](content_translation.png)

O texto traduzido substitui o texto original na discussão. Selecione **original** para mostrar o texto original novamente.

![Um comentário traduzido do espanhol para o inglês](content_translated.png)

O Loomio usa o Google Tradutor para traduzir o conteúdo quando você solicita.

<!-- translation-section: automatic-translation -->

## Tradução automática

Para traduzir discussões, comentários e propostas automaticamente, abra **Editar perfil** e ative **Traduzir conteúdo para o meu idioma automaticamente**. O Loomio traduz o conteúdo para o idioma selecionado no seu perfil.

![A preferência de tradução automática de conteúdo na página Editar perfil](automatic_translation.png)
