# Интеграции

Подключите Loomio к другим инструментам, которыми пользуется ваша группа.

<!-- translation-section: choose-where-work-belongs -->

## Выберите подходящий инструмент для работы

Loomio дополняет чаты, общие документы и инструменты управления задачами. У каждого из них своё назначение.

| Работа | Рекомендуемый инструмент |
|---|---|
| Короткие вопросы, неформальное общение и срочные новости | Чат |
| Совместная работа над документом, который постоянно обновляется | Общий документ |
| Распределение задач и отслеживание их выполнения | Инструмент управления проектами или задачами |
| Обсуждение важных тем, участие широкого круга людей, принятие решений и подведение итогов | Loomio |

Используйте Loomio, когда людям нужно время на обдумывание темы, когда всем, кого затронет решение, важно дать возможность участвовать или когда группе потребуется позже найти обсуждение и решение. Добавьте в обсуждение Loomio ссылку на соответствующий документ или задачу, чтобы участники могли легко найти материалы по теме.
