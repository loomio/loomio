Switching between rich text and Markdown now preserves basic tables, checked tasks, images, and @mention handles more reliably. Coloured text keeps its words when converted to Markdown, and videos, audio, and embedded content become links.

Edits made in Markdown are retained when switching back to rich text. The Markdown source editor and its preview remain available. Formatting that Markdown cannot represent, including task due dates and reminders, is still removed during conversion.
