# Ryhmän käyttöoikeudet

**Käyttöoikeudet**-välilehti määrittää, mitä jäsenet voivat tehdä ryhmässä ja mitä muut kuin jäsenet voivat tehdä ryhmissä, jotka eivät ole salaisia. Avaa ryhmän sivulla **asetukset**, valitse **Muokkaa ryhmän asetuksia** ja valitse sitten **Käyttöoikeudet**.

![Ryhmän käyttöoikeusasetukset](group_group_settings_permissions.png)

Ryhmän ylläpitäjillä säilyvät aina täydet hallintaoikeudet. Kun otat käyttöoikeuden käyttöön, jäsenet voivat tehdä kyseisen toiminnon ilman, että heistä tulee ryhmän ylläpitäjiä.

Käyttöoikeuksilla määritetään, voivatko jäsenet:

- lisätä jäseniä tai kutsua vieraita
- lähettää tiedotteita
- luoda alaryhmiä
- aloittaa ja hallita keskusteluja
- luoda ja hallita tunnisteita
- muokata tai poistaa kommentteja, kun asetus sallii sen
- aloittaa ehdotuksia ja kyselyjä
- luoda keskustelu- ja kyselymalleja

Ryhmissä, jotka eivät ole salaisia, ryhmän ylläpitäjät voivat myös sallia keskustelujen aloittamisen muille kuin jäsenille. Keskustelun aloittavasta henkilöstä tulee kyseisen ketjun vieras, mutta hänestä ei tule ryhmän jäsentä eikä hän saa pääsyä muihin yksityisiin keskusteluihin.

**Järjestelmänvalvojat voivat muokata jäsenten kommentteja** -asetus antaa ryhmän ylläpitäjille oikeuden muokata jäsenten kirjoittamaa sisältöä. Ota se käyttöön vain, jos ryhmäsi on sopinut, että ryhmän ylläpitäjät saavat muuttaa jäsenten kommentteja.

Tarkista käyttöoikeudet aina, kun ryhmäsi tarkoitus, jäsenistö tai moderointitarpeet muuttuvat, ja anna kullekin roolille vain sen tarvitsemat oikeudet.
