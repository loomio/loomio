Loomio 3.6.1 restores mention suggestions when editing comments and includes reliability fixes for ranked-choice polls, group imports, and Rails session compatibility. This release contains no database migrations or configuration changes.

- **Fix:** Display mention suggestions above the edit-comment dialog
- **Fix:** Keep ranked-choice minimum and maximum selections valid when poll options change
- **Fix:** Import topic item parents before their dependent records when restoring group exports
- **Fix:** Retain Rails-compatible JSON cookie decoding
- **New:** Include complete poll and reaction details in copied thread Markdown

## Comment mentions

A recent editor change rendered mention suggestions behind the edit-comment dialog. Matching people still loaded, but the person editing the comment could not see or select them. The suggestion list now renders above the dialog so mentions can be selected while editing.

## Polls, imports, and exports

If someone voted in a ranked-choice poll and new options were later added to the poll, they could receive an error when trying to save their updated vote. The number of ranking positions increased with the available options, but the maximum number of accepted choices could retain its previous value. Ranked-choice polls now update both limits together when the number of options changes, allowing voters to save the requested number of rankings.

Some group imports could fail when an export archive listed a reply or another nested timeline item before its parent. Imports now order topic items by their nesting depth so each parent is restored before its dependent records.

Copy Markdown now includes complete poll details, poll options, outcomes, votes, and comment reactions where the viewer has permission to see them. [PR #12841](https://github.com/loomio/loomio/pull/12841) includes an example of the expanded output.
