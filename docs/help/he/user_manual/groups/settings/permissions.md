# הרשאות קבוצה

הלשונית **הרשאות** קובעת מה חברים יכולים לעשות בקבוצה, ובקבוצות שאינן סודיות, גם מה יכולים לעשות מי שאינם חברי הקבוצה. בעמוד הקבוצה יש לפתוח את **הגדרות**, לבחור ב־**ערוך הגדרות קבוצה**, ואז לבחור ב־**הרשאות**.

![הגדרות הרשאות קבוצה](group_group_settings_permissions.png)

מנהלי הקבוצה שומרים תמיד על מלוא הרשאות הניהול. הפעלת הרשאה מאפשרת לחברים לבצע את הפעולה בלי להפוך אותם למנהלי קבוצה.

ההרשאות קובעות אם חברים יכולים:

- להוסיף חברים או להזמין אורחים
- לשלוח הודעות לכלל הקבוצה
- ליצור תת־קבוצות
- לפתוח ולנהל דיונים
- ליצור ולנהל תגיות
- לערוך או למחוק תגובות כאשר ההגדרה מאפשרת זאת
- לפתוח הצעות וסקרים
- ליצור תבניות לדיונים ולסקרים

בקבוצות שאינן סודיות, מנהלי הקבוצה יכולים גם לאפשר למי שאינם חברי הקבוצה לפתוח דיונים. פתיחת דיון בידי מי שאינם חברי הקבוצה מקנה להם מעמד של אורחים באותו שרשור, אך אינה מקנה להם חברות בקבוצה או גישה לדיונים פרטיים אחרים.

ההגדרה **מנהלי מערכת יכולים לערוך תגובות של חברים** מאפשרת למנהלי הקבוצה לערוך תוכן שכתבו חברים. יש להפעיל אותה רק אם הקבוצה הסכימה שלמנהלי הקבוצה צריכה להיות אפשרות לשנות תגובות של חברים.

יש לבדוק את ההרשאות בכל פעם שמטרת הקבוצה, הרכב החברים או הצרכים של ניהול התוכן משתנים, ולהעניק לכל תפקיד רק את ההרשאות הנחוצות לו.
