# Tags de categoria

As tags de categoria ajudam você a encontrar discussões, enquetes, conclusões e comentários sobre um determinado tipo de trabalho ou assunto.

As tags pertencem a toda a organização. Uma tag usada em um grupo principal é a mesma nos seus subgrupos, permitindo organizar trabalhos relacionados em toda a organização. O Loomio exibe os nomes das tags em ordem alfabética e mostra suas cores como pontos ao lado dos nomes.

Na página do seu grupo, clique em **Tags** acima da lista de conversas. Selecione uma tag para mostrar conversas que contenham pelo menos uma contribuição com essa tag. Use o campo de filtro para pesquisar em uma lista longa.

![](tags_view.png)

<!-- translation-section: apply-tags -->

## Aplicar tags

Você pode aplicar tags às suas próprias discussões, enquetes, conclusões e comentários. Admins de grupo, admins de conversa e pessoas com permissão para editar o contexto da discussão podem aplicar tags a qualquer contribuição em uma conversa desbloqueada. Em conversas diretas, todos os participantes podem aplicar tags a qualquer contribuição.

Ao iniciar uma conversa ou enquete, clique no campo **Tags** e selecione uma ou mais tags.

![](tags_add_new.png)

Comece a digitar para filtrar a lista. Selecione uma tag novamente ou clique no × dentro dela para removê-la.

<!-- translation-section: create-tags -->

## Criar tags

Admins do grupo principal sempre podem criar tags para o grupo principal e seus subgrupos. Admins de subgrupos podem criar tags ao aplicá-las ao conteúdo do seu subgrupo. A permissão do grupo **Os membros podem criar etiquetas.**, ativada por padrão, permite que outros membros que podem aplicar tags ao conteúdo criem novos nomes de tags. Se a permissão estiver desativada, os membros poderão usar as tags existentes da organização e os nomes de tags definidos por modelos no grupo de destino.

Para criar uma tag ao iniciar uma conversa ou enquete, digite seu nome no campo **Tags** e pressione Enter.

![criar nova tag](tags_create_new.png)

![nova tag criada](tags_created_new.png)

Use nomes curtos e conhecidos que os membros do grupo reconheçam, como Finanças, Governança, Embalagens ou Parcerias com cafeterias.

<!-- translation-section: template-tags -->

## Tags em modelos

Os modelos de discussão e enquete armazenam nomes de tags como padrões. Qualquer pessoa que possa criar ou editar um modelo pode alterar livremente seus nomes de tags. Salvar ou consultar um modelo não adiciona esses nomes à lista de tags da organização. Renomear ou deletar uma tag da organização não altera os padrões dos modelos.

Quando uma discussão ou enquete usa esses padrões, o Loomio aplica uma tag existente da organização ou a cria, se isso for permitido. Um membro sem permissão para criar tags ainda pode usar nomes definidos por modelos disponíveis no grupo de destino. Um modelo de outro grupo não concede permissão adicional para criar tags: seus padrões são mantidos somente se a organização de destino já tiver essas tags ou se um modelo no grupo de destino definir esses nomes. Outros nomes são descartados. Membros que podem criar tags podem manter todos os padrões do modelo.

## Editar tags

Somente admins do grupo principal podem renomear, alterar as cores, mesclar ou deletar tags. Essas alterações se aplicam a todos os usos dessas tags em toda a organização, incluindo seus subgrupos.

Na página do grupo, abra **Tags** e selecione **Editar tags**.

![editar tags de categoria](tags_edit_new.png)

Selecione o ícone de lápis ao lado de uma tag.

![editar tags de categoria](tags_edit_new_pencil.png)

Edite o nome da tag ou escolha uma cor e clique em **Salvar**.

![editar cor da tag](tags_edit_name.png)

Clique em **Deletar** para remover a tag de discussões, enquetes, conclusões e comentários em toda a organização.

![deletar tag](tags_delete.png)

### Editar tag em uma conversa ou enquete

Para alterar as tags de uma conversa ou enquete existente, abra a conversa ou enquete e clique no botão de tags ao lado das tags atuais, perto do título.

Selecione tags para adicioná-las ou removê-las. As alterações são salvas imediatamente.

O seletor mostra as tags usadas no grupo atual, as tags da organização que não estão em uso e as tags selecionadas para a contribuição. Quando houver outras tags usadas apenas em outros grupos, escolha **Mostre tags de outros grupos** para incluir tags do grupo principal e de seus subgrupos na mesma organização. Escolha **Mostrar etiquetas usadas neste grupo** para voltar à lista mais curta. Uma organização com apenas um grupo não tem a opção de ampliar a lista.

![editar tags na conversa](tags_thread_edit.png)

## Aplicar tags a contribuições

Abra o menu de ações de uma enquete, conclusão ou comentário e selecione **Aplicar tags**. O mesmo seletor usado ao lado do título da discussão permite adicionar ou remover tags. As alterações são salvas imediatamente. Quando uma contribuição tem tags, elas e o botão de tags aparecem à direita da linha com o autor, a data e a hora.

As tags se aplicam à contribuição que você seleciona. Não é possível aplicar tags a votos ou cédulas de votação.

<!-- translation-section: find-tagged-contributions -->

## Encontrar contribuições com tags

A seção **Tags** aparece na barra lateral da conversa quando uma contribuição além da discussão ou enquete inicial tem tags. Ela reúne as tags do item inicial e de todas as outras contribuições com tags. Selecione uma tag para mostrar as contribuições correspondentes com o contexto em que aparecem. Uma barra de ferramentas permanece visível acima da conversa enquanto o filtro está ativo. Feche-a com o botão × à direita, selecione a tag novamente ou escolha **Limpar** na barra lateral para voltar à visualização habitual da conversa. No celular, abra o painel de navegação da conversa para usar o mesmo filtro.

![Tags na barra lateral da conversa](tags_thread_sidebar.png)

## Pesquisar por tag

Abra **Pesquisar** na navegação superior e selecione seu grupo principal para exibir o menu de tags. Escolha uma tag para encontrar discussões, enquetes, conclusões e comentários com essa tag.

Deixe o campo de pesquisa vazio para navegar por tag ou digite uma palavra ou frase para pesquisar nas contribuições com essa tag. Selecione **Qualquer etiqueta** para limpar o filtro de tags.

![Seleção de uma tag na pesquisa global após escolher o grupo principal](tags_global_search.png)
