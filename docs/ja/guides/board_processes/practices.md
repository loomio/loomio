# ガバナンスの実践と進め方

適切なガバナンスには、取締役会の実効性を継続的に高めるため、運営方法や方針、手続きを定め、見直し、必要に応じて問い直すことが含まれます。

一方、多くの取締役会では時間が限られ、会議資料の確認や法令遵守、リスクへの対応に追われています。そのため、重要な戦略や業績について十分に議論できないことがあります。

<!-- translation-section: on-loomio -->

## Loomioでの進め方
Loomioでは、文書や方針、手続きをオンラインで共同作成できます。議論と決定はスレッドにまとまり、メンバーは都合のよい時間と場所から確認できます。

文書や方針、手続きごとに**スレッド**を作成します。スレッドには議論のほか、文書の草案や改訂版をまとめて保存できます。

文書の作成を担当する2～3人は、Loomioのスレッドで詳細を話し合えます。スレッドをその人たちだけに公開することも、グループ内で公開して、すべてのメンバーが作業の進み具合を確認できるようにすることもできます。

![](document_introduce.png#width-90)

文書の草案ができたら、**センスチェック**の投票を使って、レビューの準備ができたことをメンバーに知らせます。文書を読んで、コメントや質問を寄せてもらいます。作業の進み具合を共有できるほか、投票の締切日が参加のきっかけになります。

![](document_integrate.png#width-90)

文書の草案は、何度か修正が必要になる場合があります。

「最終」草案ができたら、文書の承認を求める**提案**を作成します。

![](document_approval.png#width-90)

Loomioを使えば、会議の貴重な時間を使わずに、会議と会議の間にガバナンス改善の作業を進められます。
