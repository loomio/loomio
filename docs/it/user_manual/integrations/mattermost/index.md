# Integrazione con Mattermost
_Collega le notifiche del tuo gruppo Loomio alla chat del tuo team su Mattermost._

Loomio può inviare notifiche ai tuoi canali Mattermost quando vengono create nuove discussioni e proposte, aggiunti commenti, espressi voti o condivise conclusioni.

---

Apri il tuo team Mattermost nel browser. Poi apri la pagina delle impostazioni delle integrazioni.
![](mm1.png)

Seleziona "Incoming Webhooks"
![](mm2.png)

Poi seleziona "Add Incoming Webhook"
![](mm3.png)

Assegna un nome semplice, seleziona il canale in cui mostrare le notifiche e seleziona Save
![](mm4.png)

Copia l'URL del webhook negli appunti. Ti servirà nel passaggio successivo.
![](mm5.png)

Assicurati di aver copiato l'URL del webhook negli appunti e segui il link qui sotto.

[Configura un'integrazione con una chat in Loomio](../chatbots/#set-up-a-chat-integration)
