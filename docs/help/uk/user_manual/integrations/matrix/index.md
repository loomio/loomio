# Інтеграція з Matrix

Loomio може надсилати сповіщення до кімнати Matrix, коли з’являються нові обговорення, опитування, коментарі, голоси та висновки. Щоб додати інтеграцію з чатом, ви маєте бути адміністратором групи.

На відміну від інших інтеграцій Loomio з чатами, Matrix не використовує вебхук. Натомість Loomio підключається через обліковий запис користувача Matrix, який діє як бот і публікує форматовані повідомлення у вашій кімнаті.

У цьому посібнику використовується клієнт Element.

---

1. Створіть обліковий запис користувача Matrix для Loomio, увійдіть у нього в Element і запросіть цей обліковий запис до кімнати Matrix, де ви хочете отримувати сповіщення. Залишайтеся в цьому сеансі — вихід робить маркер доступу недійсним.

2. У вашій групі Loomio відкрийте **Налаштування**, виберіть **Інтеграції чату** та додайте інтеграцію з чатом **Матриця**.

   ![меню додавання бота Matrix у Loomio](loomio-add-matrix-bot.png)

   ![форма налаштування бота Matrix у Loomio](loomio-matrix-bot-form.png)

3. В Element відкрийте меню облікового запису бота й виберіть **Усі налаштування**.

   ![меню налаштувань Matrix](matrix-settings-menu.png)

4. Відкрийте **Довідка та про програму** й прокрутіть до розділу **Додатково**.

   ![налаштування Matrix](matrix-settings.png)

5. Скопіюйте **Маркер доступу** та вставте його у форму Loomio.

   ![маркер доступу Matrix](matrix-access-token.png)

6. Відкрийте меню **Налаштування** кімнати й перейдіть до розділу **Додатково**.

   ![налаштування кімнати Matrix](matrix-room-settings.png)

7. Скопіюйте **Внутрішній ідентифікатор кімнати**, вставте його у форму Loomio та збережіть інтеграцію.

   ![ідентифікатор кімнати Matrix](matrix-room-id.png)
