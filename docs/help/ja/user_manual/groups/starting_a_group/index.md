# 新しいグループを始める

Loomioを初めて利用する場合は、[Loomioのウェブサイト](https://www.loomio.com/)から無料トライアルでグループを始められます。無料トライアル中に3人が提案またはアンケートに投票すると、トライアル期間が30日間延長され、サブグループとゲストの機能も利用できるようになります。すでにLoomioを利用していて、別のグループを始めたい場合は、サイドバーの**新しいグループ**を選択します。サイドバーが閉じている場合は、ページ上部のグループ切り替えメニューから選択します。

ほとんどの組織では、親グループは1つで十分です。その中に必要な数だけ[サブグループ](/en/user_manual/groups/subgroups)を作成できます。

### グループ名

グループの短くわかりやすい名前を入力します。

<!-- translation-section: group-handle -->

### グループのハンドル

Loomioはグループ名に基づいてハンドルを自動的に割り当てます。ハンドルは、`loomio.com/your-group-handle`や`your-group-handle@loomio.com`のように、グループのURLやメールアドレスに使用されます。

ハンドルは初期設定時に編集でき、後からグループ設定で変更することもできます。変更後も、以前のハンドルを使用したリンクやメールアドレスは引き続き利用できます。Loomioは以前のハンドルを最大3つ保持します。それを超えると、最も古いハンドルが失効します。

<!-- translation-section: group-description -->

### グループの説明

グループページの上部に表示する短い説明を追加し、新しいメンバーに背景情報を伝えます。

[プライバシー設定](/en/user_manual/groups/settings/privacy)を選び、**開始グループ**を選択してグループを作成します。作成者は自動的に最初のグループ管理者になり、これらの情報は後からグループ設定で更新できます。
