# 의사결정

이 가이드는 결정할 사안을 정리하고, 적절한 사람들을 참여시키고, 토론과 제안을 활용하고, 우려에 대응하고, 결론을 기록하는 전체 의사결정 과정을 설명합니다.

이 가이드는 제안 템플릿 페이지와 다릅니다. [제안 템플릿](/en/user_manual/polls/proposals/)은 하나의 제안과 그 응답 선택지를 설명합니다. 의사결정 과정에서는 시간에 따라 여러 제안을 사용할 수 있습니다.

<!-- translation-section: choose-a-process -->

## 과정 선택

| 과정 | 누가 결정하나요? | 핵심 질문 |
|---|---|---|
| [간단한 의사결정 과정](simple_decision_process) | 그룹에서 정합니다 | 어떻게 토론하고, 시험하고, 결정할 수 있나요? |
| [조언 과정](advice_process) | 개인 또는 권한을 위임받은 팀 | 결정권자는 어떤 조언을 고려해야 하나요? |
| [이의 없는 의사결정 과정](consent_process) | 그룹 | 중대한 이의 없이 제안을 안전하게 시도할 수 있나요? |
| [합의 과정](consensus_process) | 그룹 | 함께 합의에 도달할 수 있나요? |

그룹의 운영 규칙이나 의사결정 정책에서 요구하는 과정을 사용하세요. 결정의 종류에 따라 서로 다른 과정을 사용할 수 있습니다.

응답 형식을 선택하는 데만 도움이 필요하다면 [제안](/en/user_manual/polls/proposals/)과 [투표](/en/user_manual/polls/proposal_types/)를 비교하세요. **투표 시작**을 선택할 때 표시되는 재사용 가능한 선택 항목을 관리한다면 [투표 템플릿](/en/user_manual/polls/poll_templates/)을 참고하세요.
