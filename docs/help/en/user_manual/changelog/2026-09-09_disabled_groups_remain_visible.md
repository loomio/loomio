# Disabled groups remain visible

Groups with an inactive subscription remain visible to their members. Members can read the group's existing discussions and polls, and a warning explains that the subscription must be restored before activity can continue.

Starting or editing discussions, commenting, reacting, voting, managing members, and other group activity are blocked while the group is disabled. Coordinators can still manage the subscription, export group data, remove access, or delete the group. Server administrators can move or merge disabled groups.
