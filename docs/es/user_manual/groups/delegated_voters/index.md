# Votantes delegados

Si algunas personas de tu grupo deben tener derecho a voto y otras no, puedes usar **Hacer delegado** para identificar a quienes pueden votar. También puedes usar **Revocar delegado** para retirar ese derecho.

Usa delegados cuando todas las personas deban compartir el mismo espacio de discusión, pero solo un grupo definido, como la junta directiva o los representantes electos, pueda votar. Suele ser más sencillo que mantener un segundo subgrupo solo para separar a quienes pueden votar de quienes no.

Usa un subgrupo privado si sus integrantes también necesitan discusiones, archivos o información sobre sus miembros que los demás no deban ver.

![Acción Hacer delegado en el menú de un miembro](member_make_delegate.png)

Para crear una encuesta o propuesta e invitar solo a los delegados, usa la opción **Solo para personas seleccionadas**.
![Opción Solo para personas seleccionadas al iniciar una propuesta](poll_invited_people_only.png)
Después, al invitar a votar, verás la opción **Delegados de nombre-del-grupo**.
![Opción Delegados de Cooperativa Oatmilk en el formulario para invitar a votar](poll_invite_delegates_group.png)

Puedes ver quiénes son los delegados en la pestaña de miembros de la página de tu grupo. Abre el menú de filtros y selecciona **Delegados**.
![Opción Delegados en el filtro de miembros](members_list_delegates.png)
