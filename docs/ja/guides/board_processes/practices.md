# ガバナンスの実践とアプローチ

適切なガバナンスには、理事会の実効性を継続的に高めるために、ガバナンスの慣行、方針、手続きを定め、見直し、その妥当性を問い直すことが含まれます。

しかし、多くの理事会は時間が限られており、理事会資料、法令遵守、リスクへの対応に追われ、戦略や組織の成果に関する重要な課題について十分に話し合う時間を確保できていません。

## Loomioでの進め方
Loomioでは、文書、方針、手続きの作成や見直しをオンラインで進められます。ディスカッションと決定はスレッドにまとめられ、メンバーは都合のよい時間と場所でアクセスできます。

文書、方針、手続きごとに**スレッド**を作成します。スレッドはディスカッションをまとめる場であり、文書の草案とその後の改訂版を保存できます。

Loomioのスレッドでは、文書の執筆を担当する2〜3人が、文面の細部について話し合えるように作業を進められます。スレッドをその2〜3人だけの非公開にすることも、グループ内で公開して、すべてのメンバーが作業の状況を確認できるようにすることもできます。

![](document_introduce.png#width-90)

文書の草案ができたら、**意向確認アンケート**を使って、草案を確認できることをメンバーに知らせ、文書を読んでコメントや質問を寄せるよう呼びかけます。アンケートは作業の進捗を全員に知らせるとともに、締め切りを設けることで参加を促します。

![](document_integrate.png#width-90)

草案は、何度か修正する必要がある場合もあります。

「最終」草案ができたら、文書を承認するための**提案**を作成します。

![](document_approval.png#width-90)

Loomioを使うと、理事会は会議の貴重な時間を使わずに、会議と会議の間にガバナンス改善の作業を進められます。
