Loomio 3.4.2 adds Belarusian language support and related-group audiences for group invitations. It also fixes duplicate anonymous poll invitations and several authorization, navigation, subscription administration, and response-handling regressions.

- **New:** Select a parent group or related subgroup as the source audience when inviting people to a group
- **New:** Use Loomio in Belarusian
- **Fix:** Notify only newly added participants when expanding an anonymous poll's electorate
- **Fix:** Apply the correct permissions when announcing to groups
- **Fix:** Recheck group access before rendering previously cached group data
- **Fix:** Complete client reload recovery without reporting a second route error
- **Fix:** Restore the option to save and refresh Chargify-backed subscriptions
- **Fix:** Return the correct topic-item response after editing a poll response in place

## Group invitation audiences

People who can invite members to a group can select a parent group or related subgroup they belong to as an audience. Expanding the selected audience shows the individual invitees before sending and excludes existing members of the destination group. Only groups in the same organization tree are available, and the inviter must have permission to browse the source group's members.

See [PR #12783](https://github.com/loomio/loomio/pull/12783).

## Belarusian language

The application and email notifications are now available in Belarusian. Members can select беларуская мова in their user settings.

See [PR #12784](https://github.com/loomio/loomio/pull/12784).

## Anonymous poll invitations

Adding participants to an existing anonymous poll now creates invitation notifications only for newly added participants. People already in the anonymous electorate are not invited again, and submitting an invitation containing no new participants creates no notification.

See [issue #12794](https://github.com/loomio/loomio/issues/12794).

## Permissions and client recovery

Group announcements now use the group's announcement permissions. Group pages also wait for a fresh authorization response before rendering cached data, so revoked access takes effect when a group route is revisited.

When a deployment replaces client assets while someone is using Loomio, accepting the reload prompt no longer allows the interrupted route to report a second component-loading error before the page reloads.

## Administration and poll responses

Instance administrators can again save a subscription and refresh its details from Chargify in one operation.

Editing an existing poll response in place now returns its topic item and updated stance using the expected response structure. This restores the existing client contract; there are no intended B2 or B3 API compatibility changes.

## Upgrade

Make and verify a current database backup, set `LOOMIO_CONTAINER_TAG=3.4` in `.env`, then run:

```sh
./update.sh
```

This release has no new database migrations, configuration requirements, or operator actions beyond the normal update. Instances already running Loomio 3.4 do not need a separate data migration or backfill.
