# Інтэграцыя з Matrix

Loomio можа адпраўляць у вашы каналы Matrix апавяшчэнні пра новыя абмеркаванні, прапановы, каментары, галасы і высновы.

Matrix дазваляе выкарыстоўваць частку HTML у чатах, і Loomio карыстаецца гэтай магчымасцю.

Інтэграцыя з Matrix працуе інакш, чым іншыя інтэграцыі з чатамі. Яна не выкарыстоўвае вэбхук: для яе створаны асобны кліент-бот.

Стварыце ў Matrix уліковы запіс, праз які бот будзе ўваходзіць у сістэму.

Пасля стварэння ўліковага запісу ўвайдзіце праз яго, каб атрымаць звесткі, патрэбныя для наладжвання.

У гэтым кіраўніцтве выкарыстоўваецца Element.
