# Интеграция с Matrix

Loomio может отправлять уведомления в комнату Matrix, когда появляются новые обсуждения, опросы, комментарии, голоса и выводы. Чтобы добавить интеграцию с чатом, вы должны быть администратором группы.

В отличие от других интеграций Loomio с чатами, Matrix не использует вебхук. Вместо этого Loomio подключается через учётную запись Matrix, которая действует как бот и отправляет форматированные сообщения в вашу комнату.

В этом руководстве используется клиент Element.

---

1. Создайте учётную запись Matrix для Loomio, войдите в неё в Element и пригласите эту учётную запись в комнату Matrix, где должны появляться уведомления. Не выходите из этой учётной записи — выход делает токен доступа недействительным.

2. В вашей группе Loomio откройте меню группы, выберите **Интеграция чата** и добавьте интеграцию с чатом **Матрица**.

   ![Меню добавления бота Matrix в Loomio](loomio-add-matrix-bot.png)

   ![Форма настройки бота Matrix в Loomio](loomio-matrix-bot-form.png)

3. В Element откройте меню учётной записи бота и выберите **Все настройки**.

   ![Меню настроек Matrix](matrix-settings-menu.png)

4. Откройте **Справка и о программе** и прокрутите до раздела **Дополнительно**.

   ![Настройки Matrix](matrix-settings.png)

5. Скопируйте **Токен доступа** и вставьте его в форму Loomio.

   ![Токен доступа Matrix](matrix-access-token.png)

6. Откройте меню **Настройки** комнаты и перейдите в раздел **Дополнительно**.

   ![Настройки комнаты Matrix](matrix-room-settings.png)

7. Скопируйте **Внутренний идентификатор комнаты**, вставьте его в форму Loomio и сохраните интеграцию.

   ![Идентификатор комнаты Matrix](matrix-room-id.png)
