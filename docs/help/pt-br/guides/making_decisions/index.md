# Tomando decisões

Estes guias explicam processos completos de decisão: como definir uma decisão, envolver as pessoas certas, usar discussões e propostas, responder a preocupações e registrar uma conclusão.

Eles são diferentes das páginas de modelos de proposta. Um [modelo de proposta](/en/user_manual/polls/proposals/) explica uma proposta e suas opções de resposta. Um processo de decisão pode usar várias propostas ao longo do tempo.

<!-- translation-section: choose-a-process -->

## Escolha um processo

| Processo | Quem decide? | Pergunta principal |
|---|---|---|
| [Processo simples de decisão](simple_decision_process) | Definido pelo grupo | Como podemos discutir, testar e decidir? |
| [Processo de aconselhamento](advice_process) | Uma pessoa ou uma equipe delegada | Que conselhos a pessoa responsável pela decisão deve considerar? |
| [Processo de consentimento](consent_process) | O grupo | É seguro experimentar a proposta sem uma objeção relevante? |
| [Processo de consenso](consensus_process) | O grupo | Podemos chegar a um acordo coletivo? |

Use o processo exigido pelas normas de funcionamento ou pela política de decisão do seu grupo. Diferentes tipos de decisão podem usar diferentes processos.

Se você só precisa de ajuda para escolher um formato de resposta, compare [Propostas](/en/user_manual/polls/proposals/) e [Enquetes](/en/user_manual/polls/proposal_types/). Se você administra as opções reutilizáveis exibidas quando alguém seleciona **Iniciar uma votação**, consulte [Modelos de enquete](/en/user_manual/polls/poll_templates/).
