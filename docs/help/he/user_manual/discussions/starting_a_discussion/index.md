# פתיחת דיון

פתיחת דיון ב־Loomio דומה לשליחת מייל. הכותרת דומה לשורת נושא, ההקשר מציג את הנושא, ורשימת ההזמנות קובעת למי תישלח התראה.

ניתן לשאול שאלה פשוטה או לשתף מסמך מפורט עם קישורים וקבצים מצורפים. ניתן גם להשיב במייל, והתשובות יופיעו בדיון.

<!-- translation-section: new-discussion -->

## פתיחת דיון חדש

יש לבחור באפשרות **שרשור חדש** בדף הקבוצה או בדף של כל תת־קבוצה.

Loomio מציג את [תבניות הדיון](/en/user_manual/discussions/templates/) של הקבוצה. בחירה בתבנית או באפשרות **תבנית ריקה** פותחת את טופס הדיון.

![כפתור שרשור חדש בדף קואופרטיב Oatmilk](new-discussion-button.png)

![טופס פתיחת דיון לתכנון ניסוי בבקבוקים להחזרה](new-discussion-example.png)

<!-- translation-section: group -->

### קבוצה

יש לוודא שנבחרה הקבוצה או תת־הקבוצה המתאימה. כל חברי הקבוצה יכולים לראות את הדיון. ניתן גם לפתוח את הדיון בקבוצה אחרת או כ[דיון ישיר](/en/user_manual/discussions/direct_discussions/) ללא קבוצה.

>[!Tip]
>אם עדיין לא מתאים לשתף את הדיון עם הקבוצה, ניתן לפתוח אותו כדיון ישיר. ניתן להעביר אותו לקבוצה בהמשך.

<!-- translation-section: invite-and-notify -->

### הזמנה ושליחת התראות

השדה **הזמן** קובע למי תישלח התראה מיד עם פתיחת הדיון.

חברי הקבוצה יכולים לראות דיון בקבוצה שלהם גם ללא קבלת התראה. הוספת חבר קבוצה לשדה **הזמן** שולחת אליו התראה ב־Loomio ובמייל.

יש לבחור קבוצה כדי לשלוח התראה לכל חבריה, או להרחיב את הקבוצה לבחירת חברים מסוימים. יש לבחור בסימן **×** לצד שם כדי להסיר את האדם מרשימת הנמענים להתראה.

![השדה הזמן מורחב להצגת נמענים בודדים](../notifying_people/thread_notification.png)

יש להתחיל להקליד שם של חבר קבוצה ולבחור אותו מהרשימה.

![חיפוש סמירה פאטל בשדה הזמן](../notifying_people/thread_notify_user.png)

יש להזין כתובת מייל כדי להזמין אורח. אורח יכול לראות את השרשור הזה ולהשתתף בו, אך אינו יכול לראות דיונים פרטיים אחרים בקבוצה ללא הזמנה.

![הוספת כתובת מייל של אורח לשדה הזמן](../notifying_people/thread_notify_email.png)

ניתן גם לפתוח דיון ללא שליחת התראות. חברי הקבוצה עדיין יכולים למצוא אותו ב־Loomio, והוא עשוי להופיע במייל העדכונים שלהם, בהתאם להגדרות ההתראות שלהם.

<!-- translation-section: tags -->

### תגיות

יש להוסיף תגית אחת או יותר כדי לאפשר סינון וחיפוש של הדיון בהמשך. כברירת מחדל, חברים יכולים ליצור תגיות חדשות, אלא אם מנהל קבוצה מבטל את ההרשאה הזאת. למידע נוסף, ראו [תגיות קטגוריה](/en/user_manual/discussions/tags/).

<!-- translation-section: title -->

### כותרת

יש להוסיף כותרת ברורה וממוקדת שמבהירה במה עוסק הדיון.

<!-- translation-section: context -->

### הקשר

ההקשר מציג את הנושא ומגדיר את מסגרת השיחה או ההחלטה. ניתן לעצב טקסט, לצרף קבצים, להוסיף קישורים למסמכים ולהטמיע סרטונים.

ההקשר נשאר בראש השרשור, וניתן לעדכן אותו ככל שהדיון מתקדם. בסיום הדיון, ניתן גם להוסיף את המסקנה להקשר כדי שגם מי שמצטרפים מאוחר יראו מיד את התוצאה.
