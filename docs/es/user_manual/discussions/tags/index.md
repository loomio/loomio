# Etiquetas de categoría

Las etiquetas de categoría te ayudan a encontrar hilos y sondeos sobre un tipo de trabajo o tema concreto.

Las etiquetas pertenecen a toda la organización. Una etiqueta usada en un grupo principal es la misma en sus subgrupos. Así puedes organizar el trabajo relacionado en toda la organización. Loomio muestra los nombres de las etiquetas por orden alfabético y sus colores como puntos junto a los nombres.

En la página de tu grupo, haz clic en **Etiquetas** encima de la lista de hilos para ver las etiquetas usadas en el grupo actual. Selecciona una etiqueta para mostrar solo los hilos que la tengan. Usa el cuadro de filtro para buscar en una lista larga o selecciona **Mostrar más** para incluir todas las etiquetas de la organización. Selecciona **Mostrar menos** para volver a las etiquetas del grupo actual.

![](tags_view.png)

<!-- translation-section: apply-tags -->

## Aplicar etiquetas

Los miembros que pueden editar un hilo o sondeo también pueden aplicarle etiquetas.

Al iniciar un hilo o sondeo, haz clic en el campo **Etiquetas** y selecciona una o varias etiquetas.

![](tags_add_new.png)

Empieza a escribir para filtrar la lista. Para quitar una etiqueta, selecciónala de nuevo o haz clic en la × de su ficha.

<!-- translation-section: create-tags -->

## Crear etiquetas

Los administradores del grupo principal siempre pueden crear etiquetas para ese grupo y sus subgrupos. Los administradores de un subgrupo pueden crear etiquetas al etiquetar contenido de su subgrupo. El permiso **Los miembros pueden crear etiquetas**, activado de forma predeterminada, permite que otros miembros que pueden etiquetar un hilo o sondeo creen etiquetas nuevas. Si el permiso está desactivado, los miembros aún pueden aplicar las etiquetas existentes.

Para crear una etiqueta al iniciar un hilo o sondeo, escribe el nombre en el campo **Etiquetas** y pulsa Enter.

![crear una etiqueta nueva](tags_create_new.png)

![etiqueta nueva creada](tags_created_new.png)

Usa nombres breves y conocidos por los miembros del grupo, como Finanzas, Gobernanza, Embalaje o Colaboraciones con cafeterías.

<!-- translation-section: edit-tags -->

## Editar etiquetas

Solo los administradores del grupo principal pueden cambiar el nombre o el color de las etiquetas, fusionarlas o eliminarlas. Estos cambios se aplican a toda la organización, incluidos sus subgrupos.

En la página del grupo, abre **Etiquetas** y selecciona **Editar etiquetas**.

![editar etiquetas de categoría](tags_edit_new.png)

Selecciona el icono del lápiz junto a una etiqueta.

![editar etiquetas de categoría](tags_edit_new_pencil.png)

Cambia el nombre de la etiqueta o elige un color y haz clic en **Guardar**.

![editar el color de una etiqueta](tags_edit_name.png)

Haz clic en **Eliminar** para quitar la etiqueta de todos los hilos y sondeos de la organización.

![eliminar etiqueta](tags_delete.png)

### Editar etiquetas de un hilo o sondeo

Para cambiar las etiquetas de un hilo o sondeo existente, ábrelo y haz clic en el botón de etiquetas junto a las etiquetas actuales, cerca del título.

Selecciona etiquetas para añadirlas o quitarlas. Los cambios se guardan de inmediato.

![editar etiquetas de un hilo](tags_thread_edit.png)
