# Start een thread in je groep via e-mail

Je Loomio-groep heeft een e-mailadres. Stuur of stuur een e-mail door naar dit adres om een thread in de groep te starten.

Je vindt het e-mailadres van je groep op de groepspagina:
![Locatie van het e-mailadres op de groepspagina](email_email_button.png)

Als je een e-mail naar dit adres stuurt, wordt een nieuwe thread gestart. Het onderwerp van de e-mail wordt de titel van de thread, de inhoud wordt de beschrijving en eventuele bijlagen worden aan de thread toegevoegd.

Loomio gebruikt het adres in het veld "Van" om te bepalen welk groepslid de auteur van de thread wordt.

<!-- translation-section: preventing-unauthorized-emails -->

## E-mails van onbevoegden voorkomen

Alleen leden van je groep kunnen op deze manier een thread starten. Daarom moet het adres in het veld "Van" van een inkomende e-mail overeenkomen met het e-mailadres van een groepslid.

Gebruik je meerdere e-mailadressen? Voeg dan een alias toe, zodat Loomio je andere adressen herkent.

Als het adres in het veld "Van" niet overeenkomt met dat van een groepslid, krijg je een melding. Daarin kun je een alias toevoegen of alle volgende e-mails van dat adres afwijzen.

De eerste keer dat je vanaf een onbekend adres mailt, moet je dus een alias toevoegen. Daarna worden e-mails vanaf dat adres direct geaccepteerd.
