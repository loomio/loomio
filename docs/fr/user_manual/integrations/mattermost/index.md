# Intégration Mattermost
_Recevez les notifications de votre groupe Loomio dans la messagerie de votre équipe Mattermost._

Loomio peut envoyer des notifications dans vos canaux Mattermost lorsqu’une discussion ou une proposition est créée, qu’un commentaire ou un vote est ajouté, ou qu’une conclusion est publiée.

---

Ouvrez votre équipe Mattermost dans votre navigateur. Accédez ensuite aux paramètres d’intégration.
![](mm1.png)

Cliquez sur « Webhooks entrants »
![](mm2.png)

Cliquez ensuite sur « Ajouter un webhook entrant »
![](mm3.png)

Donnez-lui un nom simple, choisissez le canal où afficher les notifications, puis cliquez sur « Enregistrer »
![](mm4.png)

Copiez l’URL du webhook dans votre presse-papiers. Vous en aurez besoin à l’étape suivante.
![](mm5.png)

Vérifiez que l’URL du webhook est dans votre presse-papiers, puis suivez le lien ci-dessous.

[Configurer une intégration de messagerie dans Loomio](../chatbots/#set-up-a-chat-integration)
