# העברת פריטים בין שרשורים

ניתן להעביר פריטים נבחרים כששיחה שייכת לשרשור אחר, כששרשור מתפצל לנושאים נפרדים או כשרוצים לאחד דיונים קשורים. אין פקודה נפרדת בשם **מיזוג דיונים**.

האפשרות זמינה למנהלי קבוצה, וגם לחברים כאשר ההגדרה **חברים יכולים לנהל דיונים ותגובות** מופעלת ב[הרשאות הקבוצה](/en/user_manual/groups/settings/permissions).

יש לפתוח את תפריט שלוש הנקודות (**⋯**) בפריט ולבחור **העבר פריט**.

![](../using_discussions/comment_move.png)

יש לבחור את הפריטים להעברה.

![](../using_discussions/comment_select.png)

יש לסמן פריטים נוספים בתיבות הסימון, ואז ללחוץ על **העבר** בפס שבראש הדיון.

![](../using_discussions/move_items.png)

יש לבחור קבוצה או תת־קבוצה, ואז לחפש את דיון היעד.

כדי להעביר את הפריטים לדיון חדש, יש לבחור **דיון חדש** ולהוסיף כותרת והקשר.

![](../using_discussions/move_items_new_thread.png)

הפריטים מועברים מהשרשור המקורי לשרשור שנבחר או נוצר.

![](../using_discussions/new_thread.png)

אם אין עוד צורך בשרשור המקורי, ניתן [לנעול אותו](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread). יש למחוק אותו רק אם בטוחים שלא יהיה בו צורך שוב.
