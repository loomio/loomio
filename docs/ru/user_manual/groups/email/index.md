# Отправьте письмо, чтобы начать обсуждение в вашей группе

У вашей группы в Loomio есть адрес электронной почты. Отправьте или перешлите на него письмо, чтобы начать обсуждение в группе.

Адрес электронной почты группы указан на её странице:
![Расположение адреса электронной почты на странице группы](email_email_button.png)

Когда вы отправите письмо на этот адрес, начнётся новое обсуждение. Тема письма станет названием обсуждения, текст письма — его описанием, а прикреплённые файлы будут добавлены к обсуждению.

По адресу отправителя в поле «От» Loomio определит участника группы, который станет автором обсуждения.

## Защита от писем посторонних

Чтобы люди вне вашей группы не могли начать обсуждение по электронной почте, Loomio проверяет, совпадает ли адрес в поле «От» с адресом участника группы.

Если вы пользуетесь несколькими адресами электронной почты, добавьте псевдоним для каждого дополнительного адреса.

Если адрес отправителя не совпадает с адресом участника группы, вы получите уведомление с предложением добавить псевдоним или отклонять все последующие письма с этого адреса.

Когда вы впервые отправите письмо с неизвестного Loomio адреса, вам потребуется добавить псевдоним. После этого письма с этого адреса будут приниматься сразу.
