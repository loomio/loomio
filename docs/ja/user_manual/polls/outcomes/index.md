# 結論

提案や投票が終了すると、**結論**の入力を求められます。

![](outcome_prompt.png)

提案や投票の結果と、今後の対応を記載します。

結論は、投票や意思決定の重要な記録です。後から参照できるよう、簡潔にまとめます。

<!-- translation-section: outcome-statements-for-common-decision-processes -->

## 一般的な意思決定の進め方における結論

| **意思決定の進め方** | **決定する時点** | **結論** |
|---|---|---|
| 助言を受けて決める | 助言を受け、検討したとき。 | 決定した内容を記載し、助言や意見を寄せた人たちに感謝を伝えます。 |
| 異議がないことを確認して決める | 異議が残っていないとき。 | 妥当な異議が残っておらず、提案を「試してみてもよい」という同意が得られたことを記載します。  |
| コンセンサスで決める | ほとんどの人*が賛成したとき。 | 提案の結果と決定した内容を記載します。 |

**組織の規約または事前の合意で定められた過半数または特別多数を指します。*

結果がどうであっても、提案や投票から得られる学びがあります。

提案が通らなかった場合は、新たに分かったことを振り返り、よりよい決定に生かせるか検討します。

結論には、結果とそこから学んだことを記載できます。

![](outcome_statement.png)

関係者に通知できます。通知を受ける人には、投票結果と結論を記載したメールが Loomio から届きます。

**レビュー日**も設定できます。これは、投票や決定を見直すための将来の日付です。例えば、翌年の同じ時期に戦略を見直す場合に設定します。

![](outcome_published.png)

**結論の記載例**

> _この提案は、予算への影響を懸念する人が複数いたため、コンセンサスに至りませんでした。George と Jimena が財務面の試算を行い、来週、新たな提案を出します。_

または

> _皆さんの意見を踏まえました。プロジェクトマネージャーとして判断し、予定を10日間延長することにしました。_
