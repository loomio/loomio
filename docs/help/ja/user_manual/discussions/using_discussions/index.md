# スレッドの使い方

ディスカッションでは、背景説明、コメント、決定、結論を1つのスレッドにまとめます。このページでは、スレッドへの参加方法と、ナビゲーションや操作の使い方を説明します。

<!-- translation-section: thread-anatomy -->

## スレッドの構成

一般的なスレッドは次のように表示されます。

![](thread_navigation.png)

スレッドには、ページの上から順に次の項目があります。

**グループ名** - ディスカッションページの左上に、ディスカッションが属するグループまたはサブグループの名前が表示されます。この名前をクリックすると、グループページに戻ります。

**ディスカッションへのアクセス** - 右上のアクセスアイコンを選択すると、ディスカッションのアクセス設定が開きます。グループのディスカッションには、グループのプライバシー設定に従って、グループのメンバーと、そのディスカッションに個別に招待された人がアクセスできます。

**ディスカッションのタイトル** - ディスカッションの名前です。

**カテゴリタグ** - ディスカッションには、1つ以上のカテゴリタグを付けられます。簡潔なタグを使うと、同じ種類のディスカッションを見つけやすくなります。

**ディスカッションの作成者** - ディスカッションを開始した人の名前とアバターが、タイトルの下に表示されます。

**日付** - 日付にカーソルを合わせると、ディスカッションを開始した正確な日時が表示されます。

**で見られる** - 右側のサイドバーに、ディスカッションを読んだ人と、その日時が表示されます。

**通知済み** - 右側のサイドバーに、ディスカッションについて通知された人と、各通知が読まれたか、通知メールが開かれたかが表示されます。

**ディスカッションの背景説明** - ディスカッションの目的や前提を説明する内容です。

**ディスカッションへの反応と管理のツール** - ディスカッションの背景説明には、リアクションや編集の操作があります。右側のサイドバーには、通知、メンバー、管理に関する操作があります。

**コメント** - コメントはディスカッションの背景説明の下に表示されます。投稿者の名前、アバター、投稿日時から、誰がいつコメントを書いたかが分かります。各コメントには、リアクションや管理のツールがあります。

**ナビゲーション、通知、操作** - 右側のサイドバーには、アクティビティや節目へのショートカット、通知やメンバーに関する情報、実行できるスレッドの操作があります。

<!-- translation-section: discussion-context -->

## ディスカッションの背景説明

ディスカッションの**背景説明**は、常にディスカッションの先頭にあります。背景説明を使って、ディスカッションや決定の目的と前提を説明します。

ディスカッションの背景説明を書くときは、グループのメンバーを念頭に置きます。ディスカッションを進めるために、参加を促すにはどうすればよいかを考えます。背景説明は、簡潔で分かりやすく書くことを基本にします。

![](thread_context.png)

ディスカッションを開始または編集するときに、背景説明を書きます。鉛筆アイコンでディスカッションを**編集**します。

ディスカッションが進んだら、背景説明を更新します。背景説明は、会議室のホワイトボードのように使えます。議題、目指す結論、そこに至るまでの進め方を書きます。

背景説明パネルの下部には書式設定バーがあり、テキストの書式設定、ファイルや画像の添付、動画の埋め込みができます。

![](thread_context_edit.png)

<!-- translation-section: notify-people-about-context-changes -->

### 背景説明の変更を通知する

ディスカッションの背景説明を編集するときは、**何が変わったのでしょうか？**に更新内容の要約を入力し、通知する人を選択します。

![変更内容の要約と通知先を指定してディスカッションの背景説明を編集する画面](../notifying_people/thread_editcontext.png)

スレッドには、背景説明を編集したことが表示されます。通知先に選んだ人には、通知とともに要約が届きます。

![ディスカッションの背景説明が編集されたことを示すスレッド内の項目](../notifying_people/thread_edit_comment.png)

<!-- translation-section: navigation -->

## ナビゲーション

右側のサイドバーの**ジャンプ**から、スレッド内を移動できます。

- **始める**はディスカッションの背景説明に移動します
- **あなたにとって新しい**は、スレッドに未読のアクティビティがあるときに表示されます
- **最新**は、現在読み込まれている項目よりも新しいアクティビティがあるときに表示されます
- 節目のリンクは、重要なコメント、アンケート、結論に直接移動します
- **終わり**はスレッドの最新の項目に移動します

H2またはH3の見出しを含むコメント、アンケート、提案は、節目のリンクに自動的に追加されます。節目を選択すると、その項目に直接移動します。

![](thread_timeline_1.png)

コメント、アンケート、投票、結論を追加すると、Loomioは本人が追加した項目を既読にします。その項目は、確認が必要な新しい項目としては表示されません。

<!-- translation-section: notifications-and-members -->

## 通知とメンバー

右側のサイドバーでは、メール通知を設定できるほか、招待された人、スレッドを見た人、通知された人を確認できます。

<!-- translation-section: email-notifications-for-this-thread -->

### このスレッドのメール通知

現在の通知設定を選択すると、すべてのアクティビティについてメールを受け取る、自分が通知先に指定されたアクティビティのみ受け取る、メールを受け取らない、のいずれかを選べます。すべてのアクティビティについてメールを受け取る設定では、活発なスレッドから多くのメールが届く場合があります。

![ディスカッションのサイドバーで通知されたときにメールを受け取る設定を選択した状態](../notifying_people/thread_interact.png)

<!-- translation-section: invite-people -->

### 人を招待する

人を招待したり、ディスカッションについて通知したりするには、右サイドバーの**メンバーを招待する**を選択します。グループ、親グループ、ゲスト、チャットルーム、招待通知については、[ディスカッションに人を招待する](/en/user_manual/discussions/inviting_people)を参照してください。

<!-- translation-section: seen-by -->

### 閲覧した人

**で見られる**には、スレッドを開いた人と、その日時が表示されます。重要な情報をまだ見ていない可能性がある人を確認するのに役立ちます。

![スレッドのメンバー欄にある閲覧状況と通知済みの表示](../notifying_people/thread_engagement.png)

![スレッドのメンバーを一覧表示する閲覧状況ウィンドウ](../notifying_people/thread_seenby.png)

<!-- translation-section: notified -->

### 通知済み

**通知済み**を選択すると、ディスカッションの通知履歴が開きます。履歴には招待、メンション、返信が含まれ、通知された人が表示されます。既読情報が確認できる場合は、各通知が読まれたかどうかも表示されます。

![ディスカッションの通知履歴](../notifying_people/thread_notified.png)

## スレッド設定

スレッド管理者とグループ管理者は、**スレッド設定**を選択して返信の配置を変更したり、ディスカッションのその他の設定を行ったりできます。

![](thread_display.png)

![レイアウト、アンケートの制限、添付権限、コメントの文字数制限を含むスレッド設定](thread_layout_options.png)

### レイアウト

**年代順**を選択すると項目が投稿順に表示され、**入れ子構造**を選択すると返信が返信先の項目の下にまとめて表示されます。この変更は、スレッドの参加者全員のレイアウトに適用されます。

<a id="allow-multiple-polls-at-the-same-time"></a>

### 同時に実施できるアンケートは1つのみ

チェックを入れると、現在のアンケートが締め切られるまで、別のアンケートを開始できなくなります。新しいスレッドでは、既定でチェックが外れています。ディスカッションのテンプレートから開始したスレッドには、そのテンプレートの設定が適用されます。

### 管理者のみ添付可能

この設定を有効にすると、アンケートへの回答やメールでの返信を含め、スレッド全体で新しいファイルや本文中の画像を追加できるのは、スレッド管理者とグループ管理者のみになります。既存の添付ファイルは引き続き利用でき、参加者は自分の文章の編集や添付ファイルの削除を引き続き行えます。

ディスカッションやアンケートのテンプレートで、新しいスレッドに適用するこの設定を指定できます。[ディスカッションのテンプレート](/en/user_manual/discussions/templates)と[アンケートのテンプレート](/en/user_manual/polls/poll_templates)を参照してください。

### コメントの文字数制限

投稿を簡潔にするために、コメントごとの最大文字数を設定できます。制限しない場合は空欄にします。この制限は、管理者を含む全員に適用されます。

<!-- translation-section: actions -->

## 操作

右側のサイドバーには、スレッド全体に対する操作があります。一部の操作は、グループページのスレッドの横にある三点メニュー（**⋯**）からも実行できます。

表示される操作は権限によって異なります。グループの管理者はスレッドを管理できます。グループの設定によっては、メンバーにも一部の管理操作が許可されます。[グループの権限](/en/user_manual/groups/settings/permissions)を参照してください。

![](thread_admin.png)

<!-- translation-section: print -->

### 印刷

**印刷する**を選択すると、印刷に適したページが生成されます。ブラウザーの印刷ダイアログを使うと、PDFとして保存できます。

![](thread_print_thread.png)

<!-- translation-section: markdown -->

### Markdown

**Markdown**を選択すると、スレッド全体を構造化されたMarkdownとして保存できます。**マークダウンをコピー**を選択するとクリップボードにコピーでき、**Markdownをダウンロード**を選択すると`.md`ファイルとして保存できます。議事録、文書、決定の記録、AIアシスタント、その他のMarkdownに対応したツールで利用できます。

![](../discussion_management/copy_markdown_menu.png)

文書の冒頭には、スレッドのキー、元のURL、グループ、作成日時、最終活動日時、タグを含むYAMLフロントマターがあります。このURLからLoomioのスレッドに戻れます。その後に、ディスカッションの背景説明とすべてのコメント、アンケート、投票、結論が、スレッド表示と同じ順序と入れ子構造で含まれます。

各アンケートは一つのセクションになります。コメント、投票、結論は引用形式で表示され、返信は返信先の項目の下に引用形式で表示されます。これにより、各参加者の文章の始まりと終わりが分かります。各引用の先頭には、投稿者、投稿日時、スレッド内の項目番号、リアクションを示す行があります。投票と結論には、項目の種類も表示されます。スレッドのキーと項目番号で、Loomio内の各項目を識別できます。

Loomioは、スレッドと同じ公開範囲のルールを適用します。閲覧できない結果や投票の理由は含まれず、匿名アンケートでは投票者を特定できる情報は表示されません。投票するまで結果が非表示になる受付中のアンケートがある場合は、スレッドをエクスポートする前に投票してください。投票するまで、**Markdown**と**印刷する**は利用できません。

### スレッドのピン留めと解除

ピン留めされたスレッドは、グループページで他のスレッドより上に表示されます。新しいメンバーを迎えるディスカッション、ニュース、お知らせなどによく使われます。

グループページでスレッドの横にある三点メニュー（**⋯**）を開き、**スレッドを固定**を選択します。ピン留めされたスレッドは、ピン留めした日時の順に並びます。順序を変更するには、ピン留めを外してから再度ピン留めします。

**スレッドのピン留めを外す**を選択すると、スレッドはアクティビティに基づく表示順に戻ります。

![](../discussion_management/pin_thread.png)

<!-- translation-section: move-a-thread -->

### スレッドの移動

**スレッドを移動**を選択すると、スレッドを別のグループやサブグループに移動したり、ダイレクトスレッドに変更したりできます。移動先のグループのメンバーと、そのスレッドに個別に招待された人が閲覧できるようになります。

スレッドを移動する際、Loomioは参加権限を失う人数を表示します。招待の通知を送信せずに、その人たちをゲストとして残すことができます。別のグループやサブグループに移動する場合は、移動先のグループでゲストを招待する権限が必要です。既存のゲストは引き続きアクセスできます。

ダイレクトスレッドに変更する場合、参加したことがある人は自動的に引き続きアクセスできます。ゲストとして残す設定を選択すると、その他の現在のメンバーとゲストも引き続きアクセスできます。変更を行った人とスレッドの作成者がスレッド管理者になります。

![](../discussion_management/move_thread_select.png)

>[!Tip]
>ダイレクトスレッドのディスカッション、または非公開のサブグループで下書きを作成し、準備ができたらグループに移動します。

スレッド全体ではなく、選択したアクティビティを移動する方法については、[スレッド間での項目の移動](/en/user_manual/discussions/moving_items/)を参照してください。

<!-- translation-section: lock-or-unlock-a-thread -->

### スレッドのロックと解除

スレッドをロックすると、そのままの状態で保存できます。ロックされたスレッドでは、誰も内容の追加や変更、そのスレッドからの招待や通知を行えません。スレッドをロックできるのは、実施中のアンケートがすべて締め切られた後です。

**行動**の下にある**スレッドをロック**を選択します。ロックされたスレッドは、進行中のディスカッションの一覧から除外され、**ロック済み**のタグが付きます。

ロックされたスレッドを探すには、グループページでディスカッションのフィルターを開き、**ロック済み**を選択します。スレッドを開いて**スレッドのロックを解除**を選択すると、再びコメントや変更ができるようになります。

<!-- translation-section: delete-a-thread -->

### スレッドの削除

スレッドを削除すると完全に削除され、元に戻せません。後で必要になる可能性がある場合は、スレッドをロックしてください。

**スレッドの削除**を選択し、削除を確定します。

![](../discussion_management/thread_delete.png)
