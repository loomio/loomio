# プロフィール

プロフィールは、Loomioで他の人が誰であるかを確認するための情報です。写真、自己紹介、その他の共有したい情報を追加します。

<!-- translation-section: edit-profile -->

## プロフィールの編集

サイドバーで自分の名前を選択してユーザーメニューを開き、**プロファイル編集**を選択します。サイドバーが閉じている場合は、メニューボタン（**☰**）で開きます。

![](edit_profile.png)

<!-- translation-section: update-your-personal-info -->

## 個人情報の更新

プロフィールページで、次の項目を更新できます。

- **氏名**
- **Eメールアドレス** — Loomioアカウントに登録されているメールアドレスです。Loomioからの通知はこのアドレスに届きます。
- **ユーザー名** — 他の人が`@mention`で通知する際に使う名前です。小文字の英字、数字、アンダースコア、先頭と末尾以外のハイフンを使用できます。
- **導入** — グループの他のメンバーに向けて、自分について数行で紹介します。
- **位置** — メンバーが各地にいるグループやリモートで活動するグループで、所在地を伝えるのに役立ちます。

![](user_profile.png)

<!-- translation-section: uploading-a-profile-photo -->

## プロフィール写真のアップロード

Loomioアカウントを作成すると、名前の頭文字がプロフィールの初期画像として表示されます。写真をアップロードするには、プロフィールページの自分の画像を選択します。

![](profile_photo.png)

<!-- translation-section: language-settings -->

## 言語

Loomioは標準でブラウザーの言語を検出します。プロフィールページで希望する言語を選択することもできます。画面の表示言語やコンテンツの翻訳については、[言語と翻訳](../translation)を参照してください。

<!-- translation-section: time-zone -->

## タイムゾーン

日程調整の選択肢には、プロフィールに保存されているタイムゾーンが使用されます。ブラウザーのタイムゾーンを使用するには、**タイムゾーンを自動検出**を有効にします。手動で設定するには、無効にして**タイムゾーン**で地域を選択し、**プロフィールを更新する**を選択します。

<!-- translation-section: resetting-your-password -->

## パスワードの再設定

パスワードを変更するには、プロフィールページを開き、**パスワードを再設定**を選択します。

![](reset_password.png#width-90)

<!-- translation-section: passkeys -->

## パスキー

プロフィールページでパスキーの追加、名前の設定、削除ができます。パスキーを使うと、端末の指紋認証、顔認証、PIN、またはセキュリティキーでサインインできます。[パスキーでサインイン](../signing_in#sign-in-with-a-passkey)を参照してください。

<!-- translation-section: merge-accounts -->

## アカウントの統合

Loomioアカウントが2つある場合は、1つのアカウントに統合できます。

[アカウントの統合](../merge_accounts)を参照してください。

<!-- translation-section: deleting-your-account -->

## アカウントの削除

Loomioアカウントを完全に削除し、所属しているグループから退会するには、[Loomioアカウントの削除](../deleting_your_account)を参照してください。
