# Een nieuwe groep starten

Als je nieuw bent bij Loomio, kun je een groep starten met een gratis proefperiode via de [Loomio-website](https://www.loomio.com/). Als je Loomio al gebruikt en nog een groep wilt starten, selecteer je **Nieuwe groep** in de zijbalk.

De meeste organisaties hebben maar één hoofdgroep nodig, met daarin zoveel [subgroepen](/en/user_manual/groups/subgroups) als nodig zijn.

## Groepsgegevens

![](new_group_start.png#width-80)

<!-- translation-section: group-name -->

### Groepsnaam

Voer een korte, duidelijke naam in voor je groep.

<!-- translation-section: group-handle -->

### Groepshandle

Loomio wijst automatisch een handle toe op basis van je groepsnaam. De handle wordt gebruikt in de URL en het e-mailadres van de groep, zoals `loomio.com/your-group-handle` en `your-group-handle@loomio.com`.

Je kunt de handle tijdens het instellen aanpassen of later wijzigen in de groepsinstellingen. Als je de handle wijzigt, blijven links en e-mailadressen die de oude handle gebruiken werken. Loomio bewaart maximaal drie oude handles; daarna vervalt de oudste handle.

<!-- translation-section: group-description -->

### Groepsbeschrijving

Voeg een korte beschrijving toe die bovenaan de groepspagina verschijnt en nieuwe leden context geeft.

Kies een [privacyinstelling](/en/user_manual/groups/settings/privacy) en selecteer **Start groep** om de groep aan te maken. Je wordt automatisch de eerste groepsadmin en kunt deze gegevens later bijwerken in de groepsinstellingen.
