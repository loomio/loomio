# グループについて

Loomioのグループは、人々が集まり、ディスカッションを行い、意思決定をするための安心できる場所です。

グループのメンバーは、ここで情報を探して共有し、仕事に関わる重要なディスカッションや意思決定に参加できます。

Loomioのグループは次のように表示されます。ページ上部の画像とロゴは、組織に合わせて変更できます。グループを訪れた人が見慣れた場所だと分かり、安心して参加する助けになります。

![説明とディスカッション一覧が表示されたOatmilk Cooperativeのグループページ](group_page.png)

グループを表す名前を付け、グループの説明に次の内容を記載してください。
- このグループを**何に**使うか
- それが**なぜ**重要か
- **誰が**関わるか
- メンバーが**どのように**参加できるか

行動規範、活動規約、その他の運営に関する文書を載せることもできます。

新しいグループを準備する際は、[グループにLoomioを導入する](/en/user_manual/overview/introducing_loomio)をご覧ください。最初に取り組むことの選定から結論の記録まで、実践的な手順を紹介しています。

## 管理、進行、モデレーションと行動規範

Loomioは、誰もが参加でき、多様性と信頼を大切にしながら、グループでよりよい意思決定を行えるように設計されています。

話題によっては、グループ内で緊張が生じることがあります。十分に議論できるようにしながら、特に弱い立場にあるメンバーにとっても安心できる場を保つことが大切です。

グループの行動規範を定めることをお勧めします。適切な振る舞いについて各自の責任を共有し、自主的に守る助けになります。

行動規範の意義について詳しくは、[ファシリテーターガイド](/en/guides/facilitators_guide/commencing#culture-protocol-expectations)をご覧ください。
