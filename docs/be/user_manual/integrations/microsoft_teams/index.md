# Інтэграцыя з Microsoft Teams
_Падключыце апавяшчэнні вашай групы ў Loomio да Microsoft Teams._

Loomio можа адпраўляць апавяшчэнні ў Microsoft Teams, калі з’яўляюцца новыя абмеркаванні, прапановы, каментарыі, галасы і высновы.

---

Адкрыйце [https://teams.microsoft.com](https://teams.microsoft.com), затым націсніце «Праграмы»
![](t1.png)

Увядзіце «webhook» у поле пошуку, затым націсніце «Уваходны вэбхук»
![](t2.png)

Націсніце «Дадаць у каманду»
![](t3.png)

Увядзіце назву канала, у якім павінны з’яўляцца апавяшчэнні Loomio, і выберыце яго.
![](t4.png)

Дайце вэбхуку назву, напрыклад «Апавяшчэнні Loomio», затым націсніце «Стварыць»
![](t5.png)

Скапіруйце атрыманы URL-адрас. На апошнім кроку вы ўставіце яго ў Loomio.
![](t6.png)

_Loomio не створана кампаніяй Microsoft, не звязана з ёй і не падтрымліваецца ёю._

Цяпер, калі ў вас ёсць URL-адрас вэбхука, працягніце наладжванне інтэграцыі з чатам:

[Наладзьце інтэграцыю з чатам у Loomio](../chatbots/#set-up-a-chat-integration)
