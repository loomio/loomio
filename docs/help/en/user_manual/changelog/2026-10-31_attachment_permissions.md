# Restrict attachments in a thread

Thread admins and group admins can enable **Only admins can add attachments** in **Thread settings**. This restricts new files and inline images throughout the thread, including comments, poll responses, outcomes, and email replies. Participants can still contribute text, keep existing attachments when editing, and remove attachments.

Discussion and poll templates can supply this setting for new threads. Polls inside an existing thread follow that thread's setting. Editing a template does not change existing threads.
