# Favoritos

Os favoritos são uma lista pessoal de itens do Loomio aos quais você deseja voltar. Só você pode ver seus favoritos. Ao salvar um item, ninguém mais recebe uma notificação.

Você pode salvar como favoritos:

- discussões
- comentários
- propostas e enquetes
- votos
- conclusões

<!-- translation-section: save-a-bookmark -->

## Salvar um favorito

Abra o menu de ações do item e selecione **Salvar marcador**. Esse menu geralmente aparece como três pontos. Para uma discussão, use o menu próximo ao título. Para um comentário, voto, proposta, enquete ou conclusão, use o menu do próprio item.

![](save_bookmark.png)

<!-- translation-section: view-your-bookmarks -->

## Ver seus favoritos

Abra a barra lateral e selecione **Favoritos**. O número ao lado do link mostra quantos favoritos você salvou.

A página Favoritos mostra primeiro os itens salvos mais recentemente. Cada linha mostra o tipo de item e quem o publicou. Selecione uma linha para voltar ao item salvo.

![](bookmarks_page.png)

<!-- translation-section: remove-a-bookmark -->

## Remover um favorito

Na página Favoritos, selecione o botão para remover o marcador no fim da linha. Você também pode abrir o menu de ações do item e selecionar **Remover marcador**.

Remover um favorito afeta apenas sua lista pessoal. Você pode salvar o item novamente mais tarde.
