# Отчёт об участии

Отчёт об участии в группе показывает, как используется ваша группа в Loomio.

Вы можете выбрать группы для отчёта, начальную и конечную даты, а также интервал для группировки результатов: год, месяц, неделю или день.

Отчёт доступен всем участникам вашей группы. Каждый видит результаты только тех групп, в которых состоит, поэтому отчёты разных людей могут немного отличаться.

Чтобы открыть отчёт, нажмите значок шестерёнки в меню настроек группы, как показано ниже.

![Пункт отчёта об участии в меню Oatmilk Cooperative](group_participation_report.png)

<!-- translation-section: what-s-in-the-report -->

## Что входит в отчёт?

<!-- translation-section: actions-per-month -->

### Действия по месяцам

Посмотрите, насколько активно участники вашей группы действовали за выбранный период.

Отчёт показывает количество обсуждений, комментариев, опросов, поданных голосов и реакций за каждый месяц. График помогает увидеть, как менялась активность.

Нажмите название показателя на графике, чтобы скрыть его.

Нажмите заголовок столбца, чтобы отсортировать таблицу по нему.

![Настройки отчёта об участии, общие показатели и график активности группы Oatmilk Cooperative](group_participation_report_graph.png)

<!-- translation-section: tag-usage -->

### Использование тегов

Здесь показано, как часто применялись разные теги за выбранный период. Например, вы можете узнать, сколько решений принято с использованием определённого процесса принятия решений или шаблона.

![Активность тегов Production, Cafe partnerships и Operations по времени](group_participation_report_tags.png)

<!-- translation-section: actions-per-user -->

### Действия по пользователям
Посмотрите, кто в вашей группе участвует наиболее и наименее активно.

Таблица показывает, сколько обсуждений, комментариев, опросов, поданных голосов и реакций приходится на каждого пользователя выбранных групп за указанный период. Нажмите заголовок столбца, чтобы отсортировать таблицу по нему.

Включите **Только для делегатов**, чтобы показать тех, кто сейчас является делегатом хотя бы в одной из выбранных групп. Их действия и сведения о голосовании суммируются по всем выбранным группам. Делегаты, которые не проявляли активности за выбранный период, также остаются в таблице. При скачивании CSV применяется тот же фильтр.

![Действия делегатов с тремя уровнями участия](group_participation_report_actions_per_user.png)

<!-- translation-section: voting-record-per-user -->

### Сведения о голосовании по пользователям

Сравните количество голосов, предоставленных каждому человеку, с количеством поданных им голосов. Посмотрите, какие голосования он пропустил и кто проголосовал во всех доступных ему опросах. Если человеку не предоставляли право голоса, отчёт не показывает, что он проголосовал во всех опросах. Анонимные опросы исключены: анонимный бюллетень нельзя связывать с человеком, который его подал.

Используйте **Только для делегатов**, чтобы просмотреть сведения о голосовании действующих делегатов. При скачивании CSV применяются те же фильтры по имени и статусу делегата.

![Сведения о предоставленных, поданных и пропущенных голосах делегатов](group_participation_report_voting_record.png)

### Пользователи по странам

Количество пользователей вашей группы в каждой стране определяется по их текущим IP-адресам.

![Пользователи выбранных групп по странам](group_participation_report_users_per_country.png)

<!-- translation-section: actions-per-country -->

### Действия по странам

Посмотрите, в каких странах пользователи участвуют наиболее и наименее активно.

Как и в разделе «Действия по пользователям», здесь показаны действия пользователей, но они сгруппированы по странам, определённым для каждого пользователя.

![Действия, сгруппированные по странам](group_participation_report_actions_per_country.png)
