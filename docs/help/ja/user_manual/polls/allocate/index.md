# 配分

配分はドット投票とも呼ばれ、何かを優先すると別の何かを減らす必要があるときに、優先順位を明らかにします。各参加者は一定のポイントを受け取り、選択肢に配分します。ある選択肢に多く配分すると、ほかの選択肢に使えるポイントが少なくなります。

<!-- translation-section: when-to-use-allocate -->

## 配分を使う場面

時間、資金、注意を向けられる範囲など、使える資源が限られている場合に配分を使います。次のような用途に適しています。

- 次の計画期間に取り組む作業の優先順位を決める
- 参加型予算を複数のプロジェクトに配分する
- 複数の議題にそれぞれどれだけ時間を充てるかを決める
- 限られたボランティアの活動時間を配分する
- メンバーにとって最も重要な改善点を把握する

ポイントは相対的な優先度を表すもので、Loomioが自動的に割り当てる量ではありません。他の選択肢への支持を減らすことなく、すべての選択肢を高く評価できる場合は、[スコア](/en/user_manual/polls/score/)を使います。

<!-- translation-section: example-set-priorities-for-an-annual-strategy-review -->

## 例：年次戦略レビューの優先順位を決める

Oatmilk Cooperativeは年次戦略レビューを計画しています。レビューでどの分野に最も時間と注意を向けるべきかをメンバーに尋ねます。各メンバーは10ポイントを受け取り、5つの分野に配分します。参加者が限られたポイントの使い道を選ぶことで、グループの相対的な優先順位が明らかになります。

<!-- translation-section: set-up-the-poll -->

## アンケートを設定する

決定する内容と、ポイントが何を表すかを説明します。同じ程度の範囲を扱う選択肢を追加し、**1人あたりのポイント**を設定します。この例では、各投票者が10ポイントを受け取り、各戦略分野のレビューにどれだけ時間を使うべきかを示します。

![](form.png)

ポイント数を多くしすぎると、実際以上に精密な判断であるかのように見えることがあります。通常は、違いを示せる程度に多く、配分先を選ぶ必要がある程度に少ないポイント数が適切です。すべてのポイントを1つの選択肢に集中させてもよいかを明示します。

<!-- translation-section: vote -->

## 投票する

参加者はスライダーを動かしてポイントを配分します。Loomioは残りのポイント数を表示し、配分が設定条件を満たすまで送信できないようにします。

![](voting.png)

この例では、投票者は**メンバーの参加**と**財務の持続可能性**にそれぞれ3ポイント、**環境への影響**と**スタッフの育成**にそれぞれ2ポイントを配分し、**製品とサービス**には配分していません。0ポイントは、その分野に価値がないことを必ずしも意味しません。投票者が限られたポイントをほかの分野に使ったことを意味します。

<!-- translation-section: read-the-results -->

## 結果を読む

結果では、獲得したポイントの合計が多い順に選択肢が並びます。次の項目も表示されます。

- **ポイントの割合**：配分された全ポイントのうち、その選択肢が占める割合
- **ポイント**：配分されたポイントの合計
- **平均**：その選択肢にポイントを配分した投票者の平均ポイント数
- **有権者**：その選択肢に1ポイント以上を配分した人数

![](results.png)

この例では、**財務の持続可能性**が最も多くのポイントを獲得し、**スタッフの育成**が続いています。財務の持続可能性にはすべての投票者がポイントを配分しており、レビューに十分な時間を使う必要があるという幅広い合意がうかがえます。合計ポイントと投票者数を併せて確認すると、広く優先されている分野と、少数の人から強く支持されている分野を区別できます。

合計ポイントは、投票者数と投票者の理由と併せて確認します。

<!-- translation-section: share-an-outcome -->

## 結論を共有する

アンケートが締め切られたら、結論を共有します。アンケートは時間や資金を自動的に配分しないため、結果をどのように活用するかを説明します。結論の仕組みについては、[結論を共有する](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome)を参照してください。
