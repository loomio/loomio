# Выбаршчыкі-дэлегаты

Калі некаторыя ўдзельнікі вашай групы павінны мець права голасу, а іншыя — не, вы можаце скарыстацца функцыяй «Прызначыць дэлегатам», каб пазначыць тых, хто мае права голасу. Таксама ёсць адпаведнае дзеянне «Адклікаць статус дэлегата».

Выкарыстоўвайце дэлегатаў, калі людзі павінны мець агульную прастору для абмеркавання, але галасаваць можа толькі вызначанае кола людзей, напрыклад кіраўніцтва або абраныя прадстаўнікі. Звычайна гэта прасцей, чым падтрымліваць асобную падгрупу толькі для таго, каб аддзяліць тых, хто мае права голасу, ад тых, хто яго не мае.

Выкарыстоўвайце прыватную падгрупу, калі яе ўдзельнікам таксама патрэбныя абмеркаванні, файлы або звесткі пра ўдзельнікаў, якія іншыя ўдзельнікі не павінны бачыць.

![Дзеянне «Прызначыць дэлегатам» у меню ўдзельнікаў](member_make_delegate.png)

Каб стварыць апытанне або прапанову і запрасіць толькі дэлегатаў, выкарыстоўвайце наладу апытання «Толькі выбраныя людзі».
![Налада «Толькі выбраныя людзі» пры стварэнні прапановы](poll_invited_people_only.png)
Пасля гэтага пры запрашэнні людзей да галасавання вы ўбачыце варыянт «Дэлегаты групы назва-групы».
![Варыянт «Дэлегаты кааператыва Oatmilk» у форме запрашэння да галасавання](poll_invite_delegates_group.png)

Вы можаце паглядзець спіс дэлегатаў на ўкладцы ўдзельнікаў на старонцы вашай групы. Адкрыйце меню фільтра і выберыце «Дэлегаты».
![Варыянт «Дэлегаты» ў фільтры ўдзельнікаў](members_list_delegates.png)
