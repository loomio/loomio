# דיונים ישירים

דיון ישיר הוא דיון פרטי המיועד לאנשים מסוימים.

דיון ישיר אינו שייך לקבוצה. אין צורך שהאנשים שהוזמנו יהיו חברים בקבוצת Loomio.

ניתן לקבוע מי יוכל לצפות ולהשתתף באמצעות הוספת אנשים או כתובות דוא״ל לשדה **הזמן**.

דיונים ישירים תומכים באותן תגובות, סקרים וכלים אחרים כמו דיונים בקבוצה. הם יכולים להיות שימושיים כשאין צורך ליצור תת־קבוצה.

![טופס דיון ישיר ללא קבוצה נבחרת, עם סמירה פאטל בשדה הזמן](direct-discussion-example.png)

כדי לראות את הדיונים הישירים, יש לבחור **חוטים ישירים** בסרגל הצד. כדי להתחיל דיון ישיר נוסף, יש לבחור **דיון חדש** באותו עמוד.

![הפריט חוטים ישירים בסרגל הצד ורשימת הדיונים הישירים](direct-discussion-sidebar.png)
