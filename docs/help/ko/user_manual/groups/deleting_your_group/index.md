# 그룹 삭제

그룹 관리자만 그룹을 삭제할 수 있습니다. 그룹을 삭제하면 즉시 접근이 차단되고, 모든 그룹 및 하위 그룹 데이터가 90일 후에 영구적으로 삭제되도록 예약됩니다.

그룹을 삭제하기 전에 [그룹 데이터를 내보내고](/en/user_manual/groups/data_export) 업로드한 파일 중 보관할 파일을 다운로드하세요.

그룹을 삭제하려면 그룹의 작업 메뉴를 열고 **그룹 삭제**를 선택하세요.

![Oatmilk Cooperative 메뉴의 그룹 삭제 항목](group_delete_group.png)

그룹 핸들을 입력하여 삭제를 확정하세요.

![Oatmilk Cooperative 핸들을 입력해야 하는 확인 양식](group_delete_group_confirm.png)

삭제를 확정하면 다음과 같이 처리됩니다.

- 그룹과 해당 하위 그룹이 즉시 화면에서 사라집니다. 멤버와 그룹 관리자는 콘텐츠를 보거나 참여하거나 내보낼 수 없으며, 저장된 링크로 연 투표도 이용할 수 없습니다.
- 그룹과 해당 하위 그룹의 발송 대기 중인 활동 알림과 투표 알림이 중단됩니다. 이미 발송 중인 메시지는 도착할 수 있습니다.
- Loomio 구독이 취소됩니다.
- 그룹 외부의 직접 토론과 투표에는 영향을 주지 않습니다.

Loomio는 그룹의 하위 그룹, 멤버, 토론, 투표, 댓글 수를 안내하는 경고 이메일도 보냅니다. 실수로 그룹을 삭제했거나 아직 데이터를 내보내야 한다면, 접근 권한을 복원할 수 있도록 90일 이내에 해당 이메일에 답장하거나 저희에게 연락하세요.

## 그룹 데이터는 90일 후에 영구적으로 삭제됩니다

90일 후에 Loomio는 그룹과 해당 하위 그룹의 모든 스레드, 투표, 파일 및 기타 콘텐츠를 영구적으로 삭제합니다. 삭제 후에는 복원할 수 없습니다.
