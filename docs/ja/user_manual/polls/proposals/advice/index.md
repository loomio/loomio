# アドバイス

アドバイス提案では、個人やチームが責任を持って行う決定について意見を集めます。参加者はアドバイスを伝えるか、付け加えるアドバイスがないことを示せます。

このページでは、アドバイス提案の入力フォーム、投票、結果について説明します。決定事項の整理から結論の公開までの流れは、[アドバイスの進め方](/en/guides/making_decisions/advice_process)をご覧ください。

<!-- translation-section: when-to-use-advice -->

## アドバイスを使う場面

決定する人が、関連する専門知識を持つ人や決定の影響を受ける人から意見を求めるときに、アドバイスを使います。取引先の選定、業務上の決定、方針案、権限を委ねられた役割での決定に適しています。

アドバイスは承認を求める投票ではありません。誰が決定するのか、どのような制約があるのか、寄せられた回答をどう検討するのかを明示します。

<!-- translation-section: example-choose-a-washing-supplier -->

## 例：洗浄業者を選ぶ

オーツミルク協同組合の業務コーディネーターは、洗浄業者を選ぶ必要があります。対応能力、食品安全に関する記録、水の使用量、問い合わせへの対応時間、サポートについてアドバイスを募ります。

<!-- translation-section: set-up-the-proposal -->

## 提案を設定する

決定する内容と決定者を明記し、参加者に必要な情報を記載します。決定の影響を受ける人や、関連する知識を持つ人を招待します。初期設定の選択肢では、アドバイスを伝えるか棄権するかを選べます。

![](form.png)

<!-- translation-section: vote -->

## 投票する

参加者は**アドバイス**を選び、具体的な提案、懸念点、質問、または関連する経験を伝えます。有用な意見がない場合は棄権できます。

![](../proposal_advice_voting.png)

<!-- translation-section: read-the-results -->

## 結果を読む

グラフでは誰が回答したかを確認できますが、アドバイス提案の重要な内容は回答の理由にあります。最も多い回答をそのまま決定とせず、制約、意見の一致、相反する提案に目を向けます。

![](../proposal_advice_results.png)

決定者は、何を決めたか、アドバイスをどう判断に生かしたかを説明する結論を公開します。
