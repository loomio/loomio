# Gestion des membres

Si vous êtes admin, vous pouvez gérer les membres depuis l’onglet **Membres** de la page de votre groupe.

Cliquez sur les trois points (**⋮**) à droite du nom d’un membre pour définir son rôle, le nommer admin ou délégué, ou le retirer du groupe.

![Menu des actions pour un membre sur la page des membres d’Oatmilk Cooperative](member_management.png)

<!-- translation-section: administering-your-group -->

## Administrer votre groupe
Il existe deux types d’utilisateurs dans un groupe Loomio : les **membres** et les **admins**.

Les admins peuvent ajouter et retirer des membres, gérer leurs autorisations, définir les niveaux de confidentialité du groupe et gérer les abonnements. Ils peuvent aussi voir les adresses e-mail des membres et exporter les données du groupe.

La personne qui crée un groupe Loomio devient admin par défaut. Nous vous recommandons de nommer au moins une autre personne de confiance comme admin, afin que quelqu’un puisse toujours administrer le groupe. Vous pouvez nommer autant d’admins que vous le souhaitez.

Pour nommer un membre **admin**, ouvrez l’onglet Membres, trouvez ce membre et cliquez sur les trois points (**⋮**) à côté de son nom. Choisissez **Nommer admin**. Une étiquette `Admin` apparaîtra à côté de son nom.

![Action Nommer admin dans le menu d’un membre](member_make_admin.png)

<!-- translation-section: managing-subgroups -->

## Gérer les sous-groupes
Si vous êtes admin d’un groupe parent ou d’une organisation, vous disposez d’autorisations supplémentaires pour les sous-groupes __fermés__.

Vous pouvez rejoindre tout sous-groupe fermé en cliquant sur le bouton « Rejoindre le groupe », à gauche de la page du sous-groupe concerné, juste sous les onglets.

![Bouton Rejoindre le groupe sur la page d’un sous-groupe fermé d’Oatmilk Cooperative](member_join_subgroup.png)

Une fois membre du sous-groupe, vous pouvez aussi vous nommer admin, comme vous le feriez pour un autre membre.

>[!Note]
>Ces autorisations ne s’appliquent pas aux [sous-groupes **secrets**](/en/user_manual/groups/subgroups/?highlight=secret#permissions).

<!-- translation-section: removing-members -->

## Retirer des membres
Lorsque vous cliquez sur **Retirer du groupe**, une confirmation vous est demandée. La personne retirée n’aura plus accès aux pages, discussions, sondages ou propositions du groupe. Elle ne recevra plus d’e-mails ni de notifications concernant l’activité du groupe. Ses commentaires et ses votes resteront toutefois en place.

![Action Retirer du groupe dans le menu d’un membre](member_remove.png)

Vous pourrez ajouter à nouveau ces personnes au groupe plus tard.

<!-- translation-section: leaving-group -->

## Quitter un groupe
Pour quitter un groupe, ouvrez sa page, puis le menu à trois points, et cliquez sur **Quitter le groupe**.

![Action Quitter le groupe dans le menu des paramètres d’Oatmilk Cooperative](member_leave_group.png)

<!-- translation-section: set-title -->

## Définir un rôle
Dans l’onglet Membres, vous pouvez utiliser le champ **rôle** pour indiquer votre fonction dans le groupe ou l’organisation que vous représentez. Vous ou un admin du groupe pouvez modifier votre rôle avec **Définir un rôle** dans le menu à trois points à côté de votre nom.

![Action Définir un rôle dans le menu d’un membre](member_set_title.png)

Vous pouvez avoir un rôle différent dans chaque sous-groupe.

<!-- translation-section: member-email-addresses -->

## Adresses e-mail des membres

Seuls les admins peuvent voir les adresses e-mail des membres du groupe. Cela peut être nécessaire pour vérifier la liste des membres.

Pour voir les adresses e-mail des membres, utilisez l’[exportation des données](/en/user_manual/groups/data_export/) pour télécharger un fichier CSV, puis ouvrez-le dans Excel ou Google Sheets.

Le fichier d’exportation des données du groupe indique le nom et l’adresse e-mail de chaque personne dans chaque sous-groupe.

Vous pouvez aussi rechercher un membre par adresse e-mail dans l’onglet Membres. Si vous souhaitez retirer une personne, recherchez son adresse e-mail pour la trouver.
