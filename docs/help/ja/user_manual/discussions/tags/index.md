# カテゴリタグ

カテゴリタグを使うと、話題や業務分野に関するディスカッション、アンケート、結論、コメントを見つけられます。

タグは組織全体で共有されます。親グループで作成したタグはサブグループでも共有されるため、グループをまたいで関連する作業を追跡できます。Loomioではタグがアルファベット順に表示され、名前の横にタグの色を示す点が表示されます。

**すべてのグループ**またはグループページで、スレッド、アンケート、タスクの一覧の上にある**タグ**を選択し、タグを選ぶと、そのタグが付いた項目が表示されます。タグの一覧が長い場合は、絞り込み欄に入力して検索できます。

![](tags_view.png)

<!-- translation-section: apply-tags -->

## タグを付ける

自分のディスカッション、アンケート、結論、コメントにタグを付けられます。グループ管理者、スレッド管理者、ディスカッションの背景説明を編集する権限を持つ人は、ロックされていないスレッド内のどの項目にもタグを付けられます。ダイレクトスレッドでは、すべての参加者がどの項目にもタグを付けられます。

スレッドやアンケートを開始するときに、**タグ**欄を選択して、タグを1つ以上選びます。

![](tags_add_new.png)

文字を入力すると、一覧を絞り込めます。タグをもう一度選択するか、タグの**×**を選択すると、そのタグを外せます。

<!-- translation-section: create-tags -->

## タグを作成する

タグを作成できる人は、グループの役割と権限によって決まります。

- **親グループの管理者**は、いつでも親グループとそのサブグループで使うタグを作成できます。
- **サブグループの管理者**は、自分が管理するサブグループのコンテンツにタグを付ける際に、新しいタグを作成できます。
- コンテンツにタグを付けられる**グループの人（仲間）たち**は、**メンバーはタグを作成できます**が有効な間、新しいタグも作成できます。この設定は初期設定で有効になっています。グループ管理者が無効にすると、メンバーが使えるのは、組織の既存のタグと、そのグループのテンプレートで指定された初期設定のタグだけになります。

スレッドやアンケートを開始するときにタグを作成するには、**タグ**欄に名前を入力してEnterキーを押します。

![新しいタグを作成](tags_create_new.png)

![作成された新しいタグ](tags_created_new.png)

「財務」「組織運営」「梱包」「カフェとの連携」など、短く分かりやすい名前を使います。

<!-- translation-section: template-tags -->

## テンプレートのタグ

ディスカッションとアンケートのテンプレートには、タグ名が初期設定として保存されます。テンプレートを作成または編集できる人は、その初期設定のタグを変更できます。テンプレートを保存しても、これらの名前は組織のタグ一覧に追加されません。また、組織のタグの名前を変更したり削除したりしても、テンプレートの初期設定は変わりません。

テンプレートからディスカッションやアンケートを開始すると、Loomioは組織の一致するタグを適用します。作成者に権限がある場合は、新しいタグを作成します。

- **タグを作成できるメンバー**は、テンプレートの初期設定のタグをすべて維持できます。
- **タグを作成する権限がないメンバー**は、組織の既存のタグと、作成先のグループのテンプレートで指定された初期設定のタグを維持できます。他のグループのテンプレートにあるタグ名で、これらに一致しないものは除外されます。

<!-- translation-section: edit-tags -->

## タグを編集する

タグの名前や色の変更、統合、削除ができるのは、親グループの管理者だけです。変更は、すべてのサブグループを含む組織全体に適用されます。

グループページで**タグ**を開き、**タグを編集**を選択するか、**設定**を開いて**カテゴリタグ**を選択します。

![カテゴリタグを編集](tags_edit_new.png)

タグの横にある鉛筆アイコンを選択して編集します。

![カテゴリタグを編集](tags_edit_new_pencil.png)

タグ名を変更するか色を選択して、**保存**を選択します。

![タグの色を編集](tags_edit_name.png)

タグを別のタグに統合するには、そのタグの横にある統合アイコンを選択し、残すタグを選びます。元のタグが付いているすべての項目が、選択したタグに移ります。

タグを削除するには、**消去**（またはごみ箱アイコン）を選択します。組織内のすべてのディスカッション、アンケート、結論、コメントから、そのタグが削除されます。

![タグを削除](tags_delete.png)

<!-- translation-section: edit-tag-in-thread-or-poll -->

### スレッドやアンケートのタグを編集する

既存のスレッドやアンケートのタグを変更するには、そのスレッドやアンケートを開き、タイトル付近の現在のタグの横にあるタグボタンを選択します。

タグを選択して追加または解除します。変更はすぐに保存されます。

タグの選択画面には、現在のグループで使われているタグ、組織内の未使用のタグ、その項目で選択されているタグが表示されます。複数のグループがある組織では、**他のグループのタグを表示**を選択すると、他のグループだけで使われているタグも表示されます。**このグループで使用されているタグを表示する**を選択すると、一覧を再び絞り込めます。

![スレッドのタグを編集](tags_thread_edit.png)

<!-- translation-section: tag-contributions -->

## 投稿にタグを付ける

アンケート、結論、コメントの三点メニュー（**⋯**）を開き、**タグを適用する**を選択します。タグの選択画面でタグを追加または解除すると、変更はすぐに保存されます。投稿にタグが付いている場合、投稿者の情報がある行の右側に、タグとタグボタンが表示されます。

タグは選択した項目に適用されます。投票や投票用紙にはタグを付けられません。

<!-- translation-section: find-tagged-contributions -->

## タグ付きの投稿を見つける

スレッド内のコメント、アンケート、結論にタグが付いていると、スレッドのサイドバー（モバイルではナビゲーションドロワー）に**タグ**セクションが表示されます。

タグを選択すると、一致する項目と、その項目の返信先だけがスレッドに表示されます。スレッド全体の表示に戻るには、絞り込みバーの**×**を選択するか、タグをもう一度選択するか、サイドバーで**クリア**を選択します。

![スレッドのサイドバーのタグ](tags_thread_sidebar.png)

<!-- translation-section: global-search -->

## タグで検索

上部のナビゲーションから**検索**を開き、親グループを選択すると、タグメニューが表示されます。タグを選択すると、そのタグが付いたディスカッション、アンケート、結論、コメントを検索できます。

検索欄を空にするとタグで閲覧でき、キーワードを入力するとタグが付いた項目の中を検索できます。**任意のタグ**を選択すると、絞り込みが解除されます。

![親グループを選択した後、全体検索でタグを選択する](tags_global_search.png)
