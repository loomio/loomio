# Umfragen

Mit Umfragen kannst du Optionen auswählen, bewerten, Punkte verteilen, Rangfolgen festlegen, Verfügbarkeiten angeben oder an Wahlen teilnehmen. Wähle die Abstimmungsmethode danach aus, was die Teilnehmenden ausdrücken sollen und wie du das Ergebnis nutzen möchtest. Verwende einen [Vorschlag](/en/user_manual/polls/proposals/), wenn Personen zu einer Aussage oder einem Vorgehen Stellung nehmen sollen.

<!-- translation-section: simple-poll -->

## Einfache Umfrage

Bei [Wählen](/en/user_manual/polls/choose/) können Teilnehmende eine oder mehrere Optionen auswählen. Damit kannst du die beliebteste Option finden oder eine engere Auswahl erstellen.

<!-- translation-section: score-poll -->

## Bewertung

Bei [Punktzahl](/en/user_manual/polls/score/) bewerten Teilnehmende jede Option auf derselben Skala. Damit kannst du vergleichen, wie stark die Unterstützung ist oder wie bereit, geeignet oder wichtig die einzelnen Optionen sind.

<!-- translation-section: dot-vote -->

## Punktevergabe

Bei [Zuweisen](/en/user_manual/polls/allocate/) erhalten alle Teilnehmenden eine feste Anzahl von Punkten, die sie verteilen können. Damit kannst du Prioritäten erkennen, wenn mehr Aufmerksamkeit oder Ressourcen für eine Option weniger für eine andere bedeuten.

<!-- translation-section: ranked-choice -->

## Rangfolge

Bei [Rang](/en/user_manual/polls/rank/) ordnen Teilnehmende die Optionen nach ihren Präferenzen. Damit kannst du die bevorzugte Reihenfolge der Gruppe ermitteln oder die Option mit der größten Unterstützung auswählen.

<!-- translation-section: time-poll -->

## Zeitumfrage

Bei einer [Zeitumfrage](/en/user_manual/polls/meeting_polls/) geben Teilnehmende an, wann sie verfügbar sind. Damit kannst du ein Treffen oder eine Veranstaltung auch über Zeitzonen hinweg planen.

<!-- translation-section: stv-election -->

## STV-Wahl

Bei [STV-Wahlen](/en/user_manual/polls/stv/) ordnen Teilnehmende Kandidierende nach ihren Präferenzen. Das Verfahren ermöglicht eine Verhältniswahl mit mehreren Gewählten. Verwende STV, um ein Komitee, einen Vorstand oder eine Gruppe von Delegierten zu wählen.

<!-- translation-section: other-specialized-method -->

## Weitere spezielle Methode

Loomio bietet auch eine Fragerunde, in der Fragen ohne Abstimmung gesammelt werden. Gruppenadmins können sie unter [Umfragevorlagen](/en/user_manual/polls/poll_templates/) verfügbar machen.
