# 대표자 투표자

그룹의 일부 멤버에게만 투표 권한을 부여해야 하는 경우, "대표자 지정" 기능으로 투표 권한이 있는 멤버를 지정할 수 있습니다. 지정을 해제하는 "대표자 해제" 기능도 있습니다.

같은 토론 공간을 공유하면서 이사나 선출된 대표자 등 정해진 멤버만 투표할 수 있어야 할 때 대표자 기능을 사용하세요. 투표자와 투표 권한이 없는 멤버를 구분하기 위해 별도의 하위 그룹을 유지하는 것보다 대체로 간단합니다.

해당 멤버들에게 다른 멤버가 볼 수 없어야 하는 토론, 파일 또는 멤버십 정보도 필요한 경우에는 비공개 하위 그룹을 사용하세요.

그룹 페이지에서 **멤버**를 열고 해당 멤버를 찾은 다음, 이름 옆의 점 세 개 메뉴에서 **대표자 지정**을 선택하세요. 지정을 해제하려면 같은 메뉴에서 **대표자 해제**를 선택하세요.

![멤버 메뉴의 대표자 지정 기능](member_make_delegate.png)

투표나 제안을 만들고 대표자만 초대하려면 투표 설정에서 "선택한 사람만"을 사용하세요.
![제안을 시작할 때의 선택한 사람만 설정](poll_invited_people_only.png)
그러면 투표할 사람을 초대할 때 "group-name의 대표자" 선택지가 표시됩니다.
![투표 초대 양식의 Oatmilk Cooperative 대표자 선택지](poll_invite_delegates_group.png)

그룹 페이지의 멤버 탭에서 대표자 목록을 확인할 수 있습니다. 필터 메뉴에서 "대표자"를 선택하세요.
![멤버 필터의 대표자 선택지](members_list_delegates.png)
