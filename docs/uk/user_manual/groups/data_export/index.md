# Резервна копія або експорт даних групи

За допомогою експорту даних групи ви можете:

- Завантажити файл із даними учасників, щоб перевірити склад групи.
- Завантажити вміст групи, зокрема тексти тем і опитувань, для архівування або аналізу.
- Відкрити результати опитувань у табличному редакторі або обробити їх мовою програмування.
- [Надрукувати тему чи опитування або зберегти їх у PDF для архіву.](#print-thread-to-pdf)
- Перенести групу з усіма користувачами, темами, опитуваннями та файлами на інший сервер Loomio.

Якщо ви захочете перейти з керованих серверів Loomio [на власний сервер](https://github.com/loomio/loomio), скористайтеся цією функцією.

Якщо ви більше не хочете підтримувати власний сервер Loomio, можна перейти на керований хостинг Loomio у США, ЄС або Австралії. Щоб перенести групу на один із цих серверів, [зв’яжіться з нами](/contact).

[Зв’яжіться з нами](/contact), якщо ви хочете перенести групу з глобального сервісу Loomio на loomio.com до одного з регіональних сервісів: loomio.eu для Європи або loomio.nz для Австралії та Нової Зеландії.

### Експорт даних групи у форматі CSV

*Для роботи з даними групи в табличному редакторі, наприклад MS Excel або Google Sheets.*

Loomio підготує файл CSV у фоновому режимі й надішле вам електронною поштою посилання для завантаження. Посилання діятиме один тиждень.

### Експорт даних групи у форматі HTML

*Для збереження даних в архіві.*

Loomio підготує файл HTML у фоновому режимі й надішле вам електронною поштою посилання для завантаження. Посилання діятиме один тиждень.

<!-- translation-section: export-group-data-as-json -->

### Експорт даних групи у форматі JSON

*Для перенесення даних групи на власний сервер Loomio.*

Щоб експортувати групу, ви маєте бути її адміністратором. Експорт JSON містить:

- Групу, її учасників і запити на вступ
- Теми, коментарі, реакції, теги, шаблони, сповіщення та пов’язані записи з груп, які входять до експорту
- Опитування, варіанти відповідей, голоси та висновки; анонімне опитування входить до експорту лише після закриття
- Підгрупи, до яких ви належите
- Відкриті й закриті підгрупи, якщо ви експортуєте їхню батьківську групу як її адміністратор, навіть коли не належите до цих підгруп
- Посилання на файли й зображення, прикріплені до вмісту, який входить до експорту

Експорт JSON не містить:

- Секретних підгруп, до яких ви не належите, разом із даними про їхніх учасників і вмістом
- Підгруп, що очікують на видалення
- Анонімних опитувань, які ще не закрито
- Прямих тем і опитувань, які не належать до групи

Невдовзі ви отримаєте електронний лист із посиланням для завантаження файлу JSON.

## Друк теми у PDF

Ви можете зберегти копію теми в окремому файловому архіві.

**Друкувати** зберігає оформлення теми, усі коментарі, опитування, голоси та висновки.

У меню теми натисніть три крапки (⋯) і виберіть **Друкувати**. Loomio створить сторінку HTML, яку ви зможете надрукувати або «зберегти як PDF» за допомогою функції друку у браузері.

Ви можете скопіювати сторінку й вставити її в редактор документів, файл або сховище даних.

![Пункт «Друкувати» для обговорення поворотних пляшок](discussion_print_discussion.png#width-90)

## Імпорт даних групи на інший сервер Loomio

Інструкції з налаштування власного сервера Loomio: https://github.com/loomio/loomio

Якщо ви розмістили Loomio на власному сервері й хочете імпортувати експортовані дані:

Скопіюйте файл .json до папки `import` у контейнері:

`scp your-group-data.json username@some-domain.org:loomio-deploy/import`

Відкрийте консоль Rails у запущеному контейнері:

`docker exec -ti loomio-app rails console`

Викличте сервіс:

`GroupExportService.import('/import/your-group-data.json')`
