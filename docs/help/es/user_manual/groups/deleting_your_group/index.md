# Eliminar tu grupo

Solo un admin del grupo puede eliminar un grupo. Eliminar un grupo retira el acceso inmediatamente y programa la eliminación permanente de todos los datos del grupo y sus subgrupos después de 90 días.

Antes de eliminar un grupo, [exporta los datos del grupo](/en/user_manual/groups/data_export) y descarga los archivos subidos que quieras conservar.

Para eliminar un grupo, abre **Configuración ** en la página del grupo y selecciona **Eliminar grupo**.

![Acción Eliminar grupo en la página de configuración de Oatmilk Cooperative](group_delete_group.png)

Introduce el identificador del grupo para confirmar la eliminación.

![Formulario de confirmación que requiere el identificador de Oatmilk Cooperative](group_delete_group_confirm.png)

Cuando confirmas la eliminación:

- El grupo y sus subgrupos dejan de estar visibles inmediatamente. Los miembros y admins del grupo pierden el acceso para consultar el contenido, participar o exportarlo, incluidas las encuestas abiertas desde enlaces guardados.
- Se detienen las notificaciones de actividad y los recordatorios de encuestas pendientes del grupo y sus subgrupos, aunque los mensajes que ya se estén enviando pueden llegar igualmente.
- Se cancela tu suscripción a Loomio.
- Las discusiones y encuestas directas fuera del grupo no se ven afectadas.

Loomio también envía un correo de advertencia que indica el número de subgrupos, miembros, discusiones, encuestas y comentarios del grupo. Si eliminaste el grupo por error o todavía necesitas exportar sus datos, responde a ese correo o contacta con nosotros dentro de los 90 días para restablecer el acceso.

## Los datos del grupo se eliminan permanentemente después de 90 días

Después de 90 días, Loomio elimina permanentemente todos los hilos, encuestas, archivos y demás contenido del grupo y sus subgrupos. Esta acción es irreversible.
