# Требования к доле голосов

Установите требование к доле голосов для варианта, если для принятия предложения ему нужна определённая доля поддержки или доля голосов против не должна превышать заданный предел.

Требование к доле голосов можно сочетать с [кворумом](/en/user_manual/polls/quorum/), чтобы задать и минимальное участие, и необходимое распределение голосов.

При создании предложения выберите значок редактирования рядом с вариантом.

![Значок редактирования рядом с вариантом «Согласие»](edit-highlight-on-option.png)

## Имеющие право голоса и поданные голоса

Процент можно рассчитывать по **Поданным голосам** или по числу **Имеющих право голоса избирателей**.

![Выбор основы для расчёта доли голосов: поданные голоса или имеющие право голоса избиратели](./eligible-vs-cast.png)

**Имеющие право голоса избиратели** — все, кто может голосовать по предложению. **Поданные голоса** — только голоса, которые уже отправлены.

Если требуется поддержка 75% имеющих право голоса избирателей, вариант пройдёт только тогда, когда за него проголосуют не менее 75% всех, кто имеет право голоса.

Если требуется поддержка 60% от поданных голосов, варианту достаточно получить 60% отправленных голосов независимо от общей явки. Добавьте кворум, если ваш процесс также требует минимального участия.

## Разные требования к доле голосов

В предложении можно задать требования для нескольких вариантов. Например:

- «Согласен» — не менее 75% имеющих право голоса избирателей
- «Воздержался» — не более 30% поданных голосов
- «Блокирую» — не более 0% поданных голосов

Требования можно также добавить в [шаблон голосования](/en/user_manual/polls/poll_templates/). Тогда они будут применяться по умолчанию к новым предложениям, созданным по этому шаблону.

## Подробный пример

Кооператив Oatmilk решает, утвердить ли бюджет шестинедельного испытания возвратных бутылок. Право голоса есть у пяти человек.

Джейми выбирает шаблон предложения **Согласие**, редактирует вариант «Согласие» и включает для него требование к доле голосов.

По правилам кооператива предложение должны поддержать не менее 75% имеющих право голоса избирателей. Джейми устанавливает требование **Не менее 75% Имеющих право голоса избирателей**.

![Для варианта «Согласие» требуется поддержка не менее 75% имеющих право голоса избирателей](./consent-vote-option.png)

Джейми также устанавливает кворум 60%. Джейми и Самира голосуют за. Все поданные голоса поддерживают предложение, но их подали лишь 40% имеющих право голоса избирателей. Поэтому ни одно из требований пока не выполнено.

![Двое из пяти человек проголосовали за, но ни одно требование не выполнено](./first-vote-breakdown.png)

Затем Алекс и Морган голосуют за, а Тейлор — против. Проголосовали все пять человек, поэтому кворум достигнут. Предложение поддержали четверо из пяти имеющих право голоса избирателей. Доля поддержки составляет 80% и превышает требуемые 75%, поэтому рядом с обоими требованиями появляются зелёные галочки.

![Все пять человек проголосовали, и оба требования выполнены](./final-vote-breakdown.png)
