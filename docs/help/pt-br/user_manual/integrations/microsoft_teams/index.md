# Integração com o Microsoft Teams

O Loomio pode enviar notificações para seus canais do Microsoft Teams quando houver novas discussões, enquetes, comentários, votos e conclusões.

---

1. Abra o [Microsoft Teams](https://teams.microsoft.com) e selecione **Aplicativos**.

   ![](t1.png)

2. Pesquise por `webhook` e selecione **Webhook de Entrada**.

   ![](t2.png)

3. Selecione **Adicionar a uma equipe**.

   ![](t3.png)

4. Escolha o canal em que você quer que as notificações do Loomio apareçam.

   ![](t4.png)

5. Insira um nome, como `Loomio notifications`, e selecione **Criar**.

   ![](t5.png)

6. Copie a URL do webhook para poder colá-la no Loomio.

   ![](t6.png)

Agora que você tem uma URL de webhook, conclua a conexão no Loomio:

[Configure uma integração de chat no Loomio](../chatbots/#set-up-a-chat-integration)

_O Loomio não é criado nem apoiado pela Microsoft e não tem vínculo com ela._
