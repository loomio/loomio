# Hilos directos

Un hilo directo es un hilo privado para personas específicas. No pertenece a ningún grupo, y las personas invitadas no necesitan pertenecer a ningún grupo de Loomio.

Añade personas o direcciones de correo electrónico al campo **Invitar** para elegir quién puede ver el hilo y participar.

Los hilos directos permiten usar los mismos comentarios, encuestas y herramientas de formato que las discusiones de grupo. Son útiles para conversaciones privadas o borradores cuando no es necesario crear un subgrupo.

![Un formulario de hilo directo sin ningún grupo seleccionado y con Samira Patel en el campo Invitar](direct-discussion-example.png)

Selecciona **Hilos directos** en la barra lateral para ver tus hilos directos y encuestas. Desde allí, abre **Nuevo** y elige **Nueva discusión** para iniciar un hilo directo, o **Nuevo sondeo** para iniciar una encuesta sin un grupo.

Una encuesta directa solo es visible para las personas que invites. Después de crearla, usa [Gestionar a los votantes](/en/user_manual/polls/manage_voters) para invitar a personas o direcciones de correo electrónico.

![La opción Hilos directos en la barra lateral y la lista de hilos directos](direct-discussion-sidebar.png)

## Mover un hilo directo a un grupo

Si una conversación privada o un borrador pasa a ser un tema de interés para un grupo, puedes moverlo a un grupo o subgrupo más adelante. Consulta [Mover un hilo](/en/user_manual/discussions/using_discussions/#move-a-thread).
