# Інтэграцыя з Mattermost

Loomio можа адпраўляць апавяшчэнні ў вашы каналы Mattermost, калі з’яўляюцца новыя абмеркаванні, апытанні, каментарыі, галасы і высновы.

---

1. Адкрыйце вашу каманду Mattermost у браўзеры і перайдзіце ў **Інтэграцыі**.

   ![](mm1.png)

2. Выберыце **Уваходныя вэбхукі**.

   ![](mm2.png)

3. Выберыце **Дадаць уваходны вэбхук**.

   ![](mm3.png)

4. Увядзіце назву, выберыце канал, у якім будуць з’яўляцца апавяшчэнні, і націсніце **Захаваць**.

   ![](mm4.png)

5. Скапіруйце URL вэбхука.

   ![](mm5.png)

Цяпер, калі ў вас ёсць URL вэбхука, завяршыце падключэнне ў Loomio:

[Наладзьце інтэграцыю з чатам у Loomio](../chatbots/#set-up-a-chat-integration)
