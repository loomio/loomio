# Intégration Microsoft Teams
_Connectez les notifications de votre groupe Loomio à Microsoft Teams._

Loomio peut envoyer des notifications dans Microsoft Teams lorsque de nouvelles discussions, propositions, commentaires, votes et conclusions sont publiés.

---

Rendez-vous sur [https://teams.microsoft.com](https://teams.microsoft.com), puis cliquez sur Applications
![](t1.png)

Recherchez « webhook » dans le champ de recherche, puis cliquez sur Webhook entrant
![](t2.png)

Cliquez sur « Ajouter à une équipe »
![](t3.png)

Saisissez le nom du canal dans lequel vous souhaitez recevoir les notifications Loomio, puis sélectionnez-le.
![](t4.png)

Donnez-lui un nom, par exemple « Notifications Loomio », puis cliquez sur « Créer »
![](t5.png)

Copiez l’URL fournie ; vous la collerez dans Loomio à la dernière étape.
![](t6.png)

_Loomio n’est ni créé par Microsoft, ni affilié à Microsoft, ni pris en charge par Microsoft._

Maintenant que vous disposez d’une URL de webhook, poursuivez la configuration de votre intégration de messagerie :

[Configurer une intégration de messagerie dans Loomio](../chatbots/#set-up-a-chat-integration)
