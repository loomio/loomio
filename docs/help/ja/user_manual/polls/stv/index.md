# STV選挙

**単記移譲式投票（STV）**は、複数の候補者から複数の当選者を選ぶ比例代表の投票方法です。当選者の構成に、投票者の多様な意見が比例して反映されるようにします。

<!-- translation-section: when-to-use-stv -->

## STVを使う場面

次のような場合にSTV選挙を使います。

- 推薦された候補者の中から**委員会の委員、理事、または代表者の一団**を選びます
- 少数派も支持の割合に応じて議席を獲得できる**比例代表**を実現します
- 投票者が候補者に希望順の順位を付ける選挙を行います

>[!NOTE]
>STVは、Loomioの[ランク投票](/en/user_manual/polls/rank/)と**同じではありません**。ランク投票は、スコアに基づく簡単な順位付けで、最も望ましい選択肢を1つ選ぶものです。STVは、票の移譲と脱落のラウンドを通じて、複数の当選者を選ぶ選挙を扱います。

<!-- translation-section: creating-an-stv-election -->

## STV選挙の作成

アンケートを開始するときに、アンケートの種類として**STV選挙**を選び、候補者を選択肢として追加します。**議席数**、**集計方法**、**クォータの種類**を設定して、アンケートを調整できます。

この例では、Oatmilk Cooperativeが、返却可能な包装の試験運用を監督する3人を選びます。フォームには役割の説明と5人の候補者が記載されており、Droopクォータを使うスコットランド式STVが設定されています。

![](form.png)

<!-- translation-section: number-of-seats -->

### 議席数

当選者を何人選ぶかを設定します。候補者数より少なくする必要があります。

<!-- translation-section: counting-method -->

### 集計方法

票の集計には、次の2つの方法を使えます。

スコットランド式STV
  : 推奨の方法です。2007年からスコットランドの地方選挙で使われている加重包括グレゴリー法（WIGM）です。ルールが明確で分かりやすく、ほとんどの組織に適しています。
  
Meek式STV
  : コンピューターでのみ集計できる、より精密な方法です。候補者が当選すると、Meek式では各票のうち当選に必要のない部分を、投票者の次の希望候補者へ引き続き移譲します。集計の後の段階でその当選者に届いた票も対象になります。候補者が脱落すると、その候補者が最初から立候補していなかったものとして票を再集計します。スコットランド式STVより無駄になる票が少なくなりますが、手作業では集計を検証できません。

<!-- translation-section: quota-type -->

### クォータの種類

クォータは、候補者が議席を獲得するために必要な最小票数です。次のいずれかを選べます。

Droop
  : 推奨のクォータです。アイルランド、オーストラリア、スコットランドで使われている、STV選挙の標準的なクォータです。到達できる候補者数が議席数を超えない、最小のクォータです。支持する候補者を第一希望にする投票者の集団は、保有する票数に含まれるクォータの数以上の議席を獲得できます。次の式で計算します。
\\[ floor(\frac{votes}{(seats + 1)}) + 1 \\]

Hare
  : より大きなクォータです。票数の多い集団は、獲得する議席ごとにより多くの票を使うため、小さな集団が最後の議席を獲得しやすくなります。次の式で計算します。
    \\[ \frac{votes}{seats}\\]

どちらの式でも、*votes*は、少なくとも1人の候補者に順位を付けた投票用紙の数です。

Meek式STVでは、クォータを丸めずに計算します。Droopの場合は votes ÷ (seats + 1) です。各ラウンドで候補者が保持している票を基にクォータを再計算し、候補者はクォータを超える票を得ると当選します。
  
  >[!TIP]
  > Droopで計算される票数は、常にHareより小さくなります。例えば、100票で4議席を選ぶ選挙では、Droopクォータは21、Hareクォータは25になります。

<!-- translation-section: how-voting-works -->

## 投票の仕組み

この例では、Oatmilk Cooperativeが、再利用可能な包装の試験運用を監督する3人を選びます。投票者は候補者を線の上にドラッグし、希望順に順位を付けます。

![](stv-vote-in-progress.png)

- **ランク1** = 最も希望する候補者
- **ランク2** = 第二希望の候補者
- 希望する人数の候補者に順位を付けます

投票者は少なくとも1人の候補者に順位を付ける必要がありますが、全員に順位を付ける必要はありません。順位を付けなかった候補者には、その投票者の票は移譲されません。

<!-- translation-section: how-counting-works -->

## 集計の仕組み
集計は次の手順で行います。

1. **クォータ**（議席を獲得するために必要な最小票数）を計算します。
2. 候補者ごとに**第一希望**の票を数えます。
3. クォータに達した候補者は全員**当選**します。クォータを超える余剰票は、余剰が最も大きい候補者から順に、各票の一部の価値として投票者の次の希望候補者へ**移譲**されます。票は、集計に残っている候補者にのみ移譲されます。
4. 移譲する余剰票が残っていない場合、**票数が最も少ない候補者が脱落**します。その候補者の票は、価値を減らさずに投票者の次の希望候補者へ移譲されます。
5. 残っている候補者数と残りの議席数が等しくなった場合、クォータに達していなくても、その候補者全員が当選します。
6. それ以外の場合は、すべての議席が埋まるまで手順3から集計を繰り返します。

票の価値を分割することで、当選者に必要のない票だけを分配します。例えば、クォータが26で、候補者が40票を得ている場合、余剰は14票です。その候補者の40枚の投票用紙は、それぞれ14 ÷ 40 = 0.35票の価値で次の希望候補者へ移譲されます。

スコットランド式STVでは、スコットランドの地方議会選挙と同様に、移譲する各票の価値を小数点以下5桁で切り捨てます。

最少票数の候補者が2人以上いる場合は、過去のラウンドを直近からさかのぼり、票数に差がある最初のラウンドで票数が少なかった候補者が脱落します。

>[!TIP]
>投票用紙は、順位を付けた候補者が集計に残っている間だけ数えられます。その候補者が誰も残っていなくなると、投票用紙は「使い切られた」ものとなり、以後の集計には数えられません。

### 方法とクォータ

上部には、集計方法（スコットランド式STVまたはMeek式STV）、クォータの種類（DroopまたはHare）、クォータが表示されます。クォータは、候補者が議席を獲得するために必要だった票数です。

<!-- translation-section: elected-candidates -->

### 当選した候補者

当選者の概要が、次の5列の表に表示されます。

| 列 | 意味 |
|--------|---------|
| **候補者** | 当選した候補者の名前です。 |
| **ラウンド選出** | クォータに達して議席を獲得した集計ラウンドです。ラウンド1は、第一希望の票だけで当選したことを示します。それ以降のラウンドは、脱落した候補者の票や、当選した候補者の余剰票の移譲が必要だったことを示します。 |
| **第一希望** | この候補者を第一希望にした投票者の数です。票が移譲される前の、候補者への直接の支持を示します。 |
| **最終集計** | 当選した時点での候補者の票数です。票の移譲によって、第一希望の票数より多くなることがよくあります。 |
| **余剰** | 候補者の最終集計がクォータをどれだけ超えたかを示します（最終集計からクォータを引いた値）。余剰が大きいほど、当選に必要な票数を超えて多くの支持を得たことを示します。スコットランド式STVでは、この余剰を投票者の次の希望候補者へ再分配します。 |

過去のラウンドを参照しても同票を解消できない場合があります。同票の扱いによって当選者が変わらない場合は、集計を続けます。当選者が変わる場合は、そのラウンドで集計を停止します。同票をどのように解消しても当選する候補者は、当選者として表示されます。同票の扱いによって当選する場合も落選する場合もある候補者は、別の表に表示されます。Loomioは無作為に1人を選ぶのではなく、同票として表示します。

<!-- translation-section: round-by-round-details -->

### ラウンドごとの詳細

**ラウンドごとの詳細**を展開すると、票の移譲と候補者の脱落を確認できます。各行は候補者、各列は集計ラウンドを表します。各数値は、そのラウンドの開始時点で候補者が保持していた票数です。

![](stv-results.png)

緑色の強調表示は候補者が当選したラウンド、赤色は脱落したラウンド、オレンジ色は同票になったラウンドを示します。

## 結論を共有する

選挙を締め切ったら、結論を共有します。当選した人の名前と、役割を開始する時期を記載します。結論の使い方については、[結論を共有する](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome)をご覧ください。

## 投票用紙のエクスポート

選挙を締め切った後、結果を閲覧できる人は、独立した再集計や監査のために投票用紙をBLT形式でエクスポートできます。エクスポートには候補者の順位が含まれ、同じ順位の投票用紙は、その枚数とともに1行にまとめられます。匿名の選挙では、投票者を特定する情報、投票用紙の識別子、送信時刻、送信順序は含まれません。
