# Делегаты с правом голоса

Если право голоса должно быть только у некоторых участников вашей группы, отметьте их с помощью действия «Сделать делегатом». При необходимости статус делегата можно отменить действием «Отозвать делегата».

Используйте делегатов, когда всем нужно участвовать в одних обсуждениях, но голосовать могут только определённые люди, например руководители или избранные представители. Обычно это проще, чем создавать отдельную подгруппу только для разделения участников по праву голоса.

Если этим участникам также нужны обсуждения, файлы или сведения об участниках, которые остальные не должны видеть, создайте закрытую подгруппу.

![Действие «Сделать делегатом» в меню участника](member_make_delegate.png)

Чтобы создать голосование или предложение и пригласить только делегатов, выберите настройку «Только для избранных».
![Настройка «Только для избранных» при создании предложения](poll_invited_people_only.png)
При приглашении к голосованию вы увидите вариант «Делегаты Название группы».
![Вариант «Делегаты Oatmilk Cooperative» в форме приглашения к голосованию](poll_invite_delegates_group.png)

Список делегатов можно посмотреть на вкладке участников страницы вашей группы. Откройте меню фильтров и выберите «Делегаты».
![Вариант «Делегаты» в фильтре списка участников](members_list_delegates.png)
