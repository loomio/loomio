# Mattermost連携
_Loomioグループの通知をMattermostのチームチャットに送ります。_

新しいディスカッション、提案、コメント、投票、結論が投稿されると、LoomioからMattermostのチャンネルに通知を送れます。

---

ブラウザーでMattermostのチームを開きます。次に、連携の設定ページを開きます。
![](mm1.png)

「Incoming Webhooks」をクリックします。
![](mm2.png)

次に、「Add Incoming Webhook」をクリックします。
![](mm3.png)

わかりやすい名前を付け、通知を表示するチャンネルを選んで「Save」をクリックします。
![](mm4.png)

Webhook URLをクリップボードにコピーします。次の手順で使用します。
![](mm5.png)

Webhook URLをコピーした状態で、以下のリンクに進みます。

[Loomioでチャット連携を設定する](../chatbots/#set-up-a-chat-integration)
