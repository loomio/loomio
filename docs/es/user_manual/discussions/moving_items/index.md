# Mover elementos entre hilos

Mueve los elementos seleccionados cuando una conversación corresponda a otro hilo, un hilo se haya dividido en temas distintos o quieras reunir discusiones relacionadas. No hay un comando independiente para **Fusionar discusiones**.

Esta opción está disponible para los administradores del grupo y para los miembros cuando **Los miembros pueden gestionar discusiones y comentarios.** está activada en [Permisos del grupo](/en/user_manual/groups/settings/permissions).

Abre el menú de tres puntos (**⋯**) de un elemento y selecciona **Mover elemento**.

![](../using_discussions/comment_move.png)

Selecciona los elementos que quieras mover.

![](../using_discussions/comment_select.png)

Selecciona otros elementos con las casillas y haz clic en **Mover** en la barra de la parte superior de la discusión.

![](../using_discussions/move_items.png)

Elige el grupo o subgrupo y busca la discusión de destino.

Para mover los elementos a una discusión nueva, selecciona **Nueva discusión** y añade el título y el contexto.

![](../using_discussions/move_items_new_thread.png)

Los elementos se mueven del hilo original al hilo seleccionado o recién creado.

![](../using_discussions/new_thread.png)

Si ya no necesitas el hilo original, puedes [bloquearlo](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread). Elimínalo solo si tienes la certeza de que no volverás a necesitarlo.
