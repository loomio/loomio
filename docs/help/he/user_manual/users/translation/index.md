# שפות ותרגום

ניתן לשנות את שפת הממשק של Loomio, או לתרגם דיונים, תגובות והצעות לשפה המועדפת.

<!-- translation-section: application-translation -->

## תרגום היישום

Loomio מזהה את השפה המועדפת בדפדפן. כדי לבחור שפה אחרת, יש לפתוח את **עריכת פרופיל** ולבחור שם שפה.

![שינוי השפה המועדפת](change_language.png)

<!-- translation-section: content-translation -->

## תרגום תוכן
כאשר הודעה בקבוצה נכתבת בשפה שונה מהשפה המועדפת, מופיע מתחת לה כפתור "תרגום". ניתן ללחוץ על הכפתור כדי לתרגם את ההודעה אוטומטית לשפה המועדפת.

![פעולת תרגום מתחת לתגובה](content_translation.png)

הטקסט המתורגם מחליף את הטקסט המקורי בדיון. יש לבחור **מקור** כדי להציג שוב את הטקסט המקורי.

![תגובה שתורגמה מספרדית לאנגלית](content_translated.png)

תרגום תוכן שנכתב על ידי משתמשים מסופק באמצעות Google Translate ומתבצע לפי בקשת משתמשים.

## תרגום אוטומטי

כדי לתרגם אוטומטית תוכן שנתמך בתרגום, יש לפתוח את **עריכת פרופיל** ולבחור **תרגם תוכן לשפה שלי באופן אוטומטי**. Loomio משתמשת בשפה שנבחרה בפרופיל.

![ההעדפה לתרגום תוכן אוטומטי בדף עריכת פרופיל](automatic_translation.png)
