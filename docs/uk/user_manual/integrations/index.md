# Інтеграції

Поєднайте Loomio з іншими інструментами, якими користується ваша група.

<!-- translation-section: choose-where-work-belongs -->

## Виберіть інструмент для кожного виду роботи

Loomio доповнює чати, спільні документи та інструменти для керування завданнями. Кожен із цих інструментів підходить для свого виду роботи.

| Робота | Рекомендований інструмент |
|---|---|
| Короткі запитання, невимушене спілкування та оперативні повідомлення | Чат |
| Спільне редагування документа, який постійно оновлюється | Спільний документ |
| Призначення завдань і відстеження їх виконання | Інструмент для керування проєктами або завданнями |
| Обговорення важливих тем, участь широкого кола людей, ухвалення рішень і підбиття підсумків | Loomio |

Використовуйте Loomio, коли людям потрібен час, щоб обміркувати тему, коли всі, кого вона стосується, повинні мати можливість долучитися, або коли групі потрібно буде згодом знайти обговорення та рішення. Додайте до обговорення в Loomio посилання на відповідний документ або завдання, щоб потрібний контекст було легко знайти.
