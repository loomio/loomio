# קבוצות

קבוצה ב-Loomio היא מקום בטוח למפגש, לקיום דיונים ולקבלת החלטות.

זהו מרחב שבו חברי הקבוצה יכולים למצוא ולשתף מידע, להשתתף בדיונים חשובים ובקבלת החלטות המשפיעות על עבודתם.

כך נראית קבוצה ב-Loomio. בראש העמוד מופיעים תמונה וסמל שניתן להתאים כדי לייצג את הארגון. כך, עם ההצטרפות לקבוצה, ניתן לזהות מקום מוכר ומזמין — מרחב בטוח שבו אפשר להרגיש בבית, בין חברים, ולהשתתף באופן יעיל.

![עמוד הקבוצה של קואופרטיב Oatmilk, עם תיאור הקבוצה ורשימת הדיונים](group_page.png)

יש לבחור לקבוצה שם שקל לזהות ולהשתמש בתיאור שלה כדי להסביר את מטרתה, מי מעורב בפעילות וכיצד חברי הקבוצה יכולים להשתתף. ניתן גם להוסיף סמל, תמונת כיסוי וקישורים למסמכים, כגון מסמך המגדיר את מטרות הקבוצה וסמכויותיה.

כדי להתחיל, יש [ליצור קבוצה](/en/user_manual/groups/starting_a_group), לבחור את [הגדרות הפרטיות](/en/user_manual/groups/settings/privacy) שלה ו[להזמין אנשים](/en/user_manual/groups/inviting_people).

בעת הכנת קבוצה חדשה, ניתן לעיין ב[היכרות עם Loomio בקבוצה](/en/user_manual/overview/introducing_loomio) לקבלת סדר פעולות מעשי, מבחירת המשימה הראשונה ועד לתיעוד מסקנה.

## ניהול, הנחיה ופיקוח על השיח - כללי התנהגות

כללי התנהגות יכולים לעזור לחברי הקבוצה להבין כיצד להשתתף וכיצד הקבוצה תגיב להתנהגות בלתי הולמת. ניתן לעיין ב[מדריך להנחיה](/en/guides/facilitators_guide/commencing#culture-protocol-expectations) לקבלת הנחיות לתיאום ציפיות.
