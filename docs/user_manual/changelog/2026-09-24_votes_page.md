# Votes page

The Votes page now shows voters in a table with their vote, and their weight when the poll uses vote weights. It no longer displays vote reasons. Search and page controls help find voters in longer polls.

For anonymous polls, **View votes** shows who took part after the poll closes. Anyone who can see the results can open it. Whether each person voted stays hidden until at least three people have voted. The page never shows how or when an anonymous person voted. Only group admins see email addresses.
