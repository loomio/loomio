# Votre profil

Votre profil permet aux autres de vous reconnaître sur Loomio. Ajoutez une photo, une introduction et les autres informations que vous souhaitez partager.

<!-- translation-section: edit-profile -->

## Modifier mon profil

Ouvrez votre menu utilisateur en sélectionnant votre nom dans la barre latérale, puis sélectionnez **Modifier mon profil**. Si la barre latérale est fermée, ouvrez-la à l’aide du bouton de menu (**☰**).

![](edit_profile.png)

<!-- translation-section: update-your-personal-info -->

## Mettre à jour vos informations personnelles

Vous pouvez mettre à jour les champs suivants sur votre page de profil :

- **Nom**
- **Adresse e-mail** — l’adresse associée à votre compte Loomio, à laquelle Loomio envoie vos notifications.
- **Identifiant utilisateur** — le nom que les autres utilisent pour vous notifier avec une `@mention`. Il peut contenir des lettres minuscules, des chiffres, des traits de soulignement et des traits d’union à l’intérieur de l’identifiant.
- **Introduction** — quelques lignes pour vous présenter aux autres membres de votre groupe.
- **Lieu** — utile pour les groupes répartis sur plusieurs sites ou travaillant à distance, afin que les autres sachent où vous vous trouvez.

![](user_profile.png)

<!-- translation-section: uploading-a-profile-photo -->

## Ajouter une photo de profil

Lorsque vous créez un compte Loomio, vos initiales servent d’image de profil par défaut. Pour ajouter une photo, sélectionnez votre image sur la page de profil.

![](profile_photo.png)

<!-- translation-section: language-settings -->

## Langue

Loomio détecte par défaut la langue de votre navigateur. Vous pouvez aussi sélectionner votre langue préférée sur votre page de profil. Pour connaître les options de traduction de l’interface et du contenu, consultez [Langues et traduction](../translation).

<!-- translation-section: time-zone -->

## Fuseau horaire

Les options des sondages horaires utilisent le fuseau horaire enregistré dans votre profil. Activez **Détection automatique du fuseau horaire** pour utiliser le fuseau horaire de votre navigateur, ou désactivez cette fonction, sélectionnez votre région sous **Fuseau horaire**, puis sélectionnez **Mettre à jour mon profil**.

<!-- translation-section: resetting-your-password -->

## Réinitialiser votre mot de passe

Pour modifier votre mot de passe, ouvrez votre page de profil et sélectionnez **Réinitialiser le mot de passe**.

![](reset_password.png#width-90)

<!-- translation-section: passkeys -->

## Clés d’accès

Vous pouvez ajouter, nommer et supprimer des clés d’accès sur votre page de profil pour vous connecter à l’aide du lecteur d’empreintes digitales, de la reconnaissance faciale ou du code PIN de votre appareil, ou d’une clé de sécurité. Consultez [Se connecter avec une clé d’accès](../signing_in#sign-in-with-a-passkey).

<!-- translation-section: merge-accounts -->

## Fusionner des comptes

Si vous avez deux comptes Loomio, vous pouvez les fusionner en un seul compte.

Consultez [Fusionner des comptes](../merge_accounts).

<!-- translation-section: deleting-your-account -->

## Supprimer votre compte

Pour supprimer définitivement votre compte Loomio et quitter vos groupes, consultez [Supprimer votre compte Loomio](../deleting_your_account).
