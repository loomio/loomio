# Slack-integratie
_Koppel de meldingen van je Loomio-groep aan Slack._

Loomio kan meldingen naar je Slack-kanalen sturen wanneer er nieuwe discussies, voorstellen, reacties, stemmen en conclusies zijn. Zo ontvang je op het juiste moment belangrijke updates over discussies en besluiten.

---

Ga eerst naar [https://api.slack.com](https://api.slack.com), log in als je dat nog niet hebt gedaan en klik op Create New App

![](s1.png)

Geef je Slack-app een naam

![](s2.png)

Voeg ondersteuning voor inkomende webhooks toe

![](s3.png)

Schakel de functie vervolgens in

![](s4.png)

Voeg daarna een nieuwe webhook toe

![](s5.png)

Selecteer een kanaal

![](s6.png)

Kopieer de webhook-URL naar je klembord

![](s7.png)

Nu je een webhook-URL hebt, kun je de chatintegratie verder instellen:

[Stel een chatintegratie in Loomio in](../chatbots/#set-up-a-chat-integration)

_Loomio is niet gemaakt door Slack, is niet verbonden aan Slack en wordt niet ondersteund door Slack._
