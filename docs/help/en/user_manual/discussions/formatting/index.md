# Format text and attach files

The formatting bar appears below the text field whenever you start or edit a discussion, create a poll, or write a comment. Select the arrow at the end of the bar to show or hide all tools.

Hover over any icon to see its name.

![](thread_format_bar.png)

<!-- translation-section: attach-file -->

## Attach file

Select the paper clip icon below the text field to attach files from your device.

![](format_attach.png)

<!-- translation-section: remove-attachments -->

### Remove attachments

While editing, select **×** beside a file name to remove it.

![](thread_file_remove.png)

<!-- translation-section: insert-image -->

## Insert image

Select **Insert image** to upload an image, or paste one directly into the editor. The image appears inline in your discussion, poll, or comment.

![](format_insert_example.png)

<!-- translation-section: insert-link -->

## Insert link

You can link to any webpage or online document:

1. Highlight the text you want to turn into a link.
2. Select the link icon.
3. Paste the URL into **Insert link** and select **Apply**.

Check the sharing permissions of any external document so participants can open it. If a link preview appears below your text, you can remove it.

![](format_link.png)

<!-- translation-section: insert-emoji -->

## Insert emoji

Select the smiley icon to pick an emoji.

![](thread_insert_emoji.png)

<!-- translation-section: headings -->

## Headings

Use **Heading 1**, **Heading 2**, and **Heading 3** to structure long discussions or comments.

Comments that include a **Heading 2** or **Heading 3** are automatically added to the thread's **Jump to** list.

![](format_heading.png)

## Task list

![](format_tasks.png)

## Embed videos and webpages

You can embed supported videos and webpages anywhere the formatting bar appears:

1. Copy the URL of the video or webpage.
2. Select **Embed video**, paste the URL, and select **Apply**.

<!-- translation-section: markdown -->

## Markdown

Select **Edit Markdown** to write in Markdown.

Converting to Markdown keeps headings, bold and italic text, lists, basic tables, checked tasks, images, links, and @mentions. Videos, audio, and embedded content become links.

Text colors, highlights, underlining, alignment, and custom table layouts may be lost. Task due dates and reminders are removed; switching back to rich text creates new tasks with the same text and checked state.

<!-- translation-section: rich-text -->

### Rich text

Select **Edit rich text** to return to the formatting toolbar and convert supported Markdown into formatted text.

Select **Preview** to see how your Markdown will look without converting it.
