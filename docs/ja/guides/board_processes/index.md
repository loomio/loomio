# Loomioを活用した適切な組織運営ガイド

適切な組織運営には、理事会の会議だけでなく、会議の前後に十分なコミュニケーションを取ることが必要です。

このガイドでは、理事会や委員会でLoomioを活用する方法を紹介します。会議の合間も連絡を取り合い、緊急の案件に対応し、運営事務を減らすために役立ててください。
- 会議の合間も組織運営を進める
- やり取りを記録する
- 重要な議題に会議の時間を使う
- 詳細な記録を残し、組織の知識を引き継ぐ

Loomioは、理事会や委員会が協力してディスカッションや意思決定を行うための、多用途なツールです。

以下では、理事会や委員会でよく行われる活動と、Loomioでの進め方を紹介します。

## 理事会にオンラインでのディスカッションと意思決定の場が必要な理由

適切な組織運営には、組織の状況に合った仕組みと手続きが必要です。それによって、組織は目的に向けて効果的に活動し、法律上の義務を果たせます。

*「参加型で、合意形成を重視し、説明責任と透明性があり、状況に対応でき、効果的かつ効率的で、公平かつ包摂的であり、法の支配に従うものです。」* [国連アジア太平洋経済社会委員会](https://www.unescap.org/sites/default/d8files/knowledge-products/good-governance.pdf)。

こうした原則はすべて、十分なコミュニケーションに支えられています。

理事や理事会が直面する課題には、次のようなものがあります。

* 理事が対面で集まるのが難しい
* 重要な問題を検討する時間が限られている 
* やり取りを追跡しにくい
* 重要な問題に急いで対応する必要がある
* オンラインのビデオ会議で疲れやすい
* 理事が離れた複数の場所にいて、インターネット接続が不安定な場合もある
* 組織運営の方法や経験がさまざまである
* 多くの日常的な業務に対応する必要がある 
* 組織の知識を引き継ぐ必要がある

Loomioを使うと、理事会の会議以外でも協力を続けられます。全員が率直に、互いを尊重して話し合い、その内容を記録することで、組織運営を強化できます。
