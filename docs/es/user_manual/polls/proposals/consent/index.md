# Consentir

Una propuesta de consentimiento pregunta si es seguro probar una medida. Quienes participan pueden consentir o plantear una objeción. Una objeción señala un riesgo o daño concreto que la propuesta debe abordar.

Esta página explica cómo llevar a cabo una propuesta de consentimiento. Consulta el [proceso de consentimiento](/en/guides/making_decisions/consent_process) para conocer el proceso completo, incluidas las preguntas, la comprobación de sentido, las modificaciones, las objeciones y la conclusión.

<!-- translation-section: when-to-use-consent -->

## Cuándo usar Consentir

Usa Consentir cuando el grupo necesite una decisión viable que pueda llevarse a cabo si no hay objeciones válidas. Sirve para pruebas, políticas operativas, acuerdos sobre funciones y otras decisiones que el grupo pueda revisar después de adquirir experiencia.

Consentir no exige que todo el mundo prefiera la propuesta. Define qué constituye una objeción antes de votar y explica cómo se evaluarán y resolverán las objeciones.

## Ejemplo: iniciar una prueba con botellas

La Cooperativa de Leche de Avena propone iniciar el próximo mes una prueba de seis semanas con botellas retornables. La prueba tiene un alcance limitado e incluye una revisión, así que el grupo pregunta si es seguro llevarla a cabo.

<!-- translation-section: set-up-the-proposal -->

## Prepara la propuesta

Describe la medida propuesta, sus límites, las medidas de protección y cuándo se revisará. Define con precisión el significado de **Consentir** y **Objeción**, y pide que cada objeción incluya un motivo para poder entenderla y abordarla.

![](form.png)

<!-- translation-section: vote -->

## Vota

Quienes participan seleccionan **Consentir** cuando consideran que es suficientemente seguro probar la propuesta, aunque no sea su opción preferida. Seleccionan **Objeción** cuando pueden describir un riesgo o daño significativo.

![](../proposal_consent_voting.png)

<!-- translation-section: read-the-results -->

## Lee los resultados

El gráfico muestra las objeciones, pero el grupo debe examinar los motivos. Para resolver una objeción válida, modifica la propuesta, añade una medida de protección, cambia su alcance o decide no seguir adelante.

![](../proposal_consent_results.png)

Publica una conclusión que indique la medida acordada, las medidas de protección, quién se encargará de llevarla a cabo y cuándo la revisará el grupo.
