# Commentaires

Les commentaires sont le principal moyen de participer à une discussion. Ils sont visibles par toute personne autorisée à consulter le fil.

<!-- translation-section: reading-comments -->

## Lire les commentaires

Lorsque vous ouvrez une discussion, Loomio vous dirige vers l’activité que vous n’avez pas encore vue.

Les commentaires non lus portent une étiquette bleue **nouveau** à côté de leur heure de publication.

![](../using_discussions/thread_unread_comments.png)

<!-- translation-section: writing-a-comment -->

## Rédiger un commentaire

Rédigez un commentaire pour contribuer à la discussion. Les autres personnes peuvent répondre, réagir ou publier leurs propres commentaires.

Sélectionnez **Publier un commentaire** pour le publier. Votre commentaire sera visible par toute personne autorisée à consulter la discussion.

![](../using_discussions/comment.png)

Les outils décrits dans [Mise en forme](/en/user_manual/discussions/formatting/) sont disponibles lorsque vous rédigez des commentaires.

<!-- translation-section: mentioning-people -->

## Mentionner des personnes

Saisissez **@**, commencez à saisir le nom d’une personne, puis sélectionnez-la dans la liste. Une mention avertit immédiatement cette personne et permet de solliciter son attention ou une réponse.

![Mention de Samira Patel dans un commentaire](../notifying_people/comment_mention.png)

Pour avertir toutes les personnes du groupe, saisissez **@**, commencez à saisir le nom du groupe, puis sélectionnez-le dans la liste.

![Recherche d’Oatmilk Cooperative lors de la rédaction d’une mention de groupe](../notifying_people/mentioning_group_1.png)

![Oatmilk Cooperative sélectionné comme mention de groupe](../notifying_people/mentioning_group_2.png)

Mentionner une personne ne lui donne pas accès au fil. Utilisez **Inviter des personnes** dans la barre latérale du fil si elle n’en est pas déjà membre.

<!-- translation-section: replying-to-a-comment -->

## Répondre à un commentaire

Sélectionnez **Répondre** sous un commentaire pour y répondre. La réponse contient déjà une @mention de l’auteur du commentaire, qui reçoit une notification lorsque vous la publiez. Supprimez la mention si vous ne souhaitez pas lui envoyer de notification.

![](../using_discussions/comment_reply.png)

Vous pouvez aussi répondre à votre propre commentaire pour placer une réponse sous celui-ci.

Si un e-mail de Loomio indique que vous pouvez répondre par e-mail, votre réponse apparaîtra dans le fil.

<!-- translation-section: reactions -->

## Réactions

Utilisez le bouton en forme de visage souriant pour répondre avec un emoji. Les réactions envoient une notification à l’auteur du commentaire dans Loomio, mais aucun e-mail.

![](../using_discussions/reaction.png)

<!-- translation-section: translating-comments -->

## Traduire les commentaires

Si l’auteur utilise une autre langue que la vôtre, une action **Traduire** apparaît sous le commentaire.

![](../using_discussions/comment_translate.png)

Sélectionnez **Afficher une traduction automatique du commentaire** pour voir le commentaire dans votre langue.

![](../using_discussions/comment_translated.png)

<!-- translation-section: comment-actions -->

## Actions sur les commentaires

Les actions courantes apparaissent directement sous un commentaire. D’autres actions sont disponibles dans le menu à trois points (**⋯**).

<!-- translation-section: add-a-comment-to-jump-to -->

### Ajouter un commentaire à Aller à

Utilisez **Epingler dans la timeline ** pour ajouter un commentaire à la liste **Aller à** du fil.

Vous pouvez modifier le libellé affiché dans **Aller à**. Désépinglez le commentaire, puis épinglez-le à nouveau pour modifier le texte du lien.

>[!Tip]
>Sélectionnez les mots que vous souhaitez utiliser comme texte du lien avant de sélectionner **Epingler dans la timeline **.

Sélectionnez **Ne plus épingler** pour retirer l’élément de **Aller à**.

<!-- translation-section: edit-a-comment-and-view-changes -->

### Modifier un commentaire et consulter les modifications

Sélectionnez **Modifier** sous l’un de vos commentaires pour le modifier. Les administrateurs du groupe peuvent aussi modifier les commentaires des membres lorsque l’autorisation correspondante est activée dans le groupe.

![](../using_discussions/comment_edit.png)

Une action **Modifié** apparaît sous un commentaire modifié.

![](../using_discussions/comment_show_edits.png)

Sélectionnez **Modifié** pour consulter les modifications. Le texte supprimé est surligné en rouge et le texte ajouté en vert. Loomio enregistre qui a effectué chaque modification et à quel moment.

![](../using_discussions/comment_edits.png)

Vous pouvez modifier un commentaire lorsque :

- vous l’avez rédigé et le groupe autorise les membres à modifier leurs commentaires
- vous êtes administrateur du groupe et l’option [Les administrateurs peuvent modifier les commentaires des membres](/en/user_manual/groups/settings/permissions) est activée

<!-- translation-section: copy-a-comment-link -->

### Copier le lien d’un commentaire

Sélectionnez **Copier le lien** pour copier l’URL unique du commentaire. Vous pouvez coller le lien ailleurs pour renvoyer directement à ce commentaire.

![](../using_discussions/comment_copy_link.png)

<!-- translation-section: view-notification-history -->

### Consulter l’historique des notifications

Ouvrez le menu à trois points (**⋯**) à côté d’un commentaire et sélectionnez **Historique des notifications**.

![Historique des notifications dans le menu des actions d’un commentaire](../notifying_people/comment_notification_history.png)

L’historique des notifications indique qui a reçu une notification concernant le commentaire, quand elle a été envoyée et si elle a été lue lorsque cette information est disponible.

![Historique des notifications d’un commentaire mentionnant Samira Patel](../notifying_people/comment_notification_example.png)

<!-- translation-section: discard-restore-or-delete-a-comment -->

### Jeter, restaurer ou supprimer un commentaire

Jeter un commentaire le retire du fil, mais le conserve dans une corbeille. Vous pouvez jeter vos propres commentaires en sélectionnant **Jeter** dans le menu à trois points. Les administrateurs du groupe peuvent également jeter des commentaires.

![](../using_discussions/comment_discard.png)

**Restaurer un commentaire**

L’emplacement d’un commentaire jeté porte la mention **Elément supprimé**. Ouvrez son menu à trois points et sélectionnez **Restaurer**.

![](../using_discussions/comment_restore.png)

**Supprimer un commentaire**

Supprimer un commentaire le retire définitivement. Il ne peut pas être restauré.

Si l’option **Les membres peuvent supprimer leurs propres commentaires** est activée dans les [Permissions du groupe](/en/user_manual/groups/settings/permissions), les membres peuvent supprimer définitivement leurs propres commentaires jetés. Les administrateurs du groupe peuvent supprimer n’importe quel commentaire.

![](../using_discussions/permissions_delete_comment.png)

Ouvrez le menu à trois points d’une entrée **Elément supprimé** et sélectionnez **Supprimer**.

![](../using_discussions/comment_delete.png)

Un message de confirmation explique que le commentaire sera définitivement supprimé.

![](../using_discussions/comment_delete_message.png)
