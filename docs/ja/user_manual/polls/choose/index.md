# 選ぶ

「選ぶ」は、最も人気のある選択肢を見つけたり、候補を絞り込んだりするためのシンプルな投票です。参加者は、設定された上限と下限に従って、1つまたは複数の選択肢を選びます。この投票方法は一般に複数選択と呼ばれます。

<!-- translation-section: when-to-use-choose -->

## 「選ぶ」を使う場面

選択肢が明確に分かれていて、それぞれを選んだ人数を数えたいときに「選ぶ」を使います。次のような場合に適しています。

- 候補から会場を1つ選ぶ。
- 会議の議題を最大3つ選ぶ。
- 次の選考に進めるデザインを決める。
- メンバーが利用する予定のサービスを確認する。

「選ぶ」では、どの選択肢が選ばれたかを記録します。好みの強さや順位は記録しません。各選択肢への支持の強さを測るには[スコア投票](/en/user_manual/polls/score/)、使える予算に限りがある場合は[割り当て](/en/user_manual/polls/allocate/)、好みの順位が重要な場合は[ランク](/en/user_manual/polls/rank/)を使います。

<!-- translation-section: example-set-a-planning-meeting-agenda -->

## 例：企画会議の議題を決める

オーツミルク協同組合は、返却可能なボトルの試行について、次の企画会議でどの課題に最も時間を割くか決める必要があります。この投票では、各参加者が議題を最大2つ選びます。詳細には結果の使い方を説明し、各選択肢には違いが分かるだけの情報を記載します。

<!-- translation-section: set-up-the-poll -->

## 投票を設定する

具体的な質問を投票のタイトルにします。**詳細**には、参加者が何を考慮し、結果をどう使うかを書きます。選択肢を追加し、**最小限の選択肢**と**最大限の選択肢**を設定します。

![](form.png)

参加者が必ず1つだけ選ぶ場合は、両方を1に設定します。候補を絞り込む場合は、上限を増やします。ほぼすべての選択肢を選べるようにすると結果が判断に役立ちにくくなるため、上限を高くしすぎないでください。

選択肢の横にある鉛筆アイコンから、その意味や補足説明を追加できます。短い名前が複数の意味に解釈されそうな場合に役立ちます。

![](edit_option.png)

**その他の設定**にある**オプションをランダムな順序で表示する**を使うと、同じ選択肢が常に最初に表示される影響を減らせます。

![](random_order.png)

<!-- translation-section: vote -->

## 投票する

投票フォームには、選べる選択肢の数が表示されます。この例では、投票者は**カフェでの回収スケジュール**と**洗浄の作業手順**を選び、その選択が試行にどう関係するかを理由として記入しています。

![](voting.png)

理由を読むと、その選択肢が重要な理由や、参加者がどの作業を含むと考えているかが分かります。判断に理由が重要な場合は、投票を始める前に理由の入力設定を行います。

<!-- translation-section: read-the-results -->

## 結果を読む

結果には、各選択肢が全選択数に占める割合、その選択肢を選んだ投票者の数、まだ投票していない人が表示されます。各人が2つ選べるため、この割合は人数ではなく選択数の割合です。

![](results.png)

この例では、**カフェでの回収スケジュール**が3票です。**洗浄の作業手順**と**返却率の報告**はそれぞれ2票です。結果から、カフェでの回収に最も多くの議題時間を割くことが考えられます。同数の2つの議題については、残りの時間をどう配分するか主催者が決める必要があります。

<!-- translation-section: share-an-outcome -->

## 結論を共有する

投票が締め切られたら、結論を共有します。同数の場合の扱いも含め、結果を受けてグループが何をするかを説明します。結論の仕組みについては、[結論を共有する](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome)を参照してください。
