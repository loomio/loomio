# タスク

スレッドやコメントにタスクを追加すると、作業内容、担当者、期限を指定し、完了したかどうかを確認できます。

<!-- translation-section: add-a-task -->

## タスクを追加する

スレッドやコメントの作成中に、書式設定ツールバーを展開して**タスクリスト**をクリックします。チェックボックスの横に作業内容を入力します。

![](tasklist1.png)

<!-- translation-section: name-and-assign-the-task-to-a-person -->

## タスクに名前を付けて担当者を割り当てる

タスク内でグループのメンバーを@メンションすると、その人を担当者に割り当てられます。担当者を割り当てると、**期限を追加**ボタンが表示されます。

![](tasklist2.png)

割り当てられたタスクは、**タスク**ページに表示されます。サイドバーの**タスク**を開くと、スレッドまたは投票ごとにまとめて確認できます。

![](task_list.png)

<!-- translation-section: set-a-reminder -->

## リマインダーを設定する

**期限を追加**をクリックして、期限と、Loomioが担当者にメールでリマインダーを送るタイミングを選びます。このダイアログでは、設定済みの期限を削除することもできます。

![](taskreminderform.png)

<!-- translation-section: mark-it-as-done -->

## 完了にする

![](taskdone.png)

タスクの横にあるチェックボックスをクリックすると、完了としてマークできます。テキストの編集中、担当者として閲覧中、または**タスク**ページから操作できます。もう一度クリックすると、タスクを再開できます。
