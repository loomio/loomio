# עיצוב טקסט וצירוף קבצים

סרגל העיצוב מופיע מתחת לשדה הטקסט בעת פתיחה או עריכה של דיון, יצירת סקר או כתיבת תגובה. יש לבחור בחץ שבקצה הסרגל כדי להציג או להסתיר את כל הכלים.

כדי לראות את שם הכלי, יש להעביר את סמן העכבר מעל הסמל שלו.

![](thread_format_bar.png)

<!-- translation-section: attach-file -->

## צירוף קובץ

כדי לצרף קבצים מהמכשיר, יש לבחור בסמל מהדק הנייר שמתחת לשדה הטקסט.

![](format_attach.png)

<!-- translation-section: remove-attachments -->

### הסרת קבצים מצורפים

בעת העריכה, יש לבחור ב־**×** שלצד שם הקובץ כדי להסיר אותו.

![](thread_file_remove.png)

<!-- translation-section: insert-image -->

## הוספת תמונה

יש לבחור **הוסף תמונה** כדי להעלות תמונה, או להדביק תמונה ישירות בעורך. התמונה מוצגת בתוך תוכן הדיון, הסקר או התגובה.

![](format_insert_example.png)

<!-- translation-section: insert-link -->

## הוספת קישור

ניתן להוסיף קישור לכל דף אינטרנט או מסמך מקוון:

1. יש לבחור את הטקסט שרוצים להפוך לקישור.
2. יש לבחור בסמל הקישור.
3. יש להדביק את הכתובת בשדה **הכנס לינק** ולבחור **החל**.

יש לבדוק את הרשאות השיתוף של כל מסמך חיצוני כדי שהמשתתפים יוכלו לפתוח אותו. אם מופיעה תצוגה מקדימה של קישור מתחת לטקסט, ניתן להסיר אותה.

![](format_link.png)

<!-- translation-section: insert-emoji -->

## הוספת אימוג׳י

יש לבחור בסמל הסמיילי כדי לבחור אימוג׳י.

![](thread_insert_emoji.png)

## כותרות

יש להשתמש ב־**מכוון ל 1**, **כותרת 2** ו־**כותרת 3** כדי לארגן דיונים או תגובות ארוכים.

תגובות הכוללות **כותרת 2** או **כותרת 3** מתווספות אוטומטית לרשימת **קפיצה אל** של השרשור.

![](format_heading.png)

יש לבחור טקסט ולבחור בהדגשה, בכתב נטוי או בקו חוצה כדי להדגיש מילים או להעביר דרכן קו.

![](format_bold.png)

![](format_numbers.png)

## רשימת מטלות

יש להשתמש ב־**רשימת מטלות** כדי להוסיף תיבות סימון. בעת כתיבת משימה, יש להקליד אזכור באמצעות @ כדי להקצות אותה לחבר קבוצה, ולאחר מכן לבחור **הוסף תאריך יעד** כדי לקבוע תאריך יעד ותזכורת.

![](format_tasks.png)

לפרטים, ניתן לעיין בדף [הקצאת משימות ומעקב אחריהן](/en/user_manual/discussions/tasks/).

## הטמעת סרטונים ודפי אינטרנט

ניתן להטמיע סרטונים ודפי אינטרנט נתמכים בכל מקום שבו מופיע סרגל העיצוב:

1. יש להעתיק את כתובת הסרטון או דף האינטרנט.
2. יש לבחור **הטמע וידאו**, להדביק את הכתובת ולבחור **החל**.

ניתן להוסיף טבלה ולהשתמש בכלי הטבלה כדי להוסיף או להסיר שורות ועמודות.

## Markdown

כדי לכתוב ב-Markdown, יש לבחור **ערוך Markdown**.

המרה ל-Markdown שומרת על כותרות, טקסט מודגש ונטוי, רשימות, טבלאות בסיסיות, משימות שסומנו כבוצעו, תמונות, קישורים ואזכורים באמצעות @. סרטונים, קטעי שמע ותוכן מוטמע הופכים לקישורים.

צבעי טקסט, הדגשות בצבע, קווים תחתונים, יישור ופריסות מותאמות אישית של טבלאות עלולים להיאבד. תאריכי יעד ותזכורות של משימות מוסרים; מעבר חזרה לטקסט עשיר יוצר משימות חדשות עם אותו טקסט ואותו מצב סימון.

<!-- translation-section: rich-text -->

### טקסט עשיר

כדי לחזור לסרגל העיצוב ולהמיר תחביר Markdown נתמך לטקסט מעוצב, יש לבחור **עריכת טקסט עשיר**.

כדי לראות כיצד ייראה ה-Markdown בלי להמיר אותו, יש לבחור **תצוגה מקדימה**.
