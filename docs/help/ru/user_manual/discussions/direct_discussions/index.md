# Личные обсуждения

Личное обсуждение — это закрытое обсуждение для определённого круга людей.

Личное обсуждение не принадлежит группе. Приглашённым людям не обязательно быть участниками вашей группы в Loomio.

Вы определяете, кто может видеть обсуждение и участвовать в нём, добавляя людей или адреса электронной почты в поле **Приглашать**.

В личных обсуждениях доступны те же комментарии, опросы и другие инструменты, что и в обсуждениях группы. Они могут быть полезны, когда создавать подгруппу не требуется.

![Форма личного обсуждения без выбранной группы, с Самирой Патель в поле «Приглашать»](direct-discussion-example.png)

Выберите **Прямые темы** на боковой панели, чтобы увидеть ваши личные обсуждения и опросы. Откройте меню **Новый** и выберите **Новое обсуждение**, чтобы начать обсуждение, или **Новый опрос**, чтобы создать опрос без группы.

Личный опрос доступен только тем людям, которых вы приглашаете. После его создания используйте [**Управление избирателями**](/en/user_manual/polls/manage_voters), чтобы пригласить людей или отправить приглашения по адресам электронной почты.

![Пункт «Прямые темы» на боковой панели и список личных обсуждений](direct-discussion-sidebar.png)

## Как связаться с человеком через личное обсуждение
Личное обсуждение позволяет связаться с одним или несколькими людьми в закрытом формате без создания подгруппы.
