# ランク

ランクでは、グループ全体の希望順位を確認できます。参加者が選択肢を希望する順に並べると、Loomioは上位の選択肢に多くのポイントを割り当てます。

<!-- translation-section: when-to-use-rank -->

## ランクを使う場面

希望の順序が重要で、全体の順位を一つにまとめたいときにランクを使います。たとえば、次のような場合に役立ちます。

- 役職の候補者を1人選ぶ
- 作業計画に向けてプロジェクトの順序を決める
- 会議の議題に優先順位を付ける
- 第一希望と代替案を選ぶ
- 長い候補一覧を順位付きの候補リストに絞る

ランクはポイントに基づいて順位を決めます。比例代表方式の選挙には使えません。異なる有権者グループの意向を反映しながら複数人を選ぶ場合は、[STV選挙](/en/user_manual/polls/stv/)を使います。

<!-- translation-section: example-rank-bottle-designs -->

## 例：ボトルのデザインに順位を付ける

オーツミルク協同組合は、返却可能なボトルの試験導入に向けて、4種類のデザインに順位を付けるようメンバーに依頼します。参加者は、持ちやすさ、耐久性、顧客のニーズ、保管のしやすさ、洗浄設備との適合性を検討します。

<!-- translation-section: set-up-the-poll -->

## 投票を設定する

順位付けで何を決めるかを説明し、選択肢を追加します。各参加者が順位を付けられる選択肢の数は、**選択肢の数**で設定します。第一希望に最も多くのポイントが付き、次の選択肢は1ポイント少なくなります。順位を付けなかった選択肢にはポイントが付きません。

![](form.png)

すべての選択肢について順位が必要な場合は、全項目の順位付けを必須にします。参加者がすべてを評価するだけの情報を持っていない場合は、順位を付ける数を減らせるようにします。選択肢をランダムな順序で表示すると、最初の表示順による影響を減らせます。

<!-- translation-section: vote -->

## 投票する

参加者は選択肢をドラッグして希望する順に並べます。1番が第一希望です。順位を決めた基準を理由として追加することもできます。

![](voting.png)

この例では、**500 mlの琥珀色のボトル**を1位、**500 mlの透明なボトル**を2位にしています。どちらも既存のカフェの保管場所と洗浄設備に適合するためです。

<!-- translation-section: read-the-results -->

## 結果を読む

結果では、すべての投票を集計し、ポイントに基づく全体の順位を示します。各選択肢には次の項目が表示されます。

- **ランク**：集計結果での順位
- **ポイントの割合**：順位付けで付与された全ポイントのうち、その選択肢が占める割合
- **ポイント**：すべての投票で得たポイントの合計
- **平均**：有権者1人当たりの平均ポイント
- **有権者**：その選択肢に順位を付けた人数

![](results.png)

この例では、**500 mlの琥珀色のボトル**が1位で、**500 mlの透明なボトル**、**750 mlの琥珀色のボトル**が続きます。グループは第一候補のデザインから検討し、残りの順位を代替案の順序として活用できます。

異なる希望の傾向でも、ポイントの合計が同じになることがあります。選択肢の結果が僅差の場合や、重要な決定を行う場合は、個々の投票とその理由を確認します。
