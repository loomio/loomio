# Резервне копіювання або експорт даних групи

За допомогою функції експорту даних групи ви можете:

- Завантажити файл із даними учасників, щоб перевірити склад групи.
- Завантажити вміст вашої групи, зокрема тексти тем і опитувань, для архівування або аналізу.
- Відкрити результати опитувань в електронній таблиці або обробити їх за допомогою скриптової мови програмування.
- [Друкувати або зберігати теми чи опитування у форматі PDF для архівування.](#print-thread-to-pdf)
- Перенести вашу групу разом з усіма користувачами, темами, опитуваннями та файлами на інший сервер Loomio.

Якщо ви захочете перейти із серверів, якими керує Loomio, [на власний сервер](https://github.com/loomio/loomio), ви можете скористатися цією функцією.

Якщо ви використовуєте власний сервер Loomio й більше не хочете ним керувати, Loomio пропонує керований хостинг у США, ЄС та Австралії. Якщо ви хочете перенести вашу групу на один із цих серверів, [зв’яжіться з нами](/contact).

[Зв’яжіться з нами](/contact), якщо ви хочете перенести вашу групу Loomio з глобального сервісу Loomio на loomio.com до одного з наших регіональних сервісів: loomio.eu для Європи або loomio.nz для Австралії та Нової Зеландії.

## Експорт даних

Відкрийте розкривне меню групи, натиснувши на три крапки, і виберіть **Експортувати дані групи**.

### Експорт даних групи у форматі CSV

*Для роботи з даними групи в електронній таблиці, наприклад у MS Excel або Google Sheets.*

Loomio готує файл CSV у фоновому режимі й надсилає вам електронною поштою посилання для завантаження, коли файл готовий. Посилання доступне протягом одного тижня.

### Експорт даних групи у форматі HTML

Loomio готує файл HTML у фоновому режимі й надсилає вам електронною поштою посилання для завантаження, коли файл готовий. Посилання доступне протягом одного тижня.

<!-- translation-section: export-group-data-as-json -->

### Експорт даних групи у форматі JSON

*Для перенесення даних вашої групи на власний сервер Loomio.*

Щоб експортувати дані групи, ви маєте бути її адміністратором. Експорт у форматі JSON містить:

- Групу, її учасників і запити на приєднання
- Теми, коментарі, реакції, теги, шаблони, сповіщення та пов’язані записи з груп, включених до експорту
- Опитування, варіанти, голоси та висновки; анонімне опитування включається лише після його закриття
- Підгрупи, до яких ви належите
- Відкриті, закриті та видимі для батьківської групи підгрупи, якщо ви експортуєте їхню батьківську групу як її адміністратор, навіть якщо ви не належите до цих підгруп
- Посилання на файли та зображення, прикріплені до вмісту, включеного до експорту

Експорт у форматі JSON не містить:

- Таємних підгруп, до яких ви не належите, зокрема даних про їхніх учасників і вмісту
- Підгруп, що очікують на видалення
- Анонімних опитувань, які ще не закрито
- Прямих тем і опитувань, які не належать до групи

Невдовзі ви отримаєте електронний лист із посиланням для завантаження файлу JSON.

## Друк теми у PDF

Вам може знадобитися копія теми для зберігання в окремому файловому архіві.

Функція **Друкувати** зберігає всі коментарі, опитування, голоси та висновки разом із форматуванням теми.

У темі відкрийте меню з трьома крапками (⋯) і натисніть **Друкувати**. Loomio створить HTML-сторінку, яку ви зможете надрукувати або зберегти у PDF за допомогою функції друку у вашому браузері.

Ви можете скопіювати сторінку та вставити її в редактор документів, файл або сховище даних.

![Дія «Друкувати» для обговорення пляшок, що підлягають поверненню](discussion_print_discussion.png#width-90)

## Імпорт даних вашої групи на інший сервер Loomio

Інструкції з налаштування власного сервера Loomio доступні за адресою: https://github.com/loomio/loomio

Якщо ви самостійно розміщуєте Loomio й хочете імпортувати експортовані дані:

Скопіюйте файл .json до папки `import` екземпляра контейнера:

`scp your-group-data.json username@some-domain.org:loomio-deploy/import`

Відкрийте консоль Rails у запущеному контейнері:

`docker exec -ti loomio-app rails console`

Викличте сервіс:

`GroupExportService.import('/import/your-group-data.json')`
