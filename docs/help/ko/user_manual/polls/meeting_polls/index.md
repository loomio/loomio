# 일정 투표

**일정 투표**를 사용해 그룹의 다른 Loomio 작업과 함께 회의나 행사 시간을 정하세요. 각 참여자에게는 자신의 시간대를 기준으로 날짜와 시간 선택지가 표시됩니다.

![](meeting_polls.png)

<!-- translation-section: time-poll -->

## 투표 설정

![](timepoll_label.png)

일정 투표에 제목과 세부 내용을 입력하세요. 자신의 시간대를 기준으로 날짜와 시간 선택지를 입력하고 회의 소요 시간을 설정하세요.

선택지를 정할 때는 모두가 참석할 수 있는 시간이 있도록 다른 시간대에 있는 참여자도 고려하세요.

![](timepoll_options.png)

<!-- translation-section: voting -->

### 투표

참여자는 각 시간 선택지에 참석 가능, 필요한 경우 참석 가능, 참석 불가 중 하나를 표시합니다. 투표 이유를 추가해 참석 가능 여부를 설명하거나 다른 시간을 제안할 수도 있습니다. 적합한 선택지가 없으면 투표를 수정해 새로운 시간을 추가할 수 있습니다.

![](timepoll_vote.png)

참여자가 투표할 때마다 결과가 갱신되어 각 시간에 누가 참석할 수 있는지 표시됩니다.

<!-- translation-section: outcome -->

### 결론 공유

일정 투표가 마감되면 가장 적합한 시간을 선택하고 결론을 공유하세요. 결론의 사용 방법은 [결론 공유](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome)를 참고하세요.

![](timepoll_outcome.png)

- **알림 보내기**: 회의나 행사에 초대할 사람들을 추가하세요.
- **회의 시간**: 가장 적합한 시간을 선택하세요. 선택지는 [프로필의 시간대](/en/user_manual/users/user_profile#time-zone)를 기준으로 표시됩니다.
- **회의 이름**: 회의 이름을 입력하세요. Loomio는 기본값으로 일정 투표의 제목을 사용합니다.
- **장소**: 실제 주소나 온라인 회의 링크를 추가하세요.
- **의견**: 결정을 요약하고 회의에 필요한 안내 사항을 포함하세요.

Loomio는 선택한 시간, 회의 이름, 소요 시간, 장소, 의견을 결론 알림과 캘린더 초대에 포함합니다.
