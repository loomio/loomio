# Integraciones

Conecta Loomio con otras herramientas que utiliza tu grupo.

<!-- translation-section: choose-where-work-belongs -->

## Elige dónde hacer cada tarea

Loomio complementa el chat, los documentos compartidos y las herramientas de gestión de tareas. Cada herramienta sirve para un tipo de trabajo.

| Trabajo | Herramienta recomendada |
|---|---|
| Preguntas rápidas, conversaciones informales y novedades que requieren atención inmediata | Chat |
| Edición conjunta de un documento que se actualiza con frecuencia | Documento compartido |
| Asignación y seguimiento de tareas | Herramienta de gestión de proyectos o tareas |
| Discusiones sobre temas importantes, participación amplia, decisiones y conclusiones | Loomio |

Usa Loomio cuando las personas necesiten tiempo para considerar un tema, cuando todas las personas afectadas deban tener la oportunidad de participar o cuando el grupo necesite encontrar la discusión y la decisión más adelante. Enlaza el documento o la tarea pertinente desde la discusión de Loomio para que sea fácil encontrar el contexto.
