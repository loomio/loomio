# Déplacer des éléments entre les fils

Déplacez les éléments sélectionnés lorsqu’une conversation a sa place dans un autre fil, lorsqu’un fil s’est scindé en plusieurs sujets distincts ou lorsque vous souhaitez regrouper des discussions liées. Il n’existe pas de commande distincte **Fusionner les discussions**.

Cette option est disponible pour les administrateurs du groupe et pour les membres lorsque l’option **Les membres peuvent gérer les discussions et les commentaires.** est activée dans les [Permissions du groupe](/en/user_manual/groups/settings/permissions).

Ouvrez le menu à trois points (**⋯**) d’un élément et sélectionnez **Déplacer l'élément**.

![](../using_discussions/comment_move.png)

Sélectionnez les éléments que vous souhaitez déplacer.

![](../using_discussions/comment_select.png)

Sélectionnez les éléments supplémentaires à l’aide des cases à cocher, puis cliquez sur **Déplacer** dans le bandeau en haut de la discussion.

![](../using_discussions/move_items.png)

Choisissez le groupe ou le sous-groupe, puis recherchez la discussion de destination.

Pour déplacer les éléments dans une nouvelle discussion, sélectionnez **Nouvelle discussion** et ajoutez son titre et son contexte.

![](../using_discussions/move_items_new_thread.png)

Les éléments sont déplacés du fil d’origine vers le fil sélectionné ou nouvellement créé.

![](../using_discussions/new_thread.png)

Si le fil d’origine n’est plus nécessaire, vous pouvez [le verrouiller](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread). Supprimez-le uniquement si vous avez la certitude qu’il ne sera plus nécessaire.
