# Loomioアカウントの削除

<!-- translation-section: what-does-delete-account-mean -->

## アカウントを削除するとどうなりますか？

アカウントを削除すると、次のようになります。
- 名前、メールアドレス、その他の個人を特定できる情報を含むユーザーアカウントが、Loomioのシステムから削除されます。このアカウントでLoomioにログインできなくなります。
- 投稿したコメント、提案、ディスカッションは残りますが、名前は削除されます。グループのスレッドや提案の内容を一貫して残すためです。
- どのグループのメンバー一覧にも表示されなくなります。
- 通知メールが届かなくなります。

Loomioで作成したデータのコピーは、グループの全員にメールで送信されている可能性があります。Loomioは、送信済みのコピーを削除できません。

アカウントを削除しても、サブスクリプションは_解約されません_。支払いを止めるには、[サブスクリプション](/en/policy/subscriptions/management#cancel-your-plan)をご覧ください。

Loomioは、ユーザーの権利を守るため、所有形態、事業モデル、ソフトウェアについて基本方針を定めています。Loomioは労働者が所有する独立した協同組合です。ソフトウェアはオープンソースで、[データをエクスポート](/en/user_manual/groups/data_export)できます。Loomioがデータを販売したり、広告に利用したりすることはありません。これらの方針は[プライバシーポリシー](/en/policy/privacy)に記載され、[定款](https://www.loomio.coop/constitution.html)と[協同組合ハンドブック](https://www.loomio.coop/purpose_and_vision.html)に示された目的と価値観に基づいています。ご質問がある場合は、[お問い合わせください](/contact)。

<!-- translation-section: to-delete-your-account-entirely -->

## アカウントを完全に削除する方法

Loomioにログインします。画面左上のメニューアイコン（☰）からサイドバーを開きます。次に、画面右上にあるアカウントのアバターまたはイニシャルをクリックします。

名前の横にある下向き矢印（ ∨ ）をクリックしてユーザー設定を開きます。**プロファイル編集**を選択します。

![](profile_edit.png#width-50)

一番下までスクロールし、**アカウントを削除する**をクリックします。

![](delete_user.png)

アカウントの削除を確認するポップアップが表示されます。

![](permanently_delete_account.png#width-80)
