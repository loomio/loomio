# 非公開の提出物を集める

議論終了のグループを使うと、グループのメンバーではない人から非公開の提出物を集められます。提出物ごとに個別のディスカッションが作られ、提出者とグループの審査チームはそこで情報を交換し、質問し、決定を記録できます。提出者は、グループ内のほかの非公開ディスカッションや提出物を閲覧できません。

候補者の詳細や候補者一覧を選考中に非公開にする必要がある場合、推薦の受付に適しています。選挙、任命、委員会、理事会、代表者の役職について、自分やほかの人を推薦できます。選考委員会は推薦ごとに個別のディスカッションで審査できます。

提出物を公開すべきでない、ほかの用途には次のようなものがあります。

- 苦情、保護に関する報告、安全上の懸念、事故報告
- 個別の案件について決定の再検討を求める異議申し立てや依頼
- 調停、紛争解決、個人的な支援の依頼
- 生活困窮者向け助成金や奨学金など、個人情報、財務情報、応募資格に関する情報を含む申請
- 審査中は非公開にする必要がある封印入札や入札への回答

この方法では、提出者同士の提出物は非公開ですが、匿名ではありません。提出者にはユーザーアカウントが必要で、議論終了のグループのメンバーは全員、提出物を閲覧できます。機密情報を扱う前に、審査グループのメンバーを確認してください。

## 非公開の提出を有効にする

提出物を集めるグループまたはサブグループの管理者である必要があります。

1. グループを開きます。
2. **設定**を選択します。または、**もっと**、**グループ設定を編集する**の順に選択します。
3. **権限**を開きます。
4. **非会員でも議論を開始できます**を有効にします。
5. グループ設定を保存します。

![グループ設定の権限タブで、非会員でも議論を開始できますの項目が強調表示されている画面](non_members_can_start_discussions.png)

この設定を利用できるのは、**議論中**と**議論終了**のグループだけです。**秘密**のグループでは表示されません。設定が見つからない場合は、グループ設定の**プライバシー**を開き、**グループのプライバシー**を**議論終了**（非公開の提出物に推奨）または**議論中**に変更してから、**権限**に戻ります。

この権限を有効にしても、グループのディスカッションは公開されません。メンバーではない人は新しいディスカッションを開始し、ゲストとしてそのディスカッションにアクセスできますが、グループ内のほかの非公開ディスカッションは閲覧できません。

## 非公開の提出手続きを設定する

1. 提出物を受け付ける専用のサブグループを作成し、プライバシーを**議論終了**に設定します。サブグループを使うと、提出物を親グループのほかの活動から分けられます。
2. 選考委員会など、提出物の審査を担当する人をサブグループのメンバーに追加します。サブグループのメンバーは全員、すべての提出物を閲覧できるため、アクセスが必要な人だけを追加してください。
3. サブグループ内に[ディスカッションテンプレート](/en/user_manual/discussions/templates)を作成します。提出者に回答してほしい質問や提供してほしい情報を含めます。提出物の種類ごとに異なるディスカッションテンプレートを作成できます。
4. 提出者からのサブグループ参加申請を受け付けない場合は、メンバーシップを**招待のみ**に設定します。
5. サブグループの権限で[非公開の提出を有効にします](#enable-private-submissions)。
6. サブグループのメンバーではないアカウントで手続きを試します。
7. 提出予定者にサブグループのページを共有します。提出する前に、ユーザーアカウントへのサインインが必要です。

## 提出する

提出者はサブグループを開き、**ディスカッションを始める**を選択します。Loomioに、サブグループで利用できるディスカッションテンプレートが表示されます。該当するテンプレートを選び、質問に回答してディスカッションを開始します。

ディスカッションはサブグループに属しますが、提出者はサブグループのメンバーにはなりません。Loomioは提出者をそのディスカッションのスレッドにゲストとして追加します。提出者はスレッドを閲覧し、選考委員会や審査チームとのディスカッションに参加できます。サブグループ内のほかの非公開ディスカッションや提出物は閲覧できません。

<!-- translation-section: review-submissions -->

## 提出物を審査する

サブグループのメンバーは、サブグループ内のすべての提出物のディスカッションを閲覧できます。追加の質問をしたり、コメントや投票などのディスカッションツールを使ったりして審査を進められます。

ほかの人から情報を得る必要がある場合は、権限を持つサブグループのメンバーがその人を提出物のディスカッションに招待できます。たとえば、推薦者が推薦を提出した後、候補者の参加が必要なら、サブグループから候補者をスレッドに招待できます。招待された人はゲストとして参加し、サブグループ内のほかの非公開ディスカッションにはアクセスできません。

提出者は自分の提出物を閲覧できますが、サブグループ内のほかの非公開ディスカッションや提出物は閲覧できません。提出の受付を締め切るときは、**非会員でも議論を開始できます**を無効にします。既存のディスカッションとゲストのアクセス権は変わりません。
