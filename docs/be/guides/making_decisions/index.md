# Прыняцце рашэнняў

Гэтыя кіраўніцтвы тлумачаць увесь працэс прыняцця рашэння: як сфармуляваць пытанне, далучыць патрэбных людзей, абмеркаваць прапановы, адказаць на заўвагі і запісаць выснову.

Гэтыя кіраўніцтвы адрозніваюцца ад старонак пра шаблоны прапаноў. [Шаблон прапановы](/en/user_manual/polls/proposals/) апісвае адну прапанову і варыянты адказу на яе. У працэсе прыняцця рашэння можна паслядоўна выкарыстоўваць некалькі прапаноў.

<!-- translation-section: choose-a-process -->

## Выберыце працэс

| Працэс | Хто прымае рашэнне? | Галоўнае пытанне |
|---|---|---|
| [Просты працэс прыняцця рашэння](simple_decision_process) | Вызначае група | Як абмеркаваць, праверыць і прыняць рашэнне? |
| [Працэс кансультавання](advice_process) | Адна асоба або каманда, якой дэлегавалі паўнамоцтвы | Якія парады варта ўлічыць пры прыняцці рашэння? |
| [Працэс прыняцця рашэння без пярэчанняў](consent_process) | Група | Ці можна паспрабаваць ажыццявіць прапанову без істотных пярэчанняў? |
| [Працэс дасягнення кансэнсусу](consensus_process) | Група | Ці можам мы дасягнуць супольнай згоды? |

Выкарыстоўвайце працэс, прадугледжаны правіламі кіравання або палітыкай прыняцця рашэнняў вашай групы. Для розных відаў рашэнняў могуць падыходзіць розныя працэсы.

Калі вам трэба толькі выбраць фармат адказаў, параўнайце [Прапановы](/en/user_manual/polls/proposals/) і [Апытанні](/en/user_manual/polls/proposal_types/). Калі вы наладжваеце варыянты для паўторнага выкарыстання, якія з’яўляюцца пасля выбару **Пачаць галасаванне**, глядзіце [Шаблоны апытанняў](/en/user_manual/polls/poll_templates/).
