# Microsoft Teams-Integration
_Verbinde die Benachrichtigungen deiner Loomio-Gruppe mit Microsoft Teams._

Loomio kann Benachrichtigungen an Microsoft Teams senden, wenn es neue Diskussionen, Vorschläge, Kommentare, Stimmen oder Fazits gibt.

---

Öffne [https://teams.microsoft.com](https://teams.microsoft.com) und klicke auf Apps
![](t1.png)

Suche im Suchfeld nach „webhook“ und klicke auf Eingehender Webhook
![](t2.png)

Klicke auf „Zu einem Team hinzufügen“
![](t3.png)

Gib den Kanal ein, in dem Loomio-Benachrichtigungen erscheinen sollen, und wähle ihn aus.
![](t4.png)

Gib dem Webhook einen Namen, zum Beispiel „Loomio-Benachrichtigungen“, und klicke auf „Erstellen“
![](t5.png)

Kopiere die angezeigte URL. Im letzten Schritt fügst du sie in Loomio ein.
![](t6.png)

_Loomio wurde nicht von Microsoft entwickelt und ist weder mit Microsoft verbunden noch wird es von Microsoft unterstützt._

Du hast jetzt eine Webhook-URL. Richte als Nächstes die Chat-Integration ein:

[Chat-Integration in Loomio einrichten](../chatbots/#set-up-a-chat-integration)
