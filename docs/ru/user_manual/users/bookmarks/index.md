# Закладки

Закладки — это ваш личный список материалов Loomio, к которым вы хотите вернуться. Ваши закладки видны только вам. Когда вы сохраняете закладку, другие пользователи не получают уведомлений.

Вы можете сохранять закладки на:

- обсуждения
- комментарии
- предложения и голосования
- голоса
- результаты

<!-- translation-section: save-a-bookmark -->

## Сохранить закладку

Откройте меню действий нужного элемента и выберите **Сохранить закладку**. Обычно меню действий обозначено тремя точками. Для обсуждения откройте меню рядом с его названием. Для комментария, голоса, предложения, голосования или результата откройте меню самого элемента.

![](save_bookmark.png)

<!-- translation-section: view-your-bookmarks -->

## Просмотреть закладки

Откройте боковую панель и выберите **Закладки**. Число рядом со ссылкой показывает, сколько закладок вы сохранили.

На странице «Закладки» сначала показаны недавно сохранённые элементы. В каждой строке указан тип элемента и его автор. Выберите строку, чтобы открыть элемент.

![](bookmarks_page.png)

<!-- translation-section: remove-a-bookmark -->

## Удалить закладку

На странице «Закладки» нажмите кнопку удаления закладки в конце строки. Вы также можете открыть меню действий сохранённого элемента и выбрать **Удалить закладку**.

Удаление закладки затрагивает только ваш личный список. Позже вы можете снова сохранить этот элемент.
