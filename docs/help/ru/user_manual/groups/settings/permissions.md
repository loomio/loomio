# Разрешения группы

Вкладка разрешений определяет, какие действия в группе доступны обычным участникам, а в группах, которые не являются секретными, — также людям, не состоящим в группе. На странице группы откройте **Редактировать настройки группы**, затем выберите **Разрешения**.

![Настройки разрешений группы](group_group_settings_permissions.png)

Администраторы сохраняют возможность управлять группой. Включение разрешения для участников позволяет обычным участникам выполнять соответствующее действие, но не делает их администраторами.

Разрешения определяют, могут ли участники:

- добавлять участников или приглашать гостей;
- отправлять объявления;
- создавать подгруппы;
- начинать обсуждения и управлять ими;
- создавать теги и управлять ими;
- редактировать или удалять комментарии, если это разрешено настройками;
- создавать предложения и опросы;
- создавать шаблоны обсуждений и опросов.

В группах, которые не являются секретными, администраторы могут отдельно разрешить людям, не состоящим в группе, начинать обсуждения. Человек, не состоящий в группе, который начинает обсуждение, становится гостем этого обсуждения, но не получает доступа к другим закрытым обсуждениям и не становится участником группы.

Настройка **Администраторы могут редактировать комментарии участников.** предоставляет администраторам особую возможность модерации. Включайте её только в том случае, если группа согласилась, что администраторы должны иметь возможность изменять содержимое, созданное участниками.

Пересматривайте разрешения при изменении целей группы, её состава или обязанностей по модерации. Предоставляйте каждой роли только те возможности, которые ей необходимы.
