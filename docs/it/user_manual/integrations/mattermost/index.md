# Integrazione con Mattermost
_Collega le notifiche del tuo gruppo Loomio alla chat del tuo team Mattermost._

Loomio può inviare notifiche nei tuoi canali Mattermost quando vengono pubblicati nuove discussioni, proposte, commenti, voti e conclusioni.

---

Apri il tuo team Mattermost nel browser. Poi apri la pagina delle impostazioni delle integrazioni.
![](mm1.png)

Seleziona "Webhook in entrata"
![](mm2.png)

Poi seleziona "Aggiungi webhook in entrata"
![](mm3.png)

Assegna un nome semplice, scegli il canale in cui ricevere le notifiche e seleziona Salva
![](mm4.png)

Copia l'URL del webhook negli appunti: ti servirà nel passaggio successivo.
![](mm5.png)

Assicurati di aver copiato l'URL del webhook negli appunti e segui il link qui sotto.

[Configura un'integrazione con la chat in Loomio](../chatbots/#set-up-a-chat-integration)
