# בעלי זכות הצבעה כנציגים

אם רק לחלק מחברי הקבוצה צריכה להיות זכות הצבעה, ניתן לסמן אותם באמצעות הפעולה "לעשות נציג". ניתן גם להסיר את המינוי באמצעות "בטל נציג".

כדאי להשתמש בנציגים כאשר כולם צריכים להשתתף באותם דיונים, אך רק קבוצה מוגדרת, כגון חברי הנהלה או נציגים נבחרים, רשאית להצביע. בדרך כלל זה פשוט יותר מניהול תת־קבוצה נוספת שמטרתה היחידה היא להפריד בין בעלי זכות הצבעה לשאר החברים.

אם החברים האלה צריכים גם דיונים, קבצים או פרטי חברות שאסור לשאר החברים לראות, יש להשתמש בתת־קבוצה פרטית.

![הפעולה לעשות נציג בתפריט של חבר קבוצה](member_make_delegate.png)

כדי ליצור משאל או הצעה ולהזמין רק את הנציגים, יש לבחור בהגדרה "אנשים נבחרים בלבד".
![ההגדרה אנשים נבחרים בלבד בעת פתיחת הצעה](poll_invited_people_only.png)
לאחר מכן, בעת הזמנת אנשים להצביע, תופיע האפשרות "נציגים של שם הקבוצה".
![האפשרות נציגים של קואופרטיב חלב שיבולת שועל בטופס ההזמנה להצבעה](poll_invite_delegates_group.png)

ניתן לראות את רשימת הנציגים בלשונית החברים בדף הקבוצה. יש לפתוח את תפריט הסינון ולבחור "נציגים".
