# グループの権限

**権限** タブでは、メンバーがグループ内で行える操作を設定します。秘密のグループ以外では、メンバー以外の人が行える操作も設定できます。グループのアクションメニューから **グループ設定を編集する** を開き、**権限** を選択します。

![グループの権限設定](group_group_settings_permissions.png)

グループ管理者は常にすべての管理権限を保持します。権限を有効にすると、メンバーはグループ管理者にならなくても、その操作を行えるようになります。

権限では、メンバーが次の操作を行えるかどうかを設定できます。

- メンバーの追加またはゲストの招待
- お知らせの送信
- サブグループの作成
- ディスカッションの開始と管理
- タグの作成と管理
- 設定で許可されている場合のコメントの編集または削除
- 提案とアンケートの開始
- ディスカッションとアンケートのテンプレートの作成

秘密のグループ以外では、グループ管理者はメンバー以外の人によるディスカッションの開始も許可できます。メンバー以外の人がディスカッションを開始すると、そのスレッドのゲストになりますが、グループのメンバーになったり、他の非公開ディスカッションへのアクセス権を得たりすることはありません。

**管理者はメンバーのコメントを編集できます** の設定を有効にすると、グループ管理者はメンバーが書いた内容を編集できます。グループ管理者がメンバーのコメントを変更できることについて、グループで合意した場合にのみ有効にしてください。

グループの目的、メンバー構成、またはモデレーションの必要性が変わったときは、権限を見直し、各役割には必要な権限だけを付与してください。
