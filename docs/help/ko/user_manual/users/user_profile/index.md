# 프로필

프로필은 다른 사람들이 Loomio에서 누군지 알아볼 수 있도록 도와줍니다. 사진, 소개와 공유하고 싶은 기타 정보를 추가하세요.

<!-- translation-section: edit-profile -->

## 프로필 수정

사이드바에서 이름을 선택해 사용자 메뉴를 연 다음 **프로필 수정**을 선택하세요. 사이드바가 닫혀 있으면 메뉴 버튼(**☰**)으로 여세요.

![](edit_profile.png)

<!-- translation-section: update-your-personal-info -->

## 개인 정보 수정

프로필 페이지에서 다음 항목을 수정할 수 있습니다.

- **이름**
- **이메일 주소** — Loomio 계정에 연결된 이메일 주소이며, Loomio에서 보내는 알림을 받는 주소입니다.
- **사용자 이름** — 다른 사람들이 `@mention`으로 알림을 보낼 때 사용하는 이름입니다. 영문 소문자, 숫자, 밑줄을 사용할 수 있으며, 하이픈은 이름 중간에 사용할 수 있습니다.
- **소개** — 그룹의 다른 멤버에게 자신을 소개하는 짧은 글입니다.
- **지역** — 여러 지역에 흩어져 있거나 원격으로 활동하는 그룹에서 서로 어느 지역에 있는지 파악하는 데 도움이 됩니다.

![](user_profile.png)

<!-- translation-section: uploading-a-profile-photo -->

## 프로필 사진 업로드

Loomio 계정을 만들면 이름의 이니셜이 기본 프로필 사진으로 표시됩니다. 사진을 업로드하려면 프로필 페이지에서 프로필 사진을 선택하세요.

![](profile_photo.png)

<!-- translation-section: language-settings -->

## 언어

Loomio는 기본적으로 브라우저의 언어를 감지합니다. 프로필 페이지에서 원하는 언어를 선택할 수도 있습니다. 인터페이스와 콘텐츠의 번역 옵션은 [언어와 번역](../translation)을 참고하세요.

<!-- translation-section: time-zone -->

## 시간대

일정 투표의 선택지는 프로필에 저장된 시간대를 사용합니다. 브라우저의 시간대를 사용하려면 **시간대 자동 감지**를 켜세요. 직접 설정하려면 이 기능을 끄고 **시간대**에서 지역을 선택한 다음 **프로필 수정**을 선택하세요.

<!-- translation-section: resetting-your-password -->

## 비밀번호 재설정

비밀번호를 변경하려면 프로필 페이지를 열고 **비밀번호 재설정**을 선택하세요.

![](reset_password.png#width-90)

<!-- translation-section: passkeys -->

## 패스키

프로필 페이지에서 패스키를 추가하고, 이름을 지정하고, 삭제할 수 있습니다. 패스키를 사용하면 기기의 지문, 얼굴 인식, PIN 또는 보안 키로 로그인할 수 있습니다. [패스키로 로그인](../signing_in#sign-in-with-a-passkey)을 참고하세요.

<!-- translation-section: merge-accounts -->

## 계정 통합

Loomio 계정이 두 개 있으면 하나의 계정으로 통합할 수 있습니다.

[계정 통합](../merge_accounts)을 참고하세요.

<!-- translation-section: deleting-your-account -->

## 계정 삭제

Loomio 계정을 영구적으로 삭제하고 속한 그룹에서 탈퇴하려면 [Loomio 계정 삭제](../deleting_your_account)를 참고하세요.
