# 북마크

북마크는 나중에 다시 확인하고 싶은 Loomio 항목을 저장하는 개인 목록입니다. 북마크는 본인에게만 표시되며, 항목을 저장해도 다른 사람에게 알림이 전송되지 않습니다.

다음 항목을 북마크에 저장할 수 있습니다.

- 토론
- 댓글
- 제안 및 투표
- 개별 표
- 결론

<!-- translation-section: save-a-bookmark -->

## 북마크 저장

항목의 작업 메뉴를 열고 **북마크 저장**을 선택하세요. 작업 메뉴는 보통 점 세 개로 표시됩니다. 토론의 경우 토론 제목 근처의 작업 메뉴를 사용하세요. 댓글, 개별 표, 제안, 투표 또는 결론의 경우 해당 항목의 메뉴를 사용하세요.

![](save_bookmark.png)

<!-- translation-section: view-your-bookmarks -->

## 북마크 보기

사이드바를 열고 **북마크**를 선택하세요. 링크 옆의 숫자는 저장한 북마크 수를 나타냅니다.

북마크 페이지에는 가장 최근에 저장한 항목부터 표시됩니다. 각 행에는 항목 유형과 작성자가 표시됩니다. 행을 선택하면 북마크에 저장한 항목으로 돌아갑니다.

![](bookmarks_page.png)

<!-- translation-section: remove-a-bookmark -->

## 북마크 삭제

북마크 페이지에서 행 끝에 있는 북마크 삭제 버튼을 선택하세요. 북마크에 저장한 항목의 작업 메뉴를 열고 **북마크 삭제**를 선택할 수도 있습니다.

북마크를 삭제하면 개인 목록에서만 제거됩니다. 나중에 해당 항목을 다시 저장할 수 있습니다.
