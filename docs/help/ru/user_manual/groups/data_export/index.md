# Резервное копирование или экспорт данных группы

С помощью экспорта данных группы вы можете:

- Скачать данные участников для проверки состава группы.
- Архивировать или анализировать ветки, комментарии и опросы вашей группы.
- Открыть результаты опросов в электронной таблице или обработать их с помощью скрипта.
- [Распечатать ветку или опрос либо сохранить их в PDF для архива.](#print-thread-to-pdf)
- Перенести группу, включая её пользователей, ветки, опросы и файлы, на другой сервер Loomio.

Вы можете воспользоваться этой функцией для перехода с хостинга Loomio на [собственный сервер](https://github.com/loomio/loomio). Если вы используете собственный сервер и хотите перейти на управляемый хостинг Loomio в США, ЕС или Австралии, [свяжитесь с нами](/contact).

[Свяжитесь с нами](/contact), если вы хотите перенести группу с loomio.com на региональный сервис (loomio.eu для Европы или loomio.nz для Австралии и Новой Зеландии).

## Экспорт данных

Экспортировать данные группы может только администратор группы. Откройте **Настройки** на странице группы и выберите **Экспортировать данные группы**.

![Команда экспорта данных группы на странице настроек Oatmilk Cooperative](group_export_group_data.png)

Loomio подготавливает экспорт в фоновом режиме и отправляет вам по электронной почте ссылку для скачивания, когда данные готовы. Ссылка действует в течение одной недели.

<!-- translation-section: export-group-data-as-csv -->

### Экспорт данных группы в CSV

Используйте CSV для просмотра данных группы, включая сведения об участниках и их активности, в электронной таблице, например в Microsoft Excel или Google Sheets.

<!-- translation-section: export-group-data-as-html -->

### Экспорт данных группы в HTML

Используйте HTML, чтобы сохранить для архива удобную для чтения копию обсуждений и опросов вашей группы.

<!-- translation-section: export-group-data-as-json -->

### Экспорт данных группы в JSON

Используйте JSON для переноса данных группы на собственный сервер Loomio.

Экспорт в JSON включает:

- Группу, её участников и заявки на вступление
- Ветки, комментарии, реакции, теги, шаблоны, уведомления и связанные записи из включённых в экспорт групп
- Опросы, варианты, голоса и выводы; анонимный опрос включается только после его закрытия
- Подгруппы, в которых вы состоите
- Открытые, закрытые и видимые родительской группе подгруппы при экспорте их родительской группы, если вы являетесь её администратором, даже если вы не состоите в этих подгруппах
- Ссылки на файлы и изображения, прикреплённые к включённому в экспорт содержимому

Экспорт в JSON не включает:

- Секретные подгруппы, в которых вы не состоите, включая данные об их участниках и содержимое
- Подгруппы, ожидающие удаления
- Анонимные опросы, которые ещё не закрыты
- Личные ветки и опросы, которые не относятся к группе

## Печать ветки в PDF

Чтобы сохранить отдельную ветку для архива, откройте её меню действий и выберите **Печать**. Loomio создаст HTML-страницу с комментариями, опросами, голосами, выводами и форматированием ветки. Используйте функцию печати в браузере, чтобы распечатать страницу или сохранить её в формате PDF, либо скопируйте содержимое в другой документ.

## Импорт данных группы на другой сервер Loomio

Этот раздел предназначен для администраторов, обслуживающих собственный сервер Loomio. Инструкции по настройке доступны в [репозитории Loomio](https://github.com/loomio/loomio).

1. Скопируйте файл `.json` в папку `import` контейнера:

```sh
scp your-group-data.json username@some-domain.org:loomio-deploy/import
```

2. Откройте консоль Rails в работающем контейнере:

```sh
docker exec -ti loomio-app rails console
```

3. Запустите сервис импорта:

```ruby
GroupExportService.import('/import/your-group-data.json')
```
