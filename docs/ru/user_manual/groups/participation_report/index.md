# Отчёт об участии

Отчёт об участии в группе показывает, как используется ваша группа в Loomio.

Вы можете выбрать группы для включения в отчёт, даты начала и окончания отчётного периода и интервал для группировки результатов: год, месяц, неделю или день.

Отчёт доступен всем участникам вашей группы, однако пользователи видят результаты только тех групп, в которых состоят. Поэтому отчёты разных пользователей могут немного различаться.

Чтобы открыть отчёт, нажмите значок шестерёнки в меню настроек группы, как показано ниже.

![Пункт «Отчёт об участии» в меню группы Oatmilk Cooperative](group_participation_report.png)

## Что входит в отчёт?

<!-- translation-section: actions-per-month -->

### Действия по месяцам

Узнайте, насколько активно участники вашей группы участвуют в её работе за определённый период.

Отчёт показывает количество веток, комментариев, опросов, голосов и реакций за каждый месяц. График помогает увидеть рост и спад активности.

Нажмите нужные подписи на графике, чтобы скрыть соответствующие данные.

Нажмите заголовок столбца в таблице, чтобы отсортировать данные по этому столбцу.

![Элементы управления отчётом об участии, итоговые показатели и график активности группы Oatmilk Cooperative](group_participation_report_graph.png)

<!-- translation-section: tag-usage -->

### Использование тегов

Этот раздел показывает, как часто применялись различные теги за указанный период. Например, вы можете увидеть количество решений, принятых с использованием определённого процесса принятия решений или шаблона.

![Использование тегов «Производство», «Партнёрство с кафе» и «Операционная деятельность» с течением времени](group_participation_report_tags.png)

<!-- translation-section: actions-per-user -->

### Действия по пользователям
Узнайте, кто участвует в работе вашей группы наиболее и наименее активно.

Таблица показывает, сколько веток, комментариев, опросов, голосов и реакций приходится на каждого пользователя выбранных групп за указанный период. Нажмите заголовок столбца в таблице, чтобы отсортировать данные по этому столбцу.

Включите **Только для делегатов**, чтобы показать людей, которые сейчас являются делегатами хотя бы в одной из выбранных групп. Их активность и данные об участии в опросах суммируются по всем выбранным группам. Делегаты, у которых не было активности за выбранный период, остаются в таблице. При скачивании CSV применяется тот же фильтр.

![Действия делегатов с тремя уровнями участия](group_participation_report_actions_per_user.png)

<!-- translation-section: voting-record-per-user -->

### Участие в опросах по пользователям

Сравните количество голосов, которые каждому человеку было предложено подать, с количеством поданных голосов, просмотрите пропущенные голоса и найдите людей, подавших все предложенные им голоса. Человек, которому не предлагалось подать ни одного голоса, не отмечается как подавший все голоса. Анонимные опросы исключены, поскольку анонимный голос нельзя связывать с человеком, который его подал.

Включите **Только для делегатов**, чтобы просмотреть данные об участии нынешних делегатов в опросах. При скачивании CSV применяются те же фильтры по имени и статусу делегата.

![Данные об участии делегатов в опросах: предложенные, поданные и пропущенные голоса](group_participation_report_voting_record.png)

### Пользователи по странам

Количество пользователей вашей группы в каждой стране, определяемой по их текущим IP-адресам.

![Пользователи выбранных групп по странам](group_participation_report_users_per_country.png)

### Действия по странам

Узнайте, в каких странах пользователи участвуют наиболее и наименее активно.

Этот раздел похож на раздел «Действия по пользователям», но данные сгруппированы по стране, в которой, согласно определённому местоположению, находится пользователь.
