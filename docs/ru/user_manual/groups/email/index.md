# Отправьте письмо, чтобы создать ветку в вашей группе

У вашей группы в Loomio есть адрес электронной почты! Вы можете отправить или переслать письмо на этот адрес, чтобы создать ветку в группе.

Адрес электронной почты вашей группы указан на странице группы:
![Расположение адреса электронной почты на странице группы](email_email_button.png)

Когда вы отправите письмо на этот адрес, будет создана новая ветка. Тема письма станет заголовком ветки, текст письма — её описанием, а все вложенные файлы будут прикреплены к ветке.

По адресу в поле «От» Loomio определяет участника группы, который станет автором ветки.

## Защита от писем посторонних отправителей

Чтобы этой функцией могли пользоваться только участники вашей группы, Loomio проверяет, совпадает ли адрес в поле «От» входящего письма с адресом одного из участников группы.

Если вы используете несколько адресов электронной почты, вы можете добавить дополнительный адрес, чтобы Loomio распознавал письма с других ваших адресов.

Если адрес в поле «От» не совпадает с адресом участника группы, вы получите уведомление с предложением добавить дополнительный адрес или отклонять все последующие письма с этого адреса.

Это означает, что при первой отправке письма с неизвестного адреса вам потребуется добавить его как дополнительный. После этого письма будут приниматься сразу.

![Расположение кнопок принятия и отклонения письма с неизвестного адреса](email_unreleased_emails.png)
