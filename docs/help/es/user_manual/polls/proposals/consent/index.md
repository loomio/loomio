# Consentimiento

Una propuesta de consentimiento pregunta si es seguro poner a prueba una línea de acción. Los participantes dan su consentimiento o plantean una objeción. Una objeción identifica un riesgo o daño concreto que la propuesta debe abordar.

Esta página explica cómo llevar a cabo una propuesta de consentimiento. Consulta el [Proceso de consentimiento](/en/guides/making_decisions/consent_process) para conocer el proceso completo, incluidas las preguntas, la toma de pulso, las modificaciones, las objeciones y la conclusión.

<!-- translation-section: when-to-use-consent -->

## Cuándo usar el consentimiento

Usa el consentimiento cuando el grupo necesite una decisión viable que pueda llevarse a cabo salvo que haya una objeción válida. Es adecuado para experimentos, políticas operativas, acuerdos sobre roles y otras decisiones que el grupo pueda revisar tras adquirir experiencia.

El consentimiento no exige que la propuesta sea la opción preferida de todos. Define qué se considera una objeción antes de votar y explica cómo se evaluarán y resolverán las objeciones.

## Ejemplo: iniciar una prueba con botellas retornables

La cooperativa Oatmilk propone iniciar el próximo mes una prueba de seis semanas con botellas retornables. La prueba tiene un alcance limitado e incluye una revisión, por lo que el grupo pregunta si es seguro ponerla en práctica.

<!-- translation-section: set-up-the-proposal -->

## Configura la propuesta

Describe la acción propuesta, sus límites, las medidas de protección y el momento de revisión. Define con precisión qué significan **Consentimiento** y **Objeción**, y exige un motivo para las objeciones para que se pueda comprender y abordar la preocupación.

![](form.png)

<!-- translation-section: vote -->

## Vota

Los participantes seleccionan **Consentimiento** cuando la propuesta es lo suficientemente segura para ponerla a prueba, aunque no sea el plan que prefieren. Seleccionan **Objeción** cuando pueden describir un riesgo o daño significativo.

![](../proposal_consent_voting.png)

<!-- translation-section: read-the-results -->

## Lee los resultados

El gráfico muestra las objeciones, pero el grupo debe examinar los motivos. Resuelve una objeción válida modificando la propuesta, añadiendo una medida de protección, cambiando el alcance o decidiendo no seguir adelante.

![](../proposal_consent_results.png)

<!-- translation-section: share-an-outcome -->

## Comparte una conclusión

Cuando se cierre la propuesta, comparte una conclusión. Registra la acción acordada, cómo se resolvieron las objeciones, quién es responsable y cuándo la revisará el grupo. Consulta [Comparte una conclusión](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome) para saber cómo funcionan las conclusiones.
