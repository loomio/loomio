# עיצוב

בעת פתיחה או עריכה של דיון או משאל, או בעת כתיבת תגובה, מופיע סרגל עיצוב מתחת לשדה הטקסט. ניתן לבחור בחץ שבקצה הסרגל כדי להציג או להסתיר את כל הכלים.

כדי לראות את שם הכלי, יש להשהות מעליו את סמן העכבר.

![](thread_format_bar.png)

העיצוב מאפשר להוסיף מבנה והדגשה, כך שקל יותר לסרוק את המידע.

<!-- translation-section: attach-file -->

## צירוף קובץ

כדי לצרף קבצים מהמחשב, יש לבחור בסמל המהדק שמתחת לשדה הטקסט.

![](format_attach.png)

<!-- translation-section: remove-attachments -->

### הסרת קבצים מצורפים

בעת עריכת התוכן, יש ללחוץ על **X** שמשמאל לשם הקובץ כדי להסיר אותו.

![](thread_file_remove.png)

<!-- translation-section: insert-image -->

## הוספת תמונה

כלי זה מאפשר להוסיף תמונה ולהציג אותה.

![](format_insert_image.png)

יש לבחור קובץ תמונה מהמחשב. לאחר העלאת הקובץ, התמונה תתווסף לעורך.

![](format_insert_example.png)

התמונה תופיע בדיון, במשאל או בתגובה לאחר הפרסום.

>[!Tip]
>ניתן גם להעתיק ולהדביק תמונה ישירות ב־Loomio.

![](format_image_example.png)

<!-- translation-section: insert-link -->

## הוספת קישור

ניתן להוסיף קישור לכל מסמך או דף באינטרנט שאפשר לשתף.

כדי להוסיף קישור:

1. יש לסמן את הטקסט שאליו רוצים להוסיף קישור, למשל שם של מסמך.
2. יש ללחוץ על סמל הקישור.
3. יש להדביק את הכתובת בשדה **הכנס לינק** ולבחור **החל**.

אם המסמך מאוחסן במקום אחר, יש לבדוק את הרשאות השיתוף שלו כדי שמשתתפי הדיון יוכלו לפתוח אותו.

תצוגה מקדימה של המסמך תופיע מתחת לשדה הטקסט. ניתן להסיר אותה.

כעת, כל מי שיש להם גישה לדיון ב־Loomio והרשאה לצפות במסמך יוכלו לפתוח ולקרוא אותו.

![](format_link.png)

## כותרות

כותרות ברמות 1, 2 ו־3 עוזרות לארגן דיון או תגובה.

יש לסמן את הטקסט שישמש ככותרת ולבחור בכלי לעיצוב כותרות.

כאשר משתמשים בכותרת בתגובה, התגובה תוצמד אוטומטית לציר הזמן של הדיון.

![](format_heading.png)

![](format_bold.png)

## רשימת מטלות

![](format_tasks.png)

![](thread_colors.png)

## יישור

ניתן לבחור יישור טקסט לשמאל, למרכז או לימין.

![](thread_align.png)

## הטמעת סרטונים ודפי אינטרנט

ניתן להטמיע סרטונים ודפי אינטרנט נתמכים בכל מקום שבו מופיע סרגל עיצוב.

כדי להטמיע סרטון או דף אינטרנט: 
1. יש להעתיק את הכתובת של הסרטון או דף האינטרנט.
2. יש לבחור **הטמע וידאו**, להדביק את הכתובת ולבחור **החל**.

![](format_embed.png)

## Markdown

כדי לעבור לעריכה ב־Markdown, יש לבחור **ערוך Markdown**.

אם כבר יש טקסט בשדה, חלק מהעיצוב עשוי ללכת לאיבוד בעת ההמרה.

<!-- translation-section: rich-text -->

### טקסט עשיר

כדי לחזור לכלי העיצוב, יש לבחור **עריכת טקסט עשיר**. פעולה זו מציגה רכיבי Markdown נתמכים בצורתם המעוצבת.

**תצוגה מקדימה** מראה כיצד ייראה הטקסט לאחר הפרסום, בלי להמיר אותו.
