# Encuestas

Las encuestas recogen selecciones, puntuaciones, repartos de puntos, órdenes de preferencia, disponibilidad o votos electorales. Elige el método de votación según lo que los participantes necesiten expresar y cómo quieras utilizar el resultado. Utiliza una [propuesta](/en/user_manual/polls/proposals/) cuando las personas necesiten responder a una declaración o a un curso de acción.

| Qué quieres hacer | Método | Cómo funciona el resultado |
| --- | --- | --- |
| Encontrar opciones populares o crear una lista de preselección | [Elegir](/en/user_manual/polls/choose) (opción múltiple) | Cuenta las selecciones de cada opción |
| Comparar el grado de apoyo a las opciones | [Puntuar](/en/user_manual/polls/score) | Combina las puntuaciones en una escala común |
| Establecer prioridades con un número limitado de puntos | [Repartir](/en/user_manual/polls/allocate) (votación por puntos) | Suma los puntos repartidos a cada opción |
| Ordenar las opciones por preferencia | [Ordenar](/en/user_manual/polls/rank) (votación preferencial) | Combina los órdenes de preferencia en un orden basado en puntos |
| Encontrar un horario para una reunión | [Encuesta de horario](/en/user_manual/polls/meeting_polls) | Muestra la disponibilidad para cada horario |
| Elegir a varios representantes de forma proporcional | [Elección STV](/en/user_manual/polls/stv) | Cuenta los votos con candidatos ordenados por preferencia para elegir a varios ganadores |

<!-- translation-section: simple-poll -->

## Encuesta simple

[Elegir](/en/user_manual/polls/choose/) permite a los participantes seleccionar una o varias opciones. Utilízalo para encontrar la opción más popular o crear una lista reducida.

<!-- translation-section: score-poll -->

## Encuesta de puntuación

[Puntuar](/en/user_manual/polls/score/) permite a los participantes valorar cada opción con la misma escala. Utilízalo para comparar el grado de apoyo, preparación, idoneidad o importancia de las distintas opciones.

<!-- translation-section: dot-vote -->

## Votación por puntos

[Repartir](/en/user_manual/polls/allocate/) da a cada participante una cantidad fija de puntos para distribuir. Utilízalo para identificar prioridades cuando elegir una cosa implique dedicar menos atención o recursos a otra.

<!-- translation-section: ranked-choice -->

## Votación preferencial

[Ordenar](/en/user_manual/polls/rank/) permite a los participantes ordenar las opciones según sus preferencias. Utilízalo para conocer el orden de preferencia general del grupo o seleccionar la opción preferida.

<!-- translation-section: time-poll -->

## Encuesta de horario

La [encuesta de horario](/en/user_manual/polls/meeting_polls/) permite a los participantes indicar cuándo están disponibles. Utilízala para programar una reunión o un evento entre personas de distintas zonas horarias.

<!-- translation-section: stv-election -->

## Elección STV

Las [elecciones STV](/en/user_manual/polls/stv/) permiten a los participantes ordenar los candidatos según sus preferencias en una elección proporcional con varios puestos a cubrir. Utiliza STV para elegir un comité, una junta directiva o un grupo de delegados.
