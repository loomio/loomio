# Permissions du groupe

L’onglet des permissions définit les actions que les membres ordinaires peuvent effectuer dans le groupe et, pour les groupes non secrets, celles qui sont ouvertes aux personnes non membres. Sur la page du groupe, ouvrez **Modifier les paramètres du groupe**, puis sélectionnez **Permissions**.

![Paramètres des permissions du groupe](group_group_settings_permissions.png)

Les administrateurs conservent la possibilité de gérer le groupe. Activer une permission pour les membres leur donne accès à l’action concernée, sans en faire des administrateurs.

Les permissions déterminent notamment si les membres peuvent :

- ajouter des membres ou inviter des personnes ;
- envoyer des annonces ;
- créer des sous-groupes ;
- lancer et gérer des discussions ;
- créer et gérer des tags ;
- modifier ou supprimer des commentaires lorsque le paramètre le permet ;
- lancer des propositions et des sondages ; et
- créer des modèles de discussion et de sondage.

Dans les groupes non secrets, les administrateurs peuvent aussi autoriser séparément les personnes non membres à lancer des discussions. Une personne non membre qui lance une discussion en devient invitée. Elle n’obtient pas pour autant l’accès aux autres discussions privées et ne devient pas membre du groupe.

Le paramètre **Les administrateurs peuvent modifier les commentaires des membres** donne aux administrateurs une capacité de modération exceptionnelle. Activez-le uniquement si le groupe a convenu que les administrateurs peuvent modifier le contenu rédigé par les membres.

Réexaminez les permissions lorsque l’objectif du groupe, sa composition ou les responsabilités de modération changent. Accordez à chaque rôle uniquement les permissions dont il a besoin.
