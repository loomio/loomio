# ディスカッションの概要

Loomioのディスカッションでは、グループで情報を共有し、話し合い、意思決定できます。コメントや返信を投稿して参加します。

- トピックに関する情報を、アクセスしやすい一か所にまとめられます。
- メールで返信すると、そのコメントがディスカッションに表示されます。
- 誰がディスカッションを読んだか、誰に参加を促す必要があるかを確認できます。
- 話し合いの記録を後から簡単に見つけられます。

ディスカッションは、一般的な意見交換の場から、具体的な作業手順や意思決定の進行まで、幅広く使えます。

たとえば、特定のトピックについてディスカッションを立ち上げ、意見や情報を募り、合意できる結論に向けて話し合いを進められます。

また、同意や助言をもとにした意思決定の方法を使い、特定の決定への参加を呼びかけることもできます。

ディスカッションには投票や提案を含め、結論に向けて話し合いを進めることもできます。コメントや投票が行われると、ディスカッションのタイムラインに記録が蓄積され、重要な節目を簡単に見つけられます。

## よくある使い方

ディスカッションの一般的な使い方を紹介します。

<!-- translation-section: boards-and-governance -->

### 理事会と組織運営

**会議の準備をする** - 議題をまとめ、理事会の資料を投稿し、運営上の事項を整理します。全員が状況を把握し、会議に備えられます。

**決議案を可決する** - 経緯や背景情報を投稿し、質問に答え、決議のための提案を出します。

**Loomioで議題を話し合う** - 会議の前に議題について話し合いを始めます。会議中に時間が足りなくなった場合は、Loomioで話し合いを続けられます。

**議事録を承認し、対応事項を管理する** - 議事録を投稿して担当者を決めます。投票を使って議事録を承認できます。

<!-- translation-section: member-participation -->

### メンバーの参加

**お知らせを共有する（メーリングリストの代わりに使う）** - メンバーに情報を投稿し、コメントを募ります。

**イベントを企画する** - 運営チームで詳細を検討します。話し合いと情報をスレッドにまとめ、決まった内容をほかのメンバーに知らせます。

**方針を策定する** - 方針案を投稿し、メンバーの意見を集めて仕上げ、正式に承認します。

**総会を開く** - 全メンバーが参加する正式な会議を企画・準備・開催し、重要な方針について審議して決定します。

<!-- translation-section: self-organizing-working-teams -->

### 自律的に活動するチーム

**情報を共有する** - チームに関係する情報や報告を投稿し、コメントや話し合いを募ります。

**作業を進める** - 作業内容を示し、完了までチームメンバーから助言や意見、フィードバックを集めます。

**会議の記録と対応事項を管理する** - 会議の記録を話し合いの履歴として投稿し、作業の進捗を確認します。

**アイデアを検討する** - 気づいた課題や改善できそうな点について考えを共有し、話し合いを募ります。

**助言・同意・創発的な意思決定を行う** - 準備、提案、内容の確認、反応や異議への対応、合意、実施までを、Loomioのディスカッション内で進めます。
