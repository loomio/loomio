# Discussões diretas

Uma discussão direta é uma conversa privada para pessoas específicas. Ela não pertence a um grupo, e as pessoas convidadas não precisam pertencer a nenhum grupo do Loomio.

Adicione pessoas ou endereços de e-mail ao campo **Convidar** para escolher quem pode ver e participar.

As discussões diretas oferecem os mesmos comentários, enquetes e ferramentas de formatação que as discussões em grupo. Elas são úteis para conversas privadas ou rascunhos quando não é necessário criar um subgrupo.

![Um formulário de discussão direta sem nenhum grupo selecionado e com Samira Patel no campo Convidar](direct-discussion-example.png)

Selecione **Tópicos diretos** na barra lateral para ver suas discussões diretas e enquetes. Ali, abra **Novo** e escolha **Nova discussão** para iniciar uma discussão direta ou **Nova enquete** para iniciar uma enquete sem um grupo.

Uma enquete direta fica visível apenas para as pessoas que você convida. Depois de criá-la, use [Gerenciar eleitores](/en/user_manual/polls/manage_voters) para convidar pessoas ou endereços de e-mail.

![O item Tópicos diretos na barra lateral e a lista de discussões diretas](direct-discussion-sidebar.png)

## Mover uma discussão direta para um grupo

Se uma conversa privada ou um rascunho passar a tratar de um assunto do grupo, você pode movê-la para um grupo ou subgrupo depois. Veja [Mover uma conversa](/en/user_manual/discussions/using_discussions/#move-a-thread).
