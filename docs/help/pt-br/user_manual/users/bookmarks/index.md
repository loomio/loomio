# Favoritos

Os favoritos são uma lista pessoal de itens do Loomio que você quer acessar novamente. Seus favoritos são visíveis apenas para você, e salvar um item não notifica outras pessoas.

Você pode adicionar aos favoritos:

- discussões
- comentários
- propostas e enquetes
- votos
- conclusões

<!-- translation-section: save-a-bookmark -->

## Salvar um marcador

Abra o menu de ações do item e selecione **Salvar marcador**. O menu de ações geralmente aparece como três pontos. Para uma discussão, use o menu de ações próximo ao título da discussão; para um comentário, voto, proposta, enquete ou conclusão, use o menu do próprio item.

![](save_bookmark.png)

<!-- translation-section: view-your-bookmarks -->

## Ver seus favoritos

Abra a barra lateral e selecione **Favoritos**. O número ao lado do link mostra quantos favoritos você salvou.

A página Favoritos lista primeiro os itens que você salvou mais recentemente. Cada linha mostra o tipo de item e seu autor. Selecione uma linha para acessar novamente o item salvo nos favoritos.

![](bookmarks_page.png)

<!-- translation-section: remove-a-bookmark -->

## Remover um marcador

Na página Favoritos, selecione o botão de remover marcador no final de uma linha. Você também pode abrir o menu de ações do item salvo nos favoritos e selecionar **Remover marcador**.

Remover um marcador afeta apenas sua lista pessoal. Você pode salvar o item novamente mais tarde.
