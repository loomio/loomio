# グループ設定

グループ設定では、グループの表示方法、グループを見つけて参加できる人、メンバーができることを設定します。設定を編集できるのはグループ管理者だけです。

グループのページでアクションメニューを開き、**グループ設定を編集する**を選択します。

![グループのページからグループ設定を編集する](group_settings.png)

設定フォームは次の3つの項目に分かれています。

<!-- translation-section: group-profile -->

## グループのプロフィール

[グループのプロフィール](/en/user_manual/groups/settings/profile)では、グループ名、ハンドル、説明、カバー画像、ロゴを設定します。

<!-- translation-section: group-privacy -->

## グループのプライバシー

[グループのプライバシー](/en/user_manual/groups/settings/privacy)では、グループを見つけられる人、コンテンツを読める人、参加方法、ディレクトリへの掲載、オープングループのフォローについて設定します。

<!-- translation-section: group-permissions -->

## グループの権限

[グループの権限](/en/user_manual/groups/settings/permissions)では、メンバー、メンバー以外の人、管理者が実行できる操作を設定します。
