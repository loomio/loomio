# Tags on contributions

You can now tag individual polls, outcomes, and comments, as well as the opening discussion. Use **Apply tags** in a contribution's action menu, or the existing tag picker beside the discussion title. Organization tags and their colors are shared across these contributions; votes and ballots cannot be tagged.

The thread sidebar shows a **Tags** section once an item beyond the opening discussion or poll is tagged. The section collects all tags used in the thread. Select one to show matching contributions with parent context. Timeline entries continue to provide shortcuts to individual contributions. Use **Add to timeline** and **Remove from timeline** to manage these shortcuts; the menu actions use timeline icons to distinguish them from pinning a thread to the top of a group's thread list. The group thread list includes a thread when any eligible contribution carries the selected tag.

Global search now matches explicitly tagged contributions. Select a tag to browse without a search phrase, or combine it with words to search within those contributions. Existing thread tags have been preserved on each thread's opening discussion or poll.

Authors and thread coordinators can tag contributions in unlocked threads, including closed polls. Existing discussion-edit permissions also allow members to tag the opening discussion. The **Members can create tags** setting still controls new tag names, and parent-group admins still manage tag names and colors across the organization. Authors can tag their comments regardless of poll result visibility. Tags remain shared metadata if results become hidden again. For polls that hide results until closing, hidden comments leave the search index immediately.

Discussion and poll templates keep independent lists of default tag names. Template authors can edit these freely without adding tags to the organization. Members without permission to create tags can use existing organization tags and names prescribed by available templates in the destination group. When starting content from a template belonging to another group, other tag names are dropped while the content is saved.
