# Mover itens entre conversas

Mova comentários ou enquetes quando uma discussão pertencer a outra conversa, quando uma discussão se dividir em assuntos separados ou quando você quiser combinar conversas relacionadas.

Admins do grupo podem mover itens. Membros também podem mover itens quando **Os membros podem gerenciar discussões e comentários.** estiver habilitado em [Permissões do grupo](/en/user_manual/groups/settings/permissions).

1. Abra o menu de três pontos (**⋯**) de um item e selecione **Mover item**.

![](../using_discussions/comment_move.png)

2. Use as caixas de seleção para selecionar os itens que você quer mover e selecione **Mover** na faixa no topo da conversa.

![](../using_discussions/comment_select.png)

![](../using_discussions/move_items.png)

3. Escolha o grupo ou subgrupo de destino e procure uma discussão existente. Para criar uma nova discussão, selecione **Nova discussão**, adicione um título e um contexto e selecione **Iniciar discussão**.

![](../using_discussions/move_items_new_thread.png)

Os itens selecionados são movidos da conversa original para a conversa de destino.

![](../using_discussions/new_thread.png)

Se a conversa original não for mais necessária, você pode [bloqueá-la](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread). Exclua-a somente se tiver certeza de que você não precisará dela novamente.
