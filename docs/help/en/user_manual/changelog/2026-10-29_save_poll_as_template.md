# Save a poll as a reusable template

Use **Save as template** in a proposal or poll's action menu to reuse its content, voting options, explanations, and settings. This replaces **Make a copy** in the poll menu.

The action opens a prefilled template form with guidance and a link to the [poll template guide](/en/user_manual/polls/poll_templates). Review the example content, name the template, and save it. People in the group can then choose it when starting a new poll.

Group admins can save templates, along with members when **Members can create templates** is enabled. Voting dates, voters, votes, results, and outcomes stay with the original poll.
