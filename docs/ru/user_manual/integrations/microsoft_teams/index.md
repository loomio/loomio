# Интеграция с Microsoft Teams
_Подключите уведомления вашей группы Loomio к Microsoft Teams._

Loomio может отправлять уведомления в Microsoft Teams о новых обсуждениях, предложениях, комментариях, голосах и итогах.

---

Откройте [https://teams.microsoft.com](https://teams.microsoft.com) и нажмите **Приложения**
![](t1.png)

Введите «webhook» в строке поиска и выберите **Входящий вебхук**
![](t2.png)

Нажмите **Добавить в команду**
![](t3.png)

Введите название канала, в котором должны появляться уведомления Loomio, и выберите его.
![](t4.png)

Укажите название, например «Уведомления Loomio», затем нажмите **Создать**
![](t5.png)

Скопируйте полученный URL. На последнем шаге вы вставите его в Loomio.
![](t6.png)

_Loomio не создана Microsoft, не связана с ней и не поддерживается ею._

Теперь, когда у вас есть URL вебхука, продолжите настройку интеграции с чатом:

[Настройте интеграцию с чатом в Loomio](../chatbots/#set-up-a-chat-integration)
