# שילובים

ניתן לחבר את Loomio לכלים אחרים המשמשים את הקבוצה.

<!-- translation-section: choose-where-work-belongs -->

## בחירת המקום המתאים לעבודה

Loomio משלים צ׳אט, מסמכים משותפים וכלים לניהול משימות, במקום להחליף את כל סוגי העבודה.

| עבודה | כלי מוצע |
|---|---|
| שאלות קצרות, שיחה חברתית ועדכונים בזמן | צ׳אט |
| עריכה משותפת של מסמך שמתעדכן באופן שוטף | מסמך משותף |
| הקצאת משימות ומעקב אחריהן | כלי לניהול פרויקטים או משימות |
| דיון חשוב סביב נושא, השתתפות רחבה, החלטות ומסקנות | Loomio |

יש להעביר עבודה ל־Loomio כשנדרש זמן לשקול נושא, כשיש לתת לכל מי שמושפע ממנו הזדמנות משמעותית להשתתף, או כשהקבוצה תצטרך למצוא את הדיון ואת ההחלטה בהמשך. יש לקשר מתוך הדיון ב־Loomio למסמך או למשימה הרלוונטיים, כדי שיהיה קל למצוא את ההקשר.
