# Рэзервовае капіраванне або экспарт дадзеных групы

З дапамогай экспарту дадзеных групы вы можаце:

- Спампаваць дадзеныя ўдзельнікаў групы, каб праверыць яе склад.
- Архіваваць або аналізаваць тэмы, каментарыі і апытанні вашай групы.
- Адкрыць вынікі апытання ў электроннай табліцы або апрацаваць іх з дапамогай скрыпта.
- [Раздрукаваць тэму або апытанне ці захаваць іх у PDF для ўласнага архіва.](#print-thread-to-pdf)
- Перанесці вашу групу разам з карыстальнікамі, тэмамі, апытаннямі і файламі на іншы сервер Loomio.

Вы можаце скарыстацца гэтай функцыяй, каб перайсці з хостынгу Loomio на [ўласны сервер](https://github.com/loomio/loomio). Калі вы падтрымліваеце ўласны сервер і хочаце перайсці на хостынг з абслугоўваннем ад Loomio ў ЗША, ЕС або Аўстраліі, [звяжыцеся з намі](/contact).

[Звяжыцеся з намі](/contact), калі вы хочаце перанесці групу з loomio.com на рэгіянальны сэрвіс (loomio.eu для Еўропы або loomio.nz для Аўстраліі і Новай Зеландыі).

## Экспарт дадзеных

Экспартаваць дадзеныя групы могуць толькі адміністратары групы. Адкрыйце **Налады** на старонцы групы і выберыце **Экспартаваць дадзеныя групы**.

![Дзеянне экспарту дадзеных групы на старонцы налад Oatmilk Cooperative](group_export_group_data.png)

Loomio рыхтуе экспарт у фонавым рэжыме і дасылае вам па электроннай пошце спасылку для спампоўвання, калі экспарт гатовы. Спасылка дзейнічае на працягу аднаго тыдня.

<!-- translation-section: export-group-data-as-csv -->

### Экспарт дадзеных групы ў CSV

Выкарыстоўвайце CSV, каб праглядаць дадзеныя групы, у тым ліку звесткі пра ўдзельнікаў і іх актыўнасць, у электроннай табліцы, напрыклад у Microsoft Excel або Google Sheets.

<!-- translation-section: export-group-data-as-html -->

### Экспарт дадзеных групы ў HTML

Выкарыстоўвайце HTML, каб захаваць зручную для чытання копію абмеркаванняў і апытанняў вашай групы для архівавання.

<!-- translation-section: export-group-data-as-json -->

### Экспарт дадзеных групы ў JSON

Выкарыстоўвайце JSON, каб перанесці дадзеныя вашай групы на ўласны сервер Loomio.

Экспарт у JSON уключае:

- Групу, яе ўдзельнікаў і запыты на ўступленне
- Тэмы, каментарыі, рэакцыі, тэгі, шаблоны, апавяшчэнні і звязаныя запісы з уключаных груп
- Апытанні, варыянты, галасы і высновы; ананімнае апытанне ўключаецца толькі пасля яго закрыцця
- Падгрупы, у якіх вы ўдзельнічаеце
- Адкрытыя, закрытыя і бачныя для бацькоўскай групы падгрупы, калі вы экспартуеце іх бацькоўскую групу з правамі адміністратара бацькоўскай групы, нават калі вы не ўдзельнічаеце ў гэтых падгрупах
- Спасылкі на файлы і выявы, далучаныя да ўключанага змесціва

Экспарт у JSON не ўключае:

- Сакрэтныя падгрупы, у якіх вы не ўдзельнічаеце, у тым ліку іх склад і змесціва
- Падгрупы, якія чакаюць выдалення
- Ананімныя апытанні, якія яшчэ не закрытыя
- Прамыя тэмы і апытанні, якія не належаць да групы

## Друк тэмы ў PDF

Каб захаваць асобную тэму для ўласнага архіва, адкрыйце яе меню дзеянняў і выберыце **Друк**. Loomio стварае HTML-старонку з каментарыямі, апытаннямі, галасамі, высновамі і фарматаваннем тэмы. Скарыстайцеся інструментам друку ў вашым браўзеры, каб раздрукаваць яе або захаваць у PDF, ці скапіюйце змесціва ў іншы дакумент.

![Дзеянне друку для абмеркавання зваротных бутэлек](discussion_print_discussion.png#width-90)

## Імпарт дадзеных вашай групы на іншы сервер Loomio

Гэты раздзел прызначаны для адміністратараў, якія падтрымліваюць уласны сервер Loomio. Інструкцыі па наладжванні глядзіце ў [рэпазіторыі Loomio](https://github.com/loomio/loomio).

1. Скапіюйце файл `.json` у папку `import` кантэйнера:

```sh
scp your-group-data.json username@some-domain.org:loomio-deploy/import
```

2. Адкрыйце кансоль Rails у запушчаным кантэйнеры:

```sh
docker exec -ti loomio-app rails console
```

3. Запусціце сэрвіс імпарту:

```ruby
GroupExportService.import('/import/your-group-data.json')
```
