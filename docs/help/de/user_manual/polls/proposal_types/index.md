# Abstimmungen

Abstimmungen erfassen ausgewählte Optionen, Bewertungen, Punkteverteilungen, Rangfolgen, Verfügbarkeiten oder Wahlstimmen. Wähle die Abstimmungsart danach aus, was die Teilnehmenden ausdrücken müssen und wie du das Ergebnis verwenden möchtest. Verwende einen [Vorschlag](/en/user_manual/polls/proposals/), wenn Menschen zu einer Aussage oder einem geplanten Vorgehen Stellung nehmen sollen.

| Was du tun möchtest | Abstimmungsart | Wie das Ergebnis ermittelt wird |
| --- | --- | --- |
| Beliebte Optionen finden oder eine Vorauswahl treffen | [Auswählen](/en/user_manual/polls/choose) (Mehrfachauswahl) | Zählt, wie oft jede Option ausgewählt wurde |
| Vergleichen, wie stark Optionen unterstützt werden | [Bewerten](/en/user_manual/polls/score) | Führt Bewertungen auf einer gemeinsamen Skala zusammen |
| Mit einer begrenzten Anzahl von Punkten Prioritäten setzen | [Verteilen](/en/user_manual/polls/allocate) (Punktabstimmung) | Summiert die Punkte, die auf jede Option verteilt wurden |
| Optionen nach Präferenz ordnen | [Ordnen](/en/user_manual/polls/rank) (Rangfolge) | Führt Rangfolgen zu einer auf Punkten basierenden Reihenfolge zusammen |
| Einen Besprechungstermin finden | [Terminfindung](/en/user_manual/polls/meeting_polls) | Zeigt die Verfügbarkeit für jeden Termin |
| Mehrere Vertretungspersonen nach dem Verhältniswahlprinzip wählen | [STV-Wahl](/en/user_manual/polls/stv) | Zählt Stimmzettel mit Rangfolgen aus, um mehrere Personen zu wählen |

<!-- translation-section: simple-poll -->

## Einfache Abstimmung

[Auswählen](/en/user_manual/polls/choose/) ermöglicht es Teilnehmenden, eine oder mehrere Optionen auszuwählen. Verwende diese Abstimmungsart, um die beliebteste Option zu finden oder eine engere Auswahl zu erstellen.

<!-- translation-section: score-poll -->

## Bewertung

[Bewerten](/en/user_manual/polls/score/) ermöglicht es Teilnehmenden, jede Option auf derselben Skala zu bewerten. Verwende diese Abstimmungsart, um zu vergleichen, wie stark die Optionen unterstützt werden oder wie sie hinsichtlich Bereitschaft, Eignung oder Wichtigkeit bewertet werden.

<!-- translation-section: dot-vote -->

## Punktabstimmung

[Verteilen](/en/user_manual/polls/allocate/) gibt allen Teilnehmenden jeweils eine feste Anzahl von Punkten zum Verteilen. Verwende diese Abstimmungsart, um Prioritäten zu bestimmen, wenn die Entscheidung für eine Sache bedeutet, dass für eine andere weniger Aufmerksamkeit oder Ressourcen bleiben.

<!-- translation-section: ranked-choice -->

## Rangfolge

[Ordnen](/en/user_manual/polls/rank/) ermöglicht es Teilnehmenden, Optionen nach ihren Präferenzen zu ordnen. Verwende diese Abstimmungsart, um die von der Gruppe insgesamt bevorzugte Reihenfolge zu ermitteln oder die bevorzugte Option auszuwählen.

<!-- translation-section: time-poll -->

## Terminfindung

[Terminfindung](/en/user_manual/polls/meeting_polls/) ermöglicht es Teilnehmenden, anzugeben, wann sie verfügbar sind. Verwende diese Abstimmungsart, um ein Treffen oder eine Veranstaltung über mehrere Zeitzonen hinweg zu planen.

<!-- translation-section: stv-election -->

## STV-Wahl

[STV-Wahlen](/en/user_manual/polls/stv/) ermöglichen es Teilnehmenden, Kandidierende bei einer proportionalen Wahl mit mehreren zu besetzenden Sitzen nach ihren Präferenzen zu ordnen. Verwende STV, um einen Ausschuss, einen Vorstand oder eine Gruppe von Delegierten zu wählen.
