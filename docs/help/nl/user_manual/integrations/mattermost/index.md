# Mattermost-integratie

Loomio kan meldingen naar jouw Mattermost-kanalen sturen wanneer er nieuwe discussies, peilingen, reacties, stemmen en conclusies zijn.

---

1. Open jouw Mattermost-team in een browser en ga naar **Integraties**.

   ![](mm1.png)

2. Selecteer **Inkomende webhooks**.

   ![](mm2.png)

3. Selecteer **Inkomende webhook toevoegen**.

   ![](mm3.png)

4. Voer een naam in, kies het kanaal waarin je meldingen wilt ontvangen en selecteer **Bewaren**.

   ![](mm4.png)

5. Kopieer de webhook-URL.

   ![](mm5.png)

Nu je een webhook-URL hebt, kun je de koppeling in Loomio voltooien:

[Stel een chatintegratie in Loomio in](../chatbots/#set-up-a-chat-integration)
