# ブックマーク

ブックマークは、後でまた開きたいLoomioの項目を保存する個人用の一覧です。ブックマークは本人にのみ表示され、項目を保存しても他の人には通知されません。

次の項目をブックマークできます。

- ディスカッション
- コメント
- 提案とアンケート
- 投票
- 結論

<!-- translation-section: save-a-bookmark -->

## ブックマークを保存する

項目のアクションメニューを開き、**ブックマークを保存**を選択します。アクションメニューは通常、3つの点で表示されます。ディスカッションの場合は、ディスカッションのタイトル付近にあるアクションメニューを使います。コメント、投票、提案、アンケート、結論の場合は、その項目のメニューを使います。

![](save_bookmark.png)

<!-- translation-section: view-your-bookmarks -->

## ブックマークを表示する

サイドバーを開き、**ブックマーク**を選択します。リンクの横にある数字は、保存したブックマークの数を示します。

ブックマークページでは、最近保存した項目から順に表示されます。各行には、項目の種類と作成者が表示されます。行を選択すると、ブックマークした項目に戻ります。

![](bookmarks_page.png)

<!-- translation-section: remove-a-bookmark -->

## ブックマークを削除する

ブックマークページで、行の末尾にあるブックマーク削除ボタンを選択します。ブックマークした項目のアクションメニューを開き、**ブックマークを削除**を選択することもできます。

ブックマークを削除しても、変更されるのは個人用の一覧だけです。その項目は後で再び保存できます。
