# 다이렉트 토론

다이렉트 토론은 특정 사람들만 참여하는 비공개 토론입니다.

다이렉트 토론은 그룹에 속하지 않습니다. 초대받은 사람은 해당 Loomio 그룹의 멤버가 아니어도 됩니다.

**초대** 입력란에 사람이나 이메일 주소를 추가하여 토론을 보고 참여할 수 있는 사람을 정할 수 있습니다.

다이렉트 토론에서는 그룹 토론과 동일하게 댓글, 투표 및 기타 도구를 사용할 수 있습니다. 하위 그룹을 만들 필요가 없을 때 유용합니다.

![그룹이 선택되지 않고 초대 입력란에 Samira Patel이 추가된 다이렉트 토론 양식](direct-discussion-example.png)

사이드바에서 **개인 스레드**를 선택하면 다이렉트 토론을 볼 수 있습니다. 해당 페이지에서 **새 토론**을 선택하여 다른 다이렉트 토론을 시작하세요.

## 다이렉트 토론으로 연락하기
다이렉트 토론을 사용하면 하위 그룹을 만들지 않고도 한 명 이상의 사람에게 비공개로 연락할 수 있습니다.
