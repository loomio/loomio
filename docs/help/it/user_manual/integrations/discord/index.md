# Integrazione con Discord

Loomio può inviare notifiche ai tuoi canali Discord quando vengono pubblicati nuove discussioni, sondaggi, commenti, voti e conclusioni. Puoi anche inviare manualmente una notifica al canale quando vuoi ricordare alle persone una decisione.

---

1. Apri il tuo server Discord e vai su **Impostazioni del server**.

   ![](server-settings.png)

2. Seleziona **Integrazioni**.

   ![](integrations.png)

3. Seleziona **Aggiungi webhook**, assegnagli un nome come `Loomio`, scegli un canale e copia l'URL del webhook.

   ![](add-webhook.png)

Ora che hai un URL del webhook, completa il collegamento in Loomio:

[Configura un'integrazione con la chat in Loomio](../chatbots/#set-up-a-chat-integration)
