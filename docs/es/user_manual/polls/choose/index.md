# Elegir

Elegir es un sondeo sencillo para encontrar la opción más popular o crear una lista de opciones preferidas. Cada participante selecciona una o varias opciones, según los límites que establezcas. Este método de votación se conoce como opción múltiple.

<!-- translation-section: when-to-use-choose -->

## Cuándo usar Elegir

Usa Elegir cuando las opciones sean distintas y necesites contar cuántas personas seleccionan cada una. Sirve para:

- elegir un lugar de una lista de opciones;
- seleccionar hasta tres temas para un orden del día;
- decidir qué diseño pasa a la siguiente ronda; o
- comprobar qué servicios piensan usar los miembros.

Elegir registra las opciones seleccionadas, pero no la intensidad ni el orden de las preferencias de cada persona. Usa [Puntaje](/en/user_manual/polls/score/) para medir cuánto apoyo recibe cada opción, [Asignar](/en/user_manual/polls/allocate/) cuando haya un presupuesto limitado o [Rango](/en/user_manual/polls/rank/) cuando importe el orden de preferencia.

## Ejemplo: preparar el orden del día de una reunión de planificación

La Cooperativa Oatmilk necesita decidir qué partes de una prueba con botellas retornables requieren más tiempo en su próxima reunión de planificación. El sondeo pide a cada persona que elija hasta dos temas. Los detalles explican cómo se utilizará el resultado, y cada opción incluye información suficiente para distinguirla de las demás.

<!-- translation-section: set-up-the-poll -->

## Configurar el sondeo

Usa una pregunta concreta como título del sondeo. En **Detalles**, explica qué deben tener en cuenta los participantes y qué se hará con el resultado. Añade cada opción disponible y establece las **Opciones mínimas** y las **Máximas opciones**.

![](form.png)

Establece ambos límites en 1 si los participantes deben elegir exactamente una opción. Fija un máximo mayor si quieres crear una lista de opciones preferidas. Evita permitir tantas opciones que los participantes puedan seleccionar casi todas, porque el resultado sería menos útil.

Usa el icono del lápiz junto a una opción para aclarar su significado o añadir una explicación. Esto ayuda cuando el nombre breve de una opción puede interpretarse de distintas maneras.

![](edit_option.png)

En **Más configuraciones**, **Mostrar opciones en orden aleatorio** puede reducir el efecto de presentar siempre la misma opción en primer lugar.

![](random_order.png)

## Votar

El formulario de votación indica cuántas opciones pueden seleccionar los participantes. En este ejemplo, una persona selecciona **Calendario de recogida en cafeterías** y **Proceso de lavado**, y explica cómo se relacionan esas opciones con la prueba.

![](voting.png)

Una explicación puede mostrar por qué importa una opción y qué trabajo esperan los participantes que abarque. Si las explicaciones son importantes para la decisión, configura la opción para pedir el motivo del voto antes de iniciar el sondeo.

<!-- translation-section: read-the-results -->

## Leer los resultados

Los resultados muestran qué proporción del total de selecciones recibió cada opción, cuántas personas la seleccionaron y quiénes no han votado. Como cada persona podía elegir dos opciones, los porcentajes corresponden a las selecciones, no a las personas.

![](results.png)

En este ejemplo, **Calendario de recogida en cafeterías** recibió tres selecciones. **Proceso de lavado** e **Informe sobre la tasa de devolución** recibieron dos cada uno. El resultado respalda dedicar más tiempo del orden del día a la recogida en cafeterías, pero quien organiza la reunión aún debe decidir cómo repartir el tiempo restante entre los dos temas empatados.

## Compartir una conclusión

Cuando se cierre el sondeo, comparte una conclusión. Explica qué hará el grupo con el resultado, incluido cómo se resuelven los empates. Consulta [Compartir una conclusión](/en/user_manual/polls/intro_to_decisions#5-share-an-outcome) para saber cómo funcionan las conclusiones.
