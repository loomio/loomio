# Marcadores

Los marcadores son una lista personal de elementos de Loomio a los que quieres volver. Tus marcadores solo son visibles para ti y guardar un elemento no envía ninguna notificación a otras personas.

Puedes guardar como marcadores:

- discusiones
- comentarios
- propuestas y encuestas
- votos
- conclusiones

<!-- translation-section: save-a-bookmark -->

## Guardar un marcador

Abre el menú de acciones del elemento y selecciona **Guardar marcador**. El menú de acciones suele mostrarse como tres puntos. Para una discusión, usa el menú de acciones junto al título de la discusión; para un comentario, voto, propuesta, encuesta o conclusión, usa el menú de ese elemento.

![](save_bookmark.png)

<!-- translation-section: view-your-bookmarks -->

## Ver tus marcadores

Abre la barra lateral y selecciona **Marcadores**. El número junto al enlace indica cuántos marcadores has guardado.

La página Marcadores muestra primero los elementos que has guardado más recientemente. Cada fila muestra el tipo de elemento y quién lo creó. Selecciona una fila para volver al elemento guardado como marcador.

![](bookmarks_page.png)

<!-- translation-section: remove-a-bookmark -->

## Eliminar un marcador

En la página Marcadores, selecciona el botón para eliminar el marcador al final de una fila. También puedes abrir el menú de acciones del elemento guardado como marcador y seleccionar **Eliminar marcador**.

Eliminar un marcador solo afecta a tu lista personal. Puedes volver a guardar el elemento más adelante.
