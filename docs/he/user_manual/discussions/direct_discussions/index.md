# דיונים ישירים

דיון ישיר הוא דיון פרטי לקבוצה מסוימת של אנשים.

דיון ישיר אינו שייך לקבוצה. אנשים שהוזמנו אינם צריכים להיות חברים בקבוצת Loomio.

כדי לקבוע מי יוכל לראות את הדיון ולהשתתף בו, יש להוסיף אנשים או כתובות דוא״ל לשדה **הזמן**.

בדיונים ישירים אפשר להשתמש בתגובות, במשאלים ובכלים נוספים, כמו בדיונים קבוצתיים. הם שימושיים כשאין צורך ליצור תת־קבוצה.

![טופס לדיון ישיר ללא קבוצה נבחרת, כשסמירה פאטל מופיעה בשדה הזמן](direct-discussion-example.png)

כדי לראות את הדיונים הישירים, יש לבחור **חוטים ישירים** בסרגל הצד. כדי לפתוח דיון נוסף, יש לבחור **דיון חדש** בדף זה.
