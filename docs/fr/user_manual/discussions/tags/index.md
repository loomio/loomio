# Mots-clés de catégorie

Les mots-clés de catégorie vous aident à trouver les discussions et les sondages liés à un type de travail ou à un sujet précis.

Les mots-clés appartiennent à l’ensemble de l’organisation. Un mot-clé utilisé dans un groupe parent est le même dans ses sous-groupes. Vous pouvez ainsi organiser les travaux liés dans toute l’organisation. Loomio affiche les noms des mots-clés par ordre alphabétique et indique leur couleur par un point à côté de chaque nom.

Sur la page de votre groupe, cliquez sur **Mots-clés** au-dessus de la liste des discussions pour voir les mots-clés utilisés dans le groupe actuel. Sélectionnez un mot-clé pour n’afficher que les discussions qui le portent. Utilisez le champ de filtre pour parcourir une longue liste, ou sélectionnez **Afficher davantage** pour inclure tous les mots-clés de l’organisation. Sélectionnez **Montrer moins** pour revenir aux mots-clés du groupe actuel.

![](tags_view.png)

<!-- translation-section: apply-tags -->

## Appliquer des mots-clés

Les membres qui peuvent modifier une discussion ou un sondage peuvent y appliquer des mots-clés.

Lorsque vous créez une discussion ou un sondage, cliquez sur le champ **Mots-clés** et sélectionnez un ou plusieurs mots-clés.

![](tags_add_new.png)

Commencez à saisir du texte pour filtrer la liste. Pour retirer un mot-clé, sélectionnez-le à nouveau ou cliquez sur le × de son étiquette.

<!-- translation-section: create-tags -->

## Créer des mots-clés

Les administrateurs du groupe parent peuvent toujours créer des mots-clés pour ce groupe et ses sous-groupes. Les administrateurs de sous-groupes peuvent créer des mots-clés lorsqu’ils en ajoutent à du contenu dans leur sous-groupe. L’autorisation **Les membres peuvent créer des tags**, activée par défaut, permet aux autres membres qui peuvent ajouter des mots-clés à une discussion ou à un sondage de créer de nouveaux mots-clés. Si cette autorisation est désactivée, les membres peuvent toujours appliquer les mots-clés existants.

Pour créer un mot-clé pendant la création d’une discussion ou d’un sondage, saisissez son nom dans le champ **Mots-clés** et appuyez sur Entrée.

![créer un mot-clé](tags_create_new.png)

![nouveau mot-clé créé](tags_created_new.png)

Choisissez des noms courts et familiers aux membres du groupe, comme Finance, Gouvernance, Emballage ou Partenariats avec des cafés.

<!-- translation-section: edit-tags -->

## Modifier les mots-clés

Seuls les administrateurs du groupe parent peuvent renommer, recolorer, fusionner ou supprimer des mots-clés. Ces changements s’appliquent à toute l’organisation, y compris à ses sous-groupes.

Sur la page du groupe, ouvrez **Mots-clés** et sélectionnez **Modifier les mots-clés**.

![modifier les mots-clés de catégorie](tags_edit_new.png)

Sélectionnez l’icône en forme de crayon à côté d’un mot-clé.

![modifier les mots-clés de catégorie](tags_edit_new_pencil.png)

Modifiez le nom du mot-clé ou choisissez une couleur, puis cliquez sur **Enregistrer**.

![modifier la couleur du mot-clé](tags_edit_name.png)

Cliquez sur **Supprimer** pour retirer le mot-clé de toutes les discussions et de tous les sondages de l’organisation.

![supprimer le mot-clé](tags_delete.png)

### Modifier les mots-clés d’une discussion ou d’un sondage

Pour modifier les mots-clés d’une discussion ou d’un sondage existant, ouvrez-le et cliquez sur le bouton des mots-clés situé près du titre, à côté des mots-clés actuels.

Sélectionnez des mots-clés pour les ajouter ou les retirer. Les changements sont enregistrés immédiatement.

![modifier les mots-clés d’une discussion](tags_thread_edit.png)
