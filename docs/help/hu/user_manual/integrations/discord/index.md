# Discord-integráció

A Loomio értesítéseket küldhet a Discord-csatornáidra új beszélgetésekről, szavazásokról, hozzászólásokról, szavazatokról és következtetésekről. Kézzel is küldhetsz értesítést a csatornára, ha emlékeztetni szeretnéd az embereket egy döntésre.

---

1. Nyisd meg a Discord-szerveredet, és lépj a **Szerverbeállítások** menübe.

   ![](server-settings.png)

2. Válaszd ki az **Integrációk** lehetőséget.

   ![](integrations.png)

3. Válaszd ki a **Webhook hozzáadása** lehetőséget, adj neki nevet, például `Loomio`, válassz egy csatornát, és másold ki a webhook URL-jét.

   ![](add-webhook.png)

Most, hogy megvan a webhook URL-je, fejezd be az összekapcsolást a Loomióban:

[Csevegésintegráció beállítása a Loomióban](../chatbots/#set-up-a-chat-integration)
