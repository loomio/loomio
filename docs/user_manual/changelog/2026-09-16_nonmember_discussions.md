# Let non-members start discussions

Admins of Open and Closed groups can enable **Non-members can start discussions** in group permissions. A Loomio user can choose one of the group's discussion templates and start a discussion. This supports processes where a user nominates themselves or someone else for a position. The user becomes a guest of that discussion without joining the group or gaining access to other private discussions.

The setting is off by default and is not available for Secret groups.

See [Collect nominations](/en/user_manual/discussions/nominations) for a complete example workflow.
