# ブックマーク

ブックマークは、後で見返したい Loomio の項目を保存する個人用の一覧です。 保存した項目は自分にしか表示されず、ブックマークに追加してもほかの人には 通知されません。

次の項目をブックマークできます。

- 議論
- コメント
- 提案とアンケート
- 投票
- 結論

<!-- translation-section: save-a-bookmark -->

## ブックマークを保存する

項目の操作メニューを開き、**ブックマークを保存**を選択します。操作メニューは 通常、3つの点で表示されます。議論の場合はタイトルの近くにある操作メニューを 使います。コメント、投票、提案、アンケート、結論の場合は、それぞれの項目にある メニューを使います。

![](save_bookmark.png)

<!-- translation-section: view-your-bookmarks -->

## ブックマークを表示する

サイドバーを開き、**ブックマーク**を選択します。リンクの横の数字は、 保存したブックマークの数を示します。

ブックマークのページでは、最近保存した項目から順に表示されます。各行には 項目の種類と投稿者が表示されます。行を選択すると、その項目に移動できます。

![](bookmarks_page.png)

<!-- translation-section: remove-a-bookmark -->

## ブックマークを削除する

ブックマークのページで、行の末尾にあるブックマークの削除ボタンを選択します。 ブックマークした項目の操作メニューを開き、**ブックマークを削除**を選択することも できます。

ブックマークを削除しても、自分の一覧から取り除かれるだけです。その項目は 後で再び保存できます。
