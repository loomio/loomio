# Integrations

Connect Loomio with other tools used by your group.

## Choose where work belongs

Loomio complements chat, shared documents, and task-management tools rather than replacing every kind of work.

| Work | Suggested tool |
|---|---|
| Quick questions, social conversation, and timely updates | Chat |
| Collaborative editing of a living document | Shared document |
| Assigning and tracking tasks | Project or task-management tool |
| Important topic-based discussion, broad participation, decisions, and outcomes | Loomio |

Put work in Loomio when people need time to consider a topic, when everyone affected should have a meaningful opportunity to participate, or when the group will need to find the discussion and decision later. Link to the relevant document or task from the Loomio discussion so its context remains easy to find.

## Chat integrations

[Chat integrations](/en/user_manual/integrations/chatbots) post Loomio activity to chat services including Discord, Matrix, Mattermost, Microsoft Teams, and Slack.

## API

Use the [Loomio API](/en/user_manual/integrations/api) to connect Loomio with your own software and automated workflows.
