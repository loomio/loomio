# Kohteiden siirtäminen keskusteluketjujen välillä

Siirrä valitut kohteet, kun keskustelu kuuluu toiseen ketjuun, ketju on jakautunut eri aiheisiin tai haluat yhdistää toisiinsa liittyviä keskusteluja. Erillistä **Yhdistä keskustelut** -toimintoa ei ole.

Toiminto on ryhmän ylläpitäjien käytettävissä. Myös jäsenet voivat käyttää sitä, jos **Jäsenet voivat hallita keskusteluja ja kommentteja** on käytössä [ryhmän käyttöoikeuksissa](/en/user_manual/groups/settings/permissions).

Avaa kohteen kolmen pisteen valikko (**⋯**) ja valitse **Siirrä kohde**.

![](../using_discussions/comment_move.png)

Valitse kohteet, jotka haluat siirtää.

![](../using_discussions/comment_select.png)

Valitse mahdolliset muut kohteet valintaruuduilla ja napsauta sitten keskustelun yläreunan palkista **Liikkua**.

![](../using_discussions/move_items.png)

Valitse ryhmä tai alaryhmä ja etsi sitten keskustelu, johon haluat siirtää kohteet.

Jos haluat siirtää kohteet uuteen keskusteluun, valitse **Uusi keskustelu** ja lisää sille otsikko ja taustatiedot.

![](../using_discussions/move_items_new_thread.png)

Kohteet siirtyvät alkuperäisestä ketjusta valittuun tai juuri luotuun ketjuun.

![](../using_discussions/new_thread.png)

Jos alkuperäistä ketjua ei enää tarvita, voit [lukita sen](/en/user_manual/discussions/using_discussions/#lock-or-unlock-a-thread). Poista se vain, jos olet varma, ettei sitä tarvita enää.
