# Резервне копіювання або експорт даних групи

За допомогою експорту даних групи ви можете:

- Завантажити дані учасників, щоб перевірити склад групи.
- Архівувати або аналізувати теми, коментарі та опитування вашої групи.
- Відкрити результати опитувань в електронній таблиці або обробити їх за допомогою скрипту.
- [Друкувати або зберігати теми чи опитування у форматі PDF для власного архіву.](#print-thread-to-pdf)
- Перенести вашу групу разом із користувачами, темами, опитуваннями та файлами на інший сервер Loomio.

Ви можете скористатися цією функцією, щоб перейти із сервісу, який розміщує Loomio, на [власний сервер](https://github.com/loomio/loomio). Якщо ви використовуєте власний сервер і хочете перейти на керований хостинг Loomio у США, ЄС або Австралії, [зв’яжіться з нами](/contact).

[Зв’яжіться з нами](/contact), якщо ви хочете перенести групу з loomio.com до регіонального сервісу (loomio.eu для Європи або loomio.nz для Австралії та Нової Зеландії).

## Експорт даних

Експортувати дані групи може лише адміністратор групи. Відкрийте **Налаштування** на сторінці групи та виберіть **Експортувати дані групи**.

![Дія «Експортувати дані групи» на сторінці налаштувань Oatmilk Cooperative](group_export_group_data.png)

Loomio готує експорт у фоновому режимі й надсилає вам електронною поштою посилання для завантаження, коли він готовий. Посилання залишається активним протягом одного тижня.

<!-- translation-section: export-group-data-as-csv -->

### Експорт даних групи у форматі CSV

Використовуйте CSV, щоб переглядати дані групи, зокрема відомості про учасників та їхню активність, в електронній таблиці, наприклад у Microsoft Excel або Google Sheets.

<!-- translation-section: export-group-data-as-html -->

### Експорт даних групи у форматі HTML

Використовуйте HTML, щоб зберегти придатну для читання копію обговорень і опитувань вашої групи для архівування.

<!-- translation-section: export-group-data-as-json -->

### Експорт даних групи у форматі JSON

Використовуйте JSON, щоб перенести дані вашої групи на власний сервер Loomio.

Експорт у форматі JSON містить:

- Групу, її учасників і запити на приєднання
- Теми, коментарі, реакції, теги, шаблони, сповіщення та пов’язані записи з груп, включених до експорту
- Опитування, варіанти, голоси та висновки; анонімне опитування включається лише після його закриття
- Підгрупи, до яких ви належите
- Відкриті, закриті та видимі для батьківської групи підгрупи, якщо ви експортуєте їхню батьківську групу як її адміністратор, навіть якщо ви не належите до цих підгруп
- Посилання на файли та зображення, прикріплені до вмісту, включеного до експорту

Експорт у форматі JSON не містить:

- Таємних підгруп, до яких ви не належите, зокрема даних про їхніх учасників і вмісту
- Підгруп, що очікують на видалення
- Анонімних опитувань, які ще не закрито
- Прямих тем і опитувань, які не належать до групи

## Друк теми у PDF

Щоб зберегти окрему тему для власного архіву, відкрийте її меню дій та виберіть **Друкувати**. Loomio створює HTML-сторінку з коментарями, опитуваннями, голосами, висновками та форматуванням теми. Скористайтеся функцією друку у вашому браузері, щоб надрукувати сторінку або зберегти її у форматі PDF, або скопіюйте вміст в інший документ.

![Дія «Друкувати» для обговорення пляшок, що підлягають поверненню](discussion_print_discussion.png#width-90)

## Імпорт даних вашої групи на інший сервер Loomio

Цей розділ призначений для адміністраторів, які керують власним сервером Loomio. Інструкції з налаштування дивіться в [репозиторії Loomio](https://github.com/loomio/loomio).

1. Скопіюйте файл `.json` до папки `import` контейнера:

```sh
scp your-group-data.json username@some-domain.org:loomio-deploy/import
```

2. Відкрийте консоль Rails у запущеному контейнері:

```sh
docker exec -ti loomio-app rails console
```

3. Викличте сервіс імпорту:

```ruby
GroupExportService.import('/import/your-group-data.json')
```
