# הצעות

הצעה מבקשת מאנשים להגיב לאמירה או לדרך פעולה. המשתתפים בוחרים תשובה מתוך אפשרויות מוגדרות ויכולים להסביר את הצבעתם. ניתן להשתמש בהצעה כדי לאסוף משוב, לבקש עצה, לזהות התנגדויות או לבדוק אם יש הסכמה.

בחלק זה מוסבר כיצד לבחור ולהפעיל את תבניות ההצעה המוגדרות כברירת מחדל ב־Loomio. לתהליך מלא הכולל דיון, הצעות, תיקונים ומסקנה, אפשר להיעזר ב[מדריכים לקבלת החלטות](/en/guides/making_decisions/). לשינוי התבניות הזמינות לקבוצה, ראו [תבניות סקר](../poll_templates/).

## תבניות נוספות להצעות

Loomio מציעה גם תבניות כגון הצעה, שיפועים של הסכמה, סבב שאלות ורוב. חלקן מוסתרות בתחילה. מנהלי הקבוצה יכולים להפוך אותן לזמינות או ליצור תבנית המתאימה למונחים ולכללים של הקבוצה דרך [תבניות סקר](../poll_templates/).

## תיעוד ההצעה

ההצבעות והנימוקים מתעדכנים כל עוד ההצעה פתוחה, והמשתתפים יכולים לשנות את תגובתם. לאחר סגירת ההצעה, יש לפרסם [מסקנה](../outcomes/) המציינת את ההחלטה או את הצעד הבא. הדיון, ההצעה, ההצבעות, הנימוקים והמסקנה מתעדים כיצד הגיעה הקבוצה להחלטתה.
