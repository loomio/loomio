# Loomioのファシリテーターガイド

オンラインでファシリテーションの主要な考え方を実践するための詳しいガイドです。

Loomioはファシリテーターによって作られました。その経験は設計に大きく影響しています。このガイドでは、その背景を紹介し、対面でのファシリテーションの考え方をオンラインでどう生かすかを説明します。

<!-- translation-section: more-about-this-guide -->

## このガイドについて

専門のファシリテーターが進行する場合も、参加者同士で進行を助け合う場合も、ファシリテーションを意識していないグループが使う場合も、Loomioの基本的な役割は同じです。グループのコミュニケーションを仲立ちし、目指す結論に向けて支えます。つまり、ファシリテーションです。

Loomioは*グループウェア*です。

> 共同作業ソフトウェア（グループウェア）は、共通の課題に取り組む人々が目標を達成できるように設計されています。初期の定義の一つは「意図的なグループのプロセスと、それを支えるソフトウェア」です。-- Wikipedia

対面でのファシリテーションとオンラインでの議論の進行には、それぞれ豊富な知識や実践例、伝統があります。一方、両者を組み合わせる方法はまだ発展途上です。Loomioはこの分野に力を入れています。
