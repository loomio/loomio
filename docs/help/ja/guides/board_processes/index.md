# Loomioを活用した適切な組織運営ガイド

適切な組織運営には、理事会の会議だけでなく、会議の前後の円滑なコミュニケーションも必要です。

このガイドでは、理事会や委員会でLoomioを活用し、会議と会議の間も連絡を取り合い、緊急の案件に対応し、理事会の事務負担を減らす方法を紹介します。
- 会議と会議の間も組織運営を継続する
- コミュニケーションの経緯を把握する
- 理事会の会議を重要な課題の検討に使う
- 詳細な記録で組織の知識や経験を引き継ぐ

Loomioは、協力して活動する理事会や委員会のための、多用途なディスカッションと意思決定のツールです。

以下では、理事会や委員会で一般的に行われている実務の例と、Loomioでそれらを実践する方法を紹介します。

## 理事会にディスカッションと決定のためのオンラインの場が必要なのはなぜですか？

適切な組織運営とは、組織の状況に合った仕組みや手順が整備され、それらによって組織が目的を効果的に追求し、法的な義務を果たせる状態です。

*「参加を促し、コンセンサスを重視し、説明責任と透明性を備え、状況に対応し、効果的かつ効率的で、公平かつ包摂的であり、法の支配に従います。」* [国連アジア太平洋経済社会委員会](https://www.unescap.org/sites/default/d8files/knowledge-products/good-governance.pdf)。

これらすべての原則を支えるのが、円滑なコミュニケーションです。

理事や理事会が直面する課題には、次のようなものがあります。

* 理事が対面で集まること
* 重要な課題を検討する時間の確保
* コミュニケーションの経緯の把握
* 重大な課題への緊急対応
* オンラインのビデオ会議による疲労
* 理事が離れた複数の場所におり、インターネット接続が不安定な場合もあること
* 組織運営の実務や経験の違い
* 大量の日常業務への対応
* 組織の知識や経験の継承

Loomioを使うことで、組織運営を強化し、理事会の会議以外でも協力を進め、すべての人が率直で誠実な、互いを尊重するディスカッションに参加でき、その過程をすべて記録できます。
