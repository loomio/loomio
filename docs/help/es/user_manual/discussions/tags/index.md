# Etiquetas de categoría

Las etiquetas de categoría te ayudan a encontrar discusiones, encuestas, conclusiones y comentarios sobre un tipo de trabajo o tema concreto.

Las etiquetas pertenecen a toda la organización. Una etiqueta utilizada en un grupo principal es la misma en sus subgrupos, lo que permite organizar el trabajo relacionado en toda la organización. Loomio muestra los nombres de las etiquetas en orden alfabético y sus colores como puntos junto a los nombres.

En la página de tu grupo, haz clic en **Etiquetas**, encima de la lista de hilos. Selecciona una etiqueta para mostrar los hilos que contienen al menos una contribución con esa etiqueta. Usa el campo de filtro para buscar en una lista larga.

![](tags_view.png)

<!-- translation-section: apply-tags -->

## Aplicar etiquetas

Puedes etiquetar tus propias discusiones, encuestas, conclusiones y comentarios. Los admins del grupo, los admins del hilo y las personas con permiso para editar el contexto de la discusión pueden etiquetar cualquier contribución en un hilo desbloqueado. En los hilos directos, todos los participantes pueden etiquetar cualquier contribución.

Cuando inicies un hilo o una encuesta, haz clic en el campo **Etiquetas** y selecciona una o varias etiquetas.

![](tags_add_new.png)

Empieza a escribir para filtrar la lista. Para quitar una etiqueta, selecciónala de nuevo o haz clic en la × de la ficha de esa etiqueta.

<!-- translation-section: create-tags -->

## Crear etiquetas

Los admins del grupo principal siempre pueden crear etiquetas para el grupo principal y sus subgrupos. Los admins de los subgrupos pueden crear etiquetas al etiquetar contenido en su subgrupo. El permiso del grupo **Los miembros pueden crear etiquetas**, activado de forma predeterminada, permite que otros miembros que pueden etiquetar contenido creen nuevos nombres de etiquetas. Si el permiso está desactivado, los miembros pueden usar las etiquetas existentes de la organización y los nombres de etiquetas definidos por las plantillas del grupo de destino.

Para crear una etiqueta al iniciar un hilo o una encuesta, escribe su nombre en el campo **Etiquetas** y pulsa Enter.

![crear una etiqueta nueva](tags_create_new.png)

![etiqueta nueva creada](tags_created_new.png)

Usa nombres cortos y conocidos que los miembros del grupo reconozcan, como Finanzas, Gobernanza, Embalaje o Colaboraciones con cafeterías.

<!-- translation-section: template-tags -->

## Etiquetas en las plantillas

Las plantillas de discusiones y encuestas guardan nombres de etiquetas como valores predeterminados. Cualquier persona que pueda crear o editar una plantilla puede cambiar libremente sus nombres de etiquetas. Guardar o consultar una plantilla no añade estos nombres a la lista de etiquetas de la organización. Cambiar el nombre de una etiqueta de la organización o eliminarla no modifica los valores predeterminados de las plantillas.

Cuando una discusión o una encuesta usa esos valores predeterminados, Loomio aplica una etiqueta existente de la organización o la crea si está permitido. Un miembro sin permiso para crear etiquetas puede seguir usando los nombres definidos por las plantillas disponibles en el grupo de destino. Una plantilla de otro grupo no concede permisos adicionales para crear etiquetas: sus valores predeterminados solo se conservan si la organización de destino ya tiene esas etiquetas o si una plantilla del grupo de destino define esos nombres. Los demás nombres se descartan. Los miembros que pueden crear etiquetas pueden conservar todos los valores predeterminados de la plantilla.

## Editar etiquetas

Solo los admins del grupo principal pueden cambiar el nombre o el color de las etiquetas, fusionarlas o eliminarlas. Estos cambios se aplican a todos los usos de las etiquetas en toda la organización, incluidos sus subgrupos.

En la página del grupo, abre **Etiquetas** y selecciona **Editar etiquetas**.

![editar etiquetas de categoría](tags_edit_new.png)

Selecciona el icono del lápiz junto a una etiqueta.

![editar etiquetas de categoría](tags_edit_new_pencil.png)

Edita el nombre de la etiqueta o elige un color y luego haz clic en **Guardar**.

![editar el color de la etiqueta](tags_edit_name.png)

Haz clic en **Eliminar** para quitar la etiqueta de las discusiones, encuestas, conclusiones y comentarios de toda la organización.

![eliminar etiqueta](tags_delete.png)

### Editar etiquetas en un hilo o una encuesta

Para cambiar las etiquetas de un hilo o una encuesta existente, ábrelo y haz clic en el botón de etiquetas junto a las etiquetas actuales, cerca del título.

Selecciona etiquetas para añadirlas o quitarlas. Los cambios se guardan inmediatamente.

El selector muestra las etiquetas utilizadas en el grupo actual, las etiquetas de la organización que no se utilizan y las etiquetas seleccionadas para la contribución. Cuando hay más etiquetas que solo se utilizan en otros grupos, elige **Muestra etiquetas de otros grupos** para incluir las etiquetas del grupo principal y sus subgrupos dentro de la misma organización. Elige **Mostrar etiquetas utilizadas en este grupo** para volver a la lista más corta. Una organización con un solo grupo no tiene la opción de ampliar la lista.

![editar etiquetas en un hilo](tags_thread_edit.png)

## Etiquetar contribuciones

Abre el menú de acciones de una encuesta, una conclusión o un comentario y selecciona **Aplicar etiquetas**. El mismo selector que se usa junto al título de la discusión te permite añadir o quitar etiquetas. Los cambios se guardan inmediatamente. Cuando una contribución tiene etiquetas, sus fichas y el botón de etiquetas aparecen a la derecha en la línea que muestra el autor y la fecha y hora.

Las etiquetas se aplican a la contribución que seleccionas. Los votos y las papeletas no se pueden etiquetar.

<!-- translation-section: find-tagged-contributions -->

## Encontrar contribuciones etiquetadas

La sección **Etiquetas** aparece en la barra lateral del hilo cuando alguna contribución, además de la discusión o encuesta inicial, tiene etiquetas. Reúne las etiquetas del elemento inicial y de todas las demás contribuciones etiquetadas. Selecciona una etiqueta para mostrar las contribuciones coincidentes con el contexto al que pertenecen. Mientras el filtro está activo, una barra de herramientas permanece visible encima del hilo. Ciérrala con el botón × de la derecha, selecciona la etiqueta de nuevo o elige **Limpiar** en la barra lateral para volver a la vista habitual del hilo. En el móvil, abre el panel de navegación del hilo para usar el mismo filtro.

![Etiquetas en la barra lateral del hilo](tags_thread_sidebar.png)

<!-- translation-section: global-search -->

## Buscar por etiqueta

Abre **Buscar** desde la navegación superior y selecciona tu grupo principal para mostrar el menú de etiquetas. Elige una etiqueta para encontrar discusiones, encuestas, conclusiones y comentarios que tengan esa etiqueta.

Deja el campo de búsqueda vacío para explorar por etiqueta, o introduce una palabra o frase para buscar en las contribuciones etiquetadas. Selecciona **cualquier etiqueta** para quitar el filtro de etiquetas.

![Selección de una etiqueta en la búsqueda global después de elegir el grupo principal](tags_global_search.png)
