# Mattermost連携

Loomioでは、新しいディスカッション、アンケート、コメント、投票、結論が投稿されると、Mattermostのチャンネルに通知を送信できます。

---

1. ブラウザーでMattermostのチームを開き、**統合**に移動します。

   ![](mm1.png)

2. **受信ウェブフック**を選択します。

   ![](mm2.png)

3. **受信ウェブフックを追加**を選択します。

   ![](mm3.png)

4. 名前を入力し、通知を表示するチャンネルを選択して、**保存**を選択します。

   ![](mm4.png)

5. ウェブフックURLをコピーします。

   ![](mm5.png)

ウェブフックURLを取得したら、Loomioで接続の設定を完了します。

[Loomioでチャット連携を設定する](../chatbots/#set-up-a-chat-integration)
