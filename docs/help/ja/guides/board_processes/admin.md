# 管理と記録の保管

理事会や委員会にとって、管理業務と監査に備えた適切な記録の保管は重要であり、法律で義務付けられている場合もあります。

紙の記録に代わって、電子記録が使われるようになっています。

デジタルツールを使うと、理事会は会議の議事録を保管するだけでなく、さまざまな業務を行えます。

理事会の運営を変える：

*「理事会のグループは、運営を大きく変えました。継続的なガバナンスを可能にし、対応時間を短縮し、柔軟性、回復力、持続可能性を高めています… Loomioによって、毎年数千ポンドの経費を削減できています」*
- Austen Cordasco、Co-operative Assistance Network Limited（CAN）、事業支援サービス、英国

Loomioで作業を整理し、ディスカッションを管理し、データを安全に保ち、記録を保管する方法を見ていきます。

<!-- translation-section: administering-discussions -->

## ディスカッションの管理

Loomioには、ディスカッションの管理に役立つさまざまな機能があります。ディスカッションの右側にあるドロップダウンメニューから利用できます。

次の機能を使って、ディスカッションの一覧を整理できます。

- **ピンの議論**で、重要なディスカッションを一覧の先頭にピン留めします
- **スレッドを編集する**で、ディスカッションのタイトルを変更したり、背景説明を更新したりします
- **グループに移動**で、ディスカッションを別のグループやサブグループ、または記録保管用のグループに移動します
- **スレッドをロック**で、コメントの追加や変更を防ぎ、進行中のスレッドの一覧から除外します。ロックしたスレッドは、ディスカッションのフィルターや検索バーから見つけられ、いつでもロックを解除できます
- **ディスカッションを削除**で、記録を残す必要のないディスカッションを削除します。削除したディスカッションは復元できません

![](thread_admin.png#width-90)

<!-- translation-section: category-tags -->

## 分類用のタグ

分類用のタグをディスカッションに付けると、見つけやすくなります。タグを設定し、各ディスカッションに一貫した基準で付けてください。

理事会でよく使われるタグには、管理、年次総会、理事会、報告、財務、法務、メンバー、議事録、計画、方針、決議、定款、総会、戦略などがあります。

グループのメンバーは、**タグ**のドロップダウンメニューから、タグでディスカッションを検索できます。

![](thread_tags.png#width-90)

<!-- translation-section: maintaining-the-discussion-topic -->

## ディスカッションの話題を保つ

ディスカッションを一つの話題に絞ると、参加者全員が話し合いを進めやすくなります。

ディスカッションの途中で新しい話題が出た場合は、該当するコメントを選択して別のディスカッションに移動したり、新しいディスカッションを開始したりできます。

![](thread_comments_move.png#width-90)

<!-- translation-section: subgroups -->

## サブグループ

サブグループを使うと、連絡やメンバーを整理し、必要な人たちが一緒に作業できるようになります。例えば、小委員会や作業部会にサブグループを使えます。

[サブグループの設定。](/en/user_manual/groups/subgroups)

<!-- translation-section: archiving-records -->

## 記録の保管

スレッド内のディスカッションやアンケートでの決定を記録として残すには、**[スレッドを印刷](/en/user_manual/groups/data_export#print-thread-to-pdf)**を使い、PDFとして保存します。その後、スレッドの写しを任意の文書保管先に保存できます。

Loomioグループのデータをすべて記録として残すには、**[グループのデータをエクスポート](/en/user_manual/groups/data_export#group-data-backup-or-export)**を使います。

<!-- translation-section: data-storage -->

## データの保存

Loomioのクラウドサービスでは、データを複数のディスクに即座に書き込み、毎日バックアップを取り、複数の場所に保存することで保護しています。

スレッド、コメント、アンケート、添付ファイルのすべてのデータを、この方法で保存しています。

スレッドに添付されたファイルは、ファイルタブでも確認できます。

![](files_tab.png#width-90)
