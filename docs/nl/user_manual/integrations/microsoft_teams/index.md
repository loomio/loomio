# Microsoft Teams-integratie
_Koppel de meldingen van je Loomio-groep aan Microsoft Teams._

Loomio kan meldingen naar Microsoft Teams sturen bij nieuwe discussies, voorstellen, reacties, stemmen en conclusies.

---

Ga naar [https://teams.microsoft.com](https://teams.microsoft.com) en klik op Apps
![](t1.png)

Zoek in het zoekveld naar "webhook" en klik op Incoming Webhook
![](t2.png)

Klik op "Add to a team"
![](t3.png)

Typ de naam van het kanaal waarin je Loomio-meldingen wilt ontvangen en selecteer het.
![](t4.png)

Geef de webhook een naam, bijvoorbeeld "Loomio-meldingen", en klik op "Create"
![](t5.png)

Kopieer de URL die je krijgt. In de laatste stap plak je die in Loomio.
![](t6.png)

_Loomio is niet gemaakt door Microsoft en is niet aan Microsoft verbonden of wordt niet door Microsoft ondersteund._

Nu je een webhook-URL hebt, kun je de chatintegratie verder instellen:

[Stel een chatintegratie in Loomio in](../chatbots/#set-up-a-chat-integration)
