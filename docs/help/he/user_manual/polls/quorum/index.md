# מניין השתתפות

מניין הוא האחוז המזערי של מצביעים בעלי זכות הצבעה שהשתתפותם נדרשת כדי שהסקר יהיה תקף. ניתן להשתמש בו כאשר תהליך קבלת ההחלטות מחייב רמת השתתפות מסוימת.

בעת יצירת סקר, יש לפתוח את **הגדרות נוספות** ולהזין את האחוז הנדרש בשדה **מניין ההשתתפות**. כשאין צורך במניין, יש להשאיר את השדה ריק.

![הגדרת המניין עם מניין השתתפות של 60 אחוז](./quorum-section.png)

ניתן גם להגדיר מניין ב[תבנית סקר](/en/user_manual/polls/poll_templates/), כך שסקרים שייווצרו מהתבנית ישתמשו בו כברירת מחדל.
